## 六、处理逻辑伪代码

遵循 BNOS 节点开发规范：`main.py` 从 stdin 读 JSON、stdout 写 JSON、不依赖任何 BNOS 模块、多端口用 `filter` 路由不用 if-else 分发。

```python
import json, sys, psutil, time
from datetime import datetime

def collect_env_data(config):
    data = {"timestamp": datetime.now().isoformat()}
    if config.get("monitor_cpu"):
        data["cpu_percent"] = psutil.cpu_percent(interval=1)
    if config.get("monitor_mem"):
        mem = psutil.virtual_memory()
        data["memory_percent"] = mem.percent
        data["memory_used_gb"] = round(mem.used / 1024**3, 2)
    if config.get("monitor_time"):
        data["current_time"] = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    return data

def main():
    config = load_config()
    interval = config.get("interval_sec", 30)
    
    # 单次采集模式（BNOS listener 会定期触发）
    env_data = collect_env_data(config)
    output = {"data_type": "json", "content": env_data}
    sys.stdout.write(json.dumps(output, ensure_ascii=False))
    sys.stdout.flush()
```
