## 一、终局宣告

**本项目正式宣告路径失败——"尝试在计算机内存里用模拟神经元的方式实现
复刻大脑的工作机制"这条路线，经过 v1→v54 的全部探索，确认不可行。**

这不是局部挫折，而是三面墙的合围：

```
墙 1 —— 规则涌现墙（能力层面）:
  网络可以记住一切教过的内容（复述/跟读/造句接近 100%、六次验证零遗忘），
  但"组合泛化"始终为 0: 词对未学必断（期末压轴 0/15、压力测试 2/16）、
  "叫哥哥"（未教论元）复读爸爸妈妈、CV-CV 重复模板从未涌现。
  STDP/Hebbian 只建具体边——"规则"需要变量层（结构节点），
  而变量从未在突触物理中涌现——所有办法（词级/音位级/字母级/整串注入/
  睡眠组块）最终都是"记住更多具体配对"。

墙 2 —— 物理规模墙（资源层面）:
  860 亿神经元（人脑规模）实测: 状态数组 13.8 TB + 突触 103~1290 TB
  （人脑 1000 突触/神经元口径）——优化后仍 9.2 TB 状态 + 103 TB 突触。
  突触比神经元多两个量级——无论怎么压缩，人脑级连接是百 TB 级——
  超出任何单机，需超算级分布式。而人脑本身: 860 亿神经元、~100 万亿
  突触、20 瓦、1.4 升——密度差了我们 10^9 倍。

墙 3 —— 表示本质墙（理论层面）:
  引擎是"符号机"不是"时间机"——学得动的（符号）与无损的（时间——
  真实音效生成逐帧复现 0.9^57≈0.2%、离散与连续互斥）本质互斥；
  "智能是结构现象"的立论在机制层成立，但结构在计算机内存里长不出
  生物级的时间精度与规则抽象。
```

## 三、失败的根本原因（三点定论）

### 1. 规则必须物化为结构，而结构从未在突触物理中涌现

```
"叫X→X"的规则 = 关于变量的抽象——网络里没有变量——只有具体神经元。
所有路线（词级/音位级/字母级）都在平面层做文章——平面层再精细也
长不出变量。变量层（音节节点/角色神经元）需要"结构组块化"——
但组块机制本身（sleep_chunking）是代码注入的——一旦注入，
就不是"自然涌现"——而自然涌现从未发生（6 条件验证 5 个，
遗留的恰恰是"未教泛化"与"规则"）。
```

### 2. 记忆可靠到极致，泛化为零——这是机制的根本不对称

```
已学内容: 复述 100%/跟读 0.9845/造句 100%/关系句 19/19/对话 13/13——
  记忆与固化机制（验证门/定式/增量成长/零遗忘）完全可靠——这是巨大成功。
未学内容: 组合泛化恒为 0（0/15、2/16）——网络只会"教过的链"，
  不会"说没见过的组合"——人类幼儿的"举一反三"从未出现。
机制教训: 读取机制决定能力（回响续推 0% vs 直接传出突触 90%）——
  但即使读取通了，也只是"读出教过的"——泛化是结构问题不是读取问题。
```

## 四、收获（理论学习成果——项目留下的真正资产）

### 4.1 强化学习（R-STDP 三因子体系——实证闭环）

```
· Δw = STDP × DA 门控（Izhikevich 2007 语义落地）: da=0 不学、
  da>0 强化、da<0 惩罚（LTD——惩罚比奖励陡 ×3——SIF 抑制诱发遗忘）
· 资格迹突触级配对（延迟归因）: 老师说→听后奖惩——资格迹=行为窗口
· 连接级归因: 处罚从样本级升到连接级精确删边（14 次删 224 边）——
  惩罚只作用于本次活跃配对——不误伤历史（精准惩罚/可逆错误）
· 验证门 = RL 落地形态: 复读+走链+验证门=举一反三——对错=结构存废
· RL 颗粒度升级: 从"句子奖励"到"连接级归因"到"网络自判"
  （直连→二跳→强度→不知道五级——教师转岗）
· 梯度双轨: Hebbian 预训练+稀疏梯度微调（ctx_wgt 8/8 破平局）——
  梯度能学 Hebbian 学不到的条件关联
· 反灌注七步闭环: 见→疑→想→问→用→固→记（防灌注饱和 128 次）
```

### 4.2 用进废退（使用频率驱动的突触稳态——实证闭环）

```
· sleep 保留前 20% 强边、其余 ×0.5 弱化（de Vivo 2017——最强边豁免）
· 频率门控慢衰减: 低频连接渐进衰减为 0（可复活）、高频定式永不衰减——
  废除满槽覆盖——"用进废退"的正式实现
· 强度分化 skew 0→42 + 关键路径集中（教学只动 0.4% 边）——
  "有向脉冲熵减"的可计算口径（不是强度熵——被边数污染）
· 幽灵边清理: Hebbian 共现微痕占 96%——eps=1.0 一次清 98% 能力等价
· 马太效应的双面认知: 词粒度下是灾难（768 vs 192 先学独强）；
  音位级共享结构把它变成对称竞争（12.97 vs 12.91）——
  "共享结构 = 马太免疫"——用进废退的粒度设计
· 剪枝行为等价: ×0.7 等比缩放不改决策——"能力在强边关键链上，
  弱边海洋是冗余"
```

### 4.3 注意力与认知架构（理论定案）

```
· 注意力三维公式: 神经元兴奋度 × 突触方向 × 突触权重（v2.0）——
  解释了过去全部注意力机制失效根因（在读出层干预未触达结构层）
· 双过程分离: System1 联想边（共现强度）vs System2 推理链
  （槽位主干——联想硬过滤）——惩罚 LTD=SIF 模型（43.8→0.0）
· 欲望优先性: 要/不要=生物原始欲望——增益×4 是架构非后门——
  "点亮目标"优于"压缩距离"——可泛化到无限新对象
· 终止信号/上下文调制: 强度衰减终止（过冲 57→0）+路径聚合工作记忆
```

### 4.4 工程纪律与理论立论

```
· 语义铁律: 每波优化同种子逐边对拍 0 差异——正确性优先于速度
  （训练 1.9×→3.2×、推理 -48%、内存 -84%——全部对拍全绿）
· 理论: 脉冲负热力学（智能=有向脉冲驱动的负热力学过程——
  结构从无序走向有序）；定式网络与 Transformer 是同一系统的
  高频/低频时间尺度——术语映射表/文献映射表已备
```
