## 二、方向 1：非平衡热力学 / 负熵（命名锚点与风险）

| 文献 | 核心主张 | 与课题的关系判定 |
|---|---|---|
| Schrödinger, *What is Life?* (1944) | 生命靠"负熵"维持有序 | 谱系源头；但作者自认这是自由能的通俗表述（"若只给物理学家看，会直接讨论自由能"）——**不可作为物理断言依据，只作命名谱系引用** |
| Prigogine（1977 诺贝尔化学奖） | 耗散结构：开放系统**远离平衡**时可产生有序，且与环境共生、能量流断则结构消失 | **理论定式**：局部熵减不违反第二定律的权威依据——开放系统 dS = dₑS（交换项）+ dᵢS（产生项），第二定律只约束 dᵢS ≥ 0，"负"指向 dₑS < 0 的负熵流方向 |
| Brillouin（negentropy，1959） | 负熵缩写 + 信息论对接（信息 = 负熵） | 给"结构有序度"提供**可计算出口**（信息熵 / Shannon 熵） |
| 批评方：Rudnyi (2025)、Corning (2002)、Mae-Wan Ho (1994)、preprints (2024) | 负熵是循环定义、不可测的隐喻 | **必须知道的雷**：物理语境下"负热力学"易被批伪概念；应对 = 声明机制本体是信息/结构层面有序度，非热力学熵断言 |

## 七、命名风险应对（预设 Q&A，对外口径）

**Q1「负热力学是不是反科学 / 违反热力学第二定律？」**
不违反。开放系统熵变 dS = dₑS + dᵢS，第二定律只约束系统内部熵产生 dᵢS ≥ 0；"负"指负熵流方向 dₑS < 0（Prigogine 非平衡热力学）。局部熵减是开放系统远离平衡时的标准现象（耗散结构），不是例外。

**Q2「负熵（Schrödinger）不是被批为伪概念吗？」**
负熵作为热力学断言确有循环定义问题——Schrödinger 本人承认那是对自由能的通俗表述。但本学科不把"负热力学"当作物理量断言，只作**方向隐喻**；机制本体是**信息/结构层面的有序度**（Shannon 熵可测），与热力学熵断言无关。

**Q3「这和 SNN 有什么区别？」**
SNN 是证明"脉冲能产生智能"的首要途径（同源分支，非划界）。本学科的增量在脉冲网络之上的**自我结构理论**（存续 / 人格 / 身份同一性 / 认知免疫），不在脉冲计算本身。

**Q4「双系统读出不是 CLS 的翻版吗？」**
CLS 是**存储分工**（海马/新皮层两个存储系统）；定式网络是**同一张 W 上的两种读取接口**（走链回响 vs 直接传出突触）——存储同源、读取分工，差异在读出层而非存储层。
