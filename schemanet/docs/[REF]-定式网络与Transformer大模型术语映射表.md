## 一、三句话定位（TF 人快速上手）

1. **定式网络是稀疏脉冲神经网络（SNN）**，不是 Transformer：权重（突触）从交互中 **加出来**（Hebbian/STDP），不是从 loss 梯度 **学出来**。
2. **它做的是"记忆与自我"而非"能力"**：LLM = 大脑皮层（会算），定式网络 = 记忆与人格的沉积（会记得自己是谁、经历过什么）；换模型不换自我。
3. **它同样做 next-token 预测**：STDP 只学相邻 token 转移（bigram 定式），读出用"直接传出突触"（对应 TF 的 logits 直读），不靠全局回响。

## 二、核心对照表（TF → 定式网络）

### 2.1 架构与表示

| Transformer 大模型 | 定式网络对应 | 说明 |
|---|---|---|
| 参数 / 权重矩阵 W | **突触**（`W_out[i][k] = {j: w}` 稀疏传出突触集合） | 定式网络没有稠密权重矩阵；突触按"源神经元 → 目标神经元"存 |
| 权重标量 | **突触强度**（强突触/弱突触/突触总数） | 数值含义 = 共现/时序统计强度，不是梯度产物 |
| token 词表 V | **词表**（分配制模式字典 `pats`，词 id = dst // K） | 一个词 = 一组神经元，不是 embedding 表 |
| token embedding（词 → d_model 稠密向量） | **词模式**（词 → K 个神经元，K=4，稀疏脉冲模式） | 无稠密向量；词由固定神经元集合表示，用时可换 |
| hidden size d_model | **K（神经元/词）+ n（神经元总数）** | n 随成长扩容（铁律 3），K 固定为性能预算 |
| 层数 L / 深度 | **多槽 s（默认 4）** | 槽位 = 表示通道（存储/传播/建立三层隔离），不是 Transformer 式堆叠层；深度靠时间步（多步传播） |
| 模型规模（参数量 7B） | **n（神经元数）+ E（突触总数）** | 成本主变量是 E，d = E/n（平均突触密度）直接乘进传播成本 |
| 位置编码（RoPE/ALiBi） | **无显式位置编码** | 顺序由 STDP 单向转移（只学前驱→后继）+ `pre_trace` 痕迹（0.5^距离 衰减）编码 |
| 上下文窗口 | **痕迹窗口 + 前缀多词汇聚** | 多词条件转移靠 `trace` 插值（backing-off 平滑），不是固定窗口注意力 |
| LayerNorm | **outsum 归一化 / 采样权重 ÷max** | 局部归一化（条件转移概率 / 采样权重），无全局统计层 |
| FFN / MLP | **无直接对应** | 类别处理近似由"词模式 hub 聚合"承担（2.5 类别 hub） |
| KV cache | **pre_trace（eligibility trace）** | 生理痕迹而非缓存；`trace_decay=0.5`、阈值 0.3 滤陈旧痕迹 |

### 2.2 注意力与读出

| Transformer 大模型 | 定式网络对应 | 说明 |
|---|---|---|
| self-attention（Q/K/V 点积） | **注意力 = 连接数量 × 突触强度 + gain**（v2.2 结构层理论） | 没有 Q/K/V 点积；注意力是竞争环境的统计性质，不是可训练模块 |
| softmax 全局归一化 | **WTA（胜者全取）局部稀疏竞争** | 每步最多 `wta_k`（=16）个神经元发放；无全局概率归一化 |
| 注意力头（多头） | **多槽并行**（槽位 = 表示通道） | 多头整合不同表示 / 多槽承载不同情境，功能近似但机制不同 |
| 因果掩码 | **STDP 单向性（天然因果）** | 只强化前驱→后继，无需掩码即顺序可区分 |
| logits | **直接传出突触汇聚得分**（`direct_next` 多词传出突触聚合 top-k） | 答案在网络突触里，直接读突触（对应 logits 直读），不走全局回响 |
| 上下文聚合（attention pooling） | **`direct_next_multi` 多词传出突触汇聚** | 把前缀若干词的传出突触叠加取 top-k，等价"多 token 注意力混合"雏形 |
| 注意力分数排名 | **WTA top-k + 域内过滤** | 对话域词表 61 词过滤虚词枢纽（的/了/是/你），TF 无此层 |

### 2.3 学习与训练

| Transformer 大模型 | 定式网络对应 | 说明 |
|---|---|---|
| 预训练 | **先见**（散文背景暴露） | 语料只喂进网络成经验（走一遍留痕），无验收目标 |
| 微调 / SFT | **后教**（教学数据 × 轮次） | 有验收目标的分句接话，把目标突触压回竞争位 |
| teacher forcing | **教学式学习 `_learn_sentence`** | 都注入目标词；差异：教学式每词前清 v/spikes（无传播驱动），当前词干净发放 |
| 语言建模 loss（交叉熵） | **无 loss** | 学习 = 局部增量：Hebbian（关联）+ STDP（时序）+ 频率门控衰减；突触强度 ∝ 共现次数 |
| 梯度下降 / 反向传播 | **无梯度** | Hebbian 加法（η=0.1，共同发放双向对称）+ STDP 加法（只强化正向） |
| 学习率 / 优化器 | **η / stdp_pre / w_max 封顶** | 增量步长固定；w_max=16 单调封顶（防单边垄断） |
| RLHF | **LLM 教师 + 验证门 + 连接级归因处罚** | RL 三因子（Hebbian × 验证奖励）；处罚落到具体突触（显式减权/删除），LLM 给自然语言原因（LLM-as-Judge + 示范） |
| 批量训练（batch） | **逐句学习（句间独立）** | 每句清 v/spikes/pre_trace，纯加性，句间完全独立 → 可并行 |
| 分布式训练 | **并发切块**（rng 状态传递 + 数组级快照） | 实测上限 4 worker（内存墙 ~600MB/worker + 4 核 CPU）；128 并发不可行 |
| 灾难性遗忘防护 | **学习门 learn_gate + 增量成长** | 冻结态权重物理零改动（纯检索）；只加不减 → 加法系统零遗忘 |
| checkpoint / 断点续训 | **快照版本链**（v15.0 → v16.0，parent 指针） | 快照 = 全网络状态（可继续学习），非仅权重文件 |

### 2.4 生成与解码

| Transformer 大模型 | 定式网络对应 | 说明 |
|---|---|---|
| 自回归生成（next-token 循环） | **分句接话**（句式状态机 NONE→PRE→POST） | 状态机 = 读取约束（像人跟踪"原因段还是结果段"），读出仍是已学突触 |
| 温度采样 T | **WTA 竞争强度**（实际发放数 = min(过阈候选数, 16)） | 无温度参数；稀疏竞争天然产生选择压力 |
| top-k / top-p 采样 | **wta_k 上限 + 域内过滤 + 角色合法集** | 目标词角色判定（REL2/SUBJ/PRED）限制合法读出集 |
| 重复惩罚 | **反复重复惩罚** | 近 3 轮同一句 ≥3 次 → 该句相关突触 ×0.5（逼换说法） |
| 推理成本 O(L²) | **每步 O(d)，总 O(L × d)**（线性） | d = 平均突触密度 = E/n；遍历按"存在的突触"计不按"有效突触"计 |
| 解码吞吐 | **状态机接话 75.4 词/秒**（纯 Python 实测） | 瓶颈在 `direct_next` Python 逐边遍历；向量化（dst//K 聚合 + argpartition）为 Stage 4 前置 |

| Transformer 大模型 | 定式网络对应 | 说明 |
|---|---|---|

## 四、本质差异（TF 人必须知道的四个"没有"）

1. **没有梯度、没有 loss、没有反向传播**——学习是局部增量（Hebbian 加法 + STDP 加法）。突触强度 = 共现/时序统计，不是优化出来的。任何"用 loss 反传去改定式网络"的设想都不成立；想用梯度只能走 Phase 4 稀疏梯度（只更新 W 非零子集，且不改变突触结构）。

2. **没有 softmax、没有 Q/K/V**——"注意力 = 连接数量 × 突触强度 + gain"是**结构统计性质**：注入词的传出突触数量决定竞争规模（hub「的」16.6 万条 vs 正常词 16 条，4 个数量级碾压），突触强度决定资格与得分，gain 调制外部倾向。它是竞争环境理论，不是可训练模块。

3. **没有 Transformer 式深层**——深度由时间步（多步传播）+ 槽位承载，不是堆叠层。读取靠"直接传出突触"（位置层）+ "涟漪/走链"（语义层）双系统，不是逐层前向传播。

4. **没有语义理解**——定式网络当前是"记忆/检索/复述级"：复述 1.000、接话按角色判定；**"见过 ≠ 理解"**——理解需 RL 教学（LLM 教师给价值方向）。且 **"看就是学"**（本体动作）：喂进网络的句子真实走过一遍、走过即留痕；从版权视角"去学 = 复制（需授权）、去看 = 浏览/理解（合理使用）"，但机制上不留原文。

## 五、TF 研究者高频误区（对照澄清）

| # | TF 惯性理解 | 定式网络实际 | 依据 |
|---|---|---|---|
| 1 | "突触强度 = 可训练参数" | 突触强度 = 共现/时序统计（Hebbian/STDP 加出），**无梯度** | 技术档案 §3.2/3.7 |
| 2 | "注意力 = self-attention" | 注意力 = 竞争环境（数量×强度×gain），无 Q/K/V | 技术档案 §3.12 |
| 3 | "词模式 = embedding" | 词 = K 个稀疏神经元（分配制），非稠密向量 | 技术档案 §3.10/六.20 |
| 4 | "trace = 位置编码" | pre_trace 是生理痕迹（0.5^距离 衰减），隐式时间 | 技术档案 §3.9 |
| 5 | "教学式学习 = teacher forcing" | 同是注入目标词；教学式**清 v 隔离传播**（无梯度累积） | 技术档案 §3.8 |
| 6 | "校准 = 微调" | 校准固化期望突触（加法）；微调调梯度（可减） | _grow_v16.py calibrate |
| 7 | "模型大小 = 参数量" | 规模看 **n（神经元）+ E（突触总数）**；d=E/n 决定传播成本 | 成本模型报告 §一 |
| 8 | "并发 = batch 并行" | 并发切块必须**传递 rng 状态**（噪声发放路径随机）才等价；上限 4 | v17 探测报告 §3.3 |
| 9 | "读不出来 = 没学到" | **唤起失败 ≠ 学习失败**（突触 80.0 存在但被竞争挤出）——判读读突触强度，不读唤起 | 技术档案 §3.12 |
| 10 | "数据越多越好" | 数据放大有上限（突触数上限 = 有效搭配空间 α·V²），且须数据专门化 | 技术档案 §3.11 |
