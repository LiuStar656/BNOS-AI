## 一、背景与现状评估

### 1.1 本轮实验证据链（v1.1 → v2.0 的推翻过程）

| # | 实验 | 结果 | 结论 |
|---|---|---|---|
| ① | 26 字母训练（schema_net.py） | 26/26 零遗忘、输入 a 回响 a | **复述/模式固化能力成立**（最早模式） |
| ② | 2 万 vs 20 万真实语料（词接词 W） | 全线下降（wsum 0.1349→0.1220） | w_max 饱和实锤；数据放大无益 |
| ③ | 六引擎对照（wsum/trace/grad/candB/C） | wsum 0.1220 最强，grad 不敌 | 引擎之争无意义（都是词级） |
| ④ | 同末词命中率 | 无引擎超越 wsum | **区分 ≠ 理解** |
| ⑤ | 生成质量对比 | 全部引擎产出"标点+虚词"堆砌 | **模型不会说话**（词接词≠语言） |
| ⑥ | 句记忆检索（稀碎版） | 长位置崩溃（t9+ 0.01） | 逐位置签名=稀碎=失败 |
| ⑦ | 整句涟漪（整句单元） | 复述率 **1.000**、主题唤起强（足球唤足球/电商唤电商）、泛化续写崩（0.0244） | **整句记忆成立 + 语义联想雏形**；缺位置精度 |
| ⑧ | 技术谱系对照 | 复述=Hopfield(1982)；双系统=CLS(1995)；机制=HTM/ART/SNN | 效果未超"记忆检索"层 |

### 1.2 三个根本问题（v2.0 要解决的）

1. **数据不专门**：用混合 TF 语料训练"词接词"，等于直接给小孩发 20 万篇混合文章让他悟——26 字母时代"训练什么就是什么"的原则被丢弃了
2. **每次从头开始**：26 字母、2 万、20 万、w_max 重训、句记忆——每次新网络/新结构，**从未增量成长**（Hebbian 本是累积的，被浪费）
3. **机制错层**：20 万词接词训练把"句子"抹平了——句子级（CLS 海马对应物）从未进入网络结构；整句涟漪证明"句子可以成为记忆单元"，但它是**外挂**，不是网络长出来的

### 1.3 认知启发（用户决策 2026-08-09）

- 人的学习是**条件反射的层级化**：复读 → 下一句 → 词意 → 意思↔意思
- 语文课路径：**老师读一句学生读一句 → 学生自己读 → 理解句意 → 联想 → 举一反三**
- 三字经："读得越多印象越足"，"人之初→性本善"是**局部触发、整块唤起**（非逐词概率）
- **学习是累积的**（词不丢、句不丢），任何实验不得从头开始

## 二、核心原则

**铁律 1：数据专门化**——训练什么就用什么数据，像 26 字母训练就是 26 个字母。词用词数据、句用句数据、文用文数据，禁止用混合语料跳级。

**铁律 2：增量成长**——同一网络持续喂，永不从头开始。每阶段 = 沉淀（学习）→ 冻结（learn_gate=False）→ 验收（零遗忘）→ 再训练。

**铁律 3：神经元逐步扩容**——n 随阶段增大，与数据规模/复杂度匹配（扩容保留旧 W，旧知识零丢失）。

**铁律 4：教学协议**——严格按人语言/认知/逻辑/推理能力顺序递进（§三），前级验收通过才进下级。

## 三、人类学习能力对照

| 年龄段 | 人的能力 | 认知/语言/逻辑/推理对应物 | 定式网络 Stage |
|---|---|---|---|
| 0-1 岁 | 语音复述（咿呀学语） | 复读条件反射（模式固化） | **已完成**（26 字母） |
| 1-2 岁 | 单词命名（妈妈/苹果） | 词模式固化 + 复述 | **Stage 0 词级** |
| 2-3 岁 | 双词组合（妈妈抱/苹果好吃） | 词组合条件反射（bigram 定式） | **Stage 1 词组级** |
| 3-4 岁 | 短句（我要苹果） | 句内转移定式 + 句模式 | **Stage 2 短句级** |
| 4-6 岁 | 复杂句（因果/转折/时间） | 关系定式（因为→所以/虽然→但是） | **Stage 3 复杂句级** |
| 6-12 岁 | 文章阅读、句间逻辑 | 句接句转移 + 文章级记忆 | **Stage 4 文章级** |

## 四、分级成长路线

### Stage 0 词级（复述/命名）——数据：词表

- **数据**：专门词表（高频词 + 类别标签，如 {苹果, 香蕉, 汽车, 奔跑}）
- **训练**：每词反复经历（Hebbian 模式固化），输入词 → 回响词
- **验收**：词复述率（输入 w 判读 w）≥ 0.95；**零遗忘**（全部词学完，前面的还在）
- **n**：起于小规模（26 字母 n 级，如 256-512）

### Stage 1 词组级（组合）——数据：词对/词组

- **数据**：专门词组（主谓/动宾/修饰：苹果好吃 / 妈妈抱 / 很快）
- **训练**：词组反复经历，沉淀词组内转移（w1→w2 定式）+ 词组模式
- **验收**：词组内续词 top-1；"先学 a 再学组合，原子保留"（26 字母 combo 实验口径）
- **n**：首次扩容（512 → 1024，模式空间翻倍，词组区分度需求）

### Stage 2 短句级（句内结构）——数据：规范短句

- **数据**：专门短句（≤8 词主谓宾，无噪声：我要苹果 / 他喜欢吃西瓜）
- **训练**：短句反复经历（**跟读 + 复读**），整句涟漪 = 句模式（记忆单元）
- **验收**：句复述率（输入整句→唤起整句）≥ 0.95；整句涟漪匹配（主题唤起正确率）
- **n**：扩容（1024 → 2048-4096）

### Stage 3 复杂句级（关系）——数据：因果/转折句

- **数据**：含关系标记的专门句（因为…所以… / 虽然…但是… / 先…然后…）
- **训练**：复杂句反复经历，沉淀**关系词转移定式**（因为→所以 的强关联）
- **验收**：关系词对补全（因为→? 答所以）；句复述不退化（Stage 2 零遗忘）
- **n**：扩容（4096 → 8192，当前规模）

### Stage 4 文章级（句间逻辑）——数据：相邻句对/段落

- **数据**：专门句对（句 A → 句 B，逻辑衔接：下雨了→带伞出门）
- **训练**：句 A 涟漪 → 句 B 的转移定式（**句接句**，CLS 慢系统的句子级转移）
- **验收**：句 B 唤起率（输入句 A 涟漪 → 唤起句 B）；词级不退化
- **n**：扩容（8192 → 16384）

### Stage 5 推理级（概念）——数据：逻辑推理文本

- **数据**：专门推理语料（类比/三段论/条件推理）
- **训练**：概念涟漪 ↔ 概念涟漪转移 + 涟漪泛化（半句唤起类似句）
- **验收**：多步逻辑链补全；举一反三（同主题变体预测一致）
- **n**：按需扩容（16384 → …）

### 每阶段必做（成长协议四件套）

1. 前级零遗忘验收（旧评估集 top-1/复述率不退化）
2. 本阶段专门数据验收（位置分层 / 复述率 / 唤起率）
3. 生成质量对比（本阶段数据上，是否"会说本阶段的话"）
4. **留档（缺一不可）**：result.json（指标）+ **net.npz（模型快照：W + 构造参数 + 模式字典 pats + 分配游标 cursor）** + 数据/分级语料 + memory。**统一走 `snapshot.py`**（2026-08-09 落地）：每次训练按时间戳生成 `runs/{时间戳}/` 快照，追加追溯索引 `runs/index.jsonl`，可 `load_snapshot` 恢复续训——增量成长硬前提

## 五、数据专门化设计

### 5.1 原则

- 每阶段数据**纯净**（只含该阶段结构），禁止混合跳级
- 数据量按阶段递增（词 < 词组 < 短句 < 复杂句 < 文章 < 推理）
- **每阶段内部有重复**（跟读性质：同一内容反复出现，满足"印象越来越足"）
- 全部生成/抽取到 `data/`，可复现、可留档

### 5.2 数据来源（先抽取，后构造）

现有 corpus_open20w.json 可作为**原料库**，按阶段抽取纯净子集：

| Stage | 抽取规则 | 预估量 |
|---|---|---|
| 0 词表 | 词频 top-N（去 UNK、去停用词） | 1000-3000 词 |
| 1 词组 | 高频相邻词对（bigram 专有数据） | 5000-2 万对 |
| 2 短句 | 语料中 ≤8 词、无 UNK 的句子 | 2 万-5 万句 |
| 3 复杂句 | 含 因为/所以/虽然/但是/如果 的句子 | 1 万-3 万句 |
| 4 句对 | 语料中相邻句子对（同段落内） | 2 万-5 万对 |
| 5 推理 | 需专门构造（条件/类比模板） | 数千-数万 |

**关键**：每阶段数据 = "反复读的三字经"——同一批句子多次出现（重复率 ≥ 10 次），不是"每句一次"（v1.1 的错误）。重复率是跟读的本质。

## 六、神经元逐步扩容方案与评估

### 6.1 结论：**可以逐步增加神经元数量，且支持任意粒度（含 n+1）**

v2.1 修订（2026-08-09 用户确认）：用户问题——"n=8032 训练好后，下一次训练能不能 n+1？"答案是**能**。`expand(n_new)` 是纯追加，n_new 可以等于 n+1，也可以一次扩几百（机制等价）。"知识的增量 = 神经元的增量"，新增一个概念（如第 27 个字母）就 +1。

### 6.2 技术路径（已验证代码结构）

```python
def expand(self, n_new):            # SparseSchemaNet 新增方法
    assert n_new > self.n
    pad = n_new - self.n
    self.v            = np.vstack([self.v, np.zeros((pad, self.slots))])
    self.spikes       = np.pad(self.spikes, (0, pad))
    self.pre_trace    = np.pad(self.pre_trace, (0, pad))
    self.last_k_star  = np.pad(self.last_k_star, (0, pad))
    self.refractory_left = np.pad(self.refractory_left, (0, pad))
    self.slot_freq    = np.pad(self.slot_freq, ((0, pad), (0, 0)))
    self.W_out       += [[{} for _ in range(self.slots)] for _ in range(pad)]
    self._edge_cache += [[None] * self.slots for _ in range(pad)]
    self._edge_dirty += [[True] * self.slots for _ in range(pad)]
    self.n = n_new
```

- **旧知识 100% 保留**：W_out 前 n_old 行原样复制（连接结构不动），扩容是纯追加
- 新神经元空白 → 供新阶段学习（新词/新词组/新句模式落位）
- **粒度任意**：`n_new = n + 1`（单个新概念按需落位）或成批扩容（几十上百个），机制等价

### 6.3 关键风险与对策：分配制模式字典（v2.1 修订，取代分区冻结）

旧 `_word_pattern(n, k, word)` 用 `crc32(word)` 做种子、在 `[0, n)` 选神经元——**哈希结果依赖 n**。n 一变，旧词模式重算 → 旧 W 连接失配（灾难），n+1 直接被否。

**对策（分配制模式字典，用户已批准）**：
- **模式字典** `pats: {word: [k 个神经元索引]}` 是唯一事实源：词→神经元落位**生成一次、永久冻结、随网络一起持久化**（npz 附加保存），任何扩容都不重算旧词
- **新词落位 = 分配制**：从当前**空白神经元**按游标顺序取 k 个（分配唯一 → 新词之间零冲突），写入模式字典 +1 条
- **n 只是"可用空间上界"**：旧词条目不动，新词在 [0, n) 的空白区分配；n+1 只是把可用空间扩大 1，完全安全
- 与哈希对比：分配制牺牲"确定性跨语料复用"，换来**任意粒度扩容 + 新词零冲突**，更贴近"新概念要新神经元"的认知模型
- 验收：扩容前后，旧评估集 top-1/复述率**逐值一致**（零遗忘硬指标）；新增词复述可学（增益为正）

### 6.4 扩容触发条件（何时扩）

三种触发，全部走同一 `expand`：
- **按需 +1**：新增单个词/概念，模式字典分配游标到达 n 边界 → `expand(n+1)`（第 27 个字母场景）
- **区分度不足**：词模式冲突率（分配后仍重叠）或"排列一致性"跌破阈值 → 成批扩容（空间换区分度）
- **阶段升级**：词→词组→句→文自带扩容计划（§四 n 表），一次扩一档
- 扩容验证：扩容后新阶段学习增益为正 + 旧阶段零遗忘 → 通过

### 6.5 为什么必须扩容（不固定 n）

26 字母实验实测：n=256 时排列一致性跌到 0.10（模式空间不足，词分不开）。语言复杂度随阶段递增（词 3000 → 词组 2 万 → 句 5 万），固定 n=8192 会重演"区分度塌缩"（对应 20 万语料 w_max 饱和后的分数齐平）。**n 随阶段增大，是语言容量与模式区分度的必然需求**，与大脑随年龄增大同理。

## 七、双系统读出架构（CLS 计算化）

本轮实验确立：词级（wsum）与句级（涟漪）是两个互补系统，单一系统都不够：

| | 位置层（皮层对应物） | 语义层（海马对应物） |
|---|---|---|
| 记忆 | W 转移定式（慢统计） | 整句涟漪（快情景） |
| 精度 | 词级位置（续写） | 句级主题（联想） |
| 实测 | wsum 泛化 0.11 | 复述 1.0、主题唤起强、泛化 0.024 |
| 局限 | 只会词接词（跑偏） | 无位置精度（对不上） |

**协同方案（待 Phase 实现）**：
1. 涟漪唤起主题句集（候选池，语义过滤）
2. wsum 在候选池约束下做位置续写（词级精度）
3. 融合输出：涟漪提供"语义方向"，wsum 提供"位置落点"

引擎定位修订：wsum = 位置层主力（无参直读最快）；涟漪 = 语义层（整句单元）；grad(train_ctx) 降级为可选项（20 万干净 W 实测不敌 wsum，z=-2.91）；trace/pahe/candB/C 归档。

## 八、分阶段实施计划

### Phase A：数据专门化基建
- 写 `_data_curriculum.py`：从 corpus_open20w.json 抽取 §5.2 分级纯净数据 + 控制重复率 → `data/curriculum/`
- 验收：每级数据纯净性（词表检查、句长过滤、关系标记覆盖）

### Phase B：神经元扩容实现
- `SparseSchemaNet.expand(n_new)` + `_word_pattern_new(n_old, n_new, k, word)`（模式分区冻结）
- 扩容前后旧评估逐值一致验收（零遗忘硬指标）

### Phase C：Stage 0-1 重建（词→词组，专门数据）
- 小 n（256→1024）起步，词表 → 词组，跟读重复
- 验收：词复述率 ≥0.95、词组续词、原子保留、扩容零遗忘

### Phase D：Stage 2-3（短句→复杂句，句级复述）
- 短句反复经历（跟读）→ 整句涟漪固化（网络内，非外挂）
- 验收：句复述率 ≥0.95、关系词补全、零遗忘

### Phase E：Stage 4-5 + 双系统协同
- 句接句转移（文章级）+ 涟漪+wsum 协同读出
- 验收：句 B 唤起率、推理链补全、举一反三

## 九、风险评估

| 风险 | 等级 | 应对 |
|---|---|---|
| 模式冻结实现出错（旧词模式被改） | 高 | 扩容前后逐值对拍（旧评估集 top-1 完全一致）为硬验收 |
| 分级数据量不足（抽取太少） | 中 | 语料不够则构造模板数据（生成器）+ 用户提供专门数据 |
| 每阶段反复经历导致 W 饱和（w_max 顶满） | 中 | 沿用 w_max 64 + 扩容分担（新阶段用新神经元，旧槽不受压） |
| 句级复述在真实句上不收敛（句模式冲突） | 中 | 控制句长/词汇量；复述率 0.95 为阶段门槛，不过则缩规模 |
| 增量成长中灾难性遗忘（旧定式被覆盖） | 中 | learn_gate 冻结 + sleep 整理 + 每阶段零遗忘验收；ART 防遗忘原则 |
| 双系统协同融合引入复杂度 | 低 | 先独立验证两系统，再融合（Phase E） |

## 十、测试与验收

1. **零遗忘验收**（每阶段）：旧评估集 top-1 / 复述率 / 唤起率不退化（逐值对拍）
2. **本阶段验收**：§四各 Stage 指标（词复述 ≥0.95、词组续词、句复述 ≥0.95、关系补全、句 B 唤起、推理链）
3. **扩容验收**：expand 前后旧评估逐值一致 + 新阶段学习有增益
4. **生成质量**：每阶段数据上"会说本阶段的话"（前缀一致性 + 人工判断）
5. **回归**：abc / 26 字母 / 频率门控 sleep 不退化
6. 每阶段留档 `runs/时间戳/` + 数据留档 `data/curriculum/`
