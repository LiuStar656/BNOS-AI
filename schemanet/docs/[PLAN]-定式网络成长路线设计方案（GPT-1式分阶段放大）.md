## 一、背景与现状评估

### 1.1 本轮实验证据链（v1.1 → v2.0 的推翻过程）

| # | 实验 | 结果 | 结论 |
|---|---|---|---|
| ① | 26 字母训练（schema_net.py） | 26/26 零遗忘、输入 a 回响 a | **复述/模式固化能力成立**（最早模式） |
| ② | 2 万 vs 20 万真实语料（词接词 W） | 全线下降（wsum 0.1349→0.1220） | w_max 饱和实锤；数据放大无益 |
| ③ | 六引擎对照（wsum/trace/grad/candB/C） | wsum 0.1220 最强，grad 不敌 | 引擎之争无意义（都是词级） |
| ④ | 同末词命中率 | 无引擎超越 wsum | **区分 ≠ 理解** |
| ⑤ | 生成质量对比 | 全部引擎产出"标点+虚词"堆砌 | **模型不会说话**（词接词≠语言） |
| ⑥ | 句记忆检索（稀碎版） | 长位置崩溃（t9+ 0.01） | 逐位置签名=稀碎=失败 |
| ⑦ | 整句涟漪（整句单元） | 复述率 **1.000**、主题唤起强（足球唤足球/电商唤电商）、泛化续写崩（0.0244） | **整句记忆成立 + 语义联想雏形**；缺位置精度 |
| ⑧ | 技术谱系对照 | 复述=Hopfield(1982)；双系统=CLS(1995)；机制=HTM/ART/SNN | 效果未超"记忆检索"层 |

### 1.2 三个根本问题（v2.0 要解决的）

1. **数据不专门**：用混合 TF 语料训练"词接词"，等于直接给小孩发 20 万篇混合文章让他悟——26 字母时代"训练什么就是什么"的原则被丢弃了
2. **每次从头开始**：26 字母、2 万、20 万、w_max 重训、句记忆——每次新网络/新结构，**从未增量成长**（Hebbian 本是累积的，被浪费）
3. **机制错层**：20 万词接词训练把"句子"抹平了——句子级（CLS 海马对应物）从未进入网络结构；整句涟漪证明"句子可以成为记忆单元"，但它是**外挂**，不是网络长出来的

### 1.3 认知启发（用户决策 2026-08-09）

- 人的学习是**条件反射的层级化**：复读 → 下一句 → 词意 → 意思↔意思
- 语文课路径：**老师读一句学生读一句 → 学生自己读 → 理解句意 → 联想 → 举一反三**
- 三字经："读得越多印象越足"，"人之初→性本善"是**局部触发、整块唤起**（非逐词概率）
- **学习是累积的**（词不丢、句不丢），任何实验不得从头开始

## 二、核心原则

**铁律 1：数据专门化**——训练什么就用什么数据，像 26 字母训练就是 26 个字母。词用词数据、句用句数据、文用文数据，禁止用混合语料跳级。

**铁律 2：增量成长**——同一网络持续喂，永不从头开始。每阶段 = 沉淀（学习）→ 冻结（learn_gate=False）→ 验收（零遗忘）→ 再训练。

**铁律 3：神经元逐步扩容**——n 随阶段增大，与数据规模/复杂度匹配（扩容保留旧 W，旧知识零丢失）。

**铁律 4：教学协议**——严格按人语言/认知/逻辑/推理能力顺序递进（§三），前级验收通过才进下级。

## 三、人类学习能力对照

| 年龄段 | 人的能力 | 认知/语言/逻辑/推理对应物 | 定式网络 Stage |
|---|---|---|---|
| 0-1 岁 | 语音复述（咿呀学语） | 复读条件反射（模式固化） | **已完成**（26 字母） |

## 四、分级成长路线

### Stage 0 词级（复述/命名）——数据：词表

- **数据**：专门词表（高频词 + 类别标签，如 {苹果, 香蕉, 汽车, 奔跑}）
- **训练**：每词反复经历（Hebbian 模式固化），输入词 → 回响词
- **验收**：词复述率（输入 w 判读 w）≥ 0.95；**零遗忘**（全部词学完，前面的还在）
- **n**：起于小规模（26 字母 n 级，如 256-512）

### Stage 1 词组级（组合）——数据：词对/词组

- **数据**：专门词组（主谓/动宾/修饰：苹果好吃 / 妈妈抱 / 很快）
- **训练**：词组反复经历，沉淀词组内转移（w1→w2 定式）+ 词组模式
- **验收**：词组内续词 top-1；"先学 a 再学组合，原子保留"（26 字母 combo 实验口径）
- **n**：首次扩容（512 → 1024，模式空间翻倍，词组区分度需求）

### Stage 2 短句级（句内结构）——数据：规范短句

**状态：✅ 已完成（2026-08-10，快照 v7.0，报告见 §12 后附）**

- **数据**：专门短句（≤8 词主谓宾，无噪声：我要苹果 / 他喜欢吃西瓜）
- **训练**：短句反复经历（**跟读 + 复读**），整句涟漪 = 句模式（记忆单元）
- **验收**：句复述率（输入整句→唤起整句）≥ 0.95；整句涟漪匹配（主题唤起正确率）
- **实测（v7.0）**：句复述率 **0.9845** ✅；前缀唤起 0.2277（309/499 句）✅；字/词复述 1.0000 零遗忘 ✅
- **n**：扩容（1024 → 2048-4096；实测 n 58096 → 148140）

### Stage 2.5 词语类别（v2.4 改造：词典学词义）——数据：OpenHowNet 义原判断题

**状态：✅ 已完成（2026-08-10，快照 v8.5，实测见本段末，报告见 docs/reports/[REPORT]-定式网络Stage2.5词典学词义实验报告）**

**定位**：补词级（Stage 0-1）与句级（Stage 2）之间缺失的"语义角色层"。v2.4 改造源于用户诊断——**"词有了、词义没有"**：词形复述 1.0（模式已固化），但同类词在 stage2_sents 中几乎不同句共现（探测：食物仅 {蔬菜,猪肉} 一个 2 词块），词义（出边结构）孤立 → 举一反三无路可走。跟读（监督）只能焊"清单直连"，学不会词义；改用**词典（OpenHowNet 义原）+ RL 验证门**。

- **词义 = 词↔义原关联集合（出边结构）**：定式网络里"词义"不是额外标签，就是这个词能唤起什么、被什么唤起。词典直接给出词↔义原连接，绕开"语料无共现"的根因。
- **数据源：OpenHowNet（知网，清华 THUNLP 开源，MIT）**——约 2000 义原标注 20 万+ 中英文概念。实测 v7.0 词表 31819 词中 16781 词（**52.7%**）可查，5 万+ 词↔义原边。义原天然分两层：**类别义原**（fruit|水果、animal|动物、InstitutePlace|场所 → 类别 hub，供 Stage 2.6 槽位约束）+ **属性/功能义原**（edible|可食、study|学习 → 感知/行为通道）。
- **机制 = RL 验证门（§12.6 三因子规则）**：每条词↔义原关系 = 一道判断题——
  - "苹果是水果？对" → 验证门固化（苹果→水果 边）
  - "苹果是咸的？错" → 验证门拒绝固化（错误联想不焊死）
  - 词义 = **经验证门确认**的出边集合：可查（出边直读）、可扩展（新判断题）、可拒错（防认知偏差固化）
  - 多义原词取并集 = 多通道（类别 + 功能 + 来源），与 §12.7 语义链（苹果→水果→食物）同机制
- **类别举一反三**：与标签共享义原的未训练词（hold-out），凭其与类别成员共享的义原出边走链唤起标签——**与验证门走链同一检索机制**；未覆盖词（无义原）自然作"知道/不知道"对照（衔接 §4.8）
- **诚实边界**：① OpenHowNet 义原以**类别/功能/来源**为主，**不标注**"甜/圆/红"这类感知属性（视觉/味觉/触觉通道数据缺失，留待 Stage 4 用自然语言定义句补充，如 Wiki 定义句）；② 覆盖率 52.7%：数字/专名/新词无词义边，正好是"真不知道"的自然样本；③ 语法词性（名词/动词/形容词）仍需外部标注，作后续进阶（动作类≈动词类先近似）
- **验收**：① 类别归属（训练词→标签义原直连 ≥0.9）；② 词义举一反三（hold-out 词→本类信号占优 ≥50%）；③ 替换造句（"我要"→食物类词唤起，类别约束的槽位填充雏形）；④ 字/词/句全链零遗忘
- **实测（v8.5，全量 5 类：食物/动物/颜色/时间/地点；动作类跳过见诚实边界）**：
  - ① 类别归属 **1.0000** ✅（训练成员→本类标签直连，5 类全过）
  - ② 词义举一反三 **1.0000** ✅（hold-out 3 例/类：坐果/挂果/瓜子→食物、刺猬/北极熊/四不像→动物、红线/循环/染红→颜色、一世/一个半月/一代→时间、全日空/双人间/巷道→地点，本类信号占优 8-48 权重）
  - ③ 替换造句食物信号 **28.8 ≥ 他类 38.4×0.5** ✅（直接命中 土豆/饼干/苹果）
  - ④ 零遗忘：字 1.0000 / 词 1.0000 / 句 0.9324（base 0.9355）✅
  - 验证门拒绝 **54/54** 负例边未增长 ✅（"错"判断题不焊死）
- **实测暴露（数据驱动修正，2026-08-10）**：① HowNet 类别义原（动物/颜色/场所）覆盖的是"下巴/底色/一世"这类词，与日常类别词错位 → 标签组按人工词表词的义原**扩组**（食物+食品/蔬菜、动物+牲畜/走兽/虫、颜色+单字色名、地点+设施/房间）；② **动作类（吃/跑/跳…）HowNet 覆盖 0** → 本阶段诚实跳过（词性标注后补）；③ 成员筛选须"义原含本类标签"（"后来/最近"义原为将来/新近，无"时间"标签，排除）；④ 大网络虚词劫持（"我"→的 256）使单链走链失效 → 验收③改用出边直读聚合（与验收②同构）

**v11 迭代设计（2026-08-10，价值学习三件套，未开发）**——用户追问"造句只知可不可以、不知为什么"：

- **问题定性（统计 vs 价值）**：v10 的动宾搭配是**统计共现**（吃→苹果因例句共现、吃↛学校因无共现），网络只有关联强度、没有后果；生物是**价值学习**（吃→食物因后果好、吃↛石头因痛觉预期）。本迭代把"能不能配"的判据从统计升到**类别语义**，并让网络能说出"为什么"。
- **文献对标（查证 2026-08-10）**：RLBFF（ICLR 2026，NVIDIA）——反馈提取为**原则**（二元可答）再判断，奖励自带"为什么"（哪条原则不满足）；RLVR（DeepSeek R1）——**规则验证器自动判对错**，零人工标注；Explainable RLHF（NeurIPS 2025）——定位导致错误响应的训练数据 → 归因修正；RL with Human Advice（Frontiers 2021）——区分评价性/纠正性反馈，explanations 是建议的一种形式。
- **三件套**：
  1. **RLVR 式自动验证器（负例全自动，零人工标注）**：组合枚举自动生成负例（凡"O 类别 ∉ V 搭配类别"即负例：吃+石头、喝+学校……）；原因自动读出（O 的类别判定边 vs V 的搭配类别，均为网络已有知识）——**"原因"不需要人手写，是 2.5/v10 已学边的比对结果**；教学信号 = 类别比对验证器（对齐 RLVR：验证器自动给奖罚 + 可追溯原因）
  2. **否定知识显式固化（`~食物` 否定 hub）**：教学三要素（鼓励/解释/记忆）——正例 judge 固化（已有）；负例**解释原因** → judge(w, ~类别) 固化否定边（"石头不可吃"被记忆而非遗忘）；下次遇到直接避开（对齐生物"痛觉记忆"）
  3. **LLM 受限解释器（自然语言原因）**：网络输出的结构化诊断（V=吃、搭配类别=食物、O=石头、判定=非食物、拒绝行为）→ LLM 翻译为自然语言（"不能吃石头：因为石头不属于食物类，而吃通常搭配食物"）。**诚实底线**：输入限死（只喂网络真实学到的边）+ 输出越界拦截（LLM 生成网络边里没有的内容 → 拦截/标注"非网络知识"）——LLM 是**翻译器（代嘴）不是知识源**，解释仍是网络自己认知的语言化
- **RL 对标（补 §2.6 表）**：自动验证器 = 可验证奖励（RLVR）；否定知识边 = 带原因的负奖励（RLBFF 原则判断 / 可解释 RL）；约束强度差异（吃严格、看宽松）= 不同 (V,类别) 对的 Q 值分布；LLM 解释器 = 可解释 RL 的自然语言归因层
- **诚实边界**：① 网络"知道"错误原因的**原材料（边）与行为（拒绝），但说不出**（无语言通道），LLM 只补通道不补知识；② 自动化的粒度是**类别级**——"看石头"（类别不匹配但语义合法）会被验证器误判负例，验证器无体感；③ 语义级（苹果皮不宜吃）判不了，留缺口；④ 价值是**次级价值**（类别推理/教师信号），非生物第一性体感；⑤ "食物为什么能吃"（生理因果）仍缺（HowNet 动作义原覆盖 0）

### Stage 2.7 数字结构（v2.3 新增，2026-08-10 用户追问）——数据：数位跟读 + 组合生成

**定位**：数字域是"槽位机制"的第二战场。现代汉语数字是**双系统并存**，两者都要学：

- **中文数字（单位词系统）**：个/十/百/千/万/十万/百万/千万/亿 = **单位 hub 层级**（乘法单位词："三百四十五" = 3×100+4×10+5，每个数字绑定一个单位词；"三万/三亿" = 更高级单位），不是西方纯位值
- **阿拉伯数字（纯位值系统）**：0-9 十个数码 + **位置即权值**（"123"中 1 在百位、2 在十位、3 在个位，无显式单位词）——直接用 Stage 2.6 的**槽位位置编码**（个位槽/十位槽/百位槽，数码绑定到槽位即位值）
- **混合表达（语料常态）**："8000 万""3.5 万亿" = 阿拉伯数字（位值）+ 中文单位词（hub 进位节点）——双系统接缝，天然验证单位 hub 机制

- **机制**：
  - **数码（0-9 与 零-九）= 数字类别**（复用 Stage 2.5 类别机制）
  - **中文数位词 = 单位 hub**；**万/亿 = 四位一节的进位 hub 层级**（个十百千 | 万十百千 | 亿十百千…）
  - **阿拉伯数字位值 = 位置槽位**（复用 Stage 2.6 词序编码）——"123" = [百位槽+1][十位槽+2][个位槽+3]
  - **数数到大数靠结构生成，不靠背长链**（走链强度衰减问题在此解决：数到 1000 = 单位 hub / 位值槽位组合，不是背 1000 跳）
- **顺序（人类对照）**：数字词/数码识别（记忆）→ "三百四十五""123"组合规则（槽位绑定）→ 万/亿大数感（hub 层级）→ **双系统互译**（"123"↔"一百二十三"，位值↔单位词映射）
- **数据**：数字类别（0-9 + 零至九）+ 中文数位词跟读；语料中新闻/财经数字（"8000 万""3.5 万亿""2026 年"）为天然跟读材料
- **验收**：数字类别归属；1-100 数数链（走链续数）；进位走链（"3百4十5"→"3百4十6"、阿拉伯 "99"→"100"）；双系统互译（阿拉伯↔中文数字，仅结构映射，不要求数值大小）；词/句级零遗忘
- **诚实边界**：先学**形式（两套词序结构）**；"345 > 344"的**数值意义**需数量化表征，后置 Stage 5

### Stage 2.8 数字运算（v2.3 新增，2026-08-10 用户追问）——数据：口诀表 + 竖式样例

**定位**：运算分三个层次，开始时间不同：

| 层次 | 内容 | 机制 | 时机 |
|---|---|---|---|
| 记忆层 | 一位数四则口诀（3+4=7、7×8=56） | QA 查表 + 验证门判对错 | Stage 4 后 |
| 过程层 | 多位数竖式（23+18=41：位对位 + 进位/借位） | 位值槽位（2.7）+ 逐位查表 + 进位链 | 需序列控制/工作记忆（诚实难点） |
| 意义层 | 为什么 3+4=7（数量化表征） | Stage 5 推理 | 最晚、最硬 |

- **运算符词（加/减/乘/除）= 指令 hub**：决定"3,4"查哪张口诀表——"加"= 加法表开关、"乘"= 乘法表开关，即 §12.2"指令跟随"的天然雏形（运算符词 = 行为模式选择的指令，复用类别 hub 机制）
- **一位数四则无进位/借位** = 纯查表（四张表记忆），无过程复杂度
- **多位数竖式** = 位对位调一位数口诀 + 进位传播（个位满 10 → 十位 +1，与 2.7 数数进位同一机制）；**诚实标注**：竖式是"先个位后十位"的多步过程，需要工作记忆 + 序列控制（§12.5 多步/复合模式，单步 RL 需升级层次控制）——不是缺知识，是缺过程执行器
- **验收（记忆层）**：口诀随机抽查 top-1 正确率；错题验证门拒绝固化；词/句级零遗忘
- **诚实边界**：先能"背对"（查表），后能"算对"（过程），最后才"懂对"（意义）

### Stage 3 复杂句级（关系）——数据：因果/转折句

- **数据**：含关系标记的专门句（因为…所以… / 虽然…但是… / 先…然后…）
- **训练**：复杂句反复经历，沉淀**关系词转移定式**（因为→所以 的强关联）
- **验收**：关系词对补全（因为→? 答所以）；句复述不退化（Stage 2 零遗忘）
- **n**：扩容（4096 → 8192，当前规模）

### Stage 4 文章级（句间逻辑）——数据：句对 + 句间关系 + 文章骨架

**定位**：Stage 2 学"句内词间结构"，Stage 4 学"文内句间结构"——文章结构 = 句接句转移 + 句间关系标记 + 文章骨架：

1. **句接句转移**：句 A 涟漪 → 句 B 转移定式（跟读机制从词层搬上句层，CLS 慢系统的句子级转移）
2. **句间关系标记**：Stage 3 的关系词（因为/所以/虽然/但是）从"句内标记"延伸到"跨句标记"（"下雨了。所以带伞出门。"）——关系词是句接句的"方向标签"
3. **文章骨架**：句式骨架（主谓宾之于词 = 总分总/承接/转折布局之于句）同构；主题句/支撑句/总结句的"句子角色"可复用词语类别的 hub 机制（句子角色标签 + 句子成员）
- **验收**：句 B 唤起率（输入句 A 涟漪 → 唤起句 B）；接续不跑题（句间逻辑链）；词/句级不退化
- **QA 语料子集**：问句↔答句对是句接句的特殊形式（问句作句 A、答句作句 B），Stage 4 数据专门化时构造；配合验证门"答对固化/答错拒绝"——**答得出就说，答不出不说（衔接元认知预备）**
- **n**：扩容（8192 → 16384）

### Stage 4.5 文章类型（v2.3 新增，2026-08-10 用户追问）——数据：带类型标注的文章

**定位**：文章结构（句接句/骨架）是"文内怎么排"，**文章类型（文体/类别）是"这整篇属于哪一类"**——与词语类别（Stage 2.5）同机制、同哲学，只是单元从"词"换成"文章"：

| 层级 | 单元 | 类别机制 | 类型信号 |
|---|---|---|---|
| 词层（2.5） | 词 | 词语类别（食物/动作） | 成员↔标签共现 |
| 句层（4） | 句 | 句子角色（主题/支撑/总结） | 句子↔角色标签 |
| **文层（4.5）** | **文章** | **文章类型（记叙/说明/议论/新闻…）** | **文章模式↔类型标签** |

- **机制**：文章（整篇涟漪/模式）与类型标签反复共发放 → 类型 = 文章模式的出边 hub；新文章（没学过类型）输入 → 走链唤起类型标签 = **文体举一反三**（与"菠萝→食物类"同一检索机制）
- **识别信号**：文体标记词（说明文"首先/其次/最后"、议论文"我认为/因此/然而"、新闻"本报讯/导语"）+ 句式特征 + 内容主题——信号在定式网络里就是"文章↔类型"连接结构
- **数据（现成标注）**：语料库 raw 已备——`toutiao_cat_data.txt`（头条新闻 15 类：体育/财经/娱乐/健康…）、`online_shopping_10_cats`（电商评论 10 类）、`ChnSentiCorp`（情感分类）。数据专门化：学文章类型就用带类型标注的文章
- **顺序**：排在 Stage 4 之后（先有"整篇文章模式"，才能做"文章模式↔类型标签"绑定，同词模式先于词类别）
- **验收**：训练文章唤起类型标签 ≥0.9；hold-out 新文章唤起类型 ≥50%（文体识别举一反三）；词/句/文章级零遗忘

### Stage 4.8 元认知预备（v2.3 新增，Stage 5 前）——知道/不知道

**问题**：网络检索是确定性的，唤不起就是空，**它自己不会报告"我不知道"**——没有这个机制，QA 只能"背到就答、背不到就编"。

**机制（定式网络独有：知识 = W 图结构本身，可检查）**：

| 信号 | 是什么 | 对应认知 |
|---|---|---|
| 唤起强度 | fire_ratio 高低、走链强度衰减终止（§12.7 已验证：下一步 < 上一步×0.4 停止） | "知道感"（检索激活量） |
| 路径存在性 | "苹果→颜色"之间 W 里有没有边（图可达性，可查） | 区分"知道但没想起来"（有边弱激活）与"真不知道"（无边） |

- **阈值标定**：fire_ratio 多少算"知道"由**验证门教**——答对 → 该检索标"强知道"；答错 → 标"该说不知道"。三因子规则调制的不只是"固化不固化"，还有"**该不该开口**"
- **诚实边界**：网络做到的"不知道"是**低唤起触发"不知道"响应模式**，不是自我意识（人也是靠"检索失败感"做代理，非绝对自知）
- **定位**：原始信号（强度 + 可达性）现有机制即备，阈值标定在 Stage 5 前接入；排在 Stage 2.5/2.6/3/4 之后自然衔接 QA（见 Stage 4 的 QA 语料子集）

### Stage 5 推理级（概念）——数据：逻辑推理文本

- **数据**：专门推理语料（类比/三段论/条件推理）
- **训练**：概念涟漪 ↔ 概念涟漪转移 + 涟漪泛化（半句唤起类似句）
- **验收**：多步逻辑链补全；举一反三（同主题变体预测一致）
- **n**：按需扩容（16384 → …）

### 每阶段必做（成长协议四件套）

1. 前级零遗忘验收（旧评估集 top-1/复述率不退化）
2. 本阶段专门数据验收（位置分层 / 复述率 / 唤起率）
3. 生成质量对比（本阶段数据上，是否"会说本阶段的话"）
4. **留档（缺一不可，2026-08-10 用户决策"每次实验必须留存实验数据"）**：result.json（指标 metrics：验收数字 + 参数 + 判据）+ **net.npz（模型快照：W + 构造参数 + 模式字典 pats + 分配游标 cursor）** + 数据/分级语料（stage25_sememes.json / stage26_pos.json 等离线抽取数据留 `data/curriculum/`）+ 训练产物（判断题/槽位句集随 runs 落盘）+ 报告（docs/reports/）——**报告给结论、数据给证据，缺一不可**。**统一走 `snapshot.py` 语义版本链**（2026-08-09 落地，MAJOR.MINOR 类比软件版本）：每次训练产生新版本 `runs/v{M}_{N}_{时间戳}/`（旧版本永不删除），index.jsonl 记录 version/parent 父子链；正常续训 major+1（a→a+1→a+2），**回退训练同代变体**（a+2 出问题 → `load_version("2.0")` 回退 a+1 再训 = **a+2.1（3.1）**，与 a+2 平级直接对比）——增量成长硬前提

## 五、数据专门化设计

### 5.1 原则

- 每阶段数据**纯净**（只含该阶段结构），禁止混合跳级
- 数据量按阶段递增（词 < 词组 < 短句 < 复杂句 < 文章 < 推理）
- **每阶段内部有重复**（跟读性质：同一内容反复出现，满足"印象越来越足"）
- 全部生成/抽取到 `data/`，可复现、可留档

### 5.2 数据来源（先抽取，后构造）

现有 corpus_open20w.json 可作为**原料库**，按阶段抽取纯净子集：

| Stage | 抽取规则 | 预估量 |
|---|---|---|
| 0 词表 | 词频 top-N（去 UNK、去停用词） | 1000-3000 词 |
| 1 词组 | 高频相邻词对（bigram 专有数据） | 5000-2 万对 |
| 2 短句 | 语料中 ≤8 词、无 UNK 的句子 | 2 万-5 万句 |
| 2.5 词义 | **OpenHowNet 义原**（词↔义原判断题，验证门固化/拒绝） | 5 万+ 边（实测覆盖 v7.0 词表 52.7%） |
| 2.6 词性 | **jieba.posseg 词性标注**（v8.5 词表 → 动词 19.3%/6049 词，动作类/人称类成员离线抽取） | 3.1 万词（留档 stage26_pos.json） |
| 3 复杂句 | 含 因为/所以/虽然/但是/如果 的句子 | 1 万-3 万句 |
| 4 句对/文章 | 语料中相邻句子对（同段落内）；**Wiki 百科条目**（导语→正文→分节，句接句 + 文章骨架 + 句间逻辑） | 2 万-5 万对 |
| 4.5 文章类型 | **Wiki 条目分类标注**（人物/地理/生物/事件…，自带类型标签，省标注成本） | 数千-数万篇 |
| 5 推理 | 需专门构造（条件/类比模板） | 数千-数万 |

**Wiki 定位（v2.4 明确）**：**Stage 4/4.5 的现成语料，不是现阶段（词义/句式）语料**——Wiki 长文粒度太粗，词义阶段喂长文会重演"20 万篇混合文章让他悟"的失败；其价值在**文章级结构**（句接句、骨架、句间逻辑）与**自带分类标注**（省 4.5 的标注成本）。原始 dump 需清洗（模板/参考文献/格式标记），到 Stage 4 前按 §5.1"先抽取后构造"管线处理即可。

**关键**：每阶段数据 = "反复读的三字经"——同一批句子多次出现（重复率 ≥ 10 次），不是"每句一次"（v1.1 的错误）。重复率是跟读的本质。

## 六、神经元逐步扩容方案与评估

### 6.1 结论：**可以逐步增加神经元数量，且支持任意粒度（含 n+1）**

v2.1 修订（2026-08-09 用户确认）：用户问题——"n=8032 训练好后，下一次训练能不能 n+1？"答案是**能**。`expand(n_new)` 是纯追加，n_new 可以等于 n+1，也可以一次扩几百（机制等价）。"知识的增量 = 神经元的增量"，新增一个概念（如第 27 个字母）就 +1。

### 6.2 技术路径（已验证代码结构）

```python
def expand(self, n_new):            # SparseSchemaNet 新增方法
    assert n_new > self.n
    pad = n_new - self.n
    self.v            = np.vstack([self.v, np.zeros((pad, self.slots))])
    self.spikes       = np.pad(self.spikes, (0, pad))
    self.pre_trace    = np.pad(self.pre_trace, (0, pad))
    self.last_k_star  = np.pad(self.last_k_star, (0, pad))
    self.refractory_left = np.pad(self.refractory_left, (0, pad))
    self.slot_freq    = np.pad(self.slot_freq, ((0, pad), (0, 0)))
    self.W_out       += [[{} for _ in range(self.slots)] for _ in range(pad)]
    self._edge_cache += [[None] * self.slots for _ in range(pad)]
    self._edge_dirty += [[True] * self.slots for _ in range(pad)]
    self.n = n_new
```

- **旧知识 100% 保留**：W_out 前 n_old 行原样复制（连接结构不动），扩容是纯追加
- 新神经元空白 → 供新阶段学习（新词/新词组/新句模式落位）
- **粒度任意**：`n_new = n + 1`（单个新概念按需落位）或成批扩容（几十上百个），机制等价

### 6.3 关键风险与对策：分配制模式字典（v2.1 修订，取代分区冻结）

旧 `_word_pattern(n, k, word)` 用 `crc32(word)` 做种子、在 `[0, n)` 选神经元——**哈希结果依赖 n**。n 一变，旧词模式重算 → 旧 W 连接失配（灾难），n+1 直接被否。

**对策（分配制模式字典，用户已批准）**：
- **模式字典** `pats: {word: [k 个神经元索引]}` 是唯一事实源：词→神经元落位**生成一次、永久冻结、随网络一起持久化**（npz 附加保存），任何扩容都不重算旧词
- **新词落位 = 分配制**：从当前**空白神经元**按游标顺序取 k 个（分配唯一 → 新词之间零冲突），写入模式字典 +1 条
- **n 只是"可用空间上界"**：旧词条目不动，新词在 [0, n) 的空白区分配；n+1 只是把可用空间扩大 1，完全安全
- 与哈希对比：分配制牺牲"确定性跨语料复用"，换来**任意粒度扩容 + 新词零冲突**，更贴近"新概念要新神经元"的认知模型
- 验收：扩容前后，旧评估集 top-1/复述率**逐值一致**（零遗忘硬指标）；新增词复述可学（增益为正）

### 6.4 扩容触发条件（何时扩）

三种触发，全部走同一 `expand`：
- **按需 +1**：新增单个词/概念，模式字典分配游标到达 n 边界 → `expand(n+1)`（第 27 个字母场景）
- **区分度不足**：词模式冲突率（分配后仍重叠）或"排列一致性"跌破阈值 → 成批扩容（空间换区分度）
- **阶段升级**：词→词组→句→文自带扩容计划（§四 n 表），一次扩一档
- 扩容验证：扩容后新阶段学习增益为正 + 旧阶段零遗忘 → 通过

### 6.5 为什么必须扩容（不固定 n）

26 字母实验实测：n=256 时排列一致性跌到 0.10（模式空间不足，词分不开）。语言复杂度随阶段递增（词 3000 → 词组 2 万 → 句 5 万），固定 n=8192 会重演"区分度塌缩"（对应 20 万语料 w_max 饱和后的分数齐平）。**n 随阶段增大，是语言容量与模式区分度的必然需求**，与大脑随年龄增大同理。

### 6.6 续训闭环（v2.2 已验证 ✅ 2026-08-10）

需求（用户 2026-08-10）："模型是逐步迭代的，不是每次从 0 开始学习；以后扩大神经元规模和调整每次调用神经元的数量时，原来之前的记忆不丢。"

**闭环**（脚本 `_grow_continue.py`，报告见 §12.7 后附）：
```
load_version("2.0")   # 加载旧快照（词级，n=54000/13500 模式）
  → baseline 评估        # 零遗忘基准
  → expand(＋4096)       # 纯追加扩容
  → 复测                 # 扩容零遗忘硬指标：旧评估集逐值一致
  → 调 wta_k（2~48）     # "调整每次调用神经元的数量"
  → 分配新词 500 + 跟读   # 游标续用自动扩容
  → save_snapshot        # v6.0，版本链继续
```

**验收结果（全过）**：
- 扩容零遗忘：n 54000→58096，字/词复述 1.0000 逐值一致
- 调参零遗忘：wta_k 2~48 遍历，旧复述率不回退（wta_k=24 时字复述 0.9950 为竞争召回边界现象，非遗忘）
- 续训零遗忘：新增 500 词训练后旧字/词复述不回退，新词复述 1.0000

**关键设计**：续训起点 = `load_version()`（权重 + pats + cursor 全恢复），游标从旧 cursor 继续分配 → 新词自动落在空白神经元，旧模式一条不动。

## 十二、行为模式选择与验证门（v2.2 新增，RL 强化学习）

### 12.1 问题定义：网络不知道"用哪种模式"

Stage 0-1 已实现两种能力：
- **复读**（Hopfield 自联想）：输入完整模式 → 回响自身（"输入 a 输出 a"）
- **联想**（模式补全）：输入前缀 → 补全后续（"输入人之初输出性本善"）

**最大问题（用户 2026-08-09 提出）**：这两种是**解决问题的模式**（未来还有：先复读再联想、举一反三、总结规律/利用规律……）。一个刺激源会**同时激发多个模式的候选**（输入"人之初"：复读候选="人之初"，联想候选="性本善"），但网络**没有机制决定现在用哪个模式**。

### 12.2 认知启发：模式选择信号来自"教学指令"，不在刺激里

- 老师教："**和我一起读**" → 复读；"**人之初下一句是什么**" → 联想
- 刺激本身不携带该用哪个模式的信息，**意图/指令携带**（认知科学"指令跟随" instruction following）
- 指令本身也是词/句，在网络里有自己的神经表征（**指令模式**）——"和我一起读"唤起"复读指令"模式，调制后续行为模式选择

### 12.3 RL 的定位：不是外挂黑盒策略，而是"验证门"（三因子学习规则）

定式网络动力学是确定性的（Hebbian 无监督），RL 不训练动力学，只做一件事：

| RL 要素 | 在定式网络里的落地 |
|---|---|
| 状态 | 网络当前激活（走链到了哪里、唤起了什么候选） |
| 动作 | 检索/传播产生联想结果 |
| 奖励 | 外部/内部验证（"对"/"错"） |
| 策略更新 | **验证通过 → 该次共发放被固化；失败 → 不固化甚至弱化** |

这正是神经科学中的**三因子学习规则**（Hebbian × 奖励因子/多巴胺）：光共发放不学，共发放 + 奖励到来才强化。现有 `learn_gate`（全局布尔开关）升级为**逐次调制门**（已验证的链首尾 +强，未验证 +0，失败 -弱化）。

> **v2.6 增补（2026-08-10 用户决策，项目级硬约束）**：**所有 RL 环节的负反馈必须附 LLM 生成的自然语言原因**——"错"不能只是标量惩罚：负例 = 拒绝 + 处罚原因（自然语言），原因由 LLM 从网络结构化诊断翻译而来（LLM 是"代嘴"不是知识源；输入限死只喂网络真实边、输出越界拦截）。对齐 RLBFF（原则式奖励）/ Explainable RLHF（归因→修正）。本约束适用于后续所有 Stage（数字运算错题、推理错误、QA 回答错误等全部 RL 场景）。

### 12.4 举一反三的最小机制：联想负责"想"，复读负责"记"，验证门负责"该不该记"

以"流动的是水 / 水是液体 → 流动的是液体"为例：

| 步骤 | 机制 | 用的能力 |
|---|---|---|
| 学两条前提 | 复读"流动的是水"（流动↔水）、复读"水是液体"（水↔液体） | 现有跟读 |
| 推理出结论 | 输入"流动" → 传播走链 → 经中间项"水"唤起"液体" | 现有传播（联想） |
| 压缩成直连 | 验证通过 → 把 [流动, 液体] **复读一次** → 首尾共发放固化直连 | 复读一对新词 |

关键洞察：
- 纯两句训练下，"流动"和"液体"**从未共发放，物理上断开**——首尾直连不可能无中生有，必须靠"走链成功后把首尾复读一次"来**主动建立**
- **验证门决定该不该压缩**：未经证实的链（如"流动→水→能淹死人"）走通了也只当临时检索结果，**不固化**——这是防止错误联想/认知偏差永久焊死的闸门
- 一旦直连建立，中间项"水"不再是必经之路（组块化/知识编译，ACT-R 产生式编译对应物）——"把中间步骤去掉"的机制

### 12.4b 目标修正（用户 2026-08-10）：学"传递模式"，不是学"这句话"

**关键区分**：
- ❌ 学会"流动的是液体"= 记住了这条**实例**（换"苹果是红的、红是颜色"就失效）→ 死记硬背
- ✅ 学会"X是Y、Y是Z → X是Z"= 抽出**传递律模板**（抽象、可复用）→ 举一反三

这对应"总结规律/利用规律"的实质：**规律是结构，不是内容**。机制 = **角色槽位表征**：

```
"流动的是水" = [主语位 S + 流动] + [系词位 是] + [宾语位 O + 水]
"水是液体"   = [主语位 S + 水]   + [系词位 是] + [宾语位 O + 液体]
                  ↑ "水"同时出现在 O 位和 S 位 → 桥 → 传递链
```

- 跟读注入**角色绑定**（S↔词、O↔词），不止内容共发放
- 多条"X是Y"反复后，共性沉淀的是**槽位变换结构**（S 位条目可经 O 位衔接下一条 S→O 链）→ 传递律模板
- **利用规律 = 新实例填入槽位走链**（即使新组合从未训练过）——真泛化

| 层 | 学的是什么 | 验证方式 |
|---|---|---|
| 实例层 | 流动→液体 首尾直连（组块化） | 同组词反复可用 |
| **模式层** | S-O 槽位变换 = 传递模板 | **换未训练过的新词组合**仍能推出 |

**验收硬指标**：训练 {流动是水, 水是液体, 苹果是水果, 水果是食物, 雪是白的, 白是颜色…}，测试**从未共现**的新组合（如"鸟是动物、动物是生物 → 鸟是生物"）——模板成立才算学会模式，只回吐训练句不算。

### 12.5 与 RL 的能力边界（诚实标注）

| 目标 | RL 能否做到 | 说明 |
|---|---|---|
| 验证门：奖励调制固化/弱化 | ✅ 现在能做 | 改动最小，learn_gate 升级为调制门 |
| 指令→模式映射（"跟我读"→复读） | ✅ 能做 | 需要先把复读/联想抽象为接口化行为模式模块 |
| 行为模式仲裁（多候选选一） | ✅ 能做 | 需"候选报告接口"（观测通道）+ 明确奖励 |
| 加法举一反三（5+3=8） | ⚠️ 只做验证门部分 | 泛化靠**共享表征**（数字需数量化表征），RL 不产生泛化 |
| 多步/复合模式（先复读再联想） | ⚠️ 暂不做 | 需工作记忆 + 序列控制，RL 要从单步升级到 MDP/层次 RL |

### 12.6 最小验证实验（已实施 ✅ 2026-08-10，脚本 `_rl_gate.py`）

**语料（带角色槽位）**：
- 训练组（多实例，学传递模板）：{流动是水, 水是液体, 苹果是水果, 水果是食物, 雪是白的, 白是颜色}
- 陷阱前提（先建立真实错误链，供验证门拒绝固化）：{水能淹死人}
- 验证门拒绝对象：{流动的能淹死人}（共享中间项"水"的陷阱结论）
- 测试组（**训练中从未共现的新组合**）：{鸟是动物, 动物是生物} → 应推出"鸟是生物"

**流程**：
1. 槽位化跟读：注入 [S+X] + [是] + [O+Y] 角色绑定，多实例反复 → 沉淀 S-O 槽位变换模板
2. 走链：输入"流动" → 传播经"水"唤起"液体"
3. 验证门：老师说"流动的是液体→对"，"流动的能淹死人→错"；对链首尾复读固化，错链不固化
4. 验收（分两层）：
   - **实例层**：验证固化后"流动"能否直接唤起"液体"
   - **模式层**：测试组新组合（鸟/动物/生物从未共现训练）能否推出"鸟是生物"——**只回吐训练句不算学会模式**

**实验结果（全部 PASS ✅）**：

```
[1] 训练组 6 句 + 陷阱前提 1 句 × 3 轮 跟读完成
[2] 实例层走链（输入 流动）: 流动 → 水 → 液体 ✅ 联想链成立
[3] 验证门：流动的是液体→固化 (0.0→1.6)；流动的能淹死人→不固化 (0.0→0.0)
[验收①] 错误链前提「水能淹死人」已建立（直连 4.8）✅
         正确链固化 + 错误结论拒绝固化 → ✅
[5] 模式层泛化: 鸟 → 动物 → 生物 ✅ 结论句「鸟是生物」从未跟读 → 真举一反三
[验收②] 实例层直连 ✅
[验收③] 模式层模板 ✅
═══ 总验收: PASS ✅ ═══
```

**关键结论**：
1. **复读+验证门确实能长出直连**（实例层组块化成立：流动→液体 0.0→1.6）
2. **验证门能挡住错误联想固化**（认知偏差防护：错误链「水→淹死人」存在但错误结论不被加固，这正是不让负面联想焊死成规律的闸门）
3. **模式层真泛化成立**（传递模板套用新词组合：鸟/动物/生物从未训练共现，仍推出"鸟是生物"——学的是"X是Y、Y是Z→X是Z"模式，不是"流动的是液体"这句话）

**过程中发现并修复**：`SparseSchemaNet._edge_row` 空行返回 `(None, None)` 而非 `None`，传播时 `drive[None] += None` 报 dtype 错（此前 `_grow_zh` 碰巧未触发）；`_rl_gate.run_train` 需清 `refractory_left`（跟读独立事件，防上句发放的词在本句被不应期挡下——"流动是水"→"水是液体"中"水"连续出现，不清则水↔液体共发放学不到）。

### 12.6b 泛化压力测试（已实施 ✅ 2026-08-10，脚本 `_rl_gate_stress.py`）

五级递进，验证"彻底泛化"，全部 PASS：

| 级别 | 内容 | 结果 |
|---|---|---|
| L1 规模泛化 | 40 词 / 32 实例（8 独立链×5 词），全链走通率 | **100%（8/8）** |
| L2 链长泛化 | 4 跳传递链（A→B→C→D→E） | 含于 L1，全通 |

### 12.6c 规模压力测试与缺口修复（已实施 ✅ 2026-08-10）

**规模压力测试**（脚本 `_rl_gate_scale.py`，数据留档 `runs/`）：S1-S3 词表 100→300→1000 词，推理走通 **100%**、模板零稀释（规模本身撑得住）；噪声下推理也不受影响。但暴露**两个真实机制缺口**：

| 缺口 | 症状 | 根因 |
|------|------|------|
| 终止缺口（S4） | 57/60 条联想沿噪声连接无限蔓延 | 贪心走链无停止判据 |
| 上下文缺口（S5/S6） | 共享 hub 分支选错、被强分支吸走 | 每跳只看当前词出边，不知道"从哪来" |

**修复实验**（脚本 `_rl_gate_fix.py`，报告 [REPORT]-补缺口实验）：三补丁机制——

```
1. 整链跟读：训练时整条链作为一句复读 → 链内非相邻词建立弱直连
   （为路径聚合提供信号；认知对应"整句固化句内连接"）
2. 路径聚合走链：每步候选得分 = 路径上所有已见词出边聚合
   （认知对应"工作记忆"：记住起点调制分支选择）
3. 强度衰减终止：下一步强度 < 上一步 × 0.4 → 停止
   （认知对应"联想收敛/AI 慢下来"）
```

**验收（同一网络，只切换检索方式 → 提升归因于检索机制）**：
- F1 终止：过冲 **57 → 0 条**，推理走通保持 100%
- F2 上下文（等权分支）：A1→B1、A2→B2 旧走链错 1 条 → 新走链全对
- F3 上下文（不对称分支）：弱分支不再被强分支吸走，全对

**结论**：举一反三的联想层已具备"收敛"（终止）与"定向"（上下文）两能力，与验证门（该不该记）构成完整三角。

### 12.7 影响范围（v2.2）

### 12.7b 大网络机制验证（已实施 ✅ 2026-08-10，脚本 `_rl_gate_big.py`）

机制从构造词表（w0~w59）搬迁到 v2.0 真实网络（n=54000，13502 模式），验证真实竞争下成立。

**关键发现（第一版失败）**：贪心走链在真实网络被**字形分解带偏**——"苹果→果→苹→小…"，因为字模式与词强连接（word_to_char 0.997，跟读 8 轮）远强于槽位化语义连接（3 轮）。语义传递与字形分解共用同一 W 出边竞争，这是构造网络发现不了的矛盾。

**修复：词级走链 `walk_chain_lex`**（候选排除单字模式 + 上下文聚合 + 终止衰减）——语义传递（苹果→水果→食物）发生在词层面，字层面是构成关系，检索时分层。认知对应：人的"苹果→水果"语义联想与"苹果→苹"字形分解是不同通路。

**验收（全部通过）**：
- 词级走链：苹果→水果→食物 ✅、动物→生物 ✅（结论句从未跟读）
- 终止收敛 ✅、验证门（固化 0→1.6 / 拒绝 0→0）✅

**结论**：验证门/走链/终止/上下文全套机制在真实规模成立；接大网络的必要修正是**检索分层**（词级 vs 字级）。
