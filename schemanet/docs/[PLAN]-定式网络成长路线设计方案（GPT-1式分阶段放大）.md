> **v2.9 修订（2026-08-10）**：**对话教学升级（用户反馈："网络一直在说我吃苹果"——固定起始词教学让网络固化重复，需打破）**——① **教师发起对话**：教学不再给固定起始词，教师轮转问不同话题的问题（话术丰富但不夸张、句句不重复），网络"听"问题作答——**网络听 = 问题里听到的动词直接主导应答**（应答 Intraverbal 落地：问题里的动词引导回答里的动词，正是幼儿"你问我答"的真实机制；回响降级为备选）；② **反复重复 → 惩罚**：近 REPEAT_WINDOW=3 轮内同一句**累计出现 ≥REPEAT_TIMES=3 次**才算"反复" → 该句 V→O 与尾边**减半**（不动共享 S→V 边），逼网络换说法——打破"我吃苹果吗"由奖励越练越强的固化循环（根因：每轮示范都教同一句 + 100 分句奖励学 2 次 → 单边垄断）；③ **答非所问（不通顺）→ 惩罚**：S/V 与老师问题话题不符 → 不给奖励 + 连续计数清零 + **示范重铸正确应答**（不删边——句子本身合法，语境错不惩罚边；判定优先于重复，避免重复的错句被当"重复"处理）；④ **采样权重归一化**（÷最大权重）+ hear 引导 ×8 主导：弱边也能参与探索，强边不再垄断采样（S→V 学习初期的天然壁垒）；⑤ **话题块**（用户："老师批改后要和网络发起下一次对话"）：教师批改后围绕**同一话题继续发起对话**（换问法，TALK_BLOCK=3 轮），练熟再换下一个话题；⑥ **扩写式示范**（用户："示范的时候是把网络的话扩写的最自然"）：示范 = 网络刚说的话的扩写（Expansion 补全 / Recast 重铸 / 陈述扩问句 / 问句换具体答案 / 连说重复换宾语）；⑦ **对话记录 + 实验数据留档**（用户："教师和网络的对话也要记录""以后任何实验数据都要有留档"）：逐轮对话写 talk_log.json、汇总 + 边权重对比写 result.json、教学后网络存 net_after.npz，全部进 `runs/_speak_logs/` 带时间戳留档，基快照作对照组。**v2.9.1（2026-08-10，LLM 判断质量 + 单轮调用）**——用户："大模型要判断质量，从自然语言的角度，要教网络怎么说话"：规则打分只能查槽位（"吗"尾就问句 100），判不了"自不自然"；LLM 升级为质量判断者（LLM-as-Judge）：**"我吃西瓜吗" 规则 100 分、LLM 判 80 并点评"听着像在问自己，可以说'我可以吃西瓜吗'"**——网络因此学会自然问句；用户："把调用压缩到一轮"（参照 AAA 节点"一个 prompt 多个节标记"模式）：教学每轮 LLM 调用 **2 次 → 1 次**（`_llm_teacher_once` 一次输出【质量分数】【答非所问】【质量原因】【教师反馈】【示范句】五节标记，失败整体回退规则）；**增量成长**：默认续用最新教学产物 net_after.npz，开局即会说话（"我吃鸡蛋吗"），教学成果真正累积（铁律 2）。
> **v2.10 修订（2026-08-10）**：**v13 设计定稿：价值维度 + 拒绝表达（自我边界形成）**——用户："如何让网络学会反抗或者抵触某种信号？" + "弱边和删边会导致网络对某些信号的感受降低，而负面信号同样是强烈的"（批评现行删边惩罚 = 把"厌恶"实现成"麻木"）+ "从自闭症研究出发呢？"→ 查证 **述情障碍 / FCT / 自我倡导 / 内感受**（Alexithymia：50% 自闭症人群有信号说不出；FCT：沉默回避是问题行为、教替代沟通反应"我不要"；Self-Advocacy 三要素：自我意识→沟通→决策；Interoception：内感受→情绪词绑定）→ 三件套落地 `_speak.py` v13：① **价值标签（不删边）**：VAL 把宾语分好坏（石头=坏、搭配宾语=好），**坏宾语保持强唤起（感知）**——"抵触" = 高唤醒 + 负价值，是警觉不是麻木；② **拒绝表达（FCT 替代沟通）**：V 位加"不要"，教师示范"我不要石头"（网络学 我→不要→石头 边），**拒绝坏东西 = 100 分最高奖励**（honor the refusal）、要坏东西 = 30 分（不删边、只清零计数 + 示范）；③ **内感受→表达绑定**：hear 含坏宾语 → 网络倾向说"不要"（听到坏东西 → 拒绝优先），LLM 教师解释"石头不好，吃了会不舒服"；④ **自我边界形成**（自我倡导三要素映射：自我意识 = 自判唤起强度、沟通 = 拒绝表达"我不要X"、决策 = 采样选择）。预期结果：网络强烈感知"石头"（能说出"我吃石头"= 感知），但价值判断让它选"不要"（行为上拒绝）——"认知变化发生在价值判断上，不是麻木"，呼应心理健康实验关切。

## 一、背景与现状评估

### 1.1 本轮实验证据链（v1.1 → v2.0 的推翻过程）

| # | 实验 | 结果 | 结论 |

| ① | 26 字母训练（schema_net.py） | 26/26 零遗忘、输入 a 回响 a | **复述/模式固化能力成立**（最早模式） |

| ③ | 六引擎对照（wsum/trace/grad/candB/C） | wsum 0.1220 最强，grad 不敌 | 引擎之争无意义（都是词级） |
| ④ | 同末词命中率 | 无引擎超越 wsum | **区分 ≠ 理解** |
| ⑤ | 生成质量对比 | 全部引擎产出"标点+虚词"堆砌 | **模型不会说话**（词接词≠语言） |
| ⑥ | 句记忆检索（稀碎版） | 长位置崩溃（t9+ 0.01） | 逐位置签名=稀碎=失败 |
| ⑦ | 整句涟漪（整句单元） | 复述率 **1.000**、主题唤起强（足球唤足球/电商唤电商）、泛化续写崩（0.0244） | **整句记忆成立 + 语义联想雏形**；缺位置精度 |
| ⑧ | 技术谱系对照 | 复述=Hopfield(1982)；双系统=CLS(1995)；机制=HTM/ART/SNN | 效果未超"记忆检索"层 |

### 1.2 三个根本问题（v2.0 要解决的）

1. **数据不专门**：用混合 TF 语料训练"词接词"，等于直接给小孩发 20 万篇混合文章让他悟——26 字母时代"训练什么就是什么"的原则被丢弃了
2. **每次从头开始**：26 字母、2 万、20 万、w_max 重训、句记忆——每次新网络/新结构，**从未增量成长**（Hebbian 本是累积的，被浪费）
3. **机制错层**：20 万词接词训练把"句子"抹平了——句子级（CLS 海马对应物）从未进入网络结构；整句涟漪证明"句子可以成为记忆单元"，但它是**外挂**，不是网络长出来的

### 1.3 认知启发（用户决策 2026-08-09）

- 人的学习是**条件反射的层级化**：复读 → 下一句 → 词意 → 意思↔意思
- 语文课路径：**老师读一句学生读一句 → 学生自己读 → 理解句意 → 联想 → 举一反三**
- 三字经："读得越多印象越足"，"人之初→性本善"是**局部触发、整块唤起**（非逐词概率）
- **学习是累积的**（词不丢、句不丢），任何实验不得从头开始

## 二、核心原则

**铁律 1：数据专门化**——训练什么就用什么数据，像 26 字母训练就是 26 个字母。词用词数据、句用句数据、文用文数据，禁止用混合语料跳级。

**铁律 2：增量成长**——同一网络持续喂，永不从头开始。每阶段 = 沉淀（学习）→ 冻结（learn_gate=False）→ 验收（零遗忘）→ 再训练。

**铁律 3：神经元逐步扩容**——n 随阶段增大，与数据规模/复杂度匹配（扩容保留旧 W，旧知识零丢失）。

**铁律 4：教学协议**——严格按人语言/认知/逻辑/推理能力顺序递进（§三），前级验收通过才进下级。

**铁律 5：学习单元闭环（五步教学协议，2026-08-10 用户定稿）**——每个学习单元（词/词组/句子/数字/复杂句/文章…）都必须走完同一完整闭环，缺一步不算学会：① **是什么**（识别/复述单元形态）→ ② **怎么造**（按规则生成新实例）→ ③ **造对的**（约束合法、拒绝病态）→ ④ **为什么错**（错误归因到具体结构 + 外部教师解释）→ ⑤ **自己判断**（**先学怎么做判断，再课后练习**：判断内化到网络结构；⑤a 学怎么做（教师示范判断方法/标准）→ ⑤b 课后练习 + 教师批改讲评——教师不是退场，是转岗为批改讲评者：网络自判，教师批改对错、讲评错因，网络再修正）。句子单元已走完 ①-④（v7→v11），⑤ 网络自判 = v12 开发中；**后续每个单元一律按此五步复刻推进**，不允许"教完①②就结课"。

**铁律 6：对话即学习（交互优先，2026-08-10 用户定稿）**——用户指出"现在没做最重要的交互能力，人类最早学会的就是如何说话、和父母对话，这才是重中之重"。语言的**第一性目的是交流**——复述/造句/判断都是"说话的工具"，"交谈"才是使用工具去交流；没有对话，网络学完所有闭环也只是"会说话但不会交谈"。因此：**对话 = 教学环境（铁律级，不是某个 Stage）**——所有单元的教与学都在"网络↔教师"对话轮次中进行（教师=父母：教师说 → 网络回应 → 教师反馈 → 网络修正 → 下一轮），**五步闭环是对话的内容而非形式**；对话对象**先 LLM 教师陪练（父母角色）→ 对话能力成熟后开放真实用户**（呼应"AI 慢下来、公众可理解"愿景）。任何单元不得脱离对话场景孤立训练（"只练不说"不合格）。落地细则见 §四"对话即学习"。

## 四、分级成长路线

### 对话即学习（铁律 6 落地：教学对话机制，2026-08-10 用户定稿）

**定位**：对话 = **教学环境**（不是某个 Stage）。人类语言习得的第一经验是和父母对话（发声→回应→再发声的轮替出现在 6-12 个月，先于单词）；网络同样——所有单元的教与学都发生在"网络↔教师"的对话轮次里，**五步闭环是对话的内容，对话是五步的场景**。没有对话场景的教学 = "只练不说"，不合格（铁律 6）。

**对话轮次机制（turn-taking）**：一段对话 = 反复的"回合"——

| 回合角色 | 内容 | 网络机制 |
|---|---|---|
| 教师说 | 输入句 / 示范 / 出题（"这是什么？""跟我读：我要苹果"） | 输入走链（已有） |
| 网络回应 | 复述 / 作答 / 自判（"苹果""我要苹果""可造"） | 槽位走链生成 + 结构自判（②③⑤） |
| 教师反馈 | 肯定 / 纠正 + 讲评原因（LLM 教师判断+解释，v11） | 验证门 + 连接级归因处罚（④） |
| 网络修正 | 边修正后进入下一轮 | 处罚/固化沉淀 |
| 对话延续 | 教师按上一轮内容出下一轮（多轮上下文） | 句级转移定式 + 对话轮次 = §12 行为模式选择（复读/作答/提问/沉默都是模式） |

**对话类型（对标母语习得，由早到晚）**：
1. **轮替对话**（6-12 月）：教师发声 → 网络回声（任意输出）→ 教师回应——先学会"轮流"，内容后置（网络只有基础词级即可开始）
2. **应答对话**：教师问"这是什么？" → 网络答词（词/词组单元）；"你在做什么？" → 网络答句（句子单元）
3. **复述跟读**：教师说整句 → 网络跟读（Stage 2 整句涟漪已具备）
4. **主动发起**：网络自己开口（指向/提问）——衔接 §4.8"该不该开口"（唤起强度够 → 开口，不够 → 沉默）
5. **对话延续**：回应后教师追问 → 网络再回应（多轮，句间转移）

**对话对象阶段（先教师后用户）**：
- **阶段一 教师陪练**：LLM 教师扮演"父母"——可控（脚本 + 动态生成）、可重复（同一轮次可重放）、可批改讲评（判断+原因）。对话语料 = 脚本构造（每单元按五步出对话剧本）+ 教师临场生成。
- **阶段二 真实用户**：对话能力成熟（轮次完成率 + 回应一致率达验收线）后开放真实用户——响应"AI 慢下来、公众可理解"愿景（公众能直接和网络对话、看它怎么想）；LLM 教师退为后台保底（判断/讲评仍可介入纠错）。

**验收口径**：① 轮次完成率（"教师说→网络回应→教师反馈"一轮跑通的比例）；② 回应一致率（网络回应 vs 教师预期一致率，分档：复述/作答/自判）；③ 主动发起（§4.8：该开口时开口、不该开口不说，答不出时诚实说"不知道"）。

**诚实边界**：对话早期 = 检索/复述级（网络回的是记忆里的词句，不是生成新意）；"交谈"要升到"理解"，依赖 ④⑤ 内化后的结构自判与解释通道内化（§2.6 末未来路线）；对话内容上限 = 网络已学结构（没学过的词句自然答不出，正好是"不知道"的诚实样本）。

**v2.9 实现（对话教学升级，`_speak.py` 实测）**——用户反馈"网络一直在说我吃苹果"（固定起始词教学 → 网络固化重复）→ 应答对话落地：① **教师发起对话**（不再给固定起始词）：**话题块机制**——教师批改后围绕**同一话题继续发起下一次对话**（换问法，TALK_BLOCK=3 轮），练熟一个话题再换下一个，网络**听问题再作答**（听到问题里的动词就主导说它，应答 Intraverbal 落地，幼儿"你问我答"机制）；② **反复重复 → 惩罚**：近 3 轮内**同一句累计出现 ≥3 次**才算"反复"（连说同一句才罚，偶尔重提不算）→ 该句 V→O 与尾边减半（不动共享 S→V 边），逼网络换说法（打破"奖励越练越强 → 单边垄断"的固化循环，根因 = 每轮示范都教同一句 + 100 分句奖励学 2 次）；③ **答非所问（不通顺）→ 惩罚**：S/V 与话题不符 → 不给奖励 + 计数清零 + **示范重铸正确应答**（不删边，句子本身合法；判序在重复之前，避免重复了错句被当"重复"处理、示范跟着错动词教——实测 bug 修正）；④ **采样权重归一化**（÷最大权重）+ **hear 引导 ×8 主导**：弱边也能参与探索、听到的动词主导应答（实测修掉"问题含「什么」→ 回响同时激活所有动词 → 引导抵消"的坑）；⑤ **扩写式示范**（用户："示范的时候是把网络的话扩写的最自然"）：示范顺着网络刚说的话走——说半句补完整（Expansion）、答非所问重铸（Recast）、说陈述扩成问句、说问句换具体答案、连说重复换宾语；⑥ **对话记录 + 实验数据留档**（用户："教师和网络的对话也要记录""以后任何实验数据都要有留档"）：每轮对话（教师问/网络答/评分/反馈/奖励/示范/streak）逐轮写入 `runs/_speak_logs/{时间戳}_{种子}_{教师}/talk_log.json`，汇总指标 + 教学前后边权重对比写入 result.json，教学后网络存 net_after.npz（snapshot 同格式可恢复），基快照 v11.2 作对照组。**实测（规则教师，seed=我）**：66 轮通过——网络随话题换动词换宾语（吃→鸡蛋/饼干/苹果、喝→牛奶、看→商店/公园…）、问句 100 分主导、连续 15 次通过其中最后 5 次独立说出、答非所问 14 次清零、反复重复惩罚 3 次；教学后 S→V 边从全 0 长到 256、V→O 边按教学分化（吃→鸡蛋 120、喝→牛奶 117、看→公园 96…），对照组数据完整留档。

### 教网络说话（教学方法查证 2026-08-10：言语行为教学法 + 盲人语言教学）

**A. 言语行为教学法（Verbal Behavior，Skinner 1957 / VB-MAPP）——说话 = 四种独立操作项**

| 操作项 | 功能 | 例子 | 网络教学场景 | 现状 |
|---|---|---|---|---|
| **Echoic 仿说** | 重复他人话语 | 师说"球"→生说"球" | 跟读复述（整句涟漪） | ✅ v7 |
| **Tact 命名** | 命名事物/类别 | 看到狗→"狗" | 词↔类别标签命名 | 🟡 词单元 |
| **Mand 要求** | 动机驱动请求 | 想要果汁→"果汁" | **主动**说"我要苹果"（S+V+O） | 🟡 v9/v10 |
| **Intraverbal 应答** | 回应他人言语 | "你叫什么？"→"李明" | 回答"你要什么？→我要苹果" | ❌ 未开发 |

- **教学顺序（VB-MAPP 框架）：Mand → Echoic → Tact → Intraverbal**——先建立"说话能带来结果"的功能性动机（Mand 第一），仿说作桥梁（Echoic 第二，靠它教其余形式），再命名（Tact），最后对话应答（Intraverbal）
- **关键原则：四种操作项是独立能力，分别教、分别验收**——网络会复述"我要苹果"（Echoic）≠ 会主动要（Mand）≠ 会回答提问（Intraverbal）；"会命名苹果"也不等于"会要求苹果"（VB 核心洞见：一种语境学会 ≠ 其他语境能用）

**B. 回应性语言刺激策略（语言治疗循证：Language Stimulation / Expansion / Recast）**

- **Self-talk / Parallel talk（自我/平行对话）**：教师描述自己在做什么（"我在吃苹果"）、网络在做什么（"你在看公园"）——持续语言暴露（v7 跟读 + 对话场景）
- **Expansion（扩展，加一原则）**：网络说"苹果" → 教师扩展"我要苹果"（**每次只加一个信息点**）——网络学 S+V+O 结构的对话路径，与 ② 怎么造衔接
- **Recast（重铸）**：网络说错 → 教师**不处罚、用正确形式重说一遍**（"他走走了"→"对，他走了"）——**与 v11 处罚互补：处罚删错边（去掉错的）、重铸示对句（示范对的）**，两者合一才是完整纠错
- **Wait time（时间延迟）**：教师提问后留 5-10 秒等待——网络唤起需要传播时间，不等它就是"抢答式教学"

**C. 网络 = 盲人（用户类比 2026-08-10：定式网络无视觉，只能听和说）**

- **定位**：网络的学习通道 = 输入文本走链（听）+ 输出语句（说），**无视觉/味觉/触觉/嗅觉感知通道**——与盲童语言习得的处境一致（盲童靠**听觉模仿 + 强化**学说话，不能视觉模仿口型/表情）
- **教学适配（盲童实证映射）**：
  - 新词必须关联**可感知物**（"苹果" + 摸/闻）→ 网络 = 词↔义原/类别边（§2.5 已建）；但网络"感知" = **文本关联而非真实感知**（义原词典是语言描述）
  - **五感教学 → 文本空间替代**：盲童靠语言描述构建颜色概念（颜色认知研究：盲童形成"事物-颜色"语义维度，非"颜色-非颜色"维度）→ 网络同理："红色"绑定的是共现词（苹果/红旗），不是光波感知
  - **人称代词教学**（盲童最难点：你/我/他混淆，靠情景游戏反复练）→ 网络 S 位人称类绑定（v9/v10 已建，SVO 槽位教学同构）
  - **处理时间更长** → Wait time 策略（B）
- **Verbalism（言语主义/空洞语言）——最关键诚实边界**：盲童会用词但无对应经验（能说"红色"却不知红色是什么；实证：感知不可达的词产出更少，盲童 vs 明眼童，PMC 2025）→ **网络同理：能说"苹果是甜的"（词↔义原边）但"甜"是文本关联不是味觉**——说话内容上限 = 文本空间已学结构；感知属性词须标注"感知缺口"（诚实说"我没尝过，这是书上说的"），衔接 §4.8"该不该开口"与 §2.5 诚实边界③（HowNet 不标注感知属性）

**D. 自闭症干预启发（2026-08-10 查证：ABA/DTT → NDBI 演化链，全量落地 _speak.py）**

**为什么像**：用户直觉——"1对1 对话教学（指令→示范→反应→评分奖励→连续 15 次通过）"与 **ABA/DTT 离散试训**同构（DTT 五要素：指令 SD → 提示 → 反应 → 后果（强化/纠错）→ 回合间隔；掌握标准 mastery criterion = 连续达标通过）。对照 ABA 干预圈对这套方法近 40 年的反思与升级，暴露我们方案的坑与改进方向：

| # | 干预循证实践（出处） | 核心内容 | 网络映射 | 落地 |
|---|---|---|---|---|
| 1 | **提示渐隐 / Prompt Fading**（Touchette 1971 Time Delay；MacDuff 2001；Fading 综述） | 提示的目标是**撤掉它**；不渐隐 → **提示依赖**（孩子只在提示出现时才做，表面会了实际依赖）；正确渐隐的技能 6 个月保留 **89%** vs 不渐隐 **45%** | **我们最初的"每次都要示范" = 每次全提示 → 提示依赖风险**（网络学的可能是"等示范再模仿"而非独立说话） | ✅ 已实现：`_speak.py` 三级渐隐——连续 <10 次全示范（含问句）→ ≥10 次**撤示范**（独立说话，独立说对的句子奖励加成：多学 1 次固化独立定式） |
| 2 | **Mand 训练 / 偶发教学**（Incidental Teaching；Graham 2025） | 想表达→挡住→示范→等待→给了→重复 3-5 次；"**奖励与努力匹配：回应越大、奖励越大**"；等待更久打破提示依赖 | ② 主动造句 = Mand 训练原型（网络主动要求"我要苹果"） | ✅ 已实现：质量分级奖励（100 分问句学 2 次 > 80 分陈述学 1 次，努力/奖励匹配）；Wait time 已并入（网络自己采样探索，教师不抢话） |
| 3 | **PRT 关键反应训练**（Koegel；NCAEP EBP） | 四大支柱：动机、多线索、自我发起、**自然强化**；**强化尝试（reinforcing attempts）**——孩子试了就算数 | 半句（40 分）= 尝试，完全不给奖励 → 网络可能"不敢试" | ✅ 已实现：半句给**部分奖励**（学 [S,V] 强化 S→V 边，鼓励尝试） |
| 4 | **中性纠错**（现代 DTT 进化：停顿→重示范→再试→较低强化，"不是挫败或惩罚"） | 错误后用中性纠错程序，避免惩罚色彩 | 我们"搭配错 → 删边"是经典惩罚派 | ✅ 已实现：保留删边（网络唯一能理解的负信号，客观减权）+ LLM 教师中性语气（不打击）+ 错误后下一轮重试 |
| 5 | **掌握标准 + 泛化 + 维持**（mastery criterion；泛化跨环境/跨人；强化安排表：连续强化建立 → 间歇强化维持抗消退） | 掌握后不结束：泛化（多情境）+ 转间歇强化检验抗消退（停止强化 → 行为消退 = 网络权重遗忘/睡眠巩固对应物） | 连续 15 次 = 掌握标准；多起始词（我/你/他/猫）= 泛化 | 🟡 已实现前两环（15 次掌握 + 多种子泛化）；**维持/抗消退检验 = v12 设计**（教学后停训、间隔验收确认定式不退化，衔接铁律 2 零遗忘验收） |

**核心洞见（写进成长协议）**：① **示范是脚手架，必须渐隐**——教学收尾的标志不是"网络在有示范时能说对"，而是"撤掉示范后独立说对"（我们定：连续 15 次通过中**最后 5 次必须是独立说出**）；② **奖励要匹配努力、覆盖尝试**（说得好奖励高、尝试了有部分奖励、只有说错才删边）；③ **掌握 ≠ 结束**——掌握后要泛化（换起始词/换教师）+ 抗消退检验（v12 留）。

### 学习单元闭环明细（铁律 5 落地：每单元五步详细规划，2026-08-10 用户定稿）

**通用五步含义**（所有单元同一语义，①②③ 因单元而异、④⑤ 全单元复用通用机制）：

| 步 | 教学动作 | 网络机制 | 教师角色 |
|---|---|---|---|
| ① 是什么 | 识别单元基本形态（复述） | 模式固化 + 整块唤起 | 示范/跟读 |
| ② 怎么造 | 按规则组合**没学过**的新实例 | 槽位/hub/走链组合 | 出题/示范 |
| ③ 造对的 | 约束合法、拒绝病态 | 类别约束 + 验证门拒绝 | 判对错 |
| ④ 为什么错 | 错误归因到**具体连接** + 自然语言原因 | 连接级归因处罚（v11） | **LLM 教师**（判断+解释） |
| ⑤ 自己判断 | **⑤a 学怎么做**：先学判断方法/标准（怎么判断对错）→ **⑤b 课后练习**：网络自己判断对错（判断内化到结构） | 判断方法教学（示范）→ 结构检查自判 + 阈值标定（v12） | 示范判断方法 → **批改讲评**：批改对错 + 讲评错因，网络再修正 |

**推进原则**：① 每个单元的 ④⑤ 复用 v11/v12 通用机制（连接级归因处罚 + LLM 教师 + 结构自判），**不重复发明**；② 前单元 ⑤ 课后练习批改讲评收敛（自判错误样本纠错到收敛）才进下一单元（铁律 4/5 衔接）；③ ⑤ 的批改口径 = **网络自判 vs LLM 教师判断一致率**（教师批改作业）；④ ⑤ 之后自然衔接 §4.8（"该不该开口"阈值标定）；⑤ **每单元教学全程以对话轮次为载体**（铁律 6：教师说 → 网络回应 → 教师反馈），五步闭环 = 对话剧本内容，禁止脱离对话场景的孤立训练。

**课后练习设计原则（教学法查证 2026-08-10，⑤b 出题依据）**——查证教学法/认知科学练习设计（Testing Effect、Spacing、Interleaving、Variation、Feedback、Cognitive Load、Encoding Specificity、分层练习）：

| # | 教学法原则（出处） | 含义 | 网络实现 |
|---|---|---|---|
| 1 | 检索优先 / Testing Effect（Roediger & Karpicke 2006） | 自测回忆 > 反复重读（记忆高 ~50%）；**练习本身即学习** | 自判 = 主动从边结构"回忆"判定（走链即检索），**不重放训练样本** |
| 2 | 间隔重复 / Spacing（Ebbinghaus 遗忘曲线；Cepeda 2006） | 分散练习 > 集中突击（当天/隔天/一周，2+2+1 模式） | **适配**：网络无时间遗忘（W 不衰减）→ 间隔意义 = **分轮重测确认不回退**（铁律 2 零遗忘验收天然是间隔形式）；练习集分批、跨轮穿插 |
| 3 | 穿插练习 / Interleaving（Bjork；Rohrer & Taylor 2007） | 混合题型 > 单一连续；逼辨识差异、迁移更强（"合意困难"，当下吃力但记得牢） | 练习集**混搭不同题源**（如吃/看/画/喝交错出题），防"O槽 保底"思维定式 |
| 4 | 变式练习 / Variation（Bjork & Bjork 2020） | 同一知识点多维变式（正向/逆向/特殊/综合），防思维僵化 | 同一 (S,V) 出 **正向**（该配 O）/ **逆向**（不该配 O）/ **临界**（类别泛化二跳）三型题 |
| 5 | 即时 + 精细化反馈 / Elaborative Feedback（Butler & Roediger 2008） | 反馈在检索活跃时立即给；**解释"为什么对/错" > 只给对错信号** | LLM 教师批改 = 判断 + **讲评原因**（elaborative），每次自判后立即给（v11 已具备） |
| 6 | 认知负荷管理 / CLT（Sweller） | 先工作样例 → 撤脚手架 → 独立练习；一次一个概念 | ⑤a 工作样例（教师示范判断过程）→ ⑤b 独立练习；一次判一个组合 |
| 7 | 编码特异性 / Encoding Specificity（Tulving & Thomson 1973） | 练习线索 = 应用线索（水下记词在水下回忆更好） | 练习用**真实槽位/走链路径**（与 ②③ 同机制），判断线索 = 应用线索 |
| 8 | 分层练习（"学练展评"模式：基础过关 → 变式迁移） | 基础（自动化）/ 巩固 / 拓展（迁移），保底不封顶 | 基础题（训练组合）/ 巩固题（新组合）/ 拓展题（类别泛化二跳） |

**通用题集结构（⑤b 每单元统一）**：**三档 × 变式 × 穿插**——每次练习 = 混搭题集；批改口径 = 网络自判 vs LLM 教师一致率，**分档统计**（基础档应 ≈1.0、巩固档 ≥0.9、拓展档允许 <1.0 留泛化边界，阈值随单元定）。分档意义 = 自判置信分层（§4.8"该不该开口"的输入：拓展档低置信 → 判"不知道"更诚实）。

- **穿插**：因果/转折/顺序三类关系混出，逼辨"这组关系词配不配"
- **批改**：LLM 教师讲评语义因果错因（"因为下雨所以带伞合理；因为下雨所以不带伞不合理——因果方向错了"）

关键设计：④ 的归因对象 = 错误句间转移边/文体误判边；⑤ 的自判是 §4.8 元认知预备的最佳落点（QA 语料子集"答对固化/答错拒绝"已在 Stage 4 设计，见下）。文章单元是"复刻闭环"的完整考验（单元最大、关系最复杂）。

**⑤b 课后练习规划（文章单元）**：
- **基础档**：训练句对复测（句 A → 句 B 接得上吗？）——自判 = 句间转移直连可达性
- **巩固档**：新接续（训练过的句 A + 没配过的句 B）——主题句集二跳
- **拓展档**：文体识别（这篇是什么文体？）——类型 hub 举一反三（复用类别机制）；跨主题接续
- **变式**：正向（接得上）/ 逆向（接不上：跑题）/ 临界（模糊主题——句 A 可接多条句 B，判"哪个最相关"，低置信判"不知道"）
- **穿插**：多主题交错（足球/电商/天气混出），防"见句就续"定式
- **批改**：LLM 教师讲评（"这句接续跑题：它和上句没有共享主题词，转移边弱…"）——接续"为什么对/错"= 句间逻辑链的解释

#### 7. 推理单元（Stage 5：类比/三段论/条件推理）

| 步 | 内容 | 数据 | 机制 | 状态 |
|---|---|---|---|---|
| ① 是什么 | 逻辑链复述（前提→结论 模式） | 推理语料 | 概念涟漪 + 涟漪转移 | ⏳ 未开发 |

关键设计：④ 是五步闭环的终点形态——推理错误的归因 + 解释 = 元认知（§4.8 预备的完整体）；⑤ 的自判直接支撑"AI 慢下来、公众可理解"愿景（网络能解释自己的推理为什么成立/不成立）。

**⑤b 课后练习规划（推理单元）**：
- **基础档**：训练逻辑链复测（A→B→C 成立吗？）——自判 = 概念涟漪链路可达性
- **巩固档**：新前提组合（换概念，同构推理）——涟漪转移泛化
- **拓展档**：类比迁移（换领域同构，如 苹果:水果 = 狗:?）——类别 hub 二跳
- **变式**：正向（成立）/ 逆向（不成立：无效推理）/ 临界（看似成立实则无效——偷换概念，最高阶自判，LLM 教师裁决）
- **穿插**：三段论/类比/条件推理混出，逼辨"用哪种推理"
- **批改**：LLM 教师讲评推理错因（"大前提不成立：所有鸟都会飞 是假，因为企鹅不会飞…"）——自判 + 解释 = 网络元认知的完整体

### Stage 2.5 词语类别（v2.4 改造：词典学词义）——数据：OpenHowNet 义原判断题

**状态：✅ 已完成（2026-08-10，快照 v8.5，实测见本段末，报告见 docs/reports/[REPORT]-定式网络Stage2.5词典学词义实验报告）**——五步闭环进度（词单元）：① 是什么 ✅ v1.0/v2.0 → ② 怎么造 ✅ v8.5 → ③ 造对的 ✅ v8.5 → ④⑤ ⏳ 词单元 v13（详见 §四"学习单元闭环明细"表 1）

**定位**：补词级（Stage 0-1）与句级（Stage 2）之间缺失的"语义角色层"。v2.4 改造源于用户诊断——**"词有了、词义没有"**：词形复述 1.0（模式已固化），但同类词在 stage2_sents 中几乎不同句共现（探测：食物仅 {蔬菜,猪肉} 一个 2 词块），词义（出边结构）孤立 → 举一反三无路可走。跟读（监督）只能焊"清单直连"，学不会词义；改用**词典（OpenHowNet 义原）+ RL 验证门**。

- **词义 = 词↔义原关联集合（出边结构）**：定式网络里"词义"不是额外标签，就是这个词能唤起什么、被什么唤起。词典直接给出词↔义原连接，绕开"语料无共现"的根因。
- **数据源：OpenHowNet（知网，清华 THUNLP 开源，MIT）**——约 2000 义原标注 20 万+ 中英文概念。实测 v7.0 词表 31819 词中 16781 词（**52.7%**）可查，5 万+ 词↔义原边。义原天然分两层：**类别义原**（fruit|水果、animal|动物、InstitutePlace|场所 → 类别 hub，供 Stage 2.6 槽位约束）+ **属性/功能义原**（edible|可食、study|学习 → 感知/行为通道）。
- **机制 = RL 验证门（§12.6 三因子规则）**：每条词↔义原关系 = 一道判断题——
  - "苹果是水果？对" → 验证门固化（苹果→水果 边）
  - "苹果是咸的？错" → 验证门拒绝固化（错误联想不焊死）
  - 词义 = **经验证门确认**的出边集合：可查（出边直读）、可扩展（新判断题）、可拒错（防认知偏差固化）
  - 多义原词取并集 = 多通道（类别 + 功能 + 来源），与 §12.7 语义链（苹果→水果→食物）同机制
- **类别举一反三**：与标签共享义原的未训练词（hold-out），凭其与类别成员共享的义原出边走链唤起标签——**与验证门走链同一检索机制**；未覆盖词（无义原）自然作"知道/不知道"对照（衔接 §4.8）
- **诚实边界**：① OpenHowNet 义原以**类别/功能/来源**为主，**不标注**"甜/圆/红"这类感知属性（视觉/味觉/触觉通道数据缺失，留待 Stage 4 用自然语言定义句补充，如 Wiki 定义句）；② 覆盖率 52.7%：数字/专名/新词无词义边，正好是"真不知道"的自然样本；③ 语法词性（名词/动词/形容词）仍需外部标注，作后续进阶（动作类≈动词类先近似）
- **验收**：① 类别归属（训练词→标签义原直连 ≥0.9）；② 词义举一反三（hold-out 词→本类信号占优 ≥50%）；③ 替换造句（"我要"→食物类词唤起，类别约束的槽位填充雏形）；④ 字/词/句全链零遗忘
- **实测（v8.5，全量 5 类：食物/动物/颜色/时间/地点；动作类跳过见诚实边界）**：
  - ① 类别归属 **1.0000** ✅（训练成员→本类标签直连，5 类全过）
  - ② 词义举一反三 **1.0000** ✅（hold-out 3 例/类：坐果/挂果/瓜子→食物、刺猬/北极熊/四不像→动物、红线/循环/染红→颜色、一世/一个半月/一代→时间、全日空/双人间/巷道→地点，本类信号占优 8-48 权重）
  - ③ 替换造句食物信号 **28.8 ≥ 他类 38.4×0.5** ✅（直接命中 土豆/饼干/苹果）
  - ④ 零遗忘：字 1.0000 / 词 1.0000 / 句 0.9324（base 0.9355）✅
  - 验证门拒绝 **54/54** 负例边未增长 ✅（"错"判断题不焊死）
- **实测暴露（数据驱动修正，2026-08-10）**：① HowNet 类别义原（动物/颜色/场所）覆盖的是"下巴/底色/一世"这类词，与日常类别词错位 → 标签组按人工词表词的义原**扩组**（食物+食品/蔬菜、动物+牲畜/走兽/虫、颜色+单字色名、地点+设施/房间）；② **动作类（吃/跑/跳…）HowNet 覆盖 0** → 本阶段诚实跳过（词性标注后补）；③ 成员筛选须"义原含本类标签"（"后来/最近"义原为将来/新近，无"时间"标签，排除）；④ 大网络虚词劫持（"我"→的 256）使单链走链失效 → 验收③改用出边直读聚合（与验收②同构）

- **举一反三（类别泛化，2.5 同款机制）**：宾语词↔类别标签边（2.5 已有）→ "吃"连过的食物词经"食物"标签唤起**未共现的同类词**（吃+香蕉：香蕉没跟吃训过，凭 吃→苹果→食物→香蕉 链成立）——从典型例句学、往同类泛化
- **病句拒绝（不固化即拒绝）**：语料无"吃+学校"共现 → 吃 出边无学校 → 学校进不了候选（负例不进正例，RL 验证门哲学："验证门管该不该记"）
- **聚合机制（v9.0 大改）**：候选主源 = **V 词出边聚合**（直接搭配词 + 2 跳类别泛化），**O槽 只做骨架路径确认**（不再提供词权重）——"吃什么"由"吃"的搭配决定，候选随动词变化；无搭配词可学的动词（学/踢/读/听：学书/踢球/读报/听歌的宾语不在 O 集）→ 回退 O槽 保底泛名词池
- 诚实边界：例句为构造（教材式，无真实日常语料——评论/新闻语域不匹配已探测）；搭配表非穷尽（"买"还可接非食物商品）；"看"接地点是 O 集限制下的妥协（看风景/看家更自然）；动词完整词义仍缺，搭配是"共现结构 + 类别泛化"级

**验收数据（训练/测试组合分离——造句 ≠ 背句）**：
- S 集：人称 5-8 + 动物 5（猫/狗/鸟/鱼/兔子）≈ 10；V 集：动作 10（吃/喝/买/看/学/画/踢/洗/读/听…）；O 集：食物 8 + 地点 4 ≈ 12
- 全组合 ≈ 1200 条 → **训练 800 / 测试 400**（测试三元组 (S2,V2,O2) 三词各已单独训练槽位绑定与类别，但组合从未共同出现）
- 词↔槽位绑定与类别判断**全体词单独训**（不随组合切分）；hold-out：每类留 1-2 词不训类别判断（§2.5 机制，凭共享信号唤起）

**验收（四道，沿用 2.5 出边直读聚合防虚词劫持）**：
1. **槽位归属**：训练词→S/V/O 槽位直连 ≥0.9（我→S槽、吃→V槽、苹果→O槽）
2. **类别约束**：动作类成员→"动作"标签 ≥0.9；S/O 位沿用 2.5 四类归属不回退
3. **造句泛化（核心，两级）**：
   - ③a 骨架唤起：输入 S2 → 出边聚合唤起 V 槽词（动作类信号）；输入 [S2+V2] → 唤起 O 槽词（宾语类信号）——骨架成立
   - ③b 槽位填充（新组合 = 造句）：输入 [S2+V2] → 宾语位唤起**未组合过的** O 类词（凭"O 类标签"边被宾语位约束唤起，如"我要水"的"水"从未在"我要"组合训过）——信号占优 ≥50%（2.5 hold-out 口径）。**v2.5 增补（动宾约束后）**：配了搭配的动词 → top-8 中**该动词搭配类别占优 ≥0.5**（候选随动词变化）；**病句拒绝**：异类组合（吃+学校、喝+公园）→ 该异类词**不得进入 top-8**（语料无共现 → 无边）；未配搭配的动词（学/踢/读/听）保持宾语位名词占比 ≥0.5（诚实留白）
4. **全链零遗忘**：字/词/句复述 + 2.5 四类归属 + hold-out 全不回退

**n 增量（估算）**：3 槽位 + 动作标签 + 人称标签 + 动作成员 ~30 + 人称成员 ~7 ≈ 42 模式 × K=4 ≈ 170 神经元（v8.5 n=148604，游标续用一次扩容几百）

**实测结果（2026-08-10 全量，详见报告）**：槽位归属 1.0 / 类别约束 1.0 / 骨架成立（S槽→V槽 4.8、V槽→O槽 4.8、槽位↔类别 8.0）/ 造句填充 **400 测试组合 100%** 宾语位名词 top-8 占比 1.0 / 零遗忘（字词句 + 2.5 四类 + hold-out 15/15）。冒烟→全量修正：骨架 6 模式全连接稀释 O 位约束（0.38<0.5）→ **分离注入**（骨架只训三槽，绑定/约束用判断句单独强训）；标签出边 1:1 聚合被 HowNet 噪声劫持 → O槽 出边为主源 + 标签 ×0.3 折扣。

**v11 迭代设计（2026-08-10，RL 颗粒度升级 + 处罚原因；✅ 已完成，v11.0 规则版 / v11.1 LLM 教师首版 / v11.2 LLM 教师纯语义版，实测数据见设计末）**——用户追问"造句只知可不可以、不知为什么"+"现在 RL 颗粒度够吗"：

- **问题定性（统计 vs 价值 + 颗粒度缺口）**：v10 的动宾搭配是**统计共现**（吃→苹果因例句共现、吃↛学校因无共现），网络只有关联强度、没有后果；生物是**价值学习**（吃→食物因后果好、吃↛石头因痛觉预期）。**颗粒度缺口**：现有 RL 奖励是**样本级二元标量**（对/错打回整次共发放），而"为什么错"是**连接级**（哪条边把错词带进候选）——处罚原因必须落到具体连接，现有验证门做不到。
- **文献对标（查证 2026-08-10）**：RLBFF（ICLR 2026，NVIDIA）——奖励是**原则粒度**（每条原则一个二元判断："石头是食物吗？否"），奖励自带"为什么"（哪条原则不满足）；RLVR（DeepSeek R1）——**规则验证器自动判对错**，零人工标注；Explainable RLHF（NeurIPS 2025）——**归因粒度**：定位导致错误响应的训练数据 → 修正；RL with Human Advice（Frontiers 2021）——区分评价性/纠正性反馈，explanations 是建议的一种形式。
- **设计（核心 = RL 颗粒度升级）**：
  1. **RL 颗粒度升级：连接级归因处罚（核心设计点，v2.6 修订）**——"错"从样本级升级到连接级：
     - **归因**：错误发生时（如"吃+石头"进了候选），反向追踪候选词**靠哪条边进入 top**（石头→O槽？食物标签→石头？O槽 保底？）→ 定位具体连接 = 处罚落点（对齐 Explainable RLHF 归因→修正；RL 信用分配 credit assignment）
     - **处罚执行（连接级）**：落点边**显式减权 → 删除**（排斥 = 边不存在；稀疏网络 W 无负权重，删除即"惩罚结果"）；不是整次打回，是纠正具体连接
     - **原则级奖励**：验证器输出"每条原则的二元判断"（石头是食物吗？否）而非整句一个对/错（对齐 RLBFF 原则粒度）
  2. **LLM 教师（判断 + 原因一体，2026-08-10 用户决策）**——用户定：**强化学习时的判断由 LLM 负责**（不止处罚原因）：
     - **判断**："吃石头对吗？" → LLM 判"错"（LLM-as-Judge / RLAIF：用 LLM 反馈代替人工/规则验证）；"看石头对吗？" → LLM 判"对"——**解决规则验证器的类别级误判**（"看石头"类别不匹配但语义合法，规则比对会误判负例，LLM 语义判断能识别）
     - **解释**：LLM 同时给自然语言处罚原因（"因为石头不是食物"）——判断与原因一体输出
     - **架构划分（教学对标）**：**LLM = 教师（判断 + 解释），网络 = 学生（归因处罚 + 记忆）**——LLM 不碰网络边；处罚仍由网络执行（归因 → 连接减权删除）；判断信号注入网络 = RL 奖励（教师认可固化 / 教师否定 → 网络归因处罚）
     - **双轨实现**：LLM 判断依赖 API（DeepSeek，环境变量 DEEPSEEK_API_KEY）；**无 key 时回退规则验证器**（类别比对，v10 已验）——规则验证 = 保底，LLM 验证 = 升级，冒烟/全量都可在无 key 下跑通，LLM 接入为配置项
  3. **LLM 受限解释器（自然语言原因）**：**归因记录**（哪条边、权重、判定、处罚动作）→ 结构化诊断 → LLM 翻译为自然语言（"不能吃石头：因为石头不属于食物类（判定边），而吃通常搭配食物（共现边），候选由 O槽 出边带入 → 已删除该边"）。**诚实底线**：输入限死（只喂网络真实学到的边）+ 输出越界拦截（LLM 生成网络边里没有的内容 → 拦截/标注"非网络知识"）——LLM 是**翻译器（代嘴）不是知识源**，解释仍是网络自己认知的语言化
  - **否定知识表达**：`~食物` 否定 hub 降级为实现细节（**可不建**）——排斥用"边删除"表达（稀疏网络正权重减到 0 即不存在）；是否额外建否定 hub 由冒烟实测决定（负例频次高、需累积记忆时再建）
- **RL 对标（补 §2.6 表）**：连接级归因处罚 = 信用分配（credit assignment，奖励分配到具体连接）+ Explainable RLHF 归因修正；原则级二元奖励 = RLBFF；**LLM 教师（判断+原因） = RLAIF / LLM-as-Judge**（LLM 反馈代替人工/规则验证）；无 key 回退规则验证器 = 可验证奖励（RLVR）；约束强度差异（吃严格、看宽松）= 不同 (V,类别) 对的 Q 值分布；LLM 解释器 = 可解释 RL 的自然语言归因层
- **诚实边界**：① 网络"知道"错误原因的**原材料（边）与行为（拒绝），但说不出**（无语言通道），LLM 只补通道不补知识；② 归因粒度受"候选唤起路径可追踪"限制——多源聚合（主源+泛化+保底）时归因到主要贡献边，边权重是正实数、无负向排斥权（删除 = 惩罚上限，无"反向惩罚边"累积）；③ **验证双轨边界**——LLM 教师可识别"看石头"合法（语义判断），但判断用**外部知识**（教师知识，非网络边）；无 key 回退规则验证器仍存类别级误判（"看石头"被误判负例）；④ 语义级（苹果皮不宜吃）判不了，留缺口；⑤ 价值是**次级价值**（教师信号），非生物第一性体感；⑥ "食物为什么能吃"（生理因果）仍缺（HowNet 动作义原覆盖 0）；⑦ **外部知识注入需标注**——LLM 教师的判断结论进入网络学习信号，但网络学到的仍是自己的边（归因处罚），"为什么"的解释来源（教师知识 vs 网络边）在每次诊断中显式区分

- **⑤a 学怎么做判断（判断方法教学）**：先教判断方法/标准——结构检查怎么查（O 在不在 V 的搭配出边可达集）、阈值怎么定（唤起强度多高算"可造"）→ 教师示范判断过程（给诊断样本，教师演示"怎么判"并讲方法）→ 网络把判断方法沉淀为**判断路径模板**（先查直连、再查二跳泛化、再判强度）
- **机制（复用 §4.8 信号，无新训练机制）**：
  - 自判 = **结构检查**：O 在不在 V 的搭配出边可达集（V直连 / 类别泛化二跳可达）+ **唤起强度**（候选 top 排名/强度、走链衰减）→ 二元输出"可造/不可造" + 强度置信
  - **"该不该开口"阈值标定**：验证门教——自判对 → 标"强判断"；自判错 → 教师纠正、标"该说不知道"（§4.8 阈值标定机制）
- **⑤b 课后练习 + 教师批改讲评（内化路径）**：v11 处罚沉淀即自判基础（删边后结构上"不可造"、固化后"可造"）——**LLM 教师判断 → 网络归因处罚/固化 → 边结构状态 = 自判依据**；网络做练习（自判判定）→ **教师批改**（对照 LLM 教师判断：一致率）+ **讲评错因**（自判错误样本 → 教师解释 → 网络归因修正）→ 收敛后进入下一单元（持续学习闭环）
- **⑤b 课后练习规划（句子单元，练习设计原则见 §四"课后练习设计原则"）**：
  - **基础档**：训练组合复测（我要苹果 可造？）——自判 = O 在 V 搭配出边直连可达
  - **巩固档**：新组合（三词都单训过、组合没学过，如 我们要水）——直连 + 类别泛化二跳
  - **拓展档**：类别泛化二跳（吃+香蕉：吃→苹果→食物→香蕉 链可达？）+ 跨类临界（看+石头：类别不匹配但语义合法——**LLM 教师裁决**，网络自判凭 看→地点类 边 + 泛化可达，诚实边界：语义合法性来自教师，网络只判结构）
  - **变式**：正向（可造）/ 逆向（不可造：吃+学校）/ 临界（画+家：v11.2 实测被噪声污染又治愈的样本，作临界题）
  - **穿插**：不同 V 的搭配交错出题（吃/看/画/喝混出），防"O槽 保底"定式（v11.2 一致率 0.587 的分歧样本正是穿插素材）
  - **批改**：LLM 教师讲评错因（"动宾搭配不当，公园是地点非食物"）——批改即 v11 原因的正式化
- **验收**：① 网络自判 vs LLM 教师判断**一致率**（训练后 self-judge 对照 teacher-judge，报告里显式并列两者判定）；② 自判错误样本的教师纠错收敛；③ 继承 v11 全验收零遗忘
- **诚实边界**：自判 = 图可达性检查（路径存在 + 强度），**不是"理解为什么"**（"为什么"仍靠 LLM 解释通道，见近期未来路线）；自判上限 = 网络已学边结构，未见组合凭类别泛化可达，泛化之外判"不知道"（衔接 §4.8）；判断置信 ≠ 语义理解

### Stage 2.7 数字结构（v2.3 新增，2026-08-10 用户追问）——数据：数位跟读 + 组合生成

**定位**：数字域是"槽位机制"的第二战场。现代汉语数字是**双系统并存**，两者都要学：

- **中文数字（单位词系统）**：个/十/百/千/万/十万/百万/千万/亿 = **单位 hub 层级**（乘法单位词："三百四十五" = 3×100+4×10+5，每个数字绑定一个单位词；"三万/三亿" = 更高级单位），不是西方纯位值
- **阿拉伯数字（纯位值系统）**：0-9 十个数码 + **位置即权值**（"123"中 1 在百位、2 在十位、3 在个位，无显式单位词）——直接用 Stage 2.6 的**槽位位置编码**（个位槽/十位槽/百位槽，数码绑定到槽位即位值）
- **混合表达（语料常态）**："8000 万""3.5 万亿" = 阿拉伯数字（位值）+ 中文单位词（hub 进位节点）——双系统接缝，天然验证单位 hub 机制

- **机制**：
  - **数码（0-9 与 零-九）= 数字类别**（复用 Stage 2.5 类别机制）
  - **中文数位词 = 单位 hub**；**万/亿 = 四位一节的进位 hub 层级**（个十百千 | 万十百千 | 亿十百千…）
  - **阿拉伯数字位值 = 位置槽位**（复用 Stage 2.6 词序编码）——"123" = [百位槽+1][十位槽+2][个位槽+3]
  - **数数到大数靠结构生成，不靠背长链**（走链强度衰减问题在此解决：数到 1000 = 单位 hub / 位值槽位组合，不是背 1000 跳）
- **顺序（人类对照）**：数字词/数码识别（记忆）→ "三百四十五""123"组合规则（槽位绑定）→ 万/亿大数感（hub 层级）→ **双系统互译**（"123"↔"一百二十三"，位值↔单位词映射）
- **数据**：数字类别（0-9 + 零至九）+ 中文数位词跟读；语料中新闻/财经数字（"8000 万""3.5 万亿""2026 年"）为天然跟读材料
- **验收**：数字类别归属；1-100 数数链（走链续数）；进位走链（"3百4十5"→"3百4十6"、阿拉伯 "99"→"100"）；双系统互译（阿拉伯↔中文数字，仅结构映射，不要求数值大小）；词/句级零遗忘
- **诚实边界**：先学**形式（两套词序结构）**；"345 > 344"的**数值意义**需数量化表征，后置 Stage 5

### Stage 2.8 数字运算（v2.3 新增，2026-08-10 用户追问）——数据：口诀表 + 竖式样例

**定位**：运算分三个层次，开始时间不同：

| 层次 | 内容 | 机制 | 时机 |
|---|---|---|---|
| 记忆层 | 一位数四则口诀（3+4=7、7×8=56） | QA 查表 + 验证门判对错 | Stage 4 后 |
| 过程层 | 多位数竖式（23+18=41：位对位 + 进位/借位） | 位值槽位（2.7）+ 逐位查表 + 进位链 | 需序列控制/工作记忆（诚实难点） |
| 意义层 | 为什么 3+4=7（数量化表征） | Stage 5 推理 | 最晚、最硬 |

- **运算符词（加/减/乘/除）= 指令 hub**：决定"3,4"查哪张口诀表——"加"= 加法表开关、"乘"= 乘法表开关，即 §12.2"指令跟随"的天然雏形（运算符词 = 行为模式选择的指令，复用类别 hub 机制）
- **一位数四则无进位/借位** = 纯查表（四张表记忆），无过程复杂度
- **多位数竖式** = 位对位调一位数口诀 + 进位传播（个位满 10 → 十位 +1，与 2.7 数数进位同一机制）；**诚实标注**：竖式是"先个位后十位"的多步过程，需要工作记忆 + 序列控制（§12.5 多步/复合模式，单步 RL 需升级层次控制）——不是缺知识，是缺过程执行器
- **验收（记忆层）**：口诀随机抽查 top-1 正确率；错题验证门拒绝固化；词/句级零遗忘
- **诚实边界**：先能"背对"（查表），后能"算对"（过程），最后才"懂对"（意义）

### Stage 3 复杂句级（关系）——数据：因果/转折句

- **数据**：含关系标记的专门句（因为…所以… / 虽然…但是… / 先…然后…）
- **训练**：复杂句反复经历，沉淀**关系词转移定式**（因为→所以 的强关联）
- **验收**：关系词对补全（因为→? 答所以）；句复述不退化（Stage 2 零遗忘）
- **n**：扩容（4096 → 8192，当前规模）

### Stage 4 文章级（句间逻辑）——数据：句对 + 句间关系 + 文章骨架

**定位**：Stage 2 学"句内词间结构"，Stage 4 学"文内句间结构"——文章结构 = 句接句转移 + 句间关系标记 + 文章骨架：

1. **句接句转移**：句 A 涟漪 → 句 B 转移定式（跟读机制从词层搬上句层，CLS 慢系统的句子级转移）
2. **句间关系标记**：Stage 3 的关系词（因为/所以/虽然/但是）从"句内标记"延伸到"跨句标记"（"下雨了。所以带伞出门。"）——关系词是句接句的"方向标签"
3. **文章骨架**：句式骨架（主谓宾之于词 = 总分总/承接/转折布局之于句）同构；主题句/支撑句/总结句的"句子角色"可复用词语类别的 hub 机制（句子角色标签 + 句子成员）
- **验收**：句 B 唤起率（输入句 A 涟漪 → 唤起句 B）；接续不跑题（句间逻辑链）；词/句级不退化
- **QA 语料子集**：问句↔答句对是句接句的特殊形式（问句作句 A、答句作句 B），Stage 4 数据专门化时构造；配合验证门"答对固化/答错拒绝"——**答得出就说，答不出不说（衔接元认知预备）**
- **n**：扩容（8192 → 16384）

### Stage 4.5 文章类型（v2.3 新增，2026-08-10 用户追问）——数据：带类型标注的文章

**定位**：文章结构（句接句/骨架）是"文内怎么排"，**文章类型（文体/类别）是"这整篇属于哪一类"**——与词语类别（Stage 2.5）同机制、同哲学，只是单元从"词"换成"文章"：

| 层级 | 单元 | 类别机制 | 类型信号 |
|---|---|---|---|
| 词层（2.5） | 词 | 词语类别（食物/动作） | 成员↔标签共现 |
| 句层（4） | 句 | 句子角色（主题/支撑/总结） | 句子↔角色标签 |
| **文层（4.5）** | **文章** | **文章类型（记叙/说明/议论/新闻…）** | **文章模式↔类型标签** |

- **机制**：文章（整篇涟漪/模式）与类型标签反复共发放 → 类型 = 文章模式的出边 hub；新文章（没学过类型）输入 → 走链唤起类型标签 = **文体举一反三**（与"菠萝→食物类"同一检索机制）
- **识别信号**：文体标记词（说明文"首先/其次/最后"、议论文"我认为/因此/然而"、新闻"本报讯/导语"）+ 句式特征 + 内容主题——信号在定式网络里就是"文章↔类型"连接结构
- **数据（现成标注）**：语料库 raw 已备——`toutiao_cat_data.txt`（头条新闻 15 类：体育/财经/娱乐/健康…）、`online_shopping_10_cats`（电商评论 10 类）、`ChnSentiCorp`（情感分类）。数据专门化：学文章类型就用带类型标注的文章
- **顺序**：排在 Stage 4 之后（先有"整篇文章模式"，才能做"文章模式↔类型标签"绑定，同词模式先于词类别）
- **验收**：训练文章唤起类型标签 ≥0.9；hold-out 新文章唤起类型 ≥50%（文体识别举一反三）；词/句/文章级零遗忘

### Stage 4.8 元认知预备（v2.3 新增，Stage 5 前）——知道/不知道

**问题**：网络检索是确定性的，唤不起就是空，**它自己不会报告"我不知道"**——没有这个机制，QA 只能"背到就答、背不到就编"。

**机制（定式网络独有：知识 = W 图结构本身，可检查）**：

| 信号 | 是什么 | 对应认知 |
|---|---|---|
| 唤起强度 | fire_ratio 高低、走链强度衰减终止（§12.7 已验证：下一步 < 上一步×0.4 停止） | "知道感"（检索激活量） |
| 路径存在性 | "苹果→颜色"之间 W 里有没有边（图可达性，可查） | 区分"知道但没想起来"（有边弱激活）与"真不知道"（无边） |

- **阈值标定**：fire_ratio 多少算"知道"由**验证门教**——答对 → 该检索标"强知道"；答错 → 标"该说不知道"。三因子规则调制的不只是"固化不固化"，还有"**该不该开口**"
- **诚实边界**：网络做到的"不知道"是**低唤起触发"不知道"响应模式**，不是自我意识（人也是靠"检索失败感"做代理，非绝对自知）
- **定位**：原始信号（强度 + 可达性）现有机制即备，阈值标定在 Stage 5 前接入；排在 Stage 2.5/2.6/3/4 之后自然衔接 QA（见 Stage 4 的 QA 语料子集）

### Stage 5 推理级（概念）——数据：逻辑推理文本

- **数据**：专门推理语料（类比/三段论/条件推理）
- **训练**：概念涟漪 ↔ 概念涟漪转移 + 涟漪泛化（半句唤起类似句）
- **验收**：多步逻辑链补全；举一反三（同主题变体预测一致）
- **n**：按需扩容（16384 → …）

### 每阶段必做（成长协议四件套）

1. 前级零遗忘验收（旧评估集 top-1/复述率不退化）
2. 本阶段专门数据验收（位置分层 / 复述率 / 唤起率）
3. 生成质量对比（本阶段数据上，是否"会说本阶段的话"）
4. **留档（缺一不可，2026-08-10 用户决策"每次实验必须留存实验数据"）**：result.json（指标 metrics：验收数字 + 参数 + 判据）+ **net.npz（模型快照：W + 构造参数 + 模式字典 pats + 分配游标 cursor）** + 数据/分级语料（stage25_sememes.json / stage26_pos.json 等离线抽取数据留 `data/curriculum/`）+ 训练产物（判断题/槽位句集随 runs 落盘）+ 报告（docs/reports/）——**报告给结论、数据给证据，缺一不可**。**统一走 `snapshot.py` 语义版本链**（2026-08-09 落地，MAJOR.MINOR 类比软件版本）：每次训练产生新版本 `runs/v{M}_{N}_{时间戳}/`（旧版本永不删除），index.jsonl 记录 version/parent 父子链；正常续训 major+1（a→a+1→a+2），**回退训练同代变体**（a+2 出问题 → `load_version("2.0")` 回退 a+1 再训 = **a+2.1（3.1）**，与 a+2 平级直接对比）——增量成长硬前提

## 五、数据专门化设计

### 5.1 原则

- 每阶段数据**纯净**（只含该阶段结构），禁止混合跳级
- 数据量按阶段递增（词 < 词组 < 短句 < 复杂句 < 文章 < 推理）
- **每阶段内部有重复**（跟读性质：同一内容反复出现，满足"印象越来越足"）
- 全部生成/抽取到 `data/`，可复现、可留档

### 5.2 数据来源（先抽取，后构造）

现有 corpus_open20w.json 可作为**原料库**，按阶段抽取纯净子集：

| Stage | 抽取规则 | 预估量 |
|---|---|---|
| 0 词表 | 词频 top-N（去 UNK、去停用词） | 1000-3000 词 |
| 1 词组 | 高频相邻词对（bigram 专有数据） | 5000-2 万对 |
| 2 短句 | 语料中 ≤8 词、无 UNK 的句子 | 2 万-5 万句 |
| 2.5 词义 | **OpenHowNet 义原**（词↔义原判断题，验证门固化/拒绝） | 5 万+ 边（实测覆盖 v7.0 词表 52.7%） |
| 2.6 词性 | **jieba.posseg 词性标注**（v8.5 词表 → 动词 19.3%/6049 词，动作类/人称类成员离线抽取） | 3.1 万词（留档 stage26_pos.json） |
| 3 复杂句 | 含 因为/所以/虽然/但是/如果 的句子 | 1 万-3 万句 |
| 4 句对/文章 | 语料中相邻句子对（同段落内）；**Wiki 百科条目**（导语→正文→分节，句接句 + 文章骨架 + 句间逻辑） | 2 万-5 万对 |
| 4.5 文章类型 | **Wiki 条目分类标注**（人物/地理/生物/事件…，自带类型标签，省标注成本） | 数千-数万篇 |
| 5 推理 | 需专门构造（条件/类比模板） | 数千-数万 |

**Wiki 定位（v2.4 明确）**：**Stage 4/4.5 的现成语料，不是现阶段（词义/句式）语料**——Wiki 长文粒度太粗，词义阶段喂长文会重演"20 万篇混合文章让他悟"的失败；其价值在**文章级结构**（句接句、骨架、句间逻辑）与**自带分类标注**（省 4.5 的标注成本）。原始 dump 需清洗（模板/参考文献/格式标记），到 Stage 4 前按 §5.1"先抽取后构造"管线处理即可。

**关键**：每阶段数据 = "反复读的三字经"——同一批句子多次出现（重复率 ≥ 10 次），不是"每句一次"（v1.1 的错误）。重复率是跟读的本质。

## 六、神经元逐步扩容方案与评估

### 6.1 结论：**可以逐步增加神经元数量，且支持任意粒度（含 n+1）**

v2.1 修订（2026-08-09 用户确认）：用户问题——"n=8032 训练好后，下一次训练能不能 n+1？"答案是**能**。`expand(n_new)` 是纯追加，n_new 可以等于 n+1，也可以一次扩几百（机制等价）。"知识的增量 = 神经元的增量"，新增一个概念（如第 27 个字母）就 +1。

### 6.2 技术路径（已验证代码结构）

```python
def expand(self, n_new):            # SparseSchemaNet 新增方法
    assert n_new > self.n
    pad = n_new - self.n
    self.v            = np.vstack([self.v, np.zeros((pad, self.slots))])
    self.spikes       = np.pad(self.spikes, (0, pad))
    self.pre_trace    = np.pad(self.pre_trace, (0, pad))
    self.last_k_star  = np.pad(self.last_k_star, (0, pad))
    self.refractory_left = np.pad(self.refractory_left, (0, pad))
    self.slot_freq    = np.pad(self.slot_freq, ((0, pad), (0, 0)))
    self.W_out       += [[{} for _ in range(self.slots)] for _ in range(pad)]
    self._edge_cache += [[None] * self.slots for _ in range(pad)]
    self._edge_dirty += [[True] * self.slots for _ in range(pad)]
    self.n = n_new
```

- **旧知识 100% 保留**：W_out 前 n_old 行原样复制（连接结构不动），扩容是纯追加
- 新神经元空白 → 供新阶段学习（新词/新词组/新句模式落位）
- **粒度任意**：`n_new = n + 1`（单个新概念按需落位）或成批扩容（几十上百个），机制等价

### 6.3 关键风险与对策：分配制模式字典（v2.1 修订，取代分区冻结）

旧 `_word_pattern(n, k, word)` 用 `crc32(word)` 做种子、在 `[0, n)` 选神经元——**哈希结果依赖 n**。n 一变，旧词模式重算 → 旧 W 连接失配（灾难），n+1 直接被否。

**对策（分配制模式字典，用户已批准）**：
- **模式字典** `pats: {word: [k 个神经元索引]}` 是唯一事实源：词→神经元落位**生成一次、永久冻结、随网络一起持久化**（npz 附加保存），任何扩容都不重算旧词
- **新词落位 = 分配制**：从当前**空白神经元**按游标顺序取 k 个（分配唯一 → 新词之间零冲突），写入模式字典 +1 条
- **n 只是"可用空间上界"**：旧词条目不动，新词在 [0, n) 的空白区分配；n+1 只是把可用空间扩大 1，完全安全
- 与哈希对比：分配制牺牲"确定性跨语料复用"，换来**任意粒度扩容 + 新词零冲突**，更贴近"新概念要新神经元"的认知模型
- 验收：扩容前后，旧评估集 top-1/复述率**逐值一致**（零遗忘硬指标）；新增词复述可学（增益为正）

### 6.4 扩容触发条件（何时扩）

三种触发，全部走同一 `expand`：
- **按需 +1**：新增单个词/概念，模式字典分配游标到达 n 边界 → `expand(n+1)`（第 27 个字母场景）
- **区分度不足**：词模式冲突率（分配后仍重叠）或"排列一致性"跌破阈值 → 成批扩容（空间换区分度）
- **阶段升级**：词→词组→句→文自带扩容计划（§四 n 表），一次扩一档
- 扩容验证：扩容后新阶段学习增益为正 + 旧阶段零遗忘 → 通过

### 6.5 为什么必须扩容（不固定 n）

26 字母实验实测：n=256 时排列一致性跌到 0.10（模式空间不足，词分不开）。语言复杂度随阶段递增（词 3000 → 词组 2 万 → 句 5 万），固定 n=8192 会重演"区分度塌缩"（对应 20 万语料 w_max 饱和后的分数齐平）。**n 随阶段增大，是语言容量与模式区分度的必然需求**，与大脑随年龄增大同理。

### 6.6 续训闭环（v2.2 已验证 ✅ 2026-08-10）

需求（用户 2026-08-10）："模型是逐步迭代的，不是每次从 0 开始学习；以后扩大神经元规模和调整每次调用神经元的数量时，原来之前的记忆不丢。"

**闭环**（脚本 `_grow_continue.py`，报告见 §12.7 后附）：
```

  → baseline 评估        # 零遗忘基准
  → expand(＋4096)       # 纯追加扩容
  → 复测                 # 扩容零遗忘硬指标：旧评估集逐值一致
  → 调 wta_k（2~48）     # "调整每次调用神经元的数量"
  → 分配新词 500 + 跟读   # 游标续用自动扩容
  → save_snapshot        # v6.0，版本链继续
```

**验收结果（全过）**：
- 扩容零遗忘：n 54000→58096，字/词复述 1.0000 逐值一致
- 调参零遗忘：wta_k 2~48 遍历，旧复述率不回退（wta_k=24 时字复述 0.9950 为竞争召回边界现象，非遗忘）
- 续训零遗忘：新增 500 词训练后旧字/词复述不回退，新词复述 1.0000

**关键设计**：续训起点 = `load_version()`（权重 + pats + cursor 全恢复），游标从旧 cursor 继续分配 → 新词自动落在空白神经元，旧模式一条不动。

## 十二、行为模式选择与验证门（v2.2 新增，RL 强化学习）

### 12.1 问题定义：网络不知道"用哪种模式"

Stage 0-1 已实现两种能力：
- **复读**（Hopfield 自联想）：输入完整模式 → 回响自身（"输入 a 输出 a"）
- **联想**（模式补全）：输入前缀 → 补全后续（"输入人之初输出性本善"）

**最大问题（用户 2026-08-09 提出）**：这两种是**解决问题的模式**（未来还有：先复读再联想、举一反三、总结规律/利用规律……）。一个刺激源会**同时激发多个模式的候选**（输入"人之初"：复读候选="人之初"，联想候选="性本善"），但网络**没有机制决定现在用哪个模式**。

### 12.2 认知启发：模式选择信号来自"教学指令"，不在刺激里

- 老师教："**和我一起读**" → 复读；"**人之初下一句是什么**" → 联想
- 刺激本身不携带该用哪个模式的信息，**意图/指令携带**（认知科学"指令跟随" instruction following）
- 指令本身也是词/句，在网络里有自己的神经表征（**指令模式**）——"和我一起读"唤起"复读指令"模式，调制后续行为模式选择

### 12.3 RL 的定位：不是外挂黑盒策略，而是"验证门"（三因子学习规则）

定式网络动力学是确定性的（Hebbian 无监督），RL 不训练动力学，只做一件事：

| RL 要素 | 在定式网络里的落地 |
|---|---|
| 状态 | 网络当前激活（走链到了哪里、唤起了什么候选） |
| 动作 | 检索/传播产生联想结果 |
| 奖励 | 外部/内部验证（"对"/"错"） |
| 策略更新 | **验证通过 → 该次共发放被固化；失败 → 不固化甚至弱化** |

这正是神经科学中的**三因子学习规则**（Hebbian × 奖励因子/多巴胺）：光共发放不学，共发放 + 奖励到来才强化。现有 `learn_gate`（全局布尔开关）升级为**逐次调制门**（已验证的链首尾 +强，未验证 +0，失败 -弱化）。

> **v2.6 增补（2026-08-10 用户决策，项目级硬约束）**：**所有 RL 环节的负反馈必须附 LLM 生成的自然语言原因**——"错"不能只是标量惩罚：负例 = 拒绝 + 处罚原因（自然语言），原因由 LLM 从网络结构化诊断翻译而来（LLM 是"代嘴"不是知识源；输入限死只喂网络真实边、输出越界拦截）。对齐 RLBFF（原则式奖励）/ Explainable RLHF（归因→修正）。本约束适用于后续所有 Stage（数字运算错题、推理错误、QA 回答错误等全部 RL 场景）。

### 12.4 举一反三的最小机制：联想负责"想"，复读负责"记"，验证门负责"该不该记"

以"流动的是水 / 水是液体 → 流动的是液体"为例：

| 步骤 | 机制 | 用的能力 |
|---|---|---|
| 学两条前提 | 复读"流动的是水"（流动↔水）、复读"水是液体"（水↔液体） | 现有跟读 |
| 推理出结论 | 输入"流动" → 传播走链 → 经中间项"水"唤起"液体" | 现有传播（联想） |
| 压缩成直连 | 验证通过 → 把 [流动, 液体] **复读一次** → 首尾共发放固化直连 | 复读一对新词 |

关键洞察：
- 纯两句训练下，"流动"和"液体"**从未共发放，物理上断开**——首尾直连不可能无中生有，必须靠"走链成功后把首尾复读一次"来**主动建立**
- **验证门决定该不该压缩**：未经证实的链（如"流动→水→能淹死人"）走通了也只当临时检索结果，**不固化**——这是防止错误联想/认知偏差永久焊死的闸门
- 一旦直连建立，中间项"水"不再是必经之路（组块化/知识编译，ACT-R 产生式编译对应物）——"把中间步骤去掉"的机制

### 12.4b 目标修正（用户 2026-08-10）：学"传递模式"，不是学"这句话"

**关键区分**：
- ❌ 学会"流动的是液体"= 记住了这条**实例**（换"苹果是红的、红是颜色"就失效）→ 死记硬背
- ✅ 学会"X是Y、Y是Z → X是Z"= 抽出**传递律模板**（抽象、可复用）→ 举一反三

这对应"总结规律/利用规律"的实质：**规律是结构，不是内容**。机制 = **角色槽位表征**：

```
"流动的是水" = [主语位 S + 流动] + [系词位 是] + [宾语位 O + 水]
"水是液体"   = [主语位 S + 水]   + [系词位 是] + [宾语位 O + 液体]
                  ↑ "水"同时出现在 O 位和 S 位 → 桥 → 传递链
```

- 跟读注入**角色绑定**（S↔词、O↔词），不止内容共发放
- 多条"X是Y"反复后，共性沉淀的是**槽位变换结构**（S 位条目可经 O 位衔接下一条 S→O 链）→ 传递律模板
- **利用规律 = 新实例填入槽位走链**（即使新组合从未训练过）——真泛化

| 层 | 学的是什么 | 验证方式 |
|---|---|---|
| 实例层 | 流动→液体 首尾直连（组块化） | 同组词反复可用 |
| **模式层** | S-O 槽位变换 = 传递模板 | **换未训练过的新词组合**仍能推出 |

**验收硬指标**：训练 {流动是水, 水是液体, 苹果是水果, 水果是食物, 雪是白的, 白是颜色…}，测试**从未共现**的新组合（如"鸟是动物、动物是生物 → 鸟是生物"）——模板成立才算学会模式，只回吐训练句不算。

### 12.5 与 RL 的能力边界（诚实标注）

| 目标 | RL 能否做到 | 说明 |
|---|---|---|
| 验证门：奖励调制固化/弱化 | ✅ 现在能做 | 改动最小，learn_gate 升级为调制门 |
| 指令→模式映射（"跟我读"→复读） | ✅ 能做 | 需要先把复读/联想抽象为接口化行为模式模块 |
| 行为模式仲裁（多候选选一） | ✅ 能做 | 需"候选报告接口"（观测通道）+ 明确奖励 |
| 加法举一反三（5+3=8） | ⚠️ 只做验证门部分 | 泛化靠**共享表征**（数字需数量化表征），RL 不产生泛化 |
| 多步/复合模式（先复读再联想） | ⚠️ 暂不做 | 需工作记忆 + 序列控制，RL 要从单步升级到 MDP/层次 RL |

### 12.6 最小验证实验（已实施 ✅ 2026-08-10，脚本 `_rl_gate.py`）

**语料（带角色槽位）**：
- 训练组（多实例，学传递模板）：{流动是水, 水是液体, 苹果是水果, 水果是食物, 雪是白的, 白是颜色}
- 陷阱前提（先建立真实错误链，供验证门拒绝固化）：{水能淹死人}
- 验证门拒绝对象：{流动的能淹死人}（共享中间项"水"的陷阱结论）
- 测试组（**训练中从未共现的新组合**）：{鸟是动物, 动物是生物} → 应推出"鸟是生物"

**流程**：
1. 槽位化跟读：注入 [S+X] + [是] + [O+Y] 角色绑定，多实例反复 → 沉淀 S-O 槽位变换模板
2. 走链：输入"流动" → 传播经"水"唤起"液体"
3. 验证门：老师说"流动的是液体→对"，"流动的能淹死人→错"；对链首尾复读固化，错链不固化
4. 验收（分两层）：
   - **实例层**：验证固化后"流动"能否直接唤起"液体"
   - **模式层**：测试组新组合（鸟/动物/生物从未共现训练）能否推出"鸟是生物"——**只回吐训练句不算学会模式**

**实验结果（全部 PASS ✅）**：

```
[1] 训练组 6 句 + 陷阱前提 1 句 × 3 轮 跟读完成
[2] 实例层走链（输入 流动）: 流动 → 水 → 液体 ✅ 联想链成立
[3] 验证门：流动的是液体→固化 (0.0→1.6)；流动的能淹死人→不固化 (0.0→0.0)
[验收①] 错误链前提「水能淹死人」已建立（直连 4.8）✅
         正确链固化 + 错误结论拒绝固化 → ✅
[5] 模式层泛化: 鸟 → 动物 → 生物 ✅ 结论句「鸟是生物」从未跟读 → 真举一反三
[验收②] 实例层直连 ✅
[验收③] 模式层模板 ✅
═══ 总验收: PASS ✅ ═══
```

**关键结论**：
1. **复读+验证门确实能长出直连**（实例层组块化成立：流动→液体 0.0→1.6）
2. **验证门能挡住错误联想固化**（认知偏差防护：错误链「水→淹死人」存在但错误结论不被加固，这正是不让负面联想焊死成规律的闸门）
3. **模式层真泛化成立**（传递模板套用新词组合：鸟/动物/生物从未训练共现，仍推出"鸟是生物"——学的是"X是Y、Y是Z→X是Z"模式，不是"流动的是液体"这句话）

**过程中发现并修复**：`SparseSchemaNet._edge_row` 空行返回 `(None, None)` 而非 `None`，传播时 `drive[None] += None` 报 dtype 错（此前 `_grow_zh` 碰巧未触发）；`_rl_gate.run_train` 需清 `refractory_left`（跟读独立事件，防上句发放的词在本句被不应期挡下——"流动是水"→"水是液体"中"水"连续出现，不清则水↔液体共发放学不到）。

### 12.6c 规模压力测试与缺口修复（已实施 ✅ 2026-08-10）

**规模压力测试**（脚本 `_rl_gate_scale.py`，数据留档 `runs/`）：S1-S3 词表 100→300→1000 词，推理走通 **100%**、模板零稀释（规模本身撑得住）；噪声下推理也不受影响。但暴露**两个真实机制缺口**：

| 缺口 | 症状 | 根因 |
|------|------|------|
| 终止缺口（S4） | 57/60 条联想沿噪声连接无限蔓延 | 贪心走链无停止判据 |
| 上下文缺口（S5/S6） | 共享 hub 分支选错、被强分支吸走 | 每跳只看当前词出边，不知道"从哪来" |

**修复实验**（脚本 `_rl_gate_fix.py`，报告 [REPORT]-补缺口实验）：三补丁机制——

```
1. 整链跟读：训练时整条链作为一句复读 → 链内非相邻词建立弱直连
   （为路径聚合提供信号；认知对应"整句固化句内连接"）
2. 路径聚合走链：每步候选得分 = 路径上所有已见词出边聚合
   （认知对应"工作记忆"：记住起点调制分支选择）
3. 强度衰减终止：下一步强度 < 上一步 × 0.4 → 停止
   （认知对应"联想收敛/AI 慢下来"）
```

**验收（同一网络，只切换检索方式 → 提升归因于检索机制）**：
- F1 终止：过冲 **57 → 0 条**，推理走通保持 100%
- F2 上下文（等权分支）：A1→B1、A2→B2 旧走链错 1 条 → 新走链全对
- F3 上下文（不对称分支）：弱分支不再被强分支吸走，全对

**结论**：举一反三的联想层已具备"收敛"（终止）与"定向"（上下文）两能力，与验证门（该不该记）构成完整三角。

### 12.7b 大网络机制验证（已实施 ✅ 2026-08-10，脚本 `_rl_gate_big.py`）

机制从构造词表（w0~w59）搬迁到 v2.0 真实网络（n=54000，13502 模式），验证真实竞争下成立。

**关键发现（第一版失败）**：贪心走链在真实网络被**字形分解带偏**——"苹果→果→苹→小…"，因为字模式与词强连接（word_to_char 0.997，跟读 8 轮）远强于槽位化语义连接（3 轮）。语义传递与字形分解共用同一 W 出边竞争，这是构造网络发现不了的矛盾。

**修复：词级走链 `walk_chain_lex`**（候选排除单字模式 + 上下文聚合 + 终止衰减）——语义传递（苹果→水果→食物）发生在词层面，字层面是构成关系，检索时分层。认知对应：人的"苹果→水果"语义联想与"苹果→苹"字形分解是不同通路。

**验收（全部通过）**：
- 词级走链：苹果→水果→食物 ✅、动物→生物 ✅（结论句从未跟读）
- 终止收敛 ✅、验证门（固化 0→1.6 / 拒绝 0→0）✅

**结论**：验证门/走链/终止/上下文全套机制在真实规模成立；接大网络的必要修正是**检索分层**（词级 vs 字级）。
