## 一、为什么"直接灌"不行（教训回顾）

| 方式 | 结果 | 根因 |
|---|---|---|
| v17 散文全量"先见" | 饱和事故 + 漂移 + 黑洞（"了就"桥 228→1024、256 饱和） | 单一词对灌注 >128 次 = 饱和（[饱和归因结论 1](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L91)） |
| 20 万混合语料直训（v1.1） | 全线下降（w_max 饱和实锤） | 数据不专门 + 直接灌进 W 结构 |
| 大模型方式（预训练→微调） | 定式网络**已证伪** | 大模型灌的是参数统计；定式网络的 W = 结构本体，灌即污染 |

**关键认知**：大模型的"学习"= 梯度更新参数（语料统计压缩）；定式网络的"学习"= 结构生长（W 边 = 记忆本体）。**直接灌 = 把语料共现直接写进结构**——共现噪声（"了→就"）一旦入结构就与教学边并列竞争，超阈值即饱和。**人不是这么学的**。

## 二、人是怎么持续学新东西的（对照基准）

人的持续学习（掌握基础语言后，学任何新知识）不是"灌"：

1. **接触（见）**：先"见过"——看到/听到新事物，注意力登记，但**没记住不等于没看见**
2. **好奇（疑）**：见到与已知不符的东西 → 产生疑问（"这是什么""为什么"）——**疑问先于答案**
3. **假设（想）**：先猜（基于已有经验推测）——"猜"是学习的第一步
4. **求证（问/做）**：问人/查书/动手做——**验证假设**
5. **反馈（验）**：现实反馈对错（解渴了=对、更渴了=错）——**实践反馈，不是被灌输**
6. **巩固（固）**：在多个情境变体里反复使用（不是同一句重复）——变体分散强化
7. **遗忘（忘）**：睡眠巩固——重要的进长期记忆，不重要的清除
8. **索引（记）**：只有常用/重要的沉淀为长期记忆；其余停留在"见过"层面

**一句话**：人的学习 = **好奇驱动 + 假设验证 + 变体使用 + 睡眠沉淀**；答案不是被灌进来的，是**被验证出来的**。

## 三、反灌注式学习循环（核心设计：七步闭环）

```
新知识输入 ── 不直接写 W ──→ 【见】接触：外挂上下文 + 工作记忆（只登记，不固化）
                                 ↓
              ┌────────────────────────────────┐
              ↓ 与已有结构比对（走链/候选/强度）      │
          【疑】存疑：预测误差 / 低置信 / 缺边 / 并列  │
              │                                 │
              ├─ 无疑问（已理解）→ 直接进【用】变体使用  │
              ↓                                 │
          【想】假设：模板填充（种子模板：渴→喝 猜"喝"） │
              │                                 │
              ├─ 内部走链通 → 【自举】零 LLM 固化   │
              ↓                                 │
          【问】求证：带假设问 LLM（"是不是X？"）     │
              │   确认（误差≈0）→ 固化             │
              │   纠错（误差驱动）→ 真学习           │
              ↓                                 │
          【用】变体分散强化（同定式 5+ 情境，单一词对 ≤128 次）
              ↓                                 │
          【固】睡眠沉淀：低频清除、高频/成功边保护（双维判据）
              ↓                                 │
          【记】索引沉淀：常用/验证过的 → consolidated；其余留在外挂可检索
              └────────────────────────────────┘
```

**七步逐条（机制全部已验或已有设计）**：

### ① 见：接触不固化（外挂上下文 + 工作记忆）
- 新知识经**外挂上下文（KV cache 式）**读入——[写入 = 事件发生、不固化、检索 240 万次/s 容量无关](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L416)（§4.26-4.27）；或经**工作记忆**（隔离回路，5000 tick 自持）暂存
- 网络"见过"但结构零改动——**灌注事故的第一道闸门**
- 人本对照：人每天"见过"海量信息，只有少数进入长期记忆

### ② 疑：存疑信号触发学习（好奇驱动）
- 网络读到新内容 → 与已有结构比对 → 出现**预测误差 / 低置信 / 缺边 / 竞争并列** → 疑问信号（[§4.7 模式选择：存疑标记](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L176)）
- **学习由疑问触发，不是由数据触发**——无疑问不学（与已理解的内容不重复固化）
- 人本对照：好奇驱动（PRT 动机程序实证：主动发起提问最有效）

### ③ 想：假设生成（先思考，不直接要答案）
- 存疑 → **先猜**：种子模板填充（已知状态→需求边"渴→喝"，猜"猫渴了→喝水"）
- 内部验证：走链通 = 自举（零 LLM）；走链不通 → 进④
- [§4.6 求证循环 v2 实证：假设生成率 5/5、假设正确率 0.80、自举率 1/5](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L167)
- 人本对照：预测先于反馈的学习效果远好于直接给答案

### ④ 问：求证（LLM = 假设验证者，不是答案提供者）
- 带假设问："猫渴了，是不是该喝水？" → LLM 确认（误差≈0）或纠错（误差驱动真学习）
- LLM 调用 = 网络存疑数（live12 主动教学 60 次/轮 → 求证式 <20 次）
- **LLM 不备课不主动教**——网络选题、LLM 只答被问的
- 人本对照：问老师/查书——但前提是自己先想过

### ⑤ 用：变体分散强化（质量控制核心）
- 新学概念立刻在**同定式多变体**中使用（[B 条件零饱和实证：5 变体各 10 次 = 强化总量同 A50 但零饱和](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L84)）
- **硬约束：单一词对灌注 ≤128 次**（w_max=64 ÷ 增量 0.5——[饱和必要条件](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L91)）
- 话题块机制（同话题换问法 3 轮）复用；对话即学习（铁律 6）不变
- 人本对照：背课文不饱和 = 变体分散强化；机械刷题困死 = 单一重复

### ⑥ 固：睡眠沉淀（低频清除 + 成功边保护）
- sleep 受控压缩：低频弱边衰减/删除（min_wake 唤醒频率判据）；**高频教学边受保护**（[实验 C：sleep 对教学饱和无效](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L85)）
- 双维判据：强度（频率）+ 价值（验证）——验证门确认过的成功边即使低频也保护（[理论框架 §3.21](file:///e:/杂项/BNOS_AI_project/schemanet/docs/脉冲负热力学理论框架（修订版）.md)）
- 人本对照：睡眠巩固——白天经历夜间整理，重要保留、不重要清除

### ⑦ 记：索引沉淀（分层记忆）
- 常用/验证过的 → consolidated 注册表（固化句）+ 强边结构
- 其余 → 留在外挂上下文可检索（不占 W）
- **记忆分层：外挂（所有经历）→ 工作记忆（当前）→ 固化（验证+常用）**——与人的感觉记忆/工作记忆/长期记忆对应
- 人本对照：不是所有见过的都记住，只有重要的进入长期记忆

## 四、记忆分层架构（学习的"存"侧）

| 层 | 载体 | 容量 | 写入条件 | 对应认知 |
|---|---|---|---|---|
| 感知层 | 外挂上下文（KV cache 式） | 10M 事件 1.84GB（16M token ≈ 125-1250 倍于 LLM 128K） | 事件发生即写 | 感觉记忆（全量登记） |
| 工作层 | 工作记忆（隔离回路 + gain） | ~12 条目（wta_k/4） | 当前处理/注意 | 工作记忆 |
| 结构层 | W 边 + consolidated | 有界（阈值清除） | **验证通过 + 变体使用** | 长期记忆（成功边） |

**核心原则**：**90% 的知识可以留在感知层（外挂），只有 10% 的"验证过 + 常用"进入结构层**——结构不被信息洪流污染（驻留密度有界，[越用越强稳态](file:///e:/杂项/BNOS_AI_project/schemanet/docs/脉冲负热力学理论框架（修订版）.md)）。

## 七、验收体系

1. **反灌注验证**：新知识经循环进入结构后，**散文/大语料接触零新增饱和边**（单一词对 ≤128 次断言）
2. **联想保持**：学习新知识后，旧词的联想候选不退化（防固化句垄断，[联想缺失缺口](file:///e:/杂项/BNOS_AI_project/schemanet/docs/reports/05-机制与理论验证/[REPORT]-定式网络认知架构演进报告-灌注归因、验证门控、流式交互与记忆系统.md#L94)）
3. **理解正确率**：新知识泛化变体应答 ≥0.9（不是背原句）
4. **成功边保留**：验证过的低频边不被 sleep 误删（双维判据生效）
5. **零遗忘回归**：学习前旧评估集不回退（铁律 2）
6. **越用越强**：长期运行后结构保持"分化 + 集中"有序态（稳态长跑验证，理论框架 §十一 问题 11）

## 八、诚实边界与开放问题

- **假设质量依赖种子模板**：假设生成 = 模板填充，模板外的推理走不通（自举率 1/5 实证）——需要更多种子语义边（状态→需求）作为"常识底座"
- **LLM 判定噪声**：同假设 LLM 对猫判对、对狗判错——需投票机制（§4.6 发现）
- **"验证过才固化"的前提是"能验证"**：无现实反馈的知识（历史、文学）只能靠 LLM 教师 = 现实反馈代理——教师质量 = 验证质量
- **外挂内容参与生成（RAG 式）**：目前外挂 = 注入工作记忆，检索内容影响回答选择是下一步（理论框架 §十一 问题 9）
- **联想竞争与固化句并存**：固化句直出绕过联想竞争——如何在命中固化句时保持联想活性（§十一 问题 8）

## 九、实施计划（确认后启动）

1. **阶段一（循环定式）**：`_learn_life.py`——外挂读写 + 存疑信号 + 假设生成 + LLM 求证 + 验证门固化的最小闭环（复用 _exp_ask2/_live_stream 组件）
2. **阶段二（变体课程）**：新知识自动生成同定式变体集（5+ 情境）→ 变体分散教学（复用话题块）
3. **阶段三（分层沉淀）**：sleep 双维判据接入 + consolidated 索引沉淀 + 外挂保底
4. **阶段四（长跑验证）**：无限输入流 + 循环 → 稳态四指标（边数有界/强边稳定/行为不退化/当下重要性维持）
