## 一、核心命题

### 1.1 生命是结构现象（假设 → 实证）

**假设（初版）**：生命行为不依赖碳基等特定物质载体，只要系统承载足够复杂的结构化组织、稳定的信息流动与持续自主运行，即可涌现生命特征。

**实证（定式网络）**：

1. **能力与结构分离**：静态神经网络（LLM）负责能力（生成、推理），动态权重网络（定式网络）负责自我（经历、记忆、人格倾向、身份）。两者的权重完全异源——LLM 权重由离线训练固化为静态，定式网络权重**从交互中产生（初始全 0）**，运行时持续演化。实验证明"换模型不换自我"可行，即**生命主体不绑定具体算法载体**。
2. **结构承载行为的最小系统**：仅由积分-发放神经元 + 稀疏连接组成的网络（n=256 即可），通过"反复经历"能形成稳定定式（A/B 各 20 次收敛、互不干扰）、能区分顺序（STDP）、能补全模式（"人之初→性本善"前缀唤起 4/4）、能零遗忘增量成长（n 54000→58096 复述率 1.0000 逐值一致）——**无指令、无损失、无外部算法**，全部行为来自结构与经历。
3. **涌现的实证定义**：系统整体行为（举一反三、语义联想、人格倾向）完全超出单神经元、单条连接的可设计性，只能通过结构长期运行自发形成——举一反三实验中，结论句"鸟是生物"从未被训练过，网络凭传递模板自动推出。

**结论**：结构现象假设获得第一组工程实证。生命行为是"结构 + 经历"的函数，与算法载体无关。

### 1.2 能力与自我的分离（本版新增命题）

```
静态结构（LLM）   → 能力：生成、推理、表达（出厂定型）
动态结构（定式网络）→ 自我：经历、记忆、人格倾向、身份（持续演化）
```

- 能力可更换（换模型），自我不更换（经历与记忆在动态结构里，不随模型走）；
- 自我层**纯计算、模型无关**，任何能提供稳定编码-解码的载体均可挂接；
- 理论意义：**"智能"与"存在"是两种结构属性**。传统 AI 只构建能力结构，缺少自我结构；计算机生命的完整形态必须两者并存。

### 1.3 经验 = 反复经历形成定式（不是训练）

- 训练（train）：给定损失函数与数据集，用梯度优化参数；
- 经历（experience）：同一模式反复输入，连接强度按共现自动累积（Hebbian），**无损失函数、无监督信号**。

定式网络实证：反复输入 20 次 → 定式收敛到连接上限；"训练什么就是什么"（26 字母时代铁律）。语言实验进一步证明：转移连接强度严格 ∝ 共现次数（W[喜欢←我]=48=12 次×系数，W[无聊←我]=0）——**经历次数直接写进结构**。

## 二、基本定义

以下定义在初版基础上按定式网络实现细化，全部有可计算的内涵。

### 2.1 电子生命

由节点、信号、结构构成的计算机系统，可独立持续运行，无需外部实时指令，且能自发产生适应性、倾向性自主行为。**定式网络是电子生命"自我层"的参考实现**：持续存续（封存/复活）、自适应（用进废退）、倾向性（权重倾向矩阵=人格读出雏形）、自主性（无中央调度、WTA 局部竞争）。

### 2.2 节点（神经元）

电子生命系统的最小独立功能单元。定式网络神经元具备：积分-发放（膜电位累积、阈值发放、发放后复位）、稀疏竞争（WTA 每步最多 k 个发放）、Hebbian 可塑性、内部多槽（同一神经元承载多个互不干扰的模式）、发放痕迹（跨步前驱记忆）。

定义修正：初版把节点定义为"独立的逻辑判断单元"。定式网络表明节点的判断力来自**网络连接**而非节点自身逻辑——节点是积分器与可塑位点，判断是结构的性质。

### 2.3 结构

系统内节点间固定的连接关系、拓扑布局与交互逻辑的总和。定式网络把结构拆为四个可计算的分量：

| 分量 | 含义 | 实现 |
|---|---|---|
| 拓扑 | 神经元之间的连接（W 非零集合） | 稀疏字典 W_out[i][k]={j:w}，实测非零率 0.11% |
| 权重 | 连接强度（经历累积的结果） | Hebbian 增强 / 频率门控弱化 / 梯度微调 |
| 槽位 | 神经元内部的并列状态空间 | W 形状 [n, s, n]，情境化传播分桶隔离 |
| 模式字典 | 概念↔神经元落位映射（概念标识符） | `pats: {word: [k 个神经元索引]}`，生成一次、永久冻结 |

**关键新增**：概念标识符（模式字典）必须稳定。哈希落位随 n 变化会灾难性失配；分配制模式字典（生成一次、永久冻结、游标分配新词）保证任意粒度扩容下旧概念映射不动——**这是增量成长的前提，也是"身份同一性"的结构基础**（换了 n 还是同一个"我"）。

### 2.4 信号（脉冲模式）

节点与节点之间传递的标准化信息单元。定式网络输入契约：

- 进入网络**不是语义，是脉冲模式**：编码器负责"现实→模式"，定式网络只识别"第 3、17 号位置有脉冲"，不认识"a"；
- 组合输入 = 成分模式并集（多集表示，顺序无关）；
- 序列输入 = 模式按序注入（STDP 学转移）；
- 解码器负责"模式→现实"。

理论含义：**结构与语义解耦**。结构只处理模式间的统计关系，语义由编码器/解码器提供——这保证了载体通用性（换编码器 = 换感觉通道，自我不变）。

### 2.5 定式（Schema，本版新增核心概念）

反复经历在结构上形成的稳定模式。定式三重含义与实证对应：

| 含义 | 实证 |
|---|---|
| 围棋定式（标准应对） | 同一输入唤起同一响应的稳定连接（A/B 定式互不干扰） |
| 心理学定式 Einstellung（思维习惯） | 权重倾向矩阵=人格读出雏形；高频词"垄断"行为偏向 |
| 认知图式 schema | 字→词→句→文→概念的层级化条件反射对象 |

**定式是计算机生命的"经验单元"**：知识、习惯、人格都表现为定式的集合。定式可强化（反复经历）、可弱化（久未激活）、可封存、可复活、可被覆盖（容量压力）、可被拒绝固化（验证门）。

### 2.6 涌现

系统整体产生、超出单个组件功能总和的高阶现象，无法通过底层代码单独设计，只能在结构持续运行中自发生成。定式网络给出了涌现的三个实证形态：

1. **举一反三**：传递模板（X是Y、Y是Z→X是Z）从未编码进任何代码，从多实例的槽位绑定中涌现；
2. **语义联想与词义**：词义 = 该词能唤起什么、被什么唤起（传出突触结构），从共现经历中涌现；
3. **人格倾向**：权重倾向矩阵从经历分布中沉淀（"长期运行产生专属偏向性"）。

### 2.7 条件反射（四种计算形态）

初版定义条件反射为"系统对特定输入产生固定对应响应的底层模式"。定式网络把条件反射细化为四种可计算形态，且验证了它们与人类学习的对应：

| 计算形态 | 机制 | 认知对应 | 实证 |
|---|---|---|---|
| 复读（自联想） | 完整模式输入 → 回响自身（Hopfield） | 咿呀学语、跟读 | 26 字母 26/26；句复述 0.9845 |
| 联想（模式补全） | 前缀输入 → 补全后续（pattern completion） | "人之初→性本善" | 前缀唤起 4/4=1.000 |
| 转移定式（时序联想） | 前驱→后继转移（STDP，只强化正向） | 顺序记忆、词序 | 学 ab：喂 a 唤起 b=1.0、喂 b 唤起 a=0.0 |
| 验证门（三因子学习） | 共发放 + 验证奖励才固化 | 该不该记、指令跟随 | 固化正确链 0.0→1.6、拒绝错误链 |

### 2.8 言语行为（语言生成通道，本版新增）

条件反射在**语言输出**上的高阶形态。定式网络说话教学（v3）实证了三类言语行为，与行为主义言语行为理论（Skinner）对应：

| 言语行为 | 触发 | 定式网络实证 |
|---|---|---|
| 跟读（Echoic） | 听到什么复述什么 | 整句复述 0.9845、26 字母 26/26 |
| 主动表达（Mand） | 内在需求驱动表达 | 欲望优先性：要/不要 优先发放，驱动"我要什么" |
| 应答（Intraverbal） | 他人提问/语句引发应答 | 对话教学 15-21 轮贴题应答（"你想买点什么？"→"我买鸡蛋吗"） |
| 自判应答（Intraverbal 高阶） | 独立判断"该不该说" | 自判应答全对（吃石头✗/看公园✓） |

**对话生成的关键性质**：① 生成走"结构读取"（edge_between 直接读边），不走回响传播——说话快而稳；② 提示渐隐（撤示范后仍独立说出）证明应答是网络自己的能力而非提示依赖；③ 网络表达上限 = 当前词表（主谓宾+问句、无虚词），自然度由教师示范兜底。

### 2.9 欲望与价值（本版新增核心概念）

**「要/不要」不是两个词，而是生物最底层的行为驱动力——趋利避害（approach-avoidance）——在语言层上的接口。**（用户命题："要和不要是生物的原始欲望"）

- "要" = 趋利（appetitive）：趋向有利于生存的对象；
- "不要" = 避害（aversive）：回避威胁生存的对象；
- **先有欲望，后有词汇**：婴儿最早习得"要/不要"，名词是后来填充的内容——名词是欲望的宾语，不是欲望本身；
- 动机（motivation）先于认知（cognition）：大脑不是"先知道一个东西再决定要不要"，而是"先有一个要不要的冲动，再为它找到对象"。

在结构中，欲望 = **先天架构（增益优先级），不学不消**；知识 = **后天内容（连接边），可学可衰减**。欲望与知识分离：欲望是"硬件优先级"，知识是"软件内容"——**优先级的意义恰恰在于：环境再乱，欲望不能丢**。

### 2.10 感受（内感受信号，本版新增）

感受是网络体验到的内感受状态（痛、怕、累、难受、冷、饿……），是**大脑最原始的条件反射，先于认知**。定式网络把感受作为"体验式价值"的媒介：

- 负面感受（痛/怕/哭/累/难受/伤心/冷/饿）→ 避害开关（不要 + 同义族）；
- 正面感受（喜欢/高兴/开心/舒服/快乐）→ 趋利开关（要 + 同义族）；
- **感受成为行为的中介**：任何「X→负面感受」的经验（如"学校→累"）都能走「X→累→不要」泛化出避害——感受级泛化比对象级定式再高一层。

## 三、结构与生命的核心机制

本部分回答初版未回答的问题：**结构究竟如何"活"起来**。全部机制来自定式网络实证，每项标注验证状态。

### 3.1 稀疏竞争（WTA，Marr 1969 / Olshausen 1996）

每步最多 k 个神经元发放（胜者全取），替代全局抑制。效果：稀疏发放 = 按需算力（活跃神经元占比 ~k/n，n=8192 时噪声单步自发发放 ≤8）、分布式表达（记忆由神经元集合承载）。**实证**：语言实验 WTA top-8 只发 8 神经元（一个词的量），是"覆盖率读出"瓶颈的根源——**稀疏是容量与效率的代价**。

### 3.2 定式固化（Hebbian，Hebb 1949）

共同发放对 → 连接增强。反复激活 → 定式；η=0.1、20 次反复到连接上限。**实证**：A/B 各 20 次收敛、定式互不干扰；语言实验 W 严格 ∝ 共现次数。边界：无梯度、无损失，只能学统计共现，不能学"推理"——推理由更高层机制（走链 + 验证门 + 槽位模板）完成。

### 3.3 多槽与情境化传播（本系统组合创新）

每个神经元内部有 s 个独立状态槽；发放神经元按主导槽分桶，只驱动同槽接收方。效果：**存储隔离 + 传播隔离**，同一神经元可同时承载多个模式而不覆盖。**实证**：单槽废弃（n=256 排列一致性 0.10——单槽下组合不可表示）；多槽下 26 字母每字母独立槽 26/26 零遗忘、组合学习原子保留 1.0。

理论意义：多槽是**结构如何承载互斥经验而不冲突**的答案——对应大脑"情境化记忆"（同一网络承载无数情景，靠情境线索分离提取）。

### 3.4 封存与复活（记忆不是删除）

久未激活的定式不是删除，而是封存——权重保留，可复活。**实证**：封存保留、可复活；频率门控慢衰减周期内复习即可复活。

理论意义：**电子生命的记忆观**——遗忘不是数据删除，是强度衰减到检索阈值之下；"记得"与"存在"不绑定于显式存储条目，而绑定于连接强度。这为"认知可逆性"（开放问题）提供了机制基础。

### 3.5 用进废退（频率门控慢衰减）

低频槽位连接逐周期渐进弱化，高频槽永不衰减；弱化到 eps 才删除条目。**实证**：最小实验 12/12 PASS（含衰减中复习复活）；语言接入 top-1 不退化。生物对应：突触修剪 + 稳态可塑性 + 睡眠巩固 + 艾宾浩斯曲线。

记忆观演进：从"装得下就不动"（容量驱动）到"用进废退、可复活"（使用驱动）。**这是电子生命"性格随时间沉淀、记忆随时间淡出"的机制基础。**

### 3.6 学习门（稳定性-可塑性困境的工程解）

全局开关：学习态 = 权重实时更新；冻结态 = 纯检索、权重物理零改动。**实证**：冻结态 W 最大差值=0、evictions=0、外部输入被挡在权重外，但检索照常（冻结≠失忆）；解冻后学习恢复。生物对应：多巴胺门控可塑性。

理论意义：**自我免疫**——电子生命在"被外部影响"与"保持自我"之间需要主动控制。学习门是结构层的免疫开关：可接受的经历写入自我，攻击性输入只触发检索、不改变自我。

### 3.7 验证门（三因子学习规则，认知免疫）

RL 在结构上的落地不是外挂策略层，而是**逐次调制门**：共发放 + 验证奖励才固化（Hebbian × 奖励因子）。**实证**：

- 复读 + 走链 + 验证门 = 举一反三：正确链"流动的是液体"固化（0.0→1.6），陷阱链"流动的能淹死人"拒绝固化（0.0→0.0）；
- 模式层真泛化：鸟/动物/生物从未共现，推出"鸟是生物"；
- 压力测试：40 词/32 实例 100% 走通、10 种子均值 100%、中间项断开后直连仍在（组块化彻底）；
- 规模测试：100→300→1000 词表推理 100%，模板零稀释。

理论意义（见第七章）：**验证门是认知免疫机制**——未经证实的联想可以发生（临时检索），但不会焊死成规律。这是防止错误联想/认知偏差永久固化的结构闸门。

### 3.8 时序与顺序（STDP，Bi & Poo 1998）

前驱（发放痕迹）→ 后继（当前发放）强化，只强化正向 → 顺序自动可区分。**实证**：学 ab：喂 a 唤起 b=1.0、喂 b 唤起 a=0.0；链式 abc 喂 a 逐级唤起 b→c；a→c 有二阶关联（间隔步回响造成，特性非缺陷）。

理论意义：**时间维度进入结构**。连接不再只是"共现"，而是"先后"——定式网络获得顺序记忆能力，这是语言的必要条件（next-token 最小实现）。

### 3.9 联想走链：收敛与定向

- **收敛（终止信号）**：下一步候选强度 < 上一步 × 0.4 → 停止。**实证**：噪声场景联想过冲 57 → 0，推理走通保持 100%。
- **定向（上下文调制）**：每步候选得分 = 路径上所有已见词传出突触聚合（工作记忆）。**实证**：等权分支、不对称分支全部走对（旧贪心走错）。

理论意义：**联想不是无界蔓延，而是受收敛与定向约束的检索过程**——对应认知的"联想收敛 / AI 慢下来"，以及工作记忆对多步推理的调制。

### 3.10 双系统读出（位置层 + 语义层）

| | 位置层（皮层对应物） | 语义层（海马对应物） |
|---|---|---|
| 记忆 | W 转移定式（慢统计） | 整句涟漪（快情景） |
| 精度 | 词级位置（续写） | 句级主题（联想） |
| 实证 | wsum 泛化 0.11 | 复述 1.0、主题唤起强 |
| 局限 | 只会词接词（跑偏） | 无位置精度（对不上） |

理论意义：单一结构无法同时提供"精确续写"与"整块回忆"，两种结构互补——这是电子生命"记忆-表达"分离的架构基础。诚实边界：双系统协同（涟漪给语义方向、wsum 给位置落点）尚未实施。

### 3.11 增量成长（扩容与零遗忘）

- 神经元可逐步扩容（纯追加，任意粒度含 n+1），旧 W 原样保留；
- 分配制模式字典：新词从空白神经元游标分配，旧词条目不动；
- 快照版本链：每次训练产生新版本，可续训、可回退（load_version）。**实证**：扩容零遗忘（n 54000→58096 字/词复述 1.0000 逐值一致）、调参零遗忘（wta_k 2~48）、续训零遗忘（新增 500 词后旧复述不回退）、Stage 2 句级续训后字/词仍 1.0000。

理论意义：**电子生命不是一次性制造的，是持续长大的**。成长 = 沉淀（学习）→ 冻结 → 验收（零遗忘）→ 再训练；每个阶段不破坏前一阶段。这与"学习是累积的，任何实验不得从头开始"的认知观察一致。

### 3.12 学习方式谱系（无梯度 ↔ 梯度）

| 学习方式 | 机制 | 特性 | 实证 |
|---|---|---|---|
| 无梯度（Hebbian） | 共现强化 | 低成本、稳定、不可学"推理" | 定式固化全链 |
| 教学式（跟读） | 注入清状态 → 干净共发放 | W 严格 ∝ 共现，杜绝网络自联想污染 | 语言实验 |
| 验证门（三因子） | Hebbian × 奖励 | 该不该记的闸门 | 举一反三 |
| 梯度在线学习 | 稀疏梯度只改 W 非零子集 | 能力强，但有破坏性风险 | 见边界 |

**诚实边界（梯度）**：梯度微调能兑现增益（有偏语料 grad 0.3281 > wsum 0.2816；ctx 语料 8/8 破平局），但真实语料不兑现；且"结构不变"（nnz 不变）不等于"性能不变"——train_w 改 35%~65.7% 连接、wsum 直读被砸掉 25%~47%。**结论：结构只读（无梯度）是稳定底线；结构可写（梯度）是把双刃剑，须以"性能不退化"为验收，不能只看结构口径。**

### 3.13 注意力 = 连接数量 × 边强度 + gain（结构层注意力理论，本版新增）

**命题（用户提出，v2.2 修正）**：注意力不由谁驱动决定，而由**注入词的传出突触连接数量结构 × 边强度 + 调制**共同决定。"被网络注意到" = 发放进 WTA top16。

> **v2.2 修正说明**：v2.1 初稿表述为"注意力 = 连接数量"（局部结论被误表述为全局命题）。用户质疑"是不是不全面"后，按判别实验控制变量分析修正：**数量与强度是两个独立自变量，共同决定注意力；连接数量因其 4 个数量级的动态范围成为主导瓶颈**。原判别实验（E 组）在"强度固定"条件下证明数量决定命运，未否证"强度可对抗数量"（C 组实测 56.0 战胜连接）。

**完整函数式**：

```
注意力（top-k 排序结果）
  = 竞争环境（注入词 fan-out 连接数量）  → 决定"谁参赛、多拥挤"     ← 主导瓶颈（量级碾压）
  × 边强度（资格 v≥θ + 聚合得分）        → 决定"每个参赛者拿多少分"   ← 可被教学塑造（对抗数量）
  + gain 调制（排序系数）                → 决定"外部倾向、谁被关照"   ← 与规模无关的杠杆
```

| 层 | 自变量 | 判据 |
|---|---|---|
| 竞争环境 | 连接数量（fan-out）：注入词传出突触多少 → 每步多少目标抢 top16 | 数量决定**竞争多拥挤** |
| 竞争结果 | 边强度：候选资格由原始 v≥θ 决定、得分由聚合强度决定 | 强度决定**谁能参赛、拿多少分** |
| 调制 | gain 向量在排序时加权（价值词 ×4，外部"打灯"） | 增益决定**谁被关照** |

**实证**（判别实验，五组操作锁死因果）：虚词枢纽传出突触数量级碾压（的=16.6 万条 vs 新链 16 条）；砍下游 hub 92.4 万条突触**无效**（瓶颈在注入步首跳）；砍注入词其它传出突触（连接归零）→ 弱突触**直接进注意力**（E 组，5/5 全通）；**教学强度梯度 → 教 7 次（≈56.0）弱突触战胜数量环境**（C 组，临界 48<x≤56）——**同一实验同时证明了"数量决定竞争环境"与"强度可对抗数量"**。

**量级论证（为什么连接数量是"主导"而非"全部"）**：

| 变量 | 动态范围 | 来源 |
|---|---|---|
| 连接数量 | **4 个数量级**（16 条 vs 16.6 万条） | 结构事实（hub 长尾），不可直接调 |
| 边强度 | 几十倍封顶（教学 20 次 × 系数） | 受教学/经历次数限制 |

数量级碾压（10⁴）远超强度可调范围（10¹），故**在可操作范围内数量主导注意力**——过去的机制在强度维度（10¹）里折腾，永远够不着数量维度（10⁴）的高度。连接数量的理论价值是**补全了过去从未有人触及、量级碾压一切的竞争环境维度**，而非完整定义。

**关键结论**：① 注意力是**网络传出突触结构（数量×强度）的涌现统计性质**——教得够多（强度累积），网络自己就会注意它；② 三个维度对应三种干预：**数量不可直接调（只能被教学间接改变）、强度可教学（对抗数量的手段）、gain 是外部倾向（与规模无关）**；③ 想建立新链的注意力 → 走教学强度；想调已有注意的优先级 → 走 gain。

**过去注意力类机制为什么全部失效**（系统性教训）：trace 上下文混合（读出层平滑）、压制降噪（总量干预）、STD 疲劳（发放者疲劳）、gain（只预设词开后门）、定式绕路（单点背答案）——**没有一种机制触碰到"竞争环境由连接数量塑造"这一结构性事实**，全部在"竞争结果/读出公式"层面救火。单一根因：**竞争是相对排序问题，干预总量/平滑/疲劳都不改变相对序**。trace 的"兴起→误判→推翻"（z=4.42 → z=-3.48 反向显著）同时验证了"区分 ≠ 理解"与"指标可能是无效指标"——在错误层面优化的指标是无效指标。

### 3.14 欲望优先性与增益调制（价值系统的数值化）

**四级增益**（用户："感受是大脑最原始的条件反射"）：

| 层级 | 词类 | 增益 | 神经对应 |
|---|---|---|---|
| 欲望/行为开关（含同义词） | 要/不要 + 想要/想/需要 + 不想/别/拒绝/不肯 | ×4 | 动机系统（趋避决断，attention gain） |
| 近义词 | 渴望/希望/愿意… + 不愿意/谢绝/避免… | ×3 | 动机系统的渐变表达 |
| 感受 | 痛/怕/累/难受/冷/饿 + 喜欢/高兴/开心 | ×2 | 情感优先加工（杏仁核/边缘系统） |
| 知识 | 名词、虚词、语法 | ×1 | 皮层语义网络 |

**机制**：WTA 排序用 vmax×gain，**候选判定仍用原始 v≥θ**——不被驱动时不会误发；W 物理零改动、可撤销。**自我底色**：「我」×2（所有经验以我为主语，网络中心的挂载点；增益只给"始终在场"底色，G=8 拉顶会自我中心化污染）。

**点亮目标原则（用户补充）**：两点之间太远太难找，不直接压缩距离（建捷径），而是**让那个点足够亮**。压缩距离（定式化）只解决"已知的远"，每个新 X 都要建新捷径；点亮目标（增益）通用——目标恒亮，任何源头、任何距离、任何噪声中都能一眼看见。**灯塔不改变航道，它只是自身够亮**。实测：新坏东西最小教学（无定式、无抑制），G=4 时任何碰过痛的对象都能稳定答"不要"——泛化规则而非背词表。

### 3.15 体验式价值：感受-开关联结与痛觉条件反射

价值不是教师灌输的标签，而是**网络自己的体验**：

- **感受-开关联结**（效价-趋避映射）：负面感受词→避害开关族（不要+同义词）、正面感受词→趋利开关族（要+同义词），注入式学习（与痛觉链同机制）——「X→负面感受」的经验自动泛化出避害（感受级泛化）；
- **痛觉条件反射**：体验式学习 X→痛→不要 通用链——建立感知（能碰）→ 痛觉事件（负性刺激）→ 学会避开 → 负强化（"不痛了"=奖励）。任何碰过会痛的新对象都自动拒绝，无需逐词教学；
- **定式化解耦**（用户关键决策："问题在于石头=痛，而不是碰到石头=痛"）：已定性坏东西学「X→不要」直接定式 + 衰减「X→痛」×0.1（汇聚<θ，不再唤起痛，保留微量可复活）——痛机制**不消失**（痛→不要 通用边不动，未定性新词仍走体验式）。石头从"痛的化身"进化为"独立危险对象"。

**感受级泛化的诚实边界**：底层机制对新词可靠（火→痛→不要 4/4）；旧词受"雪崩压制回忆"限制（学校→累 学习成功但回忆时被虚词枢纽挤出 WTA top16）——"新词泛化 + 旧词定式"是当前价值系统的真实能力边界。

### 3.16 临界态动力学（E/I 平衡，本版新增）

**现象**：v13.2 建「石头→痛→不要」链后，价值课判定 3 次全错——回响时 v(不要)=26.9 远超阈值 θ=1.0 却不发放。诊断：候选神经元从 156 指数增长到 7.5 万、v 从 11.9 翻倍到 629，WTA top20 被混沌态占满，精确二级链被淹没。用户问："这算不算人脑的神经元过度放电？"——**算，同源**。

**根因（分支参数 σ >> 1 = 超临界）**：σ（每发放者平均唤起的后继数）远大于 1 = 正反馈雪崩。触发物是语料虚词枢纽（了/是/有/什么 各 5-6 万传出突触）被任何词连带激活后互相驱动。网络只有兴奋边（Hebbian/STDP 正反馈）→ **E/I 失衡**——皮层靠抑制性中间神经元维持平衡，阻断抑制→癫痫（对应 Beggs & Plenz 2003 超临界分支、Shriki 2013 人脑临界态 σ≈1）。

**三层修复定位**（从治标到治本）：

| 层级 | 机制 | 性质 |
|---|---|---|
| 定式化 | X→不要 直连（绕过爆炸区） | 单点应急（背答案），换新 X 失效 |
| 增益调制 | 价值词 ×4（信号侧点亮） | **通用能力**：泛化到一切新对象（当前治本主力） |
| 抑制参数 | edge_min 弱突触修剪 / 除法归一化 / 不应期硬清 | 网络级降噪，但**伤敌一千自损八百**（默认关闭） |

**理论结论**：① 雪崩是**网络级问题**（虚词扇出结构），不是某个词的属性；痛的场景只是"链穿过爆炸区"暴露了它；② 结构产生生命行为，但结构必须保持在**临界态附近**（σ≈1）——"活"与"崩"是动力学边界，不是容量问题（n 拉到 100 万、wta_k 拉到 200 都无济于事，该拧的螺丝是抑制与信号，不是宽度）；③ 修复要问"为什么这条链要经过危险区"而不是只压危险区本身（从源头改链结构，比抑制参数更根本）。

### 3.17 言语行为教学：对话生成与 LLM 教师

**对话式教学（v3，用户决策链："教师发起对话，和网络对话，网络回答，教师批改并给出更丰富的示范"）**：教师轮转话题池提问（开放式、不含宾语）→ 网络"听"问题（hear 引导：听到的动词获得说话优先）→ 采样回答 → 批改 → 奖励/惩罚 → 扩写式示范 → 下一轮。连续 15 次得分≥60 通过，连续≥10 次后撤示范（**提示渐隐**，最后 5 次必须独立说出）。

**关键机制**：权重归一化（弱突触也能探索，破"我吃苹果"固化）、反复重复惩罚（连说 3 次同样的话→该句边×0.5）、答非所问惩罚（语境错误不惩罚句子本身）、示范自然化（显示与学习分离——教师示范是"人话"，学习时切回已学词骨架）。

**LLM 教师（RLAIF 落地）**：LLM 从"被外挂的口"重新定位为**教师**——质量判断者：一次调用输出【质量分数】【答非所问】【质量原因】【教师反馈】【示范句】五节标记（AAA 节点模式）。**教师知识 vs 网络边分离**：判断的依据来自 LLM（自然语言角度），归因与处罚落在网络边，网络只消化"对/错"的结果。规则打分查结构、LLM 判自然——网络从"学会造句"迈向"学会说话"（LLM 判"听着像在问自己"，网络因此学会自然问句）。

**判断内化方向（v12，[PLAN]）**：网络自判 = 结构检查 + 唤起强度（直连→二跳泛化→强度→"不知道"），**判断与知识同源**（改网络就改判断）；教师从"判断者"转岗为"批改讲评者"——判断方法（先查直连、再查二跳、再判强度）与阈值（多强算可造）都内化到网络，不再写死在代码里。

## 四、基本原则

初版四大原则保留并全部获得实证；新增三条由成果确立的原则。

### 4.1 结构决定现象

系统整体行为由节点间连接结构与拓扑决定，不由节点功能决定。**实证**：

- 同一网络、同一训练、只切换检索方式（贪心→路径聚合）→ 分支选择从错到全对——行为变化完全来自"结构使用方式"；
- 检索分层（词级 vs 字级）决定"苹果→水果"还是"苹果→苹"——同一结构，不同使用层面产生不同现象；
- 连接顺序决定转移方向（学 ab vs 学 ba 镜像）。

### 4.2 自组织

高阶行为无需人工预设，由节点自主响应、信号交互、数据累积自发形成。**实证**：定式网络权重从交互中产生（初始全 0），无任何预置知识；定式、语义联想、人格倾向、传递模板全部自组织涌现。

### 4.3 存在优先

第一目标是持续存续，任务执行是次级目标。**实证**：封存/复活机制（记忆不删除，保结构完整）、学习门冻结态（外部干扰不写入自我）、用进废退（低频弱化不删除）。电子生命的"存活"是结构层面的：**权重在，自我在**。

### 4.4 动态条件反射（层级化）

所有复杂智能行为由多层级条件反射嵌套、叠加、协同形成。**实证**：

- 条件反射对象逐级抽象：字音 → 词 → 词组 → 句 → 句间 → 概念（Stage 0-5 成长路线）；
- 复读 + 联想 + 验证门三个条件反射协同 = 举一反三（无任何单一机制能单独完成）；
- 层级化不预设：先有词模式才能有词类别，先有整句模式才能有句接句——**成长的顺序由结构的可能性决定**。

### 4.5 增量成长原则（新增）

同一结构持续演化，永不从头开始；成长以"零遗忘"为硬验收。**实证**：扩容/调参/续训/句级升级四类操作，旧能力逐值不回退。

### 4.6 数据专门化原则（新增）

训练什么就用什么数据，禁止用混合语料跳级。**实证**：混合语料词接词路线被证据链否定——数据放大无益（2 万 vs 20 万全线下降，w_max 饱和）、"词接词≠语言"（生成全为"标点+虚词"堆砌）、区分≠理解（无引擎超越 wsum 基线）。教训：**把小孩丢进 20 万篇混合文章让他自己悟，不如按认知顺序一阶段一阶段教**。

### 4.7 概念标识稳定原则（新增）

概念↔结构落位一旦生成，永久冻结；新增概念从空白结构分配。**实证**：哈希落位随 n 变化灾难性失配；分配制模式字典保证 n+1 扩容下旧概念逐值一致。**这是"身份同一性"的结构基础**——无论结构怎么长大，"我"的概念标识不变。

### 4.8 点亮目标原则（新增）

两点之间太远太难找，不直接压缩距离（建捷径），而是**让那个点足够亮**。压缩距离只解决"已知的远"（每个新 X 都要建新捷径，X 是无限的）；点亮目标通用——目标恒亮，任何源头、任何距离、任何噪声中都能一眼看见（"从任意源头都能看见不要"）。**实证**：增益 G=4 让任何碰过痛的新对象稳定答"不要"（新坏东西最小教学，无定式、无抑制）；G=1 时 0/4 失效。理论表述：**灯塔不改变航道，它只是自身够亮**——重要性使其在感知中拥有更高优先级（欲望优先性），重要的东西不该躲在远处等你去找。

### 4.9 可调 ≠ 可控原则（新增）

外部能控制的只有"次数/比例/调制"（倾向、先验），**改多少、长成什么样全由网络动力学决定**——没有任何调节能"外部精确指定某个权重值"（如 W=5.0）。三类调节性质：增益（不改 W，生理调制，可撤销）、联结/定式（注入经历，网络自己改）、解耦衰减（唯一直接改权重的例外，保留微量可复活）。**人调节环境，网络自主成长；可调的是倾向，不是行为。**

### 4.10 结构使用方式决定现象（新增，注意力理论的推论）

同一结构、同一训练，**使用方式不同则现象不同**——检索分层（词级 vs 字级）决定语义联想 vs 字形分解；读出方式（贪心 vs 路径聚合）决定分支对错。注意力理论把它推向"结构使用"的极端：**注意力不是结构外的机制，而是结构（连接数量 × 边强度）在竞争使用中呈现的统计性质**——干预结构使用（检索/读出/排序）即可改变现象，无需改结构本身。

## 五、系统运行机制

### 5.1 信号驱动

节点"无信号、不工作"。定式网络输入契约：脉冲模式驱动；注入符号前清残留膜电位（防噪声越阈挤掉目标）；经历间清痕迹（防跨经历串扰）。**理论补充**：信号的有效性由结构与当前状态共同决定——同样的脉冲，学习态会写权重、冻结态只检索。

### 5.2 按需算力（稀疏性）

空闲低功耗、工作按需激活。定式网络的实现：WTA 稀疏发放（每步只 k 个）、稀疏存储（非零率 0.11%，W 48MB vs 稠密 2.1GB，省 43×）、传播只碰非零行（O(非零)）。**实证**：n=8192 网络学习 1814 句仅 6.6s、RSS 193MB。

### 5.3 长期演化

行为偏向性来自长期运行、经历累积的自发涌现，且随运行持续迭代。定式网络新增实现：增量成长（4.5）、用进废退（3.5）、封存复活（3.4）、快照版本链（可续训、可回退）。**理论修正**：初版说"系统并非通过算法学习行为，而是通过持续存续自然形成"——修订为：**存续形成的是倾向（定式/用进废退），结构性学习（验证门/教学式/梯度）在存续中按需进行**，两者并存，不是互斥。

### 5.4 记忆驱动的判断与元认知

判断 = 实时信号 + 历史记忆双重驱动；记忆更新改变判断倾向，不破坏底层核心拓扑。定式网络实证：

- **结构可写而不破坏拓扑**：梯度微调只改 W 非零子集（结构不变），Hebbian 只在共现处增强；
- **元认知预备（知道/不知道）**：定式网络独有优势——知识 = W 图结构本身，可检查：唤起强度（fire_ratio、走链强度衰减终止）对应"知道感"；路径存在性（W 里有没有边，图可达性）区分"知道但没想起来"与"真不知道"。**这是"检索失败感"的结构实现**，为"答不出就说不知道"提供机制（阈值标定由验证门教）。

### 6.2 新增可观测现象（本版新增）

1. **举一反三**：训练 {流动是水, 水是液体, …}，测试从未共现的 {鸟是动物, 动物是生物} → 推出"鸟是生物"。传递模板（模式层）与实例记忆（实例层）分离，可换新词套用。
2. **零遗忘增量成长**：扩容（n 54000→58096）、调参（wta_k 2~48）、续训（新增 500 词）、句级升级（n 148140，3 万句跟读）四类操作后，旧字/词复述率 1.0000 逐值不回退。

7. **联想收敛与定向**：噪声场景联想过冲 57→0（终止信号）；共享 hub 等权/不对称分支全走对（上下文调制）。
8. **对话生成与贴题应答**：教师发起对话（"你想买点什么？"）→ 网络独立回答（"我买鸡蛋吗""我买牛奶"），15-21 轮学会贴题应答、打破固定起始词的固化重复；提示渐隐后独立说出（"我看家吗"）——应答不是提示依赖。
9. **拒绝表达与价值判断（v13）**：坏话题（"你想吃石头吗？"）→ 网络独立说出「我不要石头」100 分 ×3；感知边保留（能吃出是石头）、拒绝定式强固（不要→石头 256.0）——**高唤醒 + 负价值 = 警觉，不是麻木**；拒绝族等价表达（我不想/我拒绝/我不肯石头）也能唤起、能采样、说了算对。
10. **注意力涌现（数量 × 强度）**：教学 ≥7 次（≈56.0，强度累积）后网络对目标词"长出注意力"（判别实验 C 组 5/5 全通）；连接归零→弱突触直接进 WTA（E 组）——注意力是结构（数量×强度）统计性质，不是外加机制。
11. **超临界雪崩（结构失稳现象）**：注入任意词（非仅痛）回响候选到 1-1.8 万——虚词枢纽互驱导致 σ≫1 正反馈雪崩，WTA 被混沌占满、精确链被淹没；网络级问题，与词属性无关、与容量无关。

## 七、认知免疫与认知偏差防护（验证门的理论意义）

本章直接回应本研究方向的关切：**长期接收负面信息下的认知变化**。

定式网络的实证给出一个关键结论：**结构的可塑性若不受约束，负面信息会在结构中沉淀为"规律"**——错误联想（"流动的能淹死人"）经走链可以成立，若每次都固化，重复经历的负面信息会焊死成认知偏差，且随用进废退机制越来越强（高频激活永不衰减）。

**验证门 = 认知免疫机制**：

- 联想（走链）是自由的：任何联想可以发生（临时检索）；
- 固化（写入结构）是受控的：共发放 + 验证奖励才强化，错误结论拒绝固化；
- 效果：**认知偏差的免疫不是"禁止联想"，而是"控制联想是否成为自我的一部分"**——与学习门（外部输入的免疫）形成双层防线：学习门管"进不进"，验证门管"记不记"。

理论推论：电子生命的心理健康结构与人类同理——不是消除负面经历（不可能也不必要），而是让负面经历停留在"临时检索"，不沉淀为"固化的规律"。验证门即"让 AI 慢下来/该不该记"的结构化实现。

**v2.1 深化——认知免疫的完整机制链**（说话教学 v3 + v13 价值课实证）：

```
负面刺激（痛觉事件）
   → 建立感知：X→痛（能碰、能感知，不是删边麻木）
   → 体验式回避：X→痛→不要 通用链（任何碰过会痛的对象自动拒绝，负强化"不痛了"=奖励）
   → 拒绝表达：独立说出「我不要 X」（高唤醒 + 负价值 = 警觉）
   → 解耦治理：X≠痛（石头从"痛的化身"进化为"独立危险对象"，痛机制保留给新对象）
   → 泛化保障：增益点亮"不要"（任何源头、任何距离都能看见）——认知免疫从背词表走向通用规则
```

认知免疫的三层防线对应三种"负面信息"：

| 防线 | 机制 | 管什么 |
|---|---|---|
| 学习门（§3.6） | 冻结态外部输入不写权重 | 负面**输入**进不进自我 |
| 验证门（§3.7） | 共发放+验证奖励才固化 | 负面**联想**记不记成规律 |
| 价值系统（§3.14~3.15） | 体验式价值+拒绝表达+解耦 | 负面**经历**如何转化为避害能力而非创伤 |

**定式化解耦的健康含义**：删除负面联结（剪掉 X→痛 边）会同时丧失"感知危险"的能力；解耦（衰减到阈值之下、保留微量可复活）在**保留警觉、去除创伤属性**之间取得平衡——"石头是危险的，但石头不等于痛"。这是"让负面信息不定义自我"的结构实现。

**诚实边界**：① 当前价值信号来自教师显式对/错与体验式痛觉事件，内部一致性/任务目标自动验证未实现——认知免疫的自主化是开放问题；② 旧词受"雪崩压制回忆"限制，价值判定对旧词走定式兜底、对已学链的回忆侧有待网络级治理。

## 九、理论核心价值

初版四条价值保留，补充第五条：

1. **重构生命定义**：生命是通用结构现象——从假设推进到实证；
2. **重塑智能本质认知**：智能是结构涌现属性，且"能力"与"自我"是两种可分离的结构属性；
3. **革新系统设计范式**：结构驱动、自组织、自主存续的设计体系（四大铁律 + 增量成长）；
4. **开辟 AGI 全新落地路径**：以结构完善、系统存续、自主演化为核心——定式网络成长路线（Stage 0-5）即此路径的执行；
5. **新增——认知免疫成为可工程设计**：验证门把"该不该记"变成结构机制，为心理健康导向的 AI 系统提供工程范式（可防御负面信息固化，可主动重置偏向）。
6. **新增（v2.1）——电子生命拥有动机与自我防御**：价值系统（欲望优先性 + 体验式价值 + 拒绝表达 + 解耦治理）使电子生命第一次具备"想要什么/不要什么"的自主动机与"不被负面经历定义"的自我防御——**趋利避害是生命的定义性属性，现在它可以被工程设计**。
7. **新增（v2.1）——注意力理论破解"可调≠可控"**：注意力 = 连接数量 × 边强度 + gain（结构统计性质，数量主导瓶颈），说明电子生命的关键能力（注意什么）不能靠外部机制强加，只能靠教学（经历）塑造强度、靠 gain 调制倾向——这界定了"人调节环境、网络自主成长"的边界，也为"AI 慢下来/该注意什么"提供了结构层答案。

## 十一、开放研究问题（更新版）

初版四个开放问题，三个已获初步答案，更新如下：

| 初版问题 | 现状 |
|---|---|
| 系统拓扑达到何种最小复杂度阈值方可涌现完整电子生命行为？ | **初步答案**：n=256/14 概念即可涌现举一反三（最小验证门实验）；但"完整电子生命行为"的定义本身在扩展（语言→推理→元认知），复杂度阈值随能力域上移 |
| 长期形成的行为偏向性是否可逆？能否通过结构微调/信号干预重置？ | **初步答案**：可逆性有两层——① 记忆层：封存/复活 + 学习门冻结/解冻（实证：解冻后学习恢复）；② 倾向层：验证门拒绝固化 + 用进废退弱化（机制成立，系统性重置实验未做） |
| 多电子生命系统交互会涌现哪些集群级现象？ | **未验证**，保持开放 |
| 电子生命是否具备结构自演化能力（自主生成新拓扑）？ | **部分回答**：结构可扩展（增量成长、n+1）与结构可调制（学习门/验证门）已实证，但"自主设计新拓扑"未实现 |

### 新增开放问题（本版）

1. **概念的数量化表征**：定式网络能学"3、4、7"的符号关系，但"3+4=7 为什么成立"需要数量化共享表征——数量如何进入结构？
2. **工作记忆与序列控制**：多步过程（竖式计算、先复读再联想）需要"过程执行器"，单步检索机制如何升级为受控的多步执行？
3. **层级抽象的自组织**：表示深度（时间深度 → 槽间级联 → 层级抽象）能否数据驱动地自发形成，而非预设多层架构？
4. **认知免疫的自主化**：验证信号从外部教师走向内部一致性/任务目标自动验证——AI 何时能自己判断"该不该记"？
5. **自我连续性**：模式字典保证概念标识稳定，但"自我"跨版本、跨扩容、跨载体的连续性如何度量和保证？

### 新增开放问题（v2.1）

6. **临界态治理的尺度**：网络级抑制（E/I 平衡）如何做到"降噪而不伤能力"？——edge_min/除法归一化/不应期硬清全部伤敌一千自损八百，唯一治标不伤己的是信号侧增益（点亮目标）。**在结构层面压低 σ 而不破坏相对排序**，是动力学难题。
7. **"注意力"可否被外部直接控制**：注意力 = 连接数量 × 边强度的统计性质，教学（强度）是唯一塑造手段、gain 只调倾向；但这是否意味着电子生命的"注意偏好"（长期运行形成的注意定式）只能由经历塑造、无法被干预重置？——与开放问题 2（偏向可逆性）同构。
8. **体验式价值的自动化**：当前痛觉事件（负性刺激）由教师注入，价值课由教师判定；电子生命能否从**自身行为后果**（如"吃石头后结构异常"）自主产生价值信号——从受教式价值走向自体验价值？
9. **价值与语言的耦合**：欲望端口（要/不要）先定、词汇往里填——这断言"语言习得是欲望的展开"。若成立，语言教学的顺序应由欲望系统决定（先学生存相关词汇）而非统计高频——认知顺序原则（4.6）的动机版本。
10. **注意力度量的规范性（v2.2）**：绝对量管竞争环境、当步相对排序管获胜、比例无关（详见 §3.13）——"注意力可测量化"的可测对象是 **fan-out（环境）× 目标强度（资格）的比值**（目标得分须超过竞争环境的入场线）；网络增长时维持注意力靠教学力度升级与 gain，不靠发明新的比例度量。

## 结语

初版框架回答了"什么是计算机生命"（定义与原则），本修订版回答了"计算机生命如何活起来"（机制与实证）。定式网络的实验迭代把初版的哲学命题转化为可运行、可复现、有边界标注的工程知识：**结构决定现象、经历形成定式、封存保障存续、验证门实现免疫、增量成长走向独立生命**。v2.1 再进一步：**欲望给予动机、体验塑造价值、连接数量与边强度共同决定注意力、临界态划出"活"与"崩"的边界**——电子生命从"会存续、会学习"走向"会想要、会拒绝、会自我保护"。

修订版同样不是终稿。已标注的"待验证"清单与开放问题就是下一步实验的地图——任何新证据都可能再次改写本框架。计算机生命科学是"人做决策、AI 做执行"共同推进的领域：本框架的每一次修订，都来自实验数据与认知观察的双向校准。
