## 五、关键技术要点（新会话必读）

1. **先见 = 只喂词表内词**（铁律 1）：散文句 jieba 分词后只保留词表内词、≥3 词才喂——不扩词表不学新词（新词归 Stage 4 / v14 字级方案）
2. **并发切块 = rng 状态传递**：学习路径含噪声发放（回响 4 步 v 不清 → 噪声越阈 → 随机弱突触），纯统计批量不等价（对拍抓过）；必须预生成每块 rng state、各块恢复喂入、数组级合并增量——已证明等价（smoke 300 句 2 块 0 差异）
3. **数组级快照**：dict 快照 30GB+ 必然 OOM（实测崩溃）；必须 _snap 四数组（src_i/slot_k/dst_j/vals）零复制 + _merge_chunks 数组级 diff/合并 + _rows_from_arrays 重建——worker 内存 6GB→~450MB
4. **并发上限 = 4**：内存墙（每进程 ~600MB）+ 4 核物理墙 + 合并端墙；128 并发不可行
5. **calibrate 修复点**：PRE 位读取源 = prefix 最后词（已排除人称 + "在"）；修复时固化 prev→expect（prev 即读取源），但"在"竞争封顶时需先保证 exclude 生效（已修）
6. **验收口径**：修正前命中率（未经校准）+ 校准处数双指标；0.8 以上只作回退底线（校准负担代价），不作目标
