## 一、定位

**AI 的持续自我层**：一个纯计算、模型无关的动态权重网络。

- 静态神经网络（LLM）负责**能力**（生成、推理），本系统负责**自我**（经历、记忆、人格倾向、身份）
- 权重从交互中产生（初始全 0，不提前赋予）；反复输入同一数据 → 形成定式
- 与 LLM 分离 → **换模型不换自我**
- 远期：外挂大模型在线吸收能力（吞并愿景，见第九节）

**一句话**：LLM 是大脑皮层（会算），定式网络是记忆与人格的沉积（会记得自己是谁、经历过什么）。

## 二、设计哲学

| 原则 | 含义 |
|------|------|
| 权重从交互中产生 | 初始空白，不预置知识 |
| 反复经历形成定式 | 经验 = 重复，不是训练（无梯度、无损失） |
| 记忆不是遗忘，是封存 | 封存 ≠ 删除，可复活 |
| 神经元是 AI 的神经元 | 不是用户的神经元 |
| 只考虑多槽 | 单槽架构已废弃（实验证明组合不可表示） |
| 槽满了就覆盖 | 人脑装不下所有知识，容量压力下旧弱记忆被篡改 |
| 冻结/学习双状态 | 根据实际情况切换；冻结期自我物理免疫篡改 |

## 三、核心机制

全部矩阵运算（numpy 向量化），七项机制：

### 3.1 积分-发放（LIF，Lapicque 1907）

```
v = v·λ + 注入脉冲 + W@spikes（分槽传播）
v ≥ θ 且 WTA 选前 k 强 → 发放；发放后全槽复位
```

- `θ=1.0` 发放阈值；`λ=0.9` 膜电位衰减
- WTA（胜者全取，Marr 1969/Olshausen 1996）：每步最多 `wta_k` 个神经元发放

### 3.2 Hebbian 学习（Hebb 1949）

```
共同发放对 (i,j)：W[i, 主导槽_i, j] += η（排除自连接，w_max=2.0 截断）
```

- 反复激活强化；η=0.1，20 次反复 → 连接到顶（2.0）

### 3.3 噪声探索

```
noise = (rng < noise_p=0.06) × noise_amp=0.5
```

- 让空神经元有机会参与竞争
- **噪声卫生**：`0.9×0.5+0.5=0.95 < θ`，杜绝连续两步噪声越阈伪发放（0.6 时会越过；decay=0 后伪发放的微小连接永久累积）

### 3.4 内部多槽 + 情境化传播（架构核心）

```
W 形状：[n 神经元, s 槽, n 入连接]
```

- 每个神经元内部有 s 个独立状态槽，不同情境的输入打不同槽
- **情境化传播**：发放神经元按主导槽分桶，只驱动同槽接收方 → 存储隔离 + 传播隔离
- 同一神经元可同时承载多个模式而不互相覆盖
- **单槽废弃**（2026-08-09 实验结论）：单槽下组合不可表示——要么融合成超组装要么随 n 增大爆炸（n=256 排列一致性跌到 0.10）

### 3.5 频率门控慢衰减（2026-08-09 取代满槽覆盖）

```
slot_freq[n, slots]  窗口内每槽位被"发放神经元主导"的唤醒计数（只数真实发放，静息不污染）
sleep_consolidate()  低频槽（<min_wake）连接逐周期 ×(1-decay) 渐进弱化，≤eps 删除条目（稀疏回收）
                    高频槽（≥min_wake）永不衰减；learn_gate=False 冻结态拒绝执行（物理零改动）
```

- 记忆观转变：**"装得下就不动"（容量驱动被动保留）→ "用进废退、可复活"（使用驱动渐进遗忘）**
- 低频定式缓慢弱化，期间被复习（Hebbian 强化）即可复活；长期不用最终归零回收
- 生物对应：突触修剪渐进性 + 稳态可塑性 + 睡眠记忆巩固 + 艾宾浩斯遗忘曲线
- `slot_cap` 满槽覆盖（写时挤最弱）**已废弃**（2026-08-09 用户决策），代码保留仅供历史留档重跑（默认 0）；`weight_decay` 无差别衰减仍废弃

### 3.6 学习门 learn_gate（冻结/学习双状态）

```
learn_gate=True  → 学习态：权重实时更新（Hebbian/STDP/频率门控衰减全执行）
learn_gate=False → 冻结态：纯检索，权重物理零改动（含 sleep 拒绝执行）
```

- 冻结期外部输入照常激活网络（识别/检索正常），但**不成为自我的一部分**
- 学术对应：多巴胺门控可塑性 + 稳定性-可塑性困境（stability-plasticity dilemma）

### 3.7 STDP 时序（token 转移，Bi & Poo 1998）

```
前驱（上一步及更早的发放痕迹）→ 后继（当前发放）：
W[后继 ← 前驱] += stdp_pre（只强化正向，δt=1 最近邻）
```

- 发放痕迹 `pre_trace`（eligibility trace 简化版）：`trace_decay=0.5` 衰减，阈值 `0.3` 滤掉非相邻的陈旧痕迹 → **只学相邻转移**
- 只强化正向 → "喂 a 唤起 b"成立、"喂 b 唤起 a"不成立（反向连接从未强化）→ **顺序自动可区分**
- `stdp_pre`/`stdp_neg` 默认 0 全关，不影响静态实验

### 3.8 教学式学习（语言实验专用，学习/回忆路径分离）

```
学习（_learn_sentence）：注入每词前清 v 与 spikes（无传播驱动）→ 当前词干净发放 → STDP 只学 pre_trace→当前词
回忆（_evoke_prefix）：   保留传播驱动（注入前缀 → 网络自己唤起后继词）
```

- 根因：学习时若保留传播，强组装（高频词）的复发发放会 WTA 压掉注入词（v-clear 后注入词脉冲 1.0 输给驱动 4.0），W 学到网络自联想而非语料词序 → "无聊垄断"（W[无聊←我]=14.0，单次出现的词被高频词组装吞并）
- 重写后 W 严格∝语料共现次数（W[喜欢←我]=48=12次×0.5×8、W[无聊←我]=0、W[无聊←觉得]=4=1次×0.5×8）
- 语言实验专用 `lang_n=2048`：静态实验 n=32 太小，k=8 分布其中两词平均交集 2.0、67% 词对碰撞，词模式无法区分（准确率被压到 0.07）

### 3.9 痕迹插值读出 trace（上下文条件转移，Phase 1，2026-08-09）

```
P(w_t | w_1..w_{t-1}) = P(w_t | 末词)            末词已决定（top1-top2 差 ≥ delta_off=0.05）
                      = Σ_i wgt_i × P(w_t | w_i)  末词平局（借整条前缀破局）
P(w_t | w_i) = W[w_t ← w_i] / outsum[w_i]   （源词出边归一化 = 条件转移概率）
wgt_i = trace_i / trace_末词，非末词再 × β=0.1
trace(w_i) = 前缀注入后该词模式神经元的 pre_trace 最大值（距离权重：相邻 0.5 / 隔一 0.125 / 隔二 0.031…）
```

- **复用 pre_trace（eligibility trace）机制，W 保持二元转移不变**，插值只发生在读出层 → 零额外学习，从"一元上下文"升级到"多词条件转移"（trigram+ 级）
- **outsum 归一化是必须的**：否则高频源词转移强度（W[喜欢←我]=48）即使痕迹很弱也淹没相邻词决定信息
- **delta_off 条件混合（backing-off 平滑）**：末词已决定 → 只用末词（≡wsum，非平局零退化）；末词平局（无统计答案）→ 借整条前缀破局
- 验证：主语料 trace 0.474（非平局零退化，平局处 2 例正确破局 5 例误翻转——精确平局无统计答案）；微语料破局机制 ✓（"我很累"+"我很忙"+"昨天很忙" → 前缀[昨天,很] 靠"昨天→忙"破"很"的平局 → 忙）；"我喜欢吃"→苹果 ✓
- 定位：LLM 注意力混合历史 token 信息的雏形（条件概率混合 = Jelinek-Mercer 插值平滑的神经实现）

### 3.10 稀疏存储 SparseSchemaNet（Phase 2，2026-08-09 验收通过）

```
稠密 SchemaNet.W[j, k, i]  ←→  稀疏 W_out[i][k] = {j: w}（i 槽 k 出边到 j）
```

- **动机**：n=8192 时稠密 W 2.1GB 不可行；实测 W 非零率仅 0.11%（Hebbian/STDP 只强化共现对）→ 稀疏化 W 48MB（省 43×），传播/更新只碰非零行（O(非零)）
- **等价性保证**：动力学逐行对齐（积分-发放/WTA/Hebbian/STDP/痕迹/不应期/学习门），唯一 RNG 调用点（noise）一致 → 同种子学习结果逐值一致（对拍：18090 非零 0 差异、outsum 全等、评估 0.5000/0.4805 一致）
- **读出向量化**：词模式 → (V,k) 索引矩阵，出边聚合 + fancy indexing，纯 numpy
- 语言实验用 slot=0，但为行为对齐保留多槽完整实现（噪声打所有槽、Hebbian/STDP 写主导槽 k_star、传播按主导槽分桶）
- 关联：sparse_net.py（代码）、_check_sparse.py（对拍）、data/gen_corpus_large.py（语料生成）

## 四、输入契约

```
现实 ──编码器──> 脉冲模式 ──定式网络──> 脉冲模式 ──解码器──> 现实
```

- 进入网络的**不是语义，是脉冲模式**；网络只识别"第 3、17 号位置有脉冲"，不认识"a"
- 编码器负责"现实→模式"（当前硬编码验证；真实接入需 embed→投影→稀疏化，且要求稳定编码）
- 解码器负责"模式→现实"
- 组合输入 = 成分模式并集（多集表示，顺序无关）；序列输入 = 模式按序注入（STDP 学转移）

## 六、关键设计决策与踩坑记录

### 6.1 单槽废弃，只考虑多槽（2026-08-09）
26 字母/组合实验证明：单槽下组合不可表示——要么融合成超组装要么随 n 增大爆炸（n=256 排列一致性跌到 0.10）。多槽实现存储隔离+传播隔离，组合层与原子层共存、原子保留 1.0。

### 6.2 频率门控慢衰减取代满槽覆盖（2026-08-09）
slot_cap 满槽覆盖（当日上午定案：装得下就不动、装不下挤最弱）同日被用户推翻：**取消写时覆盖，改为频率门控慢衰减**（低频槽不删除、逐步衰减为 0，渐进可复活）。**废除依据**：SparseSchemaNet 只存 slot_cap 属性从未实现覆盖逻辑（语言实验 slot_cap=0 实际无任何遗忘机制生效），W 单向增长（1809 万连接）；频率门控慢衰减是废除后唯一回收通道，且选择性（只忘低频）修复了 weight_decay 被废弃的根因。验证（runs/20260809_103532）：最小实验 12/12 PASS（含衰减中复习复活）+ 语言接入 top-1 不退化（wsum 0.1081 持平）+ 弱化低频连接 5.56%。

### 6.3 判读方式：首响应 vs 回响并集
- **原子重测用首响应**（第一步输入的直接激活）：强自连接（2.0）让定式持续回响 10 步并把伪发放累积进并集 = 仿真伪影（网络无抑制/不应期）
- **排列响应仍用回响并集**：并集脉冲 5 候选，WTA 单步只留 2 个，需多步收集完整组装

### 6.4 [历史] 满槽覆盖只伤弱链、保护强定式（2026-08-09 实测，机制已废弃）
slot_cap=4 压力档下学习态干扰触发 240 次覆盖，但 A/B 核心连接（2.0）与组装保留全 1.0——覆盖从最弱开始，强记忆扛得住篡改。

### 6.5 冻结实验对照严格性
两组同种子出发 → 噪声序列完全一致（learn_gate 不消耗 rng），唯一变量 = 学习门。

### 6.6 alphabet 判读缺陷（遗留）
alphabet 用末次快照判读 + slots=4 同槽共享下同槽字母不可分（decay=0 下 18/26）。修正方向：每字母独立槽（slots=26 时 26/26）或改倾向矩阵判读。**非机制问题，是判读缺陷。**

### 6.7 STDP 三个实现坑（2026-08-09 debug 定位）
1. 注入符号前残留膜电位 v 会让噪声越阈挤掉目标神经元（注入 b 时噪声 6 挤掉 b 目标 1）→ **注入前清 v**
2. 间隔步内定式可能不发放 → 严格"上一步 spikes"前驱会丢失 → **改用发放痕迹 pre_trace**
3. 回响阶段 a、b 神经元同刻发放 → 同步 Hebbian 双向污染 → **经历间清痕迹**

### 6.8 三实验同秒留档互相覆盖（2026-08-09）
时间戳秒级 + 同一秒跑完多个实验 → 留档只剩最后一个。修复：串行跑用 `Start-Sleep -Seconds 1` 区分，或槽对照实验用 `{run_stamp}_slots{n}` 目录名。

### 6.9 语言实验三个坑（2026-08-09 debug 定位）
1. **学习时传播驱动压过注入词** → W 学到网络自联想而非语料词序（"无聊垄断"：单次出现的"无聊"被高频词"我"的组装吞并，W[无聊←我]=14.0；同时"我想X" 11 次却 W[想←我]=0）→ 教学式重写（见 3.8）
2. **n=32 编码区分度灾难** → k=8 分布在 32 神经元里，两词平均交集 2.0、67% 词对碰撞 → 准确率被压到 0.07，误判为"转移没学到"→ lang_n=2048（交集期望 0.031、碰撞对仅 6/10011）后 W聚合 0.500 ≈ bigram
3. **回响读出 < W聚合读出** → WTA top-8 每次只发 8 神经元（恰好一个词的量），多候选平局（"喜欢"后 15 宾语各 0.5 平局）时 8 个神经元分散在 120 个候选里，任何词覆盖都 <0.4 → None。**覆盖率读出是动力学硬决策，只有确定性强后继才成功；W 直接读出才是有效的预测接口**

### 6.10 噪声多步累积（2026-08-09 发现）
旧"噪声卫生"论证（0.9×0.5+0.5=0.95<θ）只防**连续两步**噪声，没防多步累积：3 次噪声命中在 ~10 步窗口内即可越阈（1.0+0.9+0.81≥2 或非连续组合），n=2048×19 步真实网络自发发放 109/2048 神经元。教学式学习中无害（每步清 v），但回忆路径（不清 v、长前缀多步累积）会污染 fired 集合。待办：语言实验降 noise_amp 或回忆路径加噪声抑制。

### 6.11 trace 三个坑（Phase 1，2026-08-09 debug 定位）
1. **无归一化 → 高频词痕迹淹没决定**：Σ trace×W（W 原始强度）时，"我"痕迹 0.125×W[喜欢←我]=48 → 6.0，压过"觉得"直接后继"很"（0.5×4=2.0）→ 必须 ÷outsum 源词出边（条件概率同尺度混合）
2. **β 压降不足 → 高频词微增量翻转精确平局（对错各半，净负）**：β=0.1 后"我很"→高兴仍被"我"高频后继"喜欢"翻转（P(喜欢|我)=0.16×0.05≈0.008 > 0.1-0.1=0 平局差）——**精确平局下任何非末词正增量都翻转**，主语料无统计答案
3. **解法 = backing-off 条件混合（delta_off）**：末词 top1-top2 差 ≥0.05 → 只用末词（非平局零退化）；<0.05（真平局）→ 才借整条前缀破局。微语料验证机制 ✓，主语料净效应 = 非平局不损失 + 平局处 2 对 5 错（数据限制，Phase 2 大数据验收）
4. **破平局需要"非末词→候选词"的直接转移**（如 micro 的"昨天→忙"）；"我觉得"→很 破不了是因为 W[很←我]=0（"我→很"从未直接相邻，中间隔着今天/觉得）——W 是二元转移，上下文词必须直接连到候选词才有信号

### 6.12 Phase 4a 梯度实验三个坑（2026-08-09 debug 定位）
1. **评估口径**：梯度读出未过滤 `logits==0`（无转移信号的词），wsum 基线过滤 `scores>0` → 全 0 位置随机选词，0.13 = wsum 成功位置(35%) + 随机猜测 → 修复：`logits<=0 → -inf`（同口径）
2. **score 平局海（S 矩阵非零 98.72%）+ softmax 尾巴权重**：词模式 k=16 神经元的出边并集覆盖大半词表 → 顶级候选分差 ~1e-4 量级 → 任何非零远端权重都翻转平局。softmax 参数化梯度 ∝ wgt（越小越慢）→ 0.0001 尾巴翻转 25% 位置（0.38→0.14）→ 修复：自由参数 + 单纯形投影（clip 非负 + 归一化）
3. **uniform 语料下 CE 目标与 top-1 准确率背离**：uniform 分布（上下文无统计信息）下，CE 拉高远端权重（降 CE）但 top-1 平局扰动暴跌 → 梯度训练在 uniform 语料上不可行（与 trace 的 6.11 同源：均匀分布 = 上下文最不利场景）→ **exp2 必须用二阶依赖语料**（corpus_ctx：ctx→候选直接相邻），梯度学到 pos1=0.0547、8/8 破局

## 七、学术审视

**机制全部经典**：LIF（Lapicque 1907）、WTA/侧抑制（Marr 1969/Olshausen 1996）、Hebbian（Hebb 1949）、树突室/深度树突（Beniaguev 2021）、干扰式遗忘（遗忘由干扰非时间衰减决定）、细胞组装/吸引子（Hopfield）、SPM（Hawkins HTM）、STDP（Bi & Poo 1998）、eligibility trace、多巴胺门控可塑性。

**组合层面是新的**：多槽显式结构缓解灾难性遗忘、权重倾向矩阵读出自我（人格读出雏形）、频率门控慢衰减命题（用进废退、渐进可复活）、学习门（物理免疫篡改）、STDP 只强化正向（顺序自动区分）。

**短板**：
- 无严格归一化守恒（总量归一化为远期方向）
- WTA 是人为全局抑制（替代真实侧抑制）
- 无容量理论（Hopfield ~0.14N 未对接）
- 单 seed 无统计严谨性（后续需多 seed 跑分布）
- 编码器缺失（现实→模式的稳定编码未实现）

## 八、容量与规模估算

- 参数量：`P = s × n²`（n 神经元 × s 槽 × 每槽 n 入连接）
- 模式占据神经元规模：≈ 输入脉冲规模（WTA 激活最相近 + Hebbian 反复锁定，不扩张）
- 7B 规模反推槽数：n=4096→s≈417；n=11008→s≈58；n=65536→s≈1.6（趋近单槽）
- 警告：参数量对齐 ≠ 能力对齐（单层递归记忆 vs 分层计算）；记忆容量按经历条目算（10⁶ 条 → n×s≈10⁷）
- Hopfield 容量 ~0.14N（记忆共享神经元、容量受干扰限制）
