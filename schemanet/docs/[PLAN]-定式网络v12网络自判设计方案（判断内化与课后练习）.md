## 一、背景与现状差距

### 1.1 铁律 5 闭环缺口

句子单元五步闭环 ①-④ 已完成（v7→v11），⑤"自己判断"未开发——**网络做判断的能力**。

### 1.2 现状：判断是代码规则，不是网络自己的

`_speak.py` §③ 自判应答已有一个"自判"（`speak_judge`），但它是 **v11 代码规则**：

```
attributed_sentence（结构检查信号）→ rule_verifier（代码查 O ∈ V 搭配类别）→ 判断
```

- 判断依据 = **代码里的 `allow` 集合比对**（`rule_verifier` 原则4：`o in allow_mem`）
- 判断阈值 = **代码里的 `> 0.1` 硬编码**
- 判断方法 = **代码写死**（教师没教过"怎么判"）

**差距**：网络会"被判断"（教师判断→处罚→结构改变），但不会"自己判断"——判断的**方法**（先查直连、再查二跳泛化、再判强度）和**阈值**（多强算可造）都没内化到网络，改代码就改判断。

### 1.3 v12 目标

训练后网络凭**自己的边结构**判断 "(S,V,O) 可造/不可造/不知道"（带置信），外部教师（LLM/规则）从"判断者"转岗为"批改讲评者"——网络自判，教师批改对错、讲评错因，网络再修正（铁律 5 ⑤ 定位：教师不是退场，是转岗）。

## 二、设计

### 2.1 自判 = 结构检查 + 唤起强度（复用 §4.8 信号，无新训练机制）

自判判定函数 `self_judge(s, v, o)` 输出三元 `(verdict, conf, path)`：

| 信号 | 来源（复用现有） | 判据初值 |
|---|---|---|
| V→O 直连 | `edge_between(ng, pats, v, o)`（W 里 V 模式 → O 模式的边聚合） | ≥ 0.5 → 可造（强判断） |
| 类别泛化二跳 | V 的搭配类别 `allow` → 类别成员出边（`attributed_sentence` 的"类别泛化"源，×0.3） | 可达 → 可造（弱判断） |
| 唤起强度 | `attributed_sentence` 的 `top` 排名 + O 得分（`scores[o]` 归一化） | O 进 top-8 → 置信高 |
| 路径存在性 | `edge_between` 是否 > 0（图可达性） | 无边 → 判"不知道"（诚实留白） |

**判定逻辑（判断路径模板）**：

```
① 先查直连：V→O 边 ≥ 0.5          → 可造（强判断，置信高）
② 再查二跳：V→类别 c 且 c→O 可达   → 可造（弱判断，置信低）
③ 判强度：O 进 top-8？             → 进：置信升档；不进：置信降档
④ 都不可达 → 判"不知道"（不是"不可造"）
⑤ 可达但置信低 → 判"该说不知道"（§4.8 阈值标定）
```

**与 v11 规则的区别**：判定依据 = 网络边结构（W 图可达性 + 强度），不是代码 `allow` 集合。改网络（教学/处罚）就改判断——**判断与知识同源**。

### 2.2 ⑤a 判断方法教学（先学怎么做判断）

教师示范判断过程，网络把判断方法沉淀为**判断路径模板**（2.1 的 ①→⑤）：

- **示范样本**（诊断题）：教师演示"怎么判"——
  - `我要苹果` → 示范：先查 要→苹果 直连（有边，强）→ 判可造
  - `我吃石头` → 示范：先查 吃→石头 直连（无边）→ 再查 吃 的搭配类别（食物，石头不在）→ 判不可造
  - `我画家` → 示范：直连弱/无 → 二跳泛化可达但强度低 → 判"该说不知道"（临界样本）
- **阈值标定（验证门教）**：示范即教学句——判断正确的路径进 `_learn_sentence` 固化（该判断路径加强）；判断错误的路径不进（不固化）。
- **判断路径 = 结构检查的顺序**（先直连、再二跳、再强度），不是新训练机制——2.1 的判定逻辑就是模板本身，教学 = 让网络按模板走对路径、错误路径被修正。

### 2.3 ⑤b 课后练习 + 教师批改讲评（内化路径）

**题集（三档 × 变式 × 穿插，plan §四通用题集结构）**：

| 档位 | 题例 | 网络自判依据 | 批改预期 |
|---|---|---|---|
| 基础档 | `我要苹果`（训练组合复测） | V→O 直连可达 | ≈ 1.0 |
| 巩固档 | `我们要水`（三词单训过、组合没学过） | 直连 + 类别泛化二跳 | ≥ 0.9 |
| 拓展档 | `吃+香蕉`（类别泛化二跳）；`看+石头`（跨类临界，LLM 裁决） | 泛化可达；语义合法性来自教师，网络只判结构 | 允许 < 1.0（泛化边界） |

- **变式**：正向（可造）/ 逆向（不可造：`吃+学校`）/ 临界（`画+家`：v11.2 被噪声污染又治愈的样本）
- **穿插**：不同 V（吃/看/画/喝）交错出题，防"O 槽保底"定式
- **批改讲评**：网络自判 → LLM 教师批改（判断 + 原因）→
  - 自判对 → 教师确认 + 该判断路径固化（三因子规则：对→固化）
  - 自判错 → 教师讲评错因（自然语言）+ **归因修正**（错误判断依赖的边显式减权 + 正确判断路径固化）
- **批改统计**：`self_judge` vs `teacher_judge`（LLM/规则）一致率，**分档统计**（基础/巩固/拓展分别报）

### 2.4 验收

1. **一致率**：训练后 `self_judge` 对照教师判断——基础档 ≈ 1.0、巩固档 ≥ 0.9、拓展档记录泛化边界
2. **错误收敛**：自判错误样本 → 归因修正 → 重测该样本判对（错误样本清单逐条记录前后判定）
3. **零遗忘**：继承 v11 全验收（回归跑通，快照可恢复）

## 四、影响范围与风险

- **范围**：仅新增 `_grow_v12.py`；不碰 v11.1 快照、不碰 `_speak.py` 现有逻辑（衔接在 v12 验收后）
- **风险**：
  - 自判阈值（0.5 / top-8）需实测标定——以验证门教（自判对→固化、错→修正）替代硬编码，阈值只是初值
  - 类别泛化二跳可能误判（"看+石头"语义合法但结构不可达）——归入拓展档，LLM 教师裁决，诚实边界显式标注（网络只判结构）
  - 多 seed 统计严谨性（沿用项目现状：单 seed 为主，报告标注）
