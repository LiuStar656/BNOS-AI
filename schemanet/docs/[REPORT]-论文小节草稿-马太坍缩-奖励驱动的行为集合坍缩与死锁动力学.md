## 引言定位（本小节在论文中的一句话定位）

在 E6 混沌奖惩实验中，我们意外撞出一个此前设计未曾预期的失效模式：当奖励干预与 Hebbian"使用增强"同时开启时，持续奖励非但没有维持行为频率，反而把行为集合**坍缩到死锁**——少数神经元垄断权重，行为组发放维度跌破检测阈值，奖励随之停发，系统永久锁死。我们将该现象命名为**马太坍缩（Matthew Collapse）**：奖励强化的强者愈强效应，最终以行为多样性丧失为代价。

该现象的价值在于三点：（1）它是**撞出来的真发现**，不在任何设计假设内；（2）它提供了一个与深度学习的 **neural collapse**（Papyan et al., 2021）形成严格对照的**无梯度**坍缩案例；（3）修复它的方式（隔离 Hebbian 自增强回路）本身就是一条可操作的干预原则，并反过来保证了 E6 正结果的纯净性。

---

## 一、现象：奖励组 w 暴涨，行为频率反而归零

### 1.1 实验协议（E6 背景，详见 [PLAN]-E6）

- 网络：`SparseSchemaNet`，n=1024，WTA_K=8（每步全局最多 8 个神经元发放），w_max=16.0
- 混沌环境：Regime 8（间歇混沌，无静息态背景，自发发放率 chaos≈0.5–0.78）
- 输入模式 X（16 神经元）、行为模式 B（16 神经元）；预学习 X→B 单向边（w_pre≈66）
- **行为** = 注入 X 后响应窗口内 B 组 ≥BM=8 个神经元同时发放
- 三组对照：奖励（行为达标 → 标记活跃 X→B 资格迹 + `release_da(+0.3)`）、惩罚（同 +`release_da(−0.3)`，×3 系数）、中性（零改动）

### 1.2 反直觉观测（v2.1 协议：干预期 learn_gate=True）

| 观测点 | 奖励组（seed 43/44） | 预期 |
|---|---|---|
| X→B 权重和 w | 66 → **1514**（暴涨 23 倍） | 应上涨 |
| 测试期行为频率 f16 | **0%**（完全不达标） | 应升至高位 |
| B 组发放神经元数 | 4–6 个（< 阈值 8） | ≥8 |
| 奖励发放 | 停发（行为不达标 → 无奖励） | 持续 |

奖励把 X→B 边权重喂到了接近饱和，行为却从"能发生"变成"永不发生"——**强化与行为表现呈反向关系**，违反 E6 主实验的正向结论（learn_gate=False 时奖励组 f16=100%）。

## 二、插桩证据链：坍缩的三个阶段

定位脚本 `_tmp_diag_e6d.py`（seed 44）在 P2 干预期与 P3 测试期逐周期插桩四个指标：

- `w_sum()`：X→B 全边权重和（量化强化总量）
- `marks`：资格迹标记次数（量化奖励兑现频率）
- `fatB`：B 组神经元疲劳均值（`ng.fat`，量化发放后的疲劳积累）
- `nb_si0 / nb_si1`：P3 每周期注入后 B 组实际发放神经元数（量化行为维度）

### 阶段 1：强化集中（P2 早期，c1–c25）

奖励每周期"行为达标 → 标记**全部有边**的 X→B 配对 + 兑现"。由于 WTA 竞争下先发、高膜电位（v）的 B 神经元重复赢得竞争，**资格迹每次标记的都是同一批神经元**——奖励没有均匀分摊到 16 个 B 神经元，而是反复喂给少数赢家。`fatB` 升高、权重向赢家集中。

### 阶段 2：权重垄断与发放维度坍缩（P2 中后期）

赢家神经元权重冲向 w_max=16.0 饱和；非赢家边得不到强化（资格迹只标记活跃配对）。同时 `learn_gate=True` 使 Hebbian **使用增强**（共同发放即 +η）叠加在资格迹兑现之上——赢家越发放、边越强、越容易再发放，构成**双重自增强正反馈**。结果：B 组内部从"16 个神经元协同发放"坍缩为"少数赢家垄断发放"。

### 阶段 3：阈值失配与永久死锁（P3 测试期）

WTA 全局竞争（K=8）与噪声竞争下，被垄断后的 B 组每次只能唤起 **4–6 个**发放神经元，**恒低于行为阈值 BM=8** → 行为永不达标 → 奖励停发 → 无新强化 → 无恢复路径 → **永久死锁**。插桩实测：P3 逐周期 nb_si1∈{4,5,6}，f16=0%。

### 证据链完整性说明

- 现象复现：seed 43/44 两个种子独立出现（`[PLAN]-E6` 第四章根因③）；
- 定位复现：`_tmp_diag_e6d.py` 按正式协议在 seed 44 上完整重放 P1→P2→P3，逐周期插桩复现三个阶段的全部现象；
- 反证：同一网络参数下，把干预改为 `learn_gate=False`（仅走资格迹兑现、无 Hebbian 使用增强），3 seeds 探针即稳定，5 seeds 正式全过（reward f16=100.0±0.0，w 66→~1900）——**坍缩不是奖励本身的必然结果，而是"使用增强 × 奖励兑现"叠加的产物**。

## 三、机制归因：双重强化叠加的强者愈强回路

```
行为达标 → ① Hebbian 使用增强（learn_gate=True：共同发放对 +η）
            ② 资格迹兑现（release_da：Δw = DA × e）
         → 同一批赢家 B 神经元双重增权（w → w_max 饱和）
         → WTA 竞争进一步偏向赢家（强者愈强）
         → B 组发放维度坍缩（16 → 4–6）
         → 行为阈值失配（< BM=8）
         → 奖励停发 → 无恢复信号 → 永久死锁
```

- **Hebbian 使用增强**（①）是无监督的、自发的：只要神经元发放就写边，与奖励意图无关；
- **资格迹兑现**（②）是奖励驱动的、定向的：只标记本次活跃配对；
- 二者叠加时，①为②反复提供"同一批赢家"，②为①反复兑现"更强权重"，形成**无外部分流的正反馈回路**——这是马太坍缩的必要条件。
- 阈值化（BM=8）不是坍缩的原因，而是**放大器与锁存器**：把"发放维度下降"从渐变（4–6 个仍可被观察到）转译为"行为事件的有/无"（<8 即 0），从而切断唯一的奖励信号。

## 四、与 neural collapse 的对比（Papyan, Han & Donoho, 2021, PNAS）

Neural collapse（NC）刻画深度分类网络**训练终期**（训练误差归零后继续压 loss）出现的四重几何收敛：NC1 类内表示方差坍缩至类均值、NC2 类均值收敛至 simplex 等角紧框架（ETF）、NC3 分类器与类均值对齐、NC4 分类行为退化为最近类中心规则。

| 维度 | Neural Collapse（NC） | 马太坍缩（本文） |
|---|---|---|
| 驱动信号 | 全局梯度下降（最小化交叉熵） | **无梯度**：局部 Hebbian 使用增强 × 奖励资格迹兑现 |
| 发生阶段 | 训练终期（error=0 后继续压 loss） | 强化后期（行为已达标后继续强化） |
| 坍缩对象 | 类内表示方差（NC1） | **行为组发放维度**（16 → 4–6，跌破检测阈值） |
| 坍缩的几何 | 收敛到 simplex ETF（**保序、最大等角分离**） | 收敛到少数赢家垄断（**聚集、无序、失去多样性**） |
| 类间关系 | 类均值最大化分离（NC2） | 无类间概念（单行为类内坍缩） |
| 后果 | 结构化，与泛化/鲁棒性提升相关 | **病态死锁**，功能丧失 |
| 可分离性 | 是损失函数的隐式偏置，训练过程难以"关掉" | **可由 learn_gate 独立开关**（隔离自增强回路即消除） |

**对照的要点**：

1. **坍缩不是梯度方法的专利**。NC 长期被视为深度网络特有的隐式正则效应（与梯度流、损失景观相关）。马太坍缩证明：仅靠**局部可塑性 + 奖励**（无任何全局梯度信号），同样能自发产生"多样性坍缩"式收敛——"坍缩类现象"可能是学习动力学的一般特征，而非梯度方法的特例。这是本发现在理论层面的主要增量。
2. **同一"坍缩"词下是两种相反结局**。NC 的坍缩伴随类间最大分离（有序）；马太坍缩的坍缩伴随多样性彻底丧失（无序、死锁）。对照说明：坍缩的方向（保序 vs 失序）由**驱动信号是否携带类别区分信息**决定——梯度携带全局类别结构（→ETF），局部奖励只携带"这一行为好"（→垄断）。
3. **自增强回路可分离性**。NC 无法从训练中简单移除；马太坍缩的触发回路（Hebbian 使用增强）可以独立关闭——这为 SNN 奖惩学习提供了一条具体的防坍缩干预原则（见 §六）。

## 五、与 RL 已知现象的定位（诚实归因）

必须诚实说明：**"奖励导致行为多样性丧失"并非全新现象**。RL 文献中 policy collapse（策略坍缩）、过度开发（over-exploitation）、reward hacking 等记录了同族现象。马太坍缩的增量不在"现象是否存在"，而在三点：

1. **域**：发生在**无梯度 SNN 奖惩学习**（局部 STDP/Hebbian + 资格迹）这一具体机制域，此前 SNN 文献对"奖励驱动的 WTA 垄断死锁"缺少此类逐周期插桩记录；
2. **机制**：插桩证据链定位出**"使用增强 × 资格迹兑现"双重强化的具体叠加路径**，并指明 w_max 饱和与 WTA 全局竞争是权重集中到发放维度坍缩的传递环节——这是机制级归因，而非现象级描述；
3. **干预**：learn_gate 隔离实验给出"自增强回路是可分离模块"的实证，对应"奖励必须与无监督增强解耦"的设计原则。

论文表述中不将马太坍缩表述为"新发现的 RL 原理"，而是定位为**该机制域中一个此前未记录、证据链完整的失效模式**。

## 六、修复与设计原则（对 SNN RL 的实操含义）

- **修复**：干预期保持 `learn_gate=False`，只走 `release_da` 资格迹兑现（单向、定向、无自增强）→ 3 seeds 探针稳定、5 seeds 正式全过；
- **原则 1（解耦）**：奖励兑现与无监督可塑性（Hebbian 使用增强）必须分时或分路径隔离，否则奖励会"顺路"放大自发的不平衡；
- **原则 2（阈值安全边际）**：行为检测阈值不得与 WTA 发放上限同量级（此处 BM=8 与 WTA_K=8 无余量）——发放维度受 WTA 天然压缩时，阈值应留有裕度或随权重分布自适应；
- **原则 3（多样性哨兵）**：在强化回路中监测"行为组内发放维度 / 权重基尼系数"，作为坍缩预警指标（本实验事后插桩表明该指标在死锁前已明显劣化）。

## 七、论文定位与贡献陈述（本小节在形态 C 框架中的角色）

形态 C = E6 正结果（§5.1，定向调节 5/5 seeds，d=+6.68/−2.60）+ **本小节（马太坍缩）** + D1–D4 判别（§5.3）。本小节的贡献陈述建议：

1. **实证**：报告一个无梯度 SNN 奖惩学习中证据链完整的失效模式——奖励驱动、双重强化、WTA 放大、阈值锁存、永久死锁；
2. **理论对照**：与 neural collapse 的对照表明"多样性坍缩"不是梯度方法专利，但坍缩方向由驱动信号的信息结构决定；
3. **方法论副产物**：该坍缩的定位与修复过程本身就是 E6 正结果可信度的一部分——它解释了为什么正式协议必须隔离 Hebbian 自增强，从而排除"奖励效果来自代码后门"的质疑。

**诚实边界（论文须保留）**：
- 现象仅在两种子（43/44）+ 单插桩种子（44）上完整记录，未做系统种子扫描的"坍缩发生率"统计；
- 正式协议（learn_gate=False）下该现象被规避，因此不污染 E6 正结果；论文中它属于方法学发现而非主结果；
- "使用增强 × 资格迹兑现"的双重强化归因有插桩支持，但未做消融（如仅保留其一）的逐因子实验——该消融可作为后续工作列出。
