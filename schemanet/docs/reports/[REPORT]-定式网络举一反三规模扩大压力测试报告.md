# [WIP] 定式网络举一反三规模扩大压力测试报告

> 日期：2026-08-10 | 状态：[WIP]（发现两个机制缺口，未完全通过）| 关联：v2.2 §12.6b、`_rl_gate_scale.py`
> 需求（用户 2026-08-10）：继续，扩大规模。

---

## 一、背景与目标

泛化压力测试（40 词）证明机制成立。本报告把规模扩大三个数量级（100→300→1000 词），并引入两个真实语义网要素：**噪声干扰**（词表里必然有大量无关关联）和**共享 hub**（真实词被多条链共享，如"水"同时连接多个概念）。回答：规模本身会不会稀释模板？噪声和共享结构会不会带偏走链？

## 二、实验设计

| 测试 | 内容 | 验证点 |
|---|---|---|
| S1 | 100 词 / 20 独立链 × 5 词 | 规模 100 |
| S2 | 300 词 / 60 独立链 × 5 词 | 规模 300 |
| S3 | 1000 词 / 200 独立链 × 5 词 | 规模 1000 |
| S4 | 300 词独立链 + 297 对随机噪声词（噪声 1 轮 vs 链内 3 轮） | 噪声不把推理带偏 |
| S5 | 共享 hub：A1→X→B1、A2→X→B2（X 被两条链共享，分支等权） | 共享中间项可复用 + 分支竞争 |
| S6 | 同 S5 结构，B1 学 3 轮、B2 学 1 轮（权重不对称） | 权重差能否区分分支 |

## 三、结果

```
[S1] 100 词 / 20 链 → 推理走通 100.0%（20/20），联想过冲 0 条
[S2] 300 词 / 60 链 → 推理走通 100.0%（60/60），联想过冲 0 条
[S3] 1000 词 / 200 链 → 推理走通 100.0%（200/200），联想过冲 0 条
[S4] 300 词 + 297 随机噪声 → 推理走通 100.0%（60/60），联想过冲 57 条
[S5] A1 → X → B1 ✅ 走对分支；A2 → X → A1 ❌ 分支竞争
[S6] A1 → X → B1 ✅；A2 → X → A1 ❌（目标弱分支 B2 不可达）
```

## 四、结论

### 规模本身不是问题 ✅

100→300→1000 词，模板零稀释，推理 100% 走通，训练时间 0.2s→1.9s 线性增长。噪声下推理也 100% 走通（链内 3 轮强度压过噪声 1 轮）。

### 但暴露两个真实机制缺口 ❌

**缺口①：终止信号缺失（S4）**
噪声下推理能走通，但 57/60 条在到达链尾后**继续沿噪声连接蔓延**——联想引擎没有"该停了"的信号。已固化的直连保证"该去的地方去得到"，但没保证"不该去的地方不去"。

- 认知对应：人不可能无限联想下去，推理有结论点（"所以流动是液体"之后不会继续想到"液体能淹死人"才停）
- 哲学呼应：用户"AI 要慢下来"——联想必须能收敛，而不是发散蔓延
- 与验证门的关系：验证门管"该不该固化"（学不学），终止信号管"该不该停"（说不说）——两个不同的闸门

**缺口②：上下文调制缺失（S5/S6）**
贪心走链只看"当前词最强传出突触"，不知道"从哪来"。A2→X 后 X 的 B1/B2 等权，无法按来源分叉。S6 更极端：权重不对称时，所有路径都聚到强分支 B1，目标弱分支 B2 永远到不了。

- 认知对应：人做推理会记住起点（"流动的是水，所以流动的是液体"——知道主语是流动），上下文调制选择
- 正是用户之前讨论的"工作记忆"缺口：多步推理需要暂存起点，用上下文调制每一步的选择
- 这也是"指令模式调制行为模式"讨论的延伸：选择不是只看当前刺激，还要看来源/指令

## 五、修复方向（待定）

| 缺口 | 候选机制 | 备注 |
|---|---|---|
| 终止信号 | 结论确认（输出首尾直连成立即停）/ 走链步数上限 / 验证门联动 | 待与用户对齐 |
| 上下文调制 | 走链携带起点（工作记忆），分支选择加"来源一致性"偏置 | 需新机制，与多步/工作记忆讨论衔接 |
