## 一、实验背景与目标

**方向**：定式网络（SchemaNet）自主进化路线（用户决策：不走吞并，定式网络自己成为大模型）。Phase 0 已验证 W 聚合读出 ≈ bigram（0.500 vs 0.526）——STDP 已把语料词序沉淀进 W，但读出只用了**末词**（一元条件），上下文信息（更早的词）被丢弃。

**Phase 1 目标**：把读出从"一元"升级到**多词条件转移**（trigram+ 级）——给定前缀 `w_1..w_{t-1}` 预测 `w_t` 时利用整条前缀，而不是只看末词。约束：**不增加额外学习**（W 保持二元转移不变），在读出层用已有机制（`pre_trace` 痕迹）完成上下文混合——这是"零结构成本"的上下文升级，也是 LLM 注意力混合历史 token 信息的最小雏形。

## 二、实验设计

```
W（Phase 0 已沉淀，二元转移） ── 保持不变 ──┐
                                             ▼
前缀注入 → pre_trace（痕迹衰减 0.5，跨步保留）→ 条件概率混合读出
  P(w_t | w_1..w_{t-1}) = P(w_t | 末词)          末词已决定（top1-top2 差 ≥ delta_off）
                        = Σ_i wgt_i · P(w_t | w_i) 末词平局（backing-off 借整条前缀）
  P(w_t | w_i) = W[w_t ← w_i] / outsum[w_i]     源词传出突触归一化 = 条件转移概率
  wgt_i = trace_i / trace_末词，非末词再 × β=0.1  痕迹权重（相邻 0.5 / 隔一 0.125 / 隔二 0.031…）
```

### 2.1 参数

| 参数 | 值 | 说明 |
|---|---|---|
| n / k / 词表 | 2048 / 8 / 142 | 沿用 Phase 0（Phase 2 再扩规模） |
| trace 来源 | `pre_trace` | 既有机制，trace_decay=0.5 |
| delta_off | 0.05 | backing-off 判定：top1-top2 差小于此 → 视为平局 |
| β | 0.1 | 非末词痕迹权重压降 |
| 评估口径 | 与 Phase 0 相同 | top-1 准确率，训练集重建 + 留出句泛化 |
| 对照 | wsum（Phase 0）/ bigram / trigram | 同测试集同口径 |

### 2.2 验证手段

1. **主实验**：trace vs wsum vs bigram vs trigram 四表对照
2. **二元消歧样例**：`我觉得→很` 等（与 wsum 一致性检查）
3. **微语料破局验证**（机制确认）：构造 `"我很累"+"我很忙"+"昨天很忙"` → 前缀 `[昨天, 很]`，`很` 的后继是 1:1 精确平局（累/忙各 1 次），一元读出选不出；`W[忙←昨天]=0.0625` 直接转移 → trace 应借 `昨天` 破局 → 忙
4. **回归**：abc 静态实验 9/9 全绿（确认 trace 改动不破坏既有机制）

## 三、机制细节与三个关键坑

实现（`schema_net.py`）：新增 `_predict_cands_trace(ng, prefix, pats, vocab, slot=0)`；`_evaluate_schemanet` 加 `readout="trace"` 分支；lang 报告加 trace 行；留出测试集保持与 Phase 0 相同的随机划分（seed+9000）。

调试中定位三个坑（技术档案 6.11）：

1. **无归一化 → 高频词痕迹淹没决定**：直接用 `Σ trace × W` 混合时，"我"痕迹 0.125 × W[喜欢←我]=48 → 6.0，压过"觉得"直接后继"很"（0.5 × 4 = 2.0）。必须 `÷ outsum` 源词传出突触，让各源词的条件概率同尺度混合。
2. **β 压降不足 → 高频词微增量翻转精确平局（对错各半，净负）**：β=0.1 后"我很"→高兴 仍被"我"高频后继"喜欢"翻转（0.16×0.05≈0.008 > 平局差 0）。**精确平局下任何非末词正增量都会翻转**——主语料 100 句里"很"后 10 个后继各 1 次，无统计答案。
3. **解法 = backing-off 条件混合（delta_off）**：末词已决定 → 只用末词（非平局零退化）；末词平局 → 才借整条前缀破局。微语料验证机制 ✓，主语料净效应 = 非平局不损失 + 平局处破局。
4. **破平局需要"非末词→候选词"的直接转移**：`W[很←我]=0`（"我→很"从未直接相邻）→ "我觉得"→很 破不了"觉得"的后继平局；但 micro 里 `W[忙←昨天]` 存在（"昨天很忙"直接相邻）→ 能破局。W 是二元转移，上下文词必须直接连到候选词才有信号。

## 四、结果

### 4.1 主实验（训练 80 / 留出 20）

| 模型 | 训练集 | 留出句 | 说明 |
|---|---|---|---|
| bigram | 0.526 | 0.087 | n-gram 基线上限 |
| wsum（Phase 0） | 0.500 | 0.087 | 一元读出，= trace 的"非平局路径" |
| **trace（上下文）** | **0.474** | 0.087 | backing-off：非平局零退化 + 平局处破局 |
| trigram | 0.383 | 0.000 | 数据稀疏 |

trace 训练集 0.474 较纯 wsum 0.500 略低——因为平局位置借上下文后 5 例误翻转（对错各半的噪声）+ 2 例正确破局；**非平局位置零退化**（11 例误翻转 → 5 例，全部来自平局处）。

### 4.2 破局机制验证（微语料）

| 样例 | 输入前缀 | 一元读出 | trace 读出 | 判定 |
|---|---|---|---|---|
| 构造破平局 | [昨天, 很] | 累/忙 平局 | **忙** ✓ | 机制确认（W[忙←昨天]=0.0625 直接转移） |
| 消歧 | 我喜欢吃 | 平局（15 宾语） | **苹果** ✓ | 真实语料破局 |
| 一致性 | 我觉得 | 很 ✓ | 很 ✓ | 与 wsum 一致 |

### 4.3 回归

`--mode abc` 静态实验 9/9 归属正确——trace 改动只在读出层，不触碰学习路径。

## 五、结论

1. **机制验证通过**：痕迹插值（条件概率混合 + backing-off）把读出从一元升级到多词条件转移，W 零改动、零额外学习——"零结构成本的上下文升级"成立
2. **破平局需要直接转移**：上下文词必须与候选词直接相邻过（W 二元转移的固有属性），微语料与"我喜欢吃→苹果"均确认
3. **主语料增益受统计密度限制**：100 句里平局处无统计答案，任何信息都只能对错各半——这是数据限制不是机制缺陷，**Phase 2 大数据验收**（平局被统计密度消解后，trace 增益应转正）
4. **定位**：trace = LLM 注意力混合历史 token 的最小雏形（Jelinek-Mercer 插值平滑的神经实现），是自主进化路线"上下文支柱"的第一块台阶
