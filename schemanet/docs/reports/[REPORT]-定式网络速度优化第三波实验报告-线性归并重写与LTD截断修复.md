# [REPORT] 定式网络速度优化第三波实验报告（线性归并重写 + LTD 新键截断修复 + gain 持久化）

> 日期：2026-08-10 | 状态：[OK] | 版本：接第二波（2.6×）之后；合并内核重写 O((n+m)log)→O(n+m)，训练提速 2.6×→3.2×；顺带修复 stdp_neg>0 潜伏语义 bug、补 gain 数组持久化、量化 edge_min 唤起杠杆

## 一、背景与需求

第二波落地后 `_apply_edge_updates`（Hebbian/STDP 批量合并）成为训练路径残剩热点。本轮：

1. 拆解 `_apply_edge_updates` 内部成本 → 重写合并内核；
2. 对拍验证（主对拍 + 分支专项对拍，含 stdp_neg>0 组合）；
3. 顺带：`gain` 数组持久化、edge_min 唤起基准（量化唤起提速主杠杆）。

## 二、诊断：`_merge_rows` 内核自身占 apply 87%

逐段计时（40 发放步，每步 top=20，含高频词大行）：

| 段 | 实测 | 占比 |
|---|---|---|
| `_merge_rows`（numba） | **16.47ms/次** | 87.4% |
| concat（4 次拼接） | 1.56ms | 8.3% |
| copy_back（逐行 np.copy） | 0.78ms | 4.2% |
| flatten 循环 | 0.03ms | 0.2% |

根因：高频词（"的"传出突触 41,603 条）发放时 Hebbian 触碰其 4 万+ 大行，旧内核每发放步做 **searchsorted×m + argsort O((n+m)log)** 全量重排——大行成本被对数复杂度放大。

## 三、改造清单（sparse_net.py / snapshot.py，2026-08-10）

| # | 位置 | 改造 | 语义 |
|---|---|---|---|
| 1 | `_merge_rows` | searchsorted×m + argsort → **线性双指针归并** O(n+m)，输出直接写 out 缓冲（免逐行临时数组）；keys 行内先 argsort（m≤380 开销可忽略，大行成本由 n 主导） | = batch_update（存在键累加 + [clip_low, w_max] 截断，新键插入，有序保持） |
| 2 | `_merge_rows` 新键分支 | 新键插入也做 [clip_low, w_max] 截断（**潜伏 bug 修复**：原实现原样写 dlt，stdp_neg>0 时写入负权重；参考实现写入 max(0, -stdp_neg)=0。v13.0 对拍未触发因 stdp_neg=0） | = 参考实现 |
| 3 | `snapshot.py` | `gain` 数组入 `_pack_net`/`_restore_net`（此前不入快照，载后丢失；旧快照无此字段 → 默认全 1 向后兼容） | 持久化 |

## 四、踩坑：keys 非升序假设 → 对拍抓出 159,673 边分叉

第一版线性归并假设 keys 按神经元号升序（`top_arr=np.where(...)` 确实是升序）——**但实际 WTA top 是 `candidates[argsort(key)[::-1]]` 按 vmax×gain 降序**，Hebbian/STDP 的 keys 并非升序！对拍立即分叉（差异 159,673 边），行内先 `np.argsort(keys)` 后修复为 0 差异。教训：**内核前置条件必须来自生产调用点而非测试脚本**（测试里手造的 top_arr 是升序，掩盖了真实调用序）。

## 六、edge_min 唤起基准（唤起提速主杠杆量化）

v13.0 冻结态唤起（learn_gate=False，3 步），edge_min ∈ {0, 0.5, 1.0, 2.0}：

| edge_min | 弱突触剪除率（我/的/了/想要） | 唤起 ms/次 | 平均发放 |
|---|---|---|---|
| 0.0（现状） | 0% | 105.6 | 50 |
| 0.5 | 66–84% | 45.6–48.8 | 49–50 |
| 1.0 | 86–97% | 36.9–45.0 | 50 |
| 2.0 | — | 37.9–39.7 | 49–51 |

**结论：edge_min∈[0.5, 2.0] 唤起 105.6 → 37–49ms（≈2.5×），且发放集合不变（~50 神经元）**——弱突触本就是噪声，修剪不改变检索动力学。机制已在工作区代码实现（`sparse_net.py`），v13.0 快照未启用（其参数为 edge_min=0）；新版本快照（参数持久化修复后）可开启。
