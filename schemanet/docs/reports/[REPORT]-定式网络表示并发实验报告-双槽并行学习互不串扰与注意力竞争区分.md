## 一、背景与假设

**问题**：定式网络有并发学习能力吗？理论分三层——计算并发（批量 Hebbian，已实现）、表示并发（多槽，机制在流程未用）、在线并发（增量成长，已实现）。本实验验证**表示并发**。

**假设**：
- 槽位 = 表示通道：槽0 学 A 组"我吃苹果"、槽1 学 B 组"他看家"，两组边落在各自槽位的 `W[*][k]`（Hebbian/STDP 用每神经元主导槽 k_star 分桶）→ 各自建立、互不串扰；
- 对照：两组同槽（槽0）交替学习 → 对比槽位隔离的作用。

**方法**：真实快照 v13.0 增量试验（不动主网络结构语义），`_learn_sentence` 教学式（STDP 相邻转移 + 传播回响 Hebbian），每组 5 轮。

## 三、结论

1. **表示并发成立**：双槽并行学习两组不相关词对，两组定式各自建立、**交叉串扰边全部为 0**（他→吃 = 0、我→看 / 我→苹果 不变）——槽位隔离是表示并发的机制。
2. **并发槽学习更强**：B 组"他→看"在干净槽1 学到 110.4，同槽对照仅 40（≈2.8 倍）；"看→家"槽1=123.2 vs 槽0=56（≈2.2 倍）——**槽位隔离降低竞争，强化路径稳定**。
3. **唤起失败 ≠ 学习失败**：A 组"我→吃"边已建立（80.0），但注入"我"唤起"吃"失败（0.00）——这是注意力竞争问题，不是学习问题。

## 四、附带发现：注意力理论活体实证

"我→吃"边（80.0）存在却唤起失败，根因是**"我"的 fan-out 极大**（v13 中"我"出边 1.7 万+）→ 注入"我"后传播驱动海量候选 → "吃"被 WTA top16 **挤出**。而"他"出边少 → 竞争小 → 完整唤起。

这正是 §3.13 注意力公式的直接实证：

```
注意力（top-k 排序）= 竞争环境（注入词 fan-out 连接数量）× 边强度 + gain
"我" 注入 → 连接数量 1.7 万 → 竞争拥挤 → 吃（80.0）仍进不了 top16
"他" 注入 → 连接数量小 → 竞争清空 → 看/家 全链 1.00
```

**数量主导竞争环境，与强度无关**——80.0 的边强度救不了 1.7 万条出边带来的拥挤。这同时解释了对话教学里"我"类高频词的教学难度（v3 教学对"我"需要更多轮次）的机制根源。

## 五、诚实边界

1. **唤起读数的测量口径**：`_evoke_prefix` 的 fired 集合在间隔步后采集，注入词自身间隔步不再发放 → "自己"比例恒为 0（苹果 0.00 属测量方法，非异常）；
2. **"我→吃"唤起失败是竞争而非缺失**：需靠边强度区分（本实验已做）；若只读唤起会误判"并发不成立"（第一版判读的教训）；
3. 本实验增量修改了网络（加了 10 轮边）——**快照 v13.0 未被覆盖**（实验在内存中，结果仅存 json），不影响主链；
4. 双槽"并发"为交替学习（同一学习期两组经历并行积累），非严格同拍双注入（step 单槽注入设计如此）——槽位隔离在机制上等价，严格同拍为未来可选验证。

## 六、理论意义与后续

- **并发三层统一**：计算并发（批量 Hebbian）+ 表示并发（槽位隔离，本实验验证）+ 在线并发（增量成长）——定式网络具备梯度网络没有的"感知并行、学习并发、注意力串行"结构；
- **注意力理论实证升级**：本实验为"连接数量 × 边强度"提供了独立于判别实验的第二次活体证据（唤起失败 vs 边存在）；
- **后续**：可补严格同拍双槽注入（改 step 支持多槽脉冲）验证；可把"表示并发"补进理论 § 核心机制；槽位隔离可用于多任务并行教学（不同槽学不同领域的定式，互不污染）。
