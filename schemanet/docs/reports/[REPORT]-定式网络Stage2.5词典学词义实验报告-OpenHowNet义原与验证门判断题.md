# 定式网络 Stage 2.5 词典学词义实验报告（OpenHowNet 义原 + RL 验证门判断题）

> 日期：2026-08-10 | 状态：[OK] | 版本：v2.4 成长路线 Stage 2.5 落地（快照 v8.5）

## 一、背景与需求

成长路线"先学字、再学词、再学句"在 Stage 2（句级，v7.0）之后缺失"语义角色层"。用户诊断——**"词有了、词义没有"**：词形复述 1.0（模式已固化），但同类词在 stage2_sents 中几乎不同句共现（探测：食物仅 {蔬菜,猪肉} 一个 2 词块），词义（出边结构）孤立 → 举一反三无路可走。跟读（监督）只能焊"清单直连"，学不会词义。

**方案（v2.4 §2.5）**：改用**词典（OpenHowNet 义原）+ RL 验证门**——词义 = 词↔义原关联集合（出边结构），每条词↔义原关系 = 一道判断题："对"→验证门固化（Hebbian 共发放）、"错"→拒绝固化（不焊死）。

**验收硬指标**（§四 Stage 2.5）：
1. 类别归属（训练词→标签义原直连）≥ 0.9
2. 词义举一反三（hold-out 词→本类信号占优）≥ 50%
3. 替换造句（"我要"→食物类词唤起，类别约束的槽位填充雏形）
4. 字/词/句全链零遗忘（Stage 0-2 不回退）

## 二、实验设计

**起点**：加载 v7.0（句级续训链最新，n=148140，模式 37035：字 + 词 + 句级新词）。

**数据**：`data/curriculum/stage25_sememes.json`（OpenHowNet 义原离线抽取留档，2026-08-10）——覆盖 v7.0 词表 16776/31819 词（**52.7%**）、1837 义原去重、48635 条词↔义原边。过滤规则：纯汉字注释、长度 1-4 字、跳过虚词停用（的/了/是…）。

**流程**（[_grow_cat.py](file:///e:/杂项/BNOS_AI_project/schemanet/_grow_cat.py) v3）：

```
load_version("7.0")                     # 句级起点（字词句记忆全含）
  → 读 stage25_sememes.json（词→义原判断题数据）
  → 类别构造：训练成员（人工词表 ∩ 词典，义原须含本类标签）
              hold-out（词典自动发现，与成员共享义原）
  → 义原/标签模式分配（游标续用自动扩容，116 新模式）
  → baseline（字/词/句复述 = 零遗忘基准）
  → 验证门判断题训练：
      正例 198 边 × 5 轮（w 的每个词典义原 → 固化）
      负例 54 条（随机他类标签 → 拒绝固化）
      hold-out 只训"与成员共享的义原"（类别判断 hold-out）
  → 验收①②③④ → save_snapshot(parent="7.0") → v8.5
```

## 四、数据实测暴露与修正（2026-08-10）

HowNet 数据真实性高于方案预期假设，冒烟→全量迭代修正 4 处：

1. **HowNet 类别义原与日常类别词错位**：义原"动物"标的是"下巴/世故/一群"这类词（义原语义域宽），"颜色"只标"底色/素色"类，日常词"猫/红"反而未覆盖 → 标签义原组按**人工词表词的义原**扩组（食物+食品/蔬菜、动物+牲畜/走兽/虫、颜色+单字色名、地点+设施/房间）。
2. **动作类（吃/跑/跳…）HowNet 覆盖 0**：OpenHowNet 对常用动词标注缺失（24 词人工动作词表全无义原）→ 本阶段诚实跳过动作类（6 类变 5 类），词性标注后补（§2.5 诚实边界③）。
3. **成员筛选须"义原含本类标签"**：全量 v8.4 时间类 0.8333——"后来/最近"的义原为"将来/新近"（无"时间"标签），被误选为训练成员但类别边缺失 → 筛选条件加严后 v8.5 全类 1.0。
4. **大网络虚词劫持**：走链"我"被"的"(256 权重)、"要"被"为什么"(256) 劫持，单链走链失效 → 验收③改用**出边直读聚合**（与验收②同构），不走 WTA 传播（传播信号同样被竞争连接截断，v1 已证）。

**诚实边界复核**：① 感知属性（甜/圆/红）HowNet 不标注，留待 Stage 4 Wiki 定义句补充——本次"红色"义原实测为 ['先进','红']（象征义），印证该边界；② 52.7% 覆盖率 = 数字/专名/新词无词义边，是"真不知道"自然样本；③ 多义原词取并集（苹果→电脑 为品牌义项，真实标注，多通道不拒收）。

## 五、性能观察（为后续优化留档）

- 总耗时 204s（全量）：加载快照 + baseline/after 复述（300 词 + 100 句 × run_recall）+ 训练 12s + 验收。
- 训练本身仅 12s（198 边 × 5 轮共发放，走 run_train 快路径）；大头是复述评估（句复述 run_recall 传播 100 句 × 2 次）。
- n 仅增长 464（148140 → 148604，116 义原模式），词义层知识密度高。

## 六、结论

1. **词义建立（出边结构）**：词↔义原边经验证门固化，词义 = 经验证门确认的出边集合——"词有了、词义没有"的诊断补齐（v8.5）
2. **类别举一反三成立**：15/15 hold-out 凭共享义原走链唤起本类信号（他类信号 0），词义结构而非记忆
3. **验证门拒绝生效**：54/54 负例不焊死，防认知偏差固化
4. **零遗忘保持**：字/词/句逐值不回退，增量分配 + 续训闭环第三次验证
5. **数据边界诚实记录**：动作类缺义原跳过、标签组扩组、感知属性留待 Stage 4
