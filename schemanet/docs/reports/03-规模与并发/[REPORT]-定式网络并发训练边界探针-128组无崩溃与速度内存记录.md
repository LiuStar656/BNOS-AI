# [REPORT] 定式网络并发训练边界探针：128 组无崩溃与速度/内存记录

> 日期：2026-08-10 | 状态：[OK] | 前置：[REPORT]-定式网络并发训练边界探针-64组无崩溃与崩溃维度分析.md（本文为 64→128 扩展 + 首次记录速度与内存）

## 一、背景与目标

64 组探针已证明：教学式学习下并发量 G∈{1..64} 全组 100% 无崩溃，崩溃边界不在并发量维度。本实验：

1. **把并发量推到 128**——确认无崩溃结论是否在更大并发量下成立
2. **首次记录速度与内存**——量化"槽位代价线性"的资源账单（学习耗时、RSS 占用）
3. **对比同槽 vs 4 槽轮转**——槽位隔离在不同并发量下的表现

## 二、实验设计

| 参数 | 值 |
|---|---|
| 快照 | v13.0（n=148776，模式 37062） |
| 并发组数 G | 同槽 {1,2,4,8,16,32,64,128}；轮转 {4,8,16,32,64,128}（14 个并发点） |
| 每组教学 | 10 轮（_learn_sentence 教学式，同槽全 slot=0 / 轮转 slot = 组号 mod 4） |
| 崩溃判定 | 唤起成功率 < 0.5，或激活规模爆炸（超临界迹象） |
| 串扰测量 | 抽样 8 组（O(G×k) 替代 O(G²)） |
| 词对筛选 | 128 组初始不相关词对（基线唤起 < 0.3），随机采样 |
| 并行 | ProcessPoolExecutor 8 workers，每点独立进程测干净 RSS，边算边保存 |
| 指标 | success_rate / mean_evoke / max_cross / mean_scale / learn_sec / total_sec / rss_loaded_mb / rss_delta_mb |

## 四、判读

1. **128 组并发学习 100% 成立**：同槽与轮转成功率全 1.00、均唤起全 1.00——**崩溃点仍未达到**（崩溃前最大 G = 128）
2. **激活规模恒 84，无超临界迹象**：84 = 单句模式规模常量，128 组并发未触发激活爆炸（对照石头痛觉超临界诊断 156→46671 的指数膨胀）
3. **学习耗时近线性**：G 翻倍耗时近似翻倍（32→58.5 / 64→116.9 / 128→213.3，倍率 1.99×/2.0×/1.82×）≈ **1.67 秒/组**（10 轮）——并发代价线性，无超线性拐点
4. **内存账单**：加载成本固定 314MB（干净快照）；学习净增量（学习后−加载后）G=128 = 88MB ≈ **0.69MB/组**——槽位代价线性，与"slots 无硬上限、代价线性增长"理论一致
5. **同槽零串扰，轮转出现轻微串扰**：轮转 4 槽下每组 32 组共槽（128/4），G≥32 出现 0.25 串扰——槽位资源复用产生的轻度痕迹混杂，但**唤起仍 1.00、成功仍 1.00**，量级无害
6. **轮转均激活（67-72）< 同槽（84）**：4 槽分桶后每槽共享活跃集更小，符合槽位隔离的传播稀释

## 五、结论

- **并发量不是崩溃维度**（二次确认，64→128 双倍压力仍 100%）：教学式学习的"干净注入"（每句清 v/spikes/pre_trace）让并发组之间互不污染，并发量增大只是线性叠加，不触发崩溃
- **槽位代价线性，可水平扩展**：128 组并发学习仅需 213 秒 + 367MB，且每个并发点相互独立（可多进程并行）
- **崩溃真正维度（待验）**：A hub 竞争环境（注入词 fan-out 爆炸）/ B 传播式学习（保留传播驱动的教学）/ C 长期边密度（突触数逼近结构收敛上限）——这三个维度才是并发崩溃候选，见下一步
