## 一、实验背景与目标

**方向**：定式网络（SchemaNet）自主进化路线。有偏语料验证（b 阶段）已闭环：grad 增益 +0.047 兑现、trace 定性为无参数启发式上限。但 b 阶段语料是**自建模板**（15100 句、句长 ~4、句式重复），生成人工流畅度仅 2.05/5，且梯度学到的东西受模板化限制。

本阶段目标（对应方案 v1.2 C 路线第二阶段）：
1. 构造**开源真实语料**（4 源混合：外卖/酒店/商品评论 + 头条标题），词表 3000、句数 2 万级、句长显著长于自建语料
2. 真实语料下三路（wsum/trace/grad）top-1 对照——验证长句分布下 trace/grad 是否还增益、生成质量是否随语料真实度改善
3. 20 条生成 + 人工评估（≥3/5 达标）
4. 回归（abc/seq）+ 留档

**过程**：c3 第一版暴露 grad 生成严重退化（信任过拟合极值），经根因分析 → 用户批准变体重跑（跳过 train_ctx、lr=0.02/5ep、均匀初值+归一化）→ 生成恢复。本报告记录完整闭环。

## 二、设计

### 2.1 开源语料构造（gen_corpus_open.py）

- 数据源：外卖（waimai_10k）、酒店（ChnSentiCorp）、商品（online_shopping_10_cats）、今日头条标题（toutiao-text-classfication-dataset），多镜像下载（jsdelivr 优先 + raw + ghproxy 兜底）
- 清洗：去 URL/@/#/emoji → jieba 分词 → 标点/长度过滤 [3,30] → 每源均衡抽样 6000 → 词表 3000（排除 UNK 后补足）→ OOV→`<UNK>`

**语料统计（与 corpus_biased 对照）**：

| 指标 | corpus_biased | corpus_open | 判定 |
|---|---|---|---|
| 句数 / 词表 | 15100 / 504 | **20263 / 3000** | ✓ 标准档 |
| 句长均值 | ~4 | **14.3** | ✓ 真实长句 |
| token 覆盖率 | — | 83.4% | UNK 16.6%（OOV） |
| 来源 | 自建模板 | 4 源真实评论/标题 | ✓ |

> 真实语料特性：长句、多动词链、无模板结构 → 句法信号与自建语料完全不同，是 trace/grad 增益与生成质量的关键变量。

### 2.2 评估提速（sparse_net.py，c3 前置项）

真实语料词表 3000 → 原 `_out_edges_accum` Python 传出突触字典循环（每位置 >100ms）不可行。新增：

- `build_score_mat(ng, pats, vocab, pats_mat)` → S[V,V]（V=3000 → 72MB float64），一次性构建后评估/扫描**纯 numpy 直读**（`S[:, src]` 即 score(w, src)）
- `evaluate_wsum_smat` / `evaluate_trace_smat`：S 版评估，读出 O(V) numpy；trace 保留动力学注入骨架（单句内 pre_trace 自然累积），只把逐源神经元 Python 传出突触循环换成 S 直读
- 对拍验证（`_check_smat.py`，小语料 n=2048/k=8）：S 版 vs 原版**逐位一致**（wsum 97/200、trace 91/200）——提速不改变语义

> trace 曾试纯模拟版（跳过 step() 直接累积 pre_trace）→ 对拍失败（91 vs 97）：空拍传播驱动 WTA 选出后继神经元，pre_trace 含一步转移动力学无法纯模拟，已删除该方案。

### 2.3 验收编排（_accept_open.py，标准档）

流程：Hebbian 预训练（16210 句）→ S 矩阵构建 → delta_off 自适应扫描（留出 150 句子集，{0.005, 0.01, 0.02}）→ 训练（v1：train_ctx 20ep → train_w 10ep/lr=0.05；变体：跳过 train_ctx → train_w 5ep/lr=0.02 + 归一化）→ 三路 top-1（训练 1000/留出 600 句同一子集）→ 20 条生成（前缀 = 训练句首词 top20）→ BLEU-2 → 回归（abc/seq 子进程）。

参数：n=8192, k=16, maxlen=8, top_k=12, T=1.1, penalty=2.5, GEN_MAX=10。

### 2.4 变体设计（v1 根因驱动的参数修正）

| 项 | c3 第一版 | 变体重跑 |
|---|---|---|
| train_ctx | 20ep 全量（1516s，训练的信任被 train_w 冲掉） | **跳过**（信任直接给 trace 等效均匀初值） |
| train_w lr | 0.05 | **0.02**（温和步长） |
| train_w epochs | 10 | **5**（防过冲） |
| ctx_wgt 初值 | train_ctx 结果 | **均匀初值**（末词 1 + 远端 0.05×0.5^i，trace 等效） |
| 归一化 | 无 | 训后 clip + **归一化**（防信任幅值失控） |

## 三、结果

### 3.1 c3 第一版（runs/20260809_085940）——信任极值，生成退化

- 信任分布（train_w 后）：**[0, 0, 0, 0, 0, 0, 0, 8.2953]**（全部推到最远端 pos7，无归一化）
- top-1 留出：wsum **0.1081** / trace 0.0867 / grad 0.0951（trace-wsum -0.021 / grad-wsum -0.013）
- **grad 生成全部仅 1 词**（`[很]→很`、`[酒店]→酒店`，20/20 退化）；BLEU-2 grad **0.000**
- W 结构不变 ✓（nnz 18093945）；扰动 max 8.2747、改 67% 连接；回归 abc/seq PASS ✓
- 训练耗时：Hebbian 389.1s + train_ctx 1516.2s + train_w 121.5s

**根因链（已定位）**：
```
信任全压 pos7 → 生成前缀短（1-4 词）时 pos7 不可用 → ctx_wgt[:Ln] 全 0
→ logits 全零 → generator._sample 无有效候选 → 生成立即停止
```

### 3.2 变体重跑（runs/20260809_093405）——信任恢复，生成恢复

- 信任分布（train_w 后，已归一化）：**[0.1546, 0.3439, 0.1177, 0, 0.1887, 0.0290, 0.0476, 0.1186]**——近端主导（pos1=0.34）、远端有残余（pos4=0.19），短前缀（1-2 词）也有可用信任
- top-1 留出：wsum **0.1081** / trace 0.0979 / grad 0.0764（trace-wsum -0.010 / grad-wsum -0.032）
- **grad 生成恢复完整句**（2-9 词）：`[很]→很方便<UNK>，。不就是好吃的！`、`[房间]→房间也很<UNK>不错，的不好吃！`、`[裤子]→裤子质量<UNK>很不错，。就是不的`——不再仅前缀 1 词
- BLEU-2：grad 0.010 / trace 0.003 / wsum 0.015
- W 结构不变 ✓（nnz 18093945）；扰动 max 2.0967、改 57% 连接（比 v1 温和）；回归 abc/seq PASS ✓
- 训练耗时：Hebbian 428.1s + **train_ctx 0s（跳过）** + train_w 74.2s

## 四、分析与结论

### 4.1 根因链闭环验证：信任极值 = 生成退化根因

变体用三处修正（均匀初值 + lr 0.05→0.02 + 5ep + 归一化）把信任从 `[0×7, 8.2953]` 拉回近端主导分布，grad 生成**立即恢复**（20/20 完整句）——实证了 v1 根因分析的正确性：**生成退化不是梯度机制失败，而是训练配置导致的信任过拟合**。配套结论：v1 的 grad 留出 top-1（0.0951）是过拟合假象——信任全压 pos7 恰好拟合了评估集中占多数的长前缀位置（语料均长 14.3），但生成从短前缀出发用不上；变体信任泛化后 top-1 回落至 0.0764。

### 4.2 真实语料下三路均不超 wsum：增益不成立

真实语料（词表 3000、句长 14.3、无模板）三路 top-1 全部显著低于有偏语料（wsum 0.108 vs 0.282），**grad -0.032 / trace -0.010 均未超 wsum**——与有偏语料 grad +0.047 相反。原因：真实语料后继熵极高（每源词平均候选多、无强条件关联），梯度读出的位置信任（ctx_wgt）学到的是"长上下文可用"而非"哪个具体词"，无法转化为 top-1 增益；wsum（末词直接传出突触）在这种高熵分布下是最稳基线。**"梯度学到 Hebbian 学不动的东西"在有偏语料兑现（b 阶段）、在真实语料不兑现**——梯度读出的价值定位需要重新审视（见 §六）。

### 4.3 真实语料生成质量整体低：高熵 + UNK 干扰

三路生成均差（AI 代打 ~1.5/5、BLEU 0.003-0.015），根因：① 词表 3000 下 UNK 16.6%——OOV 词打进 `<UNK>` 造成高频占位词反复出现、打断句法；② 真实语料无模板、后继熵高 → 转移信号弱、链式生成易碎；③ 噪声多步累积（Phase 2 遗留）在长句上放大。生成质量沿语料梯度单调：uniform（模板，3.7/5）→ 有偏（短模板，2.05/5）→ 真实（高熵，1.5/5）——**生成质量与语料"结构度"正相关、与"真实度"负相关**，是当前动力学读出的结构性事实。

### 4.4 方法论注意：trace 评估口径跨版不可直接比

trace 评估（`evaluate_trace_smat`）的**动力学注入走 ng.W（step 传播），读出走训练前构建的 S 矩阵**——train_w 修改 W 后，注入用的是扰动后 W、读出是扰动前 S，两版扰动幅度不同（max 8.27 vs 2.10）→ trace 数字（0.0867 vs 0.0979）的差异部分来自口径混用，**非纯语料效应**。delta_off 扫描在 train_w 前（未扰动 W），不受影响。此混用在 b 阶段已存在，建议后续评估统一为"train_w 前评估静态三路"或"train_w 后重建 S"。

### 4.5 结论

1. **变体修复生成退化（v1 → v1.1 闭环）**：信任极值根因链被实证，工程修正（均匀初值/温和 lr/短训练/归一化）有效，grad 生成 1 词 → 完整句
2. **真实语料验证主体结论**：标准档（3000 词表/2 万句）下三路 top-1 均不超 wsum，wsum 最稳基线；grad/trace 增益项 FAIL
3. **生成质量受真实语料高熵 + UNK 16.6% 限制**，全引擎均未达 3/5——语料结构度是生成质量主变量
4. 回归全绿、W 结构不变、提速对拍一致——工程底座稳固

## 六、后续方向

- **梯度读出价值定位再讨论**：真实语料 top-1 增益不成立，但 grad 的差异在"条件预测"（长上下文）而非短前缀续写——可验证：长前缀（8+ 词）条件下 grad vs wsum 的相对表现；或转 Phase 4 的"时间深度→槽间级联"路线

- **评估口径修正（§4.4）**：静态三路评估移到 train_w 前，或 train_w 后重建 S——保证 trace/grad 数字口径干净
