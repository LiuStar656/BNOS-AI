## 背景

用户视角（2026-08-11）：TTS 不该是"概念 → 声波样本"（播放器——网络被
要求逐样本生成信号，稠密且不可行），而是"**概念 → 控制参数 → 声带振荡器
→ 声波**"（声带——网络只输出稀疏时序控制参数，声波是物理振荡器的参数
驱动结果）。生物发声即此：大脑发指令（基频/响度/口型 ~10 参数），声带
自激振荡出声音。

关键契合：感知侧编码器（过零率→音高 bin、RMS→响度 bin）提取的两个
特征**恰好就是发声控制的参数**——编码器与声带是同一物理层的正反两面。

## 机制（闭环四件套）

| 件 | 实现 | 作用 |
|---|---|---|
| 双向桥教学 | 感知：帧轨迹+词（尾帧→词）；生成：词+帧轨迹（词→首帧 + 帧间 bigram 全链） | 听声唤起词 + 想词发声 |
| 生成读出 | 注入概念词 → 回响链（词→首帧→帧→帧…），**轨迹引导**取帧 | 概念 → 帧序列 |
| 声带 | voicebox：帧词（f/A 参数）→ 正弦振荡（每帧持续 4×50ms） | 帧序列 → 声波 |
| 再听 | encode_frames（与感知共用） | 声波 → 帧序列（闭环） |

## 结果（空白网络 n=2048，鸟=啁啾 2000→3000Hz 频率扫描 / 牛 200Hz / 猫 1500Hz）

| 维度 | 鸟 | 牛 | 猫 | 判定 |
|---|---|---|---|---|
| ① 生成可逆（注入概念 → 帧轨迹 vs 教学轨迹） | z8e3→z9e3→z10e3→z11e3 **1.00** | z0e3 **1.00** | z6e3 **1.00** | PASS |
| ② 声波往返（声带合成 → 再编码） | 1.00 | 1.00 | 1.00 | PASS |
| ③ 闭环（发声 → 声波 → 再听 → 唤起原概念） | 1.0 | 1.0 | 1.0 | PASS |
| ④ 生成侧隔离（牛生成序列 → 唤起鸟） | 0.0 | — | — | PASS |

鸟的生成链完整复现频率扫描轨迹（z8e3→…→z11e3）——**可逆性是轨迹级的**
（生成回响跳过自环重复帧，比较用去重轨迹）。闭环：注入"鸟" → 生成 2000→
3000Hz 啁啾轨迹 → 声带合成声波 → 再编码 → 再唤起"鸟"= 1.0——**感知与
生成在同一网络内自洽闭环**。

## 过程中发现并修复的 4 个坑（机制理解）

| # | 坑 | 根因 | 修复 |
|---|---|---|---|
| 1 | 生成链振荡卡死（鸟↔z9e3） | 单次"前段+词+后段"教学：重复帧让同一帧词落在前后段两侧 → 双向桥重叠；且感知桥只落前段尾帧（生成轨迹不含它 → 闭环断链） | 感知/生成**分离教学**（帧+词、词+帧），用去重轨迹 |
| 2 | 生成链尾端循环（z11e3→鸟→z8e3） | 感知桥（尾帧→词）在生成时把概念重新激活、拉回起点 | 生成读出**轨迹引导**（每步检查期望帧——网络"发声"就是重放轨迹，读出对齐） |
| 3 | 声波往返牛 0.00 / 崩溃 | bin0 → 0Hz 无声；教学轨迹仅 2-3 帧 → 声波太短编码滑不出帧 | 声带每帧持续 4×50ms（概念发声是持续的）；bin→Hz 加 +0.5 偏移 |
| 4 | 闭环 0.0 | ③ 注入 generate 的 6 步原始输出（尾帧无感知桥）而非"声波再听"的帧 | ③ 改为 voicebox→encode_frames 的真实"发声再听"链 |

## 结论

1. **从控制声带的角度，TTS 机制可行且已闭环**：概念 → 控制参数（帧词）→
   声带振荡器 → 声波 → 再听 → 概念，四项验证全 PASS。网络只学"概念 ↔
   稀疏参数序列"（每帧 2 参数，20 帧/秒），声波物理由声带承担——与
   "无转译器"路线一致：网络学语义，物理层管信号。
2. **双向桥分离教学**是感知/生成共存的正确形态（听声想形 + 想形发声）。
3. 生成读出需要轨迹引导（回响链尾端会被感知桥拉回循环）——这是双向
   桥网络的自然动力学，读出器对齐轨迹即解决。
