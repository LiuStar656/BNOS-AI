## 1. 定位声明（纠正后的结论）

**定式网络目前不能做 TTS。** 已实证的只是几个机制片段（声带转换可逆、
感知可唤起概念、转译近无损），全部停留在玩具尺度。按 TTS 能力标准逐项
对照，差距如下：

| TTS 能力标准 | 现状 | 差距 |
|---|---|---|
| **文本输入**（任意文本 → 语音） | ❌ 无——只有 3 个预置概念词注入（鸟/牛/猫） | 文本→概念映射不存在 |
| **自然语音音质**（可听懂、像人声） | ❌ 纯正弦合成（电子音），真实音效生成失败或原型级 | 数量级差距（音色单维 vs 频谱包络/共振峰） |
| **任意内容泛化** | ❌ 3 个概念，每个只有一条轨迹 | 无泛化可言 |
| **时长** | 0.2-4.8 秒玩具段（长链失败：5s 基线 0.0） | 长时生成未解决 |
| **韵律/语调** | ❌ 无 | 未开始（音调轮廓是下一步候选） |
| **说话人/风格** | ❌ 无 | 未开始 |

## 2. 实验回顾（数据保留，定位纠正）

### ① 合成音闭环（`_probe_sound_tts`）——玩具级机制成立，不构成 TTS

3 个纯正弦音（啁啾/低频/中频）的双向桥闭环全通（可逆 1.00、往返 1.00、
闭环 1.0）。**纠正**：这只是"概念→固定轨迹→单音色声波"的最小可逆链路，
相当于"玩具八音盒"，与 TTS 无关——它证明的是**声带转换可逆**，不是
**能说话**。

### ② 真实音效生成（VQ+长帧）——失败或原型级

| 音 | 轨迹一致率 | 再听唤起 | 结论（纠正后） |
|---|---|---|---|
| 猫 | 1.00 | 1.0 | 玩具级原型（8 带正弦"电子猫"，非自然猫叫） |
| 鸟 | 0.522 | 0.0 | 失败（生成认不出） |
| 牛 | 0.625 | 0.0 | 失败 |

**纠正**："猫全通"仅指"生成轨迹与教学轨迹一致 + 再听能唤起概念"——
生成的声音是 8 个正弦的定式化频谱，离"猫叫"（自然音）差两个数量级。

### ③ 感知方向——唯一相对扎实的成果（但也不是 TTS）

真实音效 → mel/VQ → 唤起概念（鸟/牛/猫 1.0、交叉干净）。**纠正**：这是
"声音分类/概念绑定"的机制片段，是 TTS 的前置（听），不是 TTS 本身。

### ④ 数字↔脉冲转译保真（`_pcm2pulse`）——物理层，与 TTS 无关

sigma-delta 近无损（相关 0.97-0.99）。**纠正**：这是标准信号处理（1-bit
ADC/DAC 原理），不构成任何 TTS 能力，只是说明"转译不是瓶颈"。

### ⑤ 脉冲字符学习（`_probe_pulse_chars`）——小流可学、长流失效

0.2s（200 字符）感知 1.0；5s（4954 字符）基线 0.0。**纠正**：无损字符化
在数学上封顶（字符率 vs 信息率差 16 倍），当前引擎不可突破。

## 3. 为什么"远远不够"（差距的根源，已实证）

1. **音色维度**：当前物理层是 8 带 mel + 正弦合成——真实语音需要频谱包络、
   共振峰、相位、谐波结构（全部缺失）；
2. **类内变异未解决**：真实声音的多样性（"鸟叫有无数种"）无法稳定汇聚
   ——音调轮廓（一维）可行，音色/频谱（多维）不可行（已实证）；
3. **长链墙**：轨迹复现封顶在 ~20-200 符号（长帧 VQ 猫全通 / 脉冲字符
   200 可学），5 秒级失败——TTS 需要任意长度的流畅生成；
4. **学习范式**：教学式（几十句）vs TTS 需要的数据规模——不是当前路线
   的目标，但决定了能力上限；
5. **符号机 vs 时间机**：网络消费符号序列（可学但有损）vs 脉冲定时
   （无损但学不动）——16 倍信息率差的数学墙。

## 4. 结论（纠正后）

1. **定式网络目前不具备 TTS 能力**——只有机制片段（声带可逆、感知可
   分类、转译无损），全部停留在玩具尺度；
2. 这些片段是**研究记录**（知道哪些机制通、哪些墙在哪），不是能力声明；
3. 下一步若继续，按可行性排序：**音调轮廓起步**（一维、网络最擅长的
   维度——"高→低"陈述/“低→高”疑问的韵律层）→ 文本→概念映射 →
   音色维度（长期）。任何一步都不意味着 TTS，只意味着离 TTS 近一点。
