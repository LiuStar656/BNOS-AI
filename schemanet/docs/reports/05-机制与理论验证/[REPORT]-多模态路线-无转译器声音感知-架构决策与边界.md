## 1. 目标

多模态不用 ASR/OCR/STT/TTS/YOLO 等**外部转译模型**——不把声波/像素翻译成
符号再喂进来，而是让定式网络**自己**从原始信号长出模态概念。
转译模型的问题：概念被外部模型定死，音调/口音/空间位置等细节在转译
瞬间丢失；且引入外部依赖。本项目哲学一致：概念 = 网络内部结构
（词 → 模式分配、`_exp_modal` 管道内化、`_grow_oov` 字模式并集），
多模态是这个能力的自然延伸——**模式来源从"词表分配"扩展为"信号自组织"**。

## 2. 架构决策（本方向四个关键判断）

| # | 决策 | 理由 |
|---|---|---|
| ① | **多模态 ≠ 多进程**：共享大脑用**槽位分模态** | v35 即 slots=4；`_probe_concurrent` 已验证槽位隔离（槽0/槽1 学习互不串扰）。多进程只服务于失败隔离/跨进程部署，不是模态数量决定的 |
| ② | **声音是最优起点** | 时序是脉冲网络母语，声音是唯一天然时序外部模态（波形→脉冲流零结构转换）；物理层最薄（过零率/能量是标量统计，无语义）；合成数据可测（不依赖真实语料）；视觉最劣（空间结构需人为序列化 = 变相转译，且无空间归纳偏置） |
| ③ | **先空白网络、后 v35 接入** | 空白（机制参数对齐 v35）证明"能学会"（变量干净、失败可归因）；v35 单快照副本证明"能接进去"（不污染主链） |
| ④ | **感知模式预置（耳蜗 tonotopy）** | 频率×能量 bin 全部预分配（64 模式）——噪声扰动产生的未见帧词不崩；生物对应：频率选择性神经元先天预置 |

## 3. 实证一：最小闭环（声波 → 帧词 → 听声唤起词）

```
声波 ─物理层(过零率→频率bin + RMS→能量bin，AGC音内归一)─> 帧词序列 z{f}e{e}
     ─现有机制 _learn_sentence（bigram 链：帧→帧→…→概念词）─> 桥
     ─唤起：注入帧序列 → 回响 → 概念词模式激活比例
```

三音（鸟 3000Hz / 牛 200Hz / 猫 1000Hz），空白网络 n=2048 与 v35 单快照
接入两小节，六项指标（桥边 24.0 / 原音 / 响度×0.5 / +10% 噪声 / 短时 0.6×
/ 交叉）**全 PASS**——概念词直接复用 v35 词表（鸟/牛/猫），全程无外部模型。

## 4. 实证二：鲁棒性（"鸟的声音有无数种，还会出现干扰"）

8 种鸟叫变体（啁啾/鸣啭/短促 × 多频率）+ 白/雨/风噪声 SNR 扫描 + 掩蔽混叠：

| 维度 | 结果 | 结论 |
|---|---|---|
| 类内汇聚 | 8/8 变体唤起"鸟"= 1.0 | **概念 = 多入口汇聚点**，多样性可应对 |
| 抗噪 | 白/雨噪声 **SNR 0dB 仍 1.0**（风声偶发失效） | AGC + 序列级时间积分消化干扰 |
| 掩蔽混叠 | 鸟+牛同时 → 鸟=1.0、牛=0.0 | 竞争性掩蔽（高频占优），一方胜出非共存 |
| 类间隔离 | 牛（200Hz）→ 鸟 = 0.0 干净；**猫（900Hz）→ 鸟 = 1.0** | **频率拉不开的概念存在间接串扰（硬边界）** |

猫鸟串扰追踪定位：猫帧 z3e3 → 桥 z3e3→猫 → 猫概念回响期间接激活
鸟变体帧词（z7e2/z10e3/z12e3）→ 经"帧词→鸟"桥唤起鸟。链**弱且非确定**
（两次逐步追踪一次激活鸟、一次只激活帧词）。

## 5. 跨探针的引擎事实（四坑 → 机制理解，对一切测量/训练有用）

| 引擎事实 | 影响 | 应对 |
|---|---|---|
| **evoke 路径也在学习**（learn_gate=True 时唤起路径同样执行 Hebbian/STDP） | 验证/测量污染后续结果（实测一次验证 +19 边强） | 测量前关 learn_gate（已入两个探针） |
| **STDP 只学"尾帧→词"**（trace 衰减 0.5/步，非尾帧 trace <0.3 阈值） | 桥只在尾帧；静音尾帧断链 | 静音帧跳过编码；桥边查尾帧词 |
| **噪声 hub 弱边中继**（小网络 6% 噪声神经元必然重复 → 与多概念共发放建 0.5 级边） | 交叉串扰 1.0；**印证 v35 剪枝报告"弱边海洋是底噪"** | 验证关噪声源 + 教学后剪弱边（<1.0，v35 sleep 剪枝同款） |
| **帧间 spikes 残留**（唤起路径帧间不清，旧发放洪泛挤掉新注入） | v35 92 万边网络唤起失败 | 唤起逐帧清 spikes（仿 `_learn_sentence` 注入语义） |

## 6. 边界清单（诚实声明）

1. **频率重叠区概念分化无解**（当前机制）：猫(900Hz)↔鸟(2k+) 帧词无共享仍
   间接串扰；真实世界声音频谱重叠是常态。
2. **尾帧桥未用时序信息**：chirp/trill/chip 的帧序列模式本可区分，但桥只看
   尾帧——节奏维度完全没用上。
3. **桥单向**：只学了"帧→词"（听声唤起词），"词→帧"（想鸟叫鸟声）未建。
4. **掩蔽竞争性**：混叠时一方胜出，无共存/分离机制。
5. **实验局限**：合成音（真实鸟叫频谱复杂得多）、单说话人、无混响；
   v35 接入做了两处实验性调节（教学降噪、逐帧清 spikes），接入后未做
   既有记忆回归（free_read 12 题等）。

## 7. 路线图（按价值排序）

| 阶段 | 内容 | 解决 |
|---|---|---|
| 1 | **时序签名维度**：帧序列模式特征（chirp=频率扫描、trill=调频振荡、chip=间歇）编码进模式 | 猫鸟混淆 + "无数种鸟叫"的表达力 |
| 2 | **概念侧抑制/分化**：概念发放时抑制邻近概念，切断间接串扰链 | 边界 1/4 |
| 3 | **感知模式自聚类**：信号重复结构由网络自己分配模式（替代手工预置 bin） | 模式形成自主化（路线目标） |
| 4 | **多模态槽位化**：声音槽/文字槽跨槽绑定（"鸟叫"↔"鸟"概念联觉）+ v35 接入完整回归 | 多模态架构落地 |

## 8. 结论

无转译器多模态在现有引擎上**机制成立**（最小闭环全 PASS、8 变体汇聚、
SNR0dB 抗噪），方向可行；但**概念分化需要新维度**（时序/音色/抑制机制），
且引擎有四个已知动力学事实（evoke 学习/尾帧桥/噪声 hub/帧间残留）约束
一切训练与测量——这些事实同时是设计下一代机制的入口。
