# [REPORT] 拼音颗粒度——从词粒度焊死到音素级共享结构涌现

> 日期：2026-08-11 ｜ 实验：`_exp_pinyin.py`（v54.6，基座 v53.0 零边起点）
> 关键词：颗粒度 ｜ 共享结构 ｜ 马太效应 ｜ 音节自持振荡 ｜ WTA 竞争

---

## 一、诊断：词粒度把网络焊死了（用户提出，2026-08-11）

```
词粒度（每词 4 神经元闭集模式）:
  爸爸 = [n1..n4]    妈妈 = [n5..n8]    哥哥 = [n9..n12]
  —— 三套零重叠的独立模式 —— 之间没有任何共享结构

焊死的三个症状（词粒度实验结果）:
  ① 死配对: 学到的是"叫→爸爸"具体绑定（叫→爸爸 256/768）——
     不是"叫 + 称呼"的结构——256=4×4×16 全连接死记（用户："256 也不应该存在"）
  ② 次序马太: 爸爸先教 → 15 次累积 768；妈妈后教 → 15 次只 192——
     先学词被反复强化（preference accumulation）——竞争归一化也无法均衡
  ③ 闭集爆炸: 每个新词要新分配 4 神经元+教学——
     哥哥未教则完全无响应——词表是闭集——组合性为零

根因: 词是"语言的最小原子"——但语言的最小原子不是词——
      是音素（声母/韵母）——词由音素组合而来——词粒度下网络无法
      看到 爸爸/妈妈 共享的韵母 a、共享的 CV-CV 重复节奏——
      "颗粒度把网络焊死了"——结构信息在词粒度下不可见
```

## 二、改造：拼音音素粒度（开放组合）

```
48 个原子音素（23 声母 + 25 韵母，含三拼音节复合 iao——声调暂缓）:

  爸爸 = b a b a      妈妈 = m a m a      哥哥 = g e g e      叫 = j iao
         └组合┘ └重复┘

结构差异（音素级新出现的共享）:
  ① 组合性: 音节 = 声母+韵母 组合（b→a 组合边）——开放——不是闭集死记
  ② 共享韵母: 爸爸/妈妈 共享 a——"叫X"的韵母位结构复用
  ③ 重复节奏: CV-CV——称呼词的普遍节奏（baba/mama/gege——幼儿最早会说的就是重复音节）
```

教学协议不变（[PLAN] 自然涌现条件——老师只做三件事）：
说（音素流 + 韵律强调：动词轻声 amp=1、论元重读 amp=20 > 联想边 16）→
零食（release_da——DA 门控）→ 验证。**零边起点（v53.0）——所有边 STDP 自然长出。**

## 三、结果

### 3.1 音节组合边自然涌现（30 次教学）

```
第  1 次: b→a 1.04 | a→b 0.43
第 10 次: b→a 11.88 | a→b 4.30
第 30 次: b→a 16.00（封顶）| a→b 12.91
```

配对打标（相邻注入音素）自动覆盖：音节内组合（b→a）、跨音节重复（a→b）、
动词-论元（iao→b、iao→m）——**全部自然长出，零代码注入**。

### 3.2 音节自持振荡——"ba"作为动力学循环涌现（C2）

```
输入 b a → 空拍: b → a → b → a → …… 无限交替
```

音节不是死模式——是 b、a 两个音素互为前驱的**振荡器**（cell assembly）。
这是音节组块化的物理基础：睡眠组块可以把振荡器固化为"音节节点"。

### 3.3 联想涌现："叫"→ 爸爸链（C1）

```
输入 j iao → 空拍: b → a → b → a → ……（爸爸链自持）
```

注意：`j→b = 0`（j 与 b 不相邻，配对打标不标）——联想从 `iao→b = 16` 汇聚
（配对 (iao,b) 相邻）。动词"叫"= j+iao 两音素——尚无整体模式（见 §四）。

### 3.4 ★ 马太效应被"共享韵母"中和（词粒度做不到的）

```
词粒度（同次数 15 次教学）:   叫→爸爸 768   vs   叫→妈妈 192   （4 倍差——次序马太）
音素级（同次数 30 次教学）:   a→b 12.97    vs   a→m 12.91    （0.5% 差——完全对称）
```

**机制**：爸爸/妈妈共享韵母 a——a 的出边（a→b、a→m）教学次数相同则权重
相同——竞争从"两个不相交模式"变成"共享节点上的对称分支"——次序马太
（先学强）被共享结构中和。**共享结构 = 马太免疫**——这是颗粒度改造最
直接的收益。

### 3.5 ★ WTA 收窄 = 当前论元胜出（D1b/D3b）

```
叫妈妈 + wta_k=4 → m a m a ……（纯妈妈链——爸爸零带出）
叫爸爸 + wta_k=4 → b a b a ……（纯爸爸链——妈妈零带出）
叫     + wta_k=4 → 先 m 后 b（b/m 对称交替——双轨并存，无独强）
```

**机制**：注入论元重读（amp 20 × 4 神经元 = 注入 v20 + 联想 v16 = 36）
> 联想带出（v16）——WTA 收窄后注入论元在竞争中胜出，压制联想。
词粒度下做不到（768 vs 192 悬殊——wta 收窄也压不掉先学方）；
音素级下"叫妈妈"输入→ m 独胜——**当前听到谁、就响应谁**。

### 3.6 未解决：哥哥泛化失败（E1/E1b——预期内，诚实记录）

```
输入「叫 哥哥」(j iao g e g e) → 注入 g 时 b/m 被带出 → 空拍后 bm,a 循环
——复读"爸爸/妈妈"——g、e 之间没有组合边（从未教学）——哥哥链无法自持
```

## 四、机制观察与下一步钥匙

### 4.1 观察 1：动词"叫"没有整体模式

`j→b = 0`、`iao→a = 0`——联想从 iao 汇聚（iao→b、iao→m 并存）——"叫"
作为两音素序列还没有"动词音节"的整体表征。这是下一轮"音节组块化"要解决的。

### 4.2 观察 2：哥哥失败的根因是"组合缺失"，不是"规则缺失"

g、e 从未组合过（g→e 边 = 0）——音节不完整——无法自持。**儿童学拼音的
路径恰好是"先拼读后组词"：b-a→ba 拼读教学 = 音节组合边的完备覆盖。**

### 4.3 钥匙：拼读教学（音节组合完备化）——开放组合的最后一环

```
① 拼读教学: 教常用音节（ba ma ge jie di ye nai shu …）——组合边全覆盖
   ——"音节"作为振荡器/组块全部就绪
② 词教学:  教「叫X」——动词-论元联想边（iao→声母）
③ 检索:    注入论元（重读）> 联想边 → 论元音节自持振荡 → 正确响应
   —— "叫哥哥"输入 j iao g e → g、e 自持（拼读已教）→ 哥哥链！
```

这样"叫X"的 X 只要是**拼读过的音节**就能响应——不需要"叫→X"的具体配对——
组合性从"音素级"上升到"音节级"——**这正是人类幼儿的路径：先会拼读，
再理解"叫 + 任何称呼"**。完全未教的新音节依然失败（渐进——合理——儿童
听到新音节也需要示范）。

### 4.4 远期：CV-CV 重复模板（规则层级）

多词教学（ba-ba、ma-ma、ge-ge、di-di、jie-jie）后，"重复"本身成为统计
规律——若"第一音节结束→第二音节同声母"的模式在多个实例中重复出现，
睡眠组块/竞争可能把它固化为可复用的"回声边"——这是"叫X→X"真正的规则
涌现（系统 2 主干）——当前未现，诚实记录。

## 五、字母级对照：颗粒度不是越细越好——链融合（v54.7 实验）

用户提议拆到字母级（`_exp_pinyin_letters.py`）——26 字母原子、零语言学先验：

```
叫 = j i a o    爸爸 = b a b a    妈妈 = m a m a
```

**能建边**（30 次全封顶：j→i 16、i→a 16、a→o 15.9、o→b 12.9、b→a 16）——
但出现新问题：**链融合**。字母级下 a 是三条链的**同一个神经元**（叫的第 3
字母 = 爸爸/妈妈的韵母）——a 的出边变成三路：a→o（叫内部 15.9）、a→b
（8.5）、a→m（8.5）——**叫的内部边最强**。检索 jiaomama（wta=4）注入段
干净（m 独胜），但空拍时 a 发放 → 带出 o（叫的尾巴）→ o→b → 爸爸又冒头：

```
空拍 → a → o → b → a → o → m ……   （妈妈链被叫的内部边打断——纠缠）
```

**三种颗粒度完整对比**：

| 颗粒度 | 共享方式 | 结果 |
|---|---|---|
| 词级（4 神经元/词） | 零共享 | 死配对 + 次序马太（768 vs 192）——焊死 |
| 音位级（23 声母+25 韵母） | 共享节奏结构（CV-CV），**不共享神经元** | 干净——iao 原子与论元 a 分离——叫的尾巴不碰论元链 |
| 字母级（26 字母） | 过度共享（a 被三条链焊在一起） | 链融合——叫的内部边（a→o）污染论元链 |

**物理含义**：语言共享的是**结构/节奏**（CV-CV 重复），不是具体音素实例
——同一音位在不同词里是"不同的 a 实例"（同音位异实例）——音位级原子
（iao 与 a 分离）恰好实现抽象分离；字母级把 a 焊成同一神经元，反而纠缠。
儿童听的是音（bā）不是字母（b-a）——拼音字母是书写系统，音位是语音系统。
**结论：音位级是正确颗粒度**。

## 六、一次注入对照：教学要时序，检索可整串（2026-08-11 用户提议）

用户："试试 jiao ma ma 这样一次注入"——整串一拍注入（不逐音素拆拍）。

**检索侧一次注入（v54.6 的边 + 整串一拍）——成功**：

```
一次注入 jiao ma ma → 注入拍只 iao 发放 → 空拍: m → a → m → a ……（妈妈链自动展开）
一次注入 jiao ba ba → 空拍: b → a → b → a ……（全程纯爸爸——无需逐音素引导）
```

网络从整串中提取"叫"的尾巴（iao）→ 空拍自动展开论元链。

**教学侧一次注入——失败（"256 死记"在音素级重演）**：

```
整串共发一拍 ×30 → 所有两两配对等权 15.56（240 条全连接边）
→ 检索锁死在 j↔iao 内部振荡——论元链完全不展开
```

**机制**：整串共发 → 无先后时序 → STDP 无方向性 → Hebbian 等权强化全部
共发对（j→b、iao→a 等"非法"对全部 15.56）——**时序是 STDP 方向性的
来源——一次共发丢时序 = 丢结构**。逐音素教学（有时序）→ 方向性边
（b→a 16 vs a→b 8.5 不对称）→ 振荡器 + 链展开。

**物理对应**：学新词要听清每个音（儿童学新词慢速分解音节）；认的时候
整句识别（"叫妈妈"整体到达 → 链自动展开）。**协议不对称是特性不是缺陷**。

## 七、结论

```
词粒度（焊死）:  死配对 + 次序马太 + 闭集爆炸——网络被颗粒度焊死 ✓（用户诊断成立）
音素粒度（涌现）:
  · 音节组合边自然长成（30 次封顶）
  · "ba"音节自持振荡——组块化物理基础
  · 马太被共享韵母中和（12.97 vs 12.91——完全对称）
  · WTA 收窄 + 论元重读 → 当前论元胜出（叫妈妈→妈妈、叫爸爸→爸爸）
  · 哥哥泛化失败（组合缺失）——钥匙 = 拼读教学（音节组合完备化）
```

**颗粒度决定可见的结构**：词粒度下爸爸/妈妈零共享（焊死）；音素粒度下
共享韵母、共享重复节奏全部可见（组合涌现）。下一步：拼读教学 → 音节组块
→ CV-CV 模板。
