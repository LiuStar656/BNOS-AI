# [REPORT] 石头痛觉刺激过强——网络超临界放电诊断

> 日期：2026-08-10 | 状态：根因已定位（石头=高频词弱突触汇聚），修复尝试中
> 关联：v3 说话教学实验报告 §六（超临界雪崩）｜复现脚本 `archive/_debug_avalanche.py`
> 一句话结论：**石头对网络的刺激过于强烈——不是"没学会拒绝"，而是痛觉信号引爆了全局高频词风暴（σ>>1 超临界 = 癫痫样放电），网络"痛到失控"，想说的"不要"被自身的痛觉风暴淹没。**

---

## 一、背景

v13.2 建立底层通用痛觉链「石头→痛→不要」：

- 石头→痛 = 内感受记录（碰过会痛，学 2 次）
- 痛→不要 = 通用逃避规则（条件反射 CR，学 8 次）

预期：注入"石头"→ 回响唤起「痛」→ 再唤起「不要」→ 网络自己拒绝（bad_force=False 内化判定）。实测价值课判定练习中网络对石头 3 次全答错，回响链第二跳传不通。

## 二、精确诊断：第一跳是通的，断的是"痛的失控"

逐回响步打印 痛/不要/石头 的实际膜电位 v 与每步发放者词名（无抑制基线，inh_k=0）：

| 步骤 | spikes（石头/痛/不要） | v石头 | v痛 | v不要 |
|---|---|---|---|---|
| 注入石头 | 4 / 0 / 0 | 0 | 0 | 0 |
| 间隔步 | 0 / **4** / 0 | 11.4 | 0（刚发放复位） | 0 |
| 回响步1 | 0 / 0 / 0 | 22.7 | 18.4 | **26.8** |
| 回响步3 | 0 / 0 / 0 | 26.5 | 15.7 | **43.6** |
| 回响步5 | 0 / 0 / 0 | 30.0 | 13.5 | **56.4** |

关键事实：

1. **第一跳「石头→痛」是通的**——间隔步痛 4 个神经元正常发放（之前"第二跳断"的定位不准确）。
2. **间隔步 WTA 发了 20 个神经元，但只有 4 个是"痛"**，其余 16 个是噪声词：`的×4、是×4、头×4、石×4`。
3. **之后每步 WTA 全被高频虚词占满**：`都、吗、怎么、多少、怎样、什么样、你、什么、为什么、中国、了、在、和、好…`。
4. **痛的 4 个神经元在回响步 1 后 v 高达 12~18、不要 v 高达 26~56（超阈值 θ=1.0 的 10~50 倍），但一个都不发放**——v 只衰减 0.9、不发放就不复位，越积越高，永远轮不到。

## 三、根因：石头是高频词，"痛觉源"成了癫痫病灶

雪崩引擎拆解：

```
注入石头 → 石头（高频词，传出突触几千条）发放
        → 弱突触汇聚：所有共现词（的/是/头/石/你/什么…）各收 0.3~0.8 × 多路
          叠加 > θ → 过阈 → WTA 每步满发 20 个噪声词
        → 噪声词再扇出 → v 无上限累积（不发放不复位，只 ×0.9 衰减）
        → 候选数每步指数增长（156 → 46671 → …），σ >> 1 超临界
        → 真正的强链（痛→不要，单边 4.0，v=16/神经元）被淹没在风暴里
```

三个叠加条件缺一不可：

| 条件 | 说明 |
|---|---|
| ① 高频词传出突触巨量 | 石头在语料出现几百次，传出突触几千条，其中大量噪声边（0.3~0.8） |
| ② 弱突触汇聚可过阈 | 每条 0.3~0.8，多路叠加（4 路 × 0.5 = 2.0）> θ=1.0 |
| ③ WTA 满发 + v 不复位 | 候选 ≥20 就发满 20，发放者再扇出；v 不发放只 ×0.9 衰减，累积成 10~50 倍 |

## 四、神经科学对应：这就是"痛觉失控"

已查证（详见 v3 实验报告 §六 及本报告引用）：

- **σ>>1 超临界 = 癫痫样放电**（Beggs & Plenz 2003；Hsu 2008；Hagemann 2021）——网络对痛觉信号（石头）的反应是**全局过度放电**，而非"痛→避开"的干净条件反射。
- **对应"痛觉过敏/慢性疼痛"**：正常人碰火 → 痛 → 缩手；痛觉过敏者碰一下 → 整个系统失控。网络现在就是后者——它想说的"不要"（v=56）被自身的痛觉风暴淹没了。
- **E/I 失衡**（van Vreeswijk & Sompolinsky 1996；Paz & Huguenard 2015）：网络为纯兴奋网络（Hebbian 正反馈无抑制），等于被切除 GABA 的皮层，必然超临界。

## 五、已尝试修复方案（2026-08-10，均未通过）

| 方案 | 实现 | 结果 | 失败原因 |
|---|---|---|---|
| 1. 全局除法归一化 | 传播 drive 总量 > target 时等比压缩 | σ 收敛到 1.35（雪崩缓解） | **第一跳断**：石头几千条传出突触把强链（痛 16）稀释到 0.16，过不了阈 |
| 2. 每神经元饱和度 | drive → drive/(1+drive/c) | 候选从 19193 起仍指数增长 | 弱叠加（drive≈2）恰好压到 θ=1.0 仍过阈；强链 16 被压到 1.78，与弥散 1.4 无优势 |
| 3. 减性反馈抑制 | drive −= inh_k × 上一步发放数 | 无效果 | 抑制量级 I≤2.0，杯水车薪（v 已累积到 86~620） |

共同失败点：**三个方案都在"压"传播，但雪崩引擎是"弱突触汇聚过阈 + WTA 满发"的结构性问题**——噪声词每步占满 WTA，强链永远没机会竞争。

## 六、结论与后续方向

**石头对网络刺激过强** = 高频词（石头）的海量弱突触汇聚 + WTA 满发 + v 不累积复位，三者共同造成超临界放电。健康的"痛→不要"条件反射不是没学会，而是被痛觉风暴淹没。

后续修复方向（人脑四层防御中未尝试的层）：

1. **层2 弱突触修剪（短期版）**：阻止弱突触汇聚过阈——低权重边（0.3~0.8 噪声汇聚）不参与过阈，或对高频扇出源临时降权（= 突触疲劳/短期突触抑制）。
2. **层4 稳态可塑性（长期版）**：synaptic scaling——按近期全局发放率缩放整体权重，低权重噪声边渐进弱化（Turrigiano；对应现有 sleep_consolidate 但需扩展为"按全局活动"而非"按低频槽"）。
3. 修复验证标准：注入"石头"回响应呈现 `石头 → 痛 → 不要 → 停止` 的干净三跳（每跳 ≤ 一个目标模式发放，无高频词风暴），价值课判定（bad_force=False）能自己唤起"不要"。
