## 一、起因：CLI 交互暴露"对话能力假象"

### 1.1 触发点

定式网络交互 CLI（`_cli_net.py`，2026-08-11）上线后，真实对话暴露系统性缺陷：

```
你> 你饿不饿啊      → 守一> （沉默……）          ← 需求问法识别不了
你> 你好            → 守一> （沉默……）          ← 打招呼无回应
你> 守一你饿不饿    → 守一> 你/饿/不/饿          ← 回声
你> 写作业吗        → 守一> 然后/饿/我           ← 自由链胡话
你> 蝴蝶是什么      → 守一> （沉默……）          ← 知识真空
```

### 1.2 用户的核心质疑

"为什么现在的对话能力这么差？"——**之前场景里"效果不错"的对话能力，为什么在 CLI 里全面崩塌？**

## 二、经过：逐层诊断

### 2.1 第一层：沉默的三种真相（神经元刺激实验）

对每个沉默输入做三层检查：词表匹配（听得到吗）→ 神经元发放（工作吗）→ 记忆读出（有东西可说吗）：

| 输入 | 听得到 | 神经元发放 | 记忆读出 | 沉默类型 |
|---|---|---|---|---|
| 饿了吗（能答） | ✓ | 1 个 | 「我饿了」 | 正常回答 |
| 你好 | ✓ | **20 个** | （读不出） | **知识真空**（没教过） |
| 下雨 | ✓ | **20 个** | 「了/就/睡觉/因为/今天下雨了」 | **触发缺失**（有知识没让说） |
| 蝴蝶是什么 | ✓ | **20 个** | （读不出） | **知识真空** |
| 为什么 | ✓ | **20 个** | 「下雨了/就/睡觉/因为…」 | **触发缺失**（"为什么"不在 ASK_WORDS） |
| 写作业吗 | ✓ | **20 个** | 「然后/饿/我」 | **知识错乱**（自由链漂移） |

**结论：神经元在工作（发放 20 个），不是宕机。沉默 = 知识真空 / 触发缺失 / 知识错乱三型。**

### 2.2 第二层：回声 bug（听学误触发）

「守一你饿不饿」×2 后回声——根因：**对话示范听学把"任何含守一的话"当示范计数**——「守一是什么」（提问）计 1 + 「守一你饿不饿」计 2 → 把「你饿不饿」学成守一的应答。

修复：示范判定加**第一人称门**——应答必须以"我"开头（"守一，我在呢"=被叫者说自己 ✓；"守一你饿不饿"是对话 ✗）。

### 2.3 第三层（核心）：能力剥离实验——代码层假象实锤

把代码层（cons 固化句表 / val 验证门）剥掉，只让模型（边）说话：

| 入口 | 带代码层（看起来会的） | 裸模型（只有边） | |
|---|---|---|---|
| 名字 | 我叫守一 | **（读不出——模型里"名字"零条边！）** | 纯假象 |
| 饿 | 我饿了 | **了**（一条碎边） | 几乎全假象 |
| 冷 | 我冷 | 了/就/睡觉/因为/今天/下雨…（胡链） | 假象 |
| 守一 | 守一是我的名字 | **守一/是/我**（定式——真边） | 半真 |
| 下雨 | 了/就/睡觉/因为/今天/下雨/了/就 | **完全一样** | ✅ 真能力 |

**关键发现**：
- 固化句（`consolidate_sentence`）建"槽位主干"（定式边在模型）→ **句子模板存 cons 表（代码）**——模型有主干没内容
- 教学链（`_learn_sentence`）整句边**直接进模型**——「下雨了就睡觉」裸模型可读 = 真能力
- **「我饿了」「我叫守一」这些最核心的表达——模型根本不会——是 cons 模板念的**

### 2.4 第四层：词表位置验证（符号层 vs 机制层）

实证（net.npz 检查）：
- **符号数据**：`pats`（词→神经元 id 字典）、`vocab`、`skeletons` —— 在 net.npz，但属于**翻译器**（告诉代码"猫=神经元 123"）
- **脉冲机制**：`src_i/slot_k/dst_j/vals`（W_out 边）、gain —— 模型本体
- **代码数据**：consolidated/validation 在 meta.json

**结论：连"词"都是符号数据层给的——模型的神经元没有"词"的身份——语义入口是代码给的，语义内容（边）是注入的。**

### 2.5 第五层：奖惩机制三次重构（外部遥控器 → 神经元自身机制）

**第一代（外部乘常数）**：`boost_chain ×1.03/1.06/1.08`、`penalize ×0.8`——外部直接改边。

**第二代（内部动机表）**：novelty/value 字典——用户批评："还是外部表，不是神经元自己的"。

**第三代（R-STDP 三因子——SNN 技术标准）**：

```
引擎 sparse_net.py：
  ng.da（多巴胺水平）      ← 外部唯一接口 release_da(±1/±2)（间接触发）
  ng.elig（资格迹）        ← 发放神经元"刚才活动过"标记，指数衰减
  学习内核：Δw = STDP × (1 + DA_GAIN × da)   ← 三因子规则（Izhikevich 2007）
  DA 瞬时脉冲每 step 衰减回基线
```

实测验证：

```
① 基线（DA=0）学 a→b:  W=0.500（≈eta——第一次+1）
② DA+1 后学 b→c:       W=0.905（有价值——学更多）
③ DA+2 后学 c→d:       W=1.310（好处大——学最多）
④ DA-1 时学 d→e:       W=0.095（惩罚——学习被抑制）
```

**"第一次+1、有好处+2、好处大+3、没意思=0"由突触动力学自然涌现**——外部只判断好坏注入调质，边怎么长是神经元自己的事。

### 2.6 第六层：SNN 领域的同构先例

| 领域案例 | 模式 | 我们的对应 |
|---|---|---|
| ANN→SNN 转换（ICASSP 2020） | 训练在外部，SNN 只是推理重编码——"只有推理受益" | cons 模板 = 外部"训练好的答案" |
| STDP + 外接分类器（readout） | 判别是外部 SVM/FC 做的——"STDP 无法端到端判别" | q_nouns/cons/val = 外接 readout |
| Surrogate gradient 争议 | 学习信号来自外部数学代理——非突触机制 | 奖励判断在代码层 |

**领域共识：效果-机制分离（performance-mechanism gap）——性能来自外部组件，网络机制没承担——剥离即崩塌。**

### 2.7 第七层：自闭症机制定位（SNN×ASD 研究）

| 机制（文献） | 定式网络现状 |
|---|---|
| E/I 失衡（Purdue SNN 模型 2025） | 存在——自由链混沌漂移（自发念头打转） |
| 预测编码（Frontiers 2026） | 缺失——答错时模型感觉不到自己错了 |
| 奖赏加工异常（AIMS 2025） | 被动接收 DA——无内部预期（社会动机缺失） |
| 突触修剪异常（南大综述 2025） | 有雏形（sleep_downscale）——缺整合 |

## 三、结果：技术债账目与治疗方案

### 3.1 技术债账目

```
债的本金：代码层假象——cons/val/q_nouns 替模型说话
债的利息：每加新功能都优先往代码层加 → 模型越来越空 → 债滚利
```

**关键审计：现有网络没有任何"不可复得"的资产**——身份（脚本可重跑）、课程（数据在）、定式（可重训）——而负债（旧机制边、代码层依赖、修补痕迹）治疗清不干净——但**治疗的经验（哪些机制有效）是重训流程设计的依据**——先治后练（还债 → 预防 → 重建）。

### 3.2 治疗 vs 矫正的分界

**矫正 = 改代码层规则；治疗 = 把认知功能机制化进模型（突触动力学）。**
判断标准：**剥掉代码层（cons/val/q_nouns）后，能力还在模型里吗？** 在 = 治好了。

### 3.3 五步治疗方案（每步：机制 / 理论 / 案例）

| # | 治疗 | 治什么 | 机制实现 | 理论/案例 |

| 一 | 知识进边 | 背 vs 会 | cons 模板 → 教学链整句建边 | ANN→SNN hybrid 微调（Rathi ICLR 2020） |
| 二 | 预测编码机制化 | 答非所问 | 预期-误差-修正回路进模型（想-查-纠-说） | 预测编码（Frontiers 2026）/ Florian 2007 |
| 三 | RPE 内化 | 社会动机缺失 | DA 预期层：RPE = 实际 − 预期 | Schultz 1997 / TD-STDP（BioLCNet） |

## 五、治疗一执行记录（2026-08-11）

### 5.1 v1 尝试：STDP 教学 ×5——失败

`_learn_sentence` 教学 5 次（STDP 累积 ≈0.5 权重）——**竞争不过旧边**（教学多年的边权重 10+）——句首"我"同时是 7 句的起点——top-1 竞争全部输给旧边——「穿衣服」唯一成功（单链无竞争）。

**经验 1**：新知识进边需要教学强度（对齐 consolidate 的 64），STDP 累积太慢。

### 5.2 v2 尝试：consolidate_sentence（共享定式）——存储层成功

每句建共享定式（模板边化——主干/槽位/绑定全进模型）：
- 定式表 **1 → 5 个**（模型层真结构——剥离代码层后 read_skeleton 可见）
- 「小狗渴了要喝水」完整句裸读 ✓（新定式）
- **但触发词问答裸读未通**（从"饿"读仍碎片——治前治后无差）

### 5.3 v2 暴露的两个新问题（治疗经验）

**① 定式合并串扰**：「我饿了」+「我叫守一」同长 3 → 共享内容槽 → 槽 2 竞争（了 vs 一）→ 从"饿"读定式 = 「饿/守一」——不同句子的内容位共享槽，top 边竞争读出混乱。

**② 触发桥缺失（结构性）**：触发词（饿）在句中位置——前向链/定式从触发词出发**无法回溯句首**（"我"在"饿"前面）——固化句（cons）的"触发词→整句"是**模板检索**（代码层），链化后的等价物需要**逆向联想**（饿→我 反向边 + 读出方向选择）——**归治疗二（预测编码/语境唤起）**。

- ❌ 触发词问答裸读未通（桥缺——治疗二）
- ⚠️ 定式合并串扰（共享槽竞争——待处理）

## 六、治疗二执行记录（2026-08-11）

### 6.1 传导链物理断裂点：gain 扩容 bug（已修复——v42）

**现象**：注入「守一」→ 模型唤起高频振荡（的/了/饿）——定式槽位永远发不出——信号"传不出去"。

**根因**（`sparse_net.py` expand()）：
```
self.gain = np.pad(self.gain, (0, pad))   ← np.pad 默认填充 0！
→ 扩容新增神经元（身份词/定式槽位）gain=0
→ 传播路径 WTA 排序 key = vmax × gain = 0 → 永久垫底排除
→ 信号传到模式轨道（v=256）但发不出来——高频词（gain=1）垄断
```

**修复**：`np.pad(..., constant_values=1)` + v41 快照 328 个 gain=0→1（**v42.0 保存**）。
验证：注入「守一」→ 定式槽位被激活并沿主干传播（#149376-379 → #149380-383）——**传导链通了**。

### 6.2 定式主干缺失与轨道漂移（进行中）

- 共享定式合并时：槽→槽主干边被槽→词读出边取代——轨道中途断链
- 补主干（1024）后：词读出（64）与轨道并行发放污染序列——中途"下车"
- 轨道入口竞争：词→槽（64）与词→语料边（60）接近——并行竞争
- 本质：**缺"序列预测约束"**（当前在轨道上时只走轨道——上下文消歧）

### 6.3 历史审计：模型层生成能力从未存在过

| 时期 | 能力 | 模型层（裸唤起） | 代码层 |
|---|---|---|---|
| S1 复读（v1-v6） | 跟读回声 | ✅ 有真实痕迹（猫→猫 回声边） | 部分 |
| S2 造句（v9+） | 主谓宾 | ❌ 高频振荡 | ✅ chain_read 拿答案对边 |
| S2.5 举一反三（v8） | 类别/传递 | ❌ 动物唤不起猫狗 | ✅ walk_chain 代码读边 |

**关键证据**：`walk_chain` 注释亲口承认"**不用传播动力学**——槽位 S/是 是全局共发 hub，注入会同时激活所有主语/全词表，走链被带偏"——v9 时代就知道模型层传播走不通，选择代码绕开。**gain=0 很可能是当时"防 hub 带偏"的有意设计，被 expand 的 np.pad 扩散成所有后分配神经元锁死。**

### 6.4 SNN 领域跨过此坎的案例（2026-08-11 检索）

| 案例 | 机制 | 对应治疗 |
|---|---|---|

| Milstein 2023（J Physiol） | CA3 重放：关联突触/稀疏/节律/**发放率适应（疲劳）** | std_dep=0 必须开启（现在是 0） |

### 6.5 边强度机制检查（2026-08-11）

- **边有强度**（权重 0~64——STDP 累积）：「我→想」=13.3（11 次累积）、「我→饿」=29.8、「叫→守一」=64
- **饱和问题**：教学边教学 5 次直接到 64（w_max）——**之后见的次数不编码**——"见的越多越强"对教学边失效（饱和破坏频率编码）
- **sleep 删边不随机**（按权重：独苗弱边 + 行内最弱 18%）——但**权重=频率 ≠ 正确性**——低频正确边有被删风险——需要"正确性信号"（验证门/预测误差）参与删除决策

## 七、核心结论：网络被错误激活（2026-08-11 定稿）

**整个诊断链收敛为一个结论：网络被"统计霸主"激活，而不是被"该激活的"激活。**

### 7.1 我们问错了问题

```
问：网络哪些神经元突触最多？→ 的(11,884 入边)/了/是/有——统计霸主
    ——"突触最多"是统计事实，不是"应该被激活"的理由
应问：网络此刻应该激活谁？→ 上下文/轨道决定（注入"守一"→ 激活守一的轨道）
    ——"该激活"是语义正确——拿统计答案当语义答案 = 错误激活
```

### 7.2 错误激活的三层机制（对应三步治疗）

| 层 | 机制 | 状态 |
|---|---|---|
| ① 传导锁死 | gain 扩容 bug——后分配神经元（轨道）gain=0——没资格竞争 | ✅ 已修（v42） |
| ② 全局劫持 | WTA 按入边汇聚（vmax×gain）——hub（突触最多）垄断——候选不限于当前词驱动 | ✅ 已修（定向传播链——候选 = 当前词驱动目标） |
| ③ 局部竞争 | 当前词出边内：教学链词/语料边 vs 定式槽位——饱和同权竞争——轨道不纯 | 🔄 进行中（轨道优先——上下文消歧） |

### 7.3 治疗的本质

**让"该激活的"（上下文/轨道/预测）替代"突触最多的"（统计）**——WTA 从"统计选择"改为"语义定向"（当前词出边 → 轨道优先 → 预测约束）——对应 SNN 案例：Sejnowski 定向流 / Vreeswijk 上下文消歧。

## 九、神经元权重与内生睡眠设计（2026-08-11 发现沉淀）

### 9.1 神经元有权重（gain）——但静态闲置

- **gain（增益）**：WTA 排序 key = vmax × gain——神经元"发放优先权"——设计意图"高价值词优先"
- **v44 实测：全部 = 1.0（机制在——从未差异化——闲置）**
- 大脑对照：**内在可塑性（Intrinsic Plasticity——[Naudé et al. 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3261921/)）**——神经元按活动动态调节兴奋性（离子通道电导——增益/阈值调制）——维持发放率稳态；**发放阈值自适应**（发放后阈值升高——恢复 ~100ms）；**发放率适应**（重复刺激发放倾向降——= 我们的 fat/std_dep）

### 9.2 睡眠影响神经元兴奋性（大脑是双稳态）

- 大脑睡眠 = 突触缩放（SHY——边层）+ **神经元兴奋性调节**（离子通道电导变化——[Hill & Tononi 2005](https://journals.physiology.org/doi/full/10.1152/jn.00915.2004)；发放率适应电流驱动 UP/DOWN——[Nature Comput Sci 2025](https://www.nature.com/articles/s43588-025-00796-8)）
- **我们当前：sleep 只动突触（边）——gain/阈值/fat 完全不参与（单稳态）**——应升级为双稳态（突触缩放 + 神经元层重置）

### 9.3 "多少开始抑制"——临界频率（非硬编码阈值）

- **每次发放都抑制一点**（sAHP——后超极化累积——增量 Δ + 恢复 τ）
- **临界频率**：F_c = -1/[τ·ln(1-Δ)]——低于临界（正常激活）不累积；高于临界（hub 高频）抑制累积——**hub 抑制是动力学自涌现——不需要设定数值**
- 我们的 std_dep（fat）= 这个机制的实现（**std_dep=0 未开**——开了就有临界频率）

### 9.4 内生睡眠设计（Borbély 双过程模型 + 局部睡眠）

- **fat（抑制累积）= 睡眠压力（Process S——[Borbély 双过程模型](https://onlinelibrary.wiley.com)；腺苷——分子实现）**
- **fat 达到阈值 → 触发 sleep 重置**（双过程模型：S 过程阈值触发）
- **局部睡眠（Vyazovskiy）**：单个神经元活动过度 → 局部进入离线（down state）——**局部自触发重置——不需要全网睡**——hub（高频词）fat 累积最快 → 最早局部重置 → 垄断自消
- 设计：sleep 从"外部手动调用"升级为"网络内生节律"（fat 驱动——活动累积到阈值自动触发——全局或局部）

### 9.5 模型大小与突触数量的关系（澄清）

- **模型占用 = 突触数 × 12B**（dst 4B + w 8B）——权重数值（强度）不占额外空间（float64 固定 8B/值）
- **统一缩放（×0.1/×0.82）不省空间**（边数不变）——也不改信息（相对结构保留——"相当于没变过"）——意义只在数值稳态（防饱和——腾可塑性空间）
- **大小优化三路**：删边（信息损失——v35 激进删 94%）、量化（权重 8B→1-2B——机制零改动）、定式共享（结构性——边不随句子数线性增长）
- **v35 的 151→2.2MB 是工程删边（eps=1.0——删 <1.0 的边——含未巩固知识）——不是大脑机制**——正确：SHY（豁免 20% + 缩放 80% + 极小阈值删除——大小不变——强度稳态）

### 10.1 fat 累积引擎修复（sAHP 语义）

