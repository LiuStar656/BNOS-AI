## 背景

用户路线（2026-08-11）："先量化原始音频"——不做语义转译，让网络直接
处理原始量化音频。用户要求"继续，直到完全走不通"。本轮穷尽四个变体：

| 变体 | 输入表示 | 帧长 | 量化方式 |
|---|---|---|---|
| 逐脉冲 | Δ调制脉冲位置 | 10ms | 位置词 p0..p79 |
| B1 VQ | mel 8 维 k-means | 50ms | 64 数据驱动原型 |
| B3 长帧 VQ | 同上 | **200ms**（4×50ms 频谱平均） | 64 原型 |
| B2 群编码 | mel 8 维连续 | 200ms | 无量化（每维 8 神经元群激活数量） |

## 结果总表

| 指标 | 逐脉冲 | B1 VQ | B3 长帧 VQ | B2 群编码 |
|---|---|---|---|---|
| 轨迹长度 | 1960 词 | 74-79 帧 | **21-24 帧** | 24 帧 |
| 感知（流→概念） | 0.0 | **1.0×3**（含猫） | 鸟/猫 1.0、牛 0.0 | **1.0×3** |
| 交叉 | 干净 | 干净 | 干净 | **全 1.0 崩** |
| 生成轨迹一致率 | 0 | 0.05-0.18 | **猫 1.0 / 鸟 0.52 / 牛 0.63** | —（mel 距离 0.5） |
| 生成再听唤起 | 0 | 0 | **猫 1.0**、鸟/牛 0 | **1.0×3** |

## 结论（路线走到哪了）

1. **逐脉冲直入：完全走不通**——1960 词长链 vs trace 短程转移，时间尺度
   不匹配（实证排除）。
2. **感知方向：所有特征级方案都通**（VQ 三音全 1.0 且交叉干净；群编码
   也 1.0 但交叉崩）——"听懂真实音效"在 mel/VQ 表示下成立。
3. **生成方向：有条件通**——B3 长帧（轨迹压缩 4 倍）是关键：猫全通
   （轨迹短且帧词重复），鸟/牛部分通（跳变率 0.96-1.0，转移对不重复）。
4. **离散 vs 连续的取舍**（核心规律）：
   - 离散帧词（VQ）：**区分性强（交叉 0）但转移稀疏**（长轨迹不可学）
   - 连续群编码（B2）：**转移流畅（生成通）但区分性崩（交叉 1.0）**
   - 两者互斥——"既区分又连续"需要引擎级机制（码本承诺/侧抑制），
     超出本路线范围。

## 硬边界（穷尽后的最终答案）

| 边界 | 内容 | 根因 |
|---|---|---|
| ① 轨迹全变不可学 | 鸟/牛长帧轨迹跳变率 0.96-1.0 → bigram 转移对不重复 → 生成一致率 0.5-0.6 封顶 | 离散转移需要转移对重复出现 |
| ② 连续表示交叉失控 | 群编码帧群在音间高度重叠 → 概念桥建在重叠群上 → 交叉 1.0 | 连续表示缺乏区分性边界 |
| ③ 时间尺度 | 逐脉冲（<10ms 粒度）超出 trace 窗口（~2 步） | 动力学时间常数不匹配 |

## 路线总结（"先量化原始音频"的回答）

**没有完全走不通，但走到了离散/连续的取舍墙**：
- 感知：可行（VQ+长帧：三音全通、交叉干净）——真实音效"听懂"成立；
- 生成：在"长帧+轨迹可重复"条件下可行（猫全通），通用逐帧复现需要
  连续表示（B2 通）但代价是区分性崩溃；
- 真正的下一步是引擎级"连续表示+区分性"机制（VQ 码本承诺损失、侧抑制、
  连续向量转移学习）——这是从"离散词网络"到"连续感知网络"的换代，
  不再是物理层/探针能解决的范畴。
