## 一、场景目标（最终形态）

```
三刺激源：环境（场景事件）/ 听觉（妈妈说：前缀）/ 自身 tick（相位念头）
LLM 妈妈（一次调用多功能——AAA 节标记式）：
  故事（沉默/例行）→ 网络听 → 好奇（域外词）→ 指物问/完整问句
  → 妈妈解释+发散 → 学词入域+问句固化 → 事后询问 → 回忆验证 → 奖励
奖惩体系：基础×1.03 / 高分×1.06 / 直接回答×1.08 / 连对×1.12
          句冷却 30t / 复读减边×0.8 / 无效字减边×0.8 / 验证门沉淀
记忆沉淀：快照（net+固化句+验证门）+ --resume 恢复
```

## 二、发现的问题与解决办法（25 项）

### A. 网络行为问题（5）

| # | 问题 | 现象 | 解决办法 |
|---|---|---|---|
| 1 | **复读机** | 网络每 tick 复读同一回声句，永不沉默（故事永不触发） | 表达冷却 12 tick + 复读减边（用户规则） |
| 2 | **复读误伤对答** | 妈妈反复问"饿了吗"，网络每次答「我饿了」被当复读减边两次 | 判据改为"**换问题还说同样的话**才算复读"（同问题重复回答 = 正常对答） |
| 3 | **链漂移** | 「吃了就睡觉**因为今天下雨**」——散文残留链 | 回答路径**固化句优先**（`free_read(consolidated=, ctx=, validation=)`——问"饿了吗"→ 直接读出「我饿了」） |
| 4 | **减边打碎链** | 反复 ×0.5 后链碎成「吃/了/双」残片 | 句冷却（时间惩罚 30t，零结构伤害）为主 + 减边降级为最终手段 + 惩罚温和化 ×0.8 |
| 5 | **自发表达误罚** | 网络自发提问被 LLM 评"贴合 0"触发惩罚 | 贴合惩罚**仅对答生效**（自发表达评贴合无意义） |

### B. LLM 接入问题（4）

| # | 问题 | 现象 | 解决办法 |
|---|---|---|---|
| 6 | **标点事故** | LLM 把标点+「的」判无效字，减边 27739 条 | 标点过滤 + 功能词/需求词**永不减** + 判定标准改为"杂字"（哒/咯/呀） |
| 7 | **预算饿死** | 判定失败后 junk 不清空 → 连续失败连打 8 次吃光预算 | 判定后无论成败清空 + 冷却 60 tick |
| 8 | **LLM 失败率 ~20%** | 限流/超时/裸输出（无节标记） | 重试 3 次（间隔 0.8/1.6/2.4s 渐增）+ 裸输出容错（无节标记文本当妈妈直接说的话）→ **失败率 0%** |
| 9 | **故事退化** | ZPD 上下文把故事压成电报语（「小鸭子，饿，饿」） | ZPD 只约束【衍生】【示范】；【故事】保持完整且**允许出现 1-2 个新词**（听不懂才会问——知识来源） |

### C. 对话机制问题（6）

| # | 问题 | 现象 | 解决办法 |
|---|---|---|---|
| 10 | **提问被吞** | 表达冷却期妈妈的提问被无条件清空 → 网络装死 | 冷却中 q_nouns **保留**（提问不丢） |
| 11 | **网络无回应** | 开场话无疑问词 → q_nouns 空 → 网络永不主动互动 | 开场带疑问（"宝宝饿了吗"）+ 提问保留机制 |
| 12 | **妈妈每句都问** | 衍生必带问句 → 网络永远对答、没有自由时刻提问 | 衍生允许"讲知识不问句"（给网络插话空间） |
| 13 | **好奇词质量差** | 网络问「给？一个？小？它？」——功能词被当"不懂" | FUNC 白名单大幅扩充 + 好奇信号只在**故事/衍生**扫描（回应/解释是教学，不再引发好奇链） |
| 14 | **吸收过滥** | 解释句里「咪/喵/喵/喵」拟声碎片全入域（域膨胀） | 只吸收**网络问的目标词**（asked_word） |
| 15 | **指物问退化** | 网络问「天上掉？一双？小手？」（量词/口语碎片） | 同上（好奇源收窄）+ FUNC 再补 |

### D. 问句结构与记忆（5）

| # | 问题 | 现象 | 解决办法 |
|---|---|---|---|
| 16 | **问句读不出** | 教 `X→是→什么` 边后 free_read 仍输出「饿/了」——**桥词中继不输出桥词**（"是"被吞） | 问句走**固化句路径**：`cons[X] = [([X,是,什么], …, "ask")]`——整句读出含"是"（单测 4 词全通过） |
| 17 | **答案回忆输出问句** | `free_read` 固化选择里 ask 条目排前 | `_read_answer` 直接取 `ctype=="answer"` 条目 |
| 18 | **答案固化串味** | `last_explain` 被衍生成覆盖 → 固化的答案是衍生句 | 答案 toks **直接传参**（`teach_ask(w, answer_toks)`） |
| 19 | **记不全不重教** | 回忆失败只打日志"妈妈再说一遍"但没说 | 失败 → 妈妈真的把答案再说一遍（重新教学） |
| 20 | **记忆不沉淀** | 每轮运行都问同样的问题（蝴蝶？蘑菇？）——场景纯内存，学完即丢 | 场景结束 `save_snapshot`（net+固化句+验证门，tag="场景沉淀"）+ `--resume`：**从固化表推断恢复**（cons 有 ask/answer 条目的词 = 学过的 → 入域 + 问句结构恢复）——实测恢复 13 学词 + 7 问句 |

## 三、关键机制（沉淀为本项目的资产）

1. **"听过词 ≠ 懂词"**——懂 = 教学域内（domain/teach_out）；词表内但域外 = 好奇信号（蝴蝶/蘑菇/雨——有神经元没教过意思）
2. **问句 = 固化**——自由链读不出问句（桥词被吞），固化句路径整句读出（X是什么 含"是"）
3. **回忆验证**——提问记 WM → 30t 后妈妈问 → 网络用固化问句/固化答案读出（记得 = 结构能读出）
4. **奖惩哲学演进**——删边（麻木）→ 减半（碎链）→ 句冷却+温和减边+验证门累积（可逆+抗噪）
5. **记忆 = 结构**——场景学习全落在快照（边/固化句/验证门），`--resume` 从 cons 推断恢复——**记忆不丢，网络持续成长**

## 四、遗留边界（诚实）

- 好奇词质量依赖故事里 LLM 生成的新词（网络"会"的越多，越难触发好奇——resume 后 0 提问是正常现象）
- 吸收词的教学出边（teach_out）部分恢复（answer 条目推断）——自由链能力弱于问句/答案路径
- 验证门/学词目前存于快照但跨版本追溯未做（v36.2→36.3 的差异可对比）
