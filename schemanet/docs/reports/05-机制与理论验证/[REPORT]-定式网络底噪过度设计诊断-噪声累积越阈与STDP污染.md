## 一、发现经过（模型能力 CLI 暴露）

v51（无边状态）下运行纯模型能力 CLI（`_cli_model.py`）——输入一个词：

```
你> 猫
  模型输出: 猫            ← 回波（复读——模型能力，正确）
  噪声漂移: 40 词（徒弟、重伤、百日、舟山、第十…）  ← 异常
```

注入「猫」后，空拍时网络自发发放一批**随机词**——每 2 拍一批、每批 20 词（wta_k=20）。

## 二、底噪形成机制（四层，已跟踪实证）

**① 噪声注入（每步）**：引擎 `noise_p=0.06 × noise_amp=0.5`——每个神经元每拍 6% 概率被注入 +0.5 膜电位（模拟背景输入/离子通道噪声）。

**② 累积越阈**：膜电位每步只衰减 ×0.9（不归零）→ 连续 3 拍命中即过阈（θ=1.0）。跟踪「徒弟」神经元 #36883：

```
初始: v=0.000
t0 注入猫: v=0.500   ← 噪声命中 +0.5
t1 间隔:   v=0.950   ← 再命中: 0.5×0.9+0.5
t2:        v=1.355 ≥ θ=1.0 → 发放！（发放后 v 清零）
```

数学期望：149,396 神经元 × 0.06³ ≈ **32 个/3 拍**越阈。

**③ 全局 WTA 截断**：越阈神经元全部是候选 → 取 top 20（wta_k=20）→ 每批固定 20 个"随机词"。

**④ 发放节律（每 2 拍一批）**——空拍统计实证：

```
空拍 0: 候选 0,  发放 0     ← 注入拍后（唤起路径——无边→drive=0→候选全过滤）
空拍 1: 候选 0,  发放 20    ← 学习路径（全局 WTA）——噪声累积越阈
空拍 2: 候选 88, 发放 0     ← 唤起路径——无边→候选全剔+侧抑制清扫×0.3
空拍 3: 候选 0,  发放 20    ← 学习路径——又一批（清扫后重新累积）
```

发放 → 不应期 1 拍 + 侧抑制清扫压低落选者（×inh_loose=0.3）→ 偶数拍被抑制、奇数拍再冒 → "每 2 拍 20 词"节律。

## 三、STDP 污染实证（问题的真正危害）

底噪不是"显示上难看"——它是**知识污染引擎**。实验：v51（0 边）开 STDP，无奖励注入「猫」30 次：

```
30 次无奖励教学后总边数: 0 → 712 条
「猫」的出边: 猫→徒弟 / 猫→重伤 / 猫→百日 / 猫→舟山 … 全部 w=15.0（饱和）
全网最强边: 「要造→相会」w=38.4 —— 漂移词之间 Hebbian 共发放互连
```

污染链：

```
注入「猫」→ 猫发放（pre_trace 写入痕迹）
→ 空拍：噪声越阈 → 20 个随机词发放
→ STDP 无条件执行（mod = 1+da_gain×RPE，da=0 时 mod=1.0 照样学）
→ 猫→徒弟/重伤/百日… 建边（pre_trace 前驱→当前发放，stdp_pre=0.5/次）
→ 漂移词同拍共发放 → Hebbian 两两互连
→ 30 次 → w=15 饱和 → sleep 也删不掉（强边）
```

**结论：不需要乱灌语料——底噪 + 无条件 STDP 自己制造随机边。**
"乱灌自成一派语言"的真正引擎是双重的：外部语料统计共现（已诊断）+ 内部底噪 STDP 吸收（本次诊断）。v51 清空后若直接开学习，第一课就会重新污染。

## 四、生物对照（用户诊断定稿）

```
生物: 环境刺激时刻存在——视觉/听觉/触觉持续注入——底噪被信号盖过
      （自发活动 ~数 Hz 背景 vs 刺激驱动发放——刺激主导）

代码: 注入是稀疏事件——一个词只有 4 个神经元，其余 149,392 个神经元
      在拍空拍——没有任何"环境刺激"压制 → 底噪相对被放大
      （14.9 万神经元 × 6% 概率每拍——累积越阈 ≈ 32 个/3 拍）
```

**定稿：底噪在定式网络里属于过度设计。** 生物的背景活动有环境刺激时刻压制，代码里没有持续环境输入，稀疏注入 + 高幅噪声（0.5 足以 3 连中越阈）= 底噪从"背景"变成"主导"。

## 五、解决方案（已验证）

### 5.1 降噪：noise_amp 0.5 → 0.2

噪声保留（自发活动形态不消失——真自发思考仍需要），但**幅度不足以累积越阈**（0.2 需 6 连中才越阈：0.06^6 × 15 万 ≈ 0.0004 个——实际永不）。实测：

```
noise_amp=0.5: 30次×4空拍漂移发放 = 1200 次（现状——严重）
noise_amp=0.3: 67 次（降 94%）
noise_amp=0.2: 0 次（完全消除）✓
noise_amp=0.1: 0 次
```

### 5.2 学习门控：无信号来源的发放不参与学习

即使未来参数变化导致偶发越阈，也不该被 STDP 吸收。门控条件（引擎 `step`）：

```
signal = 本拍有注入脉冲（inp_idx 非空）或 本拍有传播驱动（drive_any > 0）
学习块（Hebbian + STDP）只在 signal 时执行
pre_trace 只记录 signal 发放（噪声发放不留痕——防"噪声→下一拍注入词"边）
slot_freq / elig 只对 signal 发放计数
```

时序验证（30 次注入「猫」）：
- 注入拍（t0）：有注入 → 学 ✓
- 传播拍（有边后）：有 drive → 学 ✓
- 噪声漂移拍（t2/t4…）：无注入无 drive → **不学** ✓

### 5.3 附带发现：elig 资格迹只写不读

`elig[top]=1.0` 置位 + `elig *= decay` 衰减——**无任何读取点**。R-STDP 三因子的"资格迹（时间信用分配）"实际未兑现：学习调制只有全局 `mod = 1+da_gain×RPE`（无 per-neuron 时间信用）。已记录，待后续实现（非本次范围）。

## 六、修复实施（已落地，2026-08-11）

- `sparse_net.py`：`noise_amp` 默认 0.5 → 0.2；`step()` 学习块加 signal 门控
- 快照参数：v51 快照内保存的 noise_amp=0.5 由加载方（CLI/教学脚本）覆盖为 0.2
  （快照是历史记录不改写——新版本快照将固化 0.2）
- `_cli_model.py`：加载 v51 时覆盖 `noise_amp=0.2`

### 6.1 实施中发现的两个二级 bug（排查过程）

修复门控时暴露了污染链的**两个隐藏环节**——它们同样产生错误边，必须一起修：

**二级 bug 1：注入拍 Hebbian 混入同拍噪声词**

修复①（门控）后仍观察到：教学「猫 是 动物」→ 猫出边出现「天水市/威粉/客胜/彼岸花…」w=1.2（=eta×12 次累积）。根因：**注入拍走学习路径（全局 WTA）**——top 是全局越阈候选，同拍噪声越阈词与注入词**一起进入 Hebbian 共发放对**（top 内两两互连）。修复：`top_sig = top[sig_mask[top]]`——学习只作用于"信号神经元"（注入 ∪ 传播驱动），噪声词被过滤。

**二级 bug 2：pre_trace 双重更新 + 间隔拍痕迹停流**

修复②（top_sig 过滤）后仍观察到：「猫→动物」跳跃边 w=8.0。根因（两个叠加）：
- **双重更新**：信号拍在门控块内更新 pre_trace + 尾部又更新一次 → 痕迹异常累积（猫 1.688 跨两拍不衰减）→ STDP 前驱判定含陈旧词 → 学出「猫→动物」（不是相邻前驱）
- **间隔拍痕迹停流**：间隔拍（top 空）pre_trace 不衰减 → 猫痕迹残留过久（0.844 > trace_thres 0.3）

修复：**衰减无条件放尾部（间隔拍痕迹持续衰减）；"加"只加信号发放（`_sig_spikes` 掩码）**——学习态 pre_trace 更新唯一化，与旧语义位级兼容。

### 6.2 冻结态对拍（位级一致性铁律）

learn_gate=False 时 `pre_trace *= decay; pre_trace += new_spikes` 保持原逻辑——3 组注入序列对拍 **位级一致** ✓（项目铁律：评估冻结态物理零改动）。

## 七、验证（实测——修复后）

| 测试 | 结果 |
