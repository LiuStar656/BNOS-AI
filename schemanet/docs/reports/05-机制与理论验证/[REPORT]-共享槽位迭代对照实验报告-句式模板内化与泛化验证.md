# [REPORT] 共享槽位迭代对照实验报告——句式模板内化与泛化验证

> 日期：2026-08-11 | 状态：[OK] | 关联：`stage/_exp_slot_shared.py`（对照实验）、`schema_net.py`（consolidate_sentence 迭代）、`_sanzi_jing.py`（吸引子修复先例）
> 需求链（用户 2026-08-11）："经常用的句子可以很快说出来，但是不经常用的就会组装错误、前后颠倒，这时候先想用句式纠正再输出——关键是这个想和纠正只靠网络该怎么办" + "共享槽位升级是补丁还是迭代？" → 结论：迭代（句法压缩）→ 对照实验验证泛化缺失是否解决

## 一、背景：泛化能力缺失（实测证据）

**现状**（句私有槽位 consolidate_sentence）：每句固化 = 句内每词分配新神经元（槽位），槽位间强边主干——**每句一条独立神经轨道**。

**实测缺失**：
```
front=猫   → 猫/饿/了/的/不/很/有     ✗ 「猫渴了要喝水」读不出——猫→饿 语料边（131.6）劫持
front=小狗 → 小狗/渴/了/的/不/很/有   ✗ 主干走 3 词就漂移（"了"的词边"的"抢过主干）
```
三个根因（自由链组装错误同源）：① 一阶转移语境污染（bigram 无语境）；② 局部对整体错（每步合法、组合漂移）；③ 无句子边界（任意词起步、前后颠倒）——**固化句有顺序轨道（主干）但句私有——主体换不了、句式归纳不出来**。

## 二、迭代设计：共享槽位定式（句法压缩）

**本质**：从"背句子"（句私有轨道）到"长句式"（跨句共享定式）——对齐用户"sleep 不是暴力剪边，而是压缩"哲学——多条同构句压缩成共享句式定式 + 内容位实例（系统巩固：海马情景 → 皮层句法）。

**结构**：
```
定式 = [主体位槽] → 渴 → 了 → 要 → [行为位槽]
       └ 内容位（槽概念——跨句共享）   └ 固定词位（词神经元即槽）
```
- **内容位槽概念**：跨句共享（所有同构句的主体位/行为位共用一个槽）——词绑定槽一次 → 多句可用
- **绑定方向化**（实验教训）：主体位词→槽（入口触发）、行为位槽→词（出口读出）、定式边前→后（轨道）——**双向绑定会回环串扰**（槽→词跳回别的绑定词）
- **强度**：定式边 1024（主干同款）——压过语料边（猫→饿 131.6）与词级竞争（"的"11.2）

## 三、对照实验（stage/_exp_slot_shared.py）

**教学**：教「小狗渴了要喝水」→ 定式建立 + 小狗↔主体位 + 喝↔行为位；教「猫渴了要喝水」→ **只绑定 猫↔主体位**（共享——不重学固定段）。

| 指标 | 对照组（句私有） | 实验组（共享槽位） |
|---|---|---|
| front=猫 | ✗ 猫/饿/了/的/不/很/有（换不了主体） | ✓ **猫/渴/了/要/喝/水/的**（完整！） |
| front=小狗 | ✗ 主干 3 词后漂移 | ✓ **小狗/渴/了/要/喝/水/的**（完整！） |
| front=他 | ✗ 读不出 | △ 诚实失败（未绑定——泛化前提是词位绑定） |
| 教学增量（第 2 句） | 整句重固（5 词双向绑定） | **只绑定 1 词**（猫↔主体位） |
| 多实例共存 | 两条独立轨道不相通 | ✓ 同定式两实例各自完整读出 |

## 四、结论

1. **主体替换泛化解决**——"猫"通过共享主体位槽进入句式轨道——从"背句子"到"长句式"的质变（构式语法：句式是抽象构式，内容是填充）
2. **顺带修复漂移**——共享定式固定段 1024 轨道压住词级竞争（对照组小狗句 3 词即漂移；实验组 6 词完整）
3. **教学量级降**——新变体 = 绑定 1 词而非整句重固（语言发展对应：学会句式后学新词即可造句）
4. **诚实边界**——泛化前提 = 词位绑定（"他"需一次"他→主体位"绑定）——绑定一次多句可用，未绑定不可填
5. **技术教训**——绑定必须方向化（入口/出口/轨道三分）——双向绑定回环串扰（实验第 3 版修掉的 bug）

## 五、接入路径（迭代版为最新版）

1. `consolidate_sentence` 升级：同构检测（长度+固定词位相同）→ 建/复用定式 + 内容位方向化绑定（旧模式保留参数兼容现有快照）
2. 定式表挂网络（ng.skeletons）→ snapshot 持久化（_pack_net 扩展）
3. `free_read` 固化分支扩展：cons 实例命中 → 整句读出（兼容）；**词位绑定命中 → 定式轨道读出**（新主体自动填位）
4. 场景"想-查-纠-说"接入：自由链生成 → 结构自查（教学边）→ 定式吸引子纠正（_sanzi_jing 机制）→ 输出
