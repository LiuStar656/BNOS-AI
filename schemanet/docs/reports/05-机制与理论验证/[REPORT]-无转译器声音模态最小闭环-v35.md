# [REPORT] 无转译器声音模态最小闭环：声波 → 帧词 → 听声唤起词（v35 实证）

> 日期：2026-08-11 | 版本：v1 | 状态：已完成（全部 PASS）
> 前置：v35 快照（`runs/v35_0_20260811_044836`）
> 脚本：`_probe_sound_modal.py` | 留档：`runs/_probe_sound_modal_20260811_091715/result.json`

## 背景

用户多模态路线（2026-08-11）：不用 ASR/OCR/STT/TTS/YOLO 等外部模型转译，
网络直接从原始信号长出模态概念。经评估，**声音是最优起点**（时序是脉冲
网络的母语；物理层最薄；合成数据可测）。本探针验证最小闭环：

```
声波 ─物理层(过零率+能量AGC，纯信号处理，无语义)─> 帧词序列(频率bin×能量bin)
     ─现有机制(_learn_sentence，bigram链)─> 帧→帧→…→概念词
     ─听声唤起─> 注入帧序列 → 概念词模式激活
```

## 方法

- **合成三音**（8kHz 采样）：鸟 3000Hz / 牛 200Hz / 猫 1000Hz 纯连续音 0.5s
  （频率间距 ≥3 bin×250Hz，过零率抖动 ±1 bin 不跨邻音）；
- **物理层**：50ms 帧 → 过零率→频率 bin、RMS→能量 bin（AGC 音内归一，
  响度变化不改变编码）→ 帧词 `z{f}e{e}`（16×4=64 感知模式）；
- **网络两小节**：A 空白网络（n=2048，机制参数从 v35 快照对齐，rng=7）
  纯内存；B v35 单快照副本（`base/`，补感知词自动扩容 149312→149568，
  教学临时降噪 noise 0.06→0——v35 每步 ~9000 噪声神经元会污染感知词行）；
- **教学**：帧序列 + 概念词拼接（"z12e3×9 鸟"），`_learn_sentence` ×3 轮；
- **验证**：①桥边（尾帧词→概念词）②原音唤起比例 ③三变体（响度×0.5 /
  +10% 高斯噪声 / 时长 0.6×）④交叉混淆（他音不唤起本词）。

## 过程中发现并修复的 5 个坑（引擎/探针工程教训）

| # | 坑 | 根因 | 修复 |
|---|---|---|---|
| 1 | 验证污染后续验证 | **evoke 路径也在学习**（learn_gate=True 时 step 学习块在唤起路径同样执行），一次验证把被验证词出边行污染成 60+ 稠密边 | 验证时临时关 learn_gate |
| 2 | 桥边测错方向/位置 | STDP 只学到**尾帧→概念词**（trace 衰减 0.5/步，非尾帧 pre_trace <0.3 阈值） | 桥边查尾帧词 |
| 3 | 帧词共享串扰 | 8bin(500Hz/bin) 时 2000Hz 与 1500Hz 抖动区在 1750Hz 重叠；3000Hz@8kHz 欠采样（2.67 samples/周期） | 16bin + 频率间距 ≥3bin + 3000/1000/200Hz |
| 4 | 交叉=1.0 的深层机制 | **噪声 hub**：小网络噪声神经元（6%×n/步）必然重复选中 → 与多音概念词共发放 → 0.5 级弱边中继；实测猫行→鸟 0.5 | 验证关噪声源 + **教学后剪弱边**（<1.0，v35 sleep 剪枝同款） |
| 5 | v35 唤起 0.0 | 帧间 spikes 残留 → 下一帧注入走"唤起路径+旧模式 92 万边洪泛"，新帧词被挤出 WTA | 唤起逐帧清 spikes（仿 `_learn_sentence` 注入语义） |

坑 1/4 与 `_probe_mem_share` 的发现同源（evoke 学习污染），坑 4 直接印证
v34↔v35 剪枝报告的"弱边海洋是底噪"——剪弱边后交叉归零。

## 结论

1. **无转译器声音感知在现有引擎上完整可行**：物理层（过零率+能量 AGC）
   编码 → 帧词即感知模式 → 现有 `_learn_sentence` 教学 → 听声唤起概念词。
   空白网络与 v35 单快照接入两小节全 PASS（原音/三变体全 1.0、交叉 0.0）。
2. **"听声唤起词"= 概念词复用现有词表**（鸟/牛/猫），跨模态绑定 = 帧词与
   概念词的 bigram 桥——**没有任何外部转译模型**。
3. 模式形成（感知模式→概念）与词汇模式同一套机制——多模态扩展 = 模式
   来源扩展，引擎零改动。

## 边界与后续

- 纯连续音（节奏/音色/包络维度未测；脉冲串的帧边界抖动需更稳的包络
  编码）；合成音单说话人风格；概念词均为 v35 已有词。
- v35 接入做了两处实验性调节（教学降噪、唤起逐帧清 spikes），未评估对
  v35 既有记忆的影响——接入后的完整回归（free_read 12 题等）留待下一轮。
- 下一步可选：①脉冲串节奏维度（编码加包络 bin）；②感知模式自聚类
  （信号重复结构 → 网络自己分配模式，替代手工 allocate）；③多模态
  槽位化（声音槽1/文字槽0 跨槽绑定，衔接"多模态用槽位"架构结论）。
