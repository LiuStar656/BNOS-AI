## 一、起点：用户诊断（2026-08-11）

> "改用拼音的形式肯定是我们之前的颗粒度把网络焊死了"

词粒度（每词 4 神经元闭集模式）的焊死症状——全部实验证实：

| 症状 | 词粒度证据 |
|---|---|
| 死配对 | 叫→爸爸 256/768（4×4×16 全连接死记——"256 也不应该存在"） |
| 次序马太 | 爸爸先教 768 vs 妈妈后教 192（4 倍差——竞争归一化也压不掉） |
| 闭集爆炸 | 哥哥未教 → 零响应；新词 = 新神经元 + 新教学——组合性为零 |

**根因**：词粒度下 爸爸/妈妈/哥哥 是零重叠的死模式——网络看不到共享的
韵母 a、看不到 CV-CV 重复节奏——**结构信息在错误颗粒度下不可见**。

## 二、成功路径（可复现）

### 路径 1：音位级（23 声母 + 25 韵母 = 48 原子）——v54.6

```
爸爸 = b a b a    妈妈 = m a m a    哥哥 = g e g e    叫 = j iao
```

| 成果 | 数据 |
|---|---|
| 音节组合边自然涌现 | b→a：1.04 → 16.00（封顶，30 次教学）|
| 重复边 | a→b：0.43 → 12.91 |
| 音节自持振荡 | 输入 b,a → 空拍 b→a→b→a 无限交替——音节组块的物理基础 |
| 联想涌现 | 输入 j,iao → 带出 b,a 链（iao→b=16——配对 (iao,b) 相邻） |
| ★ 马太中和 | a→b 12.97 vs a→m 12.91（同次数教学完全对称——共享韵母 a = 马太免疫） |
| ★ 当前论元胜出 | wta_k=4：叫妈妈 → 纯 m,a 链（注入论元 36 > 联想边 16）；叫爸爸 → 纯 b,a 链 |
| 自由联想无独强 | 输入"叫" → b/m 对称交替（词粒度是爸爸独强） |

### 路径 2：检索整串一次注入（用户提议"jiao ma ma 一次注入"）

```
一次注入 jiao ma ma → 注入拍只 iao 发放 → 空拍: m→a→m→a（妈妈链自动展开）
一次注入 jiao ba ba → 空拍: b→a→b→a（全程纯爸爸——无需逐音素引导）
```

**协议不对称是特性**：教学必须逐拍（时序=结构），检索可以整串（听到整句 → 链展开）。

## 三、失败路径（诚实归档——用户点名记录）

### 失败路径 A：词粒度（起点——被焊死）

死配对 + 次序马太 + 闭集爆炸——**已经证伪**（v52.2 实验）——本轮的起点教训。

### 失败路径 B：字母级颗粒度（26 字母——j-i-a-o-m-a-m-a）——链融合

```
能建边：j→i 16、i→a 16、a→o 15.9、o→b 12.9、b→a 16（30 次全封顶）
但：a 是三条链的同一个神经元（叫的第 3 字母 = 爸爸/妈妈的韵母）
   → a 的出边三路：a→o（叫内部 15.9）> a→b/a→m（8.5）
   → 检索 jiaomama 空拍时 a 带出 o（叫的尾巴）→ o→b → 爸爸混入
```

**失败原因**：颗粒度不是越细越好——**过度共享 = 纠缠**。字母级把"同音位
异实例"焊成同一神经元；音位级（iao 原子与 a 分离）恰好实现抽象分离。
**物理含义**：语言共享的是结构/节奏（CV-CV 重复），不是具体音素实例——
儿童听的是音（bā）不是字母（b-a）——音位是语音系统，字母是书写系统。

### 失败路径 C：教学整串一次注入——死记重演

```
整串共发一拍 ×30 → 所有两两配对等权 15.56（240 条全连接边）
→ 检索锁死在 j↔iao 内部振荡——论元链完全不展开
```

**失败原因**：无先后时序 → STDP 无方向性 → Hebbian 等权强化全部共发对
（j→b、iao→a 等"非法"对全部等权）——**词粒度 256 死记在音素级重演**。
时序是 STDP 方向性的来源——一次共发丢时序 = 丢结构。

### 失败路径 D：未教论元泛化（叫哥哥——CV-CV 重复模板）——未涌现

```
输入「叫 哥哥」(j iao g e g e) → g、e 无组合边（从未教学）→ 空拍后
bm,a 循环——复读"爸爸/妈妈"——哥哥链无法自持（wta=4 也复读妈妈）
```

**失败原因**：g,e 组合缺失——不是规则缺失。**"叫X→X"的 CV-CV 重复模板
（规则层级/系统 2 主干）本轮未涌现**——诚实记录。

**已识别的钥匙（未实施）**：拼读教学——音节组合完备化（先教 b-a→ba 的
拼读——常用音节组合边全覆盖）——音节全部能自持后，"叫哥哥"输入
j,iao,g,e → g,e 自持振荡 → 哥哥链成立——无需"叫→哥哥"配对——组合性
从音素级上升到音节级——这正是人类幼儿路径（先学拼读，再理解"叫+任何
称呼"）。完全未教的新音节依然失败（渐进——合理——儿童听到新音节也
需要示范）。

## 四、机制洞察（本轮沉淀）

```
① 时序 = 结构:  STDP 方向性来自先后时序——教学必须逐拍（失败路径 C 教训）
② 共享 = 马太免疫: 共享节点（韵母 a）上的出边对称——同次数教学 → 权重
  相同——竞争从"不相交模式"变"对称分支"（a→b 12.97 vs a→m 12.91）
③ 颗粒度决定可见结构: 词级（零共享·死记）/ 音位级（共享结构·干净）/
  字母级（过度共享·纠缠）——音位级是"共享但不纠缠"的正确层级
④ 注入论元 > 联想边: 论元重读（amp 20 > w_max 16）+ WTA 收窄（wta=4）
  ——"听"（注入）时注意跟随输入——当前论元胜出
⑤ 协议不对称: 教学逐拍（时序建边）/ 检索整串（整句识别）——
  对应儿童学新词慢速分解、听熟词整句理解
```
