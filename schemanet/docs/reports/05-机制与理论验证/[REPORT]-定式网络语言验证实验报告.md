## 一、实验背景与目标

**方向**：定式网络（SchemaNet）自身向大模型方向发展（用户决策：非外挂、非吞并）。核心论证：LLM 的本质 `P(token_t | token_{<t})` 与已验证的 STDP 转移学习同构——STDP 学脉冲模式的顺序转移，语言建模学 token 的顺序转移，机制同一，缺的是**规模**、**生成**、**长程上下文**三根支柱。

**最小验证目标**：先证明"定式网络（SchemaNet）+ 真实中文文本 → 词间转移学习"成立，对照 n-gram 基线诚实定位学到多深。这是定式网络成为大模型的地基。

## 二、实验设计

```
语料(100 条中文短句) → jieba 分词 → top-K 词表(142)
→ 每词=固定种子随机稀疏脉冲模式(n=2048, k=8)
→ STDP 教学式逐词喂句 → 定式网络沉淀词间转移
→ 评估① next-token top-1 准确率（训练集重建 + 留出句泛化）
→ 评估② 变量句式唤起 + 逐词生成
→ 对照 bigram / trigram 基线（同测试集、同 top-1 判定口径）
```

### 2.1 参数（seed=42 最终版）

| 参数 | 值 | 说明 |
|---|---|---|
| n（lang_n） | 2048 | 语言实验专用神经元数（静态实验 n=32 编码区分度不足，见三） |
| k | 8 | 每词稀疏神经元数 |
| 词表 K | 142 | top-K 词表（语料去重后实际 142 词，OOV=0） |
| stdp_pre | 0.5 | STDP 前驱→后继强化幅度 |
| w_max | 16.0 | 语言实验权重上限（转移强度∝共现次数，封顶会并列） |
| trace_decay / 阈值 | 0.5 / 0.3 | 只学相邻 bigram 转移 |
| 数据划分 | 80 训练 / 20 留出 | 随机抽样（seed+9000），非固定后半段 |
| 编码 | crc32 稳定哈希 | hash() 受 PYTHONHASHSEED 随机化，禁用 |

### 2.2 编码（关键契约）

- 每词 = 固定种子随机稀疏模式：`rng(crc32(word))` 从 n=2048 取 k=8 神经元置 1
- **稳定性**：同词永远同一模式（crc32 跨进程稳定，两次运行结果一致）
- **分布式**：所有词共享神经元，靠组合区分（"神经元被无数记忆共享"）
- **区分度**：两词期望交集 `k²/n = 64/2048 ≈ 0.031`

### 2.3 教学式学习（本实验引入的关键修正）

学习与回忆路径分离：

```
学习（_learn_sentence）：注入每词前清 v 与 spikes（无传播驱动）→ 当前词干净发放
                          → STDP 只学 pre_trace→当前词的相邻 bigram 转移
回忆（_evoke_prefix）：   保留传播驱动（注入前缀 → 网络自己唤起后继词）
```

### 2.4 三种读出对照

| 读出 | 方式 | 语义 |
|---|---|---|
| echo（回响） | 注入前缀 → 回响 1 步 → 激活集合覆盖率 | 网络动力学唤起（硬决策） |
| wsum（W聚合） | 直接读 W 转移总强度 argmax | 学到知识的直接量化 |
| wnorm（W归一） | W 聚合 ÷ 源词传出突触总强度 | 条件转移概率近似（与 wsum 同排序） |

## 三、诊断过程：三个"离谱"现象的根因

本次实验调试中遇到三个反常现象，全部定位并修复，是理解实验结果的关键上下文。

### 3.1 "无聊垄断"：W[无聊←我]=14.0（单次出现的词被吞并）

**现象**："无聊"在语料中只出现 1 次（"我觉得无聊"），但 W[无聊←我]=14.0 满额，且"无聊"传入突触来源全是高频词。

**根因**：旧版 `_learn_sentence` 学习时保留传播驱动——强组装（高频词"我"）的复发发放 WTA 压掉注入词（v-clear 后注入词脉冲 1.0 输给驱动 4.0），W 学到**网络自联想链而非语料词序**。症状还包括"我想X"出现 11 次却 W[想←我]=0。

**修复**：教学式重写（学习路径无传播，当前词干净发放）。修复后 W 严格∝语料共现次数：

```
W[喜欢←我] = 48.00   （12 次相邻 × 0.5 × 8 源 = 48 ✓）
W[想←我]   = 32.06   （8 次 × 0.5 × 8 ✓）
W[有点←我] = 16.50   （4 次 × 0.5 × 8 ✓）
W[今天←我] = 8.06    （2 次 × 0.5 × 8 ✓）
W[无聊←我] = 0.00    （无相邻转移，正确归零 ✓）
W[无聊←觉得] = 4.00  （1 次 × 0.5 × 8 ✓）
```

### 3.2 纯噪声越阈 446 神经元：两层原因

**① debug 脚本 bug**：噪声模拟每步新建 `default_rng(1)` → 每步噪声序列完全相同 → 命中神经元 v 累积到 0.5×10=5.0 → 全部越阈。446 是伪影。

**② 真实的多步累积（机制层面发现）**：旧"噪声卫生"论证（`0.9×0.5+0.5=0.95<θ`）只防了**连续两步**噪声，没防多步累积——3 次噪声命中在 ~10 步窗口内即可越阈（`1.0+0.9+0.81=2.71≥2` 或非连续组合）。真实网络 19 步零输入：**自发发放 109/2048 神经元**（单步发放数逐步达 WTA 上限 8）。

**影响评估**：教学式学习中无害（每步清 v，单步噪声 0.5<θ）；但回忆路径（`_evoke_prefix` 不清 v、长前缀多步累积）会污染 fired 集合。已在技术档案 6.10 留档为待办。

### 3.3 准确率被压到 0.07：n=32 编码区分度灾难

**现象**：语言实验报告显示 `n=32`，训练集准确率仅 0.07。

**根因**：`run_language_experiment` 沿用了静态实验 CONFIG 的 `n=32`，而 k=8 分布在 32 个神经元里 → 两词平均交集 `k²/n=2.0`，**67% 词对交集≥2**，词模式无法区分。这不是"转移没学到"，是编码空间太小。

**修复**：语言实验专用 `lang_n=2048`。n=2048 后碰撞对从 6735 降至 **6/10011**，W聚合准确率从 0.07 升至 **0.500**。

## 四、结果

### 4.1 编码预检

```
期望两词交集 k²/n ≈ 0.031（n=2048）
词对总数 10011，交集≥2 的碰撞对 6（n=32 时为 6735）
```

### 4.2 next-token top-1 准确率（同测试集、同口径）

| 模型 | 训练集 | 留出句 |
|---|---|---|
| SchemaNet-W聚合 | **0.500** | 0.087 |
| SchemaNet-W归一 | 0.500 | 0.087 |
| SchemaNet-回响 | 0.247 | 0.065 |
| bigram | 0.526 | 0.087 |
| trigram | 0.383 | 0.000 |

**解读**：
- **W聚合 0.500 ≈ bigram 0.526**：转移确实学到，直接读 W 就是有效 next-token 预测器。留出句 0.087 与 bigram 完全持平（受句式随机分布限制，非网络问题）
- **trigram 训练 0.383 < bigram 0.526**：trigram 条件在二元上下文 (a,b)，训练集里多数二元对出现次数极少或未出现 → predict 返回 None → miss。数据稀疏是 trigram 在一元评估口径下的正常代价；W聚合与 bigram 同为"一元上下文"方法，故同水平
- **回响 0.247 偏低是 WTA 稀疏发放的固有代价**，非转移没学到（见 4.5 分析）

### 4.3 变量句式唤起

```
cue='我喜欢' → top-6：吃饺子(0.375) 吃(0.25) 看书(0.25) 吗(0.125) 的(0.125) 见到(0.125)
                 ← 含真实宾语 ✓
```

15 种"我喜欢X"宾语在"喜欢"后平局（各 0.5 强度），WTA 每次只发 8 个神经元 → 覆盖分散、无词超过 min_cov，靠覆盖率排序取到的候选仍含真实宾语（吃饺子/吃/看书）。

### 4.4 生成样例

```
'你好' → 你好 呀 喜欢
'我'   → 我 喜欢
'今天' → 今天 过得 怎么样 喜欢
```

- 一步转移全部正确：你好→呀（"你好呀"）、我→喜欢（最高频后继）、今天→过得→怎么样（"你今天过得怎么样"）
- 句尾词（呀/怎么样）无后继后链式唤起开始漂移——词袋级模型的合理表现，无语法约束

### 4.5 回响读出偏低的结构原因（WTA 容量）

覆盖率读出要求词模式被完整激活（≥min_cov=0.4，即 8 神经元中 ≥4 个），而 WTA top-8 每次只发 **8 个神经元 = 恰好一个词的量**：
- 确定性强后继（如"我→喜欢"驱动 48.0 vs 次强 32.0）→ 8 个神经元全归"喜欢" → 覆盖 1.0 → 命中
- 多候选平局（"喜欢"后 15 宾语各 4.0 平局）→ 8 个神经元分散在 120 个候选里 → 任何词覆盖都 <0.4 → None

**结论**：覆盖率读出是动力学硬决策，只有确定性强后继才成功；**W 直接读出才是有效的预测接口**（0.500 ≈ bigram）。

## 五、结论

1. **转移学习验证通过**：STDP 教学式学习把语料词序沉淀进 W，直接读 W 的 next-token 准确率 0.500 ≈ bigram 0.526——"定式网络自己成为大模型"路线的最小验证里程碑达成
2. **W 强度严格∝共现次数**：W 是可信的条件转移计分器（w_max=16 消除封顶并列）
3. **编码契约成立**：crc32 稳定哈希 + n=2048 稀疏模式 → 142 词仅 6 对碰撞，可复现（两次运行一致）
4. **教学式学习是必要修正**：学习路径不清传播 → W 学自联想而非语料（无聊垄断）；清传播 → W 学语料词序
5. **已知边界**：① 回响（动力学唤起）受 WTA 容量限制，弱于 W 直接读出 ② 回忆路径噪声多步累积污染 fired 集合（待办）③ 只能学相邻转移（bigram 级），长程上下文未验证
