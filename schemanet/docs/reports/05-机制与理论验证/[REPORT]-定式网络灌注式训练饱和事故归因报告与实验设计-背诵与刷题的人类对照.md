# [REPORT] 定式网络灌注式训练饱和事故归因报告与实验设计——背诵与刷题的人类对照

> 日期：2026-08-11 | 状态：[OK] 实验完成——归因确认 | 关联：`_exp_flood.py`、v17.0 散文灌注史
> 需求（用户 2026-08-11）："灌注的时候是一篇文章灌注次数过多还是什么原因导致饱和事故？背诵课文和反复刷题也是一种灌注行为，但人并没有出现饱和事故（也有类似的：只会做题没有联想性被困死在记忆里了）"

## 一、灌注后遗症的历史证据（回顾确认）

**唯一句子级灌注点：v17.0**——"先见后教 + 并发训练（鲁迅 5 本散文全量先见 → 教学拉回 → 校准）"。

其后 v18 系列 **20 个分支**全部是"教学拉回"修补：

| 后遗症 | 证据 | 源头机制 |
|---|---|---|
| "我"万能桥 | "'我'垄断预测（无聊 14.0）与 W[我→想]=0（'我想X' 11 次却没学到）" | 散文"我"高频——统计垄断压制语义边 |
| 废话黑洞 | DEAD 词（大/说/好/还是/什么）+ BAN_EDGES 20+ 条手动禁边 | 高频功能词互驱（"的了/说大/什么好"） |
| "了就"桥 228→1024 | 自由链"X了"全部汇入"了就吃饭/睡觉"黑洞 | 散文"…了，就…"语篇衔接共现 |
| 256 饱和事故 | v30 被迫 w_max 16→64 | 散文高频共现对（的了/就在）推满 w_max |

**v34.0 实测**：单边饱和 1600/5600 万条（0.0%）且全是教学边（教学 ×15 的刻意强度）——散文饱和边已被 v18-v32 逐步压制，但结构残留（"了→就"=480 桥、自由链黑洞）仍在。

## 二、核心问题：灌注的什么维度导致饱和？

用户的关键类比：

| | 灌注方式 | 结果 |
|---|---|---|
| 网络（v17） | 鲁迅 5 本散文全量"先见" | 饱和事故 + 漂移 + 黑洞 |
| 人 · 背诵课文 | 反复背诵 + 日常变体使用 + 遗忘 | 不饱和 |
| 人 · 机械刷题 | 单一题型反复刷 | "只会做题，没有联想性，被困死在记忆里" |

**四个候选归因维度**（实验将分别操纵）：

1. **灌注次数**（同一句 ×1/×10/×50——机械重复）
2. **内容多样性**（同一句重复 vs 同主题变体句——背诵 vs 活用）
3. **遗忘机制**（sleep 开/关——人的遗忘使饱和边回落）
4. **验证/理解**（仅灌注 vs 灌注+验证门——机械记忆 vs 理解校验）

**可证伪的预期**：
- 若 A（次数）条件饱和↑且变体泛化↓ → 次数过多是主因
- 若 A 饱和但 B（变体）不饱和 → **内容单一重复**是主因（人背诵不饱和 = 变体+遗忘，不是次数本身）
- 若 C（sleep）饱和回落 → 遗忘是人的解药
- 若 D（验证门）选择正确 → 理解/标准是人的解药

## 三、实验设计

### 3.1 条件（同一 v32.0 基线独立灌注）

| 条件 | 灌注内容 | 次数 | 机制 |
|---|---|---|---|
| A1 | 「饿了就吃饭」（单句） | 1 | 基线 |
| A10 | 同上 | 10 | 适度重复 |
| A50 | 同上 | 50 | 过度重复（模拟机械刷题） |
| B | 5 个同主题变体句 | 各 10 | 多样性（模拟背诵+活用） |
| C | 单句 ×50 + sleep 遗忘 | 50 | 遗忘介入 |
| D | 单句 ×50 + 验证门固化 | 50 | 理解/标准介入 |

变体句集（B）：饿了就吃饭 / 我饿了想吃饭 / 肚子饿了要吃饭 / 饿了我去吃饭 / 饿了就要吃饭

### 3.2 测量指标

- **饱和度**：饿→了 / 了→就 / 就→吃 / 吃→饭 各 16 条神经元边中达 w_max 的比例
- **漂移/固化**：free_read(["饿"]) 的自由链输出（是否黑洞/漂移/正确）
- **变体泛化**：5 个未教问法（肚子饿了怎么办？/咕咕叫了怎么办？…）的应答正确率（含"吃/饭"）
- **联想性**：从"饿"出发的候选多样性（top-5 中非"了就吃饭"链的词数——"困死在记忆里"的量化）

### 3.3 对照逻辑（人）

- A10/A50 vs B：重复 vs 变体——"背诵课文不饱和"的机制检验
- C：遗忘——睡眠巩固的网络版
- D：验证门——"理解"的网络版
- 机械刷题困死 = A50 的预期结果（饱和 + 无联想 + 泛化崩）

## 四、实验结果（v2：次数梯度 × 变体 × 遗忘 × 验证门）

```
条件    就→吃饱和   表达               变体泛化    联想候选
A1     0/16       了/但是/饿           0/5       了,所以,我,坏,的
A10    0/16       饿/了/就/睡觉        0/5       了,所以,我,坏,的
A50    0/16       饿/了/就/吃/饭       5/5       了,所以,我,坏,的
A150  16/16       饿/了/就/吃/饭       5/5       了,所以,我,坏,的   ← 饱和阈值
A300  16/16       饿/了/就/吃/饭       5/5       了,所以,我,坏,的
B     0/16        饿/了/就/吃/饭       5/5       了,所以,我,坏,的   ← 变体=零饱和
C     16/16       饿/了/就/吃/饭       5/5       了,所以,我,坏,的   ← sleep 无效
D     16/16       饿/了/就/吃/饭       5/5       的,了,所以,我,坏
```

### 4.1 归因结论

1. **饱和的必要条件 = 单一词对灌注次数 > ~128**（教学增量 +0.5/边/次，单边到 w_max=64 需 128 次）。散文事故根因：鲁迅 5 本全量中"了→就"等共现对出现成百上千次 → 超阈值 → 饱和。**不是"灌注"本身，是"单一词对超阈值重复"**。
2. **饱和 ≠ 卡死（重要修正）**：A300 全饱和但表达正确、泛化 5/5——"就→吃"饱和=1024 vs 散文残留"就→睡觉"=256——教学边清晰胜出。真正的"并列漂移"需要**竞争双方都饱和**（256 事故本质：散文边互相并列，w_max=16 时代）。
3. **背诵课文为什么不饱和——变体分散强化**：实验 B（同骨架 5 变体，与 A50 等"就→吃"强化次数）**零饱和且表达正确**——变体把强化分散到不同词对，无单一词对超阈值。人的背诵 = 变体 + 理解；**不是遗忘**（实验 C：sleep 对教学饱和无效——教学边高频受保护）。
4. **"只会做题困死"的人类版——联想缺失，不是饱和**：所有条件中"饿"的 top-5 候选恒为 `了,所以,我,坏,的`——无语义联想（吃/饭/面包/妈妈），全是功能词+噪音。网络说对"饿了就吃饭"但不会联想——**固化句整句直出绕过联想竞争，强化了僵化**。这是下一阶段研究方向（固化句与联想竞争并存）。

### 4.2 解药排序（实验验证）

变体多样性（B 零饱和）> 教学减量（<128 次阈值）> 验证门（饱和下选择仍正确）> sleep（对教学饱和无效，只管低频遗忘）


### 4.3 "正确读文章"实验（结构化阅读 vs 直接灌注——用户："灌注导致注意被锁死在每一个字上而不是文章的内容和句式，网络还没有学会如何正确读文章"）

条件（纯内存实验 `_exp_read.py`——不保存快照）：
- A 直接读文章：8 句短文**连续灌注** ×10（句间不清痕迹——跨句词对也被 STDP 学习）
- B 正确读文章：教师解析 → 分层教学（关系词配对 + 句内结构桥 + 内容对——等量强化）

结果：
```
                    A（直接读文章）        B（结构化阅读）
句式泛化（未教组合）  5/5                 5/5
内容保持            3/3                 3/3
模板 因为→所以       24                  344（集中强化）
跨句污染：去公园→因为 80.1（新学）        0.1（基线残留）
          吃饭→因为  152（新学）         72（基线残留）
          看医生→先  80（新学）          —（无）
```

**结论**：
1. **"注意锁死在每个字上"量化确认**：连续灌注把句子边界抹掉——句 1 尾"吃饭"→句 2 首"因为"被强化到 152——网络学的不是"句子"而是"字串"，自由读时句子无缝粘连（"去公园"后接"因为"）。
2. **"正确读文章"的分水岭 = 句界保持 + 结构化解析**：B 零新增跨句边（残留全为 v32 基线散文旧边）；模板集中强化（344 vs 24）支持句式复用。
3. 泛化能力两者相同（教学边集合一致）——**差异全在污染**——污染正是"锁死"的机制：网络的"读"缺少句法层（句界/句式识别）与篇章层（句子组织），只有词对统计层。
4. **对教学的启示**：学习端必须保持句子边界（`_learn_sentence` 句间清痕即为此）；文章知识获取应走"教师解析 → 结构化教学"（分层：模板/桥/内容），而非原文灌注。

### 4.4 举一反三 = 验证门控的知识迁移（用户："知识迁移的前提是迁移后是否能验证，如果无法验证对错就会导致污染"）

**自主举一反三量化（v34.0 无教师，`_exp_generalize.py`）**：走链可达 9/9 但内容正确仅 4/9=0.44——"能说话"但"说不对"。三种失败模式：固化句垄断（新变体被已有固化句吸入）、主体×状态组合边缺失（狗→渴 无边）、"了就"桥黑洞（小猫→家吃了就睡觉）。

**污染风险实证**：「小猫」变体走链可达 ✓ 但内容错误——若"可达即固化"则污染链被永久固化。**验证信号必须分级**：

| 信号 | 内容 | 强度 | 污染拦截力 |
|---|---|---|---|
| L0 | 走链可达 | 最弱 | 无（黑洞也可达） |
| L1 | 结构同构（共享模板） | 弱 | 低 |
| L2 | 类别约束（替换词∈同类） | 中 | 中 |
| L3 | 语义模板边（状态→需求） | 强 | 高（"猫渴了→吃饭"被 渴→喝 拦截） |
| L4 | 教师判定 | 最强 | 最高（成本高） |

**设计原则（验证门控迁移）**：
1. L0-L3 全通过才自举固化——L3 语义边来自种子教学（独立于迁移生成——验证与迁移源分离，非自证）
2. 存疑区（L2 过、L3 缺——如 OOV）**不固化**——标记待教师
3. 教师只抽查存疑区——LLM 调用 = 种子 + 存疑，不被每点教学拖累
4. 对应原理：人的迁移靠现实反馈验证（渴了喝水真解渴）；网络无现实反馈——教师 = 现实反馈——验证不了的迁移必须回到教师，不能自举

### 4.5 主动求证循环（用户："让定式网络直接找 LLM 求证，而不是 LLM 主动给网络说"——PRT 依据）

**治疗依据（PRT 核心反应训练——主动探索能力的标准干预）**：《PRT动机程序促进自闭症儿童社交发起的成效检验及成分分析》验证完整动机程序对促进**主动发起提问**最有效，四成分缺一不可；李晓燕团队（温州大学）家庭干预"制造提问时机"（藏起碗筷/寻宝游戏）激活好奇心；ALSO 指出动机缺乏病因含"过度专注单一事物"（= 固化句垄断）。

**网络设计映射**：

| PRT 成分 | 网络机制 |
|---|---|
| ① 遵循孩子选择 | 疑问信号（推演卡壳/预测误差/竞争并列）决定问什么——LLM 不备课不主动教 |
| ② 穿插新旧任务 | 预测准确（已固化）↔ 预测误差（新知识）自然交替——误差出现即提问时机 |
| ③ 强化孩子的努力 | 提问行为本身 +验证（敢问就奖励——不只在答对时） |
| ④ 自然强化 | 求证成功 → 预测误差降低（RPE 归零）——实践反馈，不是 LLM 给糖果 |

**求证循环**：持续运行（新刺激=制造提问时机）→ 疑问信号（网络选题）→ 主动提问（已有句式"X怎么办？"）→ LLM 只答被问的 → 答案验证门固化 → 自然强化（下次预测准了）。LLM 从"教师"降级为"百科全书"——真正的老师是求证后预测变准这个自然结果。

**预期收益**：LLM 调用 = 网络问题数（live12 主动教学 60 次/轮 → 求证式 <20 次）。

### 4.6 求证循环 v2：假设-验证（用户："过于依赖 LLM——不会先思考。先思考可能是什么再求证，不然形成路径依赖"）

**依据**：学习 = 预测误差驱动——没有预测就没有误差就没有学习；直接求证（LLM 给答案）= 灌注翻版 + 路径依赖（预测先于反馈的研究：先预测再揭晓的学习效果远好于直接给答案）。

**v2 流程**：缺口 → ① 假设生成（模板填充：种子模板 X渴了→Y，已知状态-需求边"渴→喝"猜"喝"）→ ② 内部验证（走链通 = 自举固化——零 LLM）→ ③ 验证不过 → LLM 求证（带假设："是不是该X？"）→ 确认（误差≈0）或纠错（误差驱动真学习）→ 固化。

**实验结果（`_exp_ask2.py`，纯内存）**：
- 假设生成率 5/5（网络先思考）；假设正确率 4/5=0.80（模板填充有效）
- 自举率 1/5（小猫——零 LLM 路径打通）；LLM 调用 4 次（v1 全求证 5 次）
- 发现：① 自举率低因主体→状态边缺失（狗→渴 无边——走链不通）——补边后自举率上升；② LLM 判定噪声（同假设"喝"狗判对猫判错——需投票）

**设计结论**：假设对+走链通 → 自举（零 LLM）；假设对+走链不通 → LLM 确认（补边）；**假设错 → LLM 纠错（真学习）**——LLM 从"答案提供者"降级为"假设验证者"，大部分时候只是确认器；真正的老师 = 假设-验证的预测误差（实践反馈）。

### 4.7 模式选择 = 刺激 × 内部状态评估（用户："不是看到句式切换模式，而是看到句式根据需求选择模式——回答/思考推测/无视"）

**评估信号**（全部来自网络结构）：验证分（教师判定累积——置信度）、固化命中、主体→状态边（问句内容粒度）、候选强度与竞争差距、词表相关性。

**实验结果（`_exp_mode.py`，纯内存——6/6 = 1.00）**：

| 刺激 | 模式 | 置信 | 评估信号 |
|---|---|---|---|
| 你饿不饿呀？ | 回答 | 0.95 | 固化验证「我饿了」22 对 |
| 小狗饿了怎么办？ | 回答 | 0.85 | 狗→饿=128 边明确 |
| 疼了怎么办？ | 思考推测 | 0.55 | 帮=110 vs 我=96 竞争接近（无验证旧边） |
| 猫渴了怎么办？ | 思考推测 | 0.45 | 猫→渴=0 缺边 |
| 今天天气怎么样？ | 思考推测 | 0.55 | 很=40 vs 冷=40 并列 |
| 什么是量子力学？ | 存疑标记 | 0.20 | 弱边 4.8（几乎不懂） |

**规则**：高置信（固化验证/边明确）→ 回答（不问）；中置信（缺边/竞争）→ 思考推测（先假设——猜对自举）；低置信+相关（弱边）→ 存疑标记（事后任务间隙问）；低置信+无关（词表外）→ 无视。**"问"只是四模式之一且排在最后——网络 90% 时间不依赖 LLM**。元认知信号成型（置信度分级 0.95/0.55/0.45/0.20——"知道自己知道多少"）。

### 4.8 多维反应（用户："你太一维了——人对客观事物的反应"）

**依据**：Russell 效价-唤醒环形模型（效价×唤醒独立两维）；趋近-回避动机系统（正→趋近/负→回避/低唤醒→趋近/高唤醒→回避）；Zajonc 新颖性（新奇→回避警惕/熟悉→趋近）；评估理论（多维评估→行为——S-O-R 的"有机体"）。

**网络信号映射**：认知=验证分/候选强度；效价=情绪词关联（疼/饿/冷/怕=负，开心=正）；唤醒=状态词类别（疼/饿/怕=高，天气=低）；动机=状态→需求链（饿→了→就→吃=自助趋近；怕→躲=回避）；新颖性=验证分缺失度。

**实验结果（`_exp_mode2.py`——7/7 = 1.00）**：

| 刺激 | 反应 | 评估明细 |
|---|---|---|
| 疼 | 求助 | 负+高唤醒+无自助链→疼帮 |
| 开心 | 分享 | 正效价→我开心 |
| 猫 | 探索 | 认知中+新颖中→假设验证 |
| 量子力学 | 警惕 | 新颖高+弱边→观察（Zajonc 回避） |
| 天气 | 忽视 | 低唤醒→无聊 |
| 饿 | 需求 | 负+高唤醒+自助链可达→饿了就吃饭 |
| 怕 | 回避 | 负+回避边→我害怕 |

七种反应模式（求助/分享/探索/警惕/忽视/需求/回避）——不再是认知一维的四种。信号全部来自已有结构（情绪词/状态-需求链/验证分），未加新机制——只是打开评估维度。

### 4.9 多信号处理模式（用户："网络是全部处理还是竞争处理还是串行处理"）

**实验（`_exp_attn.py`，纯内存）**：三刺激并行（疼+妈妈+CLK_5；饿+猫+天气）三种模式：

- **A 全部处理（并行注入）❌**：build_pulse 同时注入三刺激词 → WTA 发放的全是功能词（的/了/在/不——饱和边垄断）——刺激词一个都没出现——**动力学并行处理被统计噪声淹没**（v17 散文功能词后遗症的又一实证）
- **B 竞争处理（salience）✅**：多维评估加权分 argmax——疼 6.0 > CLK 1.52 > 妈妈 1.0；饿 6.0 > 猫 3.0 > 天气 0.0——仲裁清晰
- **C 串行处理（回合）✅**：按 salience 排序依次走链（疼→疼帮；饿→我饿了；CLK→沉默合理）

**结论：竞争排序 + 串行执行**（= 人脑选择性注意 + 任务切换——"多任务并行"是错觉）。**底层 WTA 不能直接当注意力**（功能词垄断）——决策层 salience 评估器是必要组件（不是装饰）。

### 4.10 多接口信号强度评估（用户："多个刺激源从不同接口进入网络后，网络能不能评估每个刺激源的信号强度来选择处理哪一个"）

**实验**（三接口分槽注入：疼→槽0 / 妈妈→槽1 / CLK_5→槽2，纯内存）：

```
刺激自身强度（注入后 v 值——动力学真实量）：
  疼 = 24.86 ← 最强（选择它——与 salience 评估一致：高唤醒负效价优先）
  CLK_5 = 0.42    妈妈 = 0.08
传播后后继激活：妈妈→做 13.4 > 疼→帮 3.3（被功能词污染——不可靠）
功能词污染：步1 了=401.5、步2 的/了/在=300+（传播后淹没一切）
```

**结论**：
1. 网络能评估刺激源信号强度（注入时刺激词自身 v 值——不受功能词污染）——强度 argmax = 选择（疼 ✓ 与外部 salience 一致，双信号互证）
2. 功能词污染只在传播后——**强度评估必须在注入时做，不能等传播**
3. 架构分工：**选择 = 网络自身（v 强度竞争）；模式 = 评估器（选中后的反应分类）**——salience 仲裁器简化为网络自身强度

### 4.11 事件时间线（用户："在一个刻度里只能响应一件事情，但事情的尺度是线性的不是点"）

**处理单位 = 事件会话（时间线），不是刻度（点）**——注意单点（刻度内一件事）+ 事件线性（多刻度跨越）：

```
事件会话（疼事件）：
  t1 评估→求助「帮帮我」  t2 等待（时钟推进——维持检查）
  t3 无回应→升级「妈妈我疼！」  t4 回应进入→匹配→预测救助
  t5 疼信号消失→会话结束「谢谢妈妈」→释放注意→下一事件
```

**完成条件**（三选一）：① 刺激消失（外部决定）② 目标达成（得到救助）③ 超时（升级/放弃）。**打断机制**：会话中更高强度刺激进入（强度比较——4.10 的信号强度评估）→ 打断切换。对应认知科学：事件分割（event segmentation）、注意驻留（attentional dwell）、任务切换成本。
