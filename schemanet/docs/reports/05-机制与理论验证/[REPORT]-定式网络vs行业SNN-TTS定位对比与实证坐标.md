# [REPORT] 定式网络 vs 行业 SNN TTS：定位对比与我们的实证坐标

> 日期：2026-08-11 | 版本：v1 | 状态：已完成
> 触发：用户问"我们的定式网络和 SpikeVoice 的脉冲神经网络有什么区别"
> 关联：全部声音模态探针（`_probe_sound_*` 系列 10 个）、`_probe_mem_share`、
> `_probe_concurrent_v35`、`_probe_pcm_flow`

## 1. 行业现状（2026-08 检索确认）

- **SpikeVoice（ACL 2024）**：SNN 领域第一个 TTS——文本 → 脉冲 Transformer
  （STSA 注意力）→ mel 谱 → **标准数字声码器** → 波形。质量接近 ANN-TTS，
  能耗 ~10.5%。注意：它**没有做"脉冲流→数字波形"转换**——mel→波形用的是
  普通数字声码器（HiFi-GAN 类）。
- **SPIDER（2025-2029，Idiap/SNSF）**：专门研究"二进制脉冲 → 连续语音输出"
  的原则性转换（SNN + 扩散生成），进行中。
- 结论：SNN TTS 刚起步，且主流路线**回避了脉冲→数字这一步**（用数字声码器
  收尾）。

## 2. 核心对比：一个物种的两个分支

| 维度 | SpikeVoice（行业 SNN） | 定式网络（BNOS） |
|---|---|---|
| 学习范式 | 监督 + **替代梯度反向传播**（全局损失、端到端） | **局部 Hebbian/STDP + 教学式注入**（无梯度、无全局损失） |
| 结构 | 深层 Transformer 化（STSA 脉冲注意力、层叠） | **单层稀疏图**（W_out 边）+ 槽位；深度在时间 |
| 信息表示 | 脉冲率/时间编码（连续特征，目标=mel） | **符号/模式**（词=神经元集合，离散；实证为"符号机"） |
| 数据/规模 | 百万参数、数千小时语料、GPU | 千级神经元、几百句教学、CPU 秒级 |
| 输出 | mel → 数字声码器 → 波形 | 帧词/概念模式 → 声带（物理振荡器） |
| 脉冲的角色 | **节能实现细节**（去掉脉冲=普通 ANN，语义不变） | **语义本身**（概念=发放模式，脉冲不可移除） |
| 目标 | 工程性能（质量≈ANN、能耗 10%） | 认知建模（成长、概念形成、无转译、可解释） |

## 3. 三个深刻区别

1. **优化出来的 vs 长出来的**：SpikeVoice 学的是"文本→mel"函数映射，
   脉冲只是节能载体；定式网络没有函数目标——每句教学是一次"经历"，
   边从共现/转移里自组织。一个是被梯度训练的函数逼近器，一个是
   结构自组织的认知机器。
2. **深度在层 vs 深度在时间**：SpikeVoice 用层堆叠（注意力）；定式网络
   用回响/痕迹/序列教学——没有注意力，"上下文"靠 trace 与时间积分。
3. **共同的墙**：都撞上"脉冲网络抓不住长时序依赖"——SpikeVoice 造
   STSA 硬啃，我们实证了 bigram 链长轨迹学不动（B3：74→21 帧轨迹
   压缩后猫全通、鸟牛部分通）。同一个问题，两种态度。

## 4. 我们的实证坐标（声音模态一路走来的结论）

| 实验 | 结论 |
|---|---|
| 合成音最小闭环（`_probe_sound_modal`） | 感知/生成/变体全 PASS——但这是"物理层假设圈内的自洽" |
| 真实音效逆向解析（`_probe_sound_real`） | 过零率/mel 编码真实音效=帧词散乱（跳变 0.5-0.7）——牛头不对马嘴的量化根因 |
| 路线穷尽（`_probe_vq_mel`/`_longframe`/`_pop_coding`/`_pcm_flow`） | **感知通**（VQ+长帧三音 1.0、交叉干净）；**生成有条件通**（长帧+轨迹可重复：猫全通）；**离散/连续互斥**（VQ 区分性强但转移稀疏、群编码转移流畅但交叉崩）；逐脉冲直入时间尺度不匹配 |
| 数字↔脉冲转译（`_pcm2pulse`） | **sigma-delta 转译近无损**（相关 0.97-0.99）——转译保真不是问题 |
| 核心墙 | **网络学得动的（符号）与无损的（时间/连续）互斥**——引擎是"符号机"，不是"时间机" |

## 5. 定位结论

1. 定式网络不与 SpikeVoice 比质量（比不过也不该比）——它是另一条线：
   **小资源、可解释、概念自主、无转译**（这些正是大模型路线放弃的）。
2. SpikeVoice 的"脉冲"是壳，我们的"脉冲"是语义——这意味着我们面临的
   墙（时间编码学不动）是**本质性的**：符号机无法消费时间编码信息。
3. 破墙路径唯一：**引擎级改造为"时间机"**——连续时间注入、脉冲定时学习
   （让 Δ 脉冲流的时间结构与网络动力学对齐）。这是下一代的起点，物理层
   与探针层面已无可做。

## 6. 下一步（按价值）

| 方向 | 内容 | 性质 |
|---|---|---|
| 连续时间引擎 | 连续脉冲流注入 + 定时学习（真 SNN 化） | 引擎换代（破墙） |
| 二阶 sigma-delta | 鸟叫 SNR 6.8→20dB+（数字↔脉冲工程补强） | 物理层细节 |
| 感知优先落地 | 真实音效分类（ESC-50 全类别）+ 概念绑定 | 应用（感知已通） |
