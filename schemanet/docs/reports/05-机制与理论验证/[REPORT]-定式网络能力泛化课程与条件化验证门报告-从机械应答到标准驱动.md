## 二、治疗研究依据（搜索资料）

### 2.1 能力泛化（VB-MAPP）

- **多范例训练（MET）**：孤独症泛化能力弱——精选范例、范例充足、灵活策略（《中国儿童保健杂志》2024 综述）。
- **矩阵训练/重组泛化**：有限语言要素组合生成新表达——"教 4 得 28"（矩阵内泛化达标率 89.1%，情境泛化 23.5%）。
- **融合教育**：家庭/社区/自然情境泛化。

### 2.2 认知中介（"中间步骤"——机械应答的反面）

- **私语/内在言语受损是 ASD 核心缺陷**（JADD 2007, 37(9), 1617–1635，维果茨基理论）：ASD 儿童解决问题时**不会用语言引导思考和行为**（Hughes 1996; Russell 1999），直接刺激→反应——对应"机械寻找最优路径"。
- **Thinking in Speech®**（Nathan & Nathan, JKP 2018）：发展内在言语用于问题解决、**"think before speaking"**、思维灵活性、冲动控制——语言作为行为的认知中介。
- **"停住，先想一想"红绿灯式自我指导**（孔德荣）：刺激先叫"停"冻结时间，再分析问题建构反应；**"大声思考→小声思考→不出声思考"三阶段内化**（私语内化路径）。
- **PRT 自我管理/时间延迟法**（《孤独症干预的关键性技能训练法》，李丹主编）：白板打钩自评、留出思考时间逐步撤除辅助。

### 2.3 对错多维化（条件性区辨）

- **条件性区辨（conditional discrimination）**：同一个反应的对错由样本刺激（问题/情境）决定——Fisher et al. 2014, *JABA* 47(4)：专治 ASD 条件性区辨中的持续错误——结果显著度（consequence saliency）+ 反应代价。
- **多重控制（multiply controlled intraverbal）**：Kisamore, Karsten & Mann 2016, *JABA* 49(4)：回答同时受问法形式、主题、听者多变量控制——**区分性观察反应（DOR：先识别控制变量再作答）**。
- **过度选择（overselectivity）——"单一化"正是病理**：Yorlets et al. 2018, *The Psychological Record*：ASD 只注意多维刺激的单一维度（只看"饿"不看问法类型）——无错误学习+复合刺激匹配修复；Halbur et al. 2021, *Behavior Analysis in Practice*：**维度显著性**——初期让关键维度差异最大化，再逐步缩小（泛化梯度）。
- **刺激控制（Sᴰ/SΔ）**：对错只在特定前因下成立（DTT 三步回合；错误刺激控制——马凌冬：孩子靠无关线索判断对错）。

## 三、机制设计（四层全链路）

### 3.1 句子固化（公式化语言 / 海马序列记忆）

```python
def consolidate_sentence(ng, pats, cursor, seq, k=4, w=64.0):
    # 句内每词分配 k 个新神经元（槽位）
    # 词 ↔ 槽位双向绑定（语义触发 + 整句读出）
    # 槽位间独占强边（slot_i → slot_{i+1} 主干——整句序列推进）
```

- **动机**：一阶 bigram 边的局限——"就→吃 vs 就→喝"无法区分"饿/渴"语境（语境污染）；教学把中间桥推到饱和后下游全部触发收敛断链（权重悬崖 256 < 1024×0.4）。
- **读出**：起始词一经激活整句沿主干逐槽读出——"回忆一条神经轨道"而非"组合"；序列完整性由主干保证。
- **表达收束**：整句说完即完成（break）——杜绝"我饿了就吃饭就吃饭…[黑洞]"尾巴。

### 3.2 问法分型固化（应答类型 = 语用）

| 问法类型 | 示例 | 正确应答 | 固化句 |
|---|---|---|---|
| 确认（是非问） | 你饿不饿呀？/肚子饿了吗？ | 状态确认 + 人称转换 | 我饿了 |
| 怎么办（因果问） | 猫饿了怎么办？ | 因果陈述 | 饿了就吃饭 |
| 提议问（要不要+动作） | 要不要穿衣服？ | 接受提议 | 我要穿衣服 |

固化句带类型标签，free_read 按 ctx（问法类型）调制选择——前额叶任务规则调制海马提取的神经对应。

### 3.3 思考环（认知中介——"先想再说"）

```
回答路径 = 听到（trace: 问句全文）→ 理解（trace: 语义核+问法类型）
         → 思考（trace: 想到整句「…」验证对/错）→ 表达（逐词读出）
```

固化命中不直接输出——先"停住，想一想"（时间延迟——PRT 时间延迟法）：trace 记录"想到整句"，再表达环逐词读出。当前为"大声思考"阶段（私语外化），后续课程将按"大声→小声→无声"三阶段内化为无声思考。

### 3.4 条件化验证门（对错 = 结构存废）

```python
validation = {(qtype, kw, 句子): (对次数, 错次数)}   # RPE 累积
```

- **对错 = 结构存废**：教师判对 ≥2 → 固化（主干建立=验证门开启，结构里的"对"）；判错 > 对 → 该条件下禁用/解除固化（入口移除=验证门关闭，结构里的"错"）——网络"知道对错"= 查自己的结构，不再只是权重增减。
- **条件性区辨**：同句不同问法独立验证——"饿了就吃饭"答"怎么办"✅、答"想不想吃饭"❌——互不污染（修复过度选择：问法类型维度显著化）。
- **示范句 = 权威正例**：教师示范句每次注入计验证 +1（教师说"该这么说"= 对信号）——解决"确认句只有固化后才能读出、固化需要验证通过"的鸡生蛋死锁。
- **罚边条件化**：权重惩罚只用于**内容乱链**（回答不是任何已知句）；应答类型错（内容对、型不对）不动权重——防连坐破坏正确组合边（确认题答"饿了就吃饭"若罚"了→就"，会把怎么办句的正确边一起罚掉）。

## 四、实验与结果

### 4.1 泛化题库（20 题——全部未教过的问法/组合）

- 确认 ×16：4 状态 × 4 换问法（你X不X呀？/…了吗？/想不想…？/要不要…？）
- 怎么办 ×4：换主语/省略主语（猫饿了怎么办？/小狗渴了怎么办？…）

### 4.2 结果对比

| 版本 | 机制 | 复测泛化率 |
|---|---|---|
| v1 | 纯组合（bigram 走链） | 0.200（漂移链：就→睡觉 256 > 就→吃 156） |

> 注：v2 的 0.950 是"频率固化"的虚高——固化不经教师验证、回答不按问法分型、无思考过程——正是用户批判的"机械应答"。v3 的 0.800 是"标准驱动"的实分——剩余 4 个 ✗ 全部是 LLM 判定边界（提议问类型缺失 2 题 + 固化句「我冷」缺"了"等示范不稳定 2 题），网络表达本身全部自然、准确、完整。

## 九、训练沉淀与干预机制（2026-08-11 追加）

用户要求："每一次训练都要沉淀，然后在沉淀的基础上进行下一步；出大问题回退到上一步训练分支；1024 为什么饱和（不是没有上限吗）；有没有人工强制干预的手段？"

### 9.1 饱和机制澄清

**总边权上限 = 神经元对数 × w_max**：`w_max=64` 是每条边的截断上限（Hebbian/STDP 更新时 clip），"了→就"有 4×4=16 条神经元边 → 物理上限 16×64=1024。教学 160 次把 16 条边全部推到 64 即满——**不是没有上限**。之前"w_max 16→64"只是抬高单边上限（散文 256=16×16）。

### 9.2 人工强制干预手段（全部已实现）

| 手段 | 实现 | 本轮应用 |
|---|---|---|
| 直接改边权 | `ng.W_out[i][0][j] = w`（setitem） | "了就"桥单边压回 30 |
| 删边 | `del ng.W_out[i][0][j]`（delitem） | unconsolidate 移除验证门入口 |
| 批量降权 | 遍历 pats 神经元对 | 了→就 708→480（干预示例） |
| 教学减量 | 源头：×40→×15 | 了→就 从 1024 降到 708 |
| 硬过滤 | BAN_EDGES/DEAD（free_read 层） | 废话黑洞边 |

**干预的边界（诚实结论）**：降权"了就"桥只把自由链黑洞从"吃饭"换成"睡觉"——"X了"→"就"的语境污染是一阶边的根本局限，权重干预治标不治本；根治需架构级上下文调制（固化句=安全通道绕过，自由链仍是脆弱区）。

### 9.5 sleep 遗忘机制：存在但接入点错位（2026-08-11 实测教训）

用户："如果有上限，那会不会未来出现所有边都被推到上限然后网络卡死？我记得有 sleep 遗忘机制的啊"

**饱和卡死风险 = 真实存在**（256 饱和事故先例：w_max=16 时代饱和边之间 Hebbian 无法区分 → 并列 50% 漂移）。教学内容反复教（高频）→ 大量边到上限 → 无区分度 → 卡死/漂移。网络只涨不消是病根。

**sleep_consolidate 检查结论**：
- 机制**完整**（sparse_net.py:775：slot_freq 唤醒计数 + scale 弱化 + prune 回收）但**从未接入任何训练脚本**（孤儿机制）
- 接入短课程实测：**误弱化 5600 万条边**——20 题课程里绝大多数词自然低频（散文旧知识"下雨/生病"整课程 0 唤醒）→ sleep 一次全局 ×0.85——多课程累积 = 旧知识衰减殆尽
- 两个设计错位：
  ① **读取≠唤醒**：free_read 是静态读边（不走 step）——slot_freq 只在动态发放时计数——sleep 会把"未教学注入"的常用词全当低频——已修复：free_read 每步更新 slot_freq（读取=唤醒）
  ② **短课程≠真实使用**：sleep 是"用进废退"，正确接入点是**持续运行课程**（live10 类，词频分布真实）——短课程接入必误伤

**分支回退实战（v33.2 误伤 → 回退 v33.0 分支 → v34.0）**：
```
v33.0 (无 sleep) ──重训──▶ v34.0 (parent=33.0)  ← 与 v33.1/v33.2 平级 ✓
                    └ 回退入口 load_version("33.0")；分支重训传 parent="33.0"
v34.0 恢复验证：泛化应答 19/20=0.950（真实失败 0 题），固化 6 触发词/37 验证对
```

**防饱和的即时手段**（按优先级）：教学减量（×15）> 人工干预降权（了→就 708→480）> BAN_EDGES 硬过滤 > sleep（持续运行课程接入，待做）。
