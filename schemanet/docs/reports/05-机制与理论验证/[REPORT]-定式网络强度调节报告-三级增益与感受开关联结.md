## 一、背景与需求

价值课修复（增益调制）之后，用户连续提出强度相关的深化要求（2026-08-10 决策链）：

1. "直接给不要加权重，让不要在网络里足够亮，痛直接一眼就能看到" + "要也要增强，和不要持平" → 价值判断词增益；
2. "感受是大脑最原始的条件反射，相对比情绪词以外的词大" → 情绪/感受词中等增益（三级层级确立）；
3. "把正面感受和要（包括近义词）联系起来，把负面感受和不要（包括近义词）联系起来" → 感受-开关联结（效价-趋避映射）；
4. "强度能不能人为手动调节？如果可以调节，是不是就说明网络可以被控制？" → 参数化 + 可调≠可控的边界澄清。

## 二、四级增益（欲望=同义 > 近义 > 感受 > 知识）

| 层级 | 词 | 增益 | 神经对应 | 为什么 |
|---|---|---|---|---|
| **欲望/行为开关**（含同义词） | 要、不要 + 想要/想/需要 + 不想/别/拒绝/不肯 | ×4（`gain_value`） | 动机系统（趋避决断，attention gain） | 直接决定"做什么"；同义词 = 开关的等价表达（用户："同义词强度要和要/不要一样"） |
| **近义词** | 渴望/希望/愿意/期盼/期望/渴求/期待/盼望/希求 + 不愿意/谢绝/避免/回避/推辞/婉拒/躲避/躲开/回绝 | ×3（`near_gain`） | 动机系统的渐变表达 | 相近但不等价，强度略低（用户："近义词略低一点"） |
| **感受** | 痛、怕、哭、累、难受、伤心、冷、饿、喜欢、高兴、开心、舒服、快乐 | ×2（`gain_emotion`） | 情感优先加工（emotional priority，杏仁核/边缘系统） | 感受比知识原始（条件反射先于认知） |
| **知识** | 名词、虚词、语法 | ×1 | 皮层语义网络 | 最新的、最不紧急 |

**自我底色**：「我」×2（`gain_self`，与感受同级）——用户："网络里'我'应该是那个网络的中心"。中心性 = **挂载**（所有经验以我为主语，我→吃/要/不要 16.0 已具），增益只给"始终在场"的底色。实验依据：G=8 拉顶 → 注入好词也带出"我"（自我中心化污染）；G=2 → 点亮自己、好词不污染、石头判定不受破坏（"不要"×4 仍优先）。增益不持久化（教学期调制，每轮重新施加——调制层不碰 W、可撤销）。

**开关词族（25 词，中文语义查补）**：同义 7（趋利 3 + 避害 4）+ 近义 18（趋利 9 + 避害 9）。落位即"空端口"（动态 allocate）——无传入突触时完全惰性（候选判定 v≥θ 不变），不进 V_SET13、不参与说话采样，只预置增益槽位，等词汇由教学/语料填充（先定端口后填内容）。**2026-08-10 填充教学后**：25 词全落位（修复落位 bug：allocate 返回值此前被丢弃）；拒绝族（不要同义词）已填内容——定式阶段与「不要」同强度教学，见 §三"填充教学专项验证"。

**机制**（`SparseSchemaNet.gain`）：每神经元独立的增益向量，WTA 排序用 `vmax×gain`，**候选判定仍用原始 v≥θ**——不被驱动时不会误发（噪声 0.5 <θ 永远进不了候选）。**W 物理零改动**，随时可撤销（gain 重置 = 恢复默认）。

**关键验证**（新坏东西「超市」最小教学，无定式、无抑制）：增益 ×4 时「X→痛→不要」两步链在爆炸噪声中命中"不要"（不要 fired 4/4）——**泛化规则而非背词表**；好词场景"不要"恒不误发；学习路径与 gain=1 逐边对拍一致。

## 三、感受-开关联结（效价-趋避映射）

把「痛」从单例词升级为**负面感受簇**（`_feel_links`）：

- 负面感受词（痛/怕/哭/累/难受/伤心/冷/饿）→ 避害开关族：不要 + 不想/别/拒绝/不肯
- 正面感受词（喜欢/高兴/开心/舒服/快乐）→ 趋利开关族：要 + 想要/想/需要
- 落点：与痛觉链同机制（注入式学习，学 2 次，edge_between≈16），词表动态落位
- 联结目标 = 开关词族（要/不要 + 同义词）：感受唤起时整个趋利/避害族都可能被激活——"我不要/我不想/我拒绝"是同一行为的等价表达；近义词只落位（空端口、仅增益），不建立联结（联结目标是等价表达，近义是渐变表达）

**语义升级**：任何「X→负面感受」的经验（如「学校→累」）都能走「X→累→不要」泛化出避害——**感受成为行为的中介**（感受级泛化，比对象级定式 X→不要 再高一层）。

**泛化专项验证（2026-08-10，`_tmp_verify_general.py`）——感受级泛化的边界**：

- **A 新坏东西泛化（火）✓ 通过**：感知 +「火→痛」教学（无定式、无抑制）→ 火→痛=16.0，注入火 → 不要 fired 4/4。**新词传出突触干净，X→痛→不要 链畅通**——增益治本对新坏东西可靠。
- **B 感受级泛化（学校→累→不要）✗ 回忆侧受限**：「学校→累」16.0 学习**成功**（学习侧无碍），但注入学校回响时，累 每拍 v≈1.8~2.5（≥θ）**始终进不了 WTA top16**——学校是旧词，传出突触连满虚词枢纽（的/有/吗/好/哪些 各 ×4 霸榜），**虚词潮水淹没链路中间词**。链「X→感受→不要」对旧词走不通（**雪崩压制回忆**：雪崩的回忆侧表现，与学习侧无关）。
- **附：原「雪崩破坏学习」假设证伪**——此前"学校→累 学不出 0.0"是验证脚本 bug（`evoke()` 设 `learn_gate=False` 未恢复，后续教学静默失效），非网络问题；修复后学习正常。
- **附：抑制参数过强有害**——`inh_norm=8.0 + refract_clear=True` 把已定式的石头判定从 4/4 压到 0/4（正常能力也被压灭），抑制参数默认关闭是对的。

**含义**：感受级泛化 = 底层机制（新词有效），对象级定式 = 现行兜底（旧词可靠）。"新词泛化 + 旧词定式"是当前价值系统的真实能力边界；彻底解决旧词链路需网络级降噪治理（弱化虚词枢纽，独立课题）。

## 三.4 判别实验：注意力 = 连接数量 × 边强度 + 增益（2026-08-10，`_tmp_attn_final.py`；结论 v1.1 修正）

> **v1.1 修正（2026-08-10）**：本节原标题"注意力 = 连接数量"为局部结论误表述。判别实验两个控制变量分支合证：**E 组（强度固定、数量归零→弱突触直接进）= 数量决定竞争环境；C 组（数量不变、教学 7 次 56.0→5/5）= 强度可战胜数量环境**。故完整结论为"注意力 = 连接数量 × 边强度 + gain"，数量因 4 个数量级动态范围（16 条 vs 16.6 万条）成为主导瓶颈。详见[注意力机制报告 v1.1]。

**用户理论**："定式网络的注意力机制是连接数量"（v1.1：主导瓶颈而非全部）——虚词枢纽传出突触连接数量爆炸（的=16.6万条、吗=7.2万、是=6.8万），每步驱动几十万目标 → 灌满 WTA top16 → 链路中间词（累）被挤出 = **雪崩压制回忆**。数量决定竞争环境。

**判别实验**（基线 20260810_095121，n=148848，教学「学校→累」；留档 `runs/_speak_logs/20260810_101355_attention_discriminant_exp/`）：

| 组 | 操作 | 累 hits | 判读 |
|---|---|---|---|
| B STD 频率疲劳 ×3档 | 调 std_dep/std_rec，不碰连接 | 0/5（不要 5/5 完好） | 调疲劳无效且无伤 → 不是发放疲劳问题 |
| C 强度梯度 | 教 2/6/7/8/9/10/11/12 次 | 2次16.0→0/5；6次48.0→0/5；**7次56.0→5/5**；8次起全通 | **教学强度可战胜连接，临界 48< x ≤56** |
| D 物理砍 hub | 清空 17 虚词枢纽传出突触共 **92.4万条** | 教2/4次仍 0/5 | 下游扇出**非**瓶颈 → 瓶颈在注入步首跳 |
| E ★关键判别 | 砍「学校」除→累外全部传出突触（只留 16 条、总重 16.0） | **5/5 全通**（不要 也 5/5） | **连接数量归零 → 弱突触直接进注意力** |
| F 步级诊断 | 注入学校逐步 top6 v | 有/的/什么 304.0/300.4 霸榜，累 v 仅 0.93~2.2 | hub 互驱链式自振，数量级碾压 |
| 引用 edge_min 三档 | 运行时弱突触修剪（100216 留档） | 0/5；edge_min=1.0 伤 石头→不要 2/5 | 降噪无效且伤已学能力 |

**阈值定位**（学校→各词传出突触总权重）：吗=94.4、的=86.4、有=52.8、什么=48.0、上/哪个=43.2、是=38.4、累=16.0（教学 2 次后）、不要=0.0。**临界 48< x ≤56 远低于最大虚词单边（94.4/86.4）**——因为累是 4 神经元模式、16 条突触聚合 + 多步回响累计，56.0 已能挤进 top16，不须单边压过枢纽。

**结论（注意力三层结构，v1.1 修正）**：

1. **竞争环境 = 连接数量**（主导瓶颈，用户理论证实）：注入词传出突触的连接数量决定竞争池多大——hub 传出突触 4 个数量级碾压，每步把 WTA 灌满，链路中间词有资格（v≥θ）但赢不了竞争（被挤出）。
2. **竞争结果 = 强度（资格 + 得分）**：边强度决定"是否有资格"（候选判定 v≥θ）与得分高低（能否排序进 top16）——E 组证明 16.0 本身够过阈、只是原竞争环境把它挤出；**C 组证明强度可战胜环境**（56.0 挤进 top16）。数量与强度是独立自变量，共同决定注意力。
3. **瓶颈在注入步首跳竞争**：砍 92.4万条下游 hub 边无效（D 组）——旧词既有最强传出突触（学校→吗/的）是门槛；**新链只有强过"旧词既有最强传出突触"才能打进注意力**（或靠强度聚合累计超过临界 48~56）。
4. **调制 = gain 排序系数**：外部"打灯"（价值词 ×4 等），不碰连接、不碰 W——三维分层（数量=环境、强度=资格+得分、gain=倾向），与"可调≠可控"（§五）一致。

**实用含义**：旧词定式教学力度 ≥7 次（≈56.0）即可可靠唤起（此前 2 次 16.0 的默认力度对旧词不够）——**教学次数（强度）本身是对抗连接数量（环境）的手段**；新词无既有传出突触，2 次即通（火→痛 4/4，§三 A 组）。

## 五、调节机制的三类性质（可调 ≠ 可控）

| 调节 | 机制 | 改权重？ | 性质 |
|---|---|---|---|
| 增益 | gain 向量 ×排序 | 不改 W | 环境/生理调制（多巴胺/注意力式），零污染、可撤销 |
| 联结/定式 | 注入词对 → Hebbian | 网络自己改 | 注入式：外部只给经历 |
| 解耦衰减 | decay_path ×0.1 | 直接改（乘法） | 唯一例外，保留微量可复活 |

**外部能控制的只有"次数/比例/调制"，改多少、长成什么样全由网络动力学决定**——没有任何调节会"外部精确指定某个权重值"（如 W=5.0）。可调的是**倾向**（先验），不是**行为**（结果仍由经历决定）——人调节环境，网络自主成长。

## 七、结论

1. **四级增益 = 欲望优先性的数值化**：欲望+同义词（×4）> 近义词（×3）> 感受（×2）> 知识（×1）——等价表达同级最亮，渐变表达略低，感受比知识亮。
2. **开关词族 = 先定端口后填内容，拒绝族已填充**：25 词全落位；拒绝族（不要同义词）与「不要」同强度教学，能唤起、能采样、说了 honor 100 分；「不要」是最熟练主表达，族词是等价备选（随教学轮次自然累积）。
3. **感受-开关联结 = 感受级泛化**：痛升级为负面感受簇，联结目标是整个开关族（要/不要+同义词）。
4. **「我」= 网络中心的挂载点**：所有经验以我为主语；自我增益 ×2 只给"始终在场"底色（G=8 拉顶 = 自我中心化污染）。
5. **强度可手动调节 = 可影响、不可微操**：调节走注入+调制，不指定权重参数——网络仍自主成长，人控制的是环境与倾向。
