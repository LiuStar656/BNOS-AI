## 修正记录（v2.0，2026-08-11）

v1.1 将注意力表述为"连接数量 × 边强度 + 增益"。用户提出新方向："注意力与**神经元兴奋度**、**突触方向**、**突触权重**有关——具体关系有多大、怎么计算？"——经受控实验定量验证，修正为三维公式：

```
注意力(目标 j) = v_j × gain_j
v_j（传播贡献）= Σ_{i→j 有边} w_ij × (1 − fat_i)     （方向 = 可达性门，权重 = 线性汇聚）
key_j = v_j × gain_j                                  （兴奋度 = 资格 v≥θ + 排序乘法器）
```

- **突触方向**：0/1 门——无出边方向 = 完全不驱动（反向边 16.0 实测贡献为 0）
- **突触权重**：线性——v ∝ Σw（实测比值恒定 0.87~0.95，即 0.9 膜电位衰减）
- **神经元兴奋度**：乘法——key = v×gain，gain 可让低权重目标击败高权重目标（实测 gain×4 胜 w×4 的对手）

v1.1 的三个维度是 v2.0 的统计表象：**连接数量 = 方向的枚举（可达目标数）**；**边强度 = 权重**；**gain = 兴奋度调制的一半**（另一半是 v 本身——v 由方向×权重动态产生）。v2.0 下沉到动力学原语（膜电位、突触、方向），v1.1 是其在竞争环境层的投影。v1.1 的判别实验数据（强度梯度/砍 hub/砍边）仍有效，归档保留。

## 一、引言：定式网络里"注意力"是什么

定式网络的回忆是**注入词 → 传出突触驱动 → WTA 竞争 → 发放**的过程：注入一个词，被它驱动的所有候选神经元按排序键竞争，只有 **top-k**（wta_k）能发放。"被网络注意到" = **发放进 WTA top-k**。

历史现象（2026-08-10 实证）：新链「学校→累→不要」中，累 每拍 v≈1.8~2.5（远超阈值 θ=1.0），有资格发放却永远发不出来——虚词枢纽（的/有/吗/好/哪些…）每步把 top-k 灌满，链路中间词被挤出。这个现象被命名为**雪崩压制回忆**。

注意力到底由什么决定？v2.0 用三个动力学原语回答：**神经元兴奋度（v×gain）、突触方向（可达性）、突触权重（驱动强度）**——并给出定量公式。

## 二、注意力 = 神经元兴奋度 × 突触方向 × 突触权重（三维公式）

### 2.1 公式推导

WTA 排序键（引擎实现 `sparse_net.py`）：

```python
key = vmax_c * self.gain[candidates]    # 排序用 v×gain
# 候选资格：原始 v ≥ θ（与 gain 无关）
# 传播：drive[dst] += w（_prop_accum）——只有有向出边
# 定向链：keep = (drive_any > 0) | inp_mask——只有被驱动到的才参赛
```

因此目标神经元 j 的注意力排序键：

```
key_j = v_j × gain_j
v_j   = Σ_{i ∈ 本拍发放, 且存在有向边 i→j}  w_ij × (1 − fat_i)   + 注入 + 噪声残留
```

三维各自的作用与定量关系：

| 维度 | 动力学角色 | 定量关系 | 实验 |
|---|---|---|---|
| **突触方向** | 可达性门（0/1） | 无 i→j 边 → w_ij 项=0，完全不驱动 | 实验2：反向边 16.0 → v=0.18（噪声级） |
| **突触权重** | 线性驱动 | v ∝ Σw，比值恒定 ≈0.9（膜电位衰减） | 实验1b：v/w = 0.87~0.95 |
| **神经元兴奋度** | 资格 + 排序乘法 | 资格 v≥θ；排序 key = v×gain | 实验B：同权重下 gain 高者胜；实验4b：gain×4 胜 w×4 对手 |

### 2.2 方向 = 可达性门（0/1，最强约束）

**只有存在有向出边 i→j，i 的发放才能驱动 j**。反向边（j→i）对 j 的注意力毫无贡献。

实验2：猫→是 无边，是→猫 w=16（仅反向）→ 注入猫后「是」vmax=0.18（纯噪声残留，**等于无边**）——16.0 的反向突触对"猫→是"方向的注意力贡献为 **0**。

方向是三维中唯一"非连续"的：0 或 1。它决定"谁有资格参赛"——与权重无关（权重再大，方向不对也是 0）。

### 2.3 权重 = 线性驱动（v ∝ Σw）

**目标收到的膜电位与突触权重线性相关**——权重是"驱动强度"的原料。

实验1b（不过阈区间测线性，猫 4 神经元 → 是 4 神经元全连 w）：

| 权重 w | 理论 Σw（4 神经元） | 实测 v | v/w |
|---|---|---|---|
| 0.05 | 0.20 | 0.191 | 0.95 |
| 0.10 | 0.40 | 0.367 | 0.92 |
| 0.15 | 0.60 | 0.533 | 0.89 |
| 0.20 | 0.80 | 0.692 | 0.87 |

v/w 恒定（≈0.9）——**v = Σw × 0.9**（0.9 = 膜电位每拍衰减 membrane_decay）。权重贡献是**线性累加**：多个源同时驱动 = Σw_ij（实验6：猫→是/鱼 各 16.0，同拍全被驱动）。

### 2.4 兴奋度 = 资格门槛 + 排序乘法器（key = v×gain）

**神经元兴奋度 = 膜电位 v × 增益 gain**——两重作用：

1. **资格**：原始 v ≥ θ（=1.0）才能成为候选——gain 不参与资格（不会让未驱动神经元误发）
2. **排序**：key = vmax × gain——gain 是排序乘法器，决定竞争位次

实验B（同权重 w=4，gain 梯度）：四目标 drive 相同（理论 60.8），gain 1/2/4/8 → wta_k=8 时 **gain 最高的两个（鱼×4、妈妈×8）胜出** ✓

实验4b（增益超越权重）：是 w=16 gain=1（v≈18.3，key=18.3）vs 动物 w=4 gain=4（v≈13.7，key=54.7）→ wta_k=4 **动物全胜**——**兴奋度调制可让低权重目标击败高权重目标** ✓

### 2.5 乘积守恒：key = w×gain 是复合不变量

实验C：w×gain 全=16（是 16×1 / 动物 8×2 / 鱼 4×4 / 妈妈 2×8）→ wta_k=8 时四词并列——**权重与 gain 在排序键中是可交换的乘积**（w×gain=常数 → 并列，微差由噪声决胜）。

**这说明"注意力"在排序层是一个乘法表达式**：权重（知识强度）与兴奋度（状态调制）是同一把尺子的两个因子——教得越多（w 大）与状态越亮（gain 大）效果等价。

## 三、定量实验证据（2026-08-11，v2.0 受控实验）

基线 v51（无边，受控构造），注入「猫」→ 目标词 4 神经元全连 w：

| 实验 | 操作 | 结果 | 判读 |
|---|---|---|---|
| 1b 权重线性 | 猫→是 w=0.05~0.20（不过阈） | v/w 恒定 0.87~0.95 | 权重 = 线性驱动（v≈Σw×0.9） |
| 2 方向门 | 猫→是 无边，是→猫 w=16（反向） | 是 vmax=0.18（噪声级） | 反向边贡献 = 0——方向是 0/1 门 |
| A 权重梯度 | w=16/8/4/1（gain 全 1），wta_k=8 | 是(16)+动物(8) 胜出 | 高权重进 WTA（资格+排序） |
| B gain 梯度 | w=4 全同，gain=1/2/4/8，wta_k=8 | 鱼(×4)+妈妈(×8) 胜出 | 同权重下 gain 高者优先 |
| C 乘积守恒 | w×gain 全=16 | 四词并列（wta_k=8 选 2） | key=w×gain 是复合不变量 |
| 4b 增益超越 | 是 16×1 vs 动物 4×4，wta_k=4 | 动物全胜 | 兴奋度可击败权重差 4 倍的对手 |
| 6 多源驱动 | 猫→是/鱼 各 16（鱼↔猫 互连） | 回响1 全被驱动，回响2 鱼反向驱动猫 | Σw 线性累加 + 方向双向传播 |

**关键定量结论**：

1. **方向**：0/1 门——不连续、最强约束（16.0 反向 = 0）
2. **权重**：线性——v = Σw × 0.9（比值恒定）
3. **兴奋度**：乘法——key = v×gain，gain 可超越 4 倍权重差
4. **复合不变量**：w×gain 乘积守恒 → 排序并列（知识 × 状态等价）

## 四、过去的注意力机制：全景与失效分析（v1.1 保留）

### 4.1 读出层注意力：trace 上下文混合（"LLM 注意力雏形"的兴起→误判→推翻）

trace（痕迹插值读出）是项目里**第一个被称为"注意力"的机制**（"LLM 注意力混合历史 token 的最小雏形"）。它走完了完整的"兴起 → 误判 → 推翻"周期：

| 阶段 | 报告 | 结论 |
|---|---|---|
| 设计 | 上下文升级 trace 实验报告 | 读出层用 pre_trace 痕迹把"只看末词"升级为"整条前缀插值混合"（backing-off：末词已决定→只用末词；末词平局→借整条前缀破局）。小语料机制验证 ✓ |
| 兴起 | L1 报告-20万句数据放大 | 数据 10 倍放大后 trace 长位置增益 z=1.64→**4.42** 显著，被定案为"定式网络的长上下文读入机制" |
| **推翻** | L1 干净对照-训练W扰动裁决 | 同源 2 万子集**干净 W** 上 wsum 显著优于 trace（-0.0105，z=-3.48）——L1 中"trace 赢"是 train_w 打残 wsum 的假象 |
| 真实语料 | 开源语料规模验证 | 真实语料下 trace-wsum=-0.010 不达标 |
| 废弃 | 技术路径切换 v1.1→v2.0 | 八项证据链判定"引擎之争无意义"、trace 主引擎路线废弃 |

**trace 为什么失效（作为注意力）**：错层（注意力在发放竞争层 WTA，trace 在读出层）、无选择性（等权混合不是选择）、不带来新信息、增益是 train_w 污染的假象。

### 4.2 压制类降噪（针对雪崩，全部失效）

| 机制 | 实现 | 结果 | 失效根因 |
|---|---|---|---|
| 全局除法归一化 | drive 总量超 target 等比压缩 | σ 收敛 1.35，但第一跳断 | 石头几千条传出突触把强链稀释到 0.16，过不了阈 |
| 每神经元饱和度 | drive→drive/(1+drive/c) | 弱叠加恰好压到 θ 仍过阈 | 强链 16 被压到 1.78，与弥散 1.4 无优势 |
| 减性反馈抑制 | drive −= inh_k×上一步发放数 | 无效果 | 抑制量级杯水车薪 |
| edge_min 弱突触修剪 | 传播只算 ≥edge_min 的边 | 累 0/5；edge_min=1.0 伤 石头→不要 2/5 | 降噪伤敌一千自损八百 |
| refract_clear 不应期硬清 | 不应期神经元 v 清零 | 石头判定 4/4→0/4（过强） | 无差别清除 |

**共同根因**：竞争是**相对排序**问题，压制是**总量**干预——压总量不改变相对序。

### 4.3 疲劳类：STD 短期突触抑制（无效）

std_dep/std_rec 三档全 0/5——瓶颈不在发放者疲劳（hub 互驱是多词接力），在注入步首跳的竞争排序。

### 4.4 调制类：gain 增益调制（v2.0 视角下——有效且并入三维公式）

- **实现**：WTA 排序用 vmax×gain（候选判定仍用原始 v≥θ）。
- **结果**：G=4 时「不要」4/4 全通——唯一被保留的注意力类机制。
- **v2.0 重定位**：gain 不是独立机制，而是**兴奋度维度的一半**（key=v×gain 的乘法因子）——实验 B/C/4b 证明它与其他两维在同一把尺子上可交换。v1.1 说"gain 是外部倾向调制"，v2.0 明确为"兴奋度调制因子"。
- **失效边界**：gain 只对预设词生效（链路中间词无 gain 照样被挤出）——因为它不改变方向（可达性）与权重（驱动强度），只改兴奋度。

### 4.5 结构绕过：定式化「X→不要」（有效但治标）

学「X→不要」4 次直连 → 石头 注入→不要 4/4。但新坏东西无直连照样崩——绕过爆炸区不等于理解结构。

### 4.6 代码层：hear 引导（外部脚手架，非网络注意力）

教师代码挑词绕过 WTA 竞争直接给采样加权——教学脚手架，非网络机制。

## 五、对比：为什么过去的失效，新的成立（v2.0 视角）

| 维度 | 过去（读出混合/压制/疲劳/调制/绕过） | 现在（兴奋度 × 方向 × 权重） |
|---|---|---|
| 干预层级 | 结果层/读出层（竞争发生后救火） | 动力学原语层（膜电位/突触/方向） |
| 核心视角 | "想把目标词抬上去"（外部意志） | "谁被驱动、驱动多强、状态多亮"（动力学事实） |
| 选择性 | trace 等权混合、压制无差别、gain 只预设词 | 方向门（谁可达）× 权重（驱动多强）× 兴奋度（状态多亮）——三维乘积天然选择 |
| 对噪声的处理 | 压总量/剪弱突触/混入历史 | 学习门控（无信号不学——底噪不污染，见底噪报告） |
| 可计算性 | 无公式（启发式干预） | **key = (Σw×方向) × gain——三个量都可直接测量** |
| 实验结论 | trace 假象被推翻、压制断链、STD 无效、gain 开后门、定式治标 | v/w 恒定 0.9（线性）、反向 16.0→0（门）、gain 超越 4 倍权重（乘法）、w×gain 守恒（乘积等价） |

**过去机制失效的单一根因**：所有过去机制都把注意力当作"可以施加的东西"，在**竞争结果或读出公式**上做文章。但竞争是相对排序——读出平滑不改排序、总量压制不改相对序、疲劳不改注入步竞争、gain 只改预设词。**没有一种机制触碰到动力学原语层（方向/权重/兴奋度）的乘积结构**。

**v2.0 理论成立的原因**：注意力不是"机制"，是**动力学原语的乘积结构**——方向决定可达（谁参赛）、权重决定驱动（多强）、兴奋度决定排序（谁赢）。三个量全部可在网络里直接测量（W_out 查方向与权重，v/gain 查兴奋度），因此**注意力是可计算的**：

```
key_j = gain_j × Σ_{i∈fire} [i→j 边存在] × w_ij × (1 − fat_i)
```

## 六、意义与后续方向

1. **"注意力"不是要造出来的，是网络自己长出来的**：教学次数（权重 w 增长）是兴奋度之外最直接的杠杆——教得够多，w 增长 → key 增长 → 网络自己注意它。人调节环境（教学/奖励），网络自主成长。
2. **三维干预各有边界**：
   - **方向** = 可达性（结构性事实，教学建边改变——知识决定谁可被注意）
   - **权重** = 驱动强度（教学次数/学习率的领域——知识深度决定注意强度）
   - **兴奋度** = 状态调制（gain/膜电位——当前状态决定注意优先级，可被外部调质/奖励改变）
3. **可测量化**：任意目标 j 的注意力键可在线计算——`key_j = gain_j × Σw_ij（方向过滤后）× (1−fat)`——可预测"哪些词注定注意不到中间词"（诊断：中间词 key 远低于竞争环境入场线）。
4. **未来方向**：
   - 教学力度参数化：`--entrench-times` 默认 4 次（≈32.0）对旧词不足，建议评估提到 7 次（56.0）以上（v1.1 遗留，与 v2.0 权重线性结论一致）；
   - 兴奋度-权重的动态交互：fat（疲劳）已进入公式（×(1−fat_i)）——高频词驱动降效、低频定式链满效（v1.1 STD 实验"无效"是因为瓶颈在首跳，v2.0 公式中它是权重维的时变因子）；
   - 底噪修复后（noise_amp=0.2 + 学习门控），v 的噪声成分不再是污染源——兴奋度测量更干净（见底噪过度设计诊断报告）。
