> 触发：用户决策 2026-08-09——"现在实现了人之初复读人之初，能不能实现人之初到性本善？"

## 一、背景与目标

**复读已成立**：输入整句 → 唤起整句（26 字母 26/26 零遗忘、整句涟漪复述率 1.000）——这是三字经机制第一层（复读条件反射，Hopfield 自联想）。

**本实验验证第二层（下一句条件反射）**："读的越多印象越足，听到人之初就知道性本善"——输入**前缀**"人之初" → 网络内唤起**后续**"性本善"。即：**局部触发、整块唤起**（模式补全，pattern completion）。

**关键区别**：整句涟漪（_sent_ripple.py）的唤起是**外挂检索**（签名 + 倒排索引）；本实验要求**网络内长出来**（W 句内连接真实驱动）。

## 二、机制

1. **跟读**：句子反复经历（整句注入 R=30 次）→ 句内所有词共发放 → Hebbian 形成**句内强互连** → 句子固化为一个完整模式（"读的越多印象越足"）
2. **唤起**：只输入前缀（句首词神经元激活）→ 句内连接驱动后续词神经元发放 → 完整模式被补全 → 说出后续

这就是 Hopfield 模式补全在网络内的物理实现，对应 v2.0 Stage 2 短句级核心验收（句复述 ≥0.95 + 局部触发唤起）。

## 三、实验设计

| 项 | 配置 |
|---|---|
| 网络 | SchemaNet 稠密：n=256，slots=4，theta=1.0，decay=0.9，eta=0.1，w_max=2.0，wta_k=16，noise 0.06/0.5，refractory=1 |
| 词模式 | `_word_pattern(n=256, k=2)` 哈希（本验证不扩容，无模式冻结问题） |
| 句子 | A 人之初性本善 / B 春来花自开落 / C 风吹云散去远（无共词对照）；D 性相近习相远（与 A 共享"性"，串扰观察） |
| 训练 | 整句注入 × 30 次跟读（Hebbian 模式固化） |
| 评估 | ① 整句复述率（输入整句→唤起自己）；② 前缀唤起率（输入前 3 词→后 3 词神经元发放覆盖率） |

## 四、结果

### 4.1 前缀唤起（本实验核心）

| 前缀 → 后续 | 后续唤起率 | 判定 |
|---|---|---|
| 人之初 → 性本善 | **1.000** | ✅ 成立 |
| 春来花 → 自开落 | **1.000** | ✅ 成立 |
| 风吹云 → 散去远 | **1.000** | ✅ 成立 |
| 性相近 → 习相远 | **1.000** | ✅ 成立 |

**4/4 成立**：输入前缀 → 网络内驱动后续全部神经元发放 → "人之初"唤起"性本善"在网络内真实跑通。

### 4.2 整句复述（对照）

| 句子 | 复述率 |
|---|---|
| 人之初性本善 | 0.917 |
| 春来花自开落 | 1.000 |
| 风吹云散去远 | 1.000 |
| 性相近习相远 | **0.750** |

### 4.3 发现：共词串扰

D 句（性相近习相远）与 A 句共享"性"——整句复述率掉到 0.750（其余 1.000）。**词共享 = 模式竞争**："性"同时属于两个句子模式，整句注入时两个模式互相拉扯，wta 竞争压掉部分神经元。

这正是真实语言的常态（高频词"之/不/是"出现在无数句子里），是**泛化的种子也是混淆的来源**——对应用户四阶段理论里的"词意条件反射"层级，是 Stage 2 之后要解决的核心问题。前缀唤起未受影响（前缀本身强烈指向本句，模式补全占优）。

## 五、模型留档约定（本次确立，增量成长的硬前提）

用户问题："每一次训练后的模型呢？"——现状缺口：只有 `_accept_*.py` 主实验存 net.npz，小实验（涟漪/句记忆/本实验）只存指标**不存模型**。没有模型快照就无法增量续训，"每次从头开始"问题无法根治。

**约定（自本次起执行）**：

1. **每次训练必须留档模型快照** `runs/{时间戳}/net.npz`：W + 构造参数 + **词模式字典 pats**（词→神经元落位与 W 一起持久化——v2.1 分配制模式字典的前身）
2. **留档内容 = result.json（指标）+ net.npz（模型）+ 数据 + memory**，四件套缺一不可
3. **续训 = load_net → learn_gate 续学 → 再快照**（不从头开始），此即增量成长闭环
4. `save_model`/`load_net` 已分别在 _sanzi_jing.py / sparse_net.py 就位（稀疏版需补 pats 持久化，Phase B 落地）
