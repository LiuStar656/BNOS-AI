> 数据：ESC-50 开源数据集（karolpiczak/ESC-50，chirping_birds/cow/cat 真实录音 5s）

## 背景

用户评价（2026-08-11）：合成正弦音生成的结果"完全牛头不对马嘴"——
要求用开源自然音效库（ESC-50 真实录音）先**逆向解析**（真实音效过我们的
编码器变成什么）再**反推**（网络能否学回来）。

## A. 逆向解析：物理层对真实音效的编码结构

| 指标 | 过零率版（64 bin 单频估计） | mel 版（8 频带频谱指纹） |
|---|---|---|
| 鸟：主帧占比 / 跳变率 | 0.232 / **0.735** | 0.303 / **0.571** |
| 牛：主帧占比 / 跳变率 | 0.267 / **0.621** | 0.455 / **0.531** |
| 猫：主帧占比 / 跳变率 | 0.303 / **0.490** | 0.182 / **0.582** |

结论：**真实音效在离散帧词编码下"散乱"**（跳变率 0.5-0.7 = 每 2 帧就换
帧词，轨迹去重后仍 50-70 帧）。mel 频谱比过零率**略稳**（鸟 0.735→0.571、
牛 0.621→0.531），但**不是银弹**——真实音效频谱本身随时间复杂变化，
任何离散量化都会产生长而多变的轨迹。合成音"结构完美"（跳变 0-0.375）
是因为合成音恰好匹配了"单频+能量"假设——**之前所有 PASS 都在这个假设圈里**。

## B. 反推（概念 → 逐帧复现）：两层编码都失败

| 轨迹一致率 | 过零率版 | mel 版 |
|---|---|---|
| 鸟 | 0.082 | 0.193 |
| 牛 | 0.526 | 0.057 |
| 猫 | 0.204 | 0.121 |

生成声波再听 → 唤起概念：**两层全 0.0**（闭环断）。mel 版牛从 0.526 掉到
0.057——mel 帧词空间（256）更大、轨迹更长（53-58 帧），bigram 链误差
累积更严重。

**根因三层叠加**（"牛头不对马嘴"的完整解释）：
1. **物理层**：离散帧词编码丢失频谱连续性（mel 略好但不够）；
2. **表示层**：256 帧词对真实频谱仍是粗暴量化（频谱渐变 → 帧词非连续跳变）；
3. **学习层**：bigram 链不适合长轨迹——57 帧链每步 ~90% 正确率 → 全链
   正确率 ≈ 0.9^57 ≈ 0.2%；频繁跳变让预测竞争分散。

## C. 感知方向（真实音效 → 唤起概念）：mel 版成立

| 注入 | 唤起鸟 | 唤起牛 | 唤起猫 |
|---|---|---|---|
| 真实鸟叫（99 帧完整） | **1.0** | — | — |
| 真实牛叫（99 帧完整） | — | **1.0** | — |
| 真实猫叫（99 帧完整） | — | — | **0.0**（待查） |
| 交叉：牛音→鸟 / 鸟音→牛 | 0.0 / 0.0 | | |

**感知方向成立**：真实音效 → mel 轨迹 → 序列注入 → 唤起概念（鸟/牛 1.0、
交叉干净）。感知不需要逐帧复现（只需轨迹尾帧→概念桥 + 序列级注入），
因此绕开了 bigram 长链误差。猫 0.0 未查清（疑似帧词共享冲突或样本
质量问题——ESC-50 猫样本 5s 可能含大量非叫声段）。

## 结论

1. **用户评价正确且已被量化**：合成音 PASS 是物理层假设圈内的自洽，
   真实音效下生成逐帧复现（TTS）不成立——三层根因（离散编码丢连续性、
   256 词粗暴量化、bigram 链长轨迹误差累积）。
2. **感知与生成不对称**：真实音效"听懂"（→概念）成立，真实音效"说出"
   （概念→逐帧频谱）不成立——后者需要表示层升级。
3. **mel 频谱是正确的物理层方向**（解析稳定性提升），但离散帧词 + bigram
   链的表示/学习层需要换代。

## 边界与后续

- 猫 0.0 未查（帧词共享 or 样本质量）；交叉只测了牛↔鸟；
- 下一步方向（按价值）：
  ① **连续表示**：网络直接学 mel 向量序列（连续特征输入/输出，替代离散
     帧词 + bigram）——需引擎支持连续模式，改动大但治本；
  ② **感知优先落地**：真实音效分类（ESC-50 全类别）+ 概念绑定，生成侧
     降级为"概念 → 频谱原型"（低频目标）；
  ③ **长时帧/频谱平滑**：帧长 50→200ms + 时间积分，降跳变率（治标）。
