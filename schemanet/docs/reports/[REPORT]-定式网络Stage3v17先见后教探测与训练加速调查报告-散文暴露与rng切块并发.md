## 一、背景与问题

v16 校准好的目标边（他→上课 等）在"散文先见"后会不会被重新碾压，是 v17 能不能走"先见后教"路线的关键。同时全量散文（~1 万句）逐句喂入约 **60 分钟**，用户要求解决耗时、支持并发切块。

本探测回答两个问题：
- **散文先见 → 教学后教 → 分句接话**：先见会不会碾掉专门边？后教能否拉回 v16 基线（修正前 0.895）？
- **训练加速**：批量/并发切块是否可行？可行性边界与等价性证据是什么？

## 二、探测结论（先见后教，smoke 949 句实测）

散文 5 本（鲁迅公版）→ 繁转简 → 分句 → 词表内过滤（≥3 词）→ 949 句可喂。阶段链：

| 阶段 | 命中 | 命中率 | 对照 |
|---|---|---|---|
| v16 基线（修正前） | 17/19 | 0.895 | — |
| 阶段 B：散文先见后（修正前） | 18/19 | **0.947** | 反升 +0.052，无碾压 |
| 阶段 C：+108 条×2 轮后教（修正前） | 17/19 | **0.895** | 精确拉回基线 |
| 阶段 D：校准后 | 19/19 | 1.000 | 校准 1 处（=v16 负担） |

**结论：先见后教安全可用。** 散文含大量真实"因为…所以/虽然…但是"共现，先见后配对边**绝对强度抬升而非被碾**（0.947）；后教 108 条×2 轮把目标边压回基线（0.895），校准负担不变（1 处）。v17 可按此路线开发。

## 三、训练加速调查链（本报告核心）

### 3.1 需求

全量散文先见逐句 ≈ 60 分钟。用户："怎么会花这么多时间？并发呢？能不能切割分块训练？"

### 3.2 尝试一：纯统计批量（跳过动力学）→ 不等价

理论：学习规则纯加性、句间独立 → 统计相邻 bigram 共现 + 词频 → 秒级一次更新。对拍（smoke 949 句、2 个 v16.0 副本逐边对比）：

- 仅补 STDP bigram：边总数 18,467,460，一致 15,028,113，差异含 0.1 / 0.5 两类
- 补 Hebbian 词内互连后再对拍：一致 15,052,880，**仍不等价**（差异 0.1 / 0.5 两类，逐句有、批量无）

### 3.3 深查根因：回响噪声发放

构造句诊断（\_verify_diag.py）：**喂 3 个无重复词，差异竟达 3600 条，且差异边指向大量未注入词**。逐步追踪（\_trace_reverb.py）锁定：

```
_learn_sentence 每句结尾回响 4 步：v 不清零、只清 spikes
→ v = v×0.9 + 噪声 连续累积（噪声 0.5 稳态 ≈ 2.5 > θ=1.0）
→ 所有神经元越阈 → WTA 每步发 20 个随机词（wta_k 上限）
→ Hebbian(0.1) + STDP(0.5) 学出随机边
→ 每句回响产生 ~3600 条随机边（实测 456+780+1178+1179）
```

数量级闭环：**949 句 × 3600 ≈ 340 万 = 对拍差异（18,467,460 - 15,052,880 = 3,414,580）的精确数量级**。

**结论：学习路径含 rng 驱动的噪声发放，逐句路径本身不确定 → 纯统计批量在数学上不可行**（不是实现 bug，是机制）。

### 3.4 出路：rng 状态传递的进程切块 → 等价已证

原理：噪声发放只依赖 rng 序列。主进程预生成**每块边界的 rng state**（只跑 `random()` 不学习，全量约 30 秒），各进程从对应 state 恢复 rng 喂自己的句子块 → 块内噪声序列与串行**逐位一致** → 增量边合并 = 串行结果。

**等价性对拍（\_verify_chunk.py，100 句 2 块）**：

```
边总数 15,332,295，一致 15,332,295，差异 0  ✅ 切块 ≡ 串行 逐边等价
```

收益：全量逐句 60 分钟 → `--chunks 4` 约 15 分钟（每块独立进程喂 ~2500 句），满足对拍铁律。

### 3.5 附带发现：噪声发放是 v16 训练的内置特性

v16 训练一直用 `_learn_sentence`（含回响噪声发放）→ v16 快照里的随机弱边（0.1/0.5）正是它留下的。**v17 切块训练与 v16 同构，验收基线可比**；smoke 探测结论（0.947/0.895/校准 1 处）在两种路径下都稳定复现，与随机弱边无关。

## 四、结论

1. **先见后教可行**：散文先见反抬升（0.947），后教拉回基线（0.895），校准负担不变（1 处）——v17 按此路线推进。
2. **纯统计批量不可行**：学习路径含 rng 噪声发放（回响 4 步 v 不清 → 噪声累积越阈 → 每句 ~3600 随机边），对拍逐边不等价。
3. **rng 状态传递切块可行且等价**：预生成每块 rng state → 各块恢复喂入 → 增量合并；100 句 2 块对拍 0 差异。全量 60 分钟 → ~15 分钟（4 进程）。
4. **验收基线口径不变**：v17 目标仍为修正前 ≥0.95、校准 ≤1 处；0.8 以上只作回退底线（校准负担代价）。
