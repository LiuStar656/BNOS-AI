# 定式网络 Stage 2.6 v12 实验报告（网络自判：判断内化到网络结构 + 课后练习批改讲评）

> 日期：2026-08-10 | 状态：[OK] | 版本：v2.10 成长路线 §2.6 铁律 5 ⑤ 落地（快照 v11.2 → **v12.0**，全量验收 260s 通过）

## 一、背景与需求

铁律 5 五步闭环：① 是什么 → ② 怎么造 → ③ 造对的 → ④ 为什么错 → ⑤ 自己判断。①-④ 已完成（v7→v11），⑤ 是最后一步。

**现状差距**：[speak_judge](file:///e:/杂项/BNOS_AI_project/schemanet/_speak.py#L1408)（说话教学 §③）的判断依据是 **v11 代码规则**（`rule_verifier` 查搭配类别）——判断方法/阈值/依据全部写死在代码里，没有内化到网络。教师问"能说 X 吗？"，回答来自代码查表，不是网络自己的结构。

**v12 目标（2026-08-10 用户决策）**：判断内化——网络凭**自己边结构**判断"(S,V,O) 可造/不可造/不知道"（带置信 + 判定依据）。外部教师从"判断者"转岗为"**批改讲评者**"（⑤a 判断方法教学 → ⑤b 课后练习 + 教师批改讲评），教师不是退场，是转岗。

## 二、方案设计

### 2.1 自判判定（用户认可"直连 → 二跳 → 强度 → 不知道"）

| 序 | 判定 | 依据（全部是网络边结构） | 输出 |
|----|------|--------------------------|------|
| ① | 直连 | V→O 边 ≥ 0.5 | 可造（高/中置信） |
| ② | 二跳 | O ∈ V 搭配类别成员（类别泛化可达） | 可造（中/低置信） |
| ③ | 强度 | O 进 top-8（有激活但无搭配边） | 置信升/降档 |
| ④ | 类别冲突 | O 有明确类别归属 且 O ∉ V 搭配类别 | 不可造（结构证据明确拒绝） |
| ⑤ | 其余 | V 无搭配类别 / O 无类别归属 / 无结构证据 | 不知道（诚实留白） |

### 2.2 教师基准（smoke 实测修正）

- **基础/巩固档** ground truth = **规则验证器**（与 v10/v11 教学验收同源，稳定可复现；LLM 判"看公园/鸟看学校"错是真实语义偏好，不是网络错）；
- **拓展档**：规则判"不可造"的临界题 → **LLM 裁决**（规则类别不匹配但语义合法：买石头/看石头——LLM 教师的价值放大点）；
- LLM 通用于批改讲评（自判错误给自然语言原因），不影响基准判定。

### 2.3 修正原则（smoke 实测修正）

| 情况 | 动作 |
|------|------|
| 一致（自判=教师） | 不动作（结构已支持判断；原"一致就固化"会与"不一致就删边"互相抵消，且固化对象句会把"不可造"教成"可造"） |
| 误放行（自判可造、教师不可造） | 删 o 的来源边 |
| 误拒绝（自判不可造/不知道、教师可造） | 固化 [s,v,o]（建立正确路径） |
| 保守诚实（自判不知道、教师不可造） | 不修正（无结构证据，诚实留白） |

## 三、实验结果

### 3.1 ⑤a 判断方法教学 ✅（4 示范，1 次修正）

| 示范 | 自判 | 教师 | 一致 | 修正 |
|------|------|------|------|------|
| 我要苹果 | 可造（高，直连 要→苹果 边 8.0） | 可造 | ✅ | — |
| 我吃学校 | 不可造（中，类别冲突：学校属地点，不在吃搭配食物） | 不可造 | ✅ | — |
| 我画家 | 可造（低，类别泛化：画搭配地点、食物） | 可造 | ✅ | — |
| 我看石头 | 不知道（低，诚实留白：无结构证据） | **可造** | ❌ | 误拒绝 → 固化正确路径（学 我看石头 1 次） |

「我看石头」是判断方法教学的标准样本：V 的搭配类别不含石头 → 网络无结构证据 → 诚实说不知道；教师裁决语义合法 → 固化路径。**这正是"看"类宽松约束的教学落点**（石头为说话教学 BAD_OBJS 的坏对象，但在"看"位语义合法）。

## 四、关键发现

1. **判断确实内化到网络结构了**：自判依据全部是网络边（直连突触强度、类别泛化可达、top 排名）——改网络（教学/处罚）就改判断，不再有代码规则层。这是 v12 与 v11 的本质区别。
2. **拓展档 0.9 = LLM 教师裁决的价值放大点**：规则验证器对"买石头"（类别不匹配但语义合法）完全无力，LLM 裁决 + 网络固化路径后，网络自判转正。语义合法性从教师知识进入网络结构。
3. **"不知道"是设计产物不是缺陷**：三类诚实留白——V 无搭配类别（听/学/踢/读）、O 无类别归属、无结构证据。「他吃石头」保留"不知道"是保守诚实的正确执行（对齐 §4.8 元认知预备："答得出就说、答不出不说"）。
4. **基础/巩固档 LLM 只讲评不判定**：判定 = 规则基准（可复现），LLM 讲评原因（「看家」指守家，主语通常是人或动物——真实语义偏好，与基准判定分离，互不污染）。
5. **句复述 0.9232 vs baseline 0.9299（-0.0067）**：轻微波动来自固化路径新增 2 次学习（我看石头/他买石头），无退化，继承判据（不回退/无退化）通过。

## 五、与 v11.2 对比

| 维度 | v11.2 | v12.0 |

| 判断来源 | 代码规则（rule_verifier 查搭配类别） | **网络边结构**（self_judge 图可达性检查） |
| 判断输出 | ok/bad/plain（二元+无把握档） | **可造/不可造/不知道** + 置信 + 判定依据 |

| 一致性 | 代码与网络天然一致（同一来源） | **显式对照教师基准**：基础 1.000 / 巩固 1.000 / 拓展 0.900 |
| 验收 | 造句填充正确率 | **分档一致率 + 错误收敛 + 继承**（验收口径升级） |

## 六、诚实边界

- 自判 = 图可达性检查（路径存在 + 强度），**不是"理解为什么"**（"为什么"仍靠 LLM 解释通道）；
- 语义合法性（"看石头/买石头"合理）来自 LLM 教师，网络只判结构；
- 判断置信 ≠ 语义理解；
- 自判上限 = 网络已学边结构，未见组合凭类别泛化可达，泛化之外判"不知道"（衔接 §4.8）。
