## 三、暴露的问题

### 问题 1（最大发现）：快照链断裂——问答/表达/对话教学"学了但丢了"

- **证据**：`runs/index.jsonl` 的 parent 链显示 **18.12（自我表达）、18.13/15/16（问答应答）、18.14/17/18/19（对话教学/v19 正式课程）全部是 17.0 的并列分支**，主链只有 17.0 → 18.21（s3.4）→ 19.0（OOV）→ 20.0（组合教学）
- **后果**：v20.0 网络的问答边、表达边全部缺失——实测 edge 累→他=0、疼→帮=0、难过→因为=0、我→疼=0（问答 14 题、FCT 3 题、层5 1 题全断的根因）；E 唯一的 1 分 = 命名题"什么是苹果？"（苹果→是 104 来自 v17 内的 2.5 词典学词义教学，不是问答教学）
- **根因**：多个教学脚本各自 `load_version("17.0")` 起点 + 快照版本号手工管理，导致并行分支未合流——**"完成了的教学"没有进入"正式成长链"**
- **教训（铁律级）**：教学成果必须以"主链连续快照"形式沉淀，任何脚本不得 fork 旧版本另起分支（除非明确回退训练并标注）

### 问题 2：组合泛化 = 0（H 压轴 0/15）

- 14 个真实断点 = 未见词对缺边清单：汤→很、图书馆→唱、超市→玩、他→没、坚持→读书、我们→多、厨房→做、超市→买、图书馆→读、上→喝、了→牛奶、家→打扫、公园→跑步、商店→打
- 与上次考试（2/16）同构：**链读形态下"词对未学 → 必断"**——组合泛化仍靠"词对已学"托底，未见组合读不出
- 诚实边界：H 设计为必断题（暴露缺口用），0 分是如实反映，不是网络"变差了"

### 问题 3：提问池教 5/6（吃饭→为什么 未教）

- G 9/10 的 1 断 = NEW_ASKS 第 2 条（"为什么要吃饭？"）——s3.4 阶段1 主动提问只固化了 5 条提问链

### 问题 4：F 层2 判定口径漏洞（10 分假通）

- express_read 层2 分支（keyword ∈ 状态词集）：`state = keyword` 直接激活 + `seq = [expect[0], state]`——**不读任何边**（"我疼"的"我"是硬编码语用规则）
- 考试 F 层2 的 10 题全通 = 规则输出而非边驱动 → 成绩虚高 5 分，如实标注：**层2 通过 ≠ 网络有"我→疼"边**（实测该边 = 0）

### 问题 5：OOV 字造词——机制部分有效，缺字边 5 个词（用户："不要避开词表外的词，检验是否能通过字造词"）

- **已固化 OOV（v19 教学过）7/7 全通**：吃→草莓酱 96、看→红绿灯 48、用→电动牙刷 76.8、电动牙刷→刷牙 64 等边完整保留在当前快照链 → **OOV 教学成果没有丢**（与问题 1 的链断裂形成对照：OOV 在链上）
- **未固化 OOV 字造词 3/8 通（字边继承成功）**：
  - "我们吃了晚饭" ✅——了→晚饭 = 了→{晚,饭} 并集，字边 了→饭 存在
  - "她在睡午觉" ✅——睡→午觉 = 睡→{午,觉}，字边 睡→觉 存在
  - "我们在家吃早饭" ✅——吃→早饭 = 吃→{早,饭}，字边 吃→饭 存在
- **未固化 OOV 5/8 断（缺字边）**：

| 词 | 断点 | 缺的字边 |
|---|---|---|
| 椅子 | 在→椅子 | 在→椅 / 在→子 = 0 |
| 操场 | 去→操场 | 去→操 / 去→场 = 0 |
| 起床 | 早上→起床 | 早上→起 / 早上→床 = 0 |
| 雨伞 | 带→雨伞 | 带→雨 / 带→伞 = 0 |
| 袜子 | 双→袜子 | 双→袜 / 双→子 = 0 |

- **结论**：字造词机制（字模式并集 → 字边继承）**真实有效**（3/8 未见词靠字边读出）；但**依赖语境词→字的边存在**——5 个词的字从未在教学中与语境词共现 → 读不出 → **需要专门造词训练**（教这些 OOV 词的句级边，如"在椅子上/去操场/早上起床/带雨伞/穿袜子"，固化后字造词即可覆盖）
