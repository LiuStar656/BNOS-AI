## 一、背景与需求

用户指令（2026-08-10）："数字章节挪到推理单元后，开始 s3"——Stage 3 = 复杂句级（**关系**）。用户决策三个要点：

1. **教学形式 = 题集模式**（复用 v13 四阶段：自判 → 批改讲评 → 修正 → 复测）
2. **数据规模 = 小规模**（3 组关系词 × 4-6 内容变体，题集 15 道）
3. **拓展档 = 含语义因果题**（"因为下雨所以带伞 对吗？"类——内容合理性代码规则完全无力，**LLM 裁决的价值放大点**）

## 二、方案设计

### 2.1 训练（数据专门化 + 关系定式）

```
关系词对跟读 ×3  →  因为→所以 / 虽然→但是 / 先→然后 直连（边权 24.0）
错配负例拒绝 6 对 →  因为→但是 等 6 个非白名单对防御性删边（不建边）
关系句跟读 ×3    →  11 条专门句 _learn_sentence（学相邻 bigram 转移定式）
```

### 2.2 网络自判（结构检查，纯代码）

`[关系词1, X, 关系词2, Y]` 四要素：
- **配对直连** `关系词1→关系词2`（跟读建的关系定式）
- **内容链** `关系词1→X`、`X→关系词2`、`关系词2→Y`（整句记忆）
- 全通 → 可造；配对通但内容链缺 → 不知道（诚实）；配对无直连 → **不可造**（错配结构）

### 2.3 教师判定

| 题型 | 判定 | 依据 |
|------|------|------|
| 普通题（judge=rule） | 白名单配对代码规则 | (因为,所以)/(虽然,但是)/(先,然后) ∈ REL_PAIRS → 可造；否则错配不可造 |
| 语义因果题（judge=llm） | **LLM 裁决**内容合理性（合理=可造 / 不合理=不可造） | 配对必然合法，内容合理性代码盲区；无 key 回退**人工语义标注 GT**（可复现基准） |

### 2.4 修正（v13 四原则 + 语义盲区保守诚实）

| 情况 | 动作 |
|------|------|
| 一致 | 不动作 |
| 误放行（错配题） | 删错配对边 |
| 误拒绝 | 固化解 |
| **语义盲区**（配对合法但内容被教师否定） | **保守诚实不动**——结构合法 ≠ 语义合理，删边会破坏合法结构，判定由 LLM 讲评补位 |

### 2.5 LLM 讲评（只对答错/答不出）

- 所有"自判 ≠ 教师"的题生成「正确答案 + 解析」（两行格式，2026-08-10 用户定：判定用代码，LLM 只讲评）

### 2.6 题集（15 道 = 基础 5 + 巩固 4 + 拓展 6）

| 档位 | 题数 | 内容 | 预期 |
|------|------|------|------|
| 基础 | 5 | 训练句复测（因为下雨所以带伞 / 虽然下雨但是跑步 / 先吃饭然后写作业…） | 网络全对 |
| 巩固 | 4 | 新内容组合新对（bigram 链全训练过 → 网络可判）：因为生病所以睡觉 / 虽然累但是上课 / 先洗手然后睡觉… | 网络全对 |
| 拓展·错配 | 3 | 因为下雨**但是**带伞 / 虽然下雨**所以**跑步 / 先吃饭**所以**写作业 | 凭"配对无直连"拒绝 |
| 拓展·语义 | 3 | 先吃饭然后睡觉（合理）/ 因为下雨所以吃饭（✗无因果）/ 因为饿所以看医生（✗无因果） | LLM 裁决；网络对 2 道语义盲区 |

## 四、关键发现

1. **关系定式 = 一组直连**：关系词对跟读（因为→所以）建一条独立于句子的直连，错配题凭"无此直连"即可拒绝——**关系合法性被压缩成一条突触**，比内容链判断更省（图 2 直观）。
2. **语义合理性是规则盲区、LLM 放大器**：白名单代码只能判"配对对不对"，判不了"内容通不通"；LLM 裁决 3/3 与人工标注一致，讲评自然语言解释补位——Stage 3 首次把 LLM 从"讲评"升到"裁决"（用户决策）。
3. **网络语义盲区保守诚实**：结构全链通 ≠ 语义合理（因为下雨所以吃饭），网络判"可造"、教师判"不可造" → 不动网络不硬判，盲区如实记录而非掩盖——与 v13「他在吃石头」同构，且独立成档统计。
4. **数据专门化落地**：11 条专门关系句替代 15000 句真实语料——小规模、可解释、可复测；旧 stage3 真实语料弃用（违反专门化）。
5. **基础/巩固阶段1 即全对**：与 v13 不同（v13 靠修正收敛），关系定式训练直接把转移边建足，训练句与新组合链都能判——关系句"会读就会判"。

## 五、诚实边界

- 关系句结构固定为 4 词 `[关系词1, X, 关系词2, Y]`，X/Y 均为单词——**多词内容（因为下雨了所以）未覆盖**；
- 内容语义合理性网络**无任何信号**（非"学得慢"，是"没这个维度"）——语义题靠 LLM/人工标注，非网络能力；
- 语义因果题 3 道 LLM 裁决，无 key 时回退人工标注 GT（模板占位，报告已区分）——裁决质量依赖 LLM/标注，不依赖网络；
- 网络对"不知道"的判定阈值 0.1（边权）是防御性设定，未做灵敏度扫描；
- 继承句复述 0.9258 vs 训练前 0.9316（-0.0058）在容差内，但为本次实测最低点——关系词新词分配挤占部分涟漪资源，量级无害（v15 后观测）。
