# 定式网络 Stage 2.6 v11 迭代实验报告（RL 颗粒度升级：连接级归因处罚 + LLM 教师）

> 日期：2026-08-10 | 状态：[OK] | 版本：v2.6 成长路线 §2.6 v11 迭代落地（快照 v10.0 → **v11.0（规则版）/ v11.1（LLM 教师首版）/ v11.2（LLM 教师纯语义版）**）

## 一、背景与需求

v10.0 动宾搭配约束后，病句拒绝 87/87、"我喝学校"造不出来——但**网络只知"可不可以"，不知"为什么"**。用户提出本质问题（生物价值学习对照）：

- 吃饭是好的（分泌多巴胺）、吃石头是坏的（痛觉）——痛觉告诉生物"这个不能吃"，下次看到石头就知道不能吃，这才是学习；
- 老师教学：对的鼓励、错的解释原因，学生之后看到错误选项就知道**这个为什么错了**。

用户决策链（2026-08-10）：
1. "不是食物否定知识，而是强化学习处罚原因"——纠正 v11 核心方向；
2. "现在的 RL 颗粒度够吗？"——现有奖励是**样本级二元标量**（对/错打回整次共发放），处罚原因需落到**连接级**；
3. "以后所有强化学习都需要让 LLM 来输入处罚原因"（项目级硬约束）；
4. "我觉得强化学习的时候判断可以用 llm 来负责"——**LLM 升级为教师（判断 + 解释一体）**。

**RL 颗粒度三层缺口**：

| 层 | v10 现状 | v11 目标 | 对齐文献 |
|----|----------|----------|----------|
| 奖励粒度 | 样本级二元标量（整次共发放打回） | 原则级二元奖励（S 在位 / V/O 在位 / V 有搭配 / O 属搭配类 / O 进 top） | RLBFF（带原因的反馈） |
| 归因粒度 | 无（只知道整句错） | **连接级**：错误时反向追踪候选词靠哪条突触进 top → 处罚落点 = 该连接显式减权删除 | 信用分配 / Explainable RLHF |
| 表示粒度 | 稀疏网络 W 无负权重 | 删除 = 惩罚上限（排斥用"边不存在"表达） | 稀疏表示 |

## 二、实验设计

**起点**：加载 v10.0（动宾搭配链最新，n=148776，模式 37062）——在 v10 快照上迭代，不重训绑定/定式/动宾。

**流程**（[_grow_v11.py](file:///e:/杂项/BNOS_AI_project/schemanet/_grow_v11.py)）：

```
load_version("10.0")
  → 归因（attributed_sentence 升级版：每个候选词记录得分来源边）
     sources = {词: [(源类型, 源词, 目标神经元, 权重)]}
     源类型 ∈ {"V直连", "类别泛化", "O槽保底"}
  → 验证器（原则级二元判断，RLBFF 粒度；LLM 教师 or 规则回退）
  → 处罚（连接级：top 里不在搭配类别的词 → 删除其全部得分来源边）
  → 原因（LLM or 模板：归因记录 → 自然语言处罚原因，硬约束）
  → 验收⑤ 归因/处罚/原因 + 继承 v10 全验收（零遗忘）
  → 处罚后重测（正式验收③b 口径）
  → save_snapshot(parent="10.0") → v11.0
```

**双轨实现（LLM 教师）**：
- `DEEPSEEK_API_KEY` 存在 → `llm_judge()`：LLM 教师判断"`S+V+O` 搭配是否合理" + 生成自然语言原因（LLM-as-Judge / RLAIF）；**输入限死**（只喂诊断内已有实体：V/O/搭配类别）+ **输出越界拦截**（未引用诊断实体 → 标注"[非网络知识拦截]"）——LLM 是"代嘴"不是知识源；
- 无 key → `rule_verifier()`（类别比对，v10 已验）+ `template_reason()`（模板解释器，标注"[模板占位]"）；
- **v11.0**：无 `DEEPSEEK_API_KEY` → `llm_enabled=False`，规则验证器 + 模板解释器跑通；**v11.1/v11.2**：设置 `DEEPSEEK_API_KEY`（DeepSeek，2026-08-10 用户提供）→ `llm_enabled=True`，LLM 教师实际接管判断与原因（实测见 §五）。

**架构划分**：LLM = 教师（判断 + 解释）、网络 = 学生（归因处罚 + 记忆）；LLM 不碰网络边，判断结论进入学习信号但网络学到的是**自己的边**。

**关键参数**：与 v10 同种子同划分（`SEED=42`，训练 800 / 测试 400，测试组合从未整句训练），`K=4`、`R=5`、`R_SVO=3`——验收与 v10 可比。

## 四、冒烟→全量实测暴露与修正（2026-08-10）

1. **首轮全量回归（ok 125/170 vs v10 的 170/170）**：处罚删除"食物→超市"16 边是**正确的连接级处罚**（超市非食物），但连锁暴露 v10 隐藏问题——"画"的 top-8 曾靠跨类词"超市"压线撑 ratio=0.5，删超市边后 → 0.375 ❌。**诊断结论**：真正问题是 top-8 里噪声词（点/地/与/特朗普/金正恩）不在 `noun_pool`，被处罚循环的 `w in noun_pool` 过滤排除，未受处罚。
2. **修复（逻辑层）**：去掉 `in noun_pool` 过滤——非 plain 组合处罚 top 里所有不在 `allow_mem` 的词（含噪声词），plain 组合处罚 top 里不在 `noun_pool` 的词；"类别标签→噪声词"传出突触被删，top 变干净。
3. **ok_tot=3 指标异常**：hold-out 验收循环里的临时变量 `n_ok` 覆盖了主计数 `n_ok`（同一函数作用域）→ 改名 `n_hok`，序列化指标恢复 170。
4. **补"处罚后重测"环节**：正式验收③b 口径 = 处罚后最终网络状态重测（`*_retest` 指标），训练时处罚前统计作对照（`*_t1` 指标）——"处罚后重测不回退"是连接级处罚的验收方式。

## 五、LLM 教师实测（v11.1 / v11.2，2026-08-10 用户提供 API Key 后接入）

**接入链路**：`_probe_llm.py` 验证 DeepSeek API 连通 → `_grow_v11.py` 主循环接入 `llm_judge()`（kind != "plain" 时 LLM 判定覆盖规则 kind）→ 原因块复用 LLM 原因（不重复调 API）→ 教师边界演示块（不改网络）→ 冒烟 → 全量。

- **接入条件**：环境变量 `DEEPSEEK_API_KEY`（DeepSeek，2026-08-10 用户提供）；无 key 双轨回退规则验证器 + 模板解释器（v11.0 已验）。
- **判断**：`llm_judge(diag)` 输出 对/错 + 一句 ≤20 字原因；解决规则验证器类别级误判（"看石头"被误判负例——石头非"看"的搭配类别，但"看石头"合理）。
- **越界拦截**：LLM 输出未引用诊断实体（S/V/O/搭配类别）→ 返回 None（**回退规则验证器，不作判错**——诚实底线修正：越界不是"错"，是"拒绝使用"）；LLM 判断用外部知识（教师知识），**处罚归因仍在网络边内**（教师说"错"，网络学自己的边）；
- **架构**：LLM = 教师（判断+解释）、网络 = 学生（归因处罚+记忆），两者边界清晰。

### 5.1 v11.1 首版实测暴露：prompt 上下文锚定（关键 Bug）

- 首版 prompt 带"上下文：动词 {V} 的搭配类别是[{allow_txt}]"——**LLM 被给定搭配表锚定**，附和类别约束（"看"搭配地点类），把 `我+看+石头` 误判为错（"「看」搭配地点，石头非地点"），丢失语义判断能力。
- **根因**：把网络知识域（搭配类别）喂进判断 prompt，LLM 变成"复读类别表"，不是语义判断。

### 5.2 v11.2 修复：纯语义判断

- prompt 改为"**不要参考任何给定搭配表，仅凭语义常识判断**"，`allow` 只留作越界检查实体。
- 修复后验证：`我+看+石头 → 对` ✅、`我+画+石头 → 对` ✅（教师超越规则验证器）；`我+吃+石头 → 错`、`我+喝+学校 → 错`、`我+买+学校 → 错` ✅。

### 5.4 一致率 0.587 定性：设计点落地，非失败

41% 分歧全部是 **LLM 语义判断超越规则验证器**（规则验证器是类别比对，LLM 是语义常识）：

| 组合 | 规则验证器 | LLM 教师 | 说明 |
|------|-----------|----------|------|
| 鸟+吃+牛奶 | ok | 错 | 类别对（食物类）但语义不自然（鸟不吃牛奶） |
| 狗+要+西瓜 | ok | 错 | "狗不会主动要西瓜"——语义常识 |
| 我+看+石头 | 错（类别误判） | 对 | 石头非"看"搭配类别，但"看石头"合理 |
| 我+画+石头 | 错（类别误判） | 对 | 同上，语义合法 |

**结论**：规则验证器在类别级判对、LLM 在语义级判错 → 教师信号比规则更精细；规则验证器误判的"看石头/画石头"被 LLM 纠正 → **教师超越验证器的设计目标实测达成**。这正支撑 v12（§2.6）：⑤ 自判验收口径 = 网络自判 vs **LLM 教师**判断一致率（而非 vs 规则验证器）。

### 5.5 病句 LLM 原因样本（v11.2 留档，10 条示例）

```
"动宾搭配不当，公园是地点非食物。"
"「喝」与「家」语义不搭配，家不可饮用。"
"「要」后接实物，不接人名地名。"
...
```

- 原因均为 LLM 自然语言（非模板占位），依据诊断内实体（越界拦截保障）。
- 原因块**复用判断块的 LLM 输出**（判断 + 原因一体输出，不重复调 API）；网络侧"为什么"的原材料（边 + 拒绝行为）与 LLM 解释通道显式区分（诚实边界）。

## 七、结论

1. **RL 颗粒度升级落地**：奖励（样本级→原则级二元，RLBFF）、归因（→连接级，Explainable RLHF）、表示（删除 = 惩罚上限）三层同时升级——处罚从"整次打回"到"精确删边"，且删的都是**来源边**（错词靠哪条突触进 top 就删哪条）。
2. **LLM 教师架构落地并实测**：判断 + 解释一体（RLAIF/LLM-as-Judge），输入限死 + 输出越界拦截（诚实底线：LLM 是"代嘴"不是知识源）；无 key 双轨回退保证冒烟/全量可跑通；**v11.1/v11.2 接入 DeepSeek API 实测**——判断 242 次、病句 LLM 原因 174/177、prompt 锚定 Bug 修复（纯语义判断，看石头判对）、教师超越规则验证器设计点达成（一致率 0.587 即语义级 > 类别级）。
3. **硬约束满足**：87/87 病句全部附自然语言处罚原因（v11.0 为模板占位，v11.1/v11.2 起 LLM 接入后自动替换为自然语言）。
4. **处罚治愈隐藏问题**：v10 的 170/170 靠"超市"跨类词压线掩盖的噪声污染，在连接级处罚下现形并被清除——处罚后重测 170/170，且对照（t1）暴露的 2 个"画"组合正是被治愈的样本。
5. **零遗忘保持**：字/词/句 + 2.5 四类 + hold-out 逐值不回退——删边不伤已学知识。
6. **数据边界诚实记录**：模板原因是"依据网络边生成的解释句"（标注[模板占位]，非 LLM 语义）；LLM 教师判断用外部知识，与网络边来源显式区分；动词语义义原仍缺（"为什么能吃"的深层价值学习留待价值预期阶段）；越界拦截返回 None（拒绝使用）而非判错。
