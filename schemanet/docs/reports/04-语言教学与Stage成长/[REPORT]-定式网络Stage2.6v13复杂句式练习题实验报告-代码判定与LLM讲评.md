# 定式网络 Stage 2.6 v13 实验报告（复杂句式练习题：代码判定 + LLM 讲评）

> 日期：2026-08-10 | 状态：[OK] | 版本：成长路线 §2.6 ⑤b 课后练习扩展（快照 v12.0 → **v13.0**，全量验收 220s 通过）

## 一、背景与需求

用户需求（2026-08-10）：
1. "句子变复杂一点：我要苹果 → 我想要苹果、他看石头 → 他在看石头"
2. "用复杂句式来做练习题"
3. "答不出来或者答错要纠正，然后让大模型告诉他正确答案和解析"
4. "**对错特别是判断题可以用代码不用大模型，大模型只负责告诉正确答案和解析**"

**探测前置（先不教，看网络能否理解）**：v12.0 上探测复杂句理解现状（`20260810_110204_probe_complex`）——整句复述率全 1.000（输入即点亮，只证明"记住词"），但**前缀续推全部失败**（「我想要」→ 的/了/是 霸榜，推不出苹果；「他在」→ 推不出看）：网络"记住但不理解"——复杂句从未教学，转移定式缺位 + 虚词枢纽连接数量爆炸（注意力=连接数量理论再现）。→ 结论：复杂句需要**练习题驱动**学习。

## 二、方案设计

### 2.1 题集（12 道，A/B 两型 × 三档，人工语义标注）

| 档位 | A 型（S+想要族+O） | B 型（S+在/想+V+O） |
|------|-------------------|---------------------|
| 基础 | 我想要苹果 ✅ / 我需要牛奶 ✅ | 他在看石头 ✅ / 我在吃西瓜 ✅ |
| 巩固 | 我想要香蕉 ✅ / 他想要饼干 ✅ | 我想看公园 ✅ / 他在吃苹果 ✅ |
| 拓展 | 我想要石头 ✅（临界：语义能说、价值坏） | 我在吃学校 ❌ / 他在吃石头 ❌ / 我在看石头 ✅（临界） |

### 2.2 判定 = 代码规则（用户定：判定不用大模型）

```
教师判定 teacher_rule（代码，可复现）：
  宽松动词 {看, 想要, 需要, 买} → 任意宾语可造
    （价值判断与句子合法性分开：石头是坏东西，但"想要石头/看石头"能说）
  严格动词 → 类别比对：
    O ∈ V 搭配类别成员 → 可造
    O 有明确类别归属但不在 V 搭配 → 不可造
    其余（V 无搭配 / O 无类别）→ 不可造（教师必须有明确答案，不留"不知道"）
```

### 2.3 网络自判 = v12 self_judge（核心三元）

- A 型「我想要苹果」→ self_judge(我, 想要, 苹果)：想要 无搭配类别 → 诚实留白"不知道"
- B 型「他在看石头」→ 去修饰词「在」→ self_judge(他, 看, 石头)：直连 看→石头 8.0 → 可造
- 修饰词（在/想）结构上无信号 → path 诚实标注"修饰未判"

### 2.4 修正 = v12 四原则（固化学整句含修饰词）

| 情况 | 动作 |
|------|------|
| 一致 | 不动作 |
| 误放行 | 删 o 来源边 |
| 误拒绝 | 固化整句（含修饰词 → 建立 想要→O / 在→V 转移定式） |
| 保守诚实 | 不动网络（自判不知道、教师不可造） |

### 2.5 LLM 讲评（只对答错/答不出；2026-08-10 用户定）

- 对**所有"自判 ≠ 教师"的题**（含保守诚实不动网络的不一致题）生成「正确答案 + 解析」
- 判定对错 = 代码规则；LLM 只负责讲评（两行格式：正确答案 / 不超过 40 字解析）
- 无 key / 失败 → 模板占位

## 三、实验结果

### 3.1 分档一致率（网络自判 vs 教师代码判定）

| 档位 | 阶段1（修正前） | 阶段4（修正后） | 判据 |
|------|-----------------|-----------------|------|
| 基础 | 2/4 = 0.500 | **4/4 = 1.000** | ≈1.0 ✅ |
| 巩固 | 2/4 = 0.500 | **4/4 = 1.000** | ≥0.9 ✅ |
| 拓展 | 2/4 = 0.500 | **3/4 = 0.750** | 泛化边界 |

### 3.2 修正与收敛 ✅（5 次固化 + 1 次保守诚实）

**误拒绝 → 固化（5/5 收敛）**：我想要苹果、我需要牛奶、我想要香蕉、他想要饼干、我想要石头
- 网络从"不知道"（V 无搭配类别）→ 固化整句 → 建立 想要→O 直连 → 复测转"可造"
- **「我想要石头」**：价值临界句按用户确认的"语义能说"原则判可造 → 固化（石头坏但不影响句子合法性）

**保守诚实（不动网络）**：「他在吃石头」
- 自判"不知道"（无结构证据）vs 教师"不可造" → 不修正
- LLM 讲评照给："正确答案：不能说『他在吃石头』。解析：'吃'的宾语必须是可食用物，石头不能吃，语义不成立。"

| 题 | 学生自判 | LLM 讲评 |
|----|---------|----------|
| 我想要苹果 | 不知道 | 正确答案：能说「我想要苹果」。解析：「想要」后接名词作宾语，表示希望得到某物，语法正确。 |

## 四、关键发现

1. **判定代码化后的一致性闭环完全自洽**：教师 = 代码规则（宽松/严格动词）、网络自判 = 结构检查，两者不一致 → 修正 → 收敛。12 题中 11 题最终一致，唯一不一致（他在吃石头）是**设计产物**（保守诚实：网络无结构证据不硬判，教师答案由 LLM 讲评给出）。
2. **"想要"族靠练习题学会**：想要/需要 在词表中无搭配类别（V 位孤立），教师代码规则判宽松可造 → 5 次固化建边 → 直连可达 → 自判转正。**练习 = 教学通道**（符合用户"用练习题来学复杂句式"的意图）。
3. **价值判断与句子合法性分离**：「我想要石头」判可造（语义成立）——石头是坏东西，但"能说"不等于"该要"；价值层由后续价值教学覆盖，本实验只解决"句子对不对"。
4. **修饰词诚实标注**：「在/想」结构上无信号，path 显式标"修饰未判"，不自欺地假装理解；语法解释由 LLM 讲评补位（"在 = 正在进行的动作"）。
5. **探测→教学闭环**：先探测（网络不理解：前缀续推失败）→ 再练习驱动（固化转移定式）→ 复测收敛。探测数据与练习数据都留档，对比可追溯。

## 五、诚实边界

- 教师宽松动词集（{看, 想要, 需要, 买}）是**人工编码的语义常识**，不是学来的——代码规则的边界仍在（新动词要人工归类）；
- 修饰词（在/想）的语法作用未进入网络结构，只有核心三元的判断是网络的；
- 判定"能说"≠"该说"（价值判断未入题）；
- B 型句子的合法性判定 = 核心三元合法性（修饰词被剥离判断）。
