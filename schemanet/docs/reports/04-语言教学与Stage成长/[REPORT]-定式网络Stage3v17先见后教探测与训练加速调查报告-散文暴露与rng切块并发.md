## 三、训练加速调查链（本报告核心）

### 3.1 需求

全量散文先见逐句 ≈ 60 分钟。用户："怎么会花这么多时间？并发呢？能不能切割分块训练？"

### 3.2 尝试一：纯统计批量（跳过动力学）→ 不等价

理论：学习规则纯加性、句间独立 → 统计相邻 bigram 共现 + 词频 → 秒级一次更新。对拍（smoke 949 句、2 个 v16.0 副本逐边对比）：

- 仅补 STDP bigram：突触总数 18,467,460，一致 15,028,113，差异含 0.1 / 0.5 两类
- 补 Hebbian 词内互连后再对拍：一致 15,052,880，**仍不等价**（差异 0.1 / 0.5 两类，逐句有、批量无）

### 3.3 深查根因：回响噪声发放

构造句诊断（\_verify_diag.py）：**喂 3 个无重复词，差异竟达 3600 条，且差异边指向大量未注入词**。逐步追踪（\_trace_reverb.py）锁定：

```
_learn_sentence 每句结尾回响 4 步：v 不清零、只清 spikes
→ v = v×0.9 + 噪声 连续累积（噪声 0.5 稳态 ≈ 2.5 > θ=1.0）
→ 所有神经元越阈 → WTA 每步发 20 个随机词（wta_k 上限）
→ Hebbian(0.1) + STDP(0.5) 学出随机边
→ 每句回响产生 ~3600 条随机边（实测 456+780+1178+1179）
```

数量级闭环：**949 句 × 3600 ≈ 340 万 = 对拍差异（18,467,460 - 15,052,880 = 3,414,580）的精确数量级**。

**结论：学习路径含 rng 驱动的噪声发放，逐句路径本身不确定 → 纯统计批量在数学上不可行**（不是实现 bug，是机制）。

### 3.4 出路：rng 状态传递的进程切块 → 等价已证

原理：噪声发放只依赖 rng 序列。主进程预生成**每块边界的 rng state**（只跑 `random()` 不学习，全量约 30 秒），各进程从对应 state 恢复 rng 喂自己的句子块 → 块内噪声序列与串行**逐位一致** → 增量边合并 = 串行结果。

**等价性对拍（\_verify_chunk.py，100 句 2 块）**：

```
突触总数 15,332,295，一致 15,332,295，差异 0  ✅ 切块 ≡ 串行 逐边等价
```

收益：全量逐句 60 分钟 → `--chunks 4` 约 15 分钟（每块独立进程喂 ~2500 句），满足对拍铁律。

### 3.5 附带发现：噪声发放是 v16 训练的内置特性

v16 训练一直用 `_learn_sentence`（含回响噪声发放）→ v16 快照里的随机弱突触（0.1/0.5）正是它留下的。**v17 切块训练与 v16 同构，验收基线可比**；smoke 探测结论（0.947/0.895/校准 1 处）在两种路径下都稳定复现，与随机弱突触无关。

### 3.6 全量实测一：OOM 崩溃 → 数组级快照修复

全量第一次跑（4 块）**崩溃**：全部 python 进程退出、无留档。根因是 `_learn_block` 用 dict 版全量快照（`{(i,k,j): w}`）：

```
每 worker：before dict（1846 万边 ≈ 2GB）+ after dict（~2.3GB）+ set（~1.5GB）≈ 6GB
× 4 worker + 主进程合并 ≈ 30GB+ > 机器 32GB → 进程被杀
```

dict 版快照把 EdgeRow 数组（12B/边，见内存优化探针报告）**转回 dict（110B/边）**，8.5 倍放大，白费方案 A 优化。**修复：全链路数组级**——`_snap` 返回 (src_i, slot_k, dst_j, vals) 四数组（零复制 edge_view），`_merge_chunks` 数组级 diff/合并（searchsorted 键对齐 + reduceat 分组求和 + w_max 截断），`_rows_from_arrays` 一次性重建 W_out。修复后：

- 每 worker 内存 416-463MB（vs dict 版 6GB+）
- 峰值 ~2GB（vs 30GB+）
- **数组级对拍复验：smoke 300 句 2 块逐边等价通过**（chunks=4 保留）

### 3.7 全量实测二：越喂越慢（超线性）

全量 4 块学习实测 **1737s**（预估 15 分钟 → 实际 29 分钟）。原因：每句学习成本随网络突触数增长——散文不断喂入，W_out 从 1800 万边长到 4900 万边，后期每句传播碰的行更多、EdgeRow 逐条 np.insert 更贵。**句数 ×2.5（smoke 949→全量 2328/块）耗时 ×2.9（切块 295s→学习 1737s）**——超线性确认。

并发上限结论（回答"为什么不用 128 并发"）：**内存墙**（每进程 ~600MB × 128 ≈ 77GB >> 32GB）+ **核数墙**（4 核物理 CPU，4 进程已 2.00x 满载）+ **合并端墙**（128 份快照汇总驻留主进程）→ 本机最优并行度 = 4。真正提速方向不是加进程，而是降单句成本（EdgeRow 批量更新 / 数组级学习路径）。

## 四、结论

1. **先见后教可行（全量确认）**：散文全量 9310 句喂入后 0.947 ≥ 基线 0.895——不碾压专门边，先见安全，v17 可走此路线。
2. **后教拉回力需加强**：108 条×2 轮在 smoke 能拉回基线（0.895），全量拉不动"虽然→但是"配对直读断点——v17 教学量翻倍（150+ 条）是核心手段。
3. **calibrate 有修复点错位 bug**：REL2 位断点修复"了→但是"无效——需修 v16 的 calibrate 对配对直读断点的修复逻辑（按 PRE top-1 内容词定位）。
4. **纯统计批量不可行**：学习路径含 rng 噪声发放（回响 4 步 v 不清 → 噪声累积越阈 → 每句 ~3600 随机边），对拍逐边不等价。
5. **rng 状态传递切块可行且等价**：预生成每块 rng state → 各块恢复喂入 → 数组级合并；smoke 300 句 2 块对拍 0 差异。全量 60 分钟串行 → 29 分钟 4 块（越喂越慢致超线性）。
6. **数组级快照是并发前提**：dict 快照 30GB+ 必然 OOM；数组级（12B/边）把峰值压到 ~2GB，worker 内存降 13 倍。
7. **验收基线口径不变**：v17 目标修正前 ≥0.95、校准 ≤1 处；全量实测 0.947（差 1 点），靠教学量翻倍 + calibrate 修复冲击目标。

## 七、v17 对话训练实验（最终版，2026-08-10）

用户决策链："那对话呢？试试对话训练" → "老师有做示范吗（llm老师）" → **"网络答非所问，老师没有指出也没有处罚，老师的说话方式太生硬，严格对齐说话教学的脚本（_speak.py）"**。最终版严格对齐 `_speak.py`：

**机制（对齐 _speak.py）**：
- **每轮 LLM 调用 ≤1 次**（一次调用多节标记：【答非所问】【质量原因】【教师反馈】【示范句】——同 _speak 六节压缩模式；实测 83 轮 ~20 次调用；无 key/失败回退规则教师）
- **判定分层**：① 结构判定 = 角色合法集（v17 扩展集，客观项走规则不调 LLM）；② 内容判定（结构全对时）= **LLM 语义贴切度**（"搭不搭"——prompt 明确"不要因为与期望句不同就判错"，内容多样性合法；规则回退 = GEN_W 万能词判据 想/要/需要）；**ok/奖励/streak 判定源唯一**（初始判定一次定论，教学后不复判——修复了奖励门控与 ok 不一致的 bug）
- **奖励（对齐 _speak 高分句学回网络）**：答对 → **学期望句 ×1**（学网络实际回应会强化"所以→我"类次优读法——宽松判定下网络回应≠期望句；奖励 = 强化标准答案）
- **处罚（对齐 _speak 30 分 off-topic）**：答非所问/结构错 → 教师指出（妈妈式"老师问的是…"）+ 不奖励 + 示范重铸跟读 ×3 + 词对固化 ×1（校准 ×3 是单次 EVAL 量级，90 轮长循环 ×3 会把"去→医院"类边推超平衡边——实测 32→160 反超"去→公园"80）——不删边
- **连续 15 次通过（对齐 _speak need_streak）**：连续答对 15 次才算掌握，中途错一次清零重数；对话池 30 轮轮转教学，上限 90 轮
- **EVAL 回归 + 校准兜底**：教学不能破坏验收——长循环教学副作用（平衡边推超）→ EVAL <0.95 时教师批改（calibrate）拉回，处数如实记录（规则版实测 1 处：去→公园 被 去→医院 反超）
- **教师说话方式**：妈妈式自然反馈
- **教学后快照**（对齐 _speak net_after + 铁律 2）：奖励/示范/固化改的边必须落快照（首版漏存、进程结束即丢，用户指出后补）→ v18.x（parent=17.0）

对话集 30 轮 = 因果/转折/顺序 × 10（A 已见 15 + B 未见 15，固定 seed）。

| 版本 | 教学 | 结果 |
|---|---|---|
| 规则版（v18.6） | 90 轮（上限）| streak 峰值 5 未达；训练后 0.867；EVAL 0.947 → 校准兜底 1 处 → 1.000 |
| **LLM 版（v18.7）** | **83 轮** | **streak 峰值 15 通过 ✅**；奖励 58；答非所问指出 21；结构错 4；EVAL 回归 1.000（零破坏） |

**关键发现（诚实标注）**：
- **streak 通过 ≠ 规则口径复测通过**：LLM 版教学 83 轮达到"连续 15 次通过"（LLM 语义判定），但 GEN_W 规则口径复测仅 0.533——两个判定口径的差异如实报告（LLM 判"搭"的轮（如"所以我想"）在 GEN_W 口径下判答非所问）；这正是"内容多样性 vs 万能词敷衍"的判据张力，需用户裁决或后续读取机制升级（采样归一化）
- **边权现实**："我→想" = 256.0（散文霸主边，"我想"合法不该压掉），期望边多为 0——示范+固化 ≈+8/次（实测 _learn_sentence 每词对增量 +8），压不过 10 倍差距 → 万能词敷衍轮次多数"指出+示范"后仍不收敛
- **教学副作用可量化**：长循环教学会把平衡边推超（"去→医院"32→160 反超"去→公园"80）→ EVAL 校准兜底 1 处，副作用成本如实记录
