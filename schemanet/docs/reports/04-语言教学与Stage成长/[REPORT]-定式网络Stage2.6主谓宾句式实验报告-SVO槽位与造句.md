# 定式网络 Stage 2.6 主谓宾句式实验报告（S/V/O 槽位 + 类别约束 + 造句）

> 日期：2026-08-10 | 状态：[OK] | 版本：v2.5 成长路线 Stage 2.6 落地（快照 v9.0 → **v10.0 动宾迭代**）

## 一、背景与需求

成长路线"先学字、再学词、再学句"在 Stage 2.5（词义类别，v8.5）之后进入**造句**。用户诊断——从"背句"（Stage 2 复述）到"造句"：按 SVO 定式组合**没学过**的句子。Stage 2.5 的替换造句（"我要"→食物类）只有类别约束的**雏形**：主语后接时间/地点也强（他类信号 38.4 > 食物 28.8），严格"宾语位占优"缺**槽位化**——这正是 Stage 2.6 要补的。

**方案（v2.5 §2.6）**：
- 词序编码 = **角色槽位 hub 绑定**（SVO 固定语序下词↔槽位共发放绑定 ≡ 位置编码，弃 STDP 方向连接）
- V 位动作类用 **jieba.posseg 词性标注**补 2.5 缺口（探测 `_probe_svo.py`：动词覆盖 19.3%，数据留档 `stage26_pos.json`）
- S 位人称类补缺（jieba 把 我/他/她 标 r 代词不进名词类）
- 造句引擎 = **显式定式走链读出**（每步边都是网络真实学到的，§4.8 路径可查，非动力学自走——大网络虚词劫持 2.5 已证）

**验收硬指标**（§四 Stage 2.6）：
1. 槽位归属（词→本槽位直连）≥ 0.9
2. 类别约束（动作/人称 成员→标签直连）≥ 0.9
3. 定式（S槽→V槽→O槽 + 槽位↔类别约束边存在）+ 造句填充（测试组合宾语位名词类 top-8 占比 ≥ 0.5）
4. 字/词/句 + 2.5 四类归属 + hold-out 全链零遗忘

## 四、冒烟→全量实测暴露与修正（2026-08-10）

1. **定式全连接稀释 O 位约束**（冒烟实测 top8 名词占比 0.38 < 0.5 的根因）：原 `svo_train` 6 模式全连接共发放（[S槽 S词 V槽 V词 O槽 O词]），使 O槽 与 V/S 词等强相连，造句聚合被 V/S 词污染 → **分离注入**：定式只训三槽共发放（`svo_skeleton`），词↔槽位绑定用判断句两两强训。分离后 O槽 传出突触只指向 O 词（绑定）+ 槽位（定式）+ O 类标签（约束判断），造句聚合干净。
2. **路径判据残留 v→O槽 直连**（✗ 全 false）：分离注入后 V 词只绑 V槽，`v→O槽` 边必然不存在 → 判据改为槽位链：s→S槽、v→V槽、S槽→V槽→O槽、槽位↔类别约束。
3. **标签传出突触 1:1 聚合被 HowNet 噪声劫持**（名词占 0.12，top8 = [点/地/超市/与/特朗普/金正恩/会面/定下]）：食物/地点标签在 v8.5 网络的既有传出突触（HowNet 义原训练建立）指向大量噪声词 → 聚合改为 **O槽 传出突触为主源**（分离注入后干净）+ **标签传出突触 ×0.3 折扣**（保留 2.5 类成员泛化能力，防噪声反客为主）。
4. **jieba 词性噪声人工词表兜底**：学/画/种/喝/穿 标错（n/vg/zg），动作类以人工词表为准（30 单字种子全命中 v8.5）。

## 五、v10 迭代：动宾搭配约束（病句拒绝，用户 2026-08-10）

**需求**：v9.0 造句虽主谓宾结构正确，但"我吃学校""她喝公园"这类**搭配病句**照常输出——O 位约束只看"名词类"（食物/地点都装得进 O 位），不看"动词和宾语搭不搭"。

**修复**（3 处）：
1. **例句共现训练**（动宾搭配边）：`VO_PAIRS` 语料例句（"我吃苹果""她喝牛奶""鸟看公园"等，7 动词 23 宾语对）整句共发放 ×R 轮 → V 词→宾语词**直接词间边**（本阶段唯一"具体词↔具体词"边，其余词间关系经 hub 间接）。
2. **cat_members bug**：原 `set(o_words) | 类别成员` 把全部 O 集词塞进每个类别（牛奶∈"地点"、公园∈"食物"）→ allow 判定失效，异类组合全被误判合理 → 按语义归属（O_FOOD→食物、O_PLACE→地点）。
3. **泛化改二跳走链**：`V 词传出突触找类别标签`（v9.0 思路 V 没直连标签，cat_w=0 失效）→ 改为**从搭配词反推类别**（喝→牛奶→食物→香蕉，"喝香蕉"没训过但成立——二跳真实走链）。保底（O槽 传出突触 ×0.3）仅当 V 无搭配词时生效，防异类词借保底混入。

**结果**：病句拒绝 87/87、合理搭配 170/170、泛名词 143/143 全 1.0000。**"我喝学校"造不出来了**（异类 O 不进 top-8）。已知噪声：食物标签传出突触混入"超市"（2.5 HowNet 给超市连过食物义原），占比 ≤1/6 不占优，验收判据不受影响。

**诚实边界**：例句共现 = 语料驱动（非人工类别表标注"能配什么"）；动词只学 7 个有搭配的 + 4 个无搭配的诚实留白；搭配仍缺"为什么能配"（义原语义限制仍是 2.5 空缺）。

## 七、结论

1. **造句成立**：S+V → O 位名词类填充，400 个从未整句训练的测试组合 100% 命中——"背句"（Stage 2 复述）到"造句"（按定式组合新句）的质变完成（v9.0）
2. **位置编码落地**：角色槽位 hub 绑定 ≡ SVO 词序（固定语序下共发放绑定即表达位置，弃 STDP 方向连接）
3. **分离注入是句法干净的根**：定式（槽位间）+ 绑定（词↔槽位）+ 约束（槽位↔类别）三层分离训练，各自传出突触纯净，聚合才不被污染
4. **病句拒绝（v10）**：动宾搭配约束后"我喝学校"造不出来——例句共现建立 V↔O 直接词间边，搭配词反推类别二跳泛化（语料驱动，非人工标注"能配什么"）
5. **2.5 槽位填充雏形 → 严格宾语位占优**：他类信号不再压过本类（O槽 传出突触直读 + 搭配约束，非类别信号竞争）
6. **零遗忘保持**：字/词/句 + 2.5 四类 + hold-out 逐值不回退，增量分配 + 续训闭环第五次验证
7. **数据边界诚实记录**：jieba 词性噪声人工兜底、动词语义义原仍缺、只学 SVO 固定序、搭配无"为什么"
