## 三、新教学方案概要（教育阶段路径）

按人类语文教育路径重新灌（[PLAN] 全文见 docs/）：

| 阶段 | 语文重点 | 网络机制 |
|---|---|---|
| 早教（0-3） | 语音/日常名词/听指令 | 复读 + 听指令（接受性——训狗式零食 release_da） |
| 学前（3-6） | 识字/完整句（S-V-O）/儿歌 | 定式轨道（语义结构——不是统计共现） |
| 幼小衔接（5-6） | 看图说话/简单叙事 | 描述定式 + 叙事链（先/然后/最后） |
| 小学（6-12） | 字词句段篇系统语文 | 语义网/段落定式/篇章结构/古诗词 |
| 初中（12-15） | 文言文/现代文/议论文/语法 | 虚词定式/句子成分/论点论据 |
| 高中（15-18） | 文言深度/诗歌鉴赏/论证 | 多义定式（语境）/意象定式/递进论证 |

**灌法原则**：语义教学（定义/关系/行为——不灌共现统计）→ 定式化（轨道）→ 听指令先行（接受性）→ 每阶段验证（剥离代码层可读）→ SHY 睡眠巩固。
