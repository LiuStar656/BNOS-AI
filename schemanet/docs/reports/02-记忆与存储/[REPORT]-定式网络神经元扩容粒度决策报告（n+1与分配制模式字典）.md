# [REPORT] 定式网络神经元扩容粒度决策报告（n+1 与分配制模式字典）

> 日期：2026-08-09 | 版本：v1.0 | 状态：[OK]（用户已批准）
> 关联：[PLAN]-定式网络成长路线设计方案（GPT-1式分阶段放大）.md（v2.1 §六）| [REPORT]-定式网络技术路径切换报告（v1.1→v2.0）.md（§4.2 扩容评估）
> 触发：用户决策 2026-08-09——"比如说这个模型在 n=8032 的时候训练出来了，下一次训练的时候能不能 n+1？"

## 一、结论

**能。任意粒度都可以。** `SparseSchemaNet.expand(n_new)` 是纯追加扩容（旧 W 连接结构一行不动、新神经元空白），`n_new = n + 1` 只是其中的一个合法输入，可连续 `expand(n+1)` 到任意规模。"知识的增量 = 神经元的增量"——新增一个概念（如第 27 个字母）就 +1 个神经元，机制上完全支持。

## 二、陷阱分析（为什么原设计会否定 n+1）

原 `_word_pattern(n, k, word)` 用 `crc32(word)` 做种子、在 `[0, n)` 哈希选 k 个神经元。**哈希结果依赖 n**：

- n=8032 训练好 1000 个词（每个词的模式 = 具体神经元索引）
- `expand(n+1)` 后 n 变为 8033，若按新 n 重算模式 → 1000 个旧词的模式位置全部变化
- 旧 W 里存的连接是"旧位置"上的 → 全部失配 → **零遗忘立刻破产**

所以"能否 n+1"不是 `expand` 的问题（expand 本身没问题），而是**模式落位机制**的问题。必须让词的神经元落位与 n 解耦。

## 三、三个候选方案对比

| 方案 | 落位机制 | n+1 支持 | 新词冲突 | 取舍 |
|---|---|---|---|---|
| A. 哈希 + 模式冻结 | crc32 按**首次生成时**的 n 算好，永久存入模式字典，之后 n 怎么变都不重算 | ✅ | 可能碰撞（新词之间哈希重叠） | 保留确定性，但新词仍有碰撞风险 |
| B. 分配制模式字典 | 词按需从**空白神经元顺序取 k 个**，模式字典永久累积，不依赖任何 n | ✅ | **零冲突**（分配唯一） | 牺牲跨语料确定性，换取任意粒度 + 零冲突 |
| C. 保持现状（阶段成批） | 512→1024→2048 跳变扩容，哈希依赖 n | ❌ | 哈希碰撞随词数上升 | 最简单，但用户问题直接否定 |

## 四、决策：分配制模式字典（B）

用户确认采用方案 B，作为 Phase B 的实现基础。设计要点：

1. **模式字典是唯一事实源**：`pats: {word: [k 个神经元索引]}`，词→神经元落位**生成一次、永久冻结、随网络一起持久化**（npz 附加保存）。任何扩容都不重算旧词。
2. **新词落位 = 分配制**：从当前**空白神经元**按游标顺序取 k 个（分配唯一 → 新词之间零冲突），写入模式字典 +1 条。
3. **n 只是"可用空间上界"**：旧词条目不动，新词在 `[0, n)` 的空白区分配；`n+1` 只是把可用空间扩大 1，完全安全。
4. **与哈希对比的取舍**：牺牲"确定性跨语料复用"（同一词两次训练落位可能不同），换来**任意粒度扩容 + 新词零冲突**，更贴近"新概念要新神经元"的认知模型（对应用户对 26 字母→第 27 个字母的心智模型）。

## 五、扩容触发条件（何时扩，三种都走同一 expand）

| 触发 | 场景 | 粒度 |
|---|---|---|
| 按需 +1 | 新增单个词/概念，分配游标到达 n 边界（第 27 个字母） | n+1 |
| 区分度不足 | 词模式冲突率/排列一致性跌破阈值 | 成批（空间换区分度） |
| 阶段升级 | 词→词组→句→文（§四 n 表） | 一次扩一档 |

**实践判断**：n+1 能做，但不必每次训练都无脑 +1。神经元是表示资源，只有新数据需要新表示时才加；一批新词同时进来时一次扩几十上百个效果等价。节奏由触发条件决定，机制上任意粒度兼容。

## 七、影响范围（Phase B 实现变更）

- `SparseSchemaNet.expand(n_new)`：保持纯追加语义（已定稿）
- **新增 `pats` 模式字典**：词→神经元落位，随网络 npz 一起持久化（替代 `_word_pattern` 哈希的运行时重算）
- **新增分配游标**：从空白神经元顺序分配；分配前检查游标与 n 的边界 → 越界即触发 `expand`
- **兼容**：旧 26 字母实验/复述路径仍可跑（哈希模式可保留为历史代码，v2.1 训练路径走分配制）
- **验收**：扩容前后旧评估集 top-1/复述率逐值一致（零遗忘硬指标）；新增词复述可学（增益为正）
