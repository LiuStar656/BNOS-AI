# 定式网络 Stage 2 句级实验报告（短句跟读，句内结构）

> 日期：2026-08-10 | 状态：[OK] | 版本：v2.3 成长路线 Stage 2 落地（快照 v7.0）

## 一、背景与需求

成长路线"先学字、再学词、再学句"的第三段（§四 Stage 2 短句级）：网络在词级（v6.0）基础上增量长大，学**句内结构**——整句作为记忆单元固化，并具备"局部触发整块唤起"（输入句首唤起句尾，像"人之初→性本善"的句子级）。

**验收硬指标**（§四 Stage 2）：
1. 句复述率（输入整句 → 唤起整句各词）≥ 0.95
2. 前缀唤起（输入前 2 词 → 唤起后续词）> 0（句内结构 = 局部触发整块唤起）
3. 字/词零遗忘：Stage 0-1 复述率不回退（≥ baseline − 0.01）

## 二、实验设计

**起点**：加载 v6.0（词级续训链最新，n=58096，模式 14000：字 3500 + 词 10000 + 500 续训词）。

**流程**（[_grow_stage2.py](file:///e:/杂项/BNOS_AI_project/schemanet/_grow_stage2.py)）：

```
load_version("6.0")                     # 续训起点（字词记忆全含）
  → baseline 评估（字复述/词复述 = 零遗忘基准）
  → 句中新词增量分配（23035 词 → n 自动扩容 148140，游标续用）
  → 短句跟读 3 轮（整句注入句中各词模式共发放 → 句内词间连接）
  → 验收① 句复述率 ≥0.95
  → 验收② 前缀唤起（前2词 → 后段）
  → 验收③ 字/词零遗忘（不回退）
  → save_snapshot → v7.0
```

**关键参数**：`K=4`（每模式神经元）、`EVAL_N=500`（句验收抽样）、`EVAL_HANZI=200`、`EVAL_WORD=300`、`R=3`（跟读轮数）、`SEED=42`。

**数据**：`data/curriculum/stage2_sents.json`（30000 句 ≤8 词、无 UNK 短句）；抽样验收 500 句，训练 29500 句。

**增量分配**：句中未覆盖词 23035 个（覆盖率 31.3% → 全覆盖），一次性扩容避免逐词 O(n²)，游标续用自动扩容（n 58096 → 148140）。

**跟读方式**：`train_sent`（原地清零状态省分配 + 注入句中各词模式，`wta_k=句内目标数` 防级联）——不传播、清 trace，与 Stage 0-1 语义一致。

## 三、结果

### 3.1 句复述率 ✅

| 指标 | 结果 | 判定 |
|------|------|------|
| 句复述率（抽样 500） | **0.9845** | ✅ ≥ 0.95 |

整句记忆成立——输入整句能唤起整句各词，句模式作为记忆单元在网络内固化（非外挂涟漪）。

### 3.2 前缀唤起 ✅

| 指标 | 结果 | 判定 |
|------|------|------|
| 前2词 → 后段唤起率 | 0.2277（309/499 句能唤起后段） | ✅ 局部触发整块唤起 |

**诚实分析**：62% 的句子能被前缀唤起后段（机制成立——局部触发整块唤起）；但平均唤起率 0.2277 不高，即唤起了部分而非全部后续词。原因待查：后续词被共享字/高频词的竞争连接顶出 WTA？或句内连接强度低于词↔字连接（词训练 8 轮 vs 句训练 3 轮）？——机制已通，强度问题是下一实验的改进点。

### 3.3 字/词零遗忘 ✅

| 指标 | 训练前（baseline） | 训练后 | 判定 |
|------|-------------------|--------|------|
| 字复述 | 1.0000 | 1.0000 | ✅ 不回退 |
| 词复述 | 1.0000 | 1.0000 | ✅ 不回退 |

增量分配 23035 新词 + 3 轮句跟读后，Stage 0-1 字/词复述逐值保持 1.0000——零遗忘硬指标通过。

## 四、性能观察（为后续优化留档）

- 总耗时 1217s（约 20 分钟）：29500 句 × 3 轮 ≈ 16 分钟训练 + 验收。
- 热点：每句跟读走**完整动力学 step**（O(n) 噪声生成/膜电位/argmax/WTA，n=148140）+ Hebbian 两两（32×32 dict）。
- 已提出优化（未实施）：**cofire 快路径**（跟读只需"注入共发放即学"，跳过全部动力学，预计 5-8 倍提速）+ 训练关噪声 + 定向清零。需先在小样本上对照旧路径 W 逐值一致再切换。

## 五、结论

1. **句级能力落地**：句复述 0.9845（≥0.95），整句记忆在网络内成立（v7.0）
2. **局部触发整块唤起**：前缀唤起机制成立（62% 句子），强度待加强
3. **零遗忘保持**：字/词 1.0000 不回退，增量分配 + 续训闭环在句级规模再次验证
4. **性能优化空间明确**：cofire 快路径待实施
