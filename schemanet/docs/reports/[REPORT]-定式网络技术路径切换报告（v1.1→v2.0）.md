## 一、概述

本轮技术路径切换是**成长哲学的彻底重构**：从"词接词概率引擎优化"路线，切换到"**数据专门化 + 分级课程 + 增量成长 + 神经元逐步扩容 + 双系统读出**"路线。核心一句话：**训练什么就用什么数据，像 26 字母时代那样**——26 字母训练就是 26 个字母，训练词组就用词组，训练句子就用句子，禁止用混合语料跳级。

切换由用户主导的认知理论驱动（§三），由八项实验构成的证据链支撑（§二），形成 v2.0 方案的四个铁律（§四）。

## 二、v1.1 路线回顾与证据链（为什么必须切）

### 2.1 v1.1 路线是什么

主方案 v1.3 之前的技术路线：用混合 TF 语料（corpus_open20w.json，20 万句混合头条+评论）训练词接词 W（Hebbian 转移定式），在多个读出引擎（wsum/trace/grad/pahe/candB/C）间寻找最强 top-1 引擎并围绕它做优化（train_ctx 权重、w_max 饱和修复、归一化、trace 优化）。方向是"让词接词概率更准"。

### 2.2 证据链①-⑧（v1.1 → v2.0 的推翻过程）

| # | 实验 | 结果 | 结论 |
|---|---|---|---|
| ① | 26 字母训练（schema_net.py run_alphabet_experiment） | 26/26 零遗忘、输入 a 回响 a | **复述/模式固化能力成立**（最早模式）；输入 a 出 a 是自联想/回声（Hopfield 1982），非"预测下一个字母" |
| ② | 2 万 vs 20 万真实语料（词接词 W） | 全线下降（wsum 0.1349→0.1220） | w_max 饱和实锤；**数据放大无益**——混合语料词接词方向本身就是错的 |
| ③ | 六引擎对照（wsum/trace/grad/candB/C） | wsum 0.1220 最强，grad 不敌（z=-2.91） | 引擎之争无意义（都是词级概率） |
| ④ | 同末词命中率 | 无引擎超越 wsum | **区分 ≠ 理解** |
| ⑤ | 生成质量对比（结果导出 runs/20260809_220059/result.txt） | 全部引擎产出"标点+虚词"堆砌 | **模型不会说话**（词接词≠语言）；"光看指标不行，指标可能是无效指标" |
| ⑥ | 句记忆检索（稀碎版，_sent_mem.py） | 长位置崩溃（t9+ 0.0098） | 逐位置签名=稀碎=失败（证实用户判断） |
| ⑦ | 整句涟漪（整句单元，_sent_ripple.py） | 复述率 **1.000**（300/300）；主题唤起强（足球唤足球#7644/电商唤电商）；泛化续写崩（0.0244） | **整句记忆成立 + 语义联想雏形**；缺位置精度 → 双系统必然 |
| ⑧ | 技术谱系对照 | 复述=Hopfield(1982)；双系统=CLS(1995)；机制=HTM/ART/SNN | 效果未超"记忆检索"层，需回到认知发生学找路径 |

### 2.3 v1.1 的三个根本问题（v2.0 要解决的）

1. **数据不专门**：用 20 万篇混合文章训练"词接词"，等于直接给小孩发混合文章让他悟。26 字母时代"训练什么就是什么"的原则被丢弃
2. **每次从头开始**：26 字母、2 万、20 万、w_max 重训、句记忆——每次新网络/新结构，**从未增量成长**（Hebbian 本是累积的，被浪费）——"每次的训练都是在从头开始，这是最大的问题"
3. **机制错层**：20 万词接词把"句子"抹平了——句子级（CLS 海马对应物）从未进入网络结构；整句涟漪证明"句子可以成为记忆单元"，但它是外挂，不是网络长出来的

## 三、认知理论重构（用户决策 2026-08-09）

切换的哲学基础，全部来自用户对幼儿/小学生学习过程的观察：

- **四阶段条件反射**：复读 → 下一句 → 词意 → 意思↔意思
- **语文课路径**：老师读一句学生读一句 → 学生自己读 → 理解句意 → 联想 → 举一反三
- **三字经机制**：读文章不知道意思，只是机械读；"读的越多印象越足"；听到"人之初"就知道"性本善"——是**局部触发、整块唤起**（非逐词概率）
- **整句涟漪**：应该是整个句子进入网络产生的涟漪，而不是把句子拆稀碎让网络找下一个词
- **增量成长铁律**：学习是累积的（词不丢、句不丢），任何实验不得从头开始

这些观察直接否定了 v1.1 的"混合语料词接词概率"路线，指向：**数据专门化 + 分级课程（按人认知能力顺序）+ 增量成长 + 整句记忆单元**。

## 四、切换后的技术路径（v2.0 四项铁律）

**铁律 1：数据专门化**——训练什么就用什么数据。词用词数据、句用句数据、文用文数据，禁止混合语料跳级。

**铁律 2：增量成长**——同一网络持续喂，永不从头开始。每阶段 = 沉淀（学习）→ 冻结（learn_gate=False）→ 验收（零遗忘）→ 再训练。

**铁律 3：神经元逐步扩容**——n 随阶段增大，与数据规模/复杂度匹配；扩容保留旧 W，旧知识零丢失。

**铁律 4：教学协议**——严格按人语言/认知/逻辑/推理能力顺序递进（Stage 0-5），前级验收通过才进下级。

### 4.1 分级成长路线（严格对照人学习能力）

| 年龄段 | 人的能力 | 定式网络 Stage | 数据 | 验收指标 | n |
|---|---|---|---|---|---|
| 0-1 岁 | 语音复述 | 已完成（26 字母） | — | — | — |
| 1-2 岁 | 单词命名 | Stage 0 词级 | 专门词表（1000-3000 词） | 词复述率 ≥0.95、零遗忘 | 256-512 |
| 2-3 岁 | 双词组合 | Stage 1 词组级 | 专门词对（5000-2 万对） | 词组续词 top-1、原子保留 | 512→1024 |
| 3-4 岁 | 短句 | Stage 2 短句级 | ≤8 词无 UNK 句（2-5 万句） | 句复述率 ≥0.95、涟漪匹配 | 1024→2048-4096 |
| 4-6 岁 | 复杂句（因果/转折） | Stage 3 复杂句级 | 关系句（1-3 万句） | 关系词补全（因为→所以） | 4096→8192 |
| 6-12 岁 | 文章、句间逻辑 | Stage 4 文章级 | 相邻句对（2-5 万对） | 句 B 唤起率 | 8192→16384 |
| 12+ 岁 | 抽象推理 | Stage 5 推理级 | 构造推理语料 | 逻辑链补全、举一反三 | 16384→… |

**关键设计——跟读重复率**：每阶段数据 = "反复读的三字经"，同一批句子多次出现（重复率 ≥10 次），满足"印象越来越足"。这是与 v1.1"每句一次"的本质区别。

### 4.2 神经元逐步扩容评估结论（用户问题：能不能逐渐增加神经元数量）

**结论：可以，且必须。**

- **技术可行**：`SparseSchemaNet.expand(n_new)` 纯追加扩容——W_out 前 n_old 行原样保留（旧连接结构不动），新神经元空白供新阶段学习；所有状态数组 pad 对齐。旧知识 100% 保留；**粒度任意（含 n+1，见扩容粒度决策报告）**
- **为什么必须**：26 字母实验实测 n=256 时排列一致性跌到 0.10（模式空间不足，词分不开）；语言复杂度随阶段递增（词 3000 → 词组 2 万 → 句 5 万），固定 n=8192 会重演"区分度塌缩"（20 万语料 w_max 饱和后分数齐平）。n 随阶段增大是容量与模式区分度的必然需求，与大脑随年龄增大同理
- **关键风险——模式落位解耦**：旧 `_word_pattern(n,k,word)` 的 crc32 哈希依赖 n，扩容后 n 变则旧词模式变、旧 W 连接失配（灾难）。对策（v2.1 修订）：**分配制模式字典**——`pats: {word: [k 个神经元索引]}` 生成一次、永久冻结、随网络持久化；新词从空白神经元按游标顺序分配（零冲突）；n 只是可用空间上界，n+1 完全安全；验收硬指标 = 扩容前后旧评估集 top-1/复述率**逐值一致**
- **扩容触发条件**：模式冲突率超阈值，或阶段升级自带扩容计划（§4.1 n 表）

### 4.3 双系统读出架构（CLS 计算化）

| | 位置层（皮层对应物） | 语义层（海马对应物） |
|---|---|---|
| 记忆 | W 转移定式（慢统计） | 整句涟漪（快情景） |
| 精度 | 词级位置（续写） | 句级主题（联想） |
| 实测 | wsum 泛化 0.11 | 复述 1.0、主题唤起强、泛化 0.024 |
| 局限 | 只会词接词（跑偏） | 无位置精度（对不上） |

协同（Phase E 实现）：涟漪唤起主题句集（语义过滤）→ wsum 在候选池约束下位置续写（词级精度）→ 融合输出（涟漪给语义方向，wsum 给位置落点）。

## 五、切换影响范围

**废弃/归档（v1.1）**：
- grad 主引擎定案（20 万干净 W 实测不敌 wsum，z=-2.91；train_w 被实锤为系统性破坏者——4d 报告改 2058 万条/35% 连接）
- trace/pahe/candB/C 引擎优化路线（引擎之争已判定无意义）
- 20 万混合语料直训路径（词接词方向本身被否定）

**新增（v2.0）**：
- `_data_curriculum.py`（分级纯净数据抽取）+ `data/curriculum/`（分级语料留档）
- `SparseSchemaNet.expand(n_new)`（神经元扩容）+ `_word_pattern_new`（模式分区冻结）
- `_grow_stage.py`（阶段训练 + 验收脚本）
- 每阶段成长协议四件套：前级零遗忘验收 / 本阶段验收 / 生成质量对比 / 留档

**保留（已被验证的能力）**：
- 复述/模式固化（26 字母，证据①）
- 整句涟漪记忆 + 主题唤起（证据⑦，网络内实现而非外挂）
- learn_gate 冻结 / sleep_consolidate 频率门控慢衰减（增量成长的基础设施）
- w_max=64（20 万重训修复后的值，避免饱和）

## 六、后续实施（Phase A-E）

- **Phase A 数据专门化基建**：`_data_curriculum.py` 从 corpus_open20w.json 抽取 Stage 0-5 分级纯净数据 + 控制重复率 ≥10 → `data/curriculum/`
- **Phase B 神经元扩容**：`expand(n_new)` + `_word_pattern_new`（模式分区冻结），扩容前后逐值一致验收
- **Phase C Stage 0-1**：词→词组重建（n 256→1024，专门数据，跟读重复）
- **Phase D Stage 2-3**：短句→复杂句（句级复述，关系词补全）
- **Phase E Stage 4-5 + 双系统协同**：句接句转移 + 涟漪+wsum 协同读出

## 七、验收口径

1. 零遗忘验收（每阶段）：旧评估集 top-1/复述率/唤起率不退化（逐值对拍）
2. 扩容验收：expand 前后旧评估逐值一致 + 新阶段学习有增益
3. 生成质量：每阶段数据上"会说本阶段的话"（前缀一致性 + 人工判断）——不再以 top-1 为唯一指标
4. 数据纯净性：每级数据词表检查、句长过滤、关系标记覆盖验证
