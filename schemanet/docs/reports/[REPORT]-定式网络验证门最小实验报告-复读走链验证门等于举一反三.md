# [OK] 定式网络验证门最小实验报告：复读+走链+验证门=举一反三

> 日期：2026-08-10 | 状态：[OK] | 关联：v2.2 方案 §十二、`_rl_gate.py`
> 需求（用户 2026-08-10）：定式网络要学会"X是Y、Y是Z → X是Z"这个传递**模式**，而不是学会"流动的是液体"这句话（死记硬背实例）。

---

## 一、背景与目标

### 1.1 问题的起源（模式选择）

Stage 0-1 已实现两种能力：
- **复读**（Hopfield 自联想）：输入 a → 回响 a
- **联想**（模式补全）：输入"人之初" → 补全"性本善"

但两者是**解决问题的模式**，一个刺激会同时炸出多个候选，网络**不知道用哪个模式**。讨论收敛到：模式选择信号来自**教学指令**（"和我一起读"→复读），而 RL 不应当是外挂黑盒策略，而是**验证门 = 三因子学习规则**（Hebbian × 验证奖励）。

### 1.2 本次实验要回答的三个问题

1. 复读+验证门能否长出直连（实例层组块化成立？）
2. 错误联想能否被验证门挡住（认知偏差防护？）
3. 换新词组合能否推出新结论（模式层传递模板成立 = 真举一反三？）

## 二、实验设计

### 2.1 语料（带角色槽位）

| 组 | 内容 | 作用 |
|---|---|---|
| 训练组 | {流动是水, 水是液体, 苹果是水果, 水果是食物, 雪是白的, 白是颜色} | 多实例，学传递模板 |
| 陷阱前提 | {水能淹死人} | 先建立真实错误链 |
| 验证门拒绝对象 | {流动的能淹死人} | 共享中间项"水"的陷阱结论 |
| 测试组 | {鸟是动物, 动物是生物} | **训练中从未共现的新组合** |

### 2.2 机制

- **槽位化跟读**：注入 `[S+X] + [是] + [O+Y]`（S=主语位、O=宾语位），角色绑定 + 内容共发放
- **走链**：读出式联想，每跳取当前词出边最强的未访问内容词（`流动→水→液体`）
- **验证门**：老师说"对"→ 首尾 `[X,Y]` 复读一次固化直连；说"错"→ 不固化（走链结果只当临时检索）

## 三、结果（全部 PASS ✅）

```
词表 14：['流动','水','液体','苹果','水果','食物','雪','白','颜色','淹死人','鸟','动物','生物','是']
模式分配（含槽位 S/O）: 16 × k=4，n=256

[1] 训练组 6 句 + 陷阱前提 1 句 × 3 轮 跟读完成
[2] 实例层走链（输入 流动）: 流动 → 水 → 液体 ✅ 联想链成立
[3] 验证门：流动的是液体 → 固化 (0.0 → 1.6)
         流动的能淹死人 → 不固化 (0.0 → 0.0)
[验收①] 错误链前提「水能淹死人」已建立（直连 4.8）✅
         正确链固化 + 错误结论拒绝固化 → ✅
[5] 模式层泛化: 鸟 → 动物 → 生物 ✅（结论句从未跟读）
[验收②] 实例层直连 ✅
[验收③] 模式层模板 ✅
═══ 总验收: PASS ✅ ═══
```

### 三个问题逐条回答

1. **复读+验证门确实能长出直连** ✅：流动→液体 0.0→1.6（实例层组块化成立）
2. **验证门能挡住错误联想固化** ✅：错误链「水→淹死人」真实存在（4.8），但错误结论「流动的能淹死人」不被加固（0.0）——**这是不让负面联想焊死成规律的闸门**，直接对应"长期接受负面信息导致认知偏差"的防护需求
3. **模式层真泛化成立** ✅：鸟/动物/生物从未在训练中共现，仍推出"鸟是生物"——**学的是"X是Y、Y是Z→X是Z"模式，不是"流动的是液体"这句话**

## 四、过程中发现并修复的 Bug

### 4.1 `SparseSchemaNet._edge_row` 空行返回 `(None, None)`

- 现象：传播时报 `Cannot cast ufunc 'add' output from dtype('O')`
- 根因：空行返回 `(None, None)`，调用处 `if e is not None` 判断通过后执行 `drive[None] += None`
- 修复：空行返回 `None`
- 备注：此前 `_grow_zh` 碰巧所有传播神经元都有出边，未触发

### 4.2 `run_train` 未清 `refractory_left`

- 现象：单句训练连接正常，连续两句后跨句共享词连接丢失
- 根因："流动是水"→"水是液体"中"水"连续出现，第一句发放后 `refractory_left=1`，第二句被不应期挡下，水↔液体共发放学不到
- 修复：跟读是独立事件，每次 `run_train` 清 `refractory_left`（与清 `pre_trace` 同理）

## 五、结论与边界

### 成立的部分

- "单靠复读（+联想走链）+ 验证门就能实现举一反三"的用户判断被证实
- RL 在定式网络上的落地形态 = **验证门（三因子学习规则）**，不是外挂策略层
- 传递模板（学模式）与实例记忆（学句子）是两回事，且模板可套用新词组合

### 明确的边界（尚未做）

| 未验证 | 说明 |
|---|---|
| 大网络 | 玩具级 n=256/14 词 → 未接 Stage 0-1（n=54000/13500 词） |
| 数字泛化 | 5+3=8 需数字**数量化共享表征**（§12.5 标注：RL 只做验证门部分） |
| 中间项断开 | 未测"水被弱化后直连是否仍在"（组块化彻底化） |
| 验证信号来源 | 目前是老师显式给"对/错"，未测内部一致性/任务目标自动验证 |
