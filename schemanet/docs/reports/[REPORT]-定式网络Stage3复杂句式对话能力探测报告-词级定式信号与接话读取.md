## 一、背景

用户询问"目前复杂句式对话能力怎么样了"。复刻 v13 probe_complex 口径（整句复述 + 前缀续推）在 v14.0 上重测，并新增**词级 token 注入**与**滤噪**对照——v13 探测（12.0）的基线是：「我想要」→ 的/了/是 霸榜（推不出苹果，转移定式缺位）。

## 二、方法与口径

| 口径 | 做法 | 意义 |
|------|------|------|
| 整句复述 | 输入整句 → 回响比例 | 记住性（1.000 只证明记住词） |
| 前缀续推·字级 | 前缀字符串逐字注入（v13 原口径） | 与 v13 基线可比 |
| 前缀续推·词级 | 前缀 token 列表注入（先+吃饭） | 真实对话输入（词级） |
| 滤噪 | 排除高频虚词枢纽 {的,了,是,有,什么,…} | 判断定式信号是否存在（被压 vs 缺失） |

### 3.3 诊断：定式边已学进去，但"读取"读不出来

1. **信号确实存在（不是学习失败）**：词级注入 + 滤噪后，关系定式词出现在 top 中——所以→吃饭/带伞、先吃饭→写作业（链通到"然后"的传出突触）、虽然→下雨/但是、虽然下雨→但是/上课/坚持、因为→冷/困。与 self_judge 证实的配对直连（因为→所以 边权 24.0）一致：**边在，读不出**。
2. **三因素压制（读取失败根因）**：
   - **虚词枢纽多源汇聚**：的/了/是/有 在 3.7 万模式网络里连接数量爆炸，字级注入下 WTA 必然霸榜（注意力=连接数量理论再次实证）——v12→v14 三版探测字级口径全同；
   - **关系词对称竞争**：下雨→所以（#1）与 下雨→但是（#6）训练次数同为 ×3，边权无区分度 → 因为下雨 推"但是"而非"所以"——关系词后接竞争无偏向；
   - **多步传播稀释**：run_recall 传播多步，第二层词（所以/但是 的传出突触：写作业/上课/坚持）与直接边混入 top，直接边信号被摊薄。
3. **结构性症结**：检索 = "回响全部被点亮词"，不是"输出下一个词"。定式边学进去了，但没有"接话 = 取最后词直接传出突触做定向 WTA"的读取机制——**续推侧机制缺位，非数据/训练量问题**。

**回答能力结论**：
1. **是/否类（判断）回答 = 网络真实能力**：13/15，2 道盲区是设计边界（语义层网络不负责）；
2. **开放补全回答 = 答案在边里**：直接传出突触读取 9/10——因为→下雨、所以→带伞、先→刷牙、然后→写作业、看→家、吃→苹果 全部命中；
3. **唯一失败「想要→?」是训练不平衡**：真实语料高频边（的 38.4）远强于 v13 固化边（想要→苹果 ≤2.5，只固化 1-5 次）——专门数据 3 轮跟读 vs 真实语料 800 句的强度差；
4. **同一知识两种读取，结果天差地别**：前缀续推（涟漪）0%，直接传出突触 90%——**读取机制决定能力**，方案 A（直接边接话）被实证可行。

## 四、下一步建议

| 候选 | 思路 | 状态 |
|------|------|------|
| **A. 直接边接话** | 前缀注入 → 只取最后词的**直接传出突触**做 WTA（不走全局回响） | ✅ **已验证**：直接传出突触读取 top-1 9/10——这就是答案的读取通道，v15 定式对话/回答的读取机制 |
| B. 枢纽抑制 | 续推时按连接数衰减虚词枢纽（注意力=连接数量 → 反其道） | 治标：字级噪声（A 之外已不需要） |
| C. 关系词偏向 | 词对跟读加权（所以 后接 → 消除对称竞争） | 治标：下雨→所以/但是 对称（v15 可顺手加权） |
| D. 训练平衡 | 专门数据跟读轮次 ×N 匹配真实语料边强度（想要→苹果 < 的） | 治本：专门数据边与语料边同量级（v15 关系句 800 句化） |

A 已被本探测实证（9/10），作为 v15 读取机制；C/D 解决直接传出突触问答里暴露的两处弱点（对称竞争 + 训练不平衡）。
