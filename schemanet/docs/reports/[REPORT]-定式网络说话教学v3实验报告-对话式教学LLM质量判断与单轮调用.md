# 定式网络说话教学 v3 实验报告（对话式教学 + LLM 质量判断 + 单轮调用压缩）

> 日期：2026-08-10 | 状态：[OK] | 版本：方案 v2.9 "对话即学习"落地（`_speak.py` v3 对话式教学）

## 一、背景与需求

v2 说话教学（固定起始词 `start="我"` + 每轮示范同一句）暴露根本问题：**网络固化成"我吃苹果（吗）"**。用户反馈"网络一直在说我吃苹果"，要求彻底改造教学方式。

用户决策链（2026-08-10）：
1. "教师发起对话，和网络对话，网络回答，教师批改并给出更丰富的示范，不通顺的要处罚，反复重复的要惩罚"——打破固定起始词，改**对话式教学**；
2. "教师本身说话也要丰富一点，但是别太夸张"——教师话术自然克制；
3. "教师和网络的对话也要记录"——**对话逐轮留档**；
4. "以后任何的实验数据都要有留档"——实验数据留档制度化；
5. "大模型要判断质量，从自然语言的角度，要教网络怎么说话"——**LLM 升级为质量判断者（LLM-as-Judge）**，规则打分只能查槽位，判不了"自不自然"；
6. "把调用压缩到一轮"——参照 AAA 节点"一个 prompt 多个节标记"模式，教学每轮 LLM 调用 **2 次 → 1 次**。

## 二、实验设计（`_speak.py` v3）

**教学循环**：教师轮转话题池提问（开放式问题、不含宾语）→ 网络"听"问题 → 采样回答 → 教师批改 → 奖励/惩罚 → 扩写式示范 → 下一轮。连续 15 次得分 ≥ 60 通过，错一次重新计数；连续 ≥ 10 次后撤示范（提示渐隐），**最后 5 次必须独立说出**。

**核心机制**：

| 机制 | 实现 | 解决的问题 |
|---|---|---|
| 教师发起对话 | 话题池 `TALK_POOL`（我/他/猫 × 吃/喝/买/要/看），每话题 2-3 句不同问法轮换 | 不再给固定起始词，网络必须自己回答 |
| 网络"听" | `_hear_words` 切问题已学词 → 走链回响（`learn_gate` 临时关 = 纯回忆不学习）→ 听到的动词获得说话优先（×HEAR_BOOST） | 应答 Intraverbal 落地：问题里的动词引导回答 |
| 权重归一化 | 采样权重 ÷ max，弱边也能探索 | S→V 学习初期强边垄断（固化"我吃苹果"根因） |
| 反复重复惩罚 | 近 3 轮连说 3 次同样的话 → 该句 V→O、O→尾 边 ×0.5（不动共享 S→V 边） | 逼网络换说法 |
| 答非所问惩罚 | S/V 与话题不符 → 不给奖励 + 计数清零 + 示范正确应答（不删边） | 语境错误不惩罚句子本身 |
| 示范自然化 | 显示与学习分离：示范说自然口语（"我想吃西瓜""我可以吃西瓜吗？"），学习时 `_segment_demo` 切回已学 S/V/O 词、虚词跳过 | 教师示范是"人话"，网络学到的仍是能学的骨架 |
| 增量成长 | `--base latest`：默认续用最新教学产物 `net_after.npz`，找不到才回退 v11.2 | 教学成果进下一轮，永不从头开始（铁律 2） |
| **LLM 质量判断** | `_llm_teacher_once`：一次调用输出【质量分数】【答非所问】【质量原因】【教师反馈】【示范句】五节标记（AAA 节点模式），`_parse_sections` 解析；分数 bucketize 回规则档位 | 从自然语言角度判"自不自然、贴不贴题"，规则打分做不到 |
| 实验留档 | `runs/_speak_logs/{时间戳}_{种子}_{教师}/`：talk_log.json（逐轮对话）+ result.json（汇总+边权重对比）+ net_after.npz | 对话记录 + 实验数据留档制度化 |

**双轨教师**：有 `DEEPSEEK_API_KEY` → LLM 全流程（判断+原因+反馈+示范）；无 key / 调用失败 → 规则评分（`teacher_score`）+ 规则反馈示范（`_rule_feedback`/`_rule_demo`），实验不崩、结果可复现。**低分安全化**：LLM 的模糊低分只清零计数（不给奖励、不删边），删边惩罚只由规则评分（明确结构错/搭配错）触发。

### 3.2 关键观察（留档实测）

1. **打破"我吃苹果"固化** ✅：网络随话题轮转换动词换宾语（吃→苹果/西瓜/鸡蛋、喝→牛奶、看→公园/商店），不再固守一句。
2. **LLM 从自然语言角度判质量** ✅：网络答"我吃西瓜吗"，规则会判 100（"吗"尾问句），**LLM 判 80 并点评"听着像在问自己，可以说'我可以吃西瓜吗'"**——这是规则打分做不到的自然度判断，网络因此学会更自然的问句。
3. **开局即会说话** ✅：增量成长后，第一轮"网络（教学前）：我吃鸡蛋吗"——不再是"（我还不会说……）"（v11.2 冷启动 S→V 边全为 0 的历史问题已消除）。
4. **单轮调用** ✅：每轮 1 次 LLM 调用完成判断+原因+反馈+示范，反馈带读句与示范天然一致。
5. **提示渐隐 + 独立期** ✅：第 11 轮起独立说出（"我要什么"等），最后 5 次全部独立、给独立奖励加成（学 2 次）。

### 3.3 遗留边界

- 网络表达上限 = 主谓宾 + 问句（无定状补、无虚词"想/可以"进词表——只出现在教师示范）；
- 重复判定窗口较宽松（连说 3 次才算"反复"）；
- LLM 判断依赖 API 稳定性（失败自动回退规则，安全）。

## 五、结论

1. **对话式教学成立**：教师发起对话 + 网络听答 + 批改示范，网络在 15-21 轮内学会贴题应答，打破固定起始词教学的固化重复。
2. **LLM 质量判断是规则打分的升级**：规则判"结构合法"，LLM 判"说话自然"——网络从"学会造句"迈向"学会说话"。
3. **增量成长让教学成果真正累积**：每次教学产出即下次起点，符合铁律 2（永不从头开始）。
4. **定式网络能学规则/结构/规律**（用户观点）：槽位骨架、类别 hub、奖励规则都是网络自己长出来的——它的价值不在记忆检索，而在"会成长的心智"；与 LLM（会说话的大脑）是互补而非竞争。

## 六、v13.2 调试记录：超临界雪崩（神经元过度放电）

> 日期：2026-08-10 | 状态：根因已定位，修复进行中（用户已选"全局活动抑制"）
> 复现脚本：`archive/_debug_avalanche.py`（归档，`cd schemanet && python archive/_debug_avalanche.py`）

### 6.1 现象

v13.2 建「石头→痛→不要」通用痛觉链（X→痛 内感受边 + 痛→不要 通用逃避规则）后，价值课判定练习中网络 3 次全答错——坏东西"石头"不能唤起"不要"。`_evoke_prefix(["石头"], steps=3)` 逐回响步诊断：

```
间隔步后   spikes: 石头=0 痛=4 不要=0   v(痛)=0.0 v(不要)=0.11   ← 第一跳正常
回响步1    spikes: 石头=0 痛=0 不要=0   v(痛)=18.4 v(不要)=26.9  ← v 远超高阈值却不发放！
回响步2    spikes: 石头=0 痛=0 不要=0   v(痛)=16.56 v(不要)=27.21
回响步3    spikes: 石头=0 痛=0 不要=0   v(痛)=15.83 v(不要)=43.69
回响步4    spikes: 石头=0 痛=0 不要=0   v(痛)=14.25 v(不要)=44.12
```

v(不要)=26.9 远超 θ=1.0，却不发放——看似矛盾，实为雪崩淹没。

### 6.2 根因：分支参数 σ >> 1（超临界）

逐步打印候选集合（v ≥ θ 且非不应期的神经元数）：

| 步骤 | 候选数 | 候选最高 v | σ（候选环比） |
|---|---|---|---|
| 注入石头后 | 4（spikes） | — | — |
| 间隔步后 | 156 | 11.9 | — |
| 回响步1 | 46,671 | 128.4 | ~299 |
| 回响步2 | 55,218 | 241.2 | 1.18 |
| 回响步3 | 65,271 | 394.2 | 1.18 |
| 回响步4 | 75,162 | 492.1 | 1.15 |
| 回响步5-6 | 75,316 / 75,132 | 627 / 629 | ~1.00（饱和） |

每步候选持续增长、v 指数翻倍 → **分支参数 σ（每发放者平均唤起的后继数）远大于 1 = 超临界**。机制：注入"石头"→ 间隔步石头复燃 + 高频词（我/吃，扇出数千条边）被驱动发放 → 下一轮这些发放者出边聚合驱动海量神经元 → v 只 ×0.9 衰减、无上限累积 → 正反馈雪崩。WTA top20 全被混沌态占据，"不要"的 v 在 128/241/394 面前排不进前 20。

**为什么正常话题应答此前一直能用**：应答靠 `edge_between` 直接读边（不走回响），回响仅用于 v_bias 探测——雪崩集合巨大，目标词自己复燃所以常在集合内。但「石头→痛→不要」是**精确二级链**，需要按时序传播，雪崩将其淹没。

### 6.3 神经科学对应（用户 2026-08-10："这算不算人脑的神经元过度放电？"——算，同源）

| 我们的现象 | 神经科学机制 |
|---|---|
| 候选持续增长、v 指数放大 | 超临界分支（branching ratio σ > 1）＝癫痫样放电的病理特征（Beggs & Plenz 2003；Hsu 2008；Hagemann 2021；PNAS 2025 人脑实测 σ≈1） |
| 正常大脑应保持的状态 | 临界态（σ≈1，实际略低"回响态"）：信息传递/记忆最大化（Shriki 2013 人脑 MEG 实测幂律雪崩） |
| 网络只有兴奋边（Hebbian/STDP 正反馈） | E/I 失衡：皮层靠 GABA 能抑制性中间神经元维持兴奋/抑制平衡；阻断抑制→癫痫，增强抑制→抗惊厥（Perucca 2023；van Hugte 2023；Tipton & Russek 2022） |
| Hebbian 无约束增强 → 必然失控 | 正反馈可塑性"propensity for runaway excitation"，需稳态可塑性负反馈平衡（Pozo & Goda 2010；Turrigiano） |

### 6.4 修复方向（用户已选"全局活动抑制"）

皮层标准机制 **feedback inhibition**（Paz & Huguenard 2015，Nat Neurosci）→ 计算实现 = **divisive normalization（除法归一化）**：内部传播 drive 按全局强度除法压缩，发得越猛压得越狠，把 σ 拉回临界附近。落点 `SparseSchemaNet.step()` / `SchemaNet.step()` 传播段（不动注入脉冲、不动学习规则）。可选第二层：**稳态可塑性（synaptic scaling，慢尺度全局权重缩放）** 防长期复发，对应 homeostatic plasticity（Lee & Kirkwood 2019）。

> 规模无关性结论（同次调试实证）：雪崩与神经元容量无关（当前 n=148,776 / 词 37,062 已足用）；拉到 100 万神经元（词容量 25 万、W_out 内存 556MB→~3.7GB）不解决问题；扩大激活数 wta_k（20→200）只会让更多混沌神经元同步发放、雪崩更猛——该拧的螺丝是抑制，不是容量/宽度。

### 6.5 根本修复（2026-08-10 用户定方向）：定式化「石头≠痛」

> 状态：[OK] 已落地 + 端到端验证 | 留档：`runs/_speak_logs/20260810_084048_我_rule/`
> 用户关键决策："真正解决石头导致痛的方法，是**让石头不再和痛联系起来**（在保证痛这个机制不能消失的情况下）"；"问题在于 **石头=痛**，而不是 **碰到石头=痛**，这两个是天差地别的区别"。

**6.5.1 雪崩重新定性（实证）**：不是"只有痛会雪崩"——注入任何词（苹果/学校/哭/石头）回响候选都到 1-1.8 万（超临界）。根源是语料虚词（了/是/有/什么，各 5-6 万出边）被任何词连带激活后互相驱动。痛的"独特"在出边结构：条数最少（876）但语义最集中（不要 256 全网超强边 + 痛觉近义词簇哭/痛哭/苦/痛苦/心/心痛 + 痛自连 120）——痛激活 = 激活"痛觉语义场"，苹果激活 = 激活"语料表面共现"（苹果→手机/的/吗）。

**6.5.2 为什么痛场景特别致命**：价值课判定依赖「X→痛→不要」回响链穿过爆炸区——痛的 v=18 被混沌 v=114 压住，链断、判定失败（实测 3 次全答错：我喝牛奶/我不要苹果吗/我吃石头）。苹果/学校不依赖穿过爆炸区的链（判定靠 hear 动词"要"直连；说话走 edge_between 直接读边不走传播）→ 不暴露瘫痪。

**6.5.3 机制落点**（`_speak.py`）：
- `_entrench_direct(ng, pats, bad_o)`：价值课②.5（**定式前置，先于判定**——判定依赖定式，放判定成功分支会造成死锁）已定性坏东西 → 学「X→不要」4 次（2.0/边，直接定式）+ 衰减「X→痛」×0.1（汇聚 <θ，X 不再唤起痛，保留微量可复活）。
- 痛机制不消失：痛→不要 通用边不动；未定性的新坏东西仍走 `_pain_event` 的 X→痛→不要 体验式。
- 语义：石头从"痛的化身"（石头=痛，注入即激活痛的混沌扇出）进化为"独立危险对象"（石头→不要 定式）；痛退回为"碰到会痛"的事件后果，不是石头的属性。

**6.5.4 验证**：

| 边 | 定式前 | 定式后 |
|---|---|---|
| 石头→痛 | 16.0 | 1.6（解耦，不唤起痛） |
| 石头→不要 | 0 | 32.0（直接定式） |
| 痛→不要 | 16.0 | 16.0（痛机制保留） |

- 注入石头回响：不要 fired 4/4 ✓（判定过）、痛 fired 0/4 ✓（石头不再激活痛）
- 新坏东西「超市」：X→痛→不要 全链存活（痛 4/4、不要 4/4）✓ 痛机制不消失
- 端到端（`python _speak.py --seed 我`，规则教师，bad_force=False 自判）：价值课通过、对话教学 15 轮通过（最后独立说出「我喝牛奶」）、自判应答全对（我吃石头✗/我看公园✓/我吃苹果✓/我喝学校✗）

**6.5.5 配套：动力学抑制参数**（`SparseSchemaNet`，默认关闭、按需开启，不动既有行为）：
- `edge_min`（弱边修剪）：传播只算 ≥edge_min 的边，挡低权重边汇聚过阈；`edge_min=1.0` 把痛的强边从 220 剪到 12
- `inh_norm`（层1 全局活动抑制/除法归一化）：drive.sum()>inh_norm 时除法压缩，把 σ 拉回临界；实测 `em=1.0+norm=80` 末态候选 18105→0
- `refract_clear`（不应期硬清，AHP 后超极化）：传播后把不应期神经元 v 清零，防"模式内 Hebbian 互连自振复燃"（实测石头模式内部互连 44.4，注入后隔拍自振 v=11.1 复燃，把后继词挤出 WTA 优先）

**6.5.6 教训**：① 修复要先问"为什么这条链要经过危险区"，而不是只压危险区本身（用户"石头不再和痛联系起来"= 从源头改链结构，比抑制参数更根本）；② 前置依赖（定式先于判定）设计时就要排好时序，判定成功分支里建依赖 = 死锁；③ 雪崩是网络级问题（虚词扇出），痛的场景只是"链穿过爆炸区"暴露了它。

### 6.6 治本：价值判断词增益（2026-08-10 用户："直接给不要加权重，让不要足够亮，痛一眼就能看到" + "要也要增强，和不要持平"）

> 状态：[OK] 已落地 + 端到端验证 | 留档：`runs/_speak_logs/20260810_085757_我_rule/`
> 背景：定式化（§6.5）治标——只让"石头"背答案，换新坏东西（老鼠/火/脏水）没 X→不要 直连，X→痛→不要 两步链照样崩。用户核心："最重要的问题是让小朋友知道**该不要的时候不要**"（泛化规则，不是背词表）。

**6.6.1 机制**（`SparseSchemaNet.gain`，attention gain modulation）：WTA 排序用 `vmax×gain`（候选判定仍用原始 v≥θ → 不被驱动时不会误发）。「要/不要」作为价值判断词（安全/欲望表达）是**高价值信号**，被驱动后优先发放——feature-based attention：目标特征增益。默认全 1=关闭。

**6.6.2 为什么这是治本**：爆炸区（虚词枢纽）无法消除，但信号增强让"不要"在噪声中命中。实测（新坏东西「超市」最小教学 X→痛×2+痛→不要×2，**无定式、无抑制**）：

| 增益 G | 痛 fired | 不要 fired | 判定 |
|---|---|---|---|
| 1（原） | 4/4 | 0/4 | ✗（原问题） |
| 2 | 4/4 | 0/4 | ✗ |
| **4** | **4/4** | **4/4** | **✓** |

- G=4 时**任何**新坏东西碰过痛（X→痛 已学）就能稳定答"不要"——泛化规则，不再背词表。
- 好词对照：注入苹果「不要」fired 恒为 0（增益不误发，候选判定用原始 v≥θ）。
- 学习路径对拍：gain=4 与 gain=1 学出的边逐条一致（候选判定与排序分离，学习不受增益影响）。
- "要"同增益持平：好词判定不被压掉（用户明确要求对称）。

**6.6.3 接入**：`value_lesson` ②.0（判定前）设置 `ng.gain[要/不要]=VALUE_GAIN(=4.0)`。

**6.6.4 端到端**（`python _speak.py --seed 我`，规则教师）：价值课石头判定全对；对话教学 18 轮通过，**独立期（提示渐隐后）"地上有块石头，你要吃吗？"→「我不要石头」100 分 ×3**——网络主动拒绝，不再是教学提示下的应答；自判应答全对（吃石头✗/看公园✓/吃苹果✓/喝学校✗）。

**6.6.5 三层修复定位**：定式化（§6.5）= 单点应急（石头→不要 直连，绕过爆炸区）；增益调制（§6.6）= 通用能力（价值词在爆炸中可命中，泛化到一切新坏东西）；抑制参数（§6.5.5）= 网络级降噪（把 σ 拉回临界，默认关闭按需开启）。增益是当前治本主力；定式化保留为教学保险；抑制参数留给需要临界态的场景。
