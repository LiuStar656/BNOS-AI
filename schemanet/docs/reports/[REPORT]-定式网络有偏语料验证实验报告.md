## 一、实验背景与目标

**方向**：定式网络（SchemaNet）自主进化路线。Phase 2 已发现 **uniform 合成语料（corpus_large）是 trace/grad 的最不利场景**（22 模板等概率轮转 → 转移后继平局率最大化，trace 0.28 < wsum 0.38；Phase 2 发现②）。真实有偏语料下 trace 借主语痕迹破局、梯度学主语-宾语关联的增益尚属悬案——本阶段目标：**自建有偏语料，一次验证 trace/grad 增益 + 生成多样性三个悬案**，同时是 Phase 5 数据驱动的前提验证。

**本阶段目标（对应方案 v1.1 §8.5 后续方向）**：
1. 构造三层偏斜语料（词频 Zipf + 模板权重 + **主语→宾语偏好关联**），目标：词表 ≥500、句数 2000+、后继平局率下降
2. 有偏语料下三路（wsum/trace/grad）top-1 对照——验证 trace/grad 借主语痕迹破局
3. 20 条生成 + 人工评估
4. 回归（abc/seq）+ 留档

## 二、设计

### 2.1 有偏语料生成器（gen_corpus_biased.py）

三层偏斜：

1. **全局词频 Zipf**：各变量池按 `1/(i+1)^s` 权重抽样（高频词多用、低频词少用）
2. **模板带权重**：常见句式高频（"我喜欢X"权重 20、"我看书"12、问句 10…），共 27 模板
3. **主语→宾语偏好关联**（条件偏斜核心）：12 主语 × 10 单 token 偏好词（`PREF`，每主语 `zipf(1.5)` 陡分布，top1 占 ~50%）——**各主语 top1 互不相同**（我→看书、你→旅行、他→打、她→画画、爸爸→钓鱼、妈妈→做饭、朋友→吃、同事→上班、妹妹→跳舞、哥哥→踢、邻居→养、同学→跑步）→ 合并视图下"喜欢"后继近似平局、按主语分组后继明确

**构造关键**（多轮迭代踩坑沉淀）：
- 偏好词必须是 jieba **单 token**（复合词"打篮球"被拆成"打/篮球"会抹平条件关联）
- 必须有"主语+宾语"**直接相邻**的短句式（`T_short`：我看书）→ 让 `W[宾语←主语]` 非零（trace 借主语痕迹的前提）
- `subj()` 每句只能取一次（先固定主语再取偏好，否则主语-偏好错配）
- **不去重**：重复句是频率统计信号（模板组合有限，去重会把频率砍成 1 条）
- **各主语句量完全均匀**（`W_SUBJ` 全 1/n）——合并后继平局的必要条件；专属模板（"你喜欢X吗"）会打破平局（旅行 407 一骑绝尘），已改通用 subj() 版

**语料统计（与 corpus_large 对照）**：

| 指标 | corpus_large（uniform） | corpus_biased | 判定 |
|---|---|---|---|
| 句数 / 词表 | 1814 / 353 | **15100 / 504** | ✓（词表≥500） |
| freq_entropy_norm | 0.807 | **0.757** | ✓ 词频更偏 |
| top10_share | 0.370 | **0.349** | ✓ |
| succ_uniq_mean | 4.4 | 7.0 | 更高（句式更多样） |
| succ_entropy_norm | 0.425 | **0.382** | ✓ 后继分布更偏 |
| tie_share | 0.263 | 0.303 | 口径不可比（句数 8.3×，高频源词更多） |

> tie_share 上升是句数效应（15100 句 vs 1814 句 → 高频源词多、后继天然多样），非偏斜度下降；主判据为 succ_entropy_norm（0.425→0.382）。

**条件偏斜成立（2-gram 关联）**：
```
[全局→喜欢→] 跑步305 打278 旅行248 画画226 跳舞226     （合并近似平局，归一化差 ~0.01 < delta_off=0.02）
[我→喜欢→]   看书90 散步40 喝茶24                        （条件明确）
[他→喜欢→]   打120 踢43 下棋20                          （条件明确）
[她→喜欢→]   画画128 唱歌34 跳舞21                       （条件明确）
```

### 2.2 trace 增量评估提速（sparse_net.py，b3 顺手项）

trace 评估原为**每位置重放前缀**（复杂度 O(len²)），且只清 v/spikes/pre_trace、**不清 refractory_left/last_k_star**——跨调用残留（0.5% 级隐副作用）。本阶段：

1. **修正重放版**（`predict_cands_trace_sparse`）：每调用全清状态（含 refractory）——trace 语义是"给定前缀预测下一词"，与之前调用无关
2. **新增增量版**（`evaluate_schemanet_trace_inc`）：单句内逐词注入，pre_trace 自然累积不清零重放，复杂度 O(len)
3. **对拍验证**（`_check_trace_inc.py`）：noise_p=0 时两版**逐位一致**（237/237 PASS）；noise_p=0.06 时差 0.12%（纯 RNG 消耗顺序不同的噪声级差异）

### 2.3 验收编排（_accept_gen.py，corpus_biased 版）

同 Phase 3 五路判定 + 新增 trace/grad 增益判定（留出 top-1 超 wsum+0.01）。MAXLEN 5→6（有偏语料句子更长）。trace 评估改用增量版。

## 四、发现与分析

1. **grad 增益在有偏语料上兑现（+0.047），验证了 Phase 2 的预测闭环**：uniform 语料平局率最大化是梯度最不利场景（Phase 3 持平）；条件偏斜语料下 `train_w` 学到位置信任（pos1=1.98）+ W 非零子集微调（扰动 124.8 万条），把主语-宾语条件关联编码进读出——**"梯度学到 Hebbian 学不动的东西"在有偏语料上量化兑现**。

2. **trace 结构性失利，β 扫描排除参数因素**：trace 借"主语痕迹"破局的前提是 `W[宾语←主语]` 非零（T_short 提供）且**主语作为源词的传出突触分布里宾语占比够高**。但"他喜欢X"句里"他"的直接后继以"喜欢"（T_like 类权重 49/189）为主，P(打|他)≈0.1 盖不过 P(跑步|喜欢)=0.31；trace 的混合权重靠痕迹比 × β（β=0.1 时主语贡献仅 5%）。β 放大至 1.0 仍不敌（P(打|他) 本身低，加权后仍是噪声）→ **无参数启发式的结构性上限**：无法学"位置相关性"（哪些远端词对当前预测重要）。这正是**梯度参数化（ctx_wgt 可训练）的必要性证明**——Phase 4 决策"无梯度 Hebbian 先行、梯度为第二阶段"的实证支撑。

3. **生成退化（2.05/5）根因在语料模板化，非引擎退化**：① 问句模板占比高（QUESTION 10 + T_like_q 4 = 14/189），"吗"高频且被噪声污染传出突触（Phase 2 噪声多步累积发现：教学式学习中自发发放与注入词共发 → Hebbian 给句尾词"吗"造传出突触）→ "吗吗"重复 ② 短模板（2-4 词）拼接无整体语义。与 Phase 3 对比：corpus_large 句长 5 词、转移链丰富 → 3.7/5；corpus_biased 平均句长 4 词、句式重复 → 生成链短、易碎。**真实有偏语料（开源）应显著改善**——佐证 C 路线（自建→开源）第二阶段价值。

4. **trace 评估提速 + 隐 bug 修正**：重放版不清 refractory 的跨调用残留是原实现隐副作用（0.5% 级），已修正并留对拍脚本（noise_p=0 逐位一致）。增量版复杂度 O(len²)→O(len)，全量 trace 评估从分钟级降到 ~3 分钟/15000 句（训练+留出，含 step 稀疏遍历开销）。

5. **统计口径**：tie_share 在句数差异 8.3× 下不可直接对比（高频源词基数不同），改用 succ_entropy_norm 为主判据（0.425→0.382，偏斜确实建立）；β 扫描留出 2966 句 vs 验收 3020 句（OOV/短句过滤口径不同）。

## 五、结论

1. **有偏语料验证闭环达成**：三层偏斜语料（词表 504、句数 15100、条件偏斜明确、合并后继平局）构造成功，指标全部达标
2. **grad 增益兑现（+0.047）**：梯度参数化在条件偏斜语料上显著优于 Hebbian 静态读出——"梯度学到 Hebbian 学不动的东西"的量化证据
3. **trace 定性为无参数启发式上限**：β 扫描证明其结构性局限（主语痕迹弱 + 主语传出突触被高频动词稀释），不可通过调参修复；trace 定位回归"无参数兜底"而非破局主力
4. **生成质量受语料模板化限制**（2.05/5），根因已定位（问句模板高频 + 噪声污染句尾词），开源真实语料是下一步
5. **工程改进落地**：trace 增量评估（O(len²)→O(len)）+ 重放版隐 bug 修正（对拍逐位一致）；回归 abc 9/9、seq 1.0 全绿

## 七、后续方向

- **开源真实语料（C 路线第二阶段）**：自建语料已证明 grad 增益机制，真实语料的分布（长句、句法结构、对话性）应进一步释放 trace/grad 增益并改善生成——需处理 OOV、长句截断、词表自适应
- **trace 机制升级选项**：① trace β 自适应（按语料后继偏斜度动态调）② trace 痕迹改为可学习权重（即并入 ctx_wgt 同参数化）——后者等价于 grad，明确取舍
- **生成噪声抑制**：回忆/生成路径降 noise_amp 或加噪声抑制（Phase 2 噪声多步累积待办），修"吗吗"式句尾词传出突触污染
- **语料多样性**：降低问句模板占比、加长句模板（原因从句/并列结构）→ 生成链更长更连贯
- **Phase 5 表示深度**：时间深度→槽间级联，上下文 3-5 词
