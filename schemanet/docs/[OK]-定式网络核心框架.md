## 一、定位

**AI 的持续自我层**：一个纯计算、模型无关的动态权重网络。

- 静态神经网络（LLM）负责**能力**（生成、推理），本系统负责**自我**（经历、记忆、人格倾向、身份）
- 权重从交互中产生（初始全 0，不提前赋予）；反复输入同一数据 → 形成定式
- 与 LLM 分离 → **换模型不换自我**
- 与 BNOS 的关系（2026-08-10 确认）：定式网络是**自我中枢**（记忆与人格的沉积），**不是调度中枢**（任务编排交给 BNOS 节点体系）
- **自主进化路线**（2026-08-09 决策，取代"外挂 LLM 吞并愿景"）：定式网络自身逐步获得大模型能力（规模、上下文、生成、学习能力四支柱全部自生长出）
- **成长哲学 v2.0**（技术路径切换，2026-08-09 八项证据链定案）：从"词接词概率引擎优化"切到 **数据专门化 + 分级课程 + 增量成长 + 神经元逐步扩容 + 双系统读出**（见第九节）

**一句话**：LLM 是大脑皮层（会算），定式网络是记忆与人格的沉积（会记得自己是谁、经历过什么）。

### 1.1 系统定位：形态结构型持续演化系统（2026-08-11 修正，与 AAA + 大模型统一）

定式网络不是一个"模型"，而是一个**形态结构型持续演化系统**——**脉冲行为是结构自带的属性，不是通过外部设计模拟出来的**。它与 AAA + 大模型**不是微观和宏观的层级关系，而是同一个系统在不同时间尺度上的不同工作方式**：

| 时间尺度 | 系统 | 结构性质 | 脉冲来源 | 结构更新时点 | 脉冲频率 |
|---|---|---|---|---|---|
| **高频** | 定式网络 | **形态结构**（本身就是脉冲网络） | 结构自带属性 | 每次交互 | 最高（每步） |
| **低频** | AAA + 大模型 | 行为结构（非脉冲网络本身） | 外部设计凑出 | 训练 / 沉淀时 | 较低（间歇） |

- **形态结构 vs 行为结构**：定式网络本身就是脉冲网络，脉冲行为来自结构本身、不是来自外部设计；AAA + 大模型通过外部设计凑出了"脉冲行为"，但它的行为结构不是脉冲网络本身；
- **都依赖外部输入改变自身结构，区别在响应速度**：定式网络的更新发生在每次交互中（速度最快），AAA + 大模型的更新发生在训练或沉淀时（速度较慢）——不是层级关系，而是**同一系统在高频与低频两种时间尺度上的不同工作方式**；
- **功能互补**：定式网络提供高频结构更新与快速演化，AAA + 大模型提供低频总结与沉淀。

**核心命题**：

> **智能是结构现象，有向脉冲是结构变化的驱动机制，脉冲频率决定智能形成速度。**

| 时间尺度 | 结论 |
|---|---|
| 高频 | 定式网络每次交互更新一次结构，演化速度最快 |
| 低频 | AAA + 大模型在训练/沉淀时更新，演化速度较慢 |
| 统一框架 | 脉冲频率越高，结构更新越快，系统演化越快——**频率本身正在定义系统的性质** |
| 硬件 | 定式网络计算特征（稀疏查表、分支密集、随机访问）与 GPU 设计目标不匹配，CPU 是自然选择（已并行学习验证）；扩展路径不依赖更强算力，而依赖结构扩展 |
| 架构分类 | 不是"模型"，而是**"结构驱动的持续学习系统"**——不依赖大规模预训练、不依赖海量数据、不依赖 GPU，能在普通设备上持续演化、零遗忘 |

**可验证结论**：64/128 并发 0 串扰 0 崩溃 ✅（§五 40）、零遗忘增量成长 ✅（v0→v15 版本链）、高频脉冲快速演化 ✅（15 轮对话教学验证）、CPU 可用 ✅（16MB、14 万神经元运行）、CPU 并行学习 ✅。AAA（低频侧，记忆与人格中枢）的机制与结构详解见 §十一。

## 二、设计哲学

| 原则 | 含义 |
|------|------|
| 权重从交互中产生 | 初始空白，不预置知识 |
| 反复经历形成定式 | 经历 = 重复（Hebbian 痕迹）+ RL 教学（规则塑造）；见过 ≠ 理解 |
| 记忆不是遗忘，是封存 | 封存 ≠ 删除，可复活 |
| 用进废退 | 低频槽渐进弱化可复活（频率门控慢衰减）；满槽覆盖（slot_cap）已废弃 |
| 神经元是 AI 的神经元 | 不是用户的神经元 |
| 只考虑多槽 | 单槽架构已废弃（实验证明组合不可表示） |
| 冻结/学习双状态 | 根据实际情况切换；冻结期自我物理免疫篡改 |
| 加法系统，零遗忘 | 只加不减覆盖 → 无灾难性遗忘；非覆盖式遗忘（竞争挤出/串扰/sleep 误删）是弱化不是删除 |
| 双系统读出 | 走链回响（联想/续推）与直接传出突触（对话/回答）分离——语义传递与字形分解共用 W，检索须区分层级 |
| 数据专门化 + 分级课程 | 铁律：永不从头训练、增量成长、神经元逐步扩容、对话即学习 |

## 三、核心机制

全部矩阵运算（numpy 向量化），核心机制十六项（3.1-3.10 动力学底座，3.11-3.16 训练本质/注意力/增益/并发/RL/读出）：

### 3.1 积分-发放（LIF，Lapicque 1907）

```
v = v·λ + 注入脉冲 + W@spikes（分槽传播）
v ≥ θ 且 WTA 选前 k 强 → 发放；发放后全槽复位
```

- `θ=1.0` 发放阈值；`λ=0.9` 膜电位衰减
- WTA（胜者全取，Marr 1969/Olshausen 1996）：每步最多 `wta_k` 个神经元发放

### 3.2 Hebbian 学习（Hebb 1949）

```
共同发放对 (i,j)：W[i, 主导槽_i, j] += η（排除自连接，w_max=2.0 截断）
```

- 反复激活强化；η=0.1，20 次反复 → 连接到顶（2.0）

### 3.3 噪声探索

```
noise = (rng < noise_p=0.06) × noise_amp=0.5
```

- 让空神经元有机会参与竞争
- **噪声卫生**：`0.9×0.5+0.5=0.95 < θ`，杜绝连续两步噪声越阈伪发放（0.6 时会越过；decay=0 后伪发放的微小连接永久累积）

### 3.4 内部多槽 + 情境化传播（架构核心）

```
W 形状：[n 神经元, s 槽, n 入连接]
```

- 每个神经元内部有 s 个独立状态槽，不同情境的输入打不同槽
- **情境化传播**：发放神经元按主导槽分桶，只驱动同槽接收方 → 存储隔离 + 传播隔离
- 同一神经元可同时承载多个模式而不互相覆盖
- **单槽废弃**（2026-08-09 实验结论）：单槽下组合不可表示——要么融合成超组装要么随 n 增大爆炸（n=256 排列一致性跌到 0.10）

### 3.5 频率门控慢衰减（2026-08-09 取代满槽覆盖）

```
slot_freq[n, slots]  窗口内每槽位被"发放神经元主导"的唤醒计数（只数真实发放，静息不污染）
sleep_consolidate()  低频槽（<min_wake）连接逐周期 ×(1-decay) 渐进弱化，≤eps 删除条目（稀疏回收）
                    高频槽（≥min_wake）永不衰减；learn_gate=False 冻结态拒绝执行（物理零改动）
```

- 记忆观转变：**"装得下就不动"（容量驱动被动保留）→ "用进废退、可复活"（使用驱动渐进遗忘）**
- 低频定式缓慢弱化，期间被复习（Hebbian 强化）即可复活；长期不用最终归零回收
- 生物对应：突触修剪渐进性 + 稳态可塑性 + 睡眠记忆巩固 + 艾宾浩斯遗忘曲线
- `slot_cap` 满槽覆盖（写时挤最弱）**已废弃**（2026-08-09 用户决策），代码保留仅供历史留档重跑（默认 0）；`weight_decay` 无差别衰减仍废弃

### 3.6 学习门 learn_gate（冻结/学习双状态）

```
learn_gate=True  → 学习态：权重实时更新（Hebbian/STDP/频率门控衰减全执行）
learn_gate=False → 冻结态：纯检索，权重物理零改动（含 sleep 拒绝执行）
```

- 冻结期外部输入照常激活网络（识别/检索正常），但**不成为自我的一部分**
- 学术对应：多巴胺门控可塑性 + 稳定性-可塑性困境（stability-plasticity dilemma）

### 3.7 STDP 时序（token 转移，Bi & Poo 1998）

```
前驱（上一步及更早的发放痕迹）→ 后继（当前发放）：
W[后继 ← 前驱] += stdp_pre（只强化正向，δt=1 最近邻）
```

- 发放痕迹 `pre_trace`（eligibility trace 简化版）：`trace_decay=0.5` 衰减，阈值 `0.3` 滤掉非相邻的陈旧痕迹 → **只学相邻转移**
- 只强化正向 → "喂 a 唤起 b"成立、"喂 b 唤起 a"不成立（反向连接从未强化）→ **顺序自动可区分**
- `stdp_pre`/`stdp_neg` 默认 0 全关，不影响静态实验

### 3.8 教学式学习（语言实验专用，学习/回忆路径分离）

```
学习（_learn_sentence）：注入每词前清 v 与 spikes（无传播驱动）→ 当前词干净发放 → STDP 只学 pre_trace→当前词
回忆（_evoke_prefix）：   保留传播驱动（注入前缀 → 网络自己唤起后继词）
```

- 根因：学习时若保留传播，强组装（高频词）的复发发放会 WTA 压掉注入词（v-clear 后注入词脉冲 1.0 输给驱动 4.0），W 学到网络自联想而非语料词序 → "无聊垄断"（W[无聊←我]=14.0，单次出现的词被高频词组装吞并）
- 重写后 W 严格∝语料共现次数（W[喜欢←我]=48=12次×0.5×8、W[无聊←我]=0、W[无聊←觉得]=4=1次×0.5×8）
- 语言实验专用 `lang_n=2048`：静态实验 n=32 太小，k=8 分布其中两词平均交集 2.0、67% 词对碰撞，词模式无法区分（准确率被压到 0.07）

### 3.9 痕迹插值读出 trace（上下文条件转移，Phase 1，2026-08-09）

```
P(w_t | w_1..w_{t-1}) = P(w_t | 末词)            末词已决定（top1-top2 差 ≥ delta_off=0.05）
                      = Σ_i wgt_i × P(w_t | w_i)  末词平局（借整条前缀破局）
P(w_t | w_i) = W[w_t ← w_i] / outsum[w_i]   （源词传出突触归一化 = 条件转移概率）
wgt_i = trace_i / trace_末词，非末词再 × β=0.1
trace(w_i) = 前缀注入后该词模式神经元的 pre_trace 最大值（距离权重：相邻 0.5 / 隔一 0.125 / 隔二 0.031…）
```

- **复用 pre_trace（eligibility trace）机制，W 保持二元转移不变**，插值只发生在读出层 → 零额外学习，从"一元上下文"升级到"多词条件转移"（trigram+ 级）
- **outsum 归一化是必须的**：否则高频源词转移强度（W[喜欢←我]=48）即使痕迹很弱也淹没相邻词决定信息
- **delta_off 条件混合（backing-off 平滑）**：末词已决定 → 只用末词（≡wsum，非平局零退化）；末词平局（无统计答案）→ 借整条前缀破局
- 验证：主语料 trace 0.474（非平局零退化，平局处 2 例正确破局 5 例误翻转——精确平局无统计答案）；微语料破局机制 ✓（"我很累"+"我很忙"+"昨天很忙" → 前缀[昨天,很] 靠"昨天→忙"破"很"的平局 → 忙）；"我喜欢吃"→苹果 ✓
- 定位：LLM 注意力混合历史 token 信息的雏形（条件概率混合 = Jelinek-Mercer 插值平滑的神经实现）

### 3.10 稀疏存储 SparseSchemaNet（Phase 2，2026-08-09 验收通过）

```
稠密 SchemaNet.W[j, k, i]  ←→  稀疏 W_out[i][k] = {j: w}（i 槽 k 传出突触到 j）
```

- **动机**：n=8192 时稠密 W 2.1GB 不可行；实测 W 非零率仅 0.11%（Hebbian/STDP 只强化共现对）→ 稀疏化 W 48MB（省 43×），传播/更新只碰非零行（O(非零)）
- **等价性保证**：动力学逐行对齐（积分-发放/WTA/Hebbian/STDP/痕迹/不应期/学习门），唯一 RNG 调用点（noise）一致 → 同种子学习结果逐值一致（对拍：18090 非零 0 差异、outsum 全等、评估 0.5000/0.4805 一致）
- **读出向量化**：词模式 → (V,k) 索引矩阵，传出突触聚合 + fancy indexing，纯 numpy
- 语言实验用 slot=0，但为行为对齐保留多槽完整实现（噪声打所有槽、Hebbian/STDP 写主导槽 k_star、传播按主导槽分桶）
- **EdgeRow 数组化（2026-08-10，内存优化方案 A 落地）**：W_out[i][k] 由 dict 重构为 EdgeRow——`dst(int32, 排序) + w(float64)` 数组事实源 + dict 兼容接口（外部脚本零改动）。镜像 = 数组视图（dirty 机制废弃）；Hebbian/STDP 批量合并、weight_decay/sleep 整行 scale+prune；load/snapshot 按行分组批量构建。实测：加载 1.5s（原 ~分钟级）、RSS 2138→343MB（省 84%）、对拍 39 万边逐值一致。详见 docs/reports/02-记忆与存储/[REPORT]-定式网络内存优化探针实验报告-三种存储结构RSS实测.md
- 关联：sparse_net.py（代码）、_check_sparse.py（对拍）、data/gen_corpus_large.py（语料生成）

### 3.11 训练本质：见过 vs 理解（2026-08-10，用户观点定案）

**训练 = 让网络见过文本**——且比 LLM 更字面：每个句子都是真实的神经活动事件，词脉冲真的在网络里传播一遍，走过即留痕（见 3.8 教学式学习）。

```
灌入（语料批量注入 / 教学式学习） → "见过" = 传播路径留下边痕迹（统计相关：什么和什么常一起出现）
RL 教学（_speak.py：奖励/惩罚/教师示范） → "理解" = 痕迹被赋予价值方向（该怎么做）
```

- **见过 ≠ 背诵**：不留原文、不留统计分布，只留"哪些神经元序列曾被一起激活过"的路径痕迹
- **重复 = 深度**：Hebbian 累加，同一句见 N 次痕迹深 N 倍（与生物重复经历一致）
- **见过有上限**：突触数上限 = 有效搭配空间 α·V²（结构收敛定理），文本只是填充速率，填满不再长结构
- **见过 ≠ 理解**：灌入只能产生"无立场的相关"（认得「吃→石头」搭配，但不知道石头能不能吃）；规则（价值/行为决策）必须由 RL 教学塑造——奖励强化"倾向"、惩罚衰减"回避"，教师示范 + 批改 + 评分给痕迹赋予方向

**理解三步链（不可跳步，v13.2 痛觉条件反射实证）**：

```
见过（感知边：先教"我吃石头"能唤起）→ 体验（内感受：碰过会痛，X→痛 边衰减）
    → RL 塑造（"不要→X"被强化 = 条件反射，学会拒绝）
```

- 先见过：RL 只能作用在已存在的边上，无痕迹则无物可塑
- 再体验：价值来自网络自己的内感受事件，不是教师灌输的知识
- 最后 RL：规则从痕迹里长出来——同一批边，被奖励强化变"倾向"，被惩罚衰减变"回避"

**理解的判据 = 换语境做对**：回想 vs 判断在神经图上分叉——见过「吃→石头」只能在「吃」引导下唤起「石头」（关联）；懂「石头不能吃」会在坏语境问"你要吃石头吗？"时**自己**唤起「不要」（走 X→痛→不要 链，决策）。`_speak.py` 的 bad_force=False 自判测试即测此升级。

### 3.12 注意力机制 v2.2：连接数量 × 边强度 + gain（2026-08-10）

**注意力 = 竞争环境（注入词传出突触 fan-out 数量）× 边强度（资格 + 得分）+ gain 调制**。判别实验定案（E 组/C 组/D 组，runs/_speak_logs/20260810_101355）：

```
连接数量：注入词 fan-out 决定竞争规模（主导瓶颈）
  × 边强度：候选词与注入词之间的 W 权重（资格 × 得分）
  + gain：  行为开关/感受词的增益调制（见 3.13）
```

- 量级：数量维度 4 个数量级（hub「的」=16.6 万传出突触 vs 正常词 16 条），强度维度仅几十倍 → **数量是注意力瓶颈，强度是筛选器**
- E 组：连接归零 → 16 条弱突触累加 5/5 全通（无竞争时弱突触也足够）
- C 组：强度梯度 7 次 56.0→5/5（临界 48 < x ≤ 56）
- D 组：砍 92.4 万条 hub 传出突触无效（hub 数量级本身才是瓶颈）
- **唤起失败 ≠ 学习失败**：边 80.0 存在但唤起 0.00（注入词「我」fan-out 1.7 万+，被竞争挤出）→ 判读必须读边强度而非只读唤起（3.14 实证）
- v1.0 结论"连接数量决定注意力"经用户追问修正为 v1.1 完整式（数量 × 强度 × gain），理论框架同步 v2.2

### 3.13 强度调节：gain 调制（四级增益 + 感受开关联结，2026-08-10）

```
欲望开关（要/不要）×4  >  近义词族 ×3  >  感受词 ×2  >  知识内容词 ×1
```

- **欲望优先性**（理论报告）：要/不要 = 生物原始欲望在语言层的接口——增益是先天架构（不学不消），边是后天知识（可衰减）；"点亮目标"（gain）比"压缩距离"（定式）更根本
- 感受-开关联结：负面感受（痛/怕/哭/累…）→ 避害族（不要/不想/拒绝…），正面感受（喜欢/高兴/舒服…）→ 趋利族（要/想要…）
- 增益生效机制：WTA 排序前 `× gain`，让被驱动的价值词优先发放（attention gain）
- 实测：gain=4 时「X→痛→不要」在爆炸噪声中命中"不要" 4/4；泛化到新坏东西「火」✓（火→痛=16.0→不要 4/4）；同义词族强度与开关持平、近义词族略低（×3），落位即"空端口"，词汇由教学/语料后续填充

### 3.14 表示并发：槽位 = 表示通道（2026-08-10）

- **机制**：多槽并行学习互不串扰——槽0 学「我吃苹果」、槽1 学「他看家」，两组边各自落在主导槽，建立、传播、存储三层隔离
- **实证**（双槽探针）：A 组边 80.0/120.0（槽0）、B 组边 110.4/123.2（槽1）、跨组串扰全 0；**并发槽学习更强**（槽1 他→看 110.4 vs 同槽对照 40，≈2.8 倍）
- **并发边界探针（128 组）**：同槽 G∈{1…128} 成功率全 1.00、最大串扰 0、激活规模恒 84（无超临界）；轮转 4 槽 G≥32 出现 0.25 轻微串扰。**并发量不是崩溃维度**——崩溃真正维度 = A hub 竞争环境 / B 传播式学习 / C 长期边密度
- **槽位无硬上限**：slots 是构造参数（默认 4），代价线性（v 数组 ×slots×8B、W_out 空容器）
- 判读教训：唤起读数受注意力竞争污染，**边强度才是学习是否成立的判据**

### 3.15 RL 教学体系（v11→v13，2026-08-10）

语言教学的升级链：规则判定 → LLM 教师 → 网络自判 → FCT 拒绝表达 → 底层痛觉。

```
v11  RL 颗粒度升级：样本级 → 原则级奖励 + 连接级归因处罚（删 224 条错误边）+ LLM 教师判断
v12  判断内化：直连→二跳→强度→类别冲突→不知道 五档自判（课后练习 28 题 0.900）
v13  复杂句式练习题（A 型 S+想要族+O / B 型 S+在/想+V+O）+ 代码判定 + LLM 讲评
v13.1 FCT 拒绝表达：「要/不要」同义词族 + 坏东西价值池（不删边、保持强唤起 = 感知）
v13.2 痛觉底层化：X→痛 内感受边（体验）+ 痛→不要 通用逃避规则（条件反射）
```

- **奖励语义**（说话教学 v3）：拒绝坏东西 100 分 > 正确句 80 分（问句与陈述句同 80，取消问句高分）> 半句 40 > 答非所问/反复重复 30 > 结构错 20 > 搭配错 10 > 没说 0
- **教师 = LLM-as-Judge + 示范**：判断+解释一体、单轮调用；示范自然口语带虚词（网络学习时跳过 NAT_FILL，只切已学 S/V/O 词）
- **反复重复惩罚**：近 3 轮同一句出现 ≥3 次 → 该句 V→O 与尾边 ×0.5（不动共享 S→V 边）
- **对话式教学**（v3）：教师发起对话 → 网络听问题（听到动词优先应答，HEAR_BOOST=8）→ 回答 → 教师批改 → 示范更丰富说法；提示渐隐 + 连续 15 次通过
- 痛点实证：石头痛觉刺激过强 → 网络超临界放电（v(不要) 高达 26~56 却不发放，候选指数增长）——三条件缺一不可（高频词传出突触巨量 + 弱突触汇聚过阈 + WTA 满发 v 不复位），三种修复（全局归一化/饱和度/减性抑制）均未通过

### 3.16 双系统读出：走链 vs 直接传出突触（v15，2026-08-10）

成长路线 §2.6 落地段确立的读取架构，解决"**边学进去了但读不出来**"的核心矛盾（v14 探测：前缀续推 0%，因为/虽然/先 的定式词读不出）：

```
系统一 走链回响（联想/续推）：注入前缀 → 全局回响/WTA 多步续推
        → 被虚词枢纽（的/了/是/你）连接爆炸堵死（续推 0%）
系统二 直接传出突触 direct_next（对话/回答）：读词直接传出突触 top-k + 域内过滤
        → 开放补全 top-1 9/10 → v15 固化后 10/10
```

- **域内过滤（domain）**：只保留对话域词表（61 词：S/V/O + 关系词），排除虚词枢纽——虚词连接爆炸是续推 0% 的根因
- **配对直读**：关系词在倒数第二位 → 直读配对词（因为→所以 / 虽然→但是 / 先→然后，边权 24.0），解决对称竞争
- **训练平衡（R_BIAS）**：真实语料边强度碾压专门定式边（想要→的 38.4 vs 想要→苹果 ≤2.5）→ 加权跟读 + 自适应加权，在→看 8.0→208.0 反超在→你 206.4
- 语义传递与字形分解**共用同一 W 传出突触**，检索必须区分层级（词级走链候选排除单字模式，防苹果→果→苹 带偏）


## 四、输入契约

```
现实 ──编码器──> 脉冲模式 ──定式网络──> 脉冲模式 ──解码器──> 现实
```

- 进入网络的**不是语义，是脉冲模式**；网络只识别"第 3、17 号位置有脉冲"，不认识"a"
- 编码器负责"现实→模式"（当前硬编码验证；真实接入需 embed→投影→稀疏化，且要求稳定编码）
- 解码器负责"模式→现实"
- 组合输入 = 成分模式并集（多集表示，顺序无关）；序列输入 = 模式按序注入（STDP 学转移）

## 六、关键设计决策与踩坑记录

### 6.1 单槽废弃，只考虑多槽（2026-08-09）
26 字母/组合实验证明：单槽下组合不可表示——要么融合成超组装要么随 n 增大爆炸（n=256 排列一致性跌到 0.10）。多槽实现存储隔离+传播隔离，组合层与原子层共存、原子保留 1.0。

### 6.2 频率门控慢衰减取代满槽覆盖（2026-08-09）
slot_cap 满槽覆盖（当日上午定案：装得下就不动、装不下挤最弱）同日被用户推翻：**取消写时覆盖，改为频率门控慢衰减**（低频槽不删除、逐步衰减为 0，渐进可复活）。**废除依据**：SparseSchemaNet 只存 slot_cap 属性从未实现覆盖逻辑（语言实验 slot_cap=0 实际无任何遗忘机制生效），W 单向增长（1809 万连接）；频率门控慢衰减是废除后唯一回收通道，且选择性（只忘低频）修复了 weight_decay 被废弃的根因。验证（runs/20260809_103532）：最小实验 12/12 PASS（含衰减中复习复活）+ 语言接入 top-1 不退化（wsum 0.1081 持平）+ 弱化低频连接 5.56%。

### 6.3 判读方式：首响应 vs 回响并集
- **原子重测用首响应**（第一步输入的直接激活）：强自连接（2.0）让定式持续回响 10 步并把伪发放累积进并集 = 仿真伪影（网络无抑制/不应期）
- **排列响应仍用回响并集**：并集脉冲 5 候选，WTA 单步只留 2 个，需多步收集完整组装

### 6.4 [历史] 满槽覆盖只伤弱链、保护强定式（2026-08-09 实测，机制已废弃）
slot_cap=4 压力档下学习态干扰触发 240 次覆盖，但 A/B 核心连接（2.0）与组装保留全 1.0——覆盖从最弱开始，强记忆扛得住篡改。

### 6.5 冻结实验对照严格性
两组同种子出发 → 噪声序列完全一致（learn_gate 不消耗 rng），唯一变量 = 学习门。

### 6.6 alphabet 判读缺陷（遗留）
alphabet 用末次快照判读 + slots=4 同槽共享下同槽字母不可分（decay=0 下 18/26）。修正方向：每字母独立槽（slots=26 时 26/26）或改倾向矩阵判读。**非机制问题，是判读缺陷。**

### 6.7 STDP 三个实现坑（2026-08-09 debug 定位）
1. 注入符号前残留膜电位 v 会让噪声越阈挤掉目标神经元（注入 b 时噪声 6 挤掉 b 目标 1）→ **注入前清 v**
2. 间隔步内定式可能不发放 → 严格"上一步 spikes"前驱会丢失 → **改用发放痕迹 pre_trace**
3. 回响阶段 a、b 神经元同刻发放 → 同步 Hebbian 双向污染 → **经历间清痕迹**

### 6.8 三实验同秒留档互相覆盖（2026-08-09）
时间戳秒级 + 同一秒跑完多个实验 → 留档只剩最后一个。修复：串行跑用 `Start-Sleep -Seconds 1` 区分，或槽对照实验用 `{run_stamp}_slots{n}` 目录名。

### 6.9 语言实验三个坑（2026-08-09 debug 定位）
1. **学习时传播驱动压过注入词** → W 学到网络自联想而非语料词序（"无聊垄断"：单次出现的"无聊"被高频词"我"的组装吞并，W[无聊←我]=14.0；同时"我想X" 11 次却 W[想←我]=0）→ 教学式重写（见 3.8）
2. **n=32 编码区分度灾难** → k=8 分布在 32 神经元里，两词平均交集 2.0、67% 词对碰撞 → 准确率被压到 0.07，误判为"转移没学到"→ lang_n=2048（交集期望 0.031、碰撞对仅 6/10011）后 W聚合 0.500 ≈ bigram
3. **回响读出 < W聚合读出** → WTA top-8 每次只发 8 神经元（恰好一个词的量），多候选平局（"喜欢"后 15 宾语各 0.5 平局）时 8 个神经元分散在 120 个候选里，任何词覆盖都 <0.4 → None。**覆盖率读出是动力学硬决策，只有确定性强后继才成功；W 直接读出才是有效的预测接口**

### 6.10 噪声多步累积（2026-08-09 发现）
旧"噪声卫生"论证（0.9×0.5+0.5=0.95<θ）只防**连续两步**噪声，没防多步累积：3 次噪声命中在 ~10 步窗口内即可越阈（1.0+0.9+0.81≥2 或非连续组合），n=2048×19 步真实网络自发发放 109/2048 神经元。教学式学习中无害（每步清 v），但回忆路径（不清 v、长前缀多步累积）会污染 fired 集合。待办：语言实验降 noise_amp 或回忆路径加噪声抑制。

### 6.11 trace 三个坑（Phase 1，2026-08-09 debug 定位）
1. **无归一化 → 高频词痕迹淹没决定**：Σ trace×W（W 原始强度）时，"我"痕迹 0.125×W[喜欢←我]=48 → 6.0，压过"觉得"直接后继"很"（0.5×4=2.0）→ 必须 ÷outsum 源词传出突触（条件概率同尺度混合）
2. **β 压降不足 → 高频词微增量翻转精确平局（对错各半，净负）**：β=0.1 后"我很"→高兴仍被"我"高频后继"喜欢"翻转（P(喜欢|我)=0.16×0.05≈0.008 > 0.1-0.1=0 平局差）——**精确平局下任何非末词正增量都翻转**，主语料无统计答案
3. **解法 = backing-off 条件混合（delta_off）**：末词 top1-top2 差 ≥0.05 → 只用末词（非平局零退化）；<0.05（真平局）→ 才借整条前缀破局。微语料验证机制 ✓，主语料净效应 = 非平局不损失 + 平局处 2 对 5 错（数据限制，Phase 2 大数据验收）
4. **破平局需要"非末词→候选词"的直接转移**（如 micro 的"昨天→忙"）；"我觉得"→很 破不了是因为 W[很←我]=0（"我→很"从未直接相邻，中间隔着今天/觉得）——W 是二元转移，上下文词必须直接连到候选词才有信号

### 6.12 Phase 4a 梯度实验三个坑（2026-08-09 debug 定位）
1. **评估口径**：梯度读出未过滤 `logits==0`（无转移信号的词），wsum 基线过滤 `scores>0` → 全 0 位置随机选词，0.13 = wsum 成功位置(35%) + 随机猜测 → 修复：`logits<=0 → -inf`（同口径）
2. **score 平局海（S 矩阵非零 98.72%）+ softmax 尾巴权重**：词模式 k=16 神经元的传出突触并集覆盖大半词表 → 顶级候选分差 ~1e-4 量级 → 任何非零远端权重都翻转平局。softmax 参数化梯度 ∝ wgt（越小越慢）→ 0.0001 尾巴翻转 25% 位置（0.38→0.14）→ 修复：自由参数 + 单纯形投影（clip 非负 + 归一化）
3. **uniform 语料下 CE 目标与 top-1 准确率背离**：uniform 分布（上下文无统计信息）下，CE 拉高远端权重（降 CE）但 top-1 平局扰动暴跌 → 梯度训练在 uniform 语料上不可行（与 trace 的 6.11 同源：均匀分布 = 上下文最不利场景）→ **exp2 必须用二阶依赖语料**（corpus_ctx：ctx→候选直接相邻），梯度学到 pos1=0.0547、8/8 破局

### 6.13 trace 机制"兴起→推翻"教训：train_w 污染制造假象（2026-08-09/10）

trace 长上下文增益曾以 z=4.42 显著定案（L1 报告）→ **L1 干净对照推翻**：此前结论建立在 train_w 对 W 的扰动上（改 2058 万条/35% 连接），干净 W 上 wsum 0.1349 反而显著优于 trace 0.1245（z=-3.48）。**教训**：观察层（读出器）与训练层（train_w 重写）必须解耦对照——任何"机制增益"结论都要在干净 W 上复验；数据放大无益（wsum 2 万 0.1007 > 20 万 0.0722，w_max=2.0 饱和）佐证结构收敛。

### 6.14 虚词枢纽连接爆炸堵死续推（2026-08-10，v14 探测定位）

前缀续推 0% 的根因：虚词（的/了/是/你）是真实语料高频枢纽，传出突触数量爆炸 + 对称竞争 + 多步稀释——**边学进去了但走链读不出来**。解法（v15）：域内过滤（对话域 61 词）+ 配对直读（关系词）+ direct_next 直接传出突触。**教训**：读通路与写通路是两回事，W 里有边 ≠ 回响能读出来（呼应 3.12 唤起≠学习）。

### 6.15 超临界放电：痛觉信号引爆全局高频词风暴（2026-08-10）

v13.2「石头→痛→不要」建链后价值课判定 3 次全错：v(不要) 高达 26~56（超 θ=1.0 的 10~50 倍）却不发放，候选数每步指数增长（156→46671，σ~299 饱和）。三条件缺一不可：**高频词传出突触巨量 + 弱突触汇聚过阈 + WTA 满发 v 不复位**。三种修复（全局归一化/饱和度/减性抑制）均未通过——超临界是当前 WTA 全局抑制的固有弱点（学术短板见 §七）。

### 6.16 字形分解带偏词级走链（2026-08-10）

第一版贪心走链把「苹果」分解成「果→苹→小→子」；修复为词级走链（候选排除单字模式）后 苹果→水果→食物 ✅。**教训**：语义传递与字形分解共用同一 W 传出突触，检索必须按层级区分——这是双系统读出（3.16）的机制根因。

### 6.17 numba 提速三坑（2026-08-10，速度优化实验）

1. **argpartition 破坏 WTA 语义（实测 105 万边差异）**：并列 key 时 argpartition 与 argsort 的 top-k **集合**可能不同 → 发放分叉 → 网络演化连锁分叉。**top-k 语义 = argsort 的确定性选择，回退 argsort**（语义铁律优先，源码留注释）。
2. **pre_trace 衰减时序**：把衰减融进 WTA 内核会先于 STDP 读取衰减痕迹（p → decay×p）→ 阈值过滤 `> trace_thres` 的集合改变 → 语义分叉。衰减保留在 step 尾部（就地 `*=`，零分配），内核只做不应期 -1（候选判定用未递减值，与旧时序一致）。
3. **numba 首次编译延迟混入计时**：内核签名变更后 `@njit(cache=True)` 缓存失效，warm 只学 1 对不足以确认编译完毕——曾现 numba 版 37.86s vs 参考 6.90s 的假象；重跑（缓存已建）稳定 3.55s。对拍计时应"跑两遍取第二遍"。

## 七、学术审视

**机制全部经典**：LIF（Lapicque 1907）、WTA/侧抑制（Marr 1969/Olshausen 1996）、Hebbian（Hebb 1949）、树突室/深度树突（Beniaguev 2021）、干扰式遗忘（遗忘由干扰非时间衰减决定）、细胞组装/吸引子（Hopfield）、SPM（Hawkins HTM）、STDP（Bi & Poo 1998）、eligibility trace、多巴胺门控可塑性。

**组合层面是新的**：多槽显式结构缓解灾难性遗忘 + **表示并发**（槽位=通道，双槽并行互不串扰、并发学习更强 2.8×）、**零遗忘成长**（加法系统：只加不减覆盖）、**注意力=连接数量×边强度+gain**（v2.2 完整式）、**gain 调制**（欲望优先性：增益先天、边后天）、**RL 教学体系**（连接级归因处罚/LLM-as-Judge/判断内化/条件反射）、**双系统读出**（走链联想 vs 直接传出突触回答）、**结构收敛定理**（突触数上限=有效搭配空间）、频率门控慢衰减命题（用进废退、渐进可复活）、学习门（物理免疫篡改）、STDP 只强化正向（顺序自动区分）。

**短板**：
- 无严格归一化守恒（总量归一化为远期方向）
- WTA 是人为全局抑制（替代真实侧抑制）→ **超临界放电固有弱点**（高频词风暴，6.15 三种修复未通过）
- hub 连接爆炸：注意力瓶颈 = 连接数量（虚词枢纽 16.6 万传出突触），读通路需域内过滤规避
- 无容量理论（Hopfield ~0.14N 未对接）
- 单 seed 无统计严谨性（后续需多 seed 跑分布）
- 编码器缺失（现实→模式的稳定编码未实现）
- 判读必须读边强度而非唤起（唤起受注意力竞争污染）

## 八、容量与规模估算

- 参数量：`P = s × n²`（n 神经元 × s 槽 × 每槽 n 入连接）
- 模式占据神经元规模：≈ 输入脉冲规模（WTA 激活最相近 + Hebbian 反复锁定，不扩张）
- 7B 规模反推槽数：n=4096→s≈417；n=11008→s≈58；n=65536→s≈1.6（趋近单槽）
- 警告：参数量对齐 ≠ 能力对齐（单层递归记忆 vs 分层计算）；记忆容量按经历条目算（10⁶ 条 → n×s≈10⁷）
- Hopfield 容量 ~0.14N（记忆共享神经元、容量受干扰限制）
- **结构收敛定理**（2026-08-10 用户论证定案）：突触数上限 = 有效搭配空间 = **α·V²**（V 固定时与数据量无关）；V = 词表规模 = 突触数上限的平方根——文字有上限、组合有上限，数据再多结构不长
- **三层词表**：可能的词（组合空间 10³⁸）> 实际用的词（Heaps 定律，随语料亚线性增长）> 网络认识的词（内存墙：V² 反推，受内存约束）
- **1B 规模预测**（2026-08-10）：1B 边 ≈ 12GB 稳态（13B/边 × 1B）；1B 神经元 ≈ 100GB（需状态稀疏化）；路线 = n 控制小、边随经历长（结构收敛下 n 不随数据膨胀）
- **饱和分层与终极形态**（2026-08-10，结构收敛的深化——举一反三把"饱和点"提前到模式空间）：
  - **分层**：实例空间（10³⁸ 组合，无限）← 举一反三自动填充 ← 模式空间（有限定式，如 X是Y、Y是Z→X是Z）← 数据覆盖 ← 网络结构（α·V² 边）
  - **饱和点提前**：没有举一反三时"补齐海量"= 喂满实例空间（永远喂不完）；有了验证门/走链泛化，饱和点提前到**模式空间**——每模式只需几个实例，举一反三填充整个实例类（实证：SVO 400 组从未整句训练 100% 通过、鸟→动物→生物 零共现、麒麟→瑞兽→神兽 外推、验证门摘除中间项仍通）
  - **饱和三阶段**：前饱和（每句长新边）→ 饱和点（模式覆盖完，新增数据不再长边，实测 1000 词≈12 万边收敛）→ 后饱和（纯使用：走链/对话/推理只消耗边）
  - **后饱和三后果**：① 结构稳定 → 可放心梯度精调（Phase 4：Hebbian 预训练 + 结构不动，梯度只调平局处）② 从统计猜测变**确定性走链**（边存在 = 路径存在 = 知道）③ hub 竞争成主矛盾（连接数量爆炸，gain/域内过滤从优化变必需品）
  - **效率结构性差距**：大模型为实例分布付账（10⁹ tokens 起步、永不收敛），定式网络为定式付账（模式空间有限、一次搭好终身复用）——效率差从 10⁵ 量级进一步拉向"模式空间/实例空间"的结构性差距
  - **两个天花板**：① V 的内存墙（饱和边域限于认识的词；v14 字级 OOV 用字拼词推高 V，但天花板仍在）② 泛化有前提（验证门拒绝错误链 0.0→0.0，举一反三是逻辑前提内泛化，非无边界外推）
  - **终极形态**：把语言组合定式长满、对定式内任意合法路径举一反三、结构稳定到可放心精调的单机网络——知识不是"记得多"，是"**组合空间里没有走不通的合法路径**"

## 十一、AAA 记忆系统（低频时间尺度）详解

> 关联代码：`nodes/node_python_aaa_cognition/`（main.py / listener.py / db.py / memos.py / memory_provider.py / personality.py / review.py / diary.py / prompt.py / parser.py / retrieval_gate.py / session_manager.py / location.py / entity_attr_checker.py）
> 在系统中的地位：与定式网络**同属一个系统**的**低频时间尺度**工作方式（见 §一 1.1）——训练/沉淀时更新结构，脉冲频率低于定式网络（每步）
> 关联节点：`nodes/node_python_llm_infer/`（LLM 推理，cloud/deepseek）；拓扑见 `pipeline.json`

### 11.1 定位：不是认知引擎，是记忆与人格的中枢

AAA（`node_python_aaa_cognition`，BNOS 认知节点）官方定位是**"提示词拼接站"**——**不做推理、不做决策**（推理在 LLM 节点），它是"数据搬运工 + 格式化工具"：收集上下文、拼 prompt、发 LLM、回收节标记文本、解析并路由、并行写 DB（所有持久化）。工程上已演进为**认知/记忆中枢**：MemOS 语义检索、自我反思、日记、认知反思（Review）、会话摘要、人格演化、情绪管理、定位感知全套能力。

- **拓扑**（pipeline.json）：aaa_cognition ↔ llm_infer（prompt 出 / 回执入）；aaa_cognition → tts（reply）；GUI 经 `shared/gui_input.json`、`gui_reply.json` 直连
- **输入分流**（main.py process()）：text/gui（用户文本）、text/parsed/llm（LLM 回执）、text/parsed/diary（日记回执）、text/parsed/review（反思回执）、pool_batch（消息池批量）、tool_result、interrupt、db_command、switch_conversation
- **输出端口**：prompt / diary_prompt / review_prompt → llm_infer 对应端口、reply → tts / GUI、logseq → 知识归档 + 语义关联、default → 状态回执
- **通信机制**：packet 协议 `{"code", "type", "data"}` + listener 文件轮询（mtime + MD5 去重、`_processed_` 标记防重、线程池并发）

### 11.2 核心数据流（单轮对话）

**用户输入 → `_on_text`**：写 user_messages → 用户反应信号采集（打断/否定 = 负反馈）→ 日记检测（次日首条对话写昨天日记）→ 记忆预取（`retrieval_gate` 门控，默认每轮强制；MemOS top5 + `<memory-context>` 安全标签 + 凭据脱敏）→ 上下文收集（身份/自我认知/固定认知/感受/情感基调/他人认知/位置/人格/情绪/记忆检索/会话摘要全注入）→ prompt → llm_infer。

**LLM 回执 → `_on_parsed`**：节标记解析（parser）→ **分表沉淀**（db.write_parsed_async，fire-and-forget 不阻塞链路）→ 性格演化观测（回复风格 → 人格向量）→ 每 N 轮后台 Review → 每 10 条自我认知反思 → MemOS 索引 / 知识图谱 / 情感聚合后台重建 → reply 输出（带 `<心情>` 标签）。

### 11.3 记忆机制：结构化记忆（19+ 张表按语义分型）

| 表 | 用途 | 关键字段 |
|---|---|---|
| user_messages | 原始对话（user/assistant） | role/content/user_id |
| feelings | 心情 + 想法（意识流） | mood/thought |
| event_summary | 事件摘要（source='seed' 为初始背景记忆） | summary/source |
| self_cognition / other_cognition | 自我 / 他人认知（含 [沉淀]/[程序性记忆] 标记） | content |
| user_facts | 用户事实（background / preference） | category/content |
| self_info | 自我键值对（如 last_diary_date、人格属性） | key/value |
| **long_term_memory** | **记忆检索主源** | importance / decay_date / source_confidence / entity / status |
| fixed_cognition | [固定] 标记的自我认知（全局共享不隔离） | key/value |
| mood_trend / mood_value | 每日情感聚合 / 情绪数值曲线 | — |
| diaries | 日记 | date/content/mood |
| location_history | 定位历史（v5.0 从长期记忆迁出） | 经纬度/城市/精度 |
| personality_seed | 四维人格向量 + 风格描述 | warmth/playfulness/directness/curiosity |
| session_summaries | 会话级结构化记忆 | session_id/summary |
| entity_attrs | 实体-属性强绑定（防 LLM 摘要互相污染） | entity/attribute/value |

- **沉淀触发点**：每轮 LLM 回执必沉淀（12 节 → 对应表）；每 review_interval（默认 5）轮 Review 提炼 self / declarative / procedural 三类洞察（置信度 ≥0.7、命令句式过滤、同 key 至少 2 轮频次门槛）；每 10 条自我认知触发反思；每天一次日记（次日首条触发，状态持久化防重启丢失）；会话切换生成摘要；上下文超阈值压缩前抢救含"我喜欢/记住"关键词的消息到 long_term_memory
- **向量检索（MemOS，memos.py）**：SentenceTransformer（all-MiniLM-L6-v2，384 维，HF 镜像）→ numpy 暴力余弦检索 + `.npz` 索引持久化（增量重建）；只索引 long_term_memory + diaries 两个数据源（避免双源）。**检索质量工程**（针对小模型中文语义坍塌的补偿）：importance 弱加权（+0.02/级）、exchange 回放降权（-0.10）、query 逐字命中惩罚（×0.2）、中文双字 gram 提权（+0.4 上限）、importance≥5 高重要记忆无条件进候选、score<0.3 过滤、identity_key/user_id 归属隔离、status=active 过滤
- **记忆生命周期**：Jaccard >0.80 去重、importance≥4 且 >0.5 补充式合并、importance 1-5 映射过期天数、self_info 去重+同 key 覆盖+上限 100 条——**记忆不是一串聊天记录，而是带类型、带重要性、带生命周期、带归属的结构化条目**

### 11.4 人格机制：种子 + 演化 + 沉淀

- **存储**：personality_seed 四维向量（warmth/playfulness/directness/curiosity 默认 0.6/0.4/0.5/0.5）+ style_description + preset_name（默认/温柔型/理性型/毒舌型/活泼型预设）；无记录回退默认种子
- **演化（PersonalityEvolution，确定性计算、LLM 不参与）**：慢变量——情绪驱动触发（连续 10 次情绪均值 \|x\|>0.3 或方差>0.15）或每 10 次交互兜底 → 差距驱动微调（观测风格 vs 当前向量，学习率 0.06、单步限幅 ±0.02）→ 写回 personality_seed
- **反馈信号**：打断标志 + 否定句检测（负反馈）；每次回执回复风格观测（中性反馈）
- **情绪快变量**：LLM 输出【情绪调整】（clamp ±0.2）→ 阻尼回归 0.98 + 单步限 ±0.05 → mood_value 逐次记录、mood_trend 聚合
- **人格沉淀双通道**：① PersonalityEvolution 写回向量；② Review 高置信自我属性 → self_info + `[沉淀] key=value` 写入 self_cognition——人格不靠一次性设定，而是"种子 + 演化 + 沉淀"三源合一
- **身份隔离**：identity_key（默认 gui:default）贯穿所有读写；v6.0 起 user_id 多用户认知隔离（用户专属优先、全局兜底）；[固定] 标记全局共享不隔离

### 11.5 LLM 调用：完全复用 llm_infer（AAA 零内嵌 API）

AAA 把 prompt 写入 output 文件（output_prompt / output_diary_prompt / output_review_prompt），llm_infer（model_type=cloud，deepseek）按端口消费、回执写回。**prompt 结构**（prompt.py DIRECT_TEMPLATE）：固定上下文段（身份/自我认知/固定认知/感受/情感基调/他人认知/位置/人格/情绪/`<memory-context>` 记忆检索/会话摘要）+ **输出格式硬约束**——每行一个【节标记】：自然回复 / 心情 / 想法 / 情绪调整 / 事件摘要[重要性:1-5] / 自我认知 / 他人认知 / 用户信息 / 自我信息 / 用户记忆 / 环境记忆 / 实体名 / 归档标签。**本质：每轮对话让 LLM 既回复又"自白"**——回复文本 + 心情 + 内心想法（静默也输出）+ 情绪调整 + 各类认知/记忆沉淀。

### 11.6 沉淀 / 回忆的频率与触发（与高频侧对比）

- **无任何定时任务线程**，一切由**事件驱动**（消息到达）或**轮次计数**驱动
- 回忆：每轮对话事件驱动一次预取（门控默认 off = 每轮强制）；回执后再做一次归档内容的关联检索（logseq 输出用）
- 沉淀：每轮必沉淀 + 每 5 轮 Review + 每 10 条反思 + 每日日记 + 会话切换摘要
- 频率均可配置：review_interval / max_history_summary / retrieval_gate / location_update_interval（node_config.json）

**与定式网络的时间尺度对比（v3.1 修正）**：二者不是层级关系，而是**同一系统的高频/低频两种工作方式**——定式网络**每步**完成一次脉冲周期（每次交互更新结构，最高频），AAA **每次沉淀**完成一次向量写入（事件驱动、无定时任务），大模型**周期性**权重更新/摘要（最低频）。频率递减，角色互补：持续适应（高频侧）/ 结构化记忆与人格沉淀（低频侧）。

### 11.7 与总结文案的对应（2026-08-10 定稿）

| 文案 | AAA 实现 |
|---|---|
| 每次沉淀 | 每轮回执分表写入（fire-and-forget）+ 多层次沉淀节奏（Review/反思/日记/摘要/压缩抢救） |
| 结构化记忆 | 19+ 张表语义分型 + importance/decay/entity/status 元数据 + 去重合并 + 会话级摘要 |
| 人格沉淀 | 四维向量演化（PersonalityEvolution） + Review 沉淀双通道，随使用自然演化 |
| 向量相似度脉冲 | MemOS 语义检索（每轮预取 top5，重要性加权 + 回放降权 + 中文 gram 提权） |
| 低频侧（间歇更新） | 事件驱动（每次沉淀），低于定式网络的每步更新 |
