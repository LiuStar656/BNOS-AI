## 一、背景与定位

**当前状态**（语言验证已通过）：
- 定式网络（SchemaNet）已具备**最小 next-token 预测**能力：STDP 教学式学习把语料词序沉淀进 W，W聚合读出 0.500 ≈ bigram 0.526，留出句 0.087 与 bigram 持平
- 已确认的机制：反复经历形成定式、多槽存储隔离、满槽覆盖、学习门、STDP 时序、教学式学习、学习/回忆路径分离
- 编码契约：crc32 稳定稀疏模式（n=2048, k=8，碰撞对 6/10011）

**方向**（用户决策 2026-08-08 明确，2026-08-09 排除吞并）：**让定式网络自己成为大模型**。核心论证：LLM 的本质 `P(token_t | token_{<t})` 与已验证的 STDP 转移学习同构，缺的是**规模**、**生成**、**长程上下文**三根支柱。2026-08-09 方向调整：**不走外挂吞并路线**，定式网络自身逐步长出大模型能力——规模、上下文、生成、**学习能力**四根支柱全部由定式网络自主进化获得。

**实现形态**：扩展 `schema_net.py`，继续复用 CONFIG/留档机制与顶层 `schemanet/` 目录；每阶段独立留档验收。

## 二、方向理解：往大模型发展 = 三支柱 + 学习能力升级

```
                    ┌────────────────────────────────────────────┐
                    │           往大模型方向的三支柱              │
                    │  ① 规模     → n、词表、语料数量级扩展       │
                    │  ② 上下文   → 一元 → 多词条件转移（trigram+）│
                    │  ③ 生成     → 词袋 → 采样解码 → 完整句     │
                    └────────────────────────────────────────────┘
                                   │
                    ┌──────────────┴──────────────┐
                    │     自主进化主线（v1.1 调整）  │
                    │  ④ 学习能力 → 无梯度 Hebbian │
                    │              → 梯度在线学习   │
                    │              （核心跨越）      │
                    │  ⑤ 表示深度 → 时间深度→槽级联 │
                    │              → 层级抽象（远期）│
                    └─────────────────────────────┘
```

**核心认知（2026-08-09 方向调整，去吞并）**：定式网络走**自主进化路线**——不依赖外挂 LLM，由定式网络自身逐步获得大模型能力，四根支柱（规模、上下文、生成、学习能力）全部自生长出。其中 **④ 学习能力升级（无梯度 Hebbian → 梯度在线学习）是"自己成为大模型"的核心跨越**：Hebbian/STDP 学得动"反复经历形成定式"（共现、转移），学不动复杂函数（组合、长程依赖、泛化）——当前表达能力天花板 = bigram/trigram 级。让定式网络获得**参数级梯度学习**能力，才能突破定式层、进入真正的大模型表达域。原方案远期 Phase 5 的梯度在线学习提前为主线目标。表示深度（⑤）由 Phase 2 数据结果驱动，不预设 Transformer 式多层（无梯度多层是研究难题，先走时间深度/槽级联的"伪深度"）。

## 四、Phase 1：上下文升级（bigram → 多词条件转移）

### 4.1 动机

当前 W聚合读出只用**前缀末词**做条件（一元上下文，等价 bigram）。trigram 基线（二元上下文）训练 0.383 反而更低，是因为二元对数据稀疏（多数 (a,b) 对出现 1 次）。**正确路线不是无条件上 trigram，而是用定式网络已有的痕迹机制做上下文插值**。

### 4.2 方案：痕迹插值读出（trace-interpolated readout）

复用已内建的 `pre_trace`（eligibility trace）机制——评估时注入前缀后，pre_trace 天然保留各前词的衰减痕迹（距离越近痕迹越强）。**用痕迹向量调制 W 读出**：

```
P(w_t | w_1..w_{t-1}) ∝ Σ_i trace(w_i) × W[w_t ← w_i]
```

- 实现：`_predict_cands_trace(ng, prefix, ...)` —— 前缀逐词注入（复用 `_evoke_prefix` 的前半段），取最终 `ng.pre_trace`（各前词衰减痕迹）→ 对每个候选词聚合 `Σ_i trace_i × W[j, 0, pats[w_i]]` → argmax
- **不做额外学习**：W 保持二元转移，插值在读出层完成（≈ n-gram 线性插值平滑的语言学对应）
- 距离权重由 `trace_decay` 控制：0.5 → 相邻词权重 2 倍于隔一词，天然实现"近词主导、远词辅助"
- 与现有读出共存：新增 `readout="trace"`，对照 echo/wsum 评估

### 4.3 预期与验收

- 训练集准确率：W聚合 0.500 → trace 读出**≥0.55**（上下文插值吃掉"喜欢"后 15 宾语平局的一部分不确定性）
- 留出句：不退化（≥0.087）
- 具体句式验证："我喜欢吃" → 香蕉（吃 的宾语），"我想看" → 电影——二元上下文消歧的典型样例
- 对照：bigram / trigram / trace 三表同口径

### 4.4 风险

- 痕迹插值可能被高频词痕迹淹没（"我"痕迹强、主导读出）→ 可加"痕迹归一化"（痕迹÷该词总频）
- trace 只保留衰减痕迹，长距离（>3 词）上下文贡献趋零 → 本阶段目标是 trigram 级，长程留 Phase 4（LLM 兜底）

## 五、Phase 2：规模扩展（真实语料 + 大 n + 稀疏存储）

### 5.1 动机

当前 100 句/142 词/n=2048 只能验证机制。往大模型方向必须有数量级：**语料万句级、词表 2k-5k、n=8192+**。这是"规模支柱"。

### 5.2 方案

| 维度 | 当前 | Phase 2 目标 | 要点 |
|---|---|---|---|
| 语料 | 100 合成短句 | 10k-50k 句真实中文 | 数据源见「关键决策点 D1」 |
| 词表 | 142 | 2k-5k（top-K） | OOV 计数 + 映射"未知"模式 |
| n | 2048 | 8192（可调 16384） | 区分度 k²/n 保持 ~0.03 → k=16 |
| k | 8 | 16 | 词模式更大、抗碰撞 |
| W 规模 | 2048²×4×4B=64MB | 8192²×4×4B≈1GB | 必须稀疏存储（见下） |
| seed | 单 | 5 个 | 统计严谨性 |

**稀疏存储（关键工程）**：
- Hebbian 只强化共现对 → W 非零连接稀疏（预计 <5%）
- 存储：W 按"入连接"切分，每神经元每槽一条 `scipy.sparse.csr_matrix` 行（或整体 `dok_matrix` 增量构建 + 周期转 csr）
- 运算：`W @ spikes` 与 STDP 写入全部走稀疏路径，内存目标 **<200MB**
- 学习/评估复杂度：O(句数×句长×k²)（每词注入只碰词模式相关行），与 n 弱相关——这是稀疏表示相对稠密矩阵的核心优势

### 5.3 验收

- 万句级学习时间可接受（分钟级）；内存 <200MB
- 大规模下 W聚合 ≥ bigram（不退化），且词表扩大后未见性能崩塌（编码区分度预检碰撞对 <1%）
- 多 seed 结果分布报告（均值±std）

## 六、Phase 3：生成与解码（已完成，2026-08-09 验收通过，留档 runs/20260809_055328）

### 6.1 动机

当前 `_generate` 是 argmax + 防循环，两步后漂移（词袋级）。往大模型方向需要**概率解码**与**流畅性**。

### 6.2 方案

- **解码策略**：top-k 采样 + 温度 + 重复惩罚——从梯度读出（train_w 精调后的 `_logits_w`）分布采样，替代硬 argmax。**最终调优参数（2026-08-09）：top_k=12、T=1.1、penalty=2.5**（penalty 1.2 起步时高频词重复退化，2.5 修好）
- **生成停止条件**：句末词（学到"句尾模式"）或长度上限 + 最大重复兜底
- **评分**：BLEU（vs 语料原句）+ 人工流畅度 5 分制；与 bigram 采样生成对照（诚实定位）
- 生成质量目标：短句（≤10 词）流畅度 ≥ 3/5（人评）；**不追求超越 LLM**——生成是定式网络能力的展示，不是替代品

### 6.3 验收

- 20 条生成样例人工评估报告
- 与前缀一致性：生成句开头 n 词与条件前缀一致

### 6.4 验收结果（已完成，2026-08-09）

- **自动判定全过**：前缀一致性 20/20 PASS；W 结构不变（nnz 1208003→1208003）PASS；BLEU-2 参考 0.255（贪心续写对 top-k 采样无区分度，仅作参考）
- **人工流畅度 3.7/5，达标（≥3/5）**：20 条生成样例 AI 代打 5 分制。grad 主引擎流畅（"我喜欢吃香蕉很幸福因为太累了"、"我想学游泳和做实验在海边但是朋友推荐" 等 5 分样例）；trace/wsum 静态读出对照乱串（"我在医院餐厅跑步咖啡馆得实验室因为想"、"我觉得这个方案真好笑不好音乐和骑"）
- **引擎对比**：生成 = 梯度读出（`_logits_w`）采样 vs wsum/trace 静态读出——grad 明显更流畅，"会学也会说"闭环达成
- **训练耗时**：train_w 初版 373s → numpy 镜像向量化 11.8s（31×），信任分布/扰动逐位一致（详见 §7.2.2 提速记录）

### 6.5 有偏语料验证（Phase 3+，已完成，2026-08-09 验收通过，留档 runs/20260809_064139）

**动机**：Phase 2 发现②——uniform 合成语料（corpus_large）是 trace/grad 的最不利场景（平局率最大化）。真实有偏语料下 trace 借主语痕迹破局、梯度学主语-宾语关联的增益属悬案。本阶段自建有偏语料一次验证（详见 [REPORT]-定式网络有偏语料验证实验报告.md）。

- **语料**：`data/corpus_biased.json`（15100 句，三层偏斜：词频 Zipf + 模板权重 + **主语→宾语偏好关联**）。12 主语 top1 偏好互异（我→看书/他→打/她→画画…）→ 合并视图"喜欢"后继近似平局（跑步305/打278/旅行248/画画226/跳舞226，归一化差 ~0.01 < delta_off 0.02）、按主语分组明确（他→打120/她→画画128）。词表 504、succ_entropy_norm 0.425→0.382
- **top-1 留出（3020 句）**：wsum 0.2816 / trace 0.2275 / **grad 0.3281（+0.047 超 wsum，达标）**——梯度参数化在有偏语料上兑现增益
- **trace 定性为无参数启发式上限**：β 扫描（0.1→1.0）放大无帮助反而更差（0.2359→0.2111）——机制性局限（主语痕迹弱 + 主语传出突触被高频动词"喜欢"稀释，P(宾语|主语)≈0.1 盖不过合并优势 0.31），非参数未调优。**trace 定位回归"无参数兜底"，破局主力 = 梯度（ctx_wgt 可训练位置权重 pos1=1.98）**——Phase 4 决策"梯度为第二阶段"的实证支撑
- **生成退化（2.05/5）**：根因语料模板化（问句模板占比 14/189，"吗"高频 + 噪声污染句尾词传出突触 → "吗吗"重复；短模板拼接无整体语义），非引擎退化——开源真实语料应显著改善（C 路线第二阶段）
- **工程改进**：trace 评估增量版（O(len²)→O(len)）+ 重放版 refractory 跨调用残留隐 bug 修正（对拍 noise_p=0 逐位一致）；回归 abc 9/9、seq fwd=1.0 全绿

### 6.6 开源真实语料规模验证（Phase 3+，C 路线第二阶段，已完成，2026-08-09，留档 runs/20260809_085940 + runs/20260809_093405）

**动机**：b 阶段（有偏语料）证明 grad 增益机制，但语料是自建模板（句长 ~4、句式重复），生成 2.05/5。本阶段验证真实语料（长句、高熵、无模板）下 trace/grad 是否还增益、生成是否随语料真实度改善（详见 [REPORT]-定式网络开源语料规模验证实验报告.md）。

- **语料**：`data/corpus_open.json`（20263 句，4 源混合：外卖/酒店/商品评论 + 头条标题；词表 3000、句长均值 14.3、UNK 16.6%）
- **工程**：词表 3000 下评估提速——`build_score_mat` S[V,V] 矩阵（72MB）纯 numpy 直读替代 Python 传出突触循环（对拍逐位一致）；trace 增量版保留动力学注入骨架
- **c3 第一版（runs/20260809_085940）**：train_w 过拟合 → 信任分布 `[0,0,0,0,0,0,0,8.2953]` 全压最远端 pos7 → **grad 生成全部仅 1 词（20/20 退化）**。根因链：真实语料均长 14.3 → 远端信号天然占优 → train_w（lr=0.05/10ep、无归一化）把信任冲上极值；生成前缀短（1-4 词）时 pos7 不可用 → logits 全零 → 立即停止
- **变体重跑（runs/20260809_093405，批准）**：跳过 train_ctx（省 25 分钟）+ 均匀初值 + lr=0.02/5ep + 训后归一化 → 信任恢复 `[0.155, 0.344, 0.118, 0, 0.189, 0.029, 0.048, 0.119]`（近端主导）→ **grad 生成恢复完整句（BLEU-2 0.000→0.010）**——根因链闭环验证
- **top-1 留出（600 句）**：wsum 0.1081 / trace 0.0979 / grad 0.0764——**三路均不超 wsum，增益项 FAIL**。真实语料后继熵极高，位置信任学到的是"长上下文可用"而非"哪个具体词"，无法转成 top-1 增益；wsum（末词直接传出突触）是最稳基线——**"梯度学到 Hebbian 学不动的东西"在有偏语料兑现、真实语料不兑现**
- **生成质量整体低（AI 代打 ~1.5/5）**：沿语料梯度单调 uniform 3.7/5 → 有偏 2.05/5 → 真实 1.5/5——生成质量与语料"结构度"正相关、与"真实度"负相关；UNK 16.6%（OOV 占位）是最大句法破坏源
- **方法论注意**：trace 评估注入走 train_w 扰动后 W、读出走训练前 S（口径混用，跨版数字不可直接比），后续统一口径
- **结论**：真实语料规模验证完成（标准档），wsum 最稳基线坐实；梯度读出的价值在"条件预测"而非短前缀续写，定位待 §七 Phase 4 路线再评估

### 6.7 频率门控慢衰减机制（记忆管理升级，已纳入，2026-08-09 验证通过，留档 runs/20260809_103532）

**背景**：2026-08-09 用户拍板**废除 slot_cap 满槽覆盖**（写时挤最弱），改为**频率门控慢衰减**——低频唤醒槽位的连接不删除、逐步衰减为 0（渐进、可复活、用进废退）。废除后它是 W 唯一的回收通道（详见 [PLAN]-定式网络频率门控慢衰减机制设计方案.md，v0.2）。

**实现**（sparse_net.py `slot_freq` 计数 + `sleep_consolidate`）：唤醒计数只数发放神经元主导槽（静息 argmax 不污染）；低频槽连接每周期 ×(1-decay)，≤eps 删除条目（稀疏回收）；learn_gate=False 冻结态拒绝执行（物理零改动）；活跃槽（≥min_wake）永不衰减。

**Phase 2 最小验证（_accept_prune.py，12/12 PASS）**：活跃槽不动（3840→3840）、低频槽 ×(1-0.3) 精确衰减、**衰减中复习可复活**（138.32→3840 回升）、归零删除回收（0.0002→首周期 0.00014 保留→次周期 0 删除）、冻结拒绝（返回 0 零改动）、静息 50 步计数不增长。

**Phase 3 语言接入（最终验证，runs/20260809_103532，模型已保存 net.npz）**：Hebbian 预训练（20263 句，394.6s）后 sleep 整理——min_wake=P10 唤醒分位（109），弱化 100.6 万条低频连接（5.56%）；单周期衰减 30% 未达 eps 故删除 0（多周期才归零，符合渐进设计）。**验收口径升级：W 结构不变 → 活跃保留（top-1 不退化）+ 低频回收率报告**。结果：留出 top-1 三路不退化（wsum 0.1081 / trace 0.0970 / grad 0.0778 vs 无 sleep 版 0.1081/0.0979/0.0764）；前缀一致性 20/20；W 结构不变（nnz 18093945→18093945）；回归 abc/seq 全 PASS。

## 七、Phase 4（核心跨越）：学习能力升级——梯度在线学习

### 7.1 动机

定式网络当前的学习 = 无梯度 Hebbian/STDP：学得动"反复经历形成定式"（共现、一步转移），**学不动复杂函数**（组合、长程依赖、泛化）——表达能力天花板 = bigram/trigram 级。**"自己成为大模型"的核心跨越，是让定式网络获得参数级梯度学习能力**（原远期目标提前为主线）。无梯度（Hebbian）与梯度（在线学习）双轨并存：Hebbian 快、便宜、保持定式动力学；梯度准、贵、突破表达域。

### 7.2 方案：Hebbian 预训练 + 稀疏梯度在线微调

```
Phase 2 语料 ──Hebbian（教学式）──→ W 沉淀先验（共现/转移定式，0.1% 非零）
                    │
                    ▼
            softmax 读出层（W 转移 → 条件概率分布）
                    │
                    ▼
        梯度在线微调：交叉熵损失 → 稀疏梯度只作用 W 非零子集
                    │（学习门 learn_mode 扩展为 hebbian / grad / dual）
                    ▼
            定式网络具备参数级学习能力（保留定式动力学）
```

- **4a 梯度读出层**：W 转移强度 → softmax（温度可调）→ 交叉熵损失。读出层参数与 W 一起可训
- **4b 稀疏梯度**：W 非零率 0.1%，梯度只更新非零子集（稀疏梯度，内存/时间 O(非零)）——**保留定式网络的动力学**（多槽/封存/门控/痕迹全不动），梯度是"能力增强"而非"结构替换"
- **4c 双轨学习门**：`learn_gate` 扩展为 `learn_mode ∈ {hebbian, grad, dual}`——Hebbian 快（共现定式实时沉淀）、梯度准（复杂模式离线/在线精调）、dual 按场景切换
- **4d 灾难性遗忘防护**：梯度微调前 W 快照 + 封存隔离 + 学习门（梯度只在指定窗口开）——Hebbian 已沉淀的定式不被梯度洗掉

### 7.2.1 Phase 4a 可行性实验（已完成，2026-08-09 验收通过）

**目标**：花最小成本验证"定式网络获得参数级梯度学习能力"可行，回答两个问题——
① 梯度能精调 Hebbian 已沉淀的转移吗（微调 W 非零子集）？**✓（exp1：0.4935 ≥ trace 0.4805，W 非零结构不变 18090→18090）**
② 梯度能学到 Hebbian 学不到的东西吗（可学习上下文权重 vs 固定 trace 权重）？**✓（exp2 ctx 语料：信任分布学到 pos1=0.0547，微验证 8/8 破平局，留出 0.6022 > trace 0.5914 > wsum 0.5806）**

**机制（纯 numpy，零外部依赖）**：
- 前向（可微读出）：`logits[w_t] = Σ_i ctx_wgt[i] × score[w_t ← w_i]`，`score[w←src] = Σ_{j∈pats[w]} W[j,0,src]/k`；`softmax(logits/T)` → 交叉熵
- **梯度天然稀疏**：`score` 只在已有连接处非零 → `∂L/∂W` 只在 W 非零位置有值 → 稀疏性自动保持（新增连接永远无梯度，W 结构不动 = 定式动力学保留）
- 参数：W 稀疏非零项（可冻结/可微调）+ `ctx_wgt`（V 维可学习，替代 trace 的固定 β 权重）
- 优化：SGD（纯 numpy），留出集早停

**实验 1（精调验证）**：corpus.json（100 句，n=2048）——Hebbian 预训练 → 梯度微调 W 非零 + 读出温度 → 训练/留出 vs 纯 Hebbian wsum/trace
**实验 2（能力验证）**：corpus_large.json（1814 句，n=8192）——**对标 Phase 2 发现的 trace 失败场景**（均匀分布平局率最大化）：梯度训练 `ctx_wgt`（W 冻结）能否超过固定 trace 权重（0.280）甚至 wsum（0.384）？能 → 梯度学到了"该信任哪个上下文词" = 对 Hebbian 读出（固定权重）的实质能力增量

**验收（Phase 4a 通过标准）**：
- 实验 1：微调后训练/留出 ≥ 纯 Hebbian（不劣化），且 W 非零结构不变（稀疏性保持）
- 实验 2：梯度 ctx_wgt 模型 ≥ 固定 trace，且能与 wsum 对比出结论（持平或更好）
- 开销报告：梯度训练时间/内存 vs 稠密 W
- 回归：abc/seq 全绿（梯度只作用语言 W，静态实验不受影响）

### 7.2.2 Phase 4 完整落地（已完成，2026-08-09 验收通过，留档 runs/20260809_042441）

**双轨落地形态**：`grad_readout.py`（GradReadout 可复用读出/学习层，纯 numpy）+ `_accept_grad.py`（完整验收编排）。定式网络本体（SparseSchemaNet）保持纯动力学层不动，梯度学习作为独立读出层持有网络引用——4c 双轨学习门（hebbian/grad/dual）与 4d 灾难性遗忘防护（snapshot_w / restore_w / nnz / w_delta）由该层编排。

**训练流程（三段链）**：
```
语料 → Hebbian 教学式预训练（沉淀二元转移定式，快）→ train_ctx（冻结 W 快速路径，
S 矩阵预计算，只训位置信任 ctx_wgt）→ train_w（稀疏梯度只更新 W 非零子集 + ctx_wgt，
W 结构不动 = 定式动力学保留）
```

**关键发现 1：ctx_wgt 初值决定远端信任能否学起来（死锁与破局）**。远端位置权重 ctx_wgt[pos] 初值太小（trace 等效 pos3=0.006-0.07）→ 该位置 W 的梯度更新 ∝ ctx_wgt[pos]（`g = cw × g_n`）→ 极小 → W 词级不分化 → 位置梯度信号持续弱 → 死锁；均匀初值（pos 全 1.0）打破死锁：大初值 → W 大更新 → score 分化 → 位置梯度增强 → 正循环。

**关键发现 2：配置按场景敏感（近程/长程不同），非万能超参**（实验证据，两种配置微验证均 8/8 全中）：
- **近程**（ctx 距末词 1 位，corpus_ctx）：ctx_init = train_ctx 结果（pos1=0.17 起步）+ 100ep → 信任 [0.57, 1.81, 0, 0, 0]，pos1 净涨。均匀初值反而压死 pos1（末词 W 修正可自足时远端信任多余）
- **长程**（ctx 距末词 3 位，corpus_long）：ctx_init = 均匀 [1,1,1,1,1] + 200ep → 信任 [0.73, 0, 0, 1.08, 1.0]，pos3 学起。train_ctx 起步时 pos3=0.037 死锁
- **机理**：梯度优化整体 logits——若末词 W 修正即可满足训练样本，远端信任被压（近程）；若末词后继本质平局、必须靠远端 ctx 转移，远端信任保留（长程）

**关键发现 3：梯度词级修正 Hebbian 的 WTA 噪声**。corpus_ctx 中"热/冷"词频对称（36=36）但 Hebbian 沉淀后 `score(热,天气)=144 > score(冷,天气)=112`（WTA+噪声导致 ~28% 不对称偏置）——纯位置加权无法纠正（`冬天天气→冷` 猜错）；train_w 按交叉熵直接修正 W 非零连接（如"冷←冬天"增强、"热←冬天"削弱），破局成功。**"梯度学到 Hebbian 学不动的东西"在此具象化：Hebbian 只能按共现频率沉淀，不能按任务目标修正统计噪声；梯度可以。**

**验收结果（五项全过）**：
- ① 小规模超 Hebbian（corpus.json，100 句，n=2048）：训练 0.5325 > bigram 0.526（lr=0.05/100ep 突破上界；lr=0.5 长训震荡发散），留出 0.087 不劣化，W 非零 18090→18090 结构不变，扰动 12552/18090
- ② 条件组合（corpus_ctx，n=8192）：grad_test 0.6022 > trace 0.5914 > wsum 0.5806；微验证 8/8（"冬天天气"→冷、"晚上吃饭"→饱 等 4 例破 wsum 平局）；pos1=1.81；W 扰动 9588/147064
- ③ 长程关联（corpus_long，n=8192）：grad_test 0.7209 > wsum 0.7093 > trace 0.6163；微验证 8/8（"秋天的风很"→干燥、"妈妈喜欢在厨房"→看书、"早上常常在客厅"→跑步 等 4 例破局）；pos3=1.08；W 扰动 11779/154584
- ④ 开销：S 矩阵 V×V（词表 21-27 → 内存 <0.1MB，占稠密 W 2147MB 的 0.0002%）；train_w 时间 42s（近程）/211s（长程，200ep），无额外内存（稀疏梯度动态算 score）
- ⑤ 回归：abc 9/9、seq fwd=1.0/rev=0.0 全绿（子进程独立跑，梯度不影响静态实验）

**语料修正（2026-08-09）**：corpus_long 组3/4 原模板"在家"被 jieba 合并成整体词（"在""家"不在词表 → 微验证前缀失真），改为"在厨房"/"在客厅"（`[爸爸,喜欢,在,厨房,做饭]` 5 词，ctx 距末词 3 位成立）。

**train_w 提速记录（2026-08-09，31×）**：Phase 3 生成调参时 train_w 全量 373s 是最大瓶颈。**numpy 传出突触镜像**：把 `ng.W_out[i][0]` 每神经元传出突触转成 `_edge_dst[i]`（目标数组）+ `_edge_w[i]`（权重数组），`_grads` 的 dW 累积用 fancy-index 向量化（`gi += cw * g_n[dst]`），`_apply` 用 `w -= lr * gi` + `np.clip`——语义与 dict 版逐位等价，**train_w 373s → 11.8s（31×）**，信任分布 [4.6373, 0, 0.3934, 1.0354, 0.0661] 与扰动（max 9.55, 480909/1208003）与原始 dict 版完全一致 → Phase 4 验收无需重跑。**mini-batch SGD 三试皆弃**：① 梯度平均 → 有效 lr 缩水 32×，扰动 9.55→0.16、top-1 0.3268、BLEU 0.173 < wsum 0.193（生成退化）；② 不平均 + lr×32 → ctx_wgt 发散到 28.6（过冲）；③ 平均 + lr×B → 子集 top-1 仍 -3pt（**根因是 S 矩阵快照 epoch 内过期**，与 batch 无关）。结论：**batch 化不如镜像向量化**（零语义变化，在线 SGD 顺序依赖也保留）。

### 7.3 验收

- 小规模（100-1000 句）梯度微调后，训练/留出集准确率**超过纯 Hebbian**（> 0.526 bigram 上限）✓（0.5325，见 7.2.2 ①）
- 学到 Hebbian 学不动的模式：条件组合（仅在特定上下文中出现的转移）、长程关联（>3 词）✓（见 7.2.2 ②③，微验证均 8/8）
- 稀疏梯度开销可控（内存 < 稠密 W 的 10%；时间增量 < 2×）✓（S 矩阵 <0.1MB；train_w 分钟级）
- 定式保留：梯度微调后 abc/seq 回归全绿，封存/复活机制不受影响 ✓（abc 9/9、seq fwd=1.0/rev=0.0）

- 层级抽象立项需明确证据（组合表示不足的实验对照），不预设
