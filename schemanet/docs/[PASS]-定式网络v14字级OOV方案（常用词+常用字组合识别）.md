## 一、背景与现状差距

### 1.1 OOV 盲区：词级模式字典的硬伤

当前模式字典是**词级分配制**（`allocate_pats`：新词落位 k 个神经元、永久冻结）。硬伤：

```
词表外的新词（人名/新造词/领域术语）→ 无模式 → 网络"不认识、说不出"
训练时 jieba 切出的 OOV 只被统计（sparse_net L876-877），不参与学习
```

网络被锁死在"已经见过的词"里——与"组合空间"讨论的结论一致：**词级字典的识别边界 = 已登记词表**。

### 1.2 现状差距

| 层 | v13 现状 | 目标（v14） |
|---|---|---|
| 识别 | 只有词级（OOV 直接盲区） | 词级 + **字级兜底**（OOV 用字组合） |
| 语义 | 词级定式（边） | 不变（语义仍靠经历，不靠字） |
| 词表边界 | 语料 top-K（非显式） | 显式设计（常用词+常用字） |

### 1.3 v14 目标

**让网络遇到新词时，用已学的常用字"组合"出临时身份，进入语料流自动习得语义，反复出现后固化落位为正式词模式**——识别与语义解耦，识别边界从"登记过的词"扩大为"常用字的组合能力"。

## 二、设计

### 2.1 架构总览：常用词层 + 常用字层（分工不同）

```
┌─ 常用词层（主身份，已有）────────────────────────────┐
│ 模式字典 V ≈ 3.7-5.6 万词，每词 k 神经元               │
│ 职责：语义定式、搭配、价值（吃→苹果、不要→石头）       │
│ 决定模型大小（有效搭配 ~1 亿边 → 1GB 预算内饱和）       │
└──────────────────────────────────────────────┘
                ▲ 落位固化（反复出现后）
                │
┌─ 常用字层（兜底识别，新增）──────────────────────────┐
│ 字级模式字典 3500 常用字，每字 k 神经元                │
│ 职责：OOV 组合入口（词 = 字的模式并集脉冲）             │
│ 扩大识别边界，不扩大语义饱和点                         │
└──────────────────────────────────────────────┘
```

- 两层都是分配制模式字典，共用同一套 `allocate_pats` / `pats` / W 结构；
- **字级识别空间 = 3500^L（巨大），语义定式空间 = 有效搭配（~1 亿边，不变）**——识别与语义解耦。

### 2.2 新词生命周期三步

```
遇到新词"榴莲"（词表外）
  │
  ▼ ① 识别（即时，字组合）
  检测 OOV → 用"榴""莲"的字模式并集脉冲 → 临时身份，可进入句子
  │
  ▼ ② 语义（自动，Hebbian/STDP）
  "我想吃榴莲" → 同句共发放 → 吃/想 ↔ 榴莲字神经元自动建边
  反复出现几次 → 语义边自然长出来（不需要预知词义）
  │
  ▼ ③ 固化（分配制落位）
  出现频次 ≥ 阈值 → 分配专属词模式 → 语义边迁移 → 字级模式退休
```

### 2.3 实现要点

**① OOV 检测与字级脉冲**

```python
def _pulse_for_oov(ng, word, char_pats):
    """未登录词 → 组成字的模式并集脉冲（复用 COMBO 实验机制）。"""
    idxs = sorted({i for ch in word for i in char_pats.get(ch, ())})
    return idxs  # 传给注入/教学路径
```

- 触发点：教学/语料学习遇到词表外词，且**全部组成字已在字级字典**（满足才走字级；含生僻字则跳过并计数）；
- 字级字典：3500 常用字预分配（或按需落位，复用 `allocate_pats`）；
- 与词级共存：同一词在词级有模式时永远走词级（字级只服务 OOV）。

**② 语义自动学**：无新机制——OOV 词以字模式进入句子后，与现有 Hebbian/STDP/学习门同路径，语义边照常建立。

**③ 固化落位**

- 判定：OOV 出现次数 ≥ `entrench_times`（对齐现有教学固化强度）；
- 动作：`allocate_pats` 分配专属词模式 → **语义边迁移**（字模式并集上的边按强度聚合迁到新词模式）→ 字级纠缠解除；
- 迁移策略：迁移后字模式仍保留（其他词还在用），只把该词相关的边指向新身份。

### 2.4 与现有机制边界

| 机制 | 关系 |
|---|---|
| 验证门 | OOV 进入前仍过验证门（"该不该认识它"）；语义边受学习门约束 |
| 注意力 | 字级并集 = 2×k 个神经元 → 连接数量 ×2，竞争环境变化（v2.2 公式适用） |
| 临界态 | 字（部件）天然 hub（提手旁/口字旁）→ 与 hub 治理同根因，需监控 σ |
| 封存/冻结 | 固化落位后的词模式进入冻结态，字级模式只留字本身语义 |

### 2.5 词表边界设计决策（人做决策项）

| 方案 | 说明 | 推荐 |
|---|---|---|
| A：语料 top-K + 显式上限 | 维持现状来源，V 锁上限（如 6 万） | ★ 改动小、渐近 |
| B：显式《现代汉语常用词表》 | 5.6 万词表作为 V 的设计边界 | 边界清晰、需建表 |
| 常用字表 | 3500 常用字（覆盖 99% 用字），字级字典上限 | ★ 无争议 |

## 三、已有原理验证（COMBO 实验）

schema_net.py 组合学习实验已证明核心机制（L517-619）：

| 验证点 | 结果 | 代码位置 |
|---|---|---|
| 组合 token 用字并集脉冲可学 | 组合定式在独立槽位形成组装 | `_pulse_for` L553-555 |

**差距**：该实验是原型版（稠密 + 多槽 + 组装判读）；sparse 版需补 OOV 检测、字级字典、固化落位三步。

## 四、验证计划（sparse 探针实验）

1. **字级识别**：教学含 OOV 的句子（如"我想吃榴莲"），验证网络能说出"榴莲"（字并集输出）；
2. **语义自动学**：OOV 词在 3-5 次语境出现后，复述测试"吃→榴莲"唤起成立（语义边已建）；
3. **固化落位**：OOV 达固化阈值后，字级纠缠解除（"榴弹"不再串扰"榴莲"），词模式独立；
4. **原子保留**：字级字典在 OOV 学习后，单字仍可唤起（对齐 COMBO 结论）；
5. **对拍铁律**：已学词路径零改动，回归 _speak 教学快照逐字一致。

## 五、风险与边界（诚实标注）

| 风险 | 说明 | 对策 |
|---|---|---|
| 字级粒度细 | 词 = 2×k 神经元，突触数量 ×2，竞争环境变化 | 复用 v2.2 注意力公式，必要时增益补偿 |
| 字跨词纠缠 | "榴"同时属"榴莲/榴弹"，语义边串扰 | 固化落位 + 边迁移，纠缠只发生在过渡期 |
| 部件 hub | 偏旁部首天然 hub，可能加剧超临界雪崩 | 与临界态治理同根因，σ 监控前置 |
| 生僻字盲区 | 含未学字的 OOV 仍无法组合 | 字级字典 3500 覆盖 99%，残余盲区接受 |
| 迁移语义损失 | 边迁移聚合可能丢失细粒度信息 | 对拍验证 + 迁移保留原始字级边（不删除） |

## 六、规模预算（V/边/内存闭环）

| 项 | 值 | 依据 |
|---|---|---|
| 常用词 V | 3.7-5.6 万（设计锁定） | 常用词表 / 现有词表 |
| 常用字 | 3500（字级字典上限） | 《现代汉语常用字表》 |
| 有效搭配空间 | ~1 亿边 | α·V²（词类约束） |
| 1GB 内存 | 刚好装下饱和结构 | EdgeRow 8-12B/边 + 运行时 |
| 识别边界 | 3500^L（字组合） | 字级兜底后 OOV 盲区收敛 |

**结论**：v14 不扩大语义饱和点（模型不会因字级变大），只扩大识别边界——与"结构收敛"定理自洽。
