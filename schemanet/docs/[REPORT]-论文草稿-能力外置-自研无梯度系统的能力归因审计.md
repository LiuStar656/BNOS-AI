# 能力外置：自研无梯度神经形态系统中"能力归谁"的审计方法、量化与教训

> **论文草稿** | 日期：2026-08-12 | 版本：v0.1（待审阅）
> 作者：Ahdong | 关联实验：E5（`runs/paper_e5_20260812_105554/`）+ v40-v50 诊断史 + trace 事件
> 定位：方法论论文（形态 B）——面向自研系统社区（SNN/HTM/神经形态/规则系统）的能力归因审计

---

## 摘要

自研系统（脉冲神经网络、HTM、神经形态硬件、规则-神经网络混合系统）的"能力表现"通常由多个层级的机制共同产生，但绝大多数研究报告默认"能力 = 模型涌现"，从不追问**能力到底来自哪一层**。本文报告一个三层能力来源审计协议（动力学层 / 结构层 / 代码层），并将其应用于一个无梯度脉冲网络系统（SchemaNet）。审计发现三个结果：**（1）假象实锤**——系统在对话、造句、接话等任务上的高分表现来自代码层专用读出器（直接读边、配对直读、域内过滤、验证门），而非模型动力学涌现，剥离代码层后能力崩塌；**（2）量化对照（E5）**——在通用 next-token 预测任务上，纯动力学回响的硬解析 top-1（0.151）与代码层通用读出 wsum（0.108）相当（外置增益 −0.043），且两者都远低于外部基线（bigram 0.244）——即"代码层读出"并非万能外挂，它只在专用读出器对口的任务上显得强大；**（3）解耦教训（trace 事件）**——训练层对结构的扰动可污染观察层结论（曾以 z=4.42 宣布某机制为核心，被干净对照推翻为 z=−3.48），自研系统的归因必须解耦训练与评估。本文将该协议与 LLM/Agent 域的能力归因方法族（Harness-vs-Models、CapaBench、Backtrace）对齐，论证其差异：**拆分的对象是"动力学 vs 代码读出"（机制级），而非"评测脚手架 vs 模型"（接口级）**。我们认为，能力归因审计应成为自研系统研究的标准步骤——它决定了"系统在自主运行（剥离代码层）后还剩多少能力"这一核心问题的答案。

**关键词**：能力归因；自研系统；脉冲神经网络；能力外置；代码层读出；方法学

## 1. 引言

### 1.1 问题的提出

脉冲神经网络（SNN）、HTM、神经形态芯片等"无反向传播"路线的研究，长期面临一个尴尬：**系统在论文里表现得很好，但很难说清是"模型真的学会了"还是"代码帮它做了"**。一个词接词系统的对话能力、一个规则-神经网络混合系统的推理能力，往往由以下层级共同产生：

- **动力学层**：脉冲传播、回响、积分-发放本身——"模型自发产出"；
- **结构层**：训练后突触权重矩阵 W 中承载的转移/共现信息——"模型学过的东西"；
- **代码层**：为读取 W 而写的读出器、过滤规则、判读逻辑——"代码从模型里挖出来的东西"。

当"代码层"贡献了大部分能力表现时，系统实际是**半自主**的：模型存储了信息，但"会用信息"这件事是代码实现的。我们把这种现象称为**能力外置（capability outsourcing）**。能力外置本身不一定是坏事（读出器可以视为神经形态硬件的"解码器"），但如果研究者误把外置能力当作模型涌现能力，结论就会被系统性高估——这正是本文要审计的。

### 1.2 本文的问题与贡献

- **Q1（实锤）**：系统当前的高分能力表现，在多大比例上来自代码层而非模型层？
- **Q2（量化）**：在通用任务（无专用读出器对口）上，动力学层与代码层各自的能力水平如何？
- **Q3（教训）**：自研系统研究存在哪些会污染归因的陷阱（如训练层扰动观察层）？

贡献：
1. 提出**三层能力来源审计协议**（动力学/结构/代码）——可复用于其他自研系统；
2. 给出审计的完整实证（对话假象实锤 + E5 通用任务量化 + trace 解耦事件）；
3. 将该协议与 LLM/Agent 域归因方法族对齐，明确增量：**机制级归因**（拆"动力学 vs 代码读出"）而非接口级归因（拆"脚手架 vs 模型"）。

## 2. 相关工作：能力归因方法族

LLM/Agent 域近年建立了一套"能力归因"方法学，本文的审计是这套方法族向自研 SNN 机制域的迁移：

- **Harness vs Models**：用 logistic 回归 + Shapley 归因分离"评测脚手架（harness）能力"与"模型本体能力"——与本文"外置"概念最接近，但其拆分发生在**评测接口**层（prompt 工程、解码、评估脚本提供的增益），而本文拆分发生在**系统内部机制**层（动力学读出 vs 代码读出）；
- **CapaBench**（arXiv:2502.00510）：Shapley 值对 4 个模块做 2⁴=16 组合归因——**模块级**归因；本文为**机制级**（同一任务上不同读出路径的对照）；
- **Backtrace / Skill Use or Skill Theater?**（arXiv:2607.27484）：no-skill 反事实 + 六种干预对照，判断技能是否真实被使用——与本文"剥离代码层看能力是否崩塌"的反事实逻辑同族；
- **Schaeffer et al. (2023)**：能力涌现可能是度量假象——本文的对话假象实锤是同一教训在自研系统域的版本。

**差异定位**：上述工作在 LLM/Agent 域回答"能力归评测还是归模型"；本文在无梯度 SNN 域回答"能力归动力学还是归代码读出"。前者是**接口级**归因（评测外设 vs 模型），后者是**机制级**归因（模型内部两条读取路径）——归因粒度更细，且对"系统能否自主运行"这一核心问题更直接。

---

## 3. 审计协议：三层能力来源

对系统的每一项任务能力，执行三步剥离：

| 层 | 定义 | 剥离操作 |
|---|---|---|
| 动力学层 | 纯脉冲传播/回响的产出（freeze 态、无读出器） | 注入输入 → 记录发放 → 直接以激活集为输出（不附加任何读取规则） |
| 结构层 | 突触矩阵 W 中承载的转移/共现信息 | 检查"边存在"与"边被唤起"的分离（边 80.0 存在而唤起 0.00 即结构信息无法被动力学利用） |
| 代码层 | 读取 W 的规则：直接读边（direct_next）、配对直读、域内过滤、验证门、判读逻辑 | 关闭对应读出器 → 观察能力下降幅度 |

判定：若剥离代码层后能力大幅下降 → 能力外置成立；若剥离后能力保持 → 能力在动力学/结构层。

## 4. 审计一：对话能力假象实锤（v40–v50 五步治疗）

### 4.1 背景

系统在 v17 之后的"对话训练"中表现出高分：对话 13/13、造句接近 100%、关系句 19/19。这些分数曾被视为模型学习能力的证据。

### 4.2 实锤过程

按 §3 协议剥离后发现：

- **cons/val 代码假象**：对话能力的实现依赖 `cons`（一致性校验）与 `val`（验证门）等**代码层判读逻辑**——它们在读取时对网络输出做规则化修正，而非模型自发产出；剥离这些逻辑后，模型层完整生成"首现"（此前对话从未由模型层独立生成过）；
- **专用读出器**：direct_next 直接读边（对话接话 10/10）、配对直读（因为→所以）、域内过滤（排除虚词枢纽）——这些读出器"给一条读取规则就得到高分"，分数反映的是**规则的质量**，不是模型涌现能力；
- **结构层信息错位**：无监督乱灌下 W 里是统计共现而非语义结构（"猫→想→饿"伪相关，v51 清空 88.7 万边重教）——结构层存储的是相关性，不是语义。

### 4.3 判定

**对话/造句/接话能力的"外置度"接近 100%**：剥离代码层专用读出器后，这些任务的能力从高分崩塌到不可用。系统当时的真实状态是：模型层近乎"混沌"（回响读出 0.247、前缀续推 0%），高分完全由代码层支撑。这一实锤直接改变了项目路线（v51 清空重教、后续教育阶段重灌）。

## 5. 审计二：通用任务量化（E5）

### 5.1 设计

对话场景的假象实锤依赖专用读出器，那么**在没有任何专用读出器对口的通用任务**上，动力学层与代码层各自表现如何？E5 选择 next-token 预测（corpus_open，seed 42，600 测试句）：

- **动力学回响**：freeze 态注入前缀（steps=1）→ 记录激活神经元集合 → recall（目标词模式覆盖率）与硬解析 top-1（激活集按"神经元→词"反查多数投票）；
- **代码层 wsum**：同子集用 wsum 读出器给出词级概率分布取 top-1；
- **外部基线**（E3）：bigram / LSTM。

### 5.2 结果

| 口径 | top-1 | 说明 |
|---|---|---|
| 动力学回响（硬解析） | **0.1513** | recall 0.1976；无发放占比 0.0（7879 位置） |
| 代码层 wsum | 0.108 | 同子集 |
| 外置增益（wsum − 动力学） | **−0.0433** | 代码层未带来增益 |
| bigram（外部基线） | 0.2435 | — |
| LSTM（外部基线） | 0.2333 | — |

### 5.3 解读

1. **"外置增益为负"**：在通用任务上，代码层 wsum 读出（0.108）并不优于动力学回响硬解析（0.151）——"代码层"不是万能外挂；
2. **两层都远低于基线**：动力学（0.151）与代码层（0.108）均低于 bigram（0.244）——**系统的语言能力整体薄弱，不因归因层级而改变**；
3. **与 §4 的对照**：专用读出器（direct_next 等）对口任务上代码层显得强大（10/10），通用读出器（wsum）在通用任务上并不强（0.108）——**"外置"的强度是任务特异的**：外置假象发生在"专用读出器 + 对口任务"的组合上；
4. **诚实口径**：硬解析本身包含"神经元→词反查多数投票"的翻译规则，并非纯动力学自发产出——本文不宣称动力学能自发产出词级输出，只报告两条读出路径的对照。

## 6. 审计三：训练层扰动观察层（trace 事件）

### 6.1 事件

系统曾以 z=4.42 的显著性宣布"trace（上下文痕迹机制）为核心机制"；后由一项干净对照实验推翻：此前的评估在 **train_w（梯度微调）扰动后的 W** 上进行，梯度微调将 wsum 基线砸掉 25%–47%，造成 trace 占优的假象；在干净 W 上，wsum 0.1349 显著优于 trace 0.1245（z=−3.48）。

### 6.2 教训

1. **训练层扰动会污染观察层结论**：评估必须与被评估机制解耦（评估用冻结快照，训练用另一副本）；
2. **"数据放大有益"同样受污染**：需在干净 W 上重新裁决；
3. **自研系统尤其危险**：一切都在自己代码里，训练与评估常共享同一对象，污染隐蔽。

## 7. 讨论

### 7.1 三层审计的一般性

本协议不依赖具体系统：任何"结构存储 + 读出规则"的自研系统都适用。判定核心问题是"**系统在自主运行（剥离代码层）后还剩多少能力**"——对声称"自主涌现"的研究，这是必答题。

### 7.2 与归因方法族的对齐与增量

| 方法 | 域 | 归因粒度 | 拆分对象 |
|---|---|---|---|
| Harness-vs-Models | LLM/Agent | 接口级 | 评测脚手架 vs 模型 |
| CapaBench | LLM/Agent | 模块级 | 4 模块 Shapley 组合 |
| Backtrace | LLM/Agent | 干预级 | no-skill 反事实 + 六种干预 |
| **本文** | **无梯度 SNN** | **机制级** | **动力学读出 vs 代码读出（同一任务）** |

增量 = 归因粒度细化（机制级）+ 域迁移（自研 SNN 系统）+ 量化对照（E5 的外置增益）——不宣称发明新归因方法。

### 7.3 对 Agent 编排层的意义

用户路线的落点是"以 SNN 机制改造 Agent 系统"。本审计给出编排层的第一原则：**微观动力学的"能力"必须按来源分层记账**——哪些是动力学真实产出（可信）、哪些是代码读出（依赖解码器、可单独评估与替换）、哪些是假象（不可依赖）。分层记账后，编排层才能决定奖惩注入、用进废退调度的对象。

## 8. 局限与后续

1. **E5 单 seed**：量化对照目前 seed=42 单样本，多 seed 稳健性补跑已启动（后台运行中）；
2. **硬解析口径**：动力学 top-1 依赖"神经元→词"反查翻译，非纯自发产出——后续可用无翻译的脉冲解码（如时序解码器）复核；
3. **外置强度任务特异**：专用读出器对口任务上的外置度（≈100%）与通用任务（外置增益为负）的巨大差异，尚无统一的量化框架（外置度 × 任务谱）；
4. **假象实锤来自诊断史**：v40-v50 五步治疗是开发期诊断流程而非预注册对照实验，证据为代码审计而非随机对照；
5. 后续：① 外置度定量化（剥离读出器 → 能力下降百分比矩阵）；② 多任务谱的外置度剖面；③ 动力学层自组织（无读出器也能产出）的实验路线。

---

## 9. 结论

本文把一个自研无梯度脉冲系统的"能力"按动力学/结构/代码三层拆开审计：高分能力大量来自代码层专用读出器（剥离即崩）；通用任务上动力学与代码层相当且都远低于基线（外置增益 −0.043）；训练层扰动可污染观察层结论（z=4.42 → z=−3.48）。方法论增量在于将 LLM/Agent 域的归因方法族迁移至机制级（动力学 vs 代码读出）。我们主张：**能力归因审计应成为自研系统研究的标准步骤**——它决定了"自主运行后还剩多少能力"这一核心问题的诚实答案。
