# [PLAN] 盲人自闭症儿童基本常识课程（只能听和说版）

> 日期：2026-08-11 | 状态：[PLAN] 阶段 A/B/C/D 已落地（v31.0）| 依据：视障儿童早期教育（《盲童早期教育指南》尼尔曼/雅各布、《学前视障儿童教育实践与研究》王莉）、自闭症生活自理训练、VB-MAPP 生活技能领域

## 一、教育对象与原则

**教育对象**：定式网络 = 盲人自闭症儿童——**只能听和说，无视觉**。普通孩子"看来的"常识（火会烫、车来了、天黑了），盲童必须**专门教**（听觉/触觉/语言通道代偿）。

**教学原则**（盲童早期教育共识）：
1. **语言描述极为重要**——家人/教师的语言是盲童认识世界的主通道（→ 教学句 = 常识的语言化）
2. **生活自理优先**——吃饭/穿衣/洗漱/如厕先于知识（→ 阶段 B）
3. **感知代偿**——听觉/触觉代偿视觉（→ "耳朵听声音""手摸东西"本身是教学内容：盲童认识"听/摸"是其认识方式）
4. **安全第一**——盲童安全教育是核心（→ 阶段 D）
5. **早期干预从 0 岁开始**，防过度保护、鼓励独立（→ 感受表达→需求表达→自理）

## 三、教学法（每单元）

1. **常识句教学**：跟读常识链 ×R（如 早上→起床→洗手→刷牙→吃饭——生活序列语言化）
2. **验收**：chain_read（期望链约束读取——"教了什么会什么"）
3. **融入自由运行**：教学后的常识链进入 teach_out → 网络静默运行时**自己冒出常识念头**（早上想起"起床洗手刷牙吃饭"——学过的常识成为"生活"）

## 四、与"只能听和说"的对应

- 盲童的"看"= 摸/听 → 教学句"手摸东西/耳朵听声音"教的是**认知方式本身**
- 安全常识 = 语言警告（不能摸火）——盲童靠"被告知"而非"看见"学危险
- 生活序列 = 语言化的一日流程（视觉日程表的听觉版）
