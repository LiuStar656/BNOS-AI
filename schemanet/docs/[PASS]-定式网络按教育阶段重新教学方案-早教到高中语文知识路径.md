## 二、教学原则（正确灌法）

1. **语义教学——不灌统计**：教学"猫是动物/猫吃鱼"（定义/关系/行为——定式化）——不灌"我想猫"（共现统计）
2. **阶段递进——按人类教育路径**：早教 → 学前 → 幼小衔接 → 小学 → 初中 → 高中（每阶段的内容/能力匹配）
3. **定式化**（语义结构——轨道——抗污染）：每阶段的知识教成定式（骨架轨道）——不是散边
4. **接受性先行**（听指令先于表达——循证）：每阶段先"听懂"（指令→行为）再"会说"（轨道生成）
5. **验证每阶段**：输入 → 语义输出（不是统计联想）——剥离代码层（模型层可读）

## 三、阶段路径（语文知识重点 + 网络机制）

### 阶段 1：早教（0-3 岁）——语音与日常词汇

| 维度 | 内容 |
|---|---|
| **语文点** | 语音（字音）、日常名词（家人/食物/身体/动物/物品）、简单动词（吃/抱/要/给）、简单指令（听指令——接受性） |
| **网络机制** | 复读（回声——v51 机制）、听指令（指令→定式激活——接受性行为层）、简单定式（妈妈抱/我要X——2-3 词轨道） |
| **灌法** | 一对一教学：说"妈妈"→ 复读；说"拿苹果"→ 指认苹果定式（听指令——训狗式 + release_da 零食） |
| **验证** | 输入"苹果"→ 复读+定式唤起；指令"拿苹果"→ 激活苹果定式（行为响应） |

### 阶段 2：学前教育（3-6 岁）——识字启蒙与简单句

| 维度 | 内容 |
|---|---|
| **语文点** | 常用字（300-500）、词汇扩展（形容词/量词/方位词）、完整句（主谓宾——"小猫吃鱼"）、儿歌童谣（韵律）、简单问答（这是什么/你叫什么——固化问句） |
| **网络机制** | 定式化（完整句轨道——S-V-O）、问句定式（X是什么——ask 结构）、听故事（连续定式——多句） |
| **灌法** | 语义教学：教"小猫吃鱼"（S-V-O 定式——不是统计共现）、故事输入（多定式连续） |
| **验证** | 输入"小猫吃鱼"→ 定式轨道完整（猫-吃-鱼 语义结构——不是"吃/睡觉"统计） |

### 阶段 3：幼小衔接（5-6 岁）——看图说话与简单叙事

| 维度 | 内容 |
|---|---|
| **语文点** | 看图说话（描述——谁/在哪/做什么）、简单叙事（我的一天——时间顺序）、礼貌用语、课堂指令 |
| **网络机制** | 描述定式（S-V-O 扩展——时间/地点/方式）、叙事链（多定式衔接——先/然后/最后） |
| **灌法** | 看图教学（场景定式）、叙事示范（一天的定式序列） |
| **验证** | 输入"我的一天"→ 叙事定式序列（早上起床/中午吃饭/晚上睡觉——衔接） |

### 阶段 4：小学（6-12 岁）——字词句段篇系统语文

**低年级（1-2 年级）**
| 维度 | 内容 |
|---|---|
| **语文点** | 识字（常用 1600 字）、词语（近义/反义）、句子（扩句/缩句）、看图写话、朗读 |
| **网络机制** | 词汇语义网（近义/反义——类属定式）、句子扩展（定语/状语——骨架槽位扩展） |
| **验证** | 输入"苹果"→ 语义网（水果/红色/甜——不是统计联想） |

**中年级（3-4 年级）**
| 维度 | 内容 |
|---|---|
| **语文点** | 阅读理解（段落——主旨）、作文（叙事/描写）、成语、修辞（比喻/拟人） |
| **网络机制** | 段落定式（段落轨道——多句衔接）、修辞定式（比喻结构——像/如同） |
| **验证** | 输入一段话 → 主旨提取（段落轨道——核心句） |

**高年级（5-6 年级）**
| 维度 | 内容 |
|---|---|
| **语文点** | 篇章理解（全文——结构）、说明文/议论文初步、古诗词、写作（记事/写人/写景） |
| **网络机制** | 篇章结构定式（总-分-总）、古诗词定式（韵律轨道）、写作定式（记叙文六要素） |
| **验证** | 输入一篇短文 → 结构识别（总分总——段落定式衔接） |

### 阶段 5：初中（12-15 岁）——文言文与现代文

| 维度 | 内容 |
|---|---|
| **语文点** | 文言文（常用虚词/实词）、现代文阅读（散文/小说——人物/情节）、议论文（论点/论据）、语法（词性/句子成分）、写作（记叙/说明/议论） |
| **网络机制** | 文言定式（虚词轨道——之/其/而）、句子成分定式（主谓宾定状补）、议论文定式（论点-论据-论证） |
| **验证** | 输入文言句 → 虚词定式唤起；输入议论文题 → 论点-论据结构 |

### 阶段 6：高中（15-18 岁）——深度语文

| 维度 | 内容 |
|---|---|
| **语文点** | 文言文深度（一词多义/古今异义）、古代诗歌鉴赏（意象/意境）、现代文学（主题/手法）、议论文写作（论证严密）、语言运用（得体/连贯） |
| **网络机制** | 多义定式（一词多义——语境选择——预测编码）、意象定式（月/柳/酒——意境轨道）、论证定式（多层论证——递进轨道） |
| **验证** | 输入古诗 → 意象定式唤起（意境——不是字面统计） |

## 四、实施要点

### 4.1 数据来源（每阶段的语文教材/语料）

| 阶段 | 数据 |
|---|---|
| 早教/学前 | 幼儿识字卡/儿歌/绘本（语义化标注——每句教成定式） |
| 幼小衔接 | 看图说话教材/幼小衔接语文 |
| 小学 | 部编版小学语文（1-6 年级——字词句段篇序列） |
| 初中 | 部编版初中语文（文言文/现代文/作文） |
| 高中 | 部编版高中语文（必修+选修） |

### 4.2 灌法流程（每阶段统一）

```
① 数据语义化: 教材内容 → 语义单元（定义/关系/行为/结构——不是语料共现）
② 定式化教学: 语义单元 → 定式轨道（consolidate_sentence——骨架）
③ 听指令训练: 指令 → 行为（接受性——release_da 零食强化）
④ 表达验证: 输入 → 轨道生成（模型层可读——剥离代码层）
⑤ 睡眠巩固: SHY（缩放——强度稳态——每阶段末）
```

### 4.3 每阶段的验收标准

- **不依赖代码**：剥离代码层（cons/free_read）——模型层可读（轨道/语义）
- **语义正确**：输入"猫"→ 语义（动物/喵——不是统计联想）
- **阶段递进**：前阶段定式是后阶段的构件（字→词→句→段→篇）
