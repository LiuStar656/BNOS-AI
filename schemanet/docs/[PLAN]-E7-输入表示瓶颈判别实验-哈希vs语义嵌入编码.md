## 一、背景与假设

### 1.1 现状

E1-E3（corpus_open，5 seeds）语言评估大幅落后外部基线：

| 方法 | top-1（test） | PPL（all） |
|---|---|---|
| wsum | 0.112 | 608 |
| trace | 0.086 | 973 |
| grad | 0.079 | 64072 |
| bigram（基线） | 0.243 | 229 |
| LSTM（基线） | 0.233 | 131 |

### 1.2 两个候选根因

- **根因 A（表示瓶颈）**：词模式由 `_word_pattern` 生成 = crc32 哈希 → 随机稀疏模式。语义上相近的词（好吃/可口/美味）在模式空间互不相关，STDP 只能学"哈希共现"，学不到"语义规律"，也无法向近义词泛化。
- **根因 B（机制瓶颈）**：STDP 定式网络本身无法承载序列预测（8 词窗口的 bigram 转移），换什么表示都没用。

### 1.3 外部线索（EMBER，arXiv:2604.12167）

EMBER 用 **语义嵌入（BGE）+ z-score 标准化 top-k 群体编码** 作为 SNN 输入，STDP 成功学到 person-topic 关联、跨域关联等具体规律。其关键差异之一正是**输入是有语义结构的嵌入**，而非随机哈希。

### 1.4 假设 H

> 把词模式从 crc32 哈希替换为语义嵌入编码（保持稀疏接口不变），schemanet 在语言任务上的表现显著提升 → 根因 A（表示瓶颈）成立，机制本身（根因 B）不背锅。

**两种结局都有价值**：
- 假设成立 → E1-E3 落后结论改写为"表示瓶颈"，升级编码后重新评估，论文关键转折点；
- 假设不成立 → 诚实的机制性结论：定式网络在现参数下承载不了序列预测，语言非主场，资源聚焦"机制同构"（奖惩/用进废退）方向。

## 二、目标

1. 单变量判别：哈希 vs 语义编码，**唯一变量 = 模式生成器**，其余（语料、词表、网络、训练、评估口径）完全相同；
2. 三路（wsum/trace/grad）top-1 + PPL 对拍（复用 `_paper_eval.py` 管线）；
3. 语义迁移测试：训练 A 组词 → 测试 B 组近义词（训练时剔除），检验"表示是否携带语义结构可泛化"；
4. 留档 result.json + 实验报告（schemanet/docs/）。

## 三、方案设计

### 3.1 干预：语义模式生成器（复刻 EMBER z-score top-k）

- 嵌入模型：**bge-small-zh-v1.5**（384 维，中文语料；本地推理，约 100MB）
- 随机单位方向：N=8192 个 p_i（固定 rng，跨运行可复现）
- 编码：`z_i = (cos(e, p_i) − μ) / σ`，取 top-k=16 神经元 → 模式 = sorted 神经元 id 列表（与 `_word_pattern` 返回接口完全一致）
- 嵌入 → 模式映射**一次性缓存**（npz），避免重复计算
- 接口兼容：网络侧（`SparseSchemaNet`）、训练侧（`_learn_sentence`）、评估侧（wsum/trace/grad）零改动，只替换 `pats` 字典的来源

### 3.2 E7-1 主对照

| | 哈希（对照组，现状） | 语义（干预组） |
|---|---|---|
| 模式生成 | `_word_pattern`（crc32） | `_word_pattern_semantic`（z-score top-k） |
| 语料/词表/网络参数 | corpus_open，N=8192/K=16/KV=3000，完全一致 | 同左 |
| 训练流程 | Hebbian→sleep→delta 扫描→train_w（lr=0.02/5ep） | 同左 |
| 评估口径 | wsum/trace/grad：train/test top-1 + PPL(all/no-unk) | 同左 |

- 先 seed=42 单次对拍出信号；有信号再扩 seeds {42,43,44,45,46}

### 3.3 E7-2 语义迁移测试（附加判别，最直接的证据）

- 构造 mini 语义对语料（从 corpus_open 抽取含类别词的句子）：
  - A 组训练词（动物：猫/狗/鸡/牛/马/羊）
  - B 组测试词（近义词：猪/兔/鹿/狐/狼），训练语料中剔除
- 协议：训练含 A 组词的句子 → 测试含 B 组词的句子（B 词置于与 A 词相同语境，如"___ 很凶"）
- 判定：哈希模式下 B 组迁移率应 ≈0（表示无语义关联）；语义模式下 B 词与 A 词共享部分神经元 → 应观察到部分唤起（迁移率 >0）
- 若成立 → "表示携带语义结构"的铁证，无需解释

### 3.4 判定标准

| 判据 | 标准 | 结论 |
|---|---|---|
| 主判：E7-1 三路 top-1 | 语义 vs 哈希 相对提升 ≥20%（任一主流路线 wsum/trace） | 根因 A 成立 |
| 辅判：E7-1 PPL | 语义 vs 哈希 相对下降 ≥20%（all 口径） | 同上 |
| 铁证：E7-2 迁移率 | 语义组迁移率 >0 且显著高于哈希组 | 表示携带语义结构 |
| 双败（主判+铁证均不成立） | — | 根因 B（机制瓶颈），语言任务收缩 |

## 七、实验结果（2026-08-12，seed=42，corpus_open）

留档：`runs/paper_e7_20260812_123055/result.json`

### 7.1 静态重叠（表示结构存在性）

| 编码 | A×B 组模式重叠率 | 随机期望 |
|---|---|---|
| 哈希 | 0.0029 | 0.0312 |
| 语义 | **0.0645** | — |

语义编码确实让近义词共享神经元（22 倍于哈希）——表示携带语义结构的**前提成立**。

### 7.2 主对照（三路 top-1 / PPL）

| 指标 | 哈希 | 语义 | Δ |
|---|---|---|---|
| wsum top-1（test） | 0.113 | 0.083 | **−26%** |
| trace top-1（test） | 0.088 | 0.088 | 持平 |
| grad top-1（test） | 0.095 | 0.069 | **−27%** |
| wsum PPL（all） | **601** | **2356** | **恶化 4×** |
| trace PPL（all） | 954 | 2336 | 恶化 2.5× |
| 学习边数 nnz | 10,745,083 | 1,791,798 | 仅 1/6 |

### 7.3 结论：假设 H 被否定

1. **语义嵌入编码在语言建模上大幅恶化**——top-1 下降 26-27%，PPL 恶化 2.5-4 倍，边数降至 1/6；
2. **根因：任务-表示错配**——next-token 预测需要**区分性**表示（猫/狗后继不同："跑"/"叫"），语义编码的**相似性**（共享神经元）让 Hebbian 互相污染转移统计；共享神经元削弱权重结构 → sleep 删除更多边 → 网络容量坍缩；
3. **与 EMBER 的对照**：EMBER 的 z-score top-k 编码在 **person-topic 联想**任务（相似性有用）成功；本实验证明同一编码在**预测/区分**任务（相似性有害）失败——**任务性质决定表示需求**，不存在通用最优编码；
4. **对过去路线的意义**：**排除"输入表示（crc32 哈希）为语言瓶颈"假设**——语言失败根因回到机制本身（无梯度平面 STDP + 无位置编码），终结报告"规则涌现墙"结论更干净；
5. **对 Agent 编排层的启示**：语义共享表示在**相似组件唤起（联想）**场景有效、在**组件竞争选择（区分）**场景有害——编排层须按任务选择表示（"结构人设计、机制学强度"）。

### 7.4 遗留（2026-08-12 补跑后更新）

- ~~E7-2b 动态迁移未完成~~ → **已完成（2026-08-12）**：修复词表缺词 bug（A/B 组词并入语义词汇表）+ 小网络参数匹配（n=2048/k=8，独立缓存 `_e7_semantic_dyn.npz`）+ 离线加载 BGE；结果：训练 A 组 120 句模板句 → 注入 B 组近义词，B→A 唤起率 **哈希 12.5%（≈1/8 偶然）vs 语义 100.0%（8/8）**——语义共享表示在联想场景的**动态迁移铁证**（近词可经共享神经元唤起已学词模式）；
- 单 seed（42）：负结果方向明确（PPL 恶化 4×），多 seed 补跑优先级低。
