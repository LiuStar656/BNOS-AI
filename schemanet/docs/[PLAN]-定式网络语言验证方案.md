## 一、背景与现状评估

**现状**：定式网络（SchemaNet）已验证模式层机制——
① 反复经历形成定式（A/B 收敛、互不干扰）
② 多槽存储隔离（组合层与原子层共存，原子保留 1.0）
③ 满槽覆盖取代慢衰减（容量压力下只伤弱链、保护强定式）
④ 学习门 learn_gate（冻结态物理免疫篡改、检索不受影响）
⑤ **STDP token 转移学习**（同步 STDP δt=1：喂 a 唤起 b、顺序自动可区分；链式 abc 逐级唤起）

**方向**：定式网络（SchemaNet）自身向大模型方向发展（用户决策：非外挂、非吞并，而是**让定式网络（SchemaNet）自己成为大模型**）。核心论证：LLM 的本质 `P(token_t | token_{<t})` 与已验证的 STDP 转移学习同构——STDP 学的是脉冲模式的顺序转移，语言建模学的是 token 的顺序转移，机制同一，缺的是**规模**、**生成**、**长程上下文**三根支柱。

**最小验证的必要性**：机制优先于规模。先证明"定式网络（SchemaNet）+ 真实中文文本 → 词间转移学习"成立（对照 n-gram 基线），再谈扩规模。这是定式网络（SchemaNet）成为大模型的地基。

**实现形态**：用户决策 = 扩展 `schema_net.py` 加 `--mode lang`，与现有实验同仓复用 CONFIG/留档机制；代码迁移至顶层独立目录 `schemanet/`（用户决策，与 nodes/ 解耦）。

## 二、目标

1. 验证定式网络（SchemaNet）能否从真实中文短句学习**词间转移**（喂前缀 → 唤起/预测后继词）
2. 量化学到多深：对照 **bigram / trigram** 基线（统计语言模型基础线），定位"条件转移 vs 单纯共现"
3. 验证**编码稳定性**：随机稀疏模式能否稳定区分 K≈300 词（分布式编码雏形，远期"embed→投影→稀疏化"的第一块拼图）
4. 验证**带变量的句式**（如"我喜欢X"）学完后，喂前缀能否唤起语料中出现过的具体宾语
5. 所有运行独立留档（`schemanet/runs/YYYYMMDD_HHMMSS/`），禁覆盖

非目标：不做通用语言建模、不追求超越现代 LM、不引入梯度学习。

## 三、方案设计

### 3.1 整体流程

```
语料(100 条中文短句) → jieba 分词 → top-K 词表(K≈300)
→ 每词=固定种子随机稀疏脉冲模式(n=2048, k=8)
→ STDP 逐词喂句（复用 seq 机制）→ 定式网络（SchemaNet）沉淀词间转移
→ 验证① next-token top-1 准确率（训练集重建 + 留出句泛化）
→ 验证② 逐词生成完整句子
→ 对照 bigram / trigram（add-1 平滑）
```

### 3.2 编码（关键）

- 每词 = 固定种子随机稀疏模式：`rng(hash(word))` 从 n=2048 中取 k=8 个神经元置 1
- **稳定性**：同词永远同一模式（种子固定）——满足"稳定编码"要求
- **分布式**：所有词共享同一批神经元，靠组合区分（"神经元被无数记忆共享"的记忆观）
- **碰撞估算**：两词随机 k 稀疏模式的期望交集 `k²/n = 64/2048 ≈ 0.03`，300 词可区分
- 词表外（OOV）词丢弃或映射到"未知"模式（第一版丢弃并计数）

### 3.3 学习（复用 seq 机制）

- 每句 = 一次经历（对应 `_learn_seq`）：清 v → 注入词脉冲 → step → 间隔步（pre_trace 衰减一步，只留相邻前驱）→ 下一词
- STDP：前驱痕迹 → 后继强化 `W[后继←前驱]`，只强化正向
- 句尾：清 pre_trace（防跨句串扰）+ 结尾回响收敛
- 句间：注入前清膜电位残留 v（防噪声越阈挤掉目标，seq 已验证的必要卫生）

### 3.4 预测与生成

- **next-token 预测**：注入前缀词序列 → 回响 steps → 读出激活集合 → 与词表各词模式算 Jaccard，取 top-1
- **备选读出**（若回响激活不稳）：直接用 `W[·, slot, 前驱]` 聚合转移强度 argmax（可对比两种读出的一致性）
- **生成**：喂起始词 → 逐词回响 → 上一步激活作为下一步输入 → 生成完整句（设最大长度 + 定式完成即停）

### 3.5 n-gram 基线

- bigram：`P(w_t | w_{t-1}) = count(w_{t-1}, w_t) / count(w_{t-1})`
- trigram：`P(w_t | w_{t-1}, w_{t-2})`，add-1 平滑
- 只在**训练集**统计；与定式网络（SchemaNet）同一测试集、同一 top-1 判定口径

### 3.6 规模

- `n=2048, slots=4, k=8` → `W = 2048×4×2048 = 16M` 参数（float32 ≈ 64MB，numpy 分钟级可跑）
- 与 bert-tiny（4.4M）/ 小语言模型同档，符合"小参数验证"决策

## 四、分阶段实施计划

| Phase | 内容 | 验收 |
|-------|------|------|
| 0 | 语料构建：100 条中文常用短句（固定句式 + 带变量句式，如"我喜欢X/我想Y"），jieba 分词、词频统计 | K≈300 词表 + 语料 JSON 留档 `schemanet/data/` |
| 1 | 编码层：词→固定种子稀疏模式，验证区分度（词两两 Jaccard < 0.1 占比） | 300 词可区分、无高碰撞对 |
| 2 | 学习 + 预测：`--mode lang`，训练集喂入 + next-token top-1 评估 | 输出训练集重建准确率 |
| 3 | 基线对照：bigram/trigram 同口径评估 | 三表对比（SchemaNet / bigram / trigram） |
| 4 | 泛化：留出句（20 条未学）评估 + 带变量句式测试 | 泛化准确率 + 变量宾语唤起样例 |
| 5 | 生成展示 + 留档 + 汇报 | 逐词生成样例、runs 目录完整 |

## 五、风险评估

| 风险 | 等级 | 应对 |
|------|------|------|
| Hebbian/STDP 学语言的天花板：学得了共现与顺序、学不了抽象语法规则 | 高 | 用 n-gram 基线诚实定位能力边界；孵化路线中 LLM 兜底是安全网 |
| 长程依赖不足：pre_trace 痕迹只跨几步，句内词序稍长即断 | 中 | 第一版只验证短句（≤10 词）；分层/长痕迹列为后续 |
| 高频词主导（的/了/我）：转移学习被高频词吸走 | 中 | 观察词频-准确率相关性；必要时词频归一/阈值 |
| 随机模式碰撞干扰激活读出 | 低 | 3.2 节碰撞估算 + Phase 1 区分度预检 |
| jieba 分词引入外部依赖 | 低 | 仅实验脚本依赖，不影响核心；需求固定环境说明 |

## 六、测试计划

1. **编码预检**：300 词两两 Jaccard 分布（期望交集 0.03，高碰撞对计数）
2. **重建准确率**：训练句每句喂前 n-1 词 → 预测第 n 词 top-1 命中率
3. **泛化准确率**：20 条留出句同口径命中率
4. **基线对照**：SchemaNet vs bigram vs trigram（同测试集、同口径）
5. **变量唤起**："我喜欢" → 唤起宾语候选（top-k）含语料中的真实宾语
6. **生成样例**：3-5 条完整逐词生成句 + 与原句对比
7. **留档**：全部指标 JSON + 参数 → `runs/YYYYMMDD_HHMMSS/`
