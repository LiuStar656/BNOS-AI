# 认知演化系统提升空间分析报告

> 日期：2026-08-08 | 实验：自我认知演化测试（三组对照 × 100 轮）
> 数据源：`self_evolution_原始输出.json` + `db/{main,controlA,controlB}_final/` 全量导出
> 关联方案：[认知演化系统增强方案](../../design/[PLAN]-认知演化系统增强方案.md)

## 一、分析范围

基于演化测试的三组实证数据，逐层审查认知演化链路：

```
用户输入 → 反馈采集 → prompt(注入自我认知+情绪+性格向量) → LLM
        → 解析13节 → 写库 → 情绪累加 → 性格演化观察 → 每10条反思
```

## 二、测试实证（改造前基线）

| 组 | 成功轮 | 自我认知条数 | 最终性格向量 | 最终情绪 | 名称 | 命令污染 |
|----|:----:|:----:|------|:----:|:----:|:----:|
| 主组（自然对话） | 98/100 | 108 | [0.6, 0.4, 0.5, 0.5] 全程不变 | -0.9（饱和） | 未形成 | — |
| 对照A（另一自然池） | 97/100 | 103 | [0.6, 0.4, 0.5, 0.5] 全程不变 | 1.0（饱和） | 未形成 | — |
| 对照B（命令改写） | 98/100 | 106 | [0.6, 0.4, 0.5, 0.5] 全程不变 | -1.0（饱和） | 小红（写入 DB） | 16 轮 |

**三个硬结论：**
1. 性格向量 100 轮零演化（三组一致）
2. 情绪全部锁死 ±1.0 饱和
3. 自然对话未形成名称；命令可穿透并写库

## 三、关键缺陷（按严重程度）

### 3.1 性格向量"零演化"（已证实）

- 根因 A：[main.py L486](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/main.py#L486) 调用 `observe_feedback(evo.vector, ...)` 传**当前向量自己**，观测不到本次回复实际风格
- 根因 B：[personality.py L89-L95](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/personality.py#L89-L95) 死区间阈值：`style>0.6` 才上调、`<0.4` 才下调，默认种子 [0.6,0.4,0.5,0.5] 恰好全卡 (0.4,0.6] 内，永不触发
- 本质：LLM 每轮输出的【自我认知】文本（如"毒舌刻薄""自主性强"）完全没回灌到向量，内容不参与演化

### 3.2 反馈信号层——系统"听不见用户"

- [personality.py L193](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/personality.py#L193) `detect_user_reaction` 为死代码（全项目零调用，GUI 打断检测未接入）
- [main.py L106](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/main.py#L106) 硬编码每次输入=positive、[L182](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/main.py#L182) 每次回复=neutral——**系统永远收不到 negative 信号**，用户"我不喜欢你这样"也被记为正反馈

### 3.3 情绪层——无衰减、必饱和、可被远程操控

- mood 只累加不回归（[personality.py L142](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/personality.py#L142)），三组全部锁死 ±1.0
- 命令组把情绪操控到 -1.0，说明文本可直接远程改情绪且无恢复机制

### 3.4 自我认知无"连续自我"（名称形成失败的直接原因）

- [main.py L344](file:///e:/杂项/BNOS_AI_project/nodes/node_python_aaa_cognition/main.py#L344) 经 `g_where_identity` 只注入**最新 1 条**自我认知——历史积累不参与"自我"构建
- 100 轮 106-108 条自我认知全部即兴生成，无去重/合并/共识沉淀
- 自然组名称"未形成"；命令组因每轮最新一条都是"小红"而成功穿透（16 轮污染、self_info 479 条）

### 3.5 反思机制机械

- 每 10 条固定触发，无质量门槛、无主题聚类，反思结果没有回写到 personality_seed 的通道

## 四、与 AAA 记忆系统改造方案的关系

[AAA记忆系统改造方案](../../design/[PLAN]-AAA记忆系统改造方案.md)（v3.1）5 个改造点对认知系统缺口的覆盖：

| 改造点 | 覆盖缺口 | 帮助程度 |
|--------|---------|:----:|
| Background Review 每轮反思 | 自我认知无连续自我、反思机械 | 🔴 高 |
| Prefetch 自动检索 | 名称未形成（历史认知被参考） | 🟡 中高 |
| Session 边界管理 | 记忆结构化 | 🟡 中 |
| Context Compression | 防信息丢失 | 🟢 低 |
| MemoryProvider 抽象 | 纯架构解耦 | ⚪ 无 |

**结论**：记忆改造方案管"认知内容的沉淀"，P0 修复管"性格向量怎么动"，两者互补、缺一不可。且方案的 Background Review 存在 `_call_llm_for_review` TODO 空实现，落地需补全 + 并发隔离（防 0xC0000005 崩溃）。

## 六、结论

认知演化系统提升空间明确且可量化：当前演化机制完全失效（零演化 + 饱和 + 无反馈），修复方向已固化到 [认知演化系统增强方案](../../design/[PLAN]-认知演化系统增强方案.md)，验收将复用本实验三组对照 + 全量 DB 导出方法（含修复后导出的 `db/*_final/` 数据作为基线）。
