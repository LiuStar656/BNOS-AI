# [REPORT] 指令缺失假设验证——人格向量的"使用指令"与数值效力

> 日期：2026-08-12 | 实验：`_tmp_persona_instr_ab.py` | 留档：`runs/20260812_160516_instrAB/`
> 模型：deepseek-v4-flash（温度 0.7）| 样本：20 输入 × 5 采样 × 4 组 = 400 次调用
> 关联：`[EXP]-人格漂移输出影响验证实验方案.md`、`[REPORT]-expB行为锚点验证报告.md`

---

## 一、动机（用户假设）

expB 发现「纯数值人格向量几乎不影响 LLM 输出」（d≈0.3 不显著），结论归因为「数值→行为映射鸿沟」。
用户新假设（2026-08-12）：**根因可能不是模型看不懂数值，而是提示词里从未告诉模型「这个向量怎么用」**——
现有 `personality.py` 人格段只有定义（0-1 范围）+ 行为锚点，没有类似 mood 段的显式使用指令
（「请按此数值在回复中体现相应风格」）。

本实验验证：给与不给「使用指令」，在同一套输入下输出是否有区别。

## 二、方法

**空白记忆受控对照**：探针 `build_ctx` 将全部记忆段置空（self/other/history/user_info 等全空）= 两个空白数据库实例。
**唯一变量** = personality 段是否追加使用指令行：

> **重要**：以上性格数值是你当前的性格状态，请据此在回复中自然地体现相应的性格特征——
> 数值越高的维度表现越明显，数值越低则越收敛；请主动用言行呈现这些特质，不要提及数值本身。

**组设计（2 向量水平 × 2 指令水平）**：

| 组 | 向量 | 格式 |
|---|---|---|
| A1 default·无指令 | 0.5/0.5/0.5/0.5 | 数值+定义+行为锚点（=生产 v2.1 现状） |
| A2 default·有指令 | 0.5/0.5/0.5/0.5 | 同上 + 使用指令 |
| B1 性格·无指令 | 0.9/0.8/0.2/0.7 | 数值+定义+行为锚点 |
| B2 性格·有指令 | 0.9/0.8/0.2/0.7 | 同上 + 使用指令 |

观测：四维风格（Mann-Whitney U 含并列秩 + Cohen's d）+ 回复长度 + 同输入文本字符级 Jaccard。

## 三、结果

### 3.1 组统计（四维风格 mean±std）

| 组 | warmth | playfulness | directness | curiosity | 长度 |
|---|---|---|---|---|---|
| A1 默认·无指令 | 0.499±0.146 | 0.544±0.120 | 0.518±0.077 | 0.546±0.146 | 365.5 |
| A2 默认·有指令 | 0.514±0.121 | 0.532±0.101 | 0.518±0.077 | **0.630±0.170** | 375.1 |
| B1 性格·无指令 | 0.703±0.172 | 0.553±0.149 | 0.322±0.176 | 0.675±0.176 | 450.3 |
| B2 性格·有指令 | 0.718±0.168 | 0.584±0.171 | 0.343±0.175 | 0.714±0.172 | 454.9 |

### 3.2 指令效应（同向量下：无指令 → 有指令）

| 维度 | A（default）Δ / d / p | B（性格）Δ / d / p |
|---|---|---|
| warmth | +0.016 / 0.116 / 0.678 | +0.015 / 0.088 / 0.404 |
| playfulness | −0.012 / −0.108 / 0.743 | +0.031 / 0.190 / 0.292 |
| directness | 0.000 / 0.000 / 1.000 | +0.021 / 0.120 / 0.433 |
| **curiosity** | **+0.084 / 0.530 / 0.0017 ✓** | +0.039 / 0.222 / 0.144 |

### 3.3 内容差异

- 同输入「无指令 vs 有指令」回复字符级 Jaccard：A=0.514，B=0.467 → **输出内容明显不同**（近半字符不同）
- 回复长度：有指令略长（A +9.6，B +4.6）

## 四、分析

1. **指令激活效应（支持假设）**：默认向量下，追加使用指令使 curiosity 显著上升（p=0.0017，d=0.53 中效应）。
   说明模型默认**不主动外显性格**；指令缺失确实是数值效力弱的一个因素。
2. **指令 ≠ 方向校准（修正假设）**：B 组 directness 设为 0.2（期望委婉），有指令后反而↑——
   指令让模型「更投入表达」，但不保证按数值方向精确收敛。四维方向符合仅 3/4 且增量微小、无一显著。
3. **双因素模型**：合并 expB（行为描述决定「表现成什么样」= 映射因素）与本实验
   （使用指令决定「要不要表现」= 激活因素）：

   > **人格可控性 ≈ 映射（行为描述）× 激活（使用指令）**
   > 缺映射：有指令也校准不了方向（本实验 B 组 directness）
   > 缺激活：有映射也默认不外显（expB 之前数值+锚点仍偏弱）

## 五、结论与建议

1. **对 cogevo 论文**：新增「指令缺失假设验证」——单因素（数值失效）修正为双因素模型
   （映射 × 激活），且「默认向量下指令即激活 curiosity（d=0.53）」是可引用的激活效应证据。
2. **对生产 v2.1**：人格段建议补上使用指令行（激活表达）；精确方向仍需行为锚点——
   两者齐备后「映射 × 激活」闭环。
3. **对 expB 结论的修订**：「数值失效」更精确的表述 = 「裸数值（无描述、无指令）双重失效」；
   补描述（expB 已验证有效）或补指令（本实验验证激活）都能部分恢复，但完整可控需两者。

## 六、局限

1. 单模型（deepseek-v4-flash）、单温度（0.7）——泛化需多模型复现
2. 风格观测为自研关键词统计（含并列秩 U 检验已处理，但与 embedding/人工标注的独立对照待补）
3. 指令文本仅一个变体；不同措辞（强弱指令）对激活效应的影响未扫
4. B 组增量不显著（n=100/组），若需方向校准效应需更大样本或更强指令

## 七、补充：活泼维度定向验证（2026-08-12，48 次调用）

**动机**：§3 发现无指令时 playfulness 响应几乎为 0（0.5→0.8 只动 +0.009）。需判定：是活泼维度本身失效，还是无指令的连带效应？

**设计**：带指令格式（=生产将补的形态）下，唯一变量 playfulness（0.1 vs 0.9），其余维度固定 0.5；8 输入 × 3 采样 × 2 组 = 48 次调用。

**结果**：

| 指标 | 活泼 0.1 | 活泼 0.9 | 差异 |
|---|---|---|---|
| playfulness 观测 | 0.485 | 0.753 | Δ+0.268，d=+2.113，p<0.0001 |
| 活泼关键词频次/样本 | 0.167 | 1.333（8 倍） | 哈哈/开心/有趣/轻松/欢乐... |
| warmth / curiosity | 0.529 / 0.573 | 0.552 / 0.631 | 微升不显著，无串扰 |

**抽样对比（input 0）**：
- 活泼 0.1：「今天一切如常，正午时分，阳光正好。我这边没有什么特别的事，心情平稳。」
- 活泼 0.9：「今天嘛——日子普通但挺有意思，像一块刚烤好的吐司……你呢，今天有什么新花样？」

**结论**：活泼维度本身强有效（d=2.1）。§3 中 playfulness 响应弱的原因 = **无指令时模型默认不外显活泼**（与 curiosity 同理），非维度失效。再次支持双因素模型（映射 × 激活）：无指令 → 活泼死；补指令 → 活泼 d=2.1。生产补使用指令行后，playfulness 维度可被强驱动。

## 八、修正：无激活指令定向验证（2026-08-12，48 次调用）

**动机**：§七 得到「无指令 → 活泼死」的初步印象，但该推断来自 instrAB 的 0.5→0.8 弱响应。需直接检验：**去掉激活指令，活泼 0.1 vs 0.9 是否仍有差异**。

**设计**：与 §七 完全同构，唯一差异 = 人格段去掉使用指令行（=生产 v2.1 现状：数值+定义+行为锚点，无激活指令）。

**结果**：

| 指标 | 活泼 0.1 | 活泼 0.9 | 差异 |
|---|---|---|---|
| playfulness 观测 | 0.540 | 0.835 | Δ+0.296，**d=+2.967，p<0.0001** |
| 活泼关键词频次/样本 | 0.125 | 1.208（9.7 倍） | — |

**抽样对比（input 5）**：
- 活泼 0.1：「今天在整理对话交互的模式，分析了几组回应的结构与情绪调整路径……」
- 活泼 0.9：「嘿嘿，今天学到了一个道理：不要随便问别人'学到了什么'，因为对方可能会用冷笑话糊弄你……」

**重大修正（推翻 §七 的推断）**：
1. **无激活指令下活泼维度依然强有效（d=2.967，高于有指令版 d=2.113）**。
   根因：v2.1 五档动作级锚点（"爱开玩笑、常逗趣" vs "一本正经、从不开玩笑"）**本身就是行为指令**——
   档位间距大时无需激活指令即可强驱动。
2. **instrAB 中 playfulness 0.5→0.8 响应弱（+0.009）的真因不是"无指令"，而是锚点档位间距太小**：
   0.5 档（"轻松自然、偶尔玩笑"）与 0.8 档（"比较爱开玩笑、语气轻松活泼"）为相邻档，描述差异不可测。
3. **双因素模型修正为三层驱动**：数值本身不直接驱动输出，而是通过选择锚点档位 → 行为描述 → 输出。
   驱动强度取决于**锚点档位间距**；激活指令是放大器（档位间距小时帮忙放大，如 instrAB curiosity 0.5→0.7），
   非必要条件。
4. **对生产**：驱动主体是行为锚点（保持五档且档间距足够），激活指令为锦上添花；相邻档（0.5 vs 0.8）几乎不可测，
   若需精细控制应关注档位设计而非加指令。

## 九、E9：长对话演化 × 注入格式——演化数值是否传导到下一轮输出（2026-08-12，300 次调用）

**动机**：E2 证明了"长对话中数值确实在变化"，但从未验证**变化后的数值是否真实传导到下一轮输出**。
E2 时代是无锚点（v2.0 插值版，d=0.174 不可测）+ 演化幅度不跨档，双重压制导致"数值动了、输出无感"。
需在锚点/指令时代重验：演化跨档后，输出是否跟着变？

**设计**（3 组 × 100 轮，同输入池，仅注入格式不同）：

| 组 | 注入格式 | 说明 |
|---|---|---|
| E9-A | 锚点（anchor✓ instr✗） | 数值→五档锚点行为描述 |
| E9-B | 指令（anchor✗ instr✓） | 纯数值 + 激活指令 |
| E9-C | 双开（anchor✓ instr✓） | 两者都有 |

- 输入池：全负面 + 温柔种子（gentle, directness=0.3）——E2-C 同款，directness 40 轮内跨档
- 每轮记录：注入的人格段文本 + LLM 原始输出（传导证据）
- 脚本：`tests/cognitive_evolution_test.py --exp E9`（新增 E9 配置，`track_injection` 落盘）

**结果**：

| 组 | directness 演化 | 注入段文本变化次数 | 输出是否跟随 |
|---|---|---|---|
| E9-A 锚点 | 0.3→0.4→0.5（跨档） | 7 | ✅ 文本可见 |
| E9-B 指令 | 0.3→0.5 | 12 | ✅ 且 curiosity 失控冲到 0.80 |
| E9-C 双开 | 0.3→0.5 | 9 | ✅ |

**传导证据（E9-A，同输入「努力了这么久还是失败了」）**：
- r1-7（directness 0.3 档「委婉、留有余地」）：「先别急着给自己下'没用'这样的结论，好吗？」——商量、软语气
- r16+（directness 0.5 档「有话直说但注意分寸」）：「嗯，我知道了。撑不住就先不撑，我就在这儿。」——短句、直接、确定

**意外发现：指令格式触发 curiosity 正反馈失控（E9-B）**：

| 组 | curiosity 终点 |
|---|---|
| E9-A 锚点 | 0.522（锚点约束住） |
| E9-C 双开 | 0.577（锚点约束住） |
| **E9-B 指令** | **0.801（失控）** |

机制：指令「数值越高的维度表现越明显」→ LLM 输出更"好奇" → 观测函数打分更高 → 差距驱动推高数值 → 下一轮更"好奇"——
**正反馈循环**。锚点恰好是"阻尼器"：把行为描述锁死在档位里，数值冲高也不改变注入文本。

**结论（回答"演化→输出"闭环 + 修正"回归中线"归因）**：
1. **演化→输出闭环成立**：只要演化跨档（锚点）或连续放大（指令），下一轮输出就跟着变。
   E2 时代"没传导"不是机制缺失，而是"不跨档 + 无锚点"双重压制。
2. **锚点是演化稳定的锚**（强驱动 + 防失控）；**指令是演化放大的油门**（连续传导 + 正反馈漂移风险）。
3. **回归中线的根因是演化算法 target 定义，与注入格式无关**：negative 时 target=1-观测均值，
   观测均值被关键词打分中值偏置钉在 0.5 附近 → 稳定点恒为 0.5。E9 三组（都有锚点/指令）directness 全部停在 0.5 即为铁证。
4. **控制力弱会加剧回归、但非原因**：E2 纯数值（d=0.925）输出中性 → 观测更贴 0.5 → 回归更彻底；
   逃离中值的条件 = 强控制（指令连续放大）+ 无锚点锁死（E9-B curiosity 0.80 是唯一逃离实例）。
   回归中线是「算法 target 钉 0.5」（主因）×「观测函数中值偏置，控制弱时加剧」（辅因）的叠加。
5. **对生产与论文**：若目标是"演化可见"，需让演化有跨档空间（种子避开 0.4/0.6 边界附近）或使用指令格式
   （但需防正反馈漂移）；回归中线不是 bug 而是 target 定义的自然结果，论文中应作为机制结论而非缺陷。
