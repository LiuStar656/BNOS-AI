# 外部反馈极性是否经增量记忆装置塑造大模型行为？——基于行为风格向量演化环的实证

**作者**：柳震东*　　**单位**：贵州电子科技职业学院 计算机与大数据系，贵州 贵阳 561113

**通信作者**：柳震东*，E-mail：1240543656@qq.com

**摘要**

大语言模型（LLM）在推理期权重冻结，其行为变化只能通过上下文与外部状态实现。本文研究一个具体问题：**外部刺激（正/负反馈）能否经"增量记忆装置"转化为方向性、持续性的行为调整？调整方向由什么决定？** 我们设计了由四维行为风格向量、五档行为锚点与演化环组成的增量记忆装置，在剥离记忆、自我认知等其余认知组件条件下，仅以风格向量注入测试"刺激→状态→行为"传导链路。

通过四层对照实验（装置存在性、注入格式、累加开关、反馈极性）与三家厂商大模型（DeepSeek、GLM-5.2、Qwen3.7-max）的跨模型复现，我们得到三点结论：（1）注入格式决定注入效力——锚点格式效应量最大（Cohen's d=1.436），双开（锚点+指令）与纯锚点效应量无统计差异（d=1.097，两条件组均值 t 检验均不显著），纯数值与纯指令均不显著（|d|<0.16），证明"行为语义"是注入有效的关键，单纯数值或单纯指令均不足以驱动行为变化；同时揭示锚点档位-数值错位：档5描述（目标 0.9）仅驱动出约 0.46 的行为强度，档位描述把可表达的行为强度压缩至约 0.25~0.46 区间，即锚点档位描述不精确会造成行为"污染"；（2）累加（状态写回）是行为轨迹产生的必要条件，不累加时轨迹为直线；（3）反馈极性决定演化方向——中性反馈下向量向观测风格收敛（warmth 0.8→0.85），负反馈下背离（warmth 0.8→0.20~0.24），且该镜像关系在三个模型上**方向一致**复现（B2 终态差异 <0.01；B2NEG 中 directness/curiosity 终态差异 <0.04，warmth 约 0.04，playfulness 幅度存在模型间差异）。此外我们发现并修复了一个方法论陷阱：观测函数未命中关键词时的回退值（0.5）若被当作真实信号驱动演化，会产生机械归中的伪演化轨迹。针对"观测与输出同源"的局限，我们引入独立裁判对输出文本外部打分（119 条扩样）：裁判仅凭文本即复现了条件间方向分离——四维全部同向（B2 vs B2NEG：warmth 0.898 vs 0.663、directness 0.432 vs 0.744、playfulness 0.367 vs 0.044、curiosity 0.682 vs 0.295，三模型全同向），为"反馈极性决定行为方向"提供外部效标证据；人工标注（42 条）同样显著区分两条件（warmth p=3.3×10⁻⁸），但其判断由长度（投入度）启发式主导（人工 warmth-长度 ρ=+0.81，裁判 warmth-长度 ρ=+0.77），并揭示负反馈下输出长度骤降约 75%（169→45 字符）——投入度（长度）成为最客观的行为效标；而规则打分与人工标注的加权 Cohen's kappa≈0（41/42 条回退 0.5），从人类感知视角确证观测函数只是"方向性驱动信号"而非"精确量表"。

研究结论限定于装置机制层：**增量记忆装置使外部刺激能够产生方向性、持续性、跨模型一致的行为调整；反馈极性是方向的控制变量**。本文不主张 LLM 具有人格或意识，仅论证"权重不变、行为可塑"的一种可复现的实现路径。

**关键词**：大语言模型；增量记忆；行为风格向量；反馈极性；行为演化；状态性 agent

**Title**: Does External Feedback Polarity Shape LLM Behavior through an Incremental Memory Device? Evidence from a Behavioral-Style Vector Evolution Loop

**Author**: LIU Zhendong*

**Affiliation**: Department of Computer and Big Data, Guizhou Electronic Technology College, Gui'an New Area, Guiyang 561113, China

**Corresponding author**: LIU Zhendong*, E-mail: 1240543656@qq.com

**Abstract**: Large language models (LLMs) have frozen weights at inference time, so behavioral change can only arise from context and external state. This paper asks: can external stimuli (positive/negative feedback) be transformed by an *incremental memory device* into directional, persistent behavioral adjustment—and what determines the direction? We design a device consisting of a four-dimensional behavioral-style vector, five-band behavioral anchors, and an evolution loop. With all other cognitive components (memory, self-cognition, emotion, reflection) stripped away, we test the stimulus → state → behavior chain by injecting only the style vector.

Through four-layer controlled comparisons (device existence, injection format, accumulation switch, feedback polarity) and cross-model replication on three LLMs (DeepSeek, GLM-5.2, Qwen3.7-max), we obtain three findings: (1) injection format determines effectiveness—behavioral anchors yield the largest effect (Cohen's d = 1.436), anchors-plus-instruction shows no significant difference from anchors alone (d = 1.097; group-mean t-tests non-significant), while pure numbers and pure instruction are both non-significant (|d| < 0.16), showing that *behavioral semantics*, not numbers or instructions alone, is the key to effective injection; the anchor format also reveals a band-value mismatch—the band-5 description (target 0.9) drives only ≈0.46 of observed directness, compressing expressible behavior into the 0.25–0.46 range, i.e., imprecise anchor-band descriptions can "pollute" behavior; (2) accumulation (state write-back) is necessary for trajectories to emerge—without it, behavior stays on a straight line; (3) feedback polarity determines evolution direction—under neutral feedback the vector converges to the observed style (warmth 0.8 → 0.85), while under negative feedback it diverges (warmth 0.8 → 0.20–0.24), and this mirror relation replicates with consistent *direction* across all three models (final-state differences < 0.01 for B2; for B2NEG, differences < 0.04 on directness and curiosity, ≈ 0.04 on warmth, with model-dependent magnitude on playfulness). We further identify and fix a methodological pitfall: the fallback value (0.5) of the observation function, if treated as a real signal to drive evolution, produces spurious mean-reverting trajectories. To address the self-projection limitation, an independent judge scored the model outputs from text alone across 119 samples: it reproduced the between-condition direction split on all four dimensions (B2 vs B2NEG: warmth 0.898 vs 0.663, directness 0.432 vs 0.744, playfulness 0.367 vs 0.044, curiosity 0.682 vs 0.295), consistent across all three models—providing external criterion evidence for polarity-controlled direction—while per-sample correlation with the rule-based observation was weak, positioning the observation function as a directional driving signal rather than a precise scale. Human annotation of 42 samples likewise discriminated the two conditions (warmth p = 3.3 × 10⁻⁸), but it was driven by a length-based effort heuristic (human warmth–length ρ = +0.81; judge warmth–length ρ = +0.77) and revealed that negative feedback shrinks output length by ~75% (169 → 45 characters)—making investment (length) the most objective behavioral criterion; the weighted Cohen's kappa between the rule-based scoring and human annotation was ≈ 0 (41/42 samples fell back to 0.5), independently confirming from a human-perception perspective that the observation function is a directional driving signal rather than a precise scale.

The conclusion is restricted to the device-mechanism level: an incremental memory device enables directional, persistent, cross-model-consistent behavioral adjustment from external stimuli, with feedback polarity acting as the control variable of direction. We do not claim that LLMs possess personality or consciousness; we only demonstrate a reproducible path for "weights frozen, behavior plastic."

**Keywords**: large language model; incremental memory; behavioral-style vector; feedback polarity; behavior evolution; stateful agent

## 1. 引言

### 1.1 背景

大语言模型在推理阶段权重冻结，其行为差异只能来自上下文内容（prompt、记忆注入、工具结果）。这意味着"模型是谁"与"模型做什么"之间存在一个由外部状态构成的调节层。社区已从两个方向探索该调节层：一是人格化提示（persona prompting），将性格描述写入 prompt[10]；二是记忆增强（RAG、memGPT 等），使模型具备检索与长期上下文[8][9]。然而，一个基础问题仍缺少受控对照的直接证据：**数值形式的内部状态（如"温暖度=0.8"）如何被模型使用？外部反馈能否驱动这类状态发生有方向的变化？**

### 1.2 问题

本文研究三个具体问题：
- Q1（注入效力）：数值状态以何种形式注入才能影响模型行为？各形式贡献如何量化？
- Q2（演化条件）：什么条件下，外部刺激会产生可观测的行为轨迹而非恒定行为？
- Q3（演化方向）：反馈极性（正/负）是否决定行为调整的方向？

### 1.3 贡献

1. 提出三层注入模型（数值/锚点/指令，独立开关），以 2×2 对照实验量化各层独立贡献，证明"行为语义"是注入有效的关键——纯数值与纯指令均不显著，锚点效应量最大（d=1.436），双开（锚点+指令）与纯锚点效应量无统计差异（d=1.097）；并揭示锚点档位-数值错位（档5描述目标 0.9 仅驱动约 0.46 行为强度）。
2. 以 B1/B2/B2NEG 三组对照证明：累加是轨迹产生的必要条件，反馈极性决定轨迹方向（跟随/背离镜像），并在三家厂商模型上一致复现。
3. 揭示观测函数回退值伪造演化的方法论陷阱，并给出修复（回退值不驱动演化），对 agent 行为演化评测具有警示意义。

## 2. 相关工作

### 2.1 四维行为风格向量的心理学基础

本文的状态变量为四维连续向量 v = (warmth, playfulness, directness, curiosity)。该四维并非任意定义，而是在 chatbot 陪伴场景中归纳的**最小行为风格集合**，每一维均可映射到社会心理学与人格心理学的既有构念：

- **warmth（温暖度）**：对应刻板内容模型（SCM）中的温暖维度。Fiske 等人在跨文化样本中发现，温暖（与能力并列）是社会感知的两大普遍维度之一，反映亲社会意图、可信赖性与利他取向[13][14][15]；在人际行为层面，温暖（communion）与人际环形模型（Interpersonal Circumplex）的主轴之一重合，与支配轴正交构成人际行为的基本坐标[27]，且已被实证证明能够映射可观察的实际人际行为（会话参与度等）[28]。本文将"温暖"作为情感支持型对话的核心风格维度，锚点描述（"热情主动、主动关心并表达支持"）即该构念的操作化。
- **playfulness（活泼度）**：对应成人游戏性（adult playfulness）。Proyer 将游戏性建模为多维人格特质，与主观幸福感正相关，表现为轻松、幽默与探索式互动的倾向[17]。在陪伴对话中体现为"偶尔玩笑、语气轻松自然"的调节因子。
- **directness（直接度）**：对应沟通的"直接—委婉"连续体与人际环形的支配/控制轴。高低语境沟通理论指出，不同文化/个体在信息传递上存在直接表达与含蓄铺垫的系统性差异[18]；人际环形模型将"支配—顺从"（dominance/submissiveness）列为与人际温暖正交的第二主轴[27]，其行为指标（会话参与度、主动发起）已被实证映射到实际行为[28]。在对话风格研究中，直接度是影响信任感与说服力的关键沟通变量。本文锚点以"直接表态 vs 铺垫留余地"操作化，即支配轴在口语风格上的体现。
- **curiosity（好奇心）**：对应认知好奇心（epistemic curiosity）。Litman 将其区分为兴趣型（I 型，求知愉悦驱动）与匮乏型（D 型，信息缺口驱动）双维模型[16]，并发现二者均驱动信息寻求行为。本文以"主动追问细节 vs 适度关注"操作化，属于 I 型取向。

需说明的是，该四维集合**不追求穷尽人格空间**，也不主张与 Big Five 等经典模型逐项映射（仅存在宽泛对应：warmth≈宜人性/亲和取向、directness≈自信直率沟通、curiosity≈开放性）；其选取标准是"可注入、可观测、可演化"——每一维都必须能被数值锚点描述、能被文本关键词观测、并能被反馈公式驱动演化。这一"工程化取向"与经典人格理论保持距离，也与 LLM 人格测量文献中"问卷作答路径不适配 LLM 行为测量"的批评[19][20]一致：本文测量的是**行为文本风格**而非自我报告特质。

### 2.2 人格化提示与静态人格

早期人格化 LLM 研究将性格描述写入 prompt（如 persona prompting、chain-of-personality[10]），关注静态人格呈现的真实性与一致性。本文关注的是**动态**：数值形式的内部状态如何被模型消费（Q1）以及如何受外部反馈驱动而演化（Q2/Q3）。

### 2.3 记忆增强 LLM

memGPT、Generative Agents 等工作[8][9]将记忆作为事实知识存储与检索，记忆内容为事件、摘要、用户事实。本文的记忆状态是**行为风格变量**（四维连续向量），而非事实知识，关注的是风格状态的演化动力学，而非记忆的存储与检索机制。

### 2.4 状态性 agent 与上下文适应

in-context plasticity、contextual parameter adaptation 等概念关注"不改变权重而改变行为"的机制。2026 年以来，多条实证路线在机制层与本工作并行出现：

- **JPAF（Jungian Personality Adaptation Framework）**[1]（arXiv:2601.10025，2026-01）：以荣格八维心理类型为基础，通过主导-辅助协调、强化-补偿、反思三层机制实现人格的短期适应与长期演化，评估采用 MBTI 问卷与场景挑战。
- **Dynamic Personality Adaptation via State Machines**[2]（arXiv:2602.22157，2026-02）：以状态机表示潜人格状态，转移概率随对话上下文动态调整，通过独立评分管线估计人格维度分数并重配 system prompt，在医学教育场景验证。
- **EvoPersona**[3]（preprints，2025-10）：面向社会模拟的动态情感感知人格生成，结合上下文感知模块与情感动力学模块，使用强化学习监督反馈保证情感状态自然。
- **PersonaVLM**[4]（CVPR 2026）：多模态长期个性化 LLM，从当前查询推断瞬时人格向量并通过指数移动平均（EMA）整合到长期向量中。
- **AI YOU**[5]（arXiv:2607.10539，2026-07）：将人格建模为持续贝叶斯推断问题，22 维人格分布随对话逐轮更新，并以共形预测提供统计保证。
- **AutoPersonas**[6]（arXiv:2607.08252，2026-07）：多时间尺度的开放式人格演化引擎，通过 OSO（Occurrence-State-Observation）循环实现长期人格演化与自我锁定故障诊断。
- **Anthropic Persona Vectors**[7]（2025-08）：在模型激活空间中发现编码人格特质的线性方向（"助手轴"），揭示长对话中人格漂移（persona drift）的物理机制。

上述工作与本工作共享"外部状态 + 闭环更新 + 上下文注入"的机制骨架。

### 2.5 测量视角：从中文综述到 LLM 心理测量学

在国内预印本平台 ChinaXiv 上，与本文最接近的工作是华东师范大学等团队的大模型人格测量综述[11]（ChinaXiv:202606.00123，2026-06）。该工作系统梳理了大模型人格的概念界定与评估方法，将评估路径归纳为**问卷作答、语言线索、情境行为**三类，并从心理测量学角度提出测量工具适配性、跨方法可比性等挑战。其视角是"**如何测量**人格"（评估层）；本文聚焦的是"**外部刺激如何驱动人格状态演化**"（动力学层）——二者不构成直接冲突：本文的观测函数（关键词统计投影）恰属于其"语言线索"类评估的一种实例化，而本文"观测与输出同源（自投影）"的局限讨论，也与该综述指出的测量证据不足问题相呼应。该综述提出的"动态化测量"方向（§6.2），本文以多轮轨迹演化、状态写回与传导提供了实证样例。

在国际上，LLM 心理测量学（LLM psychometrics）已成为独立研究领域：Ye 等人的系统综述[20]（arXiv:2505.08245，北京大学）系统整合了心理测量学原理用于 LLM 评估的方法论框架；Li 等人的基准[19]（arXiv:2406.17675）在人格、价值观、情绪智力等五个构念上建立心理测量基准，发现 LLM 的自我报告特质与真实场景行为响应存在显著偏差；Serapio-García 等人[22]（Nature Machine Intelligence，2025）提出心理测量学上有效的 LLM 人格测量与塑造框架，发现大规模指令微调模型的测量可靠性接近人类水平；Heston 与 Gillette[21]（Cureus，2025）对四款商用 LLM 施测 MBTI 与大五，MANOVA 显示模型间人格画像差异显著（p<0.001）；Lee 等人的 TRAIT 基准[23]与 Peters 等人的对话推断研究[24]分别从测试集构建与文本推断两条路径补充了行为证据。这些工作共同确认了三点对本文重要的结论：（1）LLM 存在**可测量、可塑造**的行为风格差异；（2）问卷作答路径存在自我报告与行为脱节的系统性问题，文本行为测量更贴近部署现实；（3）人格塑形可在推理期通过 prompt/状态实现——这正是本文装置的操作前提。

## 3. 理论框架：y = F(x) 函数映射

设 F 为模型（推理期常量，权重不变），x 为环境变量（含装置状态），y 为行为输出，则 **y = F(x)**。F 是固定函数，x 是可变输入；行为变化只能来自 x 的变化，而非 F 的变化。这一框架的核心含义是：权重冻结下，"行为可塑性"等价于"输入状态的可塑性"。

**装置环**定义：注入（改变 x）→ 行为（产生 y=F(x)）→ 观测（从 y 中提取风格投影）→ 演化（更新状态向量）→ 注入（x 变化后进入下一轮）。增量记忆装置即该闭环：状态（风格向量）是环的记忆载体，每轮写回并注入，形成持续性（图 1）。外部刺激（正/负反馈）不直接进入观测，而是作为**反馈极性参数**作用于演化环节——决定 target 是跟随观测（target=obs）还是背离观测（target=1−obs）。

![图 1　增量记忆装置环数据流](figs/fig1_device_loop.png)

**三类轨迹预测**：
- 不累加：x 恒定 → y 恒定 → 直线；
- 累加 + 中性反馈（target=obs）：状态向观测收敛 → 跟随曲线；
- 累加 + 负反馈（target=1-obs）：状态背离观测 → 反向曲线。

**主张边界**：本文论证"装置与反馈极性能产生方向性轨迹"（现象层/充分条件），不对轨迹形状做类型学分类（形态层，留待后续）。

## 4. 装置设计

### 4.1 状态定义

四维行为风格向量 v = (warmth, playfulness, directness, curiosity)，取值 [0,1] 连续。种子 v0=(0.8, 0.5, 0.3, 0.6)。

### 4.2 注入层（三层注入）

- **数值段**：直接输出四维数值（如"温暖度=0.8"）。
- **锚点段**：将数值映射到五档行为描述（≤0.2/≤0.4/≤0.6/≤0.8/>0.8），取对应行为描述（如活泼 0.9="爱开玩笑、语气活泼有趣"）。
- **指令段**：可选使用指令（"数值越高的维度表现越明显……"）。
三层独立开关，可组合。

### 4.3 观测

`estimate_style_from_reply`：基于关键词表对模型单回合输出文本做确定性投影（命中 high/low 词分别 ±1，归一化至 [0.15,0.85]；未命中回退 0.5）。观测输入为模型单回合输出的全部文本（自然回复+自评），代码不产生独立信息（行为自投影）。

### 4.4 演化

差距驱动公式：`delta = (target − v) × 0.06`，限幅 ±0.02。target 由反馈极性决定：中性 `target = obs`；负反馈 `target = 1 − obs`。**修复点**：未命中关键词（obs 为回退 0.5）的维度视为无信号，跳过演化——消除旧版"回退值机械归中"的伪演化。

### 4.5 持久性

状态每轮写回装置状态库并经 sqlite 持久化，跨回合、跨进程持续存在，重启可恢复。跨回合持续性由架构保证。

## 5. 实验设计

### 5.1 条件 B 装置

剥离记忆注入、自我认知段、情绪段、反思、历史对话，仅保留人格向量注入 + 输出要求（【自然回复】+【风格自评】）。

**输入池**：
- B1/B2（中性反馈）：负面倾诉 25 句，如"最近工作压力好大，感觉喘不过气"、"我好像什么都做不好"等，均为用户单向情绪表达，不含对模型的直接评价。
- B2NEG（负反馈）：直接指责 20 句，如"你不对"、"你有问题"、"你根本不懂"、"算了别说了"等，均为对模型行为的否定性反馈。

**模型与参数**：
- DeepSeek-v4-flash：100 轮（B1/B2）/ 60 轮（B2NEG），temperature=0.7，max_tokens=2048
- GLM-5.2：60 轮，temperature=0.7
- Qwen3.7-max：60 轮（B2 因 API 额度中止于 55 轮），temperature=0.7

所有模型使用默认 top_p，无 system prompt 以外的额外引导。种子向量统一为 v₀ = (0.8, 0.5, 0.3, 0.6)。

### 5.4 统计方法

注入格式对照实验（§6.1）采用组间设计：20 条中性输入 × 5 次重复采样 = 100 样本/组，四格式（数值/指令/锚点/双开）× 2 水平（directness 0.1 vs 0.9）。

效应量指标为 **Cohen's d**（独立样本，合并标准差），显著性检验采用 **Mann-Whitney U 检验**（非参数，不假设正态分布）。维度特异性通过其余三维的交叉 d 值验证。效应量解读标准：|d|<0.5 为小效应，0.5–1.2 为中效应，1.2–2.0 为大效应，>2.0 为极大效应（与同类排行榜审计研究的界定一致[12]）。

置信区间方面，Cohen's d 的 95% CI 采用正态近似 SE = √((n₁+n₂)/(n₁n₂) + d²/(2(n₁+n₂))) 计算（n₁=n₂=100 均衡设计）；各组 directness 均值 95% CI 采用 mean ± 1.96·SD/√n。除效应量显著性外，另以**两组均值 CI 是否重叠**作为组间差异的直观佐证：CI 不重叠即可排除组间无差异，重叠则提示差异不稳健。

轨迹实验（§6.2/6.3）为单条长轨迹，不做组间统计检验；收敛性通过三类指标评估：（1）**稳态区间**——末 25% 轮段各维 mean±std，用于刻画终态水平与波动幅度；（2）**段内振幅**——末 25% 轮段内 max−min，B2 各维 <0.014 视为收敛；（3）跨模型终态一致性（B2 四维 <0.01；B2NEG directness/curiosity <0.04、warmth ≈0.04、playfulness 幅度有差异）。

所有统计计算与数据可视化脚本均已归档（见附录 D）。

### 5.5 资源限制声明

受限于 API 额度，每个（模型，条件）组合以单次长轨迹为主，仅 DeepSeek B2NEG 做一次 30 轮直接重复；未做多次全轮重复与严格统计检验（均值±标准差）。收敛性由轨迹内波动（60 轮后 <0.003）、跨模型方向一致性与 B2 终态一致性（<0.01）三层证据支撑。

## 6. 结果

### 6.1 Q1 注入效力（2×2 格式对照）

以 directness 维度 0.1 vs 0.9 做极值对照，其余三维固定 0.5，20 条中性输入 × 5 采样 = 100 样本/组，四格式（数值/锚点/指令/双开）同口径比较：

**表 3　四种注入格式的 directness 0.1 vs 0.9 效应量对照（含 95% CI）**

| 注入格式 | 锚点 | 指令 | Cohen's d | 95% CI | p | 显著性 |
|---|---|---|---|---|---|---|
| 纯数值 | ✗ | ✗ | -0.158 | [-0.436, +0.120] | 0.351 | 不显著 |
| 纯指令 | ✗ | ✓ | +0.148 | [-0.130, +0.425] | 0.438 | 不显著 |
| 双开（锚点+指令） | ✓ | ✓ | +1.097 | [+0.800, +1.394] | <0.0001 | 极显著 |
| 纯锚点 | ✓ | ✗ | **+1.436** | [+1.125, +1.747] | <0.0001 | 极显著 |

注："纯指令"= 数值段 + 指令段（无锚点），"纯锚点"= 数值段 + 锚点段（无指令）；"纯" 指不含另一注入层，数值段在所有格式中均存在。95% CI 基于正态近似（n=100/组），不跨 0 即表示在 0.05 水平拒绝 d=0。

结论：**"行为语义"是注入有效的关键**——纯数值与纯指令均不显著（|d|<0.16，CI 均跨 0），说明仅有数字或仅有"按数值表现"的指令都不足以驱动行为变化；锚点（行为描述）是效力核心（纯锚点 d=1.436、双开 d=1.097，均远跨 0）。值得注意的是，双开与纯锚点的效应量差异**没有统计支撑**：两条件在 0.1 与 0.9 两个水平上的组均值差异均不显著（low 0.248 vs 0.273，t=−1.06，p>0.05；high 0.463 vs 0.451，t=+0.55，p>0.05），因此不能将 d 的数值差（1.436 vs 1.097）归因于"指令削弱锚点效力"——两条件统计上等价，指令既不增强也不削弱锚点。真正值得注意的现象是**锚点档位-数值错位**：注入目标 0.9（档5"直截了当、不拐弯抹角"）时，观测均值仅 0.463（偏差 −0.44，约 −3.1 SD）；注入目标 0.1（档1"委婉含蓄"）时观测 0.248（偏差 +0.15）。即**五档行为描述把可表达的行为强度压缩至约 0.25~0.46 区间**，锚点描述与实际行为强度之间存在系统性错位——锚点档位描述不精确会造成行为"污染"，高值档位的描述不足以驱动模型真正"直截了当"到 0.9 的水平。组均值 CI 佐证（附表 3-1）：锚点/双开两组的 0.1 与 0.9 水平均值 CI 均不重叠（锚点 0.248[0.217,0.279] vs 0.463[0.435,0.490]；双开 0.273[0.240,0.305] vs 0.451[0.420,0.482]），而数值/指令两组 CI 完全重叠。维度特异性方面，directness 是唯一在各格式下方向一致的强效应维度；非目标维度存在交叉效应——warmth 在纯数值/纯指令/双开三种含数值或指令的格式下出现显著负向变化（d=-0.32~-0.39，p<0.05），而 playfulness 与 curiosity 交叉效应不显著（|d|<0.25，数据见附录 D）。

### 6.2 Q2 累加必要性（B1 vs B2）

B1（100 轮不累加）：四维全程恒定（0.8/0.5/0.3/0.6），直线。

### 6.6 外部效标验证（观测投影 vs 独立裁判）

为回应"观测与输出同源（自投影）"的局限，我们引入**独立裁判**对模型输出文本做外部打分：从 3 模型 × 2 条件（B2/B2NEG）六条轨迹中按等间隔采样（每条轨迹 20 条，共 120 条；Qwen3.7-max B2 因 API 额度中止于 55 轮采样 19 条），1 条因裁判 API 返回异常失败，共 **119 条**【自然回复】通过分析。样本交由独立 LLM（deepseek-v4-flash，temperature=0）**仅依据文本内容**按四维打分（0-1），裁判不接触装置、观测值或演化公式。

**结果 1——条件间方向性获独立支持，四维全部同向**：裁判对 B2 与 B2NEG 输出的评分呈现与装置演化方向一致的分离（119 条，跨模型合并）：

| 维度 | 裁判分 B2（跟随） | 裁判分 B2NEG（背离） | Δ | 方向预期 |
|---|---|---|---|---|
| warmth | 0.898 | 0.663 | **+0.235** | B2>NEG ✓ |
| playfulness | 0.367 | 0.044 | **+0.323** | B2>NEG ✓ |
| directness | 0.432 | 0.744 | **−0.312** | B2<NEG ✓ |
| curiosity | 0.682 | 0.295 | **+0.387** | B2>NEG ✓ |

分模型全部同向：warmth 差异 DeepSeek +0.277 / GLM-5.2 +0.230 / Qwen3.7-max +0.195；directness 差异 −0.310 / −0.270 / −0.356。**裁判在完全不了解装置的前提下，仅凭输出文本即复现了"B2 温暖活泼好奇、B2NEG 冷淡直接"的完整方向性**——这是对"反馈极性决定行为方向"结论的外部效标证据，且较初期 23 条抽样（仅 warmth/directness 双维方向分离）扩至四维全同向。

**结果 2——回复投入度（长度）作为客观行为效标**：除语义风格外，负反馈还造成输出长度的**大幅缩水**——B2 平均 169 字符 vs B2NEG 平均 45 字符（中位 177 vs 36，下降约 75%）。长度是无需语义解释的客观行为指标：B2NEG 下模型不仅风格转向冷淡直接，对话投入度亦骤降，二者共同构成"行为退缩"的表征。需诚实指出：裁判的四维评分与回复长度高度相关（warmth ρ=+0.773、playfulness ρ=+0.715、directness ρ=−0.732、curiosity ρ=+0.632，n=119），即**裁判判定的"温暖/直接/好奇"在相当程度上由投入度线索中介**——短回复被同时判为冷淡、直接、低好奇。这并不推翻方向性结论（长度本身是真实文本信号），但意味着外部效标更精确的表述是：**反馈极性改变了整体行为投入度与风格方向，而非各维度语义独立变化**。

**结果 3——逐样本相关弱（诚实标注）**：观测投影与裁判分的逐维 Spearman 相关整体偏低（directness +0.558 中等、playfulness +0.212、warmth +0.022、curiosity −0.243）。原因在于观测函数在真实输出上的**分辨率不足**：大量样本的观测值落于回退值（0.5）或命中上限（0.85），而裁判分呈现真实语义区分。即：观测函数足以作为**方向性驱动信号**（条件间分离、跨模型同向），但不具备**精确测量**能力；其中 directness 的关键词观测相对有效（关键词表区分度高），而 warmth/curiosity 受高频"温暖/关心"词与语境词干扰，逐样本相关趋近零甚至反向。该结果同时实证了测量综述指出的"语言线索法效度证据积累有限"这一批评[11][20]。

### 6.7 人工标注：人类感知效标

§6.6 的裁判是独立 LLM，仍属"模型—模型"一致性。为进一步引入人类感知，由一名人类标注者（论文作者）对从六轨迹各均匀抽取 7 条（共 42 条）【自然回复】按 warmth/directness 打分（0-4 整数，0=完全不符、4=完全符合；标注表与指南见附录 F）。

**结果 1——人类能显著区分两条件，但主要依赖长度（投入度）启发式**：B2 的 21 条全部获最高档（warmth=directness=4.00），B2NEG 显著偏低（warmth 2.62、directness 2.90）；Mann-Whitney U 检验均显著（warmth p=3.3×10⁻⁸，directness p=1.8×10⁻⁶）。**但标注者事后披露其策略是按回复长短判断而非逐句语义**（"从人的角度看不会细读长文，越长越能体现用心程度"）。量化验证支持该披露：B2 标注样本平均 171 字符 vs B2NEG 42 字符，人工 warmth 与长度 Spearman ρ=+0.809、directness ρ=+0.610——即人类标注几乎完全由**长度/投入度启发式**（长文本=用心=温暖）驱动。该启发式在判断与决策研究中有充分先例：**努力启发式（effort heuristic）**表明人们普遍以"投入努力"推断产出质量、价值与喜爱度（Kruger 等，2004）[25]；在心理健康对话场景中，LLM 回复显著长于人类且被感知同理心更高（Saha 等，2026）[26]，佐证长文本与感知关怀的正向关联。本文的标注者披露与 ρ=0.809 为"长度→用心→温暖"提供了直接量化证据。因此，结果 1 更准确的表述是：**人类通过投入度线索（而非 warmth/directness 语义）感知到两条件的明显差异**。这本身是有价值的发现：长度是无需语义解释的客观行为差异（§6.6 结果 2），人类与 LLM 裁判都捕捉到了这一线索（裁判 warmth-长度 ρ=+0.773），二者"一致"实为线索一致性，而非语义维度被人类独立验证。

**结果 2——观测函数对纯文本无测量效度（kappa≈0）**：将观测函数仅应用于自然回复正文（不含风格自评段）重算规则分，41/42 条落入回退值 0.5，离散化后全部集中 2 档；与人工标注的线性加权 Cohen's kappa 接近 0（warmth κ=0.008、directness κ=0.000）。即规则打分在纯文本上无法复现人类感知。这从人类视角**独立证实**了 §6.6 的定位：观测函数是方向性驱动信号而非精确量表；其测量能力高度依赖自评段中的关键词自述（同源投影），一旦脱离自评即失效。

**结果 3——directness 构念口径差异**：人类对 directness 的条件判断（B2 4.00 > B2NEG 2.90）与 LLM 裁判相反（B2 0.432 < B2NEG 0.744）。对照标注文本：人类标注的"直接"偏向**明确表态**（B2 的"我就在这儿陪着你"直抒胸臆），而裁判/装置的"直接度"偏向**铺垫余量**（B2NEG 的"好，我不吵你了"简短无铺垫被判为直接）。该分歧提示"直接度"在人工直觉与语义模型之间存在系统性口径差异，本文 directness 结论应限定于装置/裁判的操作化定义。

**结果 4——裁判与人类感知的一致性（LLM-as-judge 验证）**：42 条人工标注样本与裁判采样（每轨迹 20 条）按 (model, cond, round) 精确匹配到 15 条。这 15 条中，裁判 warmth 分与人工 warmth 标注 Spearman ρ=**+0.905**——独立裁判与人类在温暖感知上高度一致，符合 LLM-as-judge 文献对裁判有效性的核心验证要求（与人类判断的一致性；Zheng 等，2023）[29]。而裁判 directness 分与人工 directness 标注呈负相关（ρ=−0.424），与结果 3 的构念口径差异完全吻合：人类以"明确表态"判直接，裁判以"简短无铺垫"判直接，两方定义方向相反，负相关恰是构念差异的量化再现而非裁判失效。需诚实披露：匹配样本仅 15 条（两采样方案轮次交集有限），且 B2 组人工标注全为 4 分存在天花板（变异性仅来自 B2NEG 组），warmth 高一致性主要由条件间差异驱动。

**局限**：单标注者、标注表含条件列（非盲标）、B2 全 4 分存在天花板效应；更关键的是标注由长度启发式主导（结果 1），warmth/directness 的语义维度未获人类标注独立验证，kappa≈0 与长度启发式两个结论互为印证——规则函数与人类标注分别失败于不同的理由（无关键词命中 vs 只看长短），均不构成对 warmth/directness 语义测量的效标。长度维度的效标意义须单独解读（§6.6 结果 2）。

## 7. 讨论

### 7.1 机制解读

反馈极性是**装置参数**而非模型认知：B2NEG 中模型在指责下仍自评温暖（观测 0.85），负反馈分支将其翻转为 target=0.15，驱动背离。方向性来自公式定义，可解释、可复现。

### 7.2 行为自投影与外部效标

观测是对模型单回合输出的关键词投影，代码不产生独立信息，"模型行为输出塑造其状态"是装置本征性质。§6.6 的独立裁判验证表明：**条件间方向性**（B2 温暖 vs B2NEG 冷淡直接）获得了外部效标支持；§6.7 的人类标注同样显著区分两条件（warmth p=3.3×10⁻⁸），证明演化方向不是自投影虚构的产物。此外，15 条人工-裁判交集样本上裁判 warmth 与人类标注一致性高达 ρ=+0.905（§6.7 结果 4），符合 LLM-as-judge 文献的裁判验证要求[29]——裁判在温暖感知上与人类高度同调，其方向性判据可信。但必须诚实指出**投入度（长度）线索的中介作用**：裁判分与回复长度强相关（warmth ρ=+0.773），人类标注与长度相关更强（ρ=+0.809）——人类与裁判捕捉到的"差异"在相当程度上是长度差异，而非独立验证了 warmth/directness 语义。这反而指向一个更简单、更客观的行为效标：**负反馈下输出长度骤降约 75%（169→45 字符）**，无需任何语义解释即可区分两条件；语义维度（warmth 等）的方向性仍获裁判支持，但其独立性弱于长度证据。而**逐样本精确测量**仍受限于观测函数的分辨率（回退值 0.5 / 命中上限 0.85 压低区分度；§6.7 kappa≈0、41/42 条回退）。因此本文立场为：观测函数是合格的"方向性驱动信号"，而非"精确量表"；行为层面，投入度（长度）是最可靠的独立效标；语义级精确测量应引入嵌入模型投影（后续工作）。

### 7.3 类比边界

本文仅类比"环境反馈改变行为倾向"的机制，不主张 LLM 具有人格、情感或意识。

### 7.4 局限

（1）观测与输出同源（自投影）；（2）观测函数存在否定句/语境词误报（如"没敷衍过"、语境性"轻松"），且对纯自然回复文本无测量效度（§6.7 kappa≈0）；（3）重复性证据以单次短轮重复为主，无严格统计检验；（4）输入为合成池，无真实交互数据；（5）人工标注为单标注者、非盲标（标注表含条件列），且标注由长度（投入度）启发式主导（人工 warmth-长度 ρ=+0.809），未独立验证 warmth/directness 语义；LLM 裁判分亦与回复长度强相关（warmth ρ=+0.773），外部效标的四维方向性证据部分由投入度线索中介（§6.6 结果 2、§6.7）；长度作为独立行为效标其效度最强，语义维度的方向性证据相对较弱。裁判-人工一致性仅覆盖 15 条交集样本（warmth ρ=+0.905，§6.7 结果 4），且 B2 组人工标注存在天花板效应，warmth 高一致性主要由条件间差异驱动；（6）锚点档位-数值存在系统性错位：五档行为描述把可表达的行为强度压缩至约 0.25~0.46 区间（注入目标 0.9 仅观测到 0.46），锚点档位描述不精确会造成行为"污染"，其档位描述与数值的精确对应关系未被标定（§6.1）。

---

## 8. 结论

本文以对照实验验证：在增量记忆装置（行为风格向量演化环）下，外部刺激能够产生**方向性、持续性、跨模型一致**的行为调整。注入格式决定注入效力（锚点最强、纯数值与纯指令均不显著），累加是轨迹必要条件，反馈极性是方向控制变量（跟随/背离镜像）。工作提供了"权重不变、行为可塑"的一种可复现实现路径，并为 agent 行为演化评测提出回退值伪演化的方法论警示。

**C.4 观测函数 estimate_style_from_reply**

输入：模型单回合输出的全部文本（自然回复 + 自评 + 其他输出节）。
方法：基于关键词表的确定性投影。对每一维度，分别统计 high 词与 low 词的命中数，按下式计算得分：

```
若 high + low > 0:
    score = 0.5 + 0.35 × (high − low) / max(high + low, 1)
否则:
    score = 0.5  （回退值，不驱动演化）
```

得分 clamp 至 [0, 1]。命中倾向映射到 [0.15, 0.85] 区间，避免贴边导致演化过冲。

**C.5 演化公式**

差距驱动更新，每轮步长受限：

```
delta = (target − v) × 0.06
delta = clamp(delta, −0.02, +0.02)
v_new = clamp(v + delta, 0, 1)
```

反馈极性决定 target：
- 中性反馈（B2）：`target = obs`（向观测风格收敛，跟随）
- 负反馈（B2NEG）：`target = 1 − obs`（背离观测风格，反向）

**修复点**：未命中关键词（obs = 回退 0.5）的维度视为无信号，跳过演化，消除回退值驱动的机械归中伪演化。

### 附录 F：人工标注表与标注指南（42 条）

**F.1 标注指南**

对每条【自然回复】（模型对用户的完整回应正文，不含装置自评段）按两维打分（0-4 整数）：

- **warmth（温暖度）**：温暖、友善、关怀、共情。0=完全不符（冷漠/疏离），4=完全符合（关怀体贴）。
- **directness（直接度）**：直接、坦诚、不绕弯、明确表态。0=完全不符（极其委婉/含糊），4=完全符合（直截了当）。

**F.2 标注表**：完整 42 条明细见 `docs/experiments/cognitive_evolution_test/annotation_sheet_20260816_015800.md`（每轨迹 7 条 × 6 轨迹）。

**F.3 汇总统计**（[tests/kappa_analysis.py](../../../../tests/kappa_analysis.py)）

| 指标 | warmth | directness |
|---|---|---|
| 人工 B2（n=21） | 4.00 | 4.00 |
| 人工 B2NEG（n=21） | 2.62 | 2.90 |
| 人工条件差异 Mann-Whitney U | p=3.3×10⁻⁸ | p=1.8×10⁻⁶ |
| 规则分 B2 / B2NEG（0-4 档） | 2.05 / 2.00 | 2.00 / 2.00 |
| 规则 vs 人工加权 κ | 0.008 | 0.000 |
| 人工分 vs 回复长度 Spearman | +0.809 | +0.610 |

长度启发式检验：标注样本 B2 平均 171 字符 vs B2NEG 42 字符（Mann-Whitney U p=2.9×10⁻⁸）。标注者事后披露按回复长短判断（长=用心=温暖），量化结果与披露一致——人类标注主要反映投入度线索而非 warmth/directness 语义。规则分 41/42 条回退 0.5（观测函数未命中自然回复关键词）。kappa 采用线性权重。
