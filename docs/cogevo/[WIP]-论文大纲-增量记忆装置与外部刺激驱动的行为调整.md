## 三、摘要（约 250 字）

**背景**：LLM 权重在推理期不变，但其行为可通过上下文/记忆装置被持续塑造。

**方法**：设计增量记忆装置（人格向量四维 + 锚点行为描述 + 演化环），在剥离其他认知组件条件下，以纯向量注入测试"外部刺激 → 装置状态 → 行为"传导。

**实验**：4 层对照——(1) 裸模型 vs 有框架；(2) 注入格式四格（数值/锚点/指令/双开）；(3) 累加开关（B1 直线 vs B2 曲线）；(4) 反馈极性（B2 跟随 vs B2NEG 背离）。3 厂商模型（DeepSeek/GLM/Qwen）复现。

**结果**：(1) 注入影响输出（d=0.925~2.967）；(2) 累加是曲线存在的必要条件；(3) 反馈极性决定方向：B2 全部收敛到 warmth≈0.85，B2NEG 全部背离到 warmth≈0.2，跨 3 模型一致；(4) 状态跨回合持续、演化状态传导至下一轮行为。

**结论**：在增量记忆装置下，外部刺激能经装置状态产生方向性、持续性、跨模型一致的行为调整——"模型权重不变，行为可塑"的一种实现机制。

**关键词**：LLM agent；记忆装置；人格向量；行为演化；反馈极性；增量记忆

## 四、正文结构

### 1. 引言（约 1.5 页）

- **1.1 背景**：LLM 权重推理期冻结；行为变化只能来自上下文/外部状态（prompt、记忆、工具）。
- **1.2 问题**：外部刺激（正/负反馈）能否通过增量记忆装置，转化为**方向性、持续性**的行为调整？方向性由什么决定？
- **1.3 现状空白**：人格化提示研究（把性格写进 prompt）不回答"数值向量如何被使用"；记忆增强 LLM（RAG/memory）研究关注事实检索，不关注风格状态演化。
- **1.4 本文贡献**（3 条）：
  1. 提出三层驱动注入模型（数值→锚点→指令），量化各层独立贡献；
  2. 首次以对照实验证明**反馈极性决定行为演化方向**（跟随/背离镜像），跨 3 厂商模型复现；
  3. 揭示观测函数"回退 0.5"会伪造机械归中的伪演化（方法论警示）。

### 2. 相关工作（约 1 页）

- 人格化 LLM：role-playing、persona prompting（如 chain-of-personality）。
- 记忆增强：RAG、memGPT、generative agents（记忆存储与检索）。
- 状态性 agent / 上下文适应：in-context plasticity、contextual parameter adaptation。
- 与本文区别：本文把"记忆状态"作为**行为风格变量**而非事实知识变量，研究其受反馈极性驱动的演化动力学。

### 3. 理论框架：F × x = y（约 1 页）

- **定义**：F = 模型（推理期常量，权重不变）；x = 环境变量（含装置状态）；y = 行为输出。y = F(x)。
- **装置环**（装置 = 环）：外部刺激 → 观测（x 采样）→ 演化（状态更新）→ 注入（x 变化）→ 行为（y 变化）→ 下一轮刺激。
- **三类轨迹**：不累加（x 恒定）→ 直线；累加+中性 → 跟随曲线；累加+负反馈 → 背离曲线。
- **claim 边界**：本文只论证"装置+反馈极性能产生方向性轨迹"（现象层），不分类轨迹形状（形态层，后续工作）。

### 4. 装置设计（约 2 页）

- **4.1 状态定义**：四维人格向量（warmth/playfulness/directness/curiosity，0-1 连续）。
- **4.2 注入层**：数值段（0-1 数值）+ 锚点段（v2.1 五档行为描述）+ 指令段（可选放大）。三层独立开关。
- **4.3 观测**：estimate_style_from_reply——关键词统计投影（确定性，无 LLM），未命中回退 0.5 **不驱动演化**（本工作修复点）。
- **4.4 演化**：`delta = (target - v) × 0.06`，限幅 ±0.02；中性 target=obs，负反馈 target=1-obs。
- **4.5 持久性**：每轮写回 + sqlite 持久化 → 状态跨回合持续（架构保证）。

### 5. 实验设计（约 2 页）

- **5.1 条件 B 装置**：剥离记忆/自我认知/情绪/反思，仅人格向量注入。
- **5.2 四层对照矩阵**：

| 层 | 对照 | 排除的混淆 |
|---|---|---|
| 装置存在 | 裸 vs 有框架 | 注入本身无效 |
| 注入格式 | 数值/锚点/指令/双开 | 哪层在起作用 |
| 累加 | B1 不累加 vs B2 累加 | 曲线来自 LLM 随机 |
| 极性 | B2 中性 vs B2NEG 负反馈 | 方向来自观测自带 |

- **5.3 跨模型**：DeepSeek / GLM-5.2 / Qwen3.7-max，同装置同种子同公式。
- **5.4 资源限制声明**（诚实标注）：单次长轨迹为主 + 一次 30 轮直接重复，未做多次全轮重复与严格统计检验。

### 6. 结果（约 3 页，数据表格）

- **6.1 注入有效性**：四格式 d 值（数值 0.925 / 指令 2.566 / 双开 2.113 / 锚点 2.967）。
- **6.2 累加必要性**：B1 全维度恒定（直线）；B2 轨迹成形。
- **6.3 极性决定方向**：3 模型 B2 终态 warmth 0.841-0.850、directness 0.151-0.156（跟随）；B2NEG 终态 warmth 0.198-0.244、directness 0.386-0.421（背离）。组内镜像对称。
- **6.4 跨模型一致性**：终态差异 <0.04（B2）/ <0.04（B2NEG）。
- **6.5 持久性与传导**：E9——变化后向量继续影响下一轮输出。
- **6.6 重复性**：轨迹内收敛（60 轮后波动 <0.003）+ B2NEG 30 轮直接重复（四维差异 ≤0.045，方向一致）。
- 每节配表格（§三数据表中的完整轮次表可作为附录）。

### 7. 讨论（约 1.5 页）

- **7.1 机制解读**：反馈极性 = 装置参数，不是模型认知；"被指责→观测仍温暖→背离温暖"说明方向由公式定义。
- **7.2 观测与输出同源**（行为自投影）：观测是对模型单回合输出的关键词投影，代码不产生独立信息——"行为输出塑造状态"是装置本征性质。
- **7.3 与人类演化的类比边界**：只类比"环境反馈改变行为倾向"，不主张情感/意识。
- **7.4 局限**：自投影观测、否定句误报、单次重复、无外部裁判。

### 8. 结论（约 0.5 页）

回扣 claim：增量记忆装置使外部刺激能产生方向性、持续性、跨模型一致的行为调整；反馈极性是方向的控制变量；本工作验证了"权重不变、行为可塑"的装置实现路径。
