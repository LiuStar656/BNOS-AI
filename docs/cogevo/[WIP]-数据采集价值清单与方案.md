# 数据采集价值清单与方案（消息池实验·下一版附件）

> 版本：v1.0 | 日期：2026-08-08
> 适用范围：message_pool_test 系列实验（n3_25r / 5a40r_api / 5a40r_v2 / 5a30r 之后）
> 判断标准：数据能否证明系统核心主张——**认知演化闭环**（认知形成→记忆沉淀→行为影响→人格微调）

## 一、价值排序总览

| 优先级 | 数据项 | 证明的主张 | 采集成本 | 当前状态 |
|---|---|---|---|---|
| P0 | 记忆检索命中日志 | 认知→记忆→行为闭环 | 低（管线内埋点） | 缺失 |
| P0 | 静默期间的认知更新 | 弹幕式"听而不说"理念 | 低（静默分支补字段） | 缺失 |
| P0 | 人格漂移过程轨迹 | 认知演化的直接证据 | 中（依赖演化先接通） | 缺失 |
| P1 | 认知网络演化时序 | 社会认知形成过程 | 中（逐轮矩阵快照） | 缺失 |
| P1 | @提及响应率 + user_id 归因正确率 | 多用户认知验证 | 低 | 失败轮未测到 |
| P2 | 批次位置-回应对象对照 | 末位偏置量化 | 零 | 数据在但未计算 |
| P2 | 情绪-行为关联 | 情绪是否影响发言意愿 | 零 | 数据在但未交叉 |
| P3 | 回复相关性、消息生命周期 | 对话质量、轮次口径 | 中 | 缺失 |

## 二、P0 数据采集方案（核心证据链）

### 1. 记忆检索命中日志

- **采集内容**：每次决策时，从 long_term_memory 检索命中的记忆条目（id/内容摘要/相似度分），以及最终被上下文采纳的条目。
- **落点**：decisions.jsonl 新增 `memory_hits: [{id, score, adopted}]` 字段；同时写入 db 的 memory_usage 表（时间戳、决策 id、命中 id、是否采纳）。
- **验证的命题**：认知写入后是否真的在后续对话中被检索、被使用。这是"认知演化"从存储动作升级为行为影响的关键证据。
- **成本**：检索函数内埋点，无额外 LLM 调用。

### 2. 静默期间的认知更新

- **采集内容**：静默决策的"想法"字段改为记录模型真实输出（为什么沉默：没话可说/观察中/等待时机）；静默后是否仍写入了 other_cognition / user_facts / long_term_memory。
- **落点**：decisions.jsonl 静默记录补齐想法与认知写入标记；db 增加 silent_cognition 表。
- **验证的命题**：平台差异化理念"接收消息后处理消息不一定要发言"——静默不等于无认知。这同时解决静默模板污染 reply 的老问题（想法字段与发言判定分离）。
- **成本**：低，静默分支补字段。

### 3. 人格漂移过程轨迹

- **采集内容**：每轮决策后的人格向量快照（warmth/playfulness/directness/curiosity），而非只存 initial/end。
- **落点**：evolution.json 新增 `trajectory: [{round, vector}]`；db 增加 personality_trace 表。
- **验证的命题**：演化是渐进的还是突变的？从第几轮开始动？与哪类交互相关？
- **前置依赖**：先降演化触发阈值（30 次兜底 → 10-12 次），否则永远收不到非零轨迹。
- **成本**：中，依赖演化链路先修通。

## 三、P1 数据采集方案（差异化叙事）

### 4. 认知网络演化时序

- **采集内容**：每 topic 轮结束时的互认矩阵快照（谁认知了谁、新增了几条），形成时间序列。
- **落点**：db 新增 cognition_matrix_history 表，或 topic_report 增加逐轮矩阵章节。
- **验证的命题**：认知网络如何从稀疏到稠密、单向到双向、谁先成为社交中心。
- **成本**：中，需要每轮汇总 other_cognition 表。

### 5. @提及响应率 + user_id 归因正确率

- **采集内容**：被 @ 的 agent 是否回复、回复延迟、user_id 与模型实际回应对象是否一致。
- **落点**：decisions.jsonl 增加 `mention_target` / `mention_responded` / `attribution_correct` 字段；topic_report 增加统计。
- **验证的命题**：多用户认知的核心指标——平台能区分"谁在说话"且 agent 能正确回应指定对象。
- **成本**：低，上一轮 sim 消息注入已上线，只需补指标。

## 四、P2 顺手可收（零成本，供内部迭代）

### 6. 批次位置-回应对象对照

- 计算 batch_context 中每条消息的顺序号，与 decisions"回应对象"交叉统计，得出末位偏置的量化证据（5a30r 中 10 批全回末尾）。
- 用途：修末位偏置、定位黑洞（agent:0 恒不被认知）的修复前后对照。

### 7. 情绪-行为关联

- 交叉统计：mood 值与当次 reply/silent 的关系；mood 恒 0 的 agent（5a30r agent:3）与风格的关系。
- 用途：核查情绪更新链路（是否只对特定心情标签生效）。

## 五、依赖关系与实施顺序

```
P0-2 静默认知更新（低成本，独立） ─┐
P0-1 记忆检索日志（低成本，独立） ─┼→ 本轮即可做
P1-5 提及/归因指标（低成本，独立） ─┘
                                    │
P0-3 人格轨迹 ← 依赖：降演化阈值 + 修演化链路（前置）
                                    │
P1-4 认知网络时序 ← 依赖：采集落点稳定后
```
