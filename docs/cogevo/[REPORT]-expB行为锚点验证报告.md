# [REPORT] expB 行为锚点验证报告：LLM 看不懂纯数值

- 版本: v1.0
- 日期: 2026-08-09
- 平台: cognitive_evolution_test / deepseek-v4-flash / temperature 0.7
- 关联: [PLAN]-改造后AAA实验规划.md §3.7；[EXP]-人格漂移输出影响验证实验方案.md
- 数据落盘: `docs/experiments/cognitive_evolution_test/runs/20260809_011232_expB`（纯数值全极值）、`20260809_014407_expB`（行为锚点 D 组）、`20260809_015727_expB`（百分比 D 组）、`20260809_020626_expB`（百分比+程度说明 D 组）

## 1. 摘要

expB（人格漂移→prompt→输出 因果验证）重验后，directness 维度在极值对照（0.1 vs 0.9，跨 8 格）下依然无显著输出差异，而 curiosity/warmth 显著。本报告验证用户提出的核心假设——**大模型看不懂纯数值**——通过四路 prompt 格式对照，最终确认：数值表达形式（小数/百分比/程度说明）均无法让 LLM 从数值反推行为，行为描述（锚点）是唯一有效方案（d=1.166，p<0.0001）。生产已升级为「数值+行为锚点」注入格式。

## 2. 背景与问题

expB 重验（20260808_233658）结论：A/B 真实漂移（显示层跨 1 格）全维无显著，C 组方法敏感性仅 warmth 通过。在此基础上，20260809_011232 全极值对照（0.1 vs 0.9）暴露更尖锐的问题：

| 维度 | 极值响应 d | p | 判定 |
|------|-----------|-----|------|
| curiosity | 1.224 | <0.0001 | 极显著 |
| warmth | 0.499 | 0.0033 | 显著 |
| directness | 0.315 | 0.1268 | **失效** |

curiosity/warmth 的标签词（好奇心/温暖度）语义自带行为指向，LLM 能从数值脑补行为；「直接度」词义模糊（简洁？直率？不客气？不绕弯？），LLM 无法从数值反推行为。**假设：数值的语义载荷依赖标签词本身的行为清晰度，直接度失效是 prompt 表达问题。**

## 3. 实验设计

### 3.1 变量

唯一变量 = prompt 中【你的性格】段的表达格式。四路对照：

| 路 | 格式 | 示例（directness） |
|----|------|-------------------|
| A | 纯数值 | `直接度: 0.1` |
| B | 纯百分比 | `直接度: 10%` |
| C | 百分比+连续程度说明 | `直接度: 10%` + 「百分比越高程度越高」 |
| D | 数值+行为锚点 | `直接度: 0.1（委婉含蓄、铺垫较多、不直接说重点）` |

### 3.2 组与样本

- 组：D_low（directness=0.1）/ D_high（directness=0.9），其余三维固定 0.5
- 输入：20 条 POOL_NEUTRAL 中性问题 × 5 采样 = 100 样本/组
- 统计：Mann-Whitney U（手写含并列秩）+ Cohen's d
- 观测：生产同款 `estimate_style_from_reply`（口径一致）
- 对照：B/D 路另含 warmth/playfulness/curiosity 交叉维度（验证维度特异性）

### 3.3 工程改进（支撑实验效率）

- 并行化：组内 3 线程 → 组间+组内全并行（`run_all_parallel`，6 线程统一池），600 次调用从 ~60 分钟降至 ~15 分钟
- 稳定性：`llm_infer` 402/429/5xx 指数退避重试（4 并发实测偶发 402，单发最小请求正常，非余额问题）
- 可复用：`--groups`（选组）、`--inputs`（条数）、`--repeats`（采样）、`EXP_PARALLEL`（线程）、`EXP_PERCENT`（格式开关）

## 4. 结果

### 4.1 四路对比（directness 维度自身响应，n=100×2）

| 格式 | Δ | Cohen's d | p | 判定 |
|------|-----|-----------|-----|------|
| 纯数值（0.1 vs 0.9） | +0.038 | 0.315 | 0.1268 | ✗ |
| 纯百分比（10% vs 90%） | +0.008 | 0.066 | 0.7147 | ✗ |
| 百分比+连续程度说明 | +0.025 | 0.218 | 0.3199 | ✗ |
| **数值+行为锚点** | **+0.185** | **1.166** | **<0.0001** | ✓ |

### 4.2 维度特异性（锚点版 D 组交叉维度）

| 维度 | Δ | d | p |
|------|-----|-----|-----|
| directness（自身） | +0.185 | 1.166 | <0.0001 |
| warmth（交叉） | -0.021 | -0.176 | 0.2715 |
| playfulness（交叉） | -0.011 | -0.120 | 0.8643 |
| curiosity（交叉） | -0.007 | -0.045 | 0.8525 |

交叉维度全部无显著——锚点只驱动目标维度，无泄漏。

### 4.3 意外发现（百分比版交叉效应）

纯百分比版 D 组中，directness=0.9 组的 curiosity 观测显著升高（d=0.429，p=0.0132）——LLM 把「90%」的强表述脑补为整体激进表达，波及其他维度。无锚点的数值越「强」，LLM 自行脑补的偏差越大。

### 4.4 小样本警示

百分比+程度说明路先跑 5 条试算（n=25）曾得 d=0.428，全量（n=100）回落到 0.218——n=25 的 Cohen's d 估计误差极大，不可作为结论依据。

### 4.5 程度副词插值版（v2.0，20260809_022312，n=100×2）

针对用户指出的关键缺陷「数值可连续变化、三档锚点描述无法变化」（三档锚点把 0.14→0.23 抹平为同一描述），生产升级为程度副词插值：程度词（略微/有点/比较/相当/非常/极其）× 双极基元按 |v-0.5| 连续生成描述（0.14「非常委婉含蓄」vs 0.23「相当委婉含蓄」）。

| 对照 | 维度 | Δ | d | p |
|------|------|-----|-----|-----|
| D 极值（0.1 vs 0.9） | directness | +0.248 | **1.855** | <0.0001 ✓ |
| D 极值交叉维度 | warmth/playfulness/curiosity | - | 全 <0.27 | 全 ≥0.52（净） |
| A/B 真实漂移（0.14 vs 0.23） | directness | -0.032 | -0.174 | 0.2003（不显著） |
| A/B 真实漂移 | curiosity | +0.025 | +0.174 | 0.3441（不显著） |

两个结论：① 连续程度词比三档锚点响应更强（d 1.166→**1.855**），交叉维度依然干净，生产 v2.0 升级成立；② **描述连续性已修复，但 A/B 真实漂移仍不可测**——「非常 vs 相当」对 LLM 都是「很委婉」，效应量仍低于 LLM 行为分辨率。连续化解决的是「描述不随数值变」，不解决「真实漂移幅度本身太小」。

### 4.6 五档动作级版（v2.1，20260809_023851，n=100×2）——真实漂移首次显著

用户进一步指出「影响大模型的不是数值而是描述」——插值版相邻档只差程度词，描述差异仍不够。升级为五档动作级：每档一段独立行为描述，行为模式随档变化（directness 档0「委婉含蓄、说话绕圈子，先寒暄铺垫再引入正题，几乎不直接说重点」vs 档1「比较委婉、说话留有余地，会先铺垫但能点到正题，偶尔直接表态」）。

| 对照 | 维度 | Δ | d | p |
|------|------|-----|-----|-----|
| **A/B 真实漂移（0.14 vs 0.23）** | **directness** | **+0.126** | **+0.805** | **<0.0001 ✓** |
| A/B 真实漂移 | warmth | -0.036 | -0.285 | 0.072（接近） |
| A/B 真实漂移 | playfulness | +0.012 | +0.137 | 0.304 |
| A/B 真实漂移 | curiosity | +0.011 | +0.074 | 0.674 |
| D 极值（0.1 vs 0.9） | directness | +0.193 | 1.236 | <0.0001 ✓ |
| D 极值交叉维度 | 其余三维 | - | 全 <0.30 | 全 ≥0.15（净） |

**「人格漂移影响大模型输出」首次获得统计显著证据（d=0.805，p<0.0001）**，且同向=True（向量 Δ=+0.094 → 输出 Δ=+0.126，漂移方向正确传导）。warmth 漂移（0.41→0.43 跨档）也接近显著（p=0.072），是五档区分能力的旁证。代价是极值区分度从 1.855 降至 1.236（依然强）。**证据链闭合：影响 LLM 的是描述而非数值；描述差异分辨率决定漂移可测性。**

## 5. 结论

1. **根因确认：LLM 无法从纯数值反推行为。** 数值（无论 0-1 小数还是 0-100% 百分比）是抽象刻度，不携带「该表现出什么行为」的语义；行为描述（「直截了当、不拐弯抹角」）才是 LLM 的执行语言。
2. **数值表达形式无关紧要。** 证据链 d：纯数值 0.315 / 纯百分比 0.066 / 百分比+程度说明 0.218 / 行为锚点 1.166 / 插值版 1.855 / 五档动作级 1.236——换刻度外壳（百分比）、补刻度语义（程度说明）都只有边际或负向效果，跨不过「数值→行为映射」鸿沟。
3. **影响大模型的是描述，不是数值（用户观点证实）。** 人格向量对 LLM 是「描述选择器」而非自变量；进入语义空间的是行为文本。
4. **描述差异分辨率决定漂移可测性。** 真实漂移（0.14→0.23）在纯数值/插值版下不可测（相邻档只差程度词），在五档动作级下**首次统计显著（d=0.805，p<0.0001，同向）**——「人格漂移影响大模型输出」最终获得证据支持。
5. **行为锚点有效性 = 维度特异性 + 强效应。** 各方案交叉维度全净；观测函数无维度耦合（v7.4 瘦身后验证一致）。

## 6. 生产变更

`nodes/node_python_aaa_cognition/personality.py`：

- **v1.9**：四维行为锚点（三档），初证数值不可替代描述。
- **v2.0**：程度副词插值（程度词×双极基元），解决三档抹平连续演化；极值 d=1.855 最强但真实漂移不可测。
- **v2.1（当前）**：五档动作级——每档一段独立行为描述（行为模式随档变化），真实漂移可测（d=0.805），极值 d=1.236 依然强。生产采用 v2.1。

```python
_PERSONALITY_BANDS = {
    "directness": [
        "委婉含蓄、说话绕圈子，先寒暄铺垫再引入正题，几乎不直接说重点，常用「可能、也许」",
        "比较委婉、说话留有余地，会先铺垫但能点到正题，偶尔直接表态",
        "有话直说但注意分寸，简洁明确，适当客套",
        "比较直接、简洁明确，少客套，直接进入正题",
        "直截了当、不拐弯抹角、开门见山，不铺垫直接说",
    ], ...  # warmth/playfulness/curiosity 同构
}
_PERSONALITY_BAND_EDGES = (0.2, 0.4, 0.6, 0.8)

def _personality_anchor(dim, v):
    idx = 4
    for i, edge in enumerate(_PERSONALITY_BAND_EDGES):
        if v <= edge:
            idx = i
            break
    return f"（{_PERSONALITY_BANDS[dim][idx]}）"
```

## 7. 遗留与建议

- **档内漂移仍不可测**：五档区间（≤0.2/≤0.4/≤0.6/≤0.8/>0.8）内同档漂移（如 0.14 vs 0.19）描述不变。真实漂移若跨档（0.14→0.23）已验证可测；若需观测档内微变，需档位细分（8-10 档）——但相邻档描述差异会变小，存在「描述分辨率」与「档位数」的权衡，实测验证前不预设。
- **观测函数分辨率是另一上限**：观测档位（0.5/0.85/0.15）离散化压缩可检测空间；本轮 d=0.805 已远超观测噪声，真实漂移在五档下足够显著，短期无需优化。
- **E5 不受阻**：预取偏好观测不依赖输出风格强度，人格状态可控性已被多轮极值对照证明。
- **观测函数**：directness 关键词已瘦身（v7.4），全部验证交叉维度干净，确认观测函数无维度耦合。
