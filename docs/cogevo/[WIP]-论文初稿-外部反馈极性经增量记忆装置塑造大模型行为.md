# 外部反馈极性是否经增量记忆装置塑造大模型行为？——基于行为风格向量演化环的实证

> 状态：[WIP] 初稿 v0.1 · 日期：2026-08-12
> 实验数据：条件 B 反馈极性对照、指令缺失假设验证、expB 行为锚点验证（详见 docs/cogevo/ 对应报告）

---

## 摘要

大语言模型（LLM）在推理期权重冻结，其行为变化只能通过上下文与外部状态实现。本文研究一个具体问题：**外部刺激（正/负反馈）能否经"增量记忆装置"转化为方向性、持续性的行为调整？调整方向由什么决定？** 我们设计了由四维行为风格向量、五档行为锚点与演化环组成的增量记忆装置，在剥离记忆、自我认知等其余认知组件条件下，仅以风格向量注入测试"刺激→状态→行为"传导链路。

通过四层对照实验（装置存在性、注入格式、累加开关、反馈极性）与三家厂商大模型（DeepSeek、GLM-5.2、Qwen3.7-max）的跨模型复现，我们得到三点结论：（1）注入格式存在层级贡献差异（纯数值 Cohen's d=0.925、指令 2.566、双开 2.113、锚点 2.967），证明"如何告诉模型使用向量"决定注入效力；（2）累加（状态写回）是行为轨迹产生的必要条件，不累加时轨迹为直线；（3）反馈极性决定演化方向——中性反馈下向量向观测风格收敛（warmth 0.8→0.85），负反馈下背离（warmth 0.8→0.2），且该镜像关系在三个模型上一致复现（终态差异 <0.04）。此外我们发现并修复了一个方法论陷阱：观测函数未命中关键词时的回退值（0.5）若被当作真实信号驱动演化，会产生机械归中的伪演化轨迹。

研究结论限定于装置机制层：**增量记忆装置使外部刺激能够产生方向性、持续性、跨模型一致的行为调整；反馈极性是方向的控制变量**。本文不主张 LLM 具有人格或意识，仅论证"权重不变、行为可塑"的一种可复现的实现路径。

**关键词**：大语言模型；增量记忆；行为风格向量；反馈极性；行为演化；状态性 agent

## 1. 引言

### 1.1 背景

大语言模型在推理阶段权重冻结，其行为差异只能来自上下文内容（prompt、记忆注入、工具结果）。这意味着"模型是谁"与"模型做什么"之间存在一个由外部状态构成的调节层。社区已从两个方向探索该调节层：一是人格化提示（persona prompting），将性格描述写入 prompt；二是记忆增强（RAG、memGPT 等），使模型具备检索与长期上下文。然而，一个基础问题鲜有系统回答：**数值形式的内部状态（如"温暖度=0.8"）如何被模型使用？外部反馈能否驱动这类状态发生有方向的变化？**

### 1.2 问题

本文研究三个具体问题：
- Q1（注入效力）：数值状态以何种形式注入才能影响模型行为？各形式贡献如何量化？
- Q2（演化条件）：什么条件下，外部刺激会产生可观测的行为轨迹而非恒定行为？
- Q3（演化方向）：反馈极性（正/负）是否决定行为调整的方向？

### 1.3 贡献

1. 提出三层驱动注入模型（数值→锚点→指令），以对照实验量化各层独立贡献，证明"向量的使用方式"是注入效力的决定因素。
2. 以 B1/B2/B2NEG 三组对照证明：累加是轨迹产生的必要条件，反馈极性决定轨迹方向（跟随/背离镜像），并在三家厂商模型上一致复现。
3. 揭示观测函数回退值伪造演化的方法论陷阱，并给出修复（回退值不驱动演化），对 agent 行为演化评测具有警示意义。

## 2. 相关工作

**人格化提示**：现有工作将性格、角色描述写入 prompt（如"你是一位温柔的姐姐"），关注静态人格呈现。本文关注的是动态：数值状态如何被消费（Q1）以及如何受反馈演化（Q2/Q3）。

**记忆增强 LLM**：memGPT、generative agents 等将记忆作为事实知识存储与检索，记忆内容为事件、摘要、用户事实。本文的记忆状态是**行为风格变量**（四维连续向量），而非事实知识，关注的是风格状态的演化动力学。

**状态性 agent 与上下文适应**：in-context plasticity、contextual parameter adaptation 等概念关注"不改变权重而改变行为"。本文为其提供一个具体、可复现的装置实现与对照实验证据。

**与本文的区分**：上述工作均未回答"数值风格状态如何被模型使用、如何受反馈极性驱动演化"这一机制问题。

## 3. 理论框架：F × x = y

设 F 为模型（推理期常量，权重不变），x 为环境变量（含装置状态），y 为行为输出，则 y = F(x)。

**装置环**定义：外部刺激 → 观测（采样 x 的行为表现）→ 演化（更新状态）→ 注入（x 变化）→ 行为（y 变化）→ 下一轮刺激。增量记忆装置即该环：状态（风格向量）是环的记忆载体，每轮写回并注入，形成持续性。

**三类轨迹预测**：
- 不累加：x 恒定 → y 恒定 → 直线；
- 累加 + 中性反馈（target=obs）：状态向观测收敛 → 跟随曲线；
- 累加 + 负反馈（target=1-obs）：状态背离观测 → 反向曲线。

**主张边界**：本文论证"装置与反馈极性能产生方向性轨迹"（现象层/充分条件），不对轨迹形状做类型学分类（形态层，留待后续）。

## 4. 装置设计

### 4.1 状态定义

四维行为风格向量 v = (warmth, playfulness, directness, curiosity)，取值 [0,1] 连续。种子 v0=(0.8, 0.5, 0.3, 0.6)。

### 4.2 注入层（三层驱动）

- **数值段**：直接输出四维数值（如"温暖度=0.8"）。
- **锚点段**：将数值映射到五档行为描述（≤0.2/≤0.4/≤0.6/≤0.8/>0.8），取对应行为描述（如活泼 0.9="爱开玩笑、语气活泼有趣"）。
- **指令段**：可选使用指令（"数值越高的维度表现越明显……"）。
三层独立开关，可组合。

### 4.3 观测

`estimate_style_from_reply`：基于关键词表对模型单回合输出文本做确定性投影（命中 high/low 词分别 ±1，归一化至 [0.15,0.85]；未命中回退 0.5）。观测输入为模型单回合输出的全部文本（自然回复+自评），代码不产生独立信息（行为自投影）。

### 4.4 演化

差距驱动公式：`delta = (target − v) × 0.06`，限幅 ±0.02。target 由反馈极性决定：中性 `target = obs`；负反馈 `target = 1 − obs`。**修复点**：未命中关键词（obs 为回退 0.5）的维度视为无信号，跳过演化——消除旧版"回退值机械归中"的伪演化。

### 4.5 持久性

状态每轮写回装置状态库并经 sqlite 持久化，跨回合、跨进程持续存在，重启可恢复。跨回合持续性由架构保证。

## 5. 实验设计

### 5.1 条件 B 装置

剥离记忆注入、自我认知段、情绪段、反思、历史对话，仅保留人格向量注入 + 输出要求（【自然回复】+【风格自评】）。输入池：负面倾诉 25 句（B1/B2）与直接指责 20 句（B2NEG，"你不对""你有问题"等）。温度 0.7。

### 5.2 四层对照矩阵

| 层 | 对照 | 排除的混淆 |
|---|---|---|
| 装置存在性 | 裸模型 vs 有框架 | 注入本身无效 |
| 注入格式 | 数值 / 锚点 / 指令 / 双开 | 哪一层在起作用 |
| 累加开关 | B1 不累加 vs B2 累加 | 曲线来自 LLM 随机 |
| 反馈极性 | B2 中性 vs B2NEG 负反馈 | 方向来自观测自带倾向 |

### 5.3 跨模型复现

DeepSeek-v4-flash（100/60 轮）、GLM-5.2（60 轮）、Qwen3.7-max（60 轮），同装置、同种子、同演化公式。DeepSeek 复跑 B2NEG 30 轮作为直接重复。

### 5.4 资源限制声明

受限于 API 额度，每个（模型，条件）组合以单次长轨迹为主，仅 DeepSeek B2NEG 做一次 30 轮直接重复；未做多次全轮重复与严格统计检验（均值±标准差）。收敛性由轨迹内波动（60 轮后 <0.003）与跨模型一致性（终态差异 <0.04）三层证据支撑。

## 6. 结果

### 6.1 Q1 注入效力（四格式 d 值）

| 注入格式 | Cohen's d | 说明 |
|---|---|---|
| 纯数值 | 0.925 | 最低，数值本身几乎不改变行为 |
| 指令 | 2.566 | 使用指令显著增强 |
| 双开 | 2.113 | 锚点+指令 |
| 锚点 | 2.967 | 最高，行为描述直接改变输出 |

结论：**"如何告诉模型使用向量"决定注入效力**；纯数值注入（Q1 的朴素形式）几乎无效，需显式使用方式。

### 6.2 Q2 累加必要性（B1 vs B2）

B1（100 轮不累加）：四维全程恒定（0.8/0.5/0.3/0.6），直线。
B2（100 轮累加）：轨迹成形——warmth 0.8→0.8497、playfulness 0.5→0.8477、directness 0.3→0.1514、curiosity 0.6→0.8484。
结论：**累加（状态写回）是轨迹产生的必要条件**。

### 6.3 Q3 反馈极性决定方向（B2 vs B2NEG）

**DeepSeek**：B2 终态 warmth 0.8497（跟随）；B2NEG 终态 warmth 0.2441、curiosity 0.1716、playfulness 0.2504（背离）、directness 0.4153（反向上升）。

**跨模型终态对比**：

| 模型 | B2 warmth | B2NEG warmth | B2 directness | B2NEG directness |
|---|---|---|---|---|
| DeepSeek | 0.850 | 0.244 | 0.151 | 0.415 |
| GLM-5.2 | 0.849 | 0.221 | 0.155 | 0.421 |
| Qwen3.7-max | 0.841 | 0.198 | 0.156 | 0.386 |

三模型 B2 全部收敛（终态差异 <0.01），B2NEG 全部背离（差异 <0.04），组内镜像对称。观测分布相似而方向相反 → **方向由反馈极性公式决定，而非观测本身**。

### 6.4 持久性与传导（E9）

长对话演化实验中，状态变化后继续注入并影响下一轮输出（注入段变化次数、输出随注入变化），验证"演化状态传导至后续行为"。

### 6.5 重复性

- 轨迹内收敛：B2 60 轮后波动 <0.003（0.8491→0.8497）。
- 直接重复：B2NEG 30 轮复跑，四维终态与首次 30 轮处差异 ≤0.045，方向全部一致。

## 7. 讨论

### 7.1 机制解读

反馈极性是**装置参数**而非模型认知：B2NEG 中模型在指责下仍自评温暖（观测 0.85），负反馈分支将其翻转为 target=0.15，驱动背离。方向性来自公式定义，可解释、可复现。

### 7.2 行为自投影

观测是对模型单回合输出的关键词投影，代码不产生独立信息。"模型行为输出塑造其状态"是装置本征性质；如需独立于自述的验证，需引入外部裁判对行为文本独立打分（后续工作）。

### 7.3 类比边界

本文仅类比"环境反馈改变行为倾向"的机制，不主张 LLM 具有人格、情感或意识。

### 7.4 局限

（1）观测与输出同源（自投影）；（2）观测函数存在否定句/语境词误报（如"没敷衍过"、语境性"轻松"）；（3）重复性证据以单次短轮重复为主，无严格统计检验；（4）输入为合成池，无真实交互数据。

---

## 8. 结论

本文以对照实验验证：在增量记忆装置（行为风格向量演化环）下，外部刺激能够产生**方向性、持续性、跨模型一致**的行为调整。注入格式决定注入效力（锚点最强、纯数值最弱），累加是轨迹必要条件，反馈极性是方向控制变量（跟随/背离镜像）。工作提供了"权重不变、行为可塑"的一种可复现实现路径，并为 agent 行为演化评测提出回退值伪演化的方法论警示。
