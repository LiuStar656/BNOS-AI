    '''

## 四、关键修复记录

### 4.1 对话历史丢失

**问题**：重启程序后聊天记录丢失。

**根因**：消息只在内存中保存，未持久化到磁盘。

**修复**：在 `chat_page.py` 中实现 `_save_history()` 和 `_load_history()`：

```python
def _save_history(self):
    """保存当前对话历史到 JSON"""
    path = self._history_dir / f"{self._current_cid}.json"
    path.write_text(json.dumps(history, ensure_ascii=False, indent=2), encoding="utf-8")
```

### 4.2 节点管理窗口刷新闪烁

**问题**：节点管理窗口每隔几秒刷新一次，导致闪烁。

**根因**：`_on_nodes_changed` 每次收到通知都重建整个树。

**修复**：引入数据缓存比较，仅数据变化时才重建。

### 4.3 停止引擎后无法启动

**问题**：停止引擎后，再次点击启动报"存在其他引擎进程"。

**根因**：WMIC 进程检测不准确，部分进程残留。

**修复**：改用 PowerShell 精确匹配进程名和命令行参数。

### 4.4 FloatingPanel 半透明不生效

**问题**：设置面板半透明背景不显示。

**根因**：FloatingPanel 作为子窗口继承了主窗口的 `WA_TranslucentBackground`，导致渲染冲突。

**修复**：移除 `parent` 窗口关联，独立窗口 + 内层 `_container` QSS 控制透明度。
