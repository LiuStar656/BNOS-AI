## 二、核心组件设计

### 2.1 FloatingPanel 浮动面板

```python
class FloatingPanel(QDialog):
    """浮动面板基类 — 无边框、半透明、可滚动内容区"""

    def __init__(self, parent: QWidget | None = None, title="悬浮面板"):
        self.setWindowFlags(Qt.WindowType.Tool | Qt.WindowType.FramelessWindowHint)
        self.setAttribute(Qt.WidgetAttribute.WA_TranslucentBackground)
```

**架构：**

```
FloatingPanel (QDialog)
├── 外层透明窗口
├── _container (QWidget)  → 半透明背景 + 圆角边框
│   ├── 标题行 (title + 关闭按钮)
│   ├── 分隔线
│   └── QScrollArea
│       └── content (由 set_content_widget 注入)
```

**关键方法：**

| 方法 | 作用 |
|------|------|
| `set_content_widget(widget)` | 替换滚动区内容，自动触发 `_auto_resize` |
| `_auto_resize()` | 根据内容高度自适应面板尺寸 |
| `_rgba(color_key, alpha)` | 从主题色生成半透明 RGBA 值 |

### 2.3 主窗口无边框 + 边缘 resize

```python
# nativeEvent 处理 WM_NCHITTEST
def nativeEvent(self, eventType, message):
    if eventType == b"windows_generic_MSG":
        msg = ctypes.wintypes.MSG.from_address(int(message))
        if msg.message == 0x0084:  # WM_NCHITTEST
            # 计算边缘命中，返回 HTLEFT/HTRIGHT/HTTOP/HTBOTTOM 等
            return True, ctypes.c_longlong(ht).value
```

边缘判定区域：`_RESIZE_MARGIN = 8` 像素。

### 2.5 消息请求 ID 过滤

在 `message_manager.py` 中引入 `request_id`：

```python
# 发送消息时生成唯一 request_id
request_id = str(uuid.uuid4())[:8]
self._pending_requests[request_id] = callback

# 收到回复时按 request_id 路由
def _on_message_response(self, response):
    req_id = response.get("request_id")
    callback = self._pending_requests.pop(req_id, None)
    if callback:
        callback(response)
```

解决：当多个请求连续发送时，回复不会错位。

## 四、设计决策

| 决策 | 理由 |
|------|------|
| 浮动面板用 `QDialog` 而非 `QWidget` | QDialog 内置 `exec()`、`accept()`、`reject()`，模态控制方便 |
| 半透明用双层架构 | 外层 `WA_TranslucentBackground` 窗口透明，内层 `_container` 控制背景色 |
| WM_NCHITTEST 而非 QSizeGrip | QSizeGrip 右下角太小且样式难以统一 |
| request_id 而非时间戳 | UUID 前 8 位即可保证单次会话内唯一，比时间戳更可靠 |
