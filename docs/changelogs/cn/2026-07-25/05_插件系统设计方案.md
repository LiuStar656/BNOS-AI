## 二、核心设计

### 2.1 插件生命周期

```
发现 → 安装 → 注册 → 启用 → 运行 → 停用 → 卸载
```

| 阶段 | 说明 |
|------|------|
| 发现 | 扫描 `plugins/` 目录下的 `plugin.json` 清单 |
| 安装 | 复制文件到 `plugins/`，解压依赖 |
| 注册 | 读取 `plugin.json`，注册到插件注册表 |
| 启用 | 注入到运行环境，激活钩子 |
| 运行 | 响应事件总线事件，执行插件逻辑 |
| 停用 | 注销钩子，释放资源 |
| 卸载 | 删除插件目录，清理注册表 |

### 2.2 通信协议

插件与 BNOS 核心之间通过事件总线通信：

```
插件 → BNOS: 发射事件
BNOS → 插件: 订阅事件（通过钩子注册）
插件 ↔ 插件: 禁止直连，必须经核心转发
```

### 2.3 安全沙箱

- 插件运行在独立进程中（类似节点）
- 文件系统访问受限（仅 `plugins/<name>/` 目录）
- 提供权限声明系统（`plugin.json` 中声明所需权限）
