# 05 — 对话管理优化与进程重构

> 日期：2026-07-26 | 涉及文件：6 | 变更类型：UI 优化

---

## 一、问题描述

对话管理功能存在多个细节问题：对话无法重命名、归档列表未在归档面板中正确加载、聊天气泡滚动未自动到底、进程清理依赖 PowerShell 脚本不够可靠。

## 二、根因分析

1. 对话重命名 UI 交互缺失，右键菜单中未实现重命名回调
2. 归档面板直接从 `conversation_history.json` 读取但不更新 UI 状态
3. 气泡滚动逻辑中，新消息追加后未强制滚动到底部
4. 旧进程终止逻辑使用 PowerShell 脚本清理，容易遗漏子进程

## 三、修改方案

### 3.1 对话重命名 (chat_page.py)

在对话列表右键菜单中实现重命名，调用 conversation_history.json 更新函数。

### 3.2 归档面板 (chat_page.py)

修复归档面板加载逻辑，确保恢复对话后 UI 状态正确更新。

### 3.3 气泡滚动优化 (chat_bubble.py)

```python
# 修复前
def _auto_scroll(self):
    pass  # 未实现

# 修复后
def _auto_scroll(self):
    scrollbar = self._scroll_area.verticalScrollBar()
    scrollbar.setValue(scrollbar.maximum())
```

### 3.4 进程终止逻辑 (engine.py/process_killer.py)

将 PowerShell 脚本清理替换为 Python 原生进程管理：
- 使用 `subprocess.Popen.kill()` 终止子进程树
- 记录进程 PID 到状态文件，重启时清理孤儿进程

## 四、影响范围

- `gui/pages/chat_page.py`：重命名和归档逻辑
- `gui/widgets/chat_bubble.py`：自动滚动
- `bnos_runtime/engine.py`：进程终止逻辑
- `bnos_runtime/process_killer.py`：替代 PowerShell 清理脚本

## 五、验证方法

1. 右键对话 → 重命名，确认新名称正确保存
2. 删除对话 → 归档面板中能看到 → 恢复后对话出现
3. 发送新消息，确认气泡自动滚动到底部
4. 关闭程序，确认所有子进程正确终止
