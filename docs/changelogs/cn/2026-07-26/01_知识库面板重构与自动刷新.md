# 01 — 知识库面板重构与自动刷新

> 日期：2026-07-26 | 涉及文件：2 | 变更类型：功能优化

---

## 一、问题描述

原有知识库面板数据源为硬编码 JSON，无法从数据库实时读取最新记录。切换标签页到知识库时，数据停留在上一次加载的状态，必须手动刷新或等待 10 秒自动刷新定时器。

## 二、根因分析

1. `KnowledgePanel.__init__` 仅在构造时调用 `_load_data()` 加载一次数据
2. 数据库由 AAA 节点持续写入新记录，但面板没有感知更新的机制
3. 10 秒定时器虽能自动刷新，但切换页面时不会触发立即刷新

## 三、修改方案

### 3.1 数据库驱动重构 (knowledge_panel.py)

将 JSON 数据源替换为 SQLite 查询，使用 `QSqlDatabase` 或 `sqlite3` 直接读取：

```python
# 重构前：读取 JSON 文件
with open("data.json") as f:
    self._data = json.load(f)

# 重构后：从数据库查询
conn = sqlite3.connect(dbp)
rows = conn.execute("SELECT id, content, created_at FROM long_term_memory ORDER BY id DESC LIMIT 50").fetchall()
```

### 3.2 页面切换自动刷新 (main_window.py)

在 `_switch_page` 方法中，当切换到 `knowledge` 页面时触发 `_load_data()`：

```python
def _switch_page(self, page_id: str):
    ...
    self._slide_animation(target, direction)
    # 切到知识库页面时刷新数据库数据
    if page_id == "knowledge" and hasattr(target, "_load_data"):
        target._load_data()
```

同时处理动画进行中被取消的情况，在两个分支都加入刷新逻辑。

## 四、影响范围

- `gui/widgets/knowledge_panel.py`：核心重构
- `gui/main_window.py`：页面切换触发刷新

## 五、验证方法

1. 启动 GUI，切换到知识库页面，确认数据从数据库加载
2. 在聊天中输入新对话（触发 AAA 写库），切换到其他页面再切回知识库，确认数据已更新
3. 检查 10 秒自动刷新定时器仍然正常工作
