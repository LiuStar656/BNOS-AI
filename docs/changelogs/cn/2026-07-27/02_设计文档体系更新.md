# 02 — 设计文档体系更新

> 日期：2026-07-27 | 涉及文件：~10 | 变更类型：文档更新

> 合并 commits `581bbaf` (02:34) 和 `e93b3b6` (20:59)

---

## 一、问题描述

设计文档体系不完整，缺乏系统级架构设计方案（存储系统、插件系统、角色系统等）的统一规划。已有设计文档存在重复内容且未及时清理，不利于团队协作和后续开发参考。

## 二、根因分析

1. 存储系统缺乏三层架构设计文档，数据持久化方案不明确
2. 插件系统仅停留在需求阶段，缺少完整设计方案
3. 自主行为机制未形成事件驱动型设计文档
4. 通用组件复用情况无系统分析清单，存在重复开发风险
5. 角色种子系统和三维角色自定义系统缺少设计文档，制约角色相关功能开发
6. BNOS-AI 开发文档中缺少回合制滞后机制、生成标记、提示词防注入等重要设计决策记录
7. 部分老旧设计文档内容重复，需要清理

## 三、修改方案

### 3.1 新增存储系统三层架构重构方案

新增 `[OK]-存储系统三层架构重构方案.md`，定义：
- 存储层（Storage Layer）：底层数据持久化
- 服务层（Service Layer）：业务逻辑封装
- 接口层（API Layer）：对外统一访问接口

### 3.2 新增并完善插件系统设计方案

新增 `[OK]-插件系统设计方案.md`，涵盖：
- 插件生命周期管理
- 插件注册与发现机制
- 插件沙箱隔离策略
- 插件 API 定义规范

### 3.3 新增事件驱动型自主行为方案

大幅更新 `[OK]-事件驱动型自主行为方案.md`，定义事件总线、事件优先级、异步处理等核心机制。

### 3.4 新增通用组件复用分析清单

新增 `[OK]-通用组件复用分析清单.md`，对现有组件进行系统化复用分析，识别可抽象为通用组件的模块。

### 3.5 新增角色种子系统设计文档

新增 `[OK]-角色种子系统设计文档.md`（683 行），详细设计：
- 角色种子数据结构
- 种子生成与变异算法
- 种子库管理

### 3.6 新增三维角色自定义系统设计文档

新增 `[OK]-三维角色自定义系统设计文档.md`（528 行），涵盖：
- 三维模型加载与渲染
- 角色外观自定义参数
- 动画状态机设计

### 3.7 开发文档与参考文档补充

在 BNOS-AI 开发文档中补充：
- 回合制滞后机制（Turn-based Lag）
- 生成标记（Generation Mark）
- 提示词防注入（Prompt Injection Prevention）

在参考文档中补充贾维斯组件复用分析。

### 3.8 删除重复老旧文档

清理 `docs/design/` 下的重复老旧设计文档，保持文档目录整洁。
