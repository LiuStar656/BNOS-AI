## 一、问题描述

知识库面板的筛选按钮依赖硬编码的表名列表，新增数据库表后需手动更新代码才能显示。内容展示格式单一，仅支持基本文本显示，无法展示 period、keywords 等多样化字段。界面标签文案不够清晰。

## 二、根因分析

1. 筛选按钮列表在代码中硬编码，每次数据库结构变更都需要修改 Python 代码
2. 内容展示仅处理了少数几种字段类型，period、keywords 等结构化字段未做特殊格式化
3. 部分界面标签文案描述不够直观，影响用户体验

## 三、修改方案

### 3.1 动态数据库表名筛选 (knowledge_panel.py)

动态读取数据库表名生成筛选按钮，替代硬编码列表：

```python
# 修复前：硬编码表名列表
TABLE_NAMES = ["long_term_memory", "cognitive", "event_summary"]

# 修复后：动态读取数据库表名
def _load_table_names(self):
    conn = sqlite3.connect(self._db_path)
    cursor = conn.execute("SELECT name FROM sqlite_master WHERE type='table' ORDER BY name")
    tables = [row[0] for row in cursor.fetchall()]
    conn.close()
    return tables
```

根据动态表名自动生成筛选按钮，新增数据库表后无需修改代码即可显示。

### 3.2 新增内容展示格式

新增多种内容展示格式，丰富信息呈现：

```python
def _format_cell(self, field, value):
    if field == "period":
        # 显示时间段范围
        return f"{value.get('start', '')} ~ {value.get('end', '')}"
    elif field == "keywords":
        # 关键词以标签形式展示
        return ", ".join(value) if isinstance(value, list) else str(value)
    # ...其他字段格式化
```

支持 period（时间段）、keywords（关键词列表）、tags（标签）等多种字段的格式化展示。
