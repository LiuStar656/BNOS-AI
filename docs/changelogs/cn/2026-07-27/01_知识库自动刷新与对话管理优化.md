# 01 — 知识库自动刷新与对话管理优化

> 日期：2026-07-27 | 涉及文件：~7 | 变更类型：功能优化

> 基于 commit `5c879de` (2026-07-27 00:03)

---

## 一、问题描述

知识库页面在切换标签页后数据停留在上一次加载的状态，无法实时反映数据库最新记录。消息发送过程中用户无法取消正在进行的请求。聊天气泡布局边距与尺寸计算存在冗余 QTimer 调用，对话切换时可能出现状态不同步问题。

## 二、根因分析

1. 知识库页面仅在构造时加载数据，页面切换不会触发刷新，缺乏手动刷新机制
2. 消息管理器缺少取消发送请求的接口，用户发起发送后无法中断
3. 聊天气泡布局计算中冗余 `QTimer` 调用导致不必要的重绘，边距与尺寸计算未优化
4. 对话切换时 pending 回复路由未正确清理，发送状态未重置，导致 UI 状态残留

## 三、修改方案

### 3.1 知识库自动刷新 (knowledge_panel.py)

在知识库页面添加切换和定时自动刷新逻辑，刷新间隔 10 秒，同时提供手动刷新按钮：

```python
# 新增：页面显示时触发刷新
def showEvent(self, event):
    super().showEvent(event)
    self._start_auto_refresh()

# 新增：定时自动刷新
def _start_auto_refresh(self):
    self._refresh_timer = QTimer(self)
    self._refresh_timer.setInterval(10000)  # 10 秒
    self._refresh_timer.timeout.connect(self._load_data)
    self._refresh_timer.start()

def _stop_auto_refresh(self):
    if self._refresh_timer:
        self._refresh_timer.stop()
```

同时添加手动刷新按钮，允许用户随时刷新知识库数据。

### 3.2 消息取消发送 (message_manager.py)

消息管理器新增取消正在进行的发送请求方法：

```python
def cancel_sending(self):
    """取消当前正在进行的发送请求"""
    if self._current_reply and self._current_reply.isRunning():
        self._current_reply.abort()
        self._current_reply = None
        self._sending = False
```

### 3.3 气泡布局优化 (chat_bubble.py)

聊天气泡布局边距与尺寸计算优化，移除冗余 QTimer 调用：

```python
# 修复前：冗余 QTimer 调用
QTimer.singleShot(0, self._update_layout)

# 修复后：直接调用
self._update_layout()
```

同时优化边距计算逻辑，减少不必要的重绘。

### 3.4 对话切换逻辑优化 (chat_page.py)

对话切换时新增 pending 回复路由清理与发送状态重置：

```python
def _switch_conversation(self, conv_id):
    # 重置发送状态
    self._message_manager.cancel_sending()
    # 清理 pending 回复路由
    self._pending_reply = None
    # ...其余切换逻辑
```
