# 05 AI 协作创建预设与换肤闭环（工具扩充）

## 问题描述

用户提出两个能力诉求：
1. DeepSeek Harness 可以用和 AI 交互的方式创建新的预设 —— 希望 BNOS GUI 也能
   「告诉 AI 需求 → 创建 Agent 预设」
2. 标签页 UI 能否像 DSH 一样通过告诉 AI 需求动态调整（换风格、换颜色/大小/背景）

## 根因分析

- DSH 官方 README 明确 user 预设可 "authored by a person **or by an agent**"，
  且预设创建唯一路径是 `copy()`（无 CLI 命令）—— 正好适合封装成 AI 工具
- 换肤链路此前已完整（skin_registry.install → apply_skin → THEME_CHANGED →
  apply_global 即时重绘 + 提案可回退），但 AAA 侧工具注入说明仅限「UI/主题变更」，
  未涵盖预设管理等场景

## 修改方案

- **AI 协作创建预设**：`gui/core/tool_registry.py` 新增 7 个 `dsh.preset_*` 工具：
  - `dsh.preset_list`（清单 + 人格文本 + 当前默认）
  - `dsh.preset_copy`（复制创建，DSH 唯一创建路径）
  - `dsh.preset_read`（元信息/人格或 agent.cordis.yml/preset.yml 内容）
  - `dsh.preset_write`（写自定义预设文件，组合校验）
  - `dsh.preset_persona`（读写人格，空串=移除）
  - `dsh.preset_remove` / `dsh.preset_set_default`
  - handler 延迟导入 pages 层避免循环依赖
- **换肤闭环**：`nodes/node_python_aaa_cognition/gui_tools.py::tool_list_text()`
  调用时机说明由「仅当用户请求 UI/主题相关变更时才调用」放宽为
  「UI/主题/皮肤、DSH 任务、Agent 预设管理、页面导航均可调用」

## 影响范围

- ToolRegistry 工具数 25（15 ui.* + 3 dsh.run_* + 7 dsh.preset_*）
- 用户可直接对 AI 说「创建一个叫 xx 的 Agent，人格是…，禁用 bash 工具」完成创建，
  下一次 headless 任务生效
- 布局结构调整（如侧标签→顶部标签）不在换肤范围，属数据驱动 UI 改造（更大工程）

## 验证方法

- `dsh.preset_list` / `preset_persona` 写+读 / `preset_read` / `preset_set_default`
  （含恢复内置）/ `preset_remove` 全部 ok，数据一致
- 换肤链路：create_skin_proposal → approve → 即时重绘 → revert 恢复
