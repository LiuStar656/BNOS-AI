# 09 数据驱动 UI 布局动态调整（侧边栏 ↔ 顶边栏热切换 + 回退）

## 背景

GUI 换肤（颜色/大小）已支持 AI 产出 + 提案审批 + 回退，但**导航布局**仍硬编码在
`main_window._init_central`：侧边栏固定竖排、不可配置、不可切换、不可回退。用户诉求：
"把侧边栏改成顶边栏"不重启生效、不满意可回退。本日志记录布局数据驱动化全量落地。

## 内容

- **布局 Schema 化**：新增 `gui/core/layout_spec.py` — LayoutSpec dataclass（id/name/
  nav_position/nav_width/nav_height/nav_mode/nav_visible/pages/window_default）+ 校验器
  （nav_position 枚举、数值边界、pages 引用存在性、重复页检测；非法值拒绝不静默钳制）
- **布局注册中心**：新增 `gui/core/layout_registry.py` — 内置 default 代码内注册（不落盘）+
  扫描 `gui/resources/layouts/`；install 安全字符校验（同 SkinRegistry）；同名内置优先
- **布局应用器**：新增 `gui/core/layout_engine.py` — apply(spec, window)：删旧导航 →
  按 spec 创建新导航（SidebarNav/TopNav）→ 重连信号 → 保持当前页 → 持久化 layout_id →
  发布 LAYOUT_CHANGED；`bind()` 供提案审批等无窗口上下文调用
- **导航视图抽象**：`gui/widgets/sidebar.py` 改造 — 抽 NavView 接口（page_changed/
  settings_clicked/node_clicked/set_active/refresh_theme），原 Sidebar → SidebarNav（竖排，
  行为不变）；新增 `gui/widgets/top_nav.py` — TopNav 顶栏横排（icon/text/icon_text 外观）
- **MainWindow 数据驱动化**：`_init_central` 改为读配置 layout_id → LayoutEngine 组装导航；
  订阅 `LAYOUT_REQUEST` 统一入口；切换动画方向按当前布局页面顺序计算
- **提案治理扩展**：`proposal_store.py` 支持 kind="layout"（approve：prior 快照 layout_id →
  install → apply；revert 恢复 prior 布局）；提案页徽标映射加 "布局"
- **AI 工具闭环**：`tool_registry.py` 新增 `ui.list_layouts`（布局清单+激活态）与
  `ui.apply_layout`（name 引用已注册布局 / spec JSON 定义新布局，均生成提案待审批）；
  gui_tool_schemas.json 由 tool_bridge 启动时自动刷新（工具 25→27）
- **示例布局包**：`gui/resources/layouts/top-nav/layout.json` — 顶部标签栏（nav_position=top）
- **持久化**：`config.py` 增加 `layout_id` 默认值，重启自动恢复上次布局

## 验证

- offscreen 自动化 9 组断言全过：注册中心扫描 / 校验器拒非法 / 默认左栏 / top↔default
  切换（页面实例复用、当前页保持）/ 非法 spec 拒绝 / 提案 approve→revert 闭环 /
  LAYOUT_REQUEST 消息路径 / 工具注册数量
- 真机视觉回归（8 套预设 + run.bat 启动）待用户运行确认

## 使用方式

1. 用户对 AI 说「把标签栏挪到上面」→ AAA 输出 `ui.apply_layout(name="top-nav")`
2. 提案页出现「布局」提案 → 批准 → 顶部标签栏即时生效（不重启、页面状态保留）
3. 不满意 → 提案页回退 → 恢复侧边栏；重启后保持上次布局
