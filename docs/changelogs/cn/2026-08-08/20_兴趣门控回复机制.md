# 20 兴趣门控回复机制（v7.0）

## 问题描述

`exp_5a30r_v3`（20260808_115334）重跑确认**末位偏置是系统性机制缺陷**：冷板凳轮转后末位回应率仍 80.6%（31 条可定位中 25 条）。根因不是模型，而是**判定权归属**：

> 谁值得回应，由 LLM 在长上下文中自由推断 → 模型用"最后一条"作为启发式捷径。

冷板凳轮转（v6.5）只是把末位让给被忽视者，属于"利用偏置"而非"消除偏置"。机制性修复需把"回应对象判定"收归平台显式完成。

## 根因分析

| 问题 | 根因 |
|---|---|
| 末位偏置无法消除 | 回应对象由 LLM 自由推断（无显式判定），任何批次内排序调整都只是转移偏置位置 |
| 不感兴趣的 agent 也强制调 LLM | 每个候选 agent 每批都决策，即使与话题无关（浪费调用、制造凑热闹式发言） |
| 兴趣无法量化 | 无平台侧兴趣判定，兴趣分布不可观测、不可成为实验指标 |

## 修改方案

### 机制设计（对齐 `[PLAN]-兴趣门控回复机制.md`）

1. **兴趣锚点**：每个 agent 最近一次广播发言（自我介绍为初始锚点），发言后更新（兴趣随参与漂移）；
2. **兴趣值**：`cos(消息嵌入, 锚点嵌入)` 余弦相似度（`paraphrase-multilingual-MiniLM-L12-v2` 多语模型，384 维归一化向量）；
3. **门控判定**：批内消息对锚点的最大相似度 ≥ 阈值 0.60 → 过门（`reason=interest`）；`reply_to==agent` 或被 `@` 点名 → 直接过门（`reason=direct`）；
4. **编码一次、比对多次**：批内每条消息只编码一次（缓存），与全部 agent 锚点做 numpy 点积；O(m) 编码 + O(n×m) 点积，实测离线加载 7.7s + 10 条编码 0.03s，真实瓶颈始终是 LLM 调用；
5. **省调用**：未过门 agent 不调 LLM（平台判静默），判定结果（检测文本 + 兴趣值）写入各 agent 数据库 `interest_judgment` 表（用户明确要求）；
6. **兜底**：无模型 → `no_model`、无锚点 → `no_anchor`（均全过门退 v6.6）；无任何 agent 过门 → 兴趣值最高者 `interest_floor` 兜底过门（防对话停滞）；
7. **上下文不裁**：门控只决定"谁决策"，过门 agent 的 LLM 上下文仍是完整批次——保证与 v6.6 末位偏置统计口径可比；
8. **仲裁排序**：`@ 点名 > 兴趣值高 > 冷板凳（被回应少者优先）> 原顺序`（gate 关闭时兴趣维度恒 0，退回 v6.6）。

### 阈值标定（calibrate_interest_threshold.py）

用 5a30r_v3 真实 31 条 reply（25 对可计算）标定：真实接话 median 0.653 / p25 0.499；随机基线 median 0.464 / p90 0.701。取真实 p25 与基线 p90 中点 **0.600**（0.7 会丢 68% 真实接话，用户原稿阈值过高）。

### 落库（interest_judgment 表，每个 agent 自己的 sqlite）

| 列 | 含义 |
|---|---|
| `detected_text` | 检测文本：被评估消息的内容（兴趣最高/直接命中那条） |
| `interest_value` | 兴趣值：余弦相似度 |
| `passed` / `reason` | 是否过门 / 原因（direct/interest/none/interest_floor） |
| `round_no` / `message_seq` / `anchor_text` | 轮次 / 消息池全局序号 / 兴趣锚点文本 |

平台进程直写（判定发生在 LLM 决策之前，时序串行）；`db.ensure()` 建表 + 平台 `CREATE TABLE IF NOT EXISTS` 幂等兜底；`data_export` 全表导出自动覆盖。

## v7.1 增量：近期观察记录注入（方案 a，20260808）

**动机**：5a20r_v2 验证发现，未过门 agent 对消息的留存只有 interest_judgment（检测文本 + 兴趣值），但该表**不进 LLM 上下文**——"记了"但"想不起"。用户决策方案 a：过门决策时把未过门（passed=0）的最近 N 条 detected_text 注入上下文，让"看过但没回应"想得起，零额外 LLM 调用。

**实现**：`db.py` 新增 `read_recent_observations()`（按 identity_key + passed=0 过滤，id 倒序去重取 N=5 条，容错返回空串）；`main.py` `_gather_context` 注入 ctx；`prompt.py` `_CONTEXT_HEADER` 在"你的他人认知"后渲染【近期观察记录】节（空则不渲染，1对1 不受影响）。

**验收**：U13.7 五项（passed=0 过滤 + 倒序去重 + limit 上限 + 空表容错 + prompt 渲染/空节不渲染）→ 163/163 全过。

**v3 实验（20260808_130257，exp_5a20r_v3，门控 + 观察注入，新随机种子）**：

| 指标 | v2（门控） | v3（门控+注入） |
|---|---|---|
| 末位回应率 | 58.8% (10/17) | 66.7% (14/21) |
| 门控过门率 | 30/55 (54.5%)，省 25 次 | 33/45 (73.3%)，省 12 次 |
| 双向认知组 | 3 组（agent:1/3 被抹掉） | **6 组**（全员进入网络，无黑洞） |
| 低 curiosity agent | agent:1/3 各发言 1 次 | agent:1 过门 7、agent:4 过门 5 |

> v3 与 v2 同配置（门控开、阈值 0.6）但种子/话题不同（v3 话题生活化：冷萃咖啡），低 curiosity agent 未被静音——印证"认知黑洞是种子×话题的组合效应，非门控必然结果"，支持"轮次少 × 性格偏好放大"的诊断。观察注入对认知网络的单独贡献需更长轮次（40+）才能量化，20 轮内为软性影响。

## v7.2 增量：旁观者接话切入判定 + 滑动注意力窗口（20260808）

**动机**（用户设计语义）：整批判定有两类失真——(1) 对整批取"兴趣最高"判定，感兴趣消息可能被不感兴趣消息稀释；(2) 过门后对完整批次决策，无法显式表达"从谁说完话后开始接话"。用户场景：1 说话 → 2 过门答 1 → 3 没过门旁观 → 1 回复 2 → **3 作为旁观者**按时间顺序（从旧到新）逐条发言做过门判断，第一个过门的发言 = 接话切入点，决定 3 从谁的话之后开始插话。

**实现**：
1. `judge_sequence`（interest_gate.py）：候选改为**全部消息按 seq 从旧到新逐条判定（同发言者不去重）**——1 的第一条、2 的次早发言、1 的回复第三条独立判定，第一个过门的 = 切入点（target + target_speaker 落库）；
2. **接话窗口**（platform_runner.py）：过门 agent 的决策上下文 = `(自己最近发言, 切入消息]` 的所有历史消息（不含自己、无截断），`_msg_history` + `_last_speech_seq` 维护；未发言 agent 下界 = 消息池起点（旁观者看到全对话脉络）；
3. **口径**（agent_bridge.py）：`batch_context` = 窗口（决策实际所见，指标统计依据）、新增 `batch_full` = 完整批（与 v6.6 口径对照复核）、`window_size`；
4. 锚点滑动：锚点 = 各自 agent 最新一次写入消息池的发言（广播后更新），判定依据随参与漂移（滑动注意力窗口）。

**验收**：U13.8 六项（从旧到新逐条判定、同发言者独立判定、direct 优先、窗口区间、未发言下界、平台集成 batch_context/batch_full）→ **169/169** 全绿。

**实验（20260808_134554，exp_5a20r_v4，20 轮哲思话题）**：
- API 调用 total=33 vs v3 的 41（**-19.5%**）；每决策 LLM 输入字符（token 近似）3176 vs v3 4063（**-22%**，窗口收窄聚焦对话流区间）；
- agent:1/3 全程旁观：interest_judgment 33/33 条 passed=0（最高兴趣 0.590/0.554 < 0.6 阈值），实证"对这 20 轮对话不感兴趣"（判定层面 0 过门，非没机会参与）；agent:3 唯一 1 次调用是冷笑话批兜底（interest_floor），面对全历史窗口仍 silent；
- 窗口滑动实证：agent:4 逐轮窗口 seq 区间随自己发言下界滑动（[1] → [3..10] → [12] → [15]...）；
- 代价：旁观者（下界=0）窗口 = 全历史（max=27 条）个别决策 token 膨胀；参与不均随话题放大。

**60 轮新话题实验（20260808_140318，exp_5a60r_ai_self，话题"AI 该不该有自我意识"）**：
- 60/60 轮跑满，total=102（AAA 97 + 直连 5），per_agent **极均匀**（16-22 次，极差 6）——话题性质决定参与分布，"AI 自我意识"让全员（含俏皮/温和型）持续感兴趣；
- 每轮成本 1.70 调用/轮 vs v4 的 1.65——**成本跟随参与度而非轮数**，拉长轮数不放大成本；
- 60 轮产生跨显示阈值的真实漂移（agent:0 directness 0.14→0.23、curiosity 0.1→0.2；agent:3 play 0.87→0.73），成为实验 B 组 B 向量来源。

**实验 B 联动（20260808_142236，人格漂移输出影响验证）**：组 C 极值对照（warmth 0.1 vs 0.9）**d=+0.962 / p=0.0000 极显著**——首次实证"状态→输出"环：模型确实读取性格向量段并改变输出；组 A/B 真实漂移（幅度仅极值 1/8）无显著差异属统计功效不足，非注入失效。建议提高显示精度 .1f→.2f 或增大演化步长 0.02→0.05 后重跑闭环。
