# 数据浏览"仅冒号"占位修复

## 问题描述

数据浏览页面中很多条记录只显示一个冒号（如 `"content": ""`），冒号后没有内容；
用户反馈"有很条信息只有一个冒号"。经排查，8 条 `user_messages` 记录存储为
JSON 包装的**空消息**：`{"data_type": "text", "content": "", "source": "text"}`。

## 根因分析

写库层与显示层双重问题：

1. **写库层** `db.py` `_write`：`c = data.get("content", "") or json.dumps(data)`。
   content 为空字符串（falsy）时，把整个消息 dict JSON 序列化后写入
   `user_messages`，产生 `{"data_type":"text","content":"",...}` 垃圾记录。
2. **显示层** `knowledge_panel.py` `_read_db`：对 content 字段原样显示，
   空 JSON 显示为 `"content": ""`——即"冒号后没内容"的占位。

修复前验证 `_read_db()` 提取链（mood/thought 安全拼接）已无冒号残留，
说明冒号来源是这批 JSON 记录本身，而非通用提取逻辑。

## 修改方案

### 1. 堵源头（`db.py` v5.5）：空 user 消息不入库

```python
# 旧：content 为空时 JSON 序列化整段消息入库
c = data.get("content", "") or json.dumps(data, ensure_ascii=False)

# 新：空 user 消息直接丢弃
c = data.get("content", "")
if role == "user" and (c is None or str(c).strip() == ""):
    conn.close()
    return
if not c:
    c = json.dumps(data, ensure_ascii=False)
```

### 2. 兼容存量（`knowledge_panel.py` v1.6）：显示层解析 JSON 包装消息

```python
# 提取链之后新增：JSON 包装的消息解析出真实 content；为空则后续整条跳过
if isinstance(content, str) and content.lstrip().startswith("{"):
    try:
        inner = json.loads(content)
        if isinstance(inner, dict) and "content" in inner:
            content = inner.get("content") or ""
    except Exception:
        pass
```

解析后为空内容命中后续 `if not content ... continue`，垃圾记录不再显示。

## 影响范围

| 文件 | 改动 |
|------|------|
| `nodes/node_python_aaa_cognition/db.py` | `_write` 空 user 消息直接返回（v5.5） |
| `gui/widgets/knowledge_panel.py` | `_read_db` 解析 JSON 包装消息、空内容跳过（v1.6） |

存量 8 条 JSON 垃圾记录不再显示（不删除数据，仅显示层过滤）；
后续不再产生新的空消息 JSON 记录。

## 验证方法

- 写库层：`_write` 收到 `{"data_type":"text","content":"","source":"text"}`
  （role="user"）→ 直接返回，`user_messages` 无新增。
- 显示层：复现 `_read_db()` 输出，数据浏览 296 条记录中
  JSON 垃圾 0 条、仅冒号 0 条。
