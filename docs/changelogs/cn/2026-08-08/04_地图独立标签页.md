# 地图独立标签页

## 问题描述

定位地图原本放在设置悬浮窗内，入口深、空间小，与"AI 定位信息"独立可视化的定位不符，需要迁移到 GUI 单独一个侧边栏标签页展示。

## 根因分析

- 设置悬浮窗承载的是配置项（主题、性格参数、人格格式化等），地图属于运行时状态可视化，混放导致面板臃肿。
- 侧边栏已有"知识库 / 设置"等标签体系，地图作为独立页符合既有导航结构，且能给地图更大的展示空间。

## 修改方案

1. **`gui/pages/location_page.py`（新建）**：`LocationPage` 独立地图页，承载地图视图与定位信息展示。
2. **`gui/widgets/sidebar.py`**：新增"地图"标签，注册到侧边栏导航。
3. **`gui/main_window.py`**：注册 location 页面；`_after_page_switch` 在切换到地图页时懒加载，避免启动即初始化地图组件。
4. **`gui/pages/settings_panel.py`**：移除设置面板中的地图区域，设置面板回归纯配置职责。

## 影响范围

| 文件 | 改动 |
|------|------|
| `gui/pages/location_page.py`（新增） | 独立地图页 LocationPage |
| `gui/widgets/sidebar.py` | 新增"地图"标签 |
| `gui/main_window.py` | 注册 location 页面；`_after_page_switch` 懒加载 |
| `gui/pages/settings_panel.py` | 移除地图区域 |

## 验证方法

- GUI 启动后侧边栏出现"地图"标签，点击可切换到独立地图页。
- 切换前不初始化地图组件（懒加载），设置面板无地图残留。
