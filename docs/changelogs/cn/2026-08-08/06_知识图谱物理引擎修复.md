# 知识图谱物理引擎修复

## 问题描述

知识图谱布局存在五个问题：

1. 节点生成坐标随机散布，希望所有节点在**同一坐标**（画布中心）生成，生成后立即计算力矩按规则显示物理效果。
2. **力尺度功能失效**：调整 L 后布局尺寸差异过小（仅放大 1.37 倍），且中心重力随 L 衰减导致大力尺度下节点飞散。
3. 两个相互吸引的节点平衡距离太近，无法通过力尺度调节。
4. 连线在全部节点生成完成后才出现，希望与节点一样**流式**浮现。
5. **画布无限但节点空间被限制**：力尺度拉到最大时节点散布后形成正方形轮廓，不会跑到正方形外面。

## 根因分析

- 原 `setup()` 按随机坐标生成节点，位置散布无规律，物理动画从已散开的初始态开始。
- 力尺度 L 只作用于斥力强度，未缩放斥力半径与吸引平衡距离；重力先随 L 缩小（飞散）后改为固定但仍受矩形边界约束。
- `step()` 中存在 margin=30 的**矩形硬边界反弹**逻辑：大力尺度下节点被推到 1500×1200 矩形四壁，贴边排成正方形——这正是"正方形轮廓"的直接根因。
- 连线在 `_load_next_node` 全部完成后一次性创建，无流式机制。

## 修改方案

全部改动位于 `gui/widgets/knowledge_graph.py`：

1. **同坐标生成**：`setup()` 所有节点从画布中心同点生成 + 随机初速度冲量（1.0~2.0）打破对称，随后斥力/引力接管，从中心自然弹开。
2. **力尺度 L 缩放体系**：
   - 斥力半径 `REPEL_RADIUS * L`（上限画布半宽）——L 大 → 斥力范围广 → 布局更散；
   - 吸引平衡距离 `ATTRACT_TARGET_DIST * L`（clamp 25~120）——解决吸引节点贴太近，且随 L 可调；
   - 中心重力**固定** `GRAVITY_STRENGTH`，不随 L 衰减——防止大力尺度下无限飞散。
3. **圆形软边界替代矩形硬边界**：移除 margin=30 四壁反弹；新增 `BOUNDARY_RADIUS = AREA_WIDTH * 0.5`（750px）、`BOUNDARY_PULL = 0.01`，节点超出半径被柔和回拉，半径内无任何边界力——节点可自由散布到任意方向，不再形成正方形轮廓。
4. **动态画布扩展**：新增 `_expand_scene_to_fit(states)`，sceneRect 只扩大不缩小（margin=80）跟随节点包围盒，保证所有节点可滚动到。
5. **连线流式生成**：GraphEdge 记录 `start_idx` / `end_idx`，两端节点都显示时才浮现连线。
6. **节点显示重置**：`_load_next_node` 显示节点时重置引擎状态到中心并赋予冲量（2.0~4.0），保证"从中心弹出"动画可见。

## 影响范围

| 文件 | 改动 |
|------|------|
| `gui/widgets/knowledge_graph.py` | setup 同坐标生成；力尺度 L 缩放（斥力半径/吸引平衡距离）；重力固定；圆形软边界替代矩形硬边界；`_expand_scene_to_fit` 动态画布；连线流式生成；节点显示重置 + 冲量 |

## 验证方法

- 参数实验（真实相似度分布：15% 强相关 + 30% 弱相关 + 55% 无关）：L=5 布局收敛 ~400px 半径、无贴边节点；L=1 默认布局紧凑 ~124px 不受软边界影响。
- 临时验证脚本 `_verify_nobound.py`（验证后删除）11 项检查全通过：L=5 无贴边节点（无正方形轮廓）、布局收敛 max_r<700、L=1 紧凑、极端全互斥也不飞散（max_r<2500）、sceneRect 初始/扩展/只扩大不缩小、无矩形硬边界反弹代码、圆形软边界存在、编译通过。
