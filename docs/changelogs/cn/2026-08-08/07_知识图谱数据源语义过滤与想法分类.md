# 知识图谱数据源语义过滤与"想法"分类

## 问题描述

知识图谱把所有数据库表的数据都塞了进来，导致三类问题：

1. **噪声节点**：feelings 大量只有 mood 无 thought 的纯情绪词记录（如只有"开心"）；long_term_memory 混入 `role='tool'` 的工具返回（如"结果"）、`source='diary'` 的整篇日记、长度 ≤10 的碎片内容，均无语义区分度。
2. **瞬时/元数据表不应入图谱**：定位坐标、情绪统计、配置键值等非语义记忆，图谱应只呈现"AI 对用户和自己的长期语义记忆"。
3. **"想法"不可见**：feelings 表的 thought（想法）在数据预览中显示为"情感"标签，图谱 hover 显示情绪词分类，用户看不到"想法"。

## 根因分析

- `MEMORY_QUERIES` 未做质量过滤：feelings 无条件限制、long_term_memory 只按 `status='active'` 过滤，低区分度记录直接进图谱。
- `diaries`（日记）被遗漏——整篇日记以 `source='diary'` 混入 long_term_memory，未走 diaries 表统一承载，且图谱数据源未包含 diaries 表。
- feelings 节点 category 使用 mood（情绪词）作为分类，与表名/内容不一致，GUI 无法按"想法"识别。

## 修改方案

### 数据源过滤（`nodes/node_python_aaa_cognition/memos.py`）

1. **`MEMORY_QUERIES` v4 语义过滤**：
   - feelings 只保留 `thought IS NOT NULL AND thought != ''`（剔除纯情绪词噪声）；
   - long_term_memory 剔除 `role='tool'` / `source='diary'` / `LENGTH(content) > 10`（保留 exchange 合并 QA 与 seed 种子背景）；
   - **新增 diaries 表**数据源（`LENGTH(content) > 10`）；
   - 明确不纳入：user_messages（原始对话噪音）、location_history、fixed_cognition、self_info、personality_seed、mood_trend、mood_value（瞬时/元数据）。
2. **`GRAPH_INDEX_VERSION` 3→4**：触发全量重建，清除旧索引中不符合新过滤条件的残留节点。

### "想法"分类（v5）

3. **`memos.py`**：feelings 节点 category 从 `mood` 改为 `'feelings'`（GUI 显示"想法"）；`GRAPH_INDEX_VERSION` 4→5 再次全量重建。
4. **`gui/widgets/knowledge_panel.py`**：`TABLE_LABELS["feelings"]` 由"情感"改为"想法"（分类按钮与卡片标签同步）。
5. **`gui/widgets/knowledge_graph.py`**：新增 `CATEGORY_LABELS` 映射，hover 想法节点显示 `[想法]` + 想法内容。

## 影响范围

| 文件 | 改动 |
|------|------|
| `nodes/node_python_aaa_cognition/memos.py` | MEMORY_QUERIES v4 语义过滤 + 纳入 diaries；GRAPH_INDEX_VERSION 3→4；feelings category 改 'feelings'；GRAPH_INDEX_VERSION 4→5 |
| `gui/widgets/knowledge_panel.py` | TABLE_LABELS feelings "情感"→"想法" |
| `gui/widgets/knowledge_graph.py` | CATEGORY_LABELS 映射 + hover tooltip 显示"想法" |

## 验证方法

- SQL 过滤逐一核对：feelings 21 条（均含 thought）、long_term_memory 17 条（无 tool/diary/超短残留）、diaries 纳入（当前空表）。
- 全量重建后 knowledge_graph.json：117 节点，feelings 21 个节点 category 全部为 `'feelings'`，超短内容 0 残留。
- 三个文件编译检查通过（GetDiagnostics 无报错）。
- GUI：数据浏览左侧出现"想法"分类；图谱 hover 想法节点显示 `[想法]`。
