# 19 批次顺序事实源统一与七项数据采集实施（v6.6）

## 问题描述

`exp_5a30r_v2`（20260808_111908）实验分析报告遗留 6 个问题，其中 4 项为数据口径/链路缺陷，2 项为机制未达成；同时 `[PLAN]-数据采集价值清单与方案.md` 要求 7 项采集落盘，本次一并实施：

- **P0-1 decisions/events 批次顺序不一致**：decisions.batch_context 顺序 `[agent:1,2,3,4,0]` 与 events.batch_dispatched `[agent:0,1,2,3,4]` 记录同批成员但顺序不同——末位偏置分析依赖"谁在批次末尾"，顺序来源不统一会动摇所有偏置结论；
- **P0-2 空 user_id 污染 other_cognition**：round_2_agent_0 `user_id=""` 且回应对象为自身，空键进入认知矩阵统计；
- **P1-3 幽灵发言未根除**：reply 35 条 vs events 入队 30 条，topic_ended 后仍生成 5 条未入队 reply；
- **P1-4 round_9_agent_1 输出截断**：内容止于半句，想法 / user_id / 回应对象字段全空；
- **P1-5 末位偏置仍在**：黑洞消失仅是批次位置轮转的偶然结果，机制本身未动；
- **P1-6 人格零漂移**：演化兜底阈值 30 在 30 轮配置下永不触发。

## 根因分析

| 问题 | 根因 |
|---|---|
| P0-1 顺序不一致 | batch_context 与 batch_dispatched 分别从"定制顺序"与"派发顺序"两个来源记录，无全局唯一序号关联 |
| P0-2 空归因污染 | `_write_parsed` 批量路径对 `user_id=""` 未过滤，空键直接写入 other_cognition |
| P1-3 幽灵发言 | `step()` / `drain_queue()` 在 topic_ended 后仍处理残余批次并产生新决策/广播 |
| P1-4 截断 | max_tokens 放大后仍可能截断，且无截断检测与重试 |
| P1-5 末位偏置 | 回应对象仍由 LLM 从批次自由推断，无显式判定，也无量化指标 |
| P1-6 零漂移 | `_FALLBACK_TRIGGER_COUNT=30` 远高于 30 轮实验内单 agent 交互次数（5-8 次） |

## 修改方案

### P0-1 批次顺序唯一事实源（message_pool.py + platform_runner.py）
1. `Message.to_dict()` 携带 `seq`（消息池全局单调递增序号），`enqueue_input` 自增 `_seq`；
2. `platform_runner.step()` 中 `ordered = {a: self._batch_for(a, batch)}` 每个 Agent 定制顺序只计算一次，batch_context 与 batch_dispatched 同源；
3. decisions.batch_context 与 events.batch_dispatched 通过 seq 关联互证。

### P0-2 空 user_id 过滤（db.py + main.py + topic_report.py）
1. `db._write_parsed(..., skip_empty_other=True)`：批量模式跳过空归因的 other_cognition 写入（GUI 1对1 路径保留空 user_id 作为"全局认知兜底"）；
2. topic_report `_read_other_cognition` 读取侧防御性过滤空键。

### P1-3 幽灵发言源头熔断（platform_runner.py）
`step()` 与 `drain_queue()` 在 `not topic_active` 时提前返回，topic_ended 后不再产生新决策/广播。

### P1-4 截断检测 + 重试（parser.py + main.py + aaa_serve.py）
`parser.is_truncated(raw)` 双信号：未闭合节标记（`^【[^】]{1,16}$`）/ 有【自然回复】缺【情绪调整】；命中后 LLM 循环追加提示重试一次；inline 与 subprocess（aaa_serve）路径均已接入。

### P1-5 末位偏置量化指标（agent_bridge.py + topic_report.py）
决策新增 `reply_target_pos`（回应对象在 LLM 实际所见批次位置）、`batch_last_author`、`mention_targets` / `mention_responded`（回应点名者）/ `attribution_ok`（user_id==回应对象），末位偏置从"观感"变为可量化指标。

### P1-6 演化兜底阈值（personality.py）
`_FALLBACK_TRIGGER_COUNT` 30 → 10，neutral 反馈触发 warmth 收敛。

### 数据采集落盘（对齐 `[PLAN]-数据采集价值清单与方案.md`）
| 采集项 | 落盘位置 |
|---|---|

| P0-2 静默认知更新 | `silent_cognition` 表（db.py `_write_silent_cognition`）+ decisions.silent_cognition_written |
